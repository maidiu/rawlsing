## I. Closed outcomes and accounting (never conflate)
Every packet must end with exactly one signed **engineering disposition** at its actual evidence grade:
- `ACCEPT_SCOPED`: implemented or existing code demonstrably satisfies **all in-scope hard gates**, independent nonauthor receiver accepts exact frozen SHA. May carry separately named native/scientific/host/actor external HOLDs. This means **packet engineering accepted**, NOT protected merge, original35 scientific acceptance or whole machine completion.
- `ALREADY_SATISFIED`: exact existing accepted/protected owner and actual first-consumer proofs meet the same contract at the same grade; independent receiver verifies that doing nothing is valid. A source stub/import is not sufficient.
