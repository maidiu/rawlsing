7. Pushed worker return but no HQ adoption → INTAKE, not reimplement or treat ACCEPTED.
8. Reviewer is implementer or candidate changed after review → reject alleged independent acceptance.
9. Two writers overlap same exact owner/write paths → serialize/correct ownership; unrelated critical-path source science proceeds concurrently.
10. No qualified source/operation/EE12/EE13/model-use issuer → SCIENTIFIC_HOLD, never infer data nor declare measured zero/noncomparability.

## B. Executable host qualifications (separate from unit logic)
At least one locally executed Node/Python test suite in an isolated sparse worktree with captured versions, actual commands, exit status, logs and full exact SHA. Prove no scheduler side effects in advisory mode by snapshotting synthetic Git/worktree and local state before/after. Test malformed JSON, duplicate task IDs, missing quota states, fake repo refs, competing update, crash while writing local advisory state, and restart preservation. For any proposed connection to dispatcher, independently qualify existing dispatcher against its separately documented OPS-03 repair gates: complete immutable commission/session, true CLI model+variant binding, process completion notification, torn log hostility, single writer, Git-derived changed terrain, remote expected-parent refusal and trusted HQ publication. Local role prompts alone are not host isolation.

## C. Review
Independent reviewer receives exact immutable candidate+test tip, original input/expected cases frozen before execution, and fresh checkout. Must perform negative mutation tests (wrong condition, forged training privacy, stale budget, self-adoption, unexpected provider fallback and invalid reviewer signature) and verify cross-tree compatibility, not merely accept implementer's report.
