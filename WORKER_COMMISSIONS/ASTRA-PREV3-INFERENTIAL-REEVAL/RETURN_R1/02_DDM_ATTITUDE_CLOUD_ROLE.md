# DDM, respondent geometry and empirical psychological evidence

## Start from the current functional successor

The central empirical object is the joint respondent record, or an information-equivalent lawful query over it. Structural/material reports and attitudes coexist in the same survey respondent. This supports conditional response distributions, interactions, prediction and measurement hypotheses; it does not require a source sentence spelling out each discovered relation.

This is already Trii's conserved empirical/discovery burden. Current implementation must serve it through governed PRE553 producers, exact/adaptive discovery, learned-product lifecycle and FIELD FORGE's capability/relation contract. No new universal cloud object, database or geometry is necessary. Arbitrary future joint queries require sufficient respondent-bound information; a selected finite query can use an exact sufficient carrier. Source-indexed plurality remains the default. ## What historical artifacts establish

V549b retains question/driver lineage, response/respondent joins and branch-conditioned anchors. V550 code retains position signatures, co-signatures and same-respondent attitude-pair diagnostics. The inspected helper returns joint support, conditional/baseline ratios, difference, lift, normalized mutual information and Cramér's V-related strength. Its own labels say prototype/diagnostic/not-direct-evidence. It selects a modal response pair, not a latent-person posterior. ([E07](11_EVIDENCE_INDEX.md#e07)–[E10](11_EVIDENCE_INDEX.md#e10))

Trii already investigated losses in these historical generations: exhaustive pair search versus primary-star search, recursive branch information, cloud correctness and missing full-profile products. Therefore the right question is whether current exact/adaptive services conserve the declared functional frontier. It is not whether old cloud code should become current again. ([E24](11_EVIDENCE_INDEX.md#e24))

The inspected helper still supplies useful concrete verification lessons:

1. Its paired numerator can be divided by an unpaired anchor denominator. Four anchor-positive records with only two observed companion answers, both positive, give 0.5 under that ratio and 1.0 among complete pairs. The full-anchor probability is bounded by [0.5, 1.0] without further assumptions.
2. A modal-cell summary discards minority and contrasting joint configurations.
3. Support/association confidence tiers are heuristics, not sampling intervals or calibrated psychological probabilities.
4. Unweighted crosstabs and max(NMI, Cramér's V) do not constitute a survey-design-aware effect estimate; a field named mutual_information stores normalized MI.

These are static findings about the historical helper. They are not proved defects in every current successor. A current contract needs explicit denominators, retained/recoverable joint information and validation suited to its intended use; it does not need a rewrite of all old modules.

## What co-observation buys scientifically

Estimate P(A | S, C), where S is structural/material evidence, A is an attitude response or tested measurement construct, and C is context. Useful prediction is possible even when P(A | do(S), C) is unidentified.

| Role | Claim | Legitimate contribution |
|---|---|---|
| Measurement | A response imperfectly measures an expressed orientation | Noisy likelihood, with wording, response style, setting and time |
| Description | Responses co-occur within the declared source/risk set | Joint pattern or conditional distribution |
| Prediction | Other observations improve held-out response estimates | Scoped conditional model, masked-item prediction, probabilistic seeding after named-use adoption |
| Latent cloud | A fitted model summarizes correlated responses | Model-dependent membership/uncertainty; not an observed natural type |
| Mechanism | Theory suggests a pathway or moderator | Weak prior structure, competing features and falsifiable hypotheses |
| Causal effect | A design identifies an intervention contrast | Only the supported causal use, not inferred from predictive fit alone |

Accepted documentary semantics already distinguish WVS7 Q146–Q148 worry responses and WVS4 V80–V83 financial satisfaction, life satisfaction, perceived control and work/leisure orientation. They are psychologically informative reports. Satisfaction is not wealth; perceived control is not institutional power; worry is not a diagnosis. ([E15](11_EVIDENCE_INDEX.md#e15))

Country averages cannot substitute for individual relationships. Repeated cross-sections are not panels. Cross-survey string-equal respondent IDs cannot be joined as the same person. For synthetic persons, generate distributions and variation; do not copy an identifiable respondent biography.

## Minimal export through existing owners

A release or dereferenceable product should state:

- exact source release, unit, respondent/risk-set identity, scope/time and question/category meanings;
- eligible, observed, missing and routed-out counts; weights/design authority if claimed;
- complete response supports and recoverable joint information for the named analysis;
- discovery grammar/mode, actual coverage/pruning and selection provenance;
- constitutive items, predictors, outcomes, context and semantic-overlap groups;
- model/version, baseline, uncertainty, validation, permitted use and transport limits;
- producer dependencies, current selection and deterministic replay.

Reuse current fields and OBL034 lifecycle rather than create a parallel ownership system. A missing population overlay can limit inference to the observed source; it need not erase the source-local relationship. A lack of linkage or category meaning can still block that particular computation.

## Leakage controls that preserve usefulness

| Risk | Control |
|---|---|
| Define driver with X, then predict X | Mark X constitutive; reserve independent outcomes |
| Near-duplicates, recodes or translated copies | Group semantic families before splitting; review common stems and derived lineage |
| Respondent/household overlap | Partition by respondent and shared household/cluster where appropriate |
| Discover and confirm the same cloud on the same data | Freeze discovery features; validate on new respondents and disjoint measurement/outcome items |
| Context shortcuts | Report respondent-held-out and country/wave-held-out results separately; compare with context-only baseline |
| V3 input reused as criterion | Separate evidence-conditioned generation from structure-only prediction |
| Search many hypotheses and publish winners | Record all candidates; regularize/control multiplicity; freeze confirmation targets |
| Tuning on the test set | Fit selection, scaling, measurement models and expert revisions inside training folds |

Validation partitions match the intended claim; they are not a ritual demand to hold out every dimension simultaneously. Dependent-data validation needs deliberate blocking; the proposed Rawlsing design is an application, not a claim that a methodological paper validates this system. ([E18](11_EVIDENCE_INDEX.md#e18))

## Finite competing-model experiment

Use two tasks:

- **Structure-only:** predict a prespecified attitude panel from structural/context fields.
- **Evidence-conditioned:** add disjoint attitude inputs and predict other held-out items.

Compare on identical eligible units/folds: marginal/context baseline; semantic indicators; legacy-inspired expert features; DDM conditional model; SDTF/theory features; hybrid. Historical type-matrix execution is optional and separately permissioned.

Start with regularized categorical/ordinal models and one prespecified interaction family. Report log loss/Brier score, calibration, support, subgroup failures, transport degradation and cost. Use design-appropriate weights only where authorized; report source-local unweighted results as such. Cluster stability alone is not construct validity. Higher-order interaction searches should preserve the declared frontier, including cases with zero unary signal; otherwise label the search adaptive/partial.

Proposed release rule: freeze two primary outcome families and practical improvement/harm tolerances before fitting; report cluster-aware uncertainty on untouched respondents and at least one withheld context. Prefer complexity only when it adds measured value. If gains are uncertain, retain the simpler model for that scope. Negative findings complete an experiment and should revise hypotheses rather than launch another general architecture cycle.

## Entry into V3

Current PSEPF/comparator machinery is the relevant inherited route for actor-relative empirical possibility, with exact source/field/time comparability. PSEPF remains population possibility, not person truth. A new general prediction or seeding use must be explicitly reviewed where existing permissions do not cover it.

DDM may then inform bounded heterogeneous tendencies, conditioned on observed items when the task allows. It may not imply intervention effects, deterministic biography, actor knowledge of analyst-only data, or repeated annual developmental updates from one cross-sectional correlation.
