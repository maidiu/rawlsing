For rows 1–3 report breadth by source/context as well as volume. One large survey must not conceal absent families. Distinguish source-local empirical availability from certified population inference and physical full-workload execution. For row 4 preserve failures/negative findings in the declared denominator. For row 5 separate rule class, rule, application and actual consumer. For row 6 report the worst adequately supported subgroup as well as aggregate gain.

A useful checkpoint format is:

“X/Y declared sources processed; N reconciled respondents; usable observations by domain/use; K/J confirmed products; compiled rules / real applications; payloads consumed; test gain with uncertainty; time and cost per source.”

Do not improve a ratio by silently deleting hard cases or changing eligibility after looking at outcomes.

## Complexity must earn its place

For each proposed requirement record only the work cost, serious error prevented, affected outputs, measured empirical/coverage gain and whether the check can become automatic.

Provenance validity, semantic validity, formal consistency, theoretical plausibility, predictive validity, transfer, causal validity and downstream usefulness are different dimensions. A provenance PASS cannot fill the performance cell. Better prediction cannot waive incorrect semantics. Causal interpretation cannot be inferred from calibrated prediction.

Keep this dashboard small enough that HQ can see whether the generator is getting better, not merely whether the ledger is getting longer.
