## 3. Current anti-amputation tests

Any proposed Pyat refinement must answer all of these.

### A. Predictor preservation

Can a current product represent:

`POSITION → ATTITUDE POSSIBILITY`

and, where governed:

`ATTITUDE → POSITION POSSIBILITY`

`ATTITUDE → ATTITUDE POSSIBILITY`

without converting probabilistic conditionals into person essence?

### B. Fork preservation

Can a predictor surface retain:

`MODAL → MINORITY → OUTLIER → SECONDARY_SPLIT → RECURSIVE_SPLIT`

with exact scope, support, denominator and typed uncertainty?

If not, the DDM machine is not functionally conserved.

### C. Co-travel preservation

Can same-respondent response-response co-travel remain empirically available when no special semantic relation is admitted?

Required:

`NO_SPECIAL_SEMANTIC_RELATION != NO_EMPIRICAL_COTRAVEL`

### D. Joint preservation

Can an exact joint preserve:

- same respondent;
- ordered members;
- component authority;
- denominator/context;
- configuration uncertainty;
- governed roles when available;

without requiring a universal role vocabulary?

### E. Pressure preservation

Can structural-world machinery consume empirical products without:

- converting support into pressure;
- converting co-travel into causation;
- flattening minority configurations;
- writing actor state upstream?

### F. Multi-source preservation

Can multiple survey/source products contribute to one objective structural world while keeping:

- distinct universes;
- distinct respondents;
- source provenance;
- operation-specific comparability;
- no implicit pooling?

### G. Temporal preservation

Can same-survey waves become a lawful temporal field only after exact comparability, rather than by raw numerical subtraction?

### H. Parent-prior preservation

Can downstream PRE-V3 expose a field-like possibility service from which parent/coparent generation can condition progressively, without treating that service as a realized person?
