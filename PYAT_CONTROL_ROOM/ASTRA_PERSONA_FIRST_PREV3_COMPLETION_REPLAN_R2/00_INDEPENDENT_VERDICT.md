## Concrete discoveries that change the plan

1. **Original type scorer and declared intent disagree.** Local `enneagrams/cross-data/enneagramBatch.js` uses min-max normalization, not the softmax described in the pipeline document. Equal type scores give a zero denominator; missing driver values become zero. Keep it only as a historical comparison baseline, never a population-calibrated personality assignment.
2. **Atlas coverage does not establish mapping quality.** The inspected semantic table has 18,528 rows, including 14,166 fallback-cluster mappings; 14,189 rows are low confidence. The driver table has 28,983 rows, including 20,980 fallback-cluster mappings and 2,944 blank facet IDs. These are mapping-row counts, not unique original items. The historical 9-family/36-wave, 417/177 figures use a different reporting grain from the governed 35-wave queue. Do not multiply them into a completeness claim.
3. **A scale registry already prevents a consequential semantic mistake.** Afrobarometer R9 Q6A appears under a trust construct but is blocked with a note that it concerns food deprivation. Reuse the registry and its negative decisions; route this as material hardship only after exact meaning review. Reviewed transforms elsewhere may still be ordinal heuristics, not interval calibration.
4. **Temporal modeling already exists.** `ddm_v553_temporal_pressure.py::_interp` is linear; `_build_interpolated_pressure_rows` interpolates pressure components and labels anchors/interpolated years. Its confidence-penalty ledger carries heuristic provenance. Improve uncertainty and break handling in this lineage; do not commission a replacement temporal engine merely because a new Ghana comparison remains held.
5. **P01 has a real limitation stated in code.** `FrozenExpected` verifies a digest and a declared external freeze; it explicitly does not authenticate independent authorship/custody. This is useful integrity code, not external scientific issuance. Its accepted operation ceiling is bounded pair co-travel/discovery, not every all-35 operation.
6. **P04's documentation overreaches its evidence.** Its module asserts N9/N10W are absent everywhere. The fixture establishes only its own bounded non-implementation; current M4 publication/repository code exists. Determine the missing service composition and input-use semantics, not global absence from that sentence.
7. **TD_R05 contains an internal historical correction.** Its source-verification amendment strengthens YearRecord/hash/readiness/schedule findings and quarantines placeholders; later blanket fault prose is not a license to rebuild those corrected mechanisms. Local files are a different variant, so pin and compare before selecting a runtime.
8. **The Long Memory baseline is retrievable.** Exact D01 import retains 44 LMX and 30 LMQ rows with historical dispositions and Trii/Chetiri roles. Authority 40 already joins seven courts. The replan conserves those rows and routes current delta verification; another whole-history campaign is unnecessary.

## Judgment on delivery

A useful prototype may contain broad priors, conservative interpolation, simplified household models and provisional developmental parameters. These must be visible in the evidence trace and exercised by sensitivity tests. They do not require perfect scientific identification before use. A failed method comparison should result in the simpler fallback and a delivered artifact, unless the failure concerns legality, fabricated evidence, corrupted state or the specific operation's required trust boundary.

We have not executed project tests, raw surveys or V3 in this audit. Retained test results remain retained results. Static inspection cannot establish current end-to-end runnability; the first implementation commission must settle that with a bounded run, not another architecture survey.
