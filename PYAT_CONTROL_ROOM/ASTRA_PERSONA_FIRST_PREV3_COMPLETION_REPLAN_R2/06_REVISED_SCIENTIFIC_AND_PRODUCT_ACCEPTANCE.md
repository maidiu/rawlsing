# Acceptance that produces useful output

Three separate terminals: **usable bounded prototype**, **full PRE-V3 estate certificate**, **full production activation**. The first requires explicit bounded V3 authorization; it does not require all 35 sources. The latter two preserve their existing substantive obligations.

Prototype gate: actual replayable developmental state and readable expression; eight counterfactual classes; honest evidence modes; useful context sensitivity; preserved minority/joint possibilities; no unsupported diagnosis; source access and invoked trust boundaries respected. An imperfect model may pass this product gate with explicit limitations. A false measured claim may not.

Methods gate: begin with qualified empirical conditional/backoff and transparent priors. Test at most one stronger candidate for each exposed gap using equal inputs and a frozen held-out split. Use proper predictive scores appropriate to output (Brier/log score for categories, CRPS for distributions), calibration, subgroup error, coverage, sensitivity and cost. Scores and thresholds are proposed and must be set before candidate evaluation; no scores were measured here. Do not require all metrics where no held-out target exists: mark unvalidated, use broad prior sensitivity and product tests, then deliver the bounded mode.

Cross-source gate: define target population/support, variable roles, comparability and transport assumptions. Same-person joins require same-person evidence. A modeled cross-source distribution may be useful without that evidence, but its dependence assumptions remain explicit and tested. Avoid double-counting duplicated surveys or semantically repeated evidence. A failed transfer keeps source-indexed inputs or a broad prior.

Temporal gate: distinguish direct repeated-wave comparisons, partial transforms, model-based interpolation and extrapolation. Repeated cross-sections are not individual transition histories. Test a missing wave against an anchor-only baseline where lawful; test abrupt-break and horizon behavior. No universal waiting for Ghana. A weakly supported past period may still use a broad model prior with visibly weak precision.

Full-estate gate: preserve all 35 source identities, F1–F8 and AT01–AT35, original items/finite issued operations, routing/risk/design, independent expected-work no-drop proof, minority and higher-order structure, typed negatives, actual terminal consumers, privacy, replay/invalidation and required security. Preserve full Long Memory function/proof debts. No count-based closure, false intrinsic N/A, hidden unvisited frontier or fixture inflation. Source-specific holds block only consuming operations and claims.

Independent review: reviewer receives frozen candidate and independently prepared expectations; reports actual commands/exits and distinct unexecuted cases. Review of a self-consistent hash is not external authentication. N04R's passing tests include demonstrations of remaining weak behavior; 112 passes cannot mean all trust requirements passed.

Release rule: when a method timebox ends without clear improvement, retain the simpler transparent implementation and record the unresolved question. Reopen only for a failing product case, new useful evidence or a changed requirement. User-visible output is required at each product milestone; documentation alone is not completion.
