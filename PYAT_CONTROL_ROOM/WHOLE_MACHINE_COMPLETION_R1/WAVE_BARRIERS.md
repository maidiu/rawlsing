## Horizontal edge-class work, not 35 independent decoders

**Shared edges** requiring generic adopted owner implementation/hostile tests before wave-specific execution: SAV/DTA source decoding, physical header/stream, scoped encoding, opaque date/text, numeric key exactness, duplicate/repeated/ranked/MR topologies, system/user missing, split/form/module/routing, respondent versus household, original national frame/boost sample, design/PSU/weight/estimand, source-currentness, same-respondent event binding, EE12 comparability. Source-specific warrants bind original meaning to those generic edges.

**No silent PASS from one source example.** A Ghana triple exercises true same-adult semantics; it is not a replacement for R5 full item universe. A LiTS report joint exercises empirical co-travel; it does not establish entire LiTS structural field. A Uganda pair tests temporal design; it is not the universe of EE12 pair-comparability operations.

**No silent omission.** Whenever source support implies a required F1–F8 product class but current owner cannot produce it, that cell remains DEVELOPMENT_BLOCKER; lawful source-intrinsic absence requires original evidence, not a missing code path. For a finished wave, record exact source item/response, target and condition, C11 respondent/risk, query/discovery/analytical products, structural admission/refusal where relevant, downstream real consumer, currentness/replay and negative evidence.
