## D. Five different grades to maintain independently

1. **SOURCE / HISTORICAL:** actual source file/blob and its code semantics, or user chat recollection (label separately).
2. **ENGINEERING:** written code at SHA, executed tests by author, independent reviewer grade, physical performance cut.
3. **SCIENTIFIC:** valid source question, population, sampling/weight, role/scale/estimand, inference authority.
4. **RIGHTS / CURRENT / OWNER:** actual lawful source use; exact permissions, active grants, lease and recipient.
5. **INTEGRATION / PROTECTED:** true first-reader across stages, independent receiving at exact cut, protected CAS/paired CURRENT_PROGRESS.

No one category may be inferred from another. A document's statement “G5” is evidence to inspect, not a substitute for identifying the independent reviewer and executed exact work.
