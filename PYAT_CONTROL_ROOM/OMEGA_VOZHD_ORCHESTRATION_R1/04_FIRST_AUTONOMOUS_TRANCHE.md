1. Resolve live control HEAD and LATEST; verify CURRENT/manifest at immutable handoff commit. Reconcile only named active branch movement. Preserve the old canary as bounded diagnostic; do not cancel or broaden it.
2. Read this packet's README, charter, stage map, first tranche and escalation rules. Read only each worker's relevant C dossier, acceptance IDs and evidence inputs thereafter.
3. Bind the actual HQ session, worker/reviewer identities and capabilities. Default to browser Sol High. Record costs as user-reported/observed/unknown; there is no assumed token telemetry.
4. Freeze base implementation commit and required blobs. If control movement is documentary only, verify relevant code unchanged. If it changes code used by a task, reconcile the diff and pin a new base; do not silently switch the worker's base mid-run.
5. Define one integration owner and a file-ownership register. Each implementation task gets its own branch; review tasks are read-only except separate review artifacts/tests. No direct worker writes to control or semantic PRE-MAIN.
6. Identify source-free execution surface and minimal baseline suites. Freeze fixture input/expected-output hashes before candidate evaluation. Use accepted existing test builders where suitable; production modules must not import their test helpers.
7. Issue complete jobs via supported coordination tools, or ready-to-paste prompts if the host cannot create/message agents. Mark RUNNING only after actual dispatch acknowledgement. Merely publishing the plan is not worker activation.
