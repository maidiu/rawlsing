# Documentary validation and delivery scope

[Start](README.md)

The verifier checks every manifest-bound file, local Markdown targets, unique task identities, dependency references and cycles, declared routing examples, and retained no-source/no-actor authority boundaries. The initial board remains PLANNED with no assigned/launched workers. External readiness conditions are explicit; a dependency task merely returning is not its acceptance.

The current control checkpoint, its manifest bindings and named worker ref were reverified at the planning baseline. The source-free implementation checkout was clean; no application code or Rawlsing tests were executed for this plan. The executable verifier is a documentary integrity check, not qualification of any F gate or browser capability.

Run `python3 tools/verify_plan.py` from a downloaded packet. `MANIFEST.json` excludes itself to avoid self-reference. Private staging/receipt files beginning with underscore are excluded from publication. Remote publication verifies the uploaded Git blob identities and final checkpoint/pointer bindings separately.
