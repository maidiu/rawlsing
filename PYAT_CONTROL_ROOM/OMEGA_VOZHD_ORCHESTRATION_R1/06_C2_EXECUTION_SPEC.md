## C2-01 — normalize competent evidence and exact residuals

Produce `authority_succession_manifest.json`, `estate_function_coverage.json` and `exact_authority_residuals.json`. A useful coverage row is source identity × gate × demanded operation/claim, with predecessor/current authority, current owner contract, implementation identity, proof grade, populated-product state, consumer and disposition.

Use a source × F1–F8 overview to make omissions visible, but a coarse green cell never substitutes for required field/operation-specific authority. A missing demanded subcell keeps that scope unresolved. The historical 20 PASS/15 BLOCKED census remains representation history.

For each succession bind exact predecessor commit/path/blob or Library file/version/digest, semantic grain, current target contract, deterministic mapping and preserved epistemic class. Distinguish manual, derived, precedent, unresolved, review and prohibited. A documentary bridge may rebind unchanged meaning; it cannot turn missing authority into inferred ALLOW because labels or observed values seem clear.

Use index-first retrieval. Library search begins with named authority/return/version from the audit; broaden only around a concrete missing binding. Deduplicate identical content once and retain all source aliases. If only a search excerpt exists, label it partial. A resource atlas is a route to evidence, not adoption authority.

## Review and stop

Reviewer validates all inventory keys/counts and reference consistency mechanically, then inspects every scope-critical authority decision, semantic succession exception and selected-witness justification. Sample low-risk mechanically identical rows only with a documented equivalence rule; no sampling of unique disputed semantics.

Missing rows are routed to the proper authority/custody owner; ordinary retrieval gaps do not immediately consume Astra. A conflict between adopted authorities, a required semantic premise with no competent owner, or a proposed change to the required estate triggers escalation. Report a bounded search negative without claiming global nonexistence.

This lane's useful terminal can be a precise coverage/residual ledger that enables a subset workload. It need not fabricate full 35-wave authority closure to help C1 or prepare Omega-1.
