## Functional goal

Build the smallest reusable composition of current exact-query/discovery/recursive producers that supplies an actual analytical/possibility consumer. Preserve distributions, joint morphology, minority alternatives, branch ancestry, evidence states and dependency identity. A new wrapper that merely accepts preconstructed final slices is not the result.

### Current public path

Producer: `rawlsing_next.pre553_empirical_query.execute_empirical_query(*, repository, query, predicate, authority_registry, release_refs)`.

Discovery: `pre553_discovery_exact.execute_exact_bounded_discovery`; recursive producer: `pre553_recursive_handoff.execute_exact_bounded_discovery_with_handoffs`, with persisted handoff load/write and membership replay as applicable. Adaptive exploration belongs to its current owner and its explicit coverage contract.

Consumer: `source_backed_positioned_subject_possibility.evaluate_positioned_subject_possibility(*, query, rule, evidence)` consuming `PossibilitySliceEvidence`. Bounded consumer replay alone is weaker than recomputing the full producer path in a fresh process.

These are code-entrypoint bindings, not permission to relabel empirical objects as learned/admitted structural objects.

## C1-00 — settle a narrow adapter contract and oracles

Name exact input and output types, authority premises and public call trace before coding. Proposed implementation terrain is the prior draft's new analytical module/test plus a return directory. First search existing owners for a fitting representation; use a bounded extension if already owned.

The contract must bind:

| Grain | Required preservation / hostile question |
|---|---|
| Source | Exact universe and release; can two releases with identical-looking values alias? |
| Conditioning | Exact predicate, values, requested/retained conditioner bindings and source/time comparability; can same labels with different values collide? |
| Target | Exact ordered target refs, arity, topology, component authority, domain and response-state semantics |
| Denominator | Risk set, eligibility, response applicability and exact support, separate from observed zero |
| Measure | Raw versus authorized weight/design/estimand; no reversal with a different implicit measure |
| Provenance | Query/fact/replay refs, authority snapshots, used input determinants and branch lineage |
| Consumer | Exact consumer query/model rule and supplied slice; not merely an object with the right Python class |
| Coverage | Positive outcomes plus visited-negative, pruned and unvisited information at actual search grade |

A concrete risk found during static inspection: the existing possibility primitive selects slices by source/release/target/retained-conditioner IDs. Therefore the composing caller must prove binding to the exact intended condition/value/risk/measure and consumer query; matching labels alone is insufficient. Ask the independent reviewer for a counterexample using identical conditioner IDs and different values. Fix this at a lawful owned boundary, with a preserved public API or a bounded reviewed owner repair. Do not infer new subject-to-survey comparability law.

Another risk: the query and possibility owners expose different negative vocabularies. The consumer's evidence states do not directly represent every query/discovery state. Define a lossless analytical result envelope retaining original producer state, coverage and reason. A narrower consumer result may coexist only with an explicit retained distinction accessible in the final composed return; it must not report all states as UNKNOWN, VALID_EMPTY or zero. If lawful preservation cannot be expressed, return the exact owner-contract question.

Before candidate evaluation, freeze synthetic fixture rows, governed fixture authorities, expected arithmetic/support/ancestry and hostile mutations. Oracle expectations come from independently computed fixture mathematics and existing authoritative laws, never from the candidate output. New fixture authorities are test-only synthetic objects, not adopted survey authority.

## C1-02 — extend across required analytical shapes

Run AT08–AT13: attitude-to-attitude and joint-to-target conditioning, XOR/parity, equal marginals/different joints, minority/counterpatterns, secondary recursive ancestry, co-travel without S14, and non-scalar/ranked/multiselect configuration. Preserve source-native component ordering. Do not reconstruct joint distributions from marginals or use independent trait draws.

For recursive execution, persist a discovered branch through the current handoff mechanism, reopen the retained material in a fresh process, perform a second generation and consume the result. Distinguish positive handoff selection from access to full negative/coverage records. Adaptive execution must identify unvisited work; exhaustive coverage cannot be claimed from a partial frontier.

## C1-03 — lifecycle, negative states and legitimate consumption

AT14–AT19 remain mandatory at the declared C1 scope. Preserve zero, valid-empty, underpowered, unknown/unresolved, unvisited, noncomparable, blocked and integrity failure. If a state cannot occur on one path, identify the competent path where it is exercised; do not mark a mandatory case N/A merely to pass.

Declare each analytical family as a direct empirical route or a learned/adjudicated route according to existing authority. A rejected learned claim cannot be relabeled direct to bypass its rule. For a family requiring M1/M2/B5/I4, prove actual bindings, release/selection and consumer dereferences; for competent direct output, do not impose a universal wrapper.

Register actual determinants across producer and consumer boundaries through the existing lifecycle owner where applicable. Mutate one exact determinant and show all and only dependent products invalidate or reidentify; unaffected products remain usable. Serialization replay, explanatory replay and fresh empirical recomputation are separate claims. The promised fresh-process test must start from retained determinants and execute the claimed producer path.
