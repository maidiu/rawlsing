# Executive architecture decision — one destination, no bakeoff

## Final selection

**SOURCE-AUTHORITATIVE, COMPACT, REGENERABLE-HYBRID PRE553 PRODUCTION.**

This decision follows the user's stated priorities: finish the entire Rawlsing source→empirical/semantic/structural/historical/world→possibility→developmental-person pipeline; make wall-time, RAM, storage, replay and maintenance economical; preserve every legitimate inherited V547–V552J capability, especially the recursive multi-label fracture-map vision; no arbitrary question-slice, all-pairs-as-product, duplicate ungoverned engine, or three-way A/B/C reconsideration.

### Architecture
1. **Source truth:** exact immutable SAV/DTA snapshots plus source/documentary/semantic authority; SHA-qualified decoder; source/event/row and occurrence identity. Physical cache never creates scientific truth.
2. **Logical C11 and scientific owners:** keep current validated C11, native I03 query/fact/predicate/risk semantics, I05 exact/adaptive discovery, I04 structural admission, release/resolver and consumer owners. Extend physical resolution without changing logical semantics by fiat.
3. **Execution substrate:** read/decode once per source snapshot or cache rebuild; build respondent-coherent typed value/state/coordinate/event columns; preserve topology in a separate exact occurrence/event table where scalar representation is inapplicable; derive permission-keyed predicate memberships. No huge per-cell Python object graph required in the calculation hot path.
4. **Cross-session physical acceleration:** default a local immutable, compact, compressed Parquet/Zstd cache of source-qualified computational columns and the minimal exact determinant/identity index, plus reconstructible in-memory NumPy arrays/packed bitsets. Strict content/version/authority key, hash validation, fail-closed stale detection, atomic write, delete/rebuild. Cache never outranks source and governing authority. Qualify exact backend/dependency without reopening architecture.
5. **Grouped computation:** work-sharing across compatible query scopes, once-validated respondent and risk membership, group counts, higher-order branch intersections, sparse nonzero internal cells with complete-domain exact native zero semantics, compatible bidirectional conditional derivation with independently resolvable native product. Do not substitute the batch scheduler for a vectorized/pooled computation kernel.
6. **Native result production:** separate cheap numeric calculation from expensive exact scientific fact materialization; preserve all legacy exact object IDs/hashes and inline provenance where contracts require them. Optimize digest assembly, persistent object duplication and repeated refs under equivalence. Any successor compressed/indirect evidence contract must be explicitly versioned and approved, NEVER silently introduced.
7. **Actual learned and world consumption:** perform F2–F4, Authority-37 fracture map, N2/N3/N4 learned validity, N10E and authorized F5–F8/N9/N10W consumers; publish actual results as their exact dependencies complete, independently of unrelated global pair catalogue.
8. **Preserved outputs:** source/authority/identity roots, necessary irreducible semantic sidecars, scientifically qualified learned products/receipts/serving roots, and historical-world releases persist. Intermediate computational arrays/indexes are regenerable and may be retained as explicitly nonauthoritative accelerators. Generated actor history, memory and expression are later separated products, never source projections.

### Why this, not A/B as independent competing plans
- The selected physical strategy uses B's already implemented source-backed semantics; it avoids A's general persistent canonical duplicate becoming sovereign. A's Compact-V2/Serial-V4/Audit69 code is a reuse candidate for exact codecs, streaming, integrity and deterministic reconstruction, NOT a wholesale required stage or second authority.
- B-only session preparation may be cheap for one compilation but costly across real repeated use; a bounded validated cache has clear compute-economic rationale. It must be much smaller than current local materialization and lifecycle-safe.
- The frozen CACC1/CACC2 candidate was not implemented at its documented historical readiness cut; creating that exact 11-field Arrow bank and 29,002-bit masks for a LiTS-specific benchmark does NOT by itself deliver general all35 SRC04 capabilities. Build the source-neutral hybrid physical interface required by real current owners, and migrate only useful frozen design/invalidation law.
- An A/B/C bakeoff is NOT a work package, acceptance gate or reason to wait. Normal benchmarks compare old vs improved implementation of THIS selected architecture, not architectures.
