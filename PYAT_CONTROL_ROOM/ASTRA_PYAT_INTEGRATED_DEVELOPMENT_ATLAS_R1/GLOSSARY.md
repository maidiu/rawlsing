## Authority precedence

Exact current adopted law controls over stale summaries. HQD-125 retains HQD-124 while changing the full-completion interpretation. Pass 3 settles audit adjudication; Pass 4 compiles it. Earlier pass packets preserve evidence and the state of knowledge then, including later-closed queues. The delivery packet adds navigation and proposed operational detail; it does not create survey/model semantics or turn proposed work into completed proof.

## Evidence classes

Keep documentary presence, code presence, reported qualification, actual source execution, retained products, current succession and consumed functional realization separate. Immutable commit + path + blob is preferred. A branch name is only the observed mutable ref at inspection. A missing or partial local copy is not proof the remote artifact is absent. Atlas metadata counts are navigation counts, not maturity.
