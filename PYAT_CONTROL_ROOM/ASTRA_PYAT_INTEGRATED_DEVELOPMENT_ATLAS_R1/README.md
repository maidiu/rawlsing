## Scope and precedence

The full pass records are preserved. Their old stop instructions and provisional queues are historical; do not execute them as current commands. The integrated program follows the frozen Pass 3 adjudication and Pass 4 report, with detailed proposed runbooks and acceptance envelopes added for usability. No additional implementation, raw-source run, semantic invention or actor work occurred during packet assembly.

Use [the glossary](GLOSSARY.md) for every identifier namespace, proof grade and historical path alias. Evidence identities distinguish retrieved complete blobs, partial observations and preserved pass identities. Unknown maturity is not failure, and a lawful bounded refusal is not automatically full-world completion.
