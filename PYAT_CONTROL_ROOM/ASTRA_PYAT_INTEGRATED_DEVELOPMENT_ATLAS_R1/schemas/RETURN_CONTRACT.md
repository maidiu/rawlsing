# Worker return contract — proposed operational envelope

This envelope organizes evidence. It does not replace producer-owned semantic schemas or create semantic authority.

Each return must bind commission ID and issued commission ref; exact scope; input refs and authority classes; implementation commit and per-file blobs; execution runtime when used; declared proof grade; actual products and consumers; typed results/coverage; dependencies; replay and retention; tests with failures/errors/skips; source access actually performed; blockers; and exact outgoing edges proposed for wake.

Every claim records **what was proved, by which artifact, for which source/population/time/operation, at which implementation, and what remains outside the claim**. A report must identify actual executed stages separately from propagated later statuses.

Use null plus a reason for unreached metrics. Zero means measured zero. Unknown, valid-empty, not-applicable, blocked and missing authority remain distinct. A correct refusal does not close a separate required positive-world obligation.

The reviewer verifies exact refs, declared source/write terrain, independent expected truth, negative conservation, actual final consumption, replay grade and dependency completeness. HQ then adopts/rejects the bounded result and updates affected matrix cells; no whole-row maturity promotion from one green axis.

The output schemas named in node pages are proposed packet filenames. Their substantive fields must be reconciled with the existing producer contracts before implementation; they are not instructions to create a parallel semantic object system.
