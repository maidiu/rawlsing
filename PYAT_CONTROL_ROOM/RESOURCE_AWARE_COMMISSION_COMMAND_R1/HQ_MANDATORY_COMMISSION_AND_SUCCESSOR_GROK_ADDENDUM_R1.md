## Governing metric

Maximize **independently accepted, scientifically warranted actual products and downstream consumer receipts per total money, provider quota, elapsed wall clock, avoidable retries and user interventions** while preserving F1–F8/M0–M5/AT01–35 and all35 original science. Counting cheap tokens, authored tests or dispatched workers is not progress. Ordinary Browser/GitHub work can be free at marginal cash cost but expensive in serial connector latency. Appropriate local mechanical collection can reduce round trips without delegating scientific adjudication.

## Mandatory decision record for every task

`task_id`, scientific product/milestone, existing upstream owner, exact expected consumer, pre-result oracle/E requirements, actual lawful positive criterion or exact HOLD, dependencies and wake conditions, semantic/privacy/security risk, source/model/use permission, environment capabilities, source/branch and active-session lease, exact permitted write terrain, anticipated independent reviewer/receipt, four proof grades (local, integrated, actual occupancy, adoption). Do not invent more commissions when a returned worker or reusable accepted owner already meets the objective.

## Mandatory resource snapshot BEFORE scheduling

For each candidate resource: provider, model ID+variant, legitimate account alias and entitlement, machine, Python/Node/pytest/native/FS/Git/browser affordances, controlled worktree and shared object store, source/private-code export/training restrictions, one actual shared Go normalized allowance (not per SKU), separate genuine Codex A/B balances, wall/usage reset and availability, observed provider price or spend, paid cap and overflow flag, last verification timestamp, expected review independence, user touch burden. Unknown values stay null with reason and freshness. The RCM01 resource seed is a **non-live hypothesis**, not an entitlement. No provider credential, private source or user account ID in Git. Never recommend extra accounts for provider-limit evasion, unauthorized privacy export, hidden paid overflow or a fallback without cap.

## Hard eligibility BEFORE optimization

1. Science/issuer/model-use/EE12/EE13/REAL_EXECUTION and source privacy gates cannot be purchased by model quality; no automated grant. Security/original science cannot be solely judged by an economical low-capability model.
2. Browser/GitHub does source/legal scientific forensics, identity, planning and control; **not** local Python/pytest/SIGKILL/FS runtime evidence. A qualified local helper may execute and return primary logs.
3. Missing tool, unknown usable budget, stale entitlement, unverified model/variant, missing worktree/branch/lease, source-custody ambiguity, and disallowed training/export => `REQUIRES_EVIDENCE` or typed HOLD, not an invented assignment.
4. Preserve active session/worktree and avoid duplicate launch. Resolve exact direct-origin branch HEAD and user/local launch attestation. Shared-store sparse worktree, single writer, no forced reset, no blanket clone/fetch.
5. Reviewer independent of implementer and frozen exact candidate. Do not let a review of an old tree cover a changed tree. No reviewer on a shared mutable write surface.
6. Colliding writes serialized; non-overlapping source science, test-only integration, security review and world work parallelized. No arbitrary numerical global slots.
7. If external source/data issuer is missing, put that edge on explicit `SCIENTIFIC_HOLD` while eligible source-free owner development proceeds separately. Measured valid null counts as empirical product; unexpected safe refusal on an applicable job does not.
8. Existing Space Bunny dispatcher is unqualified for autonomous dispatch; only `RECOMMEND_ONLY` routing is permitted until separate runtime, security, HQ/operator approval.

## Resource comparison AFTER hard gates

Compute estimates as explicitly observed or hypothetical (never 0 for missing):
- queue + setup + solve + retry + independent review + Browser GitHub latency + reset wait = time to accepted result;
- money outlay, actual separate-account quota consumed, common Go-pool normalized fraction, expected operator touches, failure/semantic-rework risk;
- real critical-path dependencies unlocked and original-source/consumer occupancy gained.

Display Pareto alternatives and why the selected resource dominates for this *particular* task; configurable weighting and deterministic tie-break; prefer economical local Python/Node for bounded mechanics, Browser HQ for source semantics, strong local code intelligence when integration/security complexity warrants, distinct high-competence reviewer for security or provenance. Do not automatically choose premium Codex due to Browser speed or Browser merely due to cash price. Astra is reserved for constitutional/semantic conflict, consequential program recalibration or explicit user direction—not routine retry or model escalation.
