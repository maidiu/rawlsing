# Route-B Horizontal + Vertical Proving Program

## Purpose

Prove one reusable source→learned-release contract horizontally across survey families/waves while simultaneously learning what Field Forge and the objective PRE-V3 world need vertically.

## Horizontal axis

Do not start by forcing all 35 sources through one undifferentiated workload.

Use family/wave panels chosen to exercise distinct laws:

### Positive-control panel
- LiTS-I — complete B empirical closure.
- Latinobarometro 2011 — banked realization, comparatively clean source-law control.
- Afrobarometer R1 — banked realization.
- EVS 1981/1990/2008 — multiple-wave family with different physical/documentary burdens.
- GSS 1972/1973/1984 — early-wave family diversity.
- WVS Wave 1 — banked realization.

### Hardening panel
- WVS7 — huge source-local scope/routing/projection complexity.
- GSS 1993/2002/2010/2016/2024 — strong within-family topology evolution; 2024 hard multimode break.
- LiTS II/III/IV — closest natural within-family test of whether the LiTS-I learned workload generalizes without semantic copying.
- Asian Barometer W1/W4/W5 and Arab Barometer W1/W2/W5/W8 — multi-wave routing/topology/representation diversity.

### Negative/boundary controls
- Afrobarometer R5 and R9;
- Latinobarometro 1995;
- any source/variable whose exact authority is BLOCKED/UNKNOWN.

Negative controls must prove fail-closed behavior, not be “fixed” by inference.

## Within-family wave law

Cross-wave execution serves two different purposes:

1. prove the compiler can produce exact wave-local learned releases under each release's own authority;
2. test explicit comparability/temporal relation authority where separately authorized.

Wave-local product success never establishes longitudinal equivalence by itself.

## Vertical axis

For selected L1 learned releases:

```text
governed learned empirical release
→ Field Forge relation-formation court
→ structural-use admission / typed refusal
→ actor-independent structural relation graph
→ objective opportunity / mediation / temporal / topology producers as demanded
→ SDTF objective consequences only with separate mechanism authority
→ objective PRE-V3 world/release service
```

Run multiple vertical examples, not one canary:
- a marginal-only case that should remain empirical-only;
- a same-respondent joint case;
- a conditioned-difference/redistribution case;
- a valid-empty negative;
- a multi-wave relation only when comparability authority exists;
- an authority-blocked case that must remain blocked.

## Success condition

The program succeeds when:
- multiple heterogeneous sources produce the same logical PREFF-L1 contract without source-semantic leakage;
- multiple relation families reach Field Forge with exact preimages;
- Field Forge returns both positive structural relations and lawful refusals;
- at least several structurally admitted outputs continue into objective PRE-V3 producer families;
- replay/invalidation/currentness works across source and learned-product revisions;
- no old numbered-stage topology is required to explain the result.
