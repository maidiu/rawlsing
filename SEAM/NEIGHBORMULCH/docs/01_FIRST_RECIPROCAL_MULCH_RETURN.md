## II. THEORY-MULCH — two true but incompatible causal accounts

**The encounter tradition** possesses a finite, historically mediated subject: a player with real authorship of their words, time and attention, an external Other who can see and hear differently, an existing material world that may resist, and a narrator who has no permission to show an unexpressed internal life. Its existing P4/P6 code correctly produces bounded user actions and sources some actor-visible cues. **But** it also commits its own world and actor event ledger, and its MIII scene-context priority is sometimes a sourcefree fixture rather than the currently recruited organization of an actually developing person.

**The organism tradition** possesses richer body, constitutive acquired forms, recruitment, contradictory currents, independent actual actions, institutional material constraints, actor-specific experience, developmental afterlife, persistent SQLite event hashes, clock and offscreen maturation. **But** `constitution.actor_access`'s co-presence has no protected P6 directional sightline by itself; a fresh `runtime.cue` is explicitly an external research fixture, not authorized human conduct. It also commits its own world. If its internal narration is simply displayed, the opaque Other becomes transparent and the user's eye is silently installed as the world's generator.

Neither tradition deserves to be demolished wholesale. The false assumption is that a 'human encounter' and a 'psychological life event' must be separately enacted and then translated. Instead, **a person's encounter with a user is one material occurrence made asymmetrically accessible to different historical actors, and capable of becoming a causal source of the *same* actor's future life.** The actor and world need not be a single monolithic object; they need exactly differentiated legitimate write rights and event ancestry.

**The ontological synthesis** is therefore a **single event lineage with heterogeneous legitimate access**, not one physical file and not two coordinated roleplays:

```
independently existing material world + person constitution
              │
              ├── user-authored attempt (content, timing, source)
              ↓
    one world-registered occurrence, eligibility and obstacle
              ↓
  physical affordances / auditory / visual / bodily qualification
       ┌──────┴────────────────────┐
       ↓                           ↓
qualified actor uptake       bounded user availability
       ↓                           ↓
actual prior-psyche          MII private phenomenal
recruitment / initiative     exposure, never actor cause
       ↓
actor world outcome and actor-specific lived afterlife
       ↓
   the SAME persisting actor and world at later contact
```

**A real interaction may create two distinct events** (the user's utterance and a later independently chosen actor action) in the same canonical world history. This is not 'dual-writer': an *occurrence* is not independently recast as if two worlds settled it. A private attention change is not another material event by default.

## IV. CODE CHALLENGES THEORY — two immediate MULCH reversals

**Reversal 1: co-presence is not perception.** The first implementation treated `world.positions` sharing a room as sufficient to present a co-present actor in MII. That materially violated the founding doctrine: the world exceeds every person's phenomenal availability. The code correction added separately source-qualified user geometry; dark/occluded co-presence can no longer force character information into the UI. The positive theory accordingly changed: user presentation is not a world roster lookup, but a *time-indexed, materially available perceptual relation*.

**Reversal 2: acoustic stimulus is not lexical comprehension.** A visitor's exact speech is a true objective utterance, but delivering that exact proposition as an `actor_access` sound to a prelinguistic child silently preinstalls conceptual meaning. The reader now retains the objective text while a language-immature listener receives only an acoustic presence. The conceptual correction is sharper than an extra boolean: **the source's information content and the hearer's learned discriminations have different causal authority**.

**Reversal 3: user participant ≠ complete modeled actor.** R21 `ResearchLedger.commit` explicitly insists `world.positions` and registered psychological actors form one closed roster. A naive P6-to-R21 adapter would invent the user's entire cognitive/biographical actor state or cause an illegal commit. By preserving a distinct world participant identity and real user-authored contribution, the same objective world can include a player without mistaking them for the organism's sovereign psychological character. But genuine user embodiment/resources remain an open owner task, not solved by the subrecord.

**Reversal 4: event clock is not sensory reception clock.** R21's `step` reads available cues before world resolution at time *t* and recomputes lived reception after settlement at *t+1*. The original default `world.add_cue(..., lasting_ticks=0)` would make a legitimate visitor sound disappear before R21's actor-experience reader, even though its earlier actor-policy reader could act on the sound. R1 grants a **single subsequent read beat** (`lasting_ticks=1`) so the first actor step can consume the very same sourced cue. This does **not** prove the sound physically persisted. A fully correct future owner must distinguish a transient sound's timestamp from the actor's durable *received-event* reference. Multiple user events before the next actor transition can still exhaust this limited window; **that is an explicit integration defect/limitation, not a reason to expand acoustic lifetime arbitrarily**. It is a concrete first-consumer demand for the organism event/experience owner.
