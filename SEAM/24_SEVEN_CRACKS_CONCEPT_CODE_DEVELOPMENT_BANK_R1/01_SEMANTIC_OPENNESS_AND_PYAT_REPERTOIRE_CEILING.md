## Existing Rawlsing logic and actual tension

The [older PRE-V3/Field Forge *Personal Relational Field* `4](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/data/ddm_build_copy/recovery_integration/semantic_relation_R1_through_Job3/R1_20260825/PRE_MAIN_RECONCILIATION_R1/PROJECT_INHERITANCE_R1/CAMPAIGNS/N033_ORIGINARY_PERSON_WORLD_PAX_MARXICA/CORPUS/ORIGINAL/91fd9f3214a8__26_PERSONAL_RELATIONAL_FIELD_AND_EMERGENT_ATTRACTOR_R1.md) sketches V3 actor-realized disposition nodes retaining PRE-V3 repertoire semantic references. For *dispositions that actually arise from qualified PYAT content*, this makes provenance intelligible: a measured repertoire conditions what could be encountered without directly assigning a psyche.

But universalizing that path would make **historically measured adult survey concepts into the complete vocabulary of human developmental possibility**. An infant could learn a local practical distinction, novel craft, sign-language relation, ecological discrimination, obligation or meaning absent from WVS/AB indicators, yet fail a mandatory PRE-V3 node-reference gate. That would contradict SEAM/21's core proposition: *same developmental causal grammar, variable acquired semantic contents and variable relations among those contents*.

The [accepted CAN-011 authority](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/data/ddm_build_copy/vozhd_dva/20260817_downstream_completion/schematics/release/W1_CRITICAL_AUTHORITY_EXPANSION/CAN_011_V3_MIDDLE_STATE/AUTHORITY.md) registers only `V3MS_MEDIATOR`, `V3MS_TENSION`, `V3MS_PRACTICE`; `semantic_object_ref?` is optional, no fixed practice taxonomy is issued, and persistent records require exact actor-time, causal parents and admitted update rule. Opportunity, survey position, exposure, LLM inference and duration are insufficient sole causes. **This later accepted semantic contract is not identical to the older prospective Field Forge proposal.**

## Why develop this

This may be the **most fundamental boundary bug before implementation**: a richly biocultural engine can still produce a Western-measured adult with different settings if the only possible learned nodes are PYAT's survey-coded dispositions. Conversely, allowing arbitrary new free-text psychological nodes would generate untestable narrative soup.

The objective is a middle route: **historically available semantic referents and performed/experienced actor activity qualify candidate acquired contents**, without requiring a matching source-survey variable or giving an LLM authority to mint permanent meaning.

PYAT contributes the qualified material/social availability of practices, institutions, languages, tools, labels and conditional repertoires. SOROK owns actual actor-specific acquisition and content. There is no presumption that all acquisition is lexical, conscious, other-directed, or socially intended instruction.

## Prospective code interpretation (not a new approved API)

```text
QualifiedWorldReferent:
    identity/object or practice/institution/interaction in ACTUAL world,
    source/scenario grade; historical time; available access channels
    # Not yet a psychological acquisition

ActorEncounterCandidate:
    actor + qualified P2 action/received event + embodiment/access +
    object/practice referent + context + causal parent refs
    # Mere encounter or lexical hearing not an acquired concept

CAN011AcquisitionProposal:
    state_kind = MEDIATOR | PRACTICE | TENSION
    actor + scope/context + event parents + rule authority
    semantic_object_ref = admitted referent IF available and appropriate
    candidate acquired discrimination/capability/expectation
    # Rule must allow a reference without forcing a PYAT survey node
    -> CREATE / TRANSFORM / NO_CHANGE / DEFER / REFUSE

LaterActorFirstReader:
    current actor world + admitted local acquired organization + eligible acts
    -> chosen attempt/performed P2 act (or lawful quiet)
```

**Do not invent** `QualifedWorldReferent` as a second global semantic registry by default. First locate the original P2 object/practice/event, CAN-011 semantic authority and the precise existing owner able to reference it. `semantic_object_ref?` may be legitimately absent; it is not license for free-form hallucinated knowledge. Distinguish an actor's practical discrimination from their explicit linguistic explanation.

### Discriminating evidence/proof

1. Same initial modeled organism and source-qualified material worlds, differing actual access to a local tool/sign/practice: a qualified domain-specific update can create a different *kind* or referent of acquired state, not just another weight on a shared Western personality axis.
2. Keep all lived events equal and switch only culture/ethnicity/religion label: no newly acquired semantic contents.
3. Offer content only through a survey reported opinion, with no actor activity/learning rule: NO_CHANGE/HOLD, never direct psyche write.
4. Actual repeated performed practice with valid causal history may create `V3MS_PRACTICE` under a concrete test rule; merely overhearing its name does not.
5. Later real action demonstrates that the admitted learned distinction is usable; successful narrative labeling or an attractive graph alone is insufficient.

### Dependencies, risks, exact challenge to UMs

- **Depends on SC-05** for exposure versus uptake, and **feeds SC-07** so motifs can connect genuinely learned meanings rather than fixed categories.
- PYAT question: what source evidence constrains historically available objects/communication/institutions not represented as WVS disposition items, and where does F6 nonpooled reconstruction keep them hypothesis-grade?
- SOROK question: locate the existing lawful referent issuer and CAN-011 first reader. Does accepted CAN-011 `semantic_object_ref?` already suffice, or must a concrete domain-specific rule register novel referents first? Test incompatible meanings and nonverbal skill.
- **Stop condition:** if no admissible referent/actor history/rule exists, retain unknown rather than add a generic LLM semantic writer.

**Status of proposal:** grounded conceptual necessity; semantic admission/learning mechanism unissued and requires independent owner review. No PYAT repertoire ceiling and no ungoverned psychological content.
