## Constitutive principle

The persistent individual is **not** an arbitrary Python object encapsulating the social world. It is a historically individuated participant with a sparse, variable, partially inaccessible acquired organization that is *both* a consequence of actual activity and a producer of further possible activity. The present activity recruits a temporary composition. That produces an attempted action, whose objective and subjectively accessible outcomes can change the future constitution. Each revolution of the loop encounters the same historical individual in a changed world, and can change the **routes of recruitment**, not merely append traits. Distinct mutually productive actors retain their own inner afterlives; a shared relation is an objective history, not a fused consciousness.

Every effect has an actual actor-experience/objective-event parent. Not issued scientific acquisition laws.

- `adapters.py` — sourcefree read-only P3 functional record adapter **only when admitted scoped records have actual functional semantics**; explicit contract for future P2/P3/P6 first-consumer wiring.
- `cli.py` — demonstration and inspect/see/situated/chain command-line interfaces.
