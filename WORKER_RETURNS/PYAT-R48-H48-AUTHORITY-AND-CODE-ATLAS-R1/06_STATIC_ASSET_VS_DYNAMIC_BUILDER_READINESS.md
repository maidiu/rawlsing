No probabilities, actor claims or occupancy from test counts |

The boundary is hybrid: manually adjudicated meanings and constraints are static governed content; exact descriptor construction, query expansion, finite candidate enumeration and scheduling are executable transformations. The transformation may be automated where its governing rules exist. New statistical eligibility or meaning must not be inferred from an archive filename, numeric code order, a hash, observed outcomes or an engineer-created signature.
