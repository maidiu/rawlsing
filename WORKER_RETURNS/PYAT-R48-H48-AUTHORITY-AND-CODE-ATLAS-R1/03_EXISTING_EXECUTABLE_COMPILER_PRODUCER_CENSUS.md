## Bounded absence finding

The current 140-module canonical constructor census, explicit U43/B43/S44 code, WG0P4, historical V550/J builders and local archive routes do not demonstrate one currently selected all35 source-rule→complete issued NativeWorkload producer. Dynamic aliases/plugins and inaccessible machines are outside the static search. Existing pieces above must be reused before any new whole compiler is proposed. Candidate modules in 07 are implementation targets, not a declaration that no historical equivalent can exist.
