# FIABC-S35-3 — Generic Law vs Source Exception

Terminal target: `FIABC_S35_3_CLOSED35_PHYSICAL_EDGE_CLASSES_PROVED`

## Holding

The CLOSED_35 estate does **not** require 35 physical adapters.

Accepted Authority71/72 preparation, the Source-Native Constitution, the frozen decoder contract, FIABC-A04, and the later LiTS-I/WVS7 positive controls support a finite court of **14 edge classes: 13 atomic physical classes plus 1 composition meta-class**.

The source matrix is many-to-many. A source belongs to every edge class its bytes/metadata/topology actually exhibit. A compound source is therefore an intersection of reusable laws, not a new adapter species.

The governing candidate law is:

`candidate-local physical strategy may differ -> exact physical incidence / replay identity / governed semantic result may not`.

A/B/C may differ in reader library, traversal, streaming, materialization, cache/index layout, sparse representation, or other physical work. They may not use those differences to change source SHA, source-row association, raw storage values, physical missing class, variable/dictionary identity, topology, routing authority, coordinate scope, weight authority, or any other governed semantic/replay identity.

## 1. Minimal class decomposition

The manifest intentionally keeps the following distinctions separate because merging them would erase a different physical law, hostile obligation, or proof status.

### EC01 — format family: SAV vs DTA

SAV and DTA are two plugins under one format-neutral incidence contract. The denominator is exactly 31 SAV + 4 DTA. Format is an execution fact, not semantic authority.

This class is generic implementation, not source-specific exception handling.

### EC02 — explicit text decoding mode

Source-local decoding modes include BIG-5, windows-1252, native UTF-8, and the exact-SHA latin1 compatibility paths. Automatic guessing/fallback is forbidden.

This is separate from EC03 because an explicit encoding mode can be perfectly lawful without malformed source text.

### EC03 — malformed declared-text quarantine

EVS 1999/2008 declare UTF-8 while exact source metadata contains malformed byte sequences. Latin1 is compatibility execution only. It permits physical extraction but does not authorize repaired/intended label semantics.

This is a semantic-admissibility quarantine on top of EC02, not a different decoder family.

### EC04 — metadata vs storage nonidentity

Two accepted sources prove one common law:

- WVS Wave 1: display format `F2.0` does not change the 9–10 digit raw S007 magnitude.
- Latinobarometro 2024: nominal SAV header value `174` does not truncate or rewrite the 332-variable dictionary/data stream.

The common law is that presentation/header metadata is not permitted to rewrite the physical stream.

The current generic decoder handles the WVS1 side because raw values and display metadata are separate. It does **not** currently expose the Latinobarometro-2024 raw `nominal_case_size=174` witness in `PhysicalSourceIncidence.file_metadata`. That is the one proved generic physical-carrier gap in this court. The repair should be generic raw-header metadata preservation or an equivalent generic raw-layout witness — **not** a Latinobarometro-only semantic adapter.

### EC05 — physical missingness multiclass

System missing, user-missing discrete/range/extended states, and ordinary storage values that look like nonresponse are different physical states.

Examples include Arab Barometer W2 system missing beside ordinary labeled code 0, South Asia W1 code 8 changing physical status by variable, ordinary blank string in Arab Barometer W8, and the SAV/DTA user/system missing combinations recorded throughout PREP72.

No missing mechanism supplies semantic response meaning by itself.

### EC06 — all-missing column retention

All-missing does not mean nonexistent. EVS1990 q745, the LiTS-I all-system repeated slot, WVS1 all-system columns, and WVS4 all-row typed-missing columns remain source information with variable/slot identity and row incidence.

This law is narrower than EC11: EC06 protects zero-substantive-information columns from disappearance; EC11 protects distinct variables/dictionaries from aliasing even when observed values look equivalent.

### EC07 — native-ID scope/collision/noninjectivity

Native respondent IDs are attributes until scope/injectivity authority closes them. Snapshot SHA + physical row ordinal remains irreducible replay identity.

Duplicate IDs, repeated zero, country-scoped IDs, sparse IDs, typed-missing IDs, and unsafe/no-native-ID sources all reduce to the same physical law: no deduplication/reindexing may merge source rows.

### EC08 — native multiple-response-set topology

Native MR set names, membership and overlap are physical topology. Asian Barometer W5 Q112/SE15 overlap without becoming one set; EVS2008 carries 13 native sets; EVS2017 carries its own Q4/Q11 topology.

MR metadata may be represented differently internally, but cannot be deduplicated by name/member similarity.

### EC09 — ordered/repeated slot topology

Ranked choices, repeated events, ordered household slots, triplets, 14-slot structures and visit blocks preserve occurrence identity, multiplicity and order.

This is not routing. A slot can exist physically regardless of whether later authority says a respondent was eligible for it.

### EC10 — form/module/skip/routing carriers

Split forms, ballots, country modules, masks, phases, explicit skip variables and routing carriers are physical structure. LiTS-IV's 134 `*_skip` carriers and ten visit blocks are the strongest current DTA example; GSS form/ballot/version structure and Arab/Asian/South-Asia module structure provide SAV examples.

The generic decoder may preserve the carrier without interpreting eligibility. Routing semantics remain external governed authority.

### EC11 — variable/dictionary identity noncollapse

Equal vectors, reused names or superficially similar labels do not erase variable identity or per-variable dictionary identity.

WVS4 V220/Q223_LOCAL is the cleanest equal-vector counterexample; Latinobarometro-2024 reused names and Arab Barometer W5 extra Q101 dictionary codes exercise the same noncollapse law.

### EC12 — weight/design multiplicity and domain

Raw weight/design carriers are physical facts; weight purpose, target population, estimand, normalization and lawful combination are separate authority.

A/B/C may choose not to consume a weight for a RAW/unweighted workload, but they may not discard candidate weight/design variables or silently select/combine/normalize them.

LiTS-I's current proving scope being RAW/unweighted and WVS7's population/weight permission being separately bounded are positive examples of **refusing** semantic overreach, not proof that the weight edge is closed estate-wide.

### EC13 — source-local coordinate carriers

Country/geography/source-position fields are source-local physical carriers. Code systems can drift across waves and may participate in scoped native identity.

WVS7 B_COUNTRY is the current positive source-specific realization. It proves the generic coordinate slot can be bound under exact authority while global role remains administrative metadata. It does not authorize cross-wave country-code equivalence.

### EC14 — compound edge interaction court

EC14 is deliberately a **composition meta-class**, not a fourteenth adapter interface.

Some accepted packets are compound/P0 because several atomic edges must survive simultaneously: LiTS-IV reader+text+skip+visit+weight; Latinobarometro-2024 raw-layout+dictionary+weight-domain; WVS1 display/storage+missing/all-missing+weights; EVS1999/2008 text quarantine combined with routing/MR burdens; GSS and Arab/Asian compound layouts.

The hostile requirement is intersectional: passing one constituent edge cannot license loss of another.

## 2. Why this is minimal rather than source-specialized

The following tempting collapses are rejected:

- **EC02 into EC03:** not all explicit encoding modes involve malformed text.
- **EC05 into EC06:** missing-state classification and column retention are different failure modes.
- **EC06 into EC11:** dropping an all-missing column is different from aliasing two extant equal-looking variables.
- **EC08/EC09 into EC10:** MR/ordered event topology and routing eligibility are explicitly separate in the Source-Native Constitution.
- **EC12 into EC13:** weight/design authority and coordinate authority have different semantic owners and fail-closed rules.
- **EC14 into source adapters:** compound sources are intersections of EC01–EC13 and therefore do not justify source-specific semantic code paths.

Conversely, WVS1 display-vs-storage and Latinobarometro-2024 header-vs-stream remain one EC04 class because the same physical law controls both: metadata may describe but may not rewrite/truncate stored incidence. Their hostile fixtures are source-specific sentinels under one generic law.

## 3. Generic decoder/facade coverage

Current generic implementation already has the right architecture for most atomic classes:

- `pre553_physical_decoder.py` supplies one `PhysicalSourceIncidence` for SAV/DTA;
- exact-SHA compatibility overrides are explicit and nonsemantic;
- physical missing state is typed and includes source declaration in the physical binding key;
- row ordinals survive chunk/full-read strategies;
- per-variable labels/dictionaries/display metadata and MR metadata are retained;
- the source-backed C11 facade requires explicit row, topology, routing, coordinate and weight authority rather than inferring them from physical values.

The implementation ceiling must remain explicit.

1. The Wave-3 fan-in is integrated but source execution is still outside that browser proof.
2. LiTS-I and WVS7 are the only current source-specific realizations proved by FIABC-A04.
3. Authority71/72 packet readiness is not source certification and not current PRE553 packaging.
4. EC04's Latinobarometro-2024 raw nominal-header witness is not represented by the current generic `PhysicalSourceIncidence.file_metadata` surface.
5. For the other source-specific combinations, absence of current execution proof is **not** evidence that a new adapter is required. It is unexecuted/unissued realization debt unless a later hostile court proves an actual generic representation gap.

## 4. A/B/C survival contract

For every CLOSED_35 source, each candidate must satisfy every matrix-listed edge class simultaneously.

Allowed candidate differences are physical implementation choices only. A candidate is non-equivalent if any such choice changes:

- exact source SHA or substituted source bytes;
- physical row/variable incidence;
- raw storage value or missing declaration/class;
- variable/dictionary/display/header information required by the applicable class;
- source-row replay identity;
- MR/repeated/ranked/form/module/skip topology;
- source-local coordinate carrier or its governed scope;
- candidate weight/design carrier set or governed weight authority;
- explicit UNKNOWN/nonauthority status;
- final governed semantic/replay/output identity at the comparison boundary.

A faster physical strategy that destroys one of those is not an optimization; it is a different computation.

## 6. Court conclusion

The finite physical source burden is therefore bounded.

There is no evidentiary basis for 35 special adapters. There is one current generic raw-layout metadata gap (Latinobarometro-2024's nominal-header witness), a set of source-specific authority/execution debts, and a reusable finite edge court that A/B/C can be required to survive without semantic divergence.

This return proves the **edge-class decomposition from accepted source-preparation evidence**. It does not certify the 35 sources, execute CLOSED_35 through A/B/C, or upgrade Authority71/72 packet readiness into runtime realization.
