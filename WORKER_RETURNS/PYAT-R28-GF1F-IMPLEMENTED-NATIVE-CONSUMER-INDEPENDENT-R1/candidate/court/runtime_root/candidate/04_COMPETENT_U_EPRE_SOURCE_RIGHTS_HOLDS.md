# Competent prospective original U, E_pre, source and rights holds

## Nothing here is an issuance

This return is a bounded **sourcefree test-only** implementation.  It does not
issue, authenticate or promote any genuine prospective original source right.
Every issuer ref used is a `TEST_ONLY` fixture-owner custody witness, held at
`SOURCE_FREE_DEV`.  The register's `fixture_use_grant` records exactly that and
is the only permission the gate ever dereferences.

## Holds carried into the report

Every run returns these unchanged holds, which are structural, not incidental:

| Hold | Meaning |
|---|---|
| `ORIGINAL_U_E_CUSTODY_NOT_AUTHENTICATED` | the prospective original U, E_pre and custody principals are not authenticated |
| `SOURCE_USE_NOT_GRANTED` | source-use permission for real original data is not granted |
| `SEMANTIC_OWNER_ADOPTION_NOT_GRANTED` | semantic owner adoption is not granted |

Additional owner-level holds observed inside the P01 reports:

| Hold | Meaning |
|---|---|
| `EXTERNAL_CUSTODIAN_ISSUER_HOLD` | the external custodian issuer is not signed |
| `SOURCE_USE_AND_REAL_EXECUTION_NOT_GRANTED` | real original execution is not granted |
| `ORDERED_OWNER_NOT_ISSUED` | the ordered-topology semantic owner is not issued, so the two `ORDERED` obligations stay HELD |

## Exact actionable real-source gateway

Before any real original source can be admitted, the following must be
supplied by competent principals.  Each item is named precisely so a future
commission can act on it without re-deriving it.

| # | Missing item | Type / name | Required before |
|---|---|---|---|
| 1 | Competent prospective original **U** | real respondent/universe principal, signed, with a stable namespace distinct from the synthetic `PV2-ADULT-A/B` test namespaces | admission of any real original respondent row |
| 2 | Competent prospective original **source / operation** | signed source artifact reference and source licence for the real instrument battery, bound to a real `raw_wave` (not the synthetic `W1`) | admission of any real source release |
| 3 | Signed independent **E_pre before D** | a signed, independently authored expected set committed before the first producer call, with its own custody principal | any claim that the expected set was not derived from results |
| 4 | Binary custody / source licence | the binary custody certificate and source-use licence covering redistribution and derived-relation publication | any derived-relation or consumer publication |
| 5 | First possible original **GT2 slice** | the smallest real instrument slice whose native item order, roles and topology the ordered-topology owner has been issued for | promoting the two HELD `ORDERED` obligations to runnable |

## What this return does NOT claim

* No real original survey respondent data was used, created or admitted.
* No source/E/EE permission, 35 waves, N11/N12, V3, actor or canonical
  adoption.
* The sourcefree result is never called a real-source E pre-result.
* Source-authorized positive remains a separate future gate and is not a global
  block to sourcefree method advancement: the sourcefree register, gate,
  role/topology validation and consumer witness are all executable and tested.
