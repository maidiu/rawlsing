## 6. What would count as scientific issuance

A competent owner would need to provide, for the chosen narrow family:

1. Rule ID, version, content hash, owner and scope.
2. Exact actor-experienced parent and access/source witness.
3. Exact input fields, state/history predicates and rival-response exclusions.
4. Exact target kind, payload, lifecycle and valid-empty behavior.
5. Later consumer identity and the actual permitted/action result it changes.
6. Scope, uncertainty, transport limits and refusal conditions.
7. Independent source/owner acceptance; a code test or a simulation output is not self-validation.

Without that, the correct status is `MISSING_RULE` or `HELD`, not `NO_CHANGE`.
