## Public API

`ProgressivePrefixInput` carries one actual producer prefix: exact target ref,
ordered conditioner refs/values, repository/release, empirical query, predicate,
authority registry, positioned consumer query, model rule and condition witness.

`configure_progressive_world_context`:

- validates target and prefix order;
- invokes actual `provide_empirical_possibility_slice_ext` for every prefix;
- requires exact `EXACT_SUPPORTED` consumer results and actual composition
  evidence;
- builds actual P41 `SelectedWorldCatalog` snapshots T0/T1 over the same
  source-free empirical identity;
- optionally revokes one named world scope;
- registers an opaque local handle. No subject-selected runtime/oracle is the
  authority; the actual P41 packet is fixed at `f27d1101…`.

`ProgressiveWorldRequest` selects the handle, T0/T1 snapshot, purpose,
currentness/as-of. `progressive_world_view` invokes actual pinned P41 with
`world_part=True`, an actual structural service and a provider made from the
actual computed prefix extensions.

World revocation produces a typed unavailable route, not a fabricated zero.
The sourcefree fixture is not original source evidence; F5/F6/F7 original
product families, selective invalidation across the full estate, original
temporal pairs and R09 protected capture remain held.
