  witness.
- `configure_progressive_world_context(...)`: validates actual prefix

  `provide_empirical_possibility_slice_ext` for every prefix (or the accepted
  single-condition provider), builds/retains actual P41 selected-world snapshots
  over the same R05 source identity, and registers an opaque local handle.
- `ProgressiveWorldRequest`: handle, snapshot key (`T0`/`T1`), purpose,
  currentness/as-of.
- `progressive_world_view(request)`: resolves the registered context, runs the
  actual pinned P41 service with `world_part=True` and a provider built from the
  actual computed prefix extensions, and returns the actual N9 world + N10E

The public function does not hardcode Q86, X/Y, one conditioner, or a fixed
calendar pair. Tests instantiate the existing admitted R05 source law with two
prefixes and a world rule snapshot; fixtures do not become original source
