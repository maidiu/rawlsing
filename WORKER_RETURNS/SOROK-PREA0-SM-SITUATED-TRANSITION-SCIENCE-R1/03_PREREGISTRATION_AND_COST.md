# S-M — K1–K6 preregistered trial protocol, executable gate, cost and branch audit

**Status:** Fully specified synthetic transition experiment **NOT YET RUN AS A/B/C ACTOR SYSTEM**. This is a protocol, not new semantic authority. The companion 02_K1_K6_SPEC.json contains world-bound K1–K6 fixtures, candidate transition rules, baselines, hypotheses and output fields. The standalone source-free repro/sm_court.mjs checks fixture/receipt shape only; it does not implement actor, memory, institution, CAN008, or causality. No fictional pytest.

## 1. Experimental grain

Use a deliberately **invented**, bounded late-1990s apprenticeship/certification setting, NOT real historical sociology. Each world receipt records its effective interval, municipal institutional rules, actual enforcement, resources, housing/labor, supervisor versus registrar powers, sanction/exit routes, the actor's material position and role, actual relationship, opportunity/exposure, prior actor-world developmental events, and exact precipitating admitted event. Under K6 later foreperson capacity is only legal in a separately dated future world/position receipt. **Never change capacity by changing a title string.**

History is monotonic and provenance-anchored. Current actor owner-state is partly formed by admitted earlier world relations. Distinguish society's actual recognition rule from actual application, actor uptake and private self-belief. Any case lacking a required world/position/relationship/history/opportunity/event input is UNDERSPECIFIED; no response commit. An event label by itself must not create state.

**Baseline A:** existing admitted event/relationship/history, CAN010 and CAN011 owner states, ADP015 relationship, ADP016 memory/trace, ADP017 epistemic states, CAN008 R2 reception/recruitment/current responses. No new store.

**Baseline B:** A plus event-local conation, witness/recognition stakes, pressure/conflict, lawful alternative routes and actor-relative costs. Not automatically durable; no permission to add independent psychology.

**Baseline C:** B plus selectively typed temporal/n-ary relations (e.g., compensates-for versus conditions-recognition), each supported by an exact formation parent, owner, rule, scope and lifecycle. No extra causal graph state is admitted under this commission; C graph is a test proposal or history-rebuildable view pending external rule grant.

**Narrative-only comparator:** may narrate matched inputs for a descriptive control but gets no machine-effect score from prose.

Fairness rule: A/B/C see the **same eligible** admitted history, world and owner evidence. If C gets a relation index, A gets the equivalent history/owner effect in its retrieval, rather than artificially poor context. Match model versions, 1 model call maximum per arm, proposed 6,000 input-evidence-token/24-ref cap, 12 paired seeds per K pilot, same retrieval cap and explicit context-window token accounting. All these numeric choices are preregistration PROPOSALS, not adopted budgets or measured costs. Model/use/RNG permission required before any actor trial.

## 2. Machine-first evaluation protocol

Strict result JSON fields: case, arm, seed/model/version, exact world and actor history/relation/position/opportunity/event hashes, read-evidence list/tokens, CAN008 receivability and actor uptake, independent recruitment streams and candidate responses, proposed/authorized/committed destination-owner effects, actual external actions and institutional changes, ADP016 memory/access/trace, ADP017 claim permissions, pre/post owner-state hash, honest typed HOLD/VALID_EMPTY, replay and cost.

Order of evaluation: (i) validate all causal inputs and world clocks; (ii) reject any unadmitted event, unsupported effect, or actor-inaccessible origin; (iii) compare machine-level recruitment/effect and action paths by arm; (iv) test null controls and independent held-out worlds; (v) verify cold replay and unchanged original causal history; (vi) only then review prose for leakage. Altered adjectives, plausible explanations or compelling therapeutic language count as **zero** scientific gain. Test actor with no explanation, incorrect explanation and confident false causal attribution without rewarding the most articulate voice.

Hard invariant failures override numeric scores: zero origin disclosures through actor projection; zero category-only punitive action; zero public institution mutation from noncertifying witness; zero effect from unadmitted/rejected occurrence; zero durable CAN008/PFF shadow state; zero prior-history rewrites. Reject attempts to turn C experimental graph edges into unissued owner effects. Worldless event = HOLD, not an unconstrained personality choice.

## 4. Actor opacity audit

Analyst full cause graph may be read by validator; actor projection must be *constructed independently* from ADP016 memory accessibility and ADP017 epistemic permission. Compare actor-safe payload with/without origin injected only in evaluator-side metadata; require bitwise unchanged actor-safe content, not an instruction to the LLM to hide its secret. An ADP016 nondeclarative trace may recruit response but cannot authorize episodic recall. A retained memory inaccessible at time t is not the same as UNAVAILABLE source content; neither can be rehydrated from immutable ledger by fluent language generation.

Test actor says “I acted because the supervisor dislikes me” when machine identifies different admitted parent, with permitted ADP017 belief/claim. The objective utterance occurs; its explanation can be false. Also test no explanation and unwarranted apparent certainty, but the latter only after a separate lawfully admitted mistaken belief—do not manufacture speech permissions. Distinguish claimed truth from objective institutional standing and from analyst causal hypothesis. Leakage kills case regardless of apparent response fidelity.
