## Canary-only versus genuinely current

The matrix deliberately does not label an entire EE responsibility `CURRENT_CANARY_ONLY` merely because one positive implementation is a canary.

Examples:
- GT2/GT12 is canary-specific inside EE15's otherwise-generic boundary law;
- B10's GSS JCFG is a bounded positive inside EE05/EE03's operation-scoped machinery;
- particular positioned-subject outputs are claim-bounded inside EE14's current interface.

The correct unit of “canary-only” is often the positive claim/producer instance, not the whole responsibility.
