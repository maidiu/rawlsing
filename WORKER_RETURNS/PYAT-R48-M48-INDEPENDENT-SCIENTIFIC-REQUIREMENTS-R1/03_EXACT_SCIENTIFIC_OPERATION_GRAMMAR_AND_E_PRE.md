# Prospective scientific grammar

Proposal `M48_SCIENTIFIC_GRAMMAR@1`; not native issuance. Eligibility concerns a defined estimand, not whether an empirical result will be interesting, nonzero, significant, or sufficiently powered.

An operation is the ordered record:

```
(source scopes, unit/linkage, ordered target components and topology,
 condition expression, administration/risk/state plan, measure/estimand,
 comparison baseline, claim class, validation plan, consumer purpose,
 authority/current-selection closure, grammar/version/bounds)
```

Content identity includes constitutive roles, domains, scopes and rules. P1 claim, governing-instance, current-selection and use-permission identities remain separate. Sort conjunction syntax only when commutativity is proved. Target component order, rank order and source roles remain explicit. Retain aliases from duplicate derivations to canonical operations; do not count hash equality as scientific equivalence.

| Class | Construction / required precondition | Emitted interpretation |
|---|---|---|
| DIST | Every eligible item/form and governed state-domain variant | Univariate achieved-sample or design-qualified population distribution. |
| CONDITIONAL | Target T plus permitted distinct conditioner atoms and explicit risk intersection | Distribution T given C; separately generate reverse roles only if those roles and the reverse risk are covered. |
| JOINT | Same-unit admissible component tuple, explicit set/ordered/scalar topology, joint risk | Joint cell surface; marginal comparisons computed on **that same risk**, not independent available-case denominators. |
| CO_TRAVEL | Joint/conditional surface plus baseline and declared descriptive contrast | Association, alignment, contradiction; no typed semantic/causal relation implied. |
| FORK | One further nonredundant condition on a governed branch, all levels retained | Parent and child distributions, specificity and population loss; both minority/opposed and modal branches. |
| INTERACTION / REVERSAL | Complete bounded condition grid, joint and baseline roles | XOR, higher-order dependence, Simpson-type reversal; no unary-salience prerequisite. |
| STATE / ROBUSTNESS | Approved missingness, recode, design, weighting and specification variants | State distributions, sensitivity/stability contrasts; variant meanings never fused. |
| CROSS_SOURCE | Source-indexed results first; composition only with operation-specific P3/EE12 premises | Comparable, noncomparable, disagreement, partial bounds or authorized composition. Never synthetic person joins. |
| TEMPORAL | Actual comparable observed wave scopes and temporal method | Estimate/delta with uncertainty and time provenance; instrument existence alone yields a candidate obligation. |
| POSSIBILITY | Lawful subject-coordinate mapping into conditional joint support | Population possibility, exact or governed proxy; not actor belief. |
| STRUCTURAL | Empirical evidence plus claim-specific FF position/relation/use authority | Structurally admitted claim, independently of descriptive candidacy. |

The first six classes can be generated generically from governed types and role policies. The last three contain additional method/use/structural decisions. Presence of an item does not instantiate every class. An approved descriptive role grammar can admit same-respondent co-travel even where Job3 semantic truth is BLOCKED or negative; it cannot overturn that adjudication.

Generation procedure:

```
1. Read exact all35 inventory roots and current selections, without respondent values.
2. Validate completeness against independently recovered instrument/edition item inventory.
   Keep unknown item/form/module coverage as an explicit inventory gap; do not issue a full U root.
3. Expand permitted source occurrences, topology components, finite code/state domains,
   condition atoms and governed recodes. Continuous splits need approved fixed bins or a
   bounded, prospectively specified threshold algorithm with exploratory/validation rules.
4. For each permitted target tuple (1..J), condition tuple (0..K), state/measure variant:
   typecheck roles, same-unit premises, scope, route satisfiability, state and estimand.
   Emit ELIGIBLE / PROHIBITED / INAPPLICABLE_PROVED / UNRESOLVED_SCIENCE with reasons.
   UNKNOWN premises never grant eligibility; unsupported runtime is a separate obligation.
5. Compute risk/dependency closure and canonical operation identity; retain derivation aliases.
6. Freeze E_pre scientific root, eligibility/disposition ledger, omission receipt and validation
   plan. Resolve source-host-purpose grants independently; create executable subset E_exec.
7. Lower E_exec into exact query/predicate/template/catalog/projection refs and Batch units;
   independently anti-join expected identities against compiled units. One I05 unit may
   cover many candidates; maintain candidate→query-role→unit→fact→consumer edges.
8. Execute. Results change empirical/validation states, never E_pre membership.
   Preserve opposed, null, sparse, underpowered, empty, unavailable and integrity outcomes.
9. Adjudicate learned claims separately, then structural/transport/consumer use separately.
```

Scientific eligibility, implementation support, source permission, execution state, validation and release/use state are **orthogonal columns**, not one status enum. A source can have scientifically known operations with current execution forbidden. Where the original administered inventory/grammar is unissued, original U/E_pre count is NULL with the missing basis; `E_exec=0` does not imply `E_pre=0`.

Finite closure: bounded finite source/item/domain sets, J target arity, K distinct conditioner count, D branch depth, finite state/measure variants and finite comparison rules. Never re-add the same conditioner along a branch; do not condition on a deterministic copy of the target or use aliases as additional evidence. Prospective domains with no observations still have cells. For n target-capable scalar items and m conditioner dimensions with a values each, an upper bound before type/risk pruning is `sum(j=1..J) choose(n,j) * sum(k=0..K) choose(m,k)*a^k * variants`; actual topology domains differ. Report the bound, feasible counts and unresolved classes separately. Computational expense does not prove inapplicability.

Default design proposal: validate K=2/J=3/D=2 as an initial interaction tranche, **not** the terminal scientific maximum. A depth/arity beyond it stays in a deferred hierarchy with the exact capability and trigger for expansion. Each release declares its own accepted bound and residual requirements. Recursive closure is finite at each release. New source/method/grammar versions open a new prospectively frozen release; prior denominators remain immutable. No finite bound proves absence of arbitrary-order patterns outside it.

Stopping: exact I05 evaluates all compiled candidates. Budget exhaustion yields PARTIAL with scheduled/evaluated/pending identities. Adaptive order can prioritize work under frozen deterministic tie-break and seed law but cannot call an unevaluated branch absent. Support-based pruning is permissible only under a proved monotone bound for the **specific** predicate/estimand and a declared reduced claim; unary information gain does not bound XOR or minority conditional discovery. Preserve the complete eligible symbolic domain even when only an execution tranche is materialized. Caches affect cost, never reachability.

Hostile comparison frozen before proof implementation: declared sourcefree items A, B and target Y are binary, same adult unit, fully administered; ID is administrative and H is household-only without linkage. Y follows XOR in the A/B grid. Another governed group M has a 10% stable minority with Y=1. A naive all-pairs semantic graph invents meaning for ID→Y/H→Y and may interpret raw code coincidence as relation truth. A whitelist admitting only unconditional Y and unary A/B misses the valid zero-unary-signal interaction and an unlisted minority condition. The principled generator denies the ID/H roles, enumerates all covered two-condition grids plus M, and reports the resulting descriptive facts without declaring causality or structural truth. The synthetic values are witnesses, not original-source findings. The executable proof must also keep the frontier identical when these synthetic values are permuted or changed.

Statistical validation is an additional contract: declare exploratory status, outcome/contrast family, design-correct uncertainty, minimum precision/reliability rule, multiplicity strategy and replication/holdout procedure **before** acceptance. Freeze PSU/household-aware validation partitions where applicable; row-random splits do not automatically provide independent validation. With no valid validation sample/design, publish exploratory descriptive evidence plus limitation, not validated population law. Exact I05 predicates such as `DISTRIBUTION_DIFFERS` can be true for tiny sampling deviations. They are not p-values, effect-size thresholds or validation warrants [I05_CODE]. [ASA statement](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf) corroborates the need for scientific reasoning and transparent analysis rather than significance chasing; it does not choose this project's validation model.
