## Two-call accounting — hypothesis, not observation

Earlier Sorok 42 demanded two model calls per consequentially active synthetic actor: with n serial actor passes, planned calls=2n; two active actors 4, three 6. Later Sorok 101 proposes a normal two high-capability calls with minimum competent grain/owner routing and local user phenomenal composition. These are related but not automatically equivalent: an event requiring several interacting actors could make the per-actor multiplier dominate, and some no-op/valid-empty/physical-only events may need no actor model pass. Freeze actor-count criteria *before* measuring.

For one actor pass, define measured input/output tokens A_i, B_i; eligible per-token provider rates r_Ain, r_Aout, r_Bin, r_Bout; provider billed cache read/write costs where applicable. Model-charge baseline per completed pass = A_i_in*r_Ain + A_i_out*r_Aout + B_i_in*r_Bin + B_i_out*r_Bout + any cache and minimum/call fees. Full expected cost per successful turn must ALSO include attempts aborted or rerendered, local assembly/semantic checks, transport, platform, storage/trace and all active/causally ordered actors. No current price inferred from an older market note; no price point, average response time or two-call efficiency can be asserted without real invoices and traces.

Critical path latency cannot be obtained by adding hypothetical token rates. For a single dependent actor: input transduction duration + local owner compute + realization duration + local admission/world transaction + projection + delivery; on hard failure include rerender and recovery. Multi-actor parallelism is constrained by actor-specific event order and any cross-actor causal dependencies. Measure p50/p95/p99, time-to-first-visible and user-perceived interruption separately, at actual n=1/2/3 and cold/warm context. Include event-less, rejected and deferred turns in distribution denominators. Report a rerender as a new model invocation, not a free retry; a no-output operational retry also carries attempted cost/latency where billed.
