# PRE-Runtime-Package Gates and Blockers — Arab Barometer Audit

This file distinguishes **source defects** from **future admission gates**. Absence of a current PRE553 runtime package is not treated as a defect.

## Common source-free gap

### Exact historical/documentary dependency closure

Classification: `SOURCE_FREE_GAP`

All four realization packets pin the canonical survey SHA, base coordinates, and source-local law, but their Authority71/72/questionnaire provenance is cited in human-readable form (packet names, gap IDs, questionnaire pages) rather than as one complete content-addressed dependency graph consumable by a future runtime package.

Required closure before runtime qualification:

- exact immutable refs/content hashes for the accepted Authority71/72 inputs actually relied upon;
- exact documentary artifact/page or governed excerpt refs for each semantic rule admitted to runtime;
- no “latest”, “current”, adjacent-file, filename-only, or branch-tip fallback;
- runtime package identity must include those dependency refs.

This can be closed without opening source bytes.

## Common qualified-source gates

### Decoder-native representation → R5 binding keys

Classification: `REQUIRES_QUALIFIED_SOURCE_OBSERVATION`

The generic consumer uses `PRE553_R5_TYPED_VALUE_CODEC@1.0.0` and `PRE553_PHYSICAL_VALUE_BINDING@2.0.0`. The binding key includes typed raw value, physical missing state, and source missing declaration.

A future package must therefore derive its physical-key domain from the qualified decoder output for the exact source SHA. It must not assume that documentary `0`, `98`, `99999`, or another code is a Python `int`, `float`, or any other host representation.

### Whole-source physical-edge closure

Classification: `REQUIRES_QUALIFIED_SOURCE_OBSERVATION`

Each source already declares its S35/R35 dimensions, but each return explicitly says whole-source physical equivalence was not executed. That future court must preserve the entire declared edge surface, not only runtime-selected questions.

## Runtime-package requirements — not present defects

Classification: `REQUIRES_RUNTIME_PACKAGE`

For every wave a future package must provide, where applicable:

1. an exact `GovernedC11Projection` tied to the canonical source SHA;
2. exact `PhysicalSlot` identity (ordinal + name) and R5 `physical_value_binding_key` values;
3. source-state → C11 typed-state mapping with no generic substitution;
4. exact question/value → response-value refs only where documentary authority exists;
5. exact route/risk ownership and replayable membership for routed targets;
6. adopted runtime authority/catalog identities with frozen release scope;
7. generated query/predicate/fact preimage retention;
8. post-I05/terminal consumer closure over those exact preimages and refs.

## Wave-specific runtime cautions

### ARAB1

The U+0092-bearing literal source string is a physical/source witness. A display-normalized string must have a separately governed transform and a different semantic dependency path. Never use the normalized display string as a substitute physical key.

### ARAB2

The Q2062 ordinary zero and SYSTEM_MISSING state must necessarily produce different physical binding material because physical state is part of the PRE553 key. A dictionary label reading “0. missing” is metadata only.

### ARAB5

Unobserved Q101 dictionary entries must remain in source dictionary identity while remaining absent from observed-incidence claims and unadmitted to substantive response semantics. Missing WT/PSU cannot become row exclusion.

### ARAB8

Empty `BLOCK_ID` is an ordinary string lane, not system missing. Equal Q1/STRATUM vectors cannot collapse the two `PhysicalSlot` owners: slot identity is ordinal+name even if per-cell physical value keys coincide.

## Net admission state

No source is blocked from **authoring** a future runtime package merely because bounded UNKNOWNs exist.

Before that package can be **qualified**, however, it must close the source-free dependency graph and acquire the qualified decoder/whole-source observations required for exact representation and physical-edge proof.
