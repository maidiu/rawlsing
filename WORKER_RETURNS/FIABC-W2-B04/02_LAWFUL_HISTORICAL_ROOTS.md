# FIABC-W2-B04 — Lawful Historical / Immutable Roots

## Rule

A dependency is lawful to retain by immutable reference when the historical or worker-return bytes are themselves part of an accepted authority identity, replay closure, governed evidence chain, or frozen experimental implementation definition. Location age is not enough to create a succession defect.

This follows the Wave-1 Dva/Trii/Chetiri holding:

- direct producer reuse is preferred to serial republication for neatness;
- a logical semantic jurisdiction does not require a separately materialized physical stage;
- rebuildability does not erase authority or replay identity;
- a canonical semantic object does not require one permanent payload carrier.

The relevant current PRE553 owner law remains:

`physical truth -> explicit semantic authority/projection -> I02 seal -> exact repository -> I03 -> I05`

Repositories, caches, worker-return packages, replay builders, and orchestration do not acquire semantic ownership merely by carrying or reconstructing these objects.
