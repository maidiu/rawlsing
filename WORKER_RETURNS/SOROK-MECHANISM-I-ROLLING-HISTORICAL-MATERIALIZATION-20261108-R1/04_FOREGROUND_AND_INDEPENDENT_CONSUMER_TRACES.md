# Foreground and independent world traces

## Foreground resource

`run_p4.new` captures an existing visible tool affordance and saves its
target and demand together. The P4 command wakes the history worker after
the foreground ledger is durable. The mock HTTP trace in [02](02_MODEL_PROVIDER_AND_JOB_RECEIPTS.md)
runs that worker in a separate process. The owner admits a compatible
physical claim and a subsequent committed inspection reads the identical
fact ID. This is a sourcefree engineering proof.

## Independent world output

`run_p4.advance` calls the existing S46 interval producer. The actual
repair reduces material stock and yields a confirmed world event. The
historical owner binds its completed output and queues a separate target
without a user inspection. The test leases that target, passes the sealed
packet through the provider adapter with injected transport, and commits
the returned physical condition through the existing owner. The event is
outside the user's perception. The foreground surface omits the target
and a direct inspection request is refused.

This verifies independent world **production** of a historical target and
subsequent materialization. The inherited S46 prerequisite reads present
tool availability, stock, free hours and actor location. It has no qualified
requirement for the newly admitted condition. Independent world **use** of
newly materialized depth therefore remains held. Live model invocation
and independent receiving also remain open.
