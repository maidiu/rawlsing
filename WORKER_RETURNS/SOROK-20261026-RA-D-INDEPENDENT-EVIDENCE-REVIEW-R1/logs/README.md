# Review logs

All paths are sanitized with placeholders. Hashes and observed values are unchanged.

| File | Meaning |
|---|---|
| `environment.txt` | Host/Python/pytest/git environment, reviewer branch/head, no-provider/no-edit flags. |
| `independent_pytest/*.log` | Reviewer's independent focused pytest runs for the ten suites. |
| `independent_pytest_summary.json` | Counts extracted from those logs (131 total). |
| `reviewer_source_identity.json` | Independent 183/183 S52 Python blob check, five ancestor divergences, S50 31/31, imported module hashes. |
| `reviewer_probe_result.json` | Independent material chain, source-cut controls, controlled paid mutation, later material consumer and S52 hostile RED. |
| `reviewer_v3_functions.json` | Independent one-year recovered-V3 function run; pressure-flow history/memory, topology, roundtrip. |
| `s50_entrypoint.json` | S50 actual-root HOLD and fixture projection. |
| `s44_entrypoint.json` | S44 test-only A-actor first event and targetless result. |
| `s45_entrypoint.json` | S45 language-mediated encounter values. |
| `s47_entrypoint.json` | S47 objective interval conditioning and `NO_CHANGE` target. |
| `s51_entrypoint.json` | S51 G18 object, one-event hypothesis, relevance and S49 `SOURCE_OWNER_HOLD/OPEN_CHOICE_SET`. |
| `s52_entrypoint.json` | S52 conditional candidate, controlled material deltas, cold candidate match. |
| `*.stderr.log` | Empty unless an error occurred; files are retained for completeness. |

The RA-D artifacts themselves are not copied here; the review reads them at `6d3610c5…` and `shasum -a 256 -c` confirms their committed hashes.
