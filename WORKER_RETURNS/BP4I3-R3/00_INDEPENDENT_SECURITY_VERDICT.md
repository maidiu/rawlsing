The author's fork tests seed no episodes and miss this contradiction. Original owners must decide the immutable-origin versus child-location law before changing either identity.

The direct guard correctly rejects `@2`, so this is a consumer bypass of the stated version contract, not an inability to read the bytes.

No signature was invented. An anchor over the current payload could not distinguish those states. The owner must extend coverage or explicitly exclude these claims.

**BP4I3-04 — C9/C12 test-version conflict (P2).** All 141 C12 and 23 S36 Python/SQL source files used by the hard-coded dependencies matched their exact Git cuts.
