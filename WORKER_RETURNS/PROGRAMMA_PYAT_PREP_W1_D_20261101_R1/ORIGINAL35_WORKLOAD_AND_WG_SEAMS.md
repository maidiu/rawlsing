### WG2: prospective finite science frontier

Operator classes differ by scientific object: one categorical response distribution is not equivalent to a respondent-conditioned denominator, higher-order same-person joint, split-form sample, repeated/ranked response, cross-family source-indexed field or comparable-wave trend. Accepted source response labels do not self-issue valid conditioning/joints; an observed zero or weak subgroup is an empirical result, **not** an eligibility exclusion. M48 proposal enumerates DIST, CONDITIONAL, JOINT, CO_TRAVEL, FORK, INTERACTION, STATE, CROSS_SOURCE, TEMPORAL, POSSIBILITY, STRUCTURAL. P1 implements five narrower sourcefree classes: DISTRIBUTION, CONDITIONAL, JOINT, HETEROGENEITY, RECURSIVE_BRANCH. Proxy/hypothetical requires an independent method signer; never substitute for direct measurements.

**P1 conservation limitation (direct static code and test):** `construct_original35_epre` calculates `expected_item_count=sum(len(wave.items) for wave in input.waves)`, i.e. only caller-submitted items. No external instrument-wide oracle is consulted; `no_drop_ok` may be true even when an entire original item was not provided. `_operations_for_item` emits one `CONDITIONER_BINDING_ABSENT` HOLD for a missing binding, while a complete binding in the synthetic test specifies six target×condition combinations; `test_conditional_binding_absence_is_typed_hold_not_silent_drop` asserts 835 operation records rather than the standard 840, and `no_drop_ok=True`. Therefore P1 genuinely conserves typed **declared** work, but cannot assert conserved **original admissible** work. This is a gap relative to WG1/WG2 full oracle, not proof P1 violated its intentionally bounded contract.
