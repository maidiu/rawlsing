## C. Tight dependency logic and stopping rules

1. Physical source + live grant **AND** versioned administered U/routing/missing/design **AND** scientifically issued operation policy/Epre **AND** authorized operation/consumer workload are required for **original35 native source use**. R157/B43 read rights alone do not issue U/Epre; G50 grammar alone does not issue read rights.

No relaunch of those halted workers or automatic widening from later narrow grants.
