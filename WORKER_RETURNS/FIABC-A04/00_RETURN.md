## Holding

The estate is neither "35 sources done" nor "35 adapters missing."

Seven distinct states must remain separate:

1. **PREPARATION** — exact bytes/SHA, decoder expectations, documentary map, hostile fixtures, authority gaps and future court plan.
2. **DOCUMENTARY_AUTHORITY** — accepted permission to assert source meaning, including lawful UNKNOWN.
3. **GENERIC_IMPLEMENTATION** — format/source-neutral code such as the physical decoder and C05-R2A facade.
4. **SOURCE_SPECIFIC_PROJECTION_AUTHORITY** — governed mapping from a particular source's physical slots/states into current C11 semantics.
5. **SOURCE_CERTIFICATION** — exact source instance crossed the governed decoder/authority/replay/hostile court at a named scope.
6. **RUNTIME_PACKAGE** — current query/discovery/authority package built from a certified or governed source projection.
7. **LIVE_EXECUTABLE_CONSUMPTION** — the current running/court graph actually binds and consumes that package.

Collapsing any adjacent pair produces the two recurring false claims this commission was designed to prevent.
