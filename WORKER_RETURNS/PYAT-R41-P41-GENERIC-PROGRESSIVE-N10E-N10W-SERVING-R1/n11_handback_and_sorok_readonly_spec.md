## Sorok C0 read-only interface specification (external; not invoked here)

Shape only — this worker never invokes CAN008 or commands Sorok; any adoption
is a competent later decision by the Sorok owner.

**Permitted operations (read-only):**

1. Read exact values of an already-issued P41 receipt (`n10e_steps` cells,
   denominators, uncertainty) with its `content_hash`.
2. Compare two epochs' receipts for equality or exact cell deltas at the
   structural-rule grain (values only; no probability promotion).
3. Retain receipt references (`receipt_hash`, `consumer_result_hash`) as
   historical evidence.
4. Request `historical_receipt(hash)` — archival reads only
   (`archival_only=true`, `fresh_use_authorized=false`).

**Forbidden operations:**

1. Mutate the catalog, publish rules, or substitute snapshots/releases.
2. Reuse a revoked/no-current receipt for fresh serve.
3. Treat TEST_ONLY fixture numerics as observed source facts.
4. Install N9/OC05, generate parents/actors, or emit encounter/route
   probability from these values.
5. Cross-source person binding or dyad claims without separate linkage
   authority.

Interface version: `P41_VERSIONED_CONSUMER_CONTRACT@1`; versioned provider
fields as in `positioned_possibility_service_contract.md`.
