# Pre-runtime-package blockers and admission gates

## Scope law

This file distinguishes three things that must not be collapsed:

1. a **source-free contract gap** that can be seen from existing governed code/packets;
2. an **authority blocker** where the source package correctly refuses to invent meaning;
3. a **later runtime/qualified-source gate** that is expected because a source-specific realization module is not a current PRE553 runtime package.

No absence of a current runtime package is classified as a defect.

## Source-specific disposition

### EVS 1999

**Source-free gap: exact typed missing-state preservation is not closed.**

The exact reader contract uses `user_missing=True`, but the EVS1999 realization's frozen `R35_REQUIRED_PHYSICAL_DIMENSIONS` contains physical metadata, variable order, raw storage, replay identity, reader/config digest, compatibility-decode evidence, and routing carriers — not `typed_missingness`. Unlike EVS2008, WVS1, and LAT2011, it exposes no source-specific typed missing-state projection.

This is a preparedness gap, not permission to infer what any missing code means. The lawful repair is source-free in form: extend the governed physical contract to retain decoder missing-state/declaration evidence, or provide an equally exact governed proof that the relevant distinction is outside the source's preservation burden. Do **not** infer missing semantics from frequencies, labels, compatibility-rendered text, or neighboring waves.

Other EVS1999 gates are normal runtime-package work:

- materialize exact R5 physical keys only after decoder representation is qualified;
- translate exact documentary variable/value authority into PRE553 question/response refs;
- if documentary routing is emitted as PRE553 routing facts, bind exact risk-set ownership and member-set replay;
- package ZA3811 v3.0.0/national/master documentary authority as immutable historical snapshots;
- preserve `DOCUMENTARY_ALIGNMENT_UNKNOWN` rather than forcing a generic response terminal.

The latin1 path remains **physical-only**. A runtime adapter may consume its cells; it may not acquire text-semantic authority from the compatibility rendering.

### EVS 2008

No source-free realization defect was found in the audited failure classes.

The package is prepared at source-law grain for:

- physical-only latin1 compatibility;
- typed missingness;
- exact 13-set MR topology;
- alias/overlap noncollapse;
- scoped routing authority;
- v372's intentionally unresolved negative subcode;
- bounded unknown outside exact producer authority;
- R35 whole-source physical edge hooks.

Runtime admission still requires exact decoder representation observation and a current PRE553 package. That package must not map producer `-1..-5` by numeric resemblance alone. In particular, `v372` must remain:

`EVS_STANDARDIZED_MISSING__NEGATIVE_SUBCODE_NOT_RECOVERABLE_FROM_DATE_RENDERING`

with:

`UNKNOWN_WITHIN_PRODUCER_NEGATIVE_MISSING_DOMAIN`

until a separately authorized numeric/storage witness exists.

If PRE553 routing facts are emitted, exact risk-set ownership/member replay is required; the existing documentary route law is not itself a materialized respondent membership set.

### WVS Wave 1

No source-free physical-preservation defect was found. The realization is deliberately bounded, and those bounds must survive packaging.

**Authority blocker:** exact routing/risk-set membership is not globally authorized. The realization explicitly preserves `BOUNDED_UNKNOWN` where source-native routing/applicability authority is absent. Large missing blocks, all-system columns, or documentary labels cannot be used to construct respondent risk sets.

Other hard boundaries:

- S007 raw storage is not its F2.0 display rendering.
- V3/S007 snapshot injectivity or naming does not create replay identity.
- system missing, user-missing value/range, and ordinary storage remain distinct.
- all eight all-system columns remain source information.
- all 13 weight carriers remain present, but role/design/estimand are bounded unknown and no default weight is authorized.

A current PRE553 package may emit only question/value/routing/weight semantics for which exact authority exists. If a workload requires a routing risk set that the accepted W1 packet does not authorize, the gate is `AUTHORITY_BLOCKED`, not “infer it from the data.”

### Latinobarometro 2011

No source-free realization defect was found in the audited failure classes.

The critical producer/consumer boundary is **layer identity**:

- questionnaire = administered wording/routing/instrument response codes;
- released-data codebook = released variable/storage semantics;
- methodology = sample/design/country-specific weighting description.

The `P1ST=-2` fixture proves why a numeric-equality adapter is unlawful: questionnaire coding cannot rewrite released-SAV storage state, and released storage cannot rewrite the questionnaire.

`WT` is ready as a preserved physical/source carrier, but not as a generic PRE553 analytical weight. Current `WeightSlotRule`/WeightMeasureFact admission requires exact design and estimand authority. The source realization intentionally authorizes neither an aggregate estimand nor a default WT selection. A workload that wants a pooled/default weight therefore needs new exact authority; carrier presence is not enough.

`IDENPA` is the source-local country coordinate. `NUMENTRE` and `IDENPA+NUMENTRE` do not replace `SOURCE_SHA256+ROW_ORDINAL` replay identity. The packet's zero-based WT ordinal 413 and the generic decoder's one-based ordinal 414 are an index-convention boundary, not two variable identities; a runtime package must bind the decoder slot convention explicitly.

- no I05 execution;
- no measured P2X;

Those are either later gates or lawful bounded unknowns.
