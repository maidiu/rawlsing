## Holding

Wave 1 already proved the governing distinction: preservation of historical bytes or even accepted doctrine is not enough. A measured A/B/C result is succession-valid only when each comparison-required inherited obligation has an exact, inspectable chain:

`inherited obligation -> accepted authority -> current authoritative owner -> executable binding -> live consumer -> A/B/C invariant + cost class`.

This return turns that chain into a machine-readable schema and a fail-closed preflight contract. It does not adjudicate the still-open Wave-2 boundary, semantic-authority, Candidate-C, parity-oracle, or measurement courts; instead it makes unresolved outputs from those courts mechanically block acceptance of a measured P2X result.

- exact refs must resolve to pinned commits/content identities;
- historical or superseded owners cannot satisfy a current-owner slot;
- an adopted owner must have an explicit producer-to-consumer binding and a matching live receipt, not mere repository presence;
- semantic ownership and cost ownership are represented separately;
- typed negative-state law must be explicit and non-collapsing;
- deferred functions require an exact boundary adjudication rather than a local skip;

- `GENUINELY_MISSING` requires evidence that historical/current owner, disconnected binding, superseded implementation, and lawful deferral alternatives were checked first.
