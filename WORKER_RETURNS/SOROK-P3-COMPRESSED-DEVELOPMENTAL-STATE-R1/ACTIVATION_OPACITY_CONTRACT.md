## Activation API

`activate(records, *, identity, context, registry) -> dict`

All documents use canonical JSON/digest from #704; hash fields cover the document excluding their hash. Inputs are detached. `identity` is the actual P2 StateIdentity.document(). Every record uses INTEGRATION_CONTRACT's immutable normalized schema, belongs to the exact root/actor/branch, is effective before/equal current clock, and has a verified hash, source_hash, registry_hash and complete rule_id/version/hash descriptor in the frozen registry. Reject a bad record, not silently skip a bad hash/root/source/version. The fixed registry document contains `grade=SOURCEFREE_TEST_ONLY`, `rules=[{rule_id,rule_version,rule_hash}]`, `source_hash`, `incompatible_modes=[[mode_a,mode_b],...]` and its content hash. Only explicit TEST_ONLY registry identity is accepted; production/native positive requests refuse.

`context` is an owner-supplied immutable document: root, actor, branch, clock, project, counterpart, interlocutor_role, relation_ref, obligation_refs, actor_observed (bool), material_eligible (bool or null), source_refs (nonempty exact source hashes), grade=SOURCEFREE_TEST_ONLY, hash. HQ validates its source documents/configuration and actual P2 material/access receipts before invoking this pure reader. The reader verifies exact binding/hash/types and never treats a demographic label as a predicate. It is not an external-source issuer.

Record payload keeps B1's `mode` and optional explicit TEST_ONLY selectors `activation_roles`, `relation_refs`, `obligation_refs`, `requires_actor_access`. Validate selector types. They are source-hashed hypothetical scope predicates, not native traits. Match exact project/counterpart; evaluate exact source-bound role/relation/obligation/access selectors without changing stored records. An absent necessary input gives UNKNOWN; an explicit unmet selector or inaccessible actor gives INHIBITED; a supported matching read gives ELIGIBLE. Material eligibility is reported independently for each stream and must not create resources, erase capacity or imply enacted action. A stream may be psychologically eligible while material execution is held. No global winner, score or implicit priority.

Return grade, identity, context_hash, registry_hash, entries [{record_id, record_hash, kind, mode, activation (ELIGIBLE|INHIBITED|UNKNOWN), material_eligible, readset}], and contradictions [[record_id_a,record_id_b],...]. Contradiction exists only for same-scope explicitly registry-declared incompatible modes, never merely because two different records exist. Record all independently addressable streams; mark overall status CONTRADICTION when declared incompatible commitments coexist, even if only one is expressed in current context. No lifecycle transition or activation flag is persisted. No writes, no CREATE, REACTIVATE, DORMANT, WEAKEN, REINFORCE or resolution. A separate HQ frozen TEST_ONLY response rule consumes eligible streams; native Rule A remains MISSING_RULE.
