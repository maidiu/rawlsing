# Immutable native facts, current fixture authority and original-manifest replay

`FactCustody` stores canonical bytes, rejects conflicting same-key content and returns detached read/snapshot/restore objects. Snapshot hash validation and collision checks finish before any restored state is changed. The ordinary consumer reconstructs genuine accepted EmpiricalFact objects and verifies native ref, full semantic projection, actual query/predicate/risk/universe, source edition and output projection. A new internally consistent hash is not sufficient: the independently held fixture issuance journal must match the fact produced by a real native I03 invocation and the receipt produced by a real native batch run. Owner-issued original compiled plan identity is also required. Generic custody dictionaries are not accepted native results.

Current grant/version/source/known-at state is read from the separately provisioned TEST_ONLY fixture owner. A mutable legacy plan grant hint can deny/tamper a request but cannot create permission or override withdrawal. Revocation preserves immutable historical bytes and denies current reads/resume. The owner snapshot and issued-plan/fact/receipt journal are distinct from the request and checkpoint. Cold checkpoints include actual original UnitExecutionReceipt preimages and refs/hashes, native fact payloads, source material/editions, independent frontier root and original manifest. The fixture owner seals these bytes; attacker recomputing the outer checksum cannot forge that seal. Restoring through accepted prior_receipts retains original provenance and attempt identities. Completed replay is idempotent in the existing plan, with zero extra executions.

The fixture owner directory/code/host/key is the explicitly trusted local test harness. A host administrator or caller able to modify that trusted component is outside this test boundary. Private ephemeral fixture keys are ignored under runtime and never committed. This is not an external source licence, production cryptographic issuer, distributed currentness service or real model authority. Original data rights remain unissued.
