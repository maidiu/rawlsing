# D03 → D04 productive target/recruiter seam

**Status:** prepared, not implemented and not READY. D03 produces a bounded sourcefree immediate response; it does not write a durable target, memory, acquired trait or performed action.

## Exact D03 output an authorized D04 may consume

| D03 field | D04 relevance |
|---|---|
| `identity` root/actor/branch/clock/state_hash | owner identity; no foreign root |
| `speech_scope.event_id`, `event_hash`, `text`, `speaker_actor_id`, `alias`, `role`, `receipt` | the actual public speech uptake; no hidden reason or decision internals |
| `prior_organization_scope.project`, `counterpart`, `plan_hash`, `scope_kind` | sourcefree P3 prior organization, explicitly not parent identity |
| `activation_context.hash`, `actor_observed`, `material_eligible` | exact activation basis; actual C04 child receipt; material feasibility not evaluated |
| `immediate_response.status`, `eligible_modes`, eligible/withheld record hashes, `contradictions`, `streams` | allowed immediate candidates; not a chosen or durable target |
| `durable_formation.status = MISSING_RULE`, `written = false`, `records = []`, `target_candidate = null` | D03 does not form durable state |
| `source_closure.hash` and files | exact reader identity |
| `store_head.before == after` | no P3 write |

## D04 required ingress

D04 must add its own explicit sourcefree target rule and consume the D03 fields above, not `admissible_options` or provider prose. It must supply:

- an authorized P3 target writer/owner and exact sourcefree target-kind policy;
- a bounded target identity/version and pre/post head expectation;
- the actual speech-event hash, child receipt, prior organization scope and activation context hash;
- a declared acquire/inhibit/reinforce/hold outcome, including evaluated NO_CHANGE and explicit MISSING_RULE/HELD cases;
- B05 duration/antecedent evidence where the packet requires it;
- a real later performed consumer distinct from the same response computation.

## Forbidden shortcuts

- Treating an immediate response mode, option label, provider prose or retrospective narrative as a durable target, memory or native CAN/ADP rule.
- Writing a target from the D03 test fixture's expected response/mode.
- Relabelling the sourcefree `vertical:counterpart` as the registered parent/mother identity.
- Treating parent hidden reason, cash/period noise, decision internals or portal gaze as Nadia-read facts.
- Claiming D04 completeness without D03/B05 qualification or without a distinct later performed consumer.

## Current blocker

D03 is adequate for its bounded immediate-uptake contract, but D04 remains dependency-held on qualified D03/B05 and an explicit target-rule owner. No D04 code or store mutation is part of this return.
