## Scientific interpretation and clocks

The midpoint calculation is exactly `.20 + (5/10)*(.60-.20) = .40`; linear slope is .04/year. That is a model, not an identified observation. Without trajectory assumptions, a bounded scalar at 1995 remains in [0,1], giving maximum absolute error .60 for .40. With explicitly imposed monotonicity between the endpoints, the identification set is [.20,.60] and the midpoint's maximum absolute error is .20. Neither bound is a sampling confidence interval. Sample design, calibration error, variance and national inference are unidentified. M0/M2 impose persistence; their labels do not prove universal safety. Smooth interpolation requires stable measurement, comparable cohort/geography/instrument, a justified trajectory model, and no intervening break. Otherwise prefer typed unknown, partial identification, or an explicitly hypothetical hold.

The code separates target observation time from publication time only through one query year and a retrospective boolean. It has no independent archival known-at upper bound, effective/discovered-at revocation timestamps, or historical-entitlement/current-computation grant pair. A supplied retrospective archive is therefore a caller precondition, not an authenticated dated snapshot. Current denial booleans passing tests do not establish lawful historical rights reconstruction. Historical publication is not historic person knowledge, actual exposure, remembered exposure, or a longitudinal cohort estimand; the API supplies no actor-memory evidence.
