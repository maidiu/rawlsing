## Scientific candidate construction is a two-census procedure
`U` = all **administered native measurement occurrences** admissibly covered by a frozen exact edition/scope. One questionnaire stem may have 0..N option/subitem/repeated/ranked/country/household occurrences; unknown routing is **unknown**, not absent. `E_pre` = prospectively lawful operations over U, emitted by *existing authored* scientific grammar with roles, estimands, risk, design, weight and consumer scope. Many U have no eligible E_pre; some E_pre use several U. Neither 18,285 research identities nor A42 cells equals U or E_pre.

| Morphology | U occurrence rule | E_pre guard |
|---|---|---|
| single categorical/ordinal | code + explicit response/missing option definitions + person/unit | target distribution; ordinal interpretation requires issued order |
| multiselect | stem + separately addressable options and respondent co-selection | full set/joint only when native co-occurrence and nonexclusive semantics supported; no fake scalar |
| ranked/repeated | occurrence index, rank/multiplicity, within-person carrier | rank/order-specific operations; no alphabetical lexical coercion |
| household/selected adult | household, selected-person key and who answered what | no person/household join absent exact same-carrier authority/linkage and selection weight |
| routing/conditional | question path, skip structure, administered/not-asked, risk set | predicate must condition on eligible routed population; unknown route held |
| country/form/shard | exact native variant, edition, language/translation and sampling universe | no pooled country or form operation sans source relation and comparability |
| weights/design/estimand | weight kind, stratum, cluster, frame, raw/support denominator | separate weighted/unweighted admission; absent weight -> typed `WEIGHT_NOT_AUTHORIZED` |
| cross-wave/multi-source/time | independent source edition, wave/time, target and harmonization | F6/F7 separate owner, no inferred comparability from labels |
