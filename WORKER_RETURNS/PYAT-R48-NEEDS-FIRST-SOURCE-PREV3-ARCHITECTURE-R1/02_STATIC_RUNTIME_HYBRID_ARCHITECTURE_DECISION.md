# Architecture decision — hybrid, no compulsory new physical layer

**Decision:** `HYBRID__REUSE_SOURCE_AUTHORITY_AND_EXACT_OPERATORS__BUILD_OR_RECOVER_U_EPRE_PRODUCER_AND_BINDERS__QUALIFY_RUNTIME_SEPARATELY`. Neither source catalogue entries nor a new code module alone can do all required science. Static metadata is not a live licence; runtime search is not a licence to invent measurement semantics.

| Function | Classification / shape | Persistence and invalidation | Content-owner and correctness reason |
|---|---|---|---|
| Source editions, questionnaires, codebooks, county/shard/form, survey manuals | **A** governed archival **resources** (existing at partial historical scope; inspect exact successor) | immutable source-hash authority + version/edition; invalidate source-dependent descendants upon correction | competent source/instrument owner decides facts; no parser can say what a question *means* |
| V550/551/552, P2/P3/P3C/V550J/HARVEST/P10 relations, item scope/response/routing/missing weights | **A** governed semantic resources, partial reusable; specific source-only gaps require **new adjudication**, not heuristic filling | preserve historical grants, current-lifecycle/ref, exact provenance and source-specific validity | exact label overlap or item pair not sufficient for semantic/joint use |
| Index of source item occurrences and owner evidence | **B** rebuildable, exact compiled index **plus** human-reviewed completeness evidence | derived from versioned source instrument/roster; integrity root; invalidate on source/authority edit | `U` is administered occurrence with per country/form/risk/rank; may contain >research register |
| Eligible operation production | **C** **generic compiler/constructor** using governed grammar: emit finite E_pre with typed exclusions / holds; **build/recover** | freeze rules and candidate denominator before results; recompile on authority/scope change; retain old roots | finite space cannot be 'all pairs'; source-specific scientific role/design decisions stay with qualified owners |
| Source rights / permission | **D** independently authenticated host+purpose+edition+operation entitlement; runtime check **on every use** | current revocation, time and export/retention rules; never derive from presence of bytes | licence custodian; historic LiTS AS2B grant not portable |

| One-time country personality/Enneagram vector as source proxy | **F** not sufficient for prospective empirical/structural/person needs | historical/legacy contextual resource only unless separately governed | aggregate field cannot instantiate individual psychology |

**Failure modes against a false monolith:** one blob fuses licence, source meaning and estimator; makes expiry nonlocal; cannot invalidate one country/form; masks unknown with 0; feeds psyche directly. **Failure modes against resources-only:** 35 manually selected item lists and fixed pair hypotheses do not independently discover emergent minority forks; new questions require a person to handwrite code. **Failure modes against code-only:** grammar over mere variable labels confuses household/respondent and invents weighted estimands. Therefore thin reusable producer **and** governed resources **and** qualified runtime, with optional compiled model persistence.

**Authority/currentness:** issued `SourceEdition`, `InstrumentOccurrence` and `ScientificOperationRule` each get distinct issuer/claim/lifecycle/permission refs. Compiled indexes do not become authoritative simply by hashing. An authorized recompute may change values but not retroactively rewrite source or old end-product evidence. Revoke/new semantic edition -> invalidate exact affected U/E_pre, query batch, learned release, F-consumers/N11 descendants; unaffected sibling fields stay usable with unchanged refs. Four clocks: source/research effective time, publication, requested as-of, and current permission/release status.
