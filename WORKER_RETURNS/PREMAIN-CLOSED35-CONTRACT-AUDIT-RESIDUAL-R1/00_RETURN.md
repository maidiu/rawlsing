## Critical contract finding

A declarative source realization is not a current PRE553 runtime package.

The generic PRE553 seam currently makes representation identity materially causal:

- `physical_value_binding_key(...)` hashes the R5 typed encoding of the decoder-observed raw value together with physical missing state and source missing declaration;
- a response rule is selected by exact `physical_key`;
- an unbound response value/state is rejected rather than repaired by label/frequency/missingness inference.

Therefore every future CLOSED35 runtime package must bind governed rules to the **lawful decoder representation**, not merely to an equal-looking numeric magnitude.

Separately, exact I05 retains empirical-fact preimages internally, but the current cross-stage audit question remains whether dynamically generated query/fact preimages and source-specific terminal states survive into every post-I05 consumer rather than being resolved only from a static pre-search catalog or substituted into generic fields.

Those are source-free/generic admission questions, not defects in a CLOSED35 source.

## Classification semantics

The check matrix uses only the commissioned states:

- `PROVED_READY`: the banked source packet already carries the required law at audit grain.
- `NOT_APPLICABLE`: the banked source edge/domain does not invoke the check.
- `SOURCE_FREE_GAP`: closure belongs to generic PRE553/FIABC machinery, not this source's documentary estate.
- `REQUIRES_RUNTIME_PACKAGE`: the generic capability exists or is structurally expressible, but no source runtime package freezes the needed exact preimage/scope.
- `REQUIRES_QUALIFIED_SOURCE_OBSERVATION`: only a later authorized exact-source court can issue the required physical receipt.
- `AUTHORITY_BLOCKED`: an exact producer/documentary relation required by the check remains unknown.

Absence of a runtime package is never counted as a source defect.
