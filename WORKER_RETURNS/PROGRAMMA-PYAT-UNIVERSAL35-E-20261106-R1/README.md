# Universal35 E — FIELD FORGE empirical ingress

Thin source-neutral ingress over existing current owners. Not a second empirical
or FIELD FORGE engine.

## Frozen interface

```text
rawlsing_next.pre553_field_forge_empirical_ingress.ingest_empirical_fact(
  fact=EmpiricalFact@1.0.0,
  query=EmpiricalQuerySpec@1.0.0,
  conditioner_ref=None,
  target_ref=None,
  producer_permission_ceiling=("FIELD_FORGE_RELATION_PRODUCTION",),
  relation_permission_ceiling=None,
  try_structural_bridge=True,
)
```

Existing owner chain: frozen
`field_forge_conditional_support.produce_exact_conditional_support_profile`
then `gt12_c_to_d_relation_bridge.bridge_gt12_c_relation_to_d_evidence`.
Structural admission is not called and no structural grant is returned.

## Cold-use commands

```text
python3 WORKER_RETURNS/PROGRAMMA-PYAT-UNIVERSAL35-E-20261106-R1/run_ingress.py abi
python3 WORKER_RETURNS/PROGRAMMA-PYAT-UNIVERSAL35-E-20261106-R1/run_ingress.py selftest
```

`selftest` uses labeled TEST_ONLY sourcefree current-owner fixtures: a two-target
GT2-compatible fact yields the existing conditional support profile with withheld
structural meaning; a current I03/N10E one-target fact yields the typed
two-target refusal.

r1 exact linkage: condition predicate, measure basis, response-state semantics,
source scope and measure kind must equal the bound query before delegation.
Missing/None/mismatch is a typed ingress error. See `revisions/r1/00_RETURN.md`.

## D binding

D must supply exact current `EmpiricalFact@1.0.0` + `EmpiricalQuerySpec@1.0.0`
objects matching `D_INPUT_CONTRACT.json`. Authentic D products are
`NOT_RECEIVED_BY_E`; this return contains no original response bytes.

## Cold envelope command (r2)

```text
python3 -m rawlsing_next.pre553_field_forge_empirical_ingress \
  --envelope <exact-envelope.json> [--out <result.json>]
```

The envelope schema is `PRE553_FIELD_FORGE_EMPIRICAL_ENVELOPE@1`; see
`INTERFACE.json` and `D_INPUT_CONTRACT.json`. It is a thin serializer around the
existing accepted `ingest_empirical_fact` owner, not a second engine.
