**Is whole-person back-generation computationally ridiculous?** **Not at this grain.** With finite precommitted attempt slots (4), ~20 typed events per father history, rule-driven forward construction and one frozen LLM proposal call per fixture/route, back-generation costs milliseconds per attempt. S-G's R1 combinatorial-explosion risk (`O(C·H·E)`) does not materialize here because history construction is a bounded rule-driven search, not per-ancestor model generation. ## Dev-loop mechanism defects found and fixed (disclosure)

During lab implementation, one substantive scientific defect was found and fixed before the final run (kept for the record; final run is post-fix):
1. **Endpoint teleology (serious):** the first construction draft wrote the endpoint state's place *from the endpoint constraint* instead of deriving it from the causal chain — exactly the "endpoint-ready psyche by fiat" failure S-G `02` §4 forbids. Fixed: endpoint state is now derived from route-establishing events; unconstructible endpoints (K11-RETRY-BIAS) then fail honestly for the right reason. Two draft runs before the fix are NOT evidence and are excluded from receipts.
2. Receipt-binding gaps (selection→dedup hash chain binding; qualification receipts missing route truth fields; a detector false-positive on the phrase "no typicality mandate") were repaired as mechanism/telemetry defects, without weakening any contract assertion.
