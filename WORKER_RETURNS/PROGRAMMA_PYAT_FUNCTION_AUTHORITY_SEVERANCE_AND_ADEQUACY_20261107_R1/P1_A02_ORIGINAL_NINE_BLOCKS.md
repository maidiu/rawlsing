# FIABC-A02 — NON-REGENERABLE SEMANTIC CAPITAL

## Governing rule

A carrier may be regenerated. A governed meaning may not be regenerated **by convenience**.

For this return, "non-regenerable" means that after losing the governing authority object, the project cannot lawfully recreate the same semantic claim merely from source bytes, labels, codes, layout, frequencies, missingness patterns, lexical similarity, empirical association, newer timestamps, or a cleaner implementation.

The recovered R3 consumer guide states the project-level rule directly: later work is supposed to reuse already established semantic-relation structure, failure law, coverage law and source-first distinctions rather than rediscover them. A later campaign may supersede them only with explicit governed evidence.

## 1. Question / proposition identity

Non-regenerable content includes:

- whether two implementations express the same governed proposition;
- whether an implementation is the same canonical question across a specific scope;
- manual-review decisions and exact historical reviewer rulings;
- structural-coordinate assignment and blocked-coordinate judgments;
- whether a legacy governed row survives despite absence from a newer target.

Forbidden substitutes:

- variable-code similarity;
- text similarity;
- same driver/facet;
- newer generated registry;
- newest timestamp;
- current file presence alone.

## 2. Response semantics

Non-regenerable content includes:

- substantive versus special/context/administrative response status;
- response direction;
- response intensity;
- neutral/boundary meaning;
- response-scale certification;
- source/manual exceptions.

Forbidden substitutes:

- numeric ordering alone;
- response labels alone;
- old `inferred_from_response_family` assignments;
- assuming every blank direction is an authority failure;
- reviving quarantined legacy rows as semantic assignments.

Mechanical work allowed after authority exists:

- applying an exact certified contract;
- joining an exact governed response row;
- computing a numerical coordinate from an already-authorized signed/intensity mapping.

## 3. Routing / applicability / risk sets

Non-regenerable content includes:

- whether a question is in scope for a respondent;

Forbidden substitutes:

Mechanical work allowed after authority exists:

## 6. Negative and unresolved states

The following distinctions are authority-bearing and must survive exactly:

`REJECT != PROVEN_NEGATIVE`

`BLOCKED != NEGATIVE`

`TYPED_SEMANTIC_NEGATIVE != EMPIRICAL_ANTI_CORRELATION`

`ZERO_POSITIVE_COVERAGE != ABSENCE`

`NOT_EXAMINED != NEGATIVE`

`WITHDRAWN_OR_NOT_CURRENT != FALSE`

`ROUTING_UNKNOWN != NOT_APPLICABLE`

`PHYSICAL_MISSING != SEMANTIC_MISSING`

A later successor obligation may authorize new work without mutating the frozen earlier verdict.

## 7. Weights / design / estimand

Source documentation can govern a weight's purpose. It does not automatically decide every Rawlsing query's estimand.

Non-regenerable content includes:

- which weight/design regime is authorized for a specific claimed estimand;
- whether sample designs are compatible;
- whether a variance estimator is authorized;
- whether cross-source values are measurement-compatible.

Forbidden substitutes:

- selecting a weight because it exists;
- defaulting to the most common weight;
- inferring variance design from a PSU field;
- inferring portability from semantic relation or respondent linkage.

## 8. Source relation / universe / composition

The estate distinguishes:

- source/wave identity;
- respondent linkage;
- source-semantic equivalence;
- overlap/non-duplication;
- sample pooling;
- estimand composition;
- backfill;
- measurement/scale compatibility.

None of those relations automatically entails the next.

Exact crosswalks are therefore semantic authority. String similarity is not.
