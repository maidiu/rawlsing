### 2.2 Gonzalez, Lerch & Lebiere (2003) — instance-based learning theory (IBLT)
**Primary abstract actually read**, Wiley `Cognitive Science` 27(4), 591–635, DOI `10.1207/s15516709cog2704_2`: `https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog2704_2`; public Carnegie Mellon repository `https://kilthub.cmu.edu/articles/journal_contribution/Instance-Based_Learning_in_Dynamic_Decision_Making/6571193` abstract also found. **Access level: published abstract, NOT full methods/results or raw experiment data.** The paper proposes instances containing situations/actions/experienced outcomes, similarity-based retrieval, adaptive strategies, necessity-based choice and feedback updates; implements an ACT-R model and reports experimental comparisons approximating relative trends/magnitudes of human data in dynamic decision tasks. **Legitimate warrant:** a functioning generative, experience-conditioned *model family* exists and has at least task-domain empirical evaluation; it is false that all practice generation is a priori arbitrary. **Limit:** not independently validated for this synthetic A/B, social ideology, heterogeneous milieus or a specific GM01 inspection learning effect; no adoption of paper's numerical utilities/probabilities.

## 3. Constructive model is a *substantive simulation commitment*, not mere “we will decide later”

The A mechanism names a finite, testable choice-construction class. Given *exactly sourced* actor projects/histories, it constructs actions *not supplied as response outputs*, independently checks feasibility and actor knowledge, builds multiple context-dependent reason links, performs an explicit finite pairwise comparison or leaves choices open. It can actually produce a selected action where source-grounded conditional priorities produce one undefeated candidate. The contested part is the declared selector when sources leave genuine alternatives: whether to leave OPEN, invoke a separately authored policy, or use legitimate randomness is a **product-modeling commitment**; it cannot be silently absorbed into free-form “what would Nadia say?” prose.

The T mechanism names a finite, testable acquisition class. It records independently performed case episodes with visible feedback, proposes context-guarded method reuse and later tests adaptation; only a specific rule with beforestate and independent transfer can qualify a `V3MS_PRACTICE` target. An *actually enacted simulated trajectory* supplies valid source evidence **inside the simulated world** but *not independent empirical validation that humans learn that way*. The true scientific source/behavioral-prior and qualification constraints are distinct from code correctness, just as S35 demanded.

### Why this is not the rejected CAN011 legacy recurrence rule
The old test-only `prior_response_count >= 2` and two declared action IDs encode learning in the rule inputs. S38 never uses action count as sufficient. It distinguishes:
1. **current activation** of previously sourced competence, requiring no new T;
2. **encoded episodic experience**, belonging to the competent memory/event owner and able to affect later retrieval if governing law permits, requiring no fictitious target;
3. **learned conditional procedure**, with beforestate, novel method/procedural qualification and independent later context-specific transfer under exact rules; *only* this may support an **explicitly proposed** T CREATE (not currently issued).
A CAN011 update can still correctly be NO_CHANGE after 100 repeated procedures with no qualified comparative change, while one extraordinary actual instructional episode may create a memorable case without establishing practice.

**T construction test:** Baseline actor cannot execute a particular *composed method* despite comparable tools (tested by independent world capability evaluator, not lack-of-tool substitution). A learns constituent relation via independent observed demonstration, attempts method, gets feedback, successfully applies it later to a changed but applicable pump variant with own action. Store source-bound episodic experience; propose scoped `V3MS_PRACTICE` with method/guard/beforestate/transfer witnesses only **under a specifically issued CAN011 T**. Remove instruction or enacted practice parent while keeping later opportunity/role/tools constant: the same later **eligible-method availability and attempted-action consumer** must not claim this trained method as acquired; restored source restores candidate. Without T issuance, run this as explicitly TEST_ONLY procedural compilation with `CAN011_NO_CHANGE`, preserving truthful actor event/memory.

**Countercase:** Learner fails task because no tool, then B gives tool and learner succeeds with unchanged method. Expected T `NO_CHANGE` even if a dozen successes ensue; opportunity, not acquired procedure, explains the difference. Another countercase: A performed method once but received no outcome feedback and no valid transfer; *episodic record* exists, newly acquired durable method claim does not.

**Atomicity:** admitted independent world action source and CAN008 response receipt are separate from any proposed CAN011 update. A denial of T must leave actor history and current world action intact; it must not rewrite prior speech, change objective tool stocks, mint a ghost learned method or collapse contradictory projects.
