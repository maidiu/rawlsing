## Positive / negative oracle

- Positive: actual M01 discovery product -> M1 RULE_SATISFIED -> M2 release ->
  actual C1 conditional evidence -> unchanged N10E consumer EXACT_SUPPORTED.
- Refuse: nonproductive/blocked learned product, missing M2 release/protocol,
  absent current selection when required, unsupported/absent empirical evidence,
  producer query/predicate mismatch, or evidence source universe outside the
  learned disposition.
- Sever/restore: blocked learned product or changed empirical determinant changes
  the SAME consumer assertion; exact original restores positive.
- Preserve typed statuses and AXES: observed zero/supported, ZERO_SUPPORT,
  unsupported/held distinctions, valid null/empty, allmissing Z UNRESOLVED
  denominator 16 (retained by the existing status/reducer court, not redefined
  here).
