For a bounded local successor lab:
- SQLite event/relational truth store;
- content-addressed artifact files or blob table;
- deterministic transaction/version checks;
- immutable export to Parquet/DuckDB only when analysis requires it;
- no graph database until traversal measurements justify it.

This is a replaceable baseline, not production freeze.
