## K1 — Same world, divergent generated persons

**Target:** prove the machine can generate divergent lawful persons under identical competent structural context.

Hold world/provider, initialization authority, scheduler and rules fixed. Vary only governed stochastic/event history.

**Pass:** held-out response differences are traceable to different admitted histories and survive renderer paraphrase controls.

**Fail/kill:** differences exist only in prose; hidden type/persona labels are needed; or outputs diverge without causal ancestry.

## K2 — Same nodes, different topology

Construct two persons with the same inventory of durable state objects but different admitted relation topology.

**Pass:** topology intervention changes predicted/recruited responses in preregistered held-out situations while equal-node controls remain stable.

**Fail/kill rich graph causality:** prompt wording or graph labels explain the difference; relation topology adds no value over event/relation history; or intervention has uncontrolled collateral state changes.

**Consequence:** if failed, keep relational topology as derived analysis/index rather than causal state.

## K4 — Corrective recurrence

Create an earlier interpretation/expectation and a later event with controlled resemblance plus a critical difference (e.g. failure followed by apology/repair).

**Pass:** later history can lawfully narrow, differentiate, reinforce or revise organization according to admitted outcome; no mandatory healing or trigger script.

**Fail:** recurrence only increments a wound scalar, always generalizes, or rewrites the original event.

## K5 — Recognition conflict / private-social reality

**Pass:** the machine differentiates destabilization, public/private split, internalization, resistant self-trust and unresolved conflict without equating defiance with truth.

## K6 — Internalization → external discipline

Generate an actor who has internalized a norm through admitted history. Provide an opportunity to judge/sanction another.

- same norm exposure without internalization;
- internalization without sanction capacity;
- sanction capacity without norm history.

**Pass:** outward policing requires both generated organization and opportunity/power; category membership alone does not generate behavior.

**Fail:** demographic/category label directly produces punitive action.
