# D11 — Concrete successor V3/PFF / Sorok program

**Status:** SHADOW RECOMMENDATION. No implementation is authorized by this document.

The successor should start from the smallest architecture that preserves Rawlsing's constitutive personhood and lets richer psychology earn itself experimentally.

## S0 — Freeze the constitutional kernel, not the full ontology

Freeze:
- event identity and immutable history;
- sparse actor initialization;
- owner-specific durable state;
- objective/perceived relationship noncollapse;
- memory/access/trace/interpretation noncollapse;
- private causal state vs actor access vs outward occurrence vs user phenomenology;
- structure→person mediation, no demographic psyche shortcut;
- one person across epochal and live time;
- renderer/proposal cannot self-canonicalize.

Do **not** freeze a large new desire/love/recognition/power object family.

## S1 — Minimal event/relation transition kernel

Implement a laboratory successor with:
- actor/version;
- event ledger;
- relation instances;
- existing expectation/striving/mediator/tension/practice owners where lawfully reused;
- CAN-008 compatible event coupling;
- typed target effects;
- actor-access projection;
- exact provenance and replay.

Use synthetic StructuralWorldPort receipts clearly marked laboratory-only.

Then run K1 and integrity parts of K3/K6.

## S2 — Transition-science microcourt

Choose a **small concrete rule family** rather than a complete psychology:
- recognition/criticism event;
- expectation/striving conflict;
- relationship-specific receivability;
- one memory/causal-trace consequence.

For every rule specify:
- source/destination owners;
- event class;
- eligibility;
- no-change outcomes;
- contradiction handling;
- actor-access ceiling;
- stochastic or deterministic semantics;
- scientific status.

Compare:
A. event/relation-first baseline;
B. baseline + explicit conative event-local configuration;
C. baseline + richer relation topology.

Run K1/K3/K4/K5 with equal model/retrieval budgets.

**Promotion rule:** richer state becomes durable only if it adds repeatable held-out value not explained by existing owner state/history.

Build two schedulers over the same transition substrate:

No elapsed-time psyche mutation without a rule/event.

A live admitted user event enters the same history consumed by later epochal development.

Run K8.

PFF owns bounded present interaction residue/specialization; it does not become a second biography or duplicate CAN-008.

## S7 — Attractor / Enneagram research lane

First implement derived trajectory summaries from exact graph/history.

Then compare:
A. history/graph only;
B. history/graph + derived cached attractor;
C. history/graph + genuinely causal slow latent state.

Only C requires new transition authority and must beat A under held-out tests.

Enneagram remains:
- downstream interpretive shadow;
- versioned/uncertain;
- competing/no-conclusion allowed;
- never causal type assignment.

If no incremental value, omit it from runtime.

## Sorok success criterion before weld

A source-free successor laboratory should demonstrate:
- one generated focal person;
- generated caregivers/coparent relation;
- event-parented development;
- lawful inaccessible residue;
- relationship-specific response;
- correction/reinterpretation;
- live event reentry into later development;
- actor opacity;
- exact replay/provenance;
- bounded computational cost.

This is still **not** PRE-V3 integration or whole-product proof.

## Sorok stop conditions

Stop/reduce a mechanism if:
- its effect is only renderer wording;
- it duplicates an existing owner;
- it requires an LLM to invent causal truth;
- its label, rather than its antecedent state, changes behavior;
- actor access leaks from objective history;
- it cannot survive K1–K6 controls;
- its social recursion cost is unbounded;
- it only works with a manually scripted final Nadia.
