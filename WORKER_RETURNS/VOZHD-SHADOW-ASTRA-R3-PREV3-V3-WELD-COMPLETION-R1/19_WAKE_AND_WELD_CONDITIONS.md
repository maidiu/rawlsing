# D18 — Wake, authority grants and physical weld conditions

**Status:** SHADOW RECOMMENDATION. This document cannot grant any of the authorities it describes.

The project must not collapse distinct permissions into one "green light."

## 1. Distinct grants

### G-SOURCE — original source / operation grant
Authorizes exact source use and operation at declared scope.

Does not authorize:
- actor generation;
- model use;
- V3 wake;
- physical weld.

### G-MODEL — model-use grant
Authorizes specified model/provider/prompt class for a declared experiment or runtime.

Does not make model output causal truth.

### G-LAB-ACTOR — synthetic/generated actor laboratory grant
Authorizes bounded source-free or lawfully sourced actor simulation for explicit experimental purposes.

Does not imply production/person release.

### G-N12-ACTOR — operative V3 wake
Competent N12 decision after current PRE-V3 acceptance requirements.

This is separate from local laboratory work.

### G-WELD — physical PRE-V3→V3 integration grant
Authorizes a specific versioned adapter between a declared terminal PRE-V3 service and declared successor V3 consumer.

N12 and weld may be coordinated but should remain conceptually explicit.

### G-RELEASE — product/human-alpha release
Requires operational, scientific, privacy/access and experience criteria beyond a technical weld.

No earlier grant implies it.

## 2. PRE-V3 prerequisites for physical weld candidate

Before a production-like weld is even proposed:

1. **Positive N9 terminal service**
   - actual selected world, not only refusal/checklist;
   - current/historical/as-of behavior;
   - exact identities/provenance;
   - n-ary role preservation where demanded;
   - typed missing/negative/held/proxy states;
   - demand-relative dereference closure.

2. **Positive N10E**
   - actual empirical possibilities;
   - exact respondent/unit/denominator/design/estimand;
   - uncertainty and use ceiling.

3. **N10W / parent-coparent ceiling**
   - ordered progressive conditioning or explicit bounded alternative;
   - parent pairing dependence labeled empirical/modelled/unknown;
   - no false dyad claims.

4. **Required F1–F8 functional obligations**
   at current acceptance grain, including temporal/consequence products actually used.

5. **N11 whole joined gate**
   remains distinct from one successful vertical.

6. **Current source/model/use permissions**
   valid at the terminal service cut.

## 3. Successor V3/PFF prerequisites

Before the physical weld is useful:

1. event/relation-first kernel exists at F2;
2. K1/K3 integrity demonstrate lawful historical differentiation and actor opacity;
3. K4/K5 show nontrivial recurrence/recognition behavior under controlled interventions;
4. K6 blocks direct category→behavior shortcuts;
5. K7 has a bounded important-other promotion/depth rule if parent/caregiver recursion is in the target vertical;
6. K8 demonstrates one durable person across live and epochal scheduling;
7. memory/access/trace/interpretation are separately represented;
8. occurrence/materialization candidate has an owner or an explicit HOLD;
9. replay/transaction/versioning works at lab grain;
10. cost/latency envelope is measured rather than assumed.

Richer conative topology/attractor state is **not** a prerequisite unless its own court shows it is constitutive.

## 5. Explicit N12 decision

N12 should answer at least:

- Which terminal PRE-V3 commit/service is being woken toward V3?
- Which successor V3 commit/schema is the consumer?
- Which model/use grants exist?
- Which actor class/lab/operative scope is authorized?
- Which K9/K10 receipts are accepted?
- Which unresolved items are tolerable vs blocking?
- Is the physical adapter authorized now, deferred or rejected?

A green N11 does not auto-answer these.

## 6. Physical weld procedure

If authorized:

1. freeze exact PRE-V3 provider commit;
2. freeze exact successor consumer commit;
3. freeze adapter schema/version and generated-binding semantics;
4. run source-free semantic K9/K10 regression;
5. run authorized positive real-source/current-world vertical;
6. verify no raw source interpretation occurs inside V3;
7. verify actor-generated facts are not written upstream as empirical truth;
8. verify exact provenance/permissions survive into causal receipts;
9. verify rollback/replay;
10. retain full changed-path / remote SHA / test-execution audit.

Adapter may:
- rename/encode;
- dereference;
- preserve identity;
- bind receipts;
- index;
- call provider owners.

Adapter may **not**:
- invent empirical probabilities;
- infer wounds/desires;
- synthesize missing relations;
- default unknown authority;
- widen permissions;
- erase negative states.

## 7. End-to-end acceptance after weld

A bounded successful vertical should show:

```text
governed source/world
→ positive PRE-V3 terminal service
→ pipeline-produced caregiver/focal-person possibility
→ generated developmental events
→ durable actor state + lawful memory/trace
→ present event recruitment
→ admitted outward occurrence
→ later historical reentry
```

with exact provenance and no hand-authored final persona.

One vertical demonstrates feasibility at that grain; it does not substitute for N11 whole-estate acceptance or A4 generalization.

## 8. Hard HOLD conditions

Physical weld remains HOLD if any are true:
- terminal world is still mostly negative/refusal;
- N10W silently multiplies marginals or invents dyads;
- downstream requires upstream actor psychology;
- V3 reinterprets raw survey/source semantics;
- generated binding ownership is ambiguous;
- unavailable memories leak into actor narration;
- successor person only works when manually scripted;
- K9/K10 expose information loss;
- occurrence/materialization has no admissible owner for claimed surface;
- no competent N12/weld authority exists.

## 9. After weld: product wake remains separate

Human alpha requires additional evidence:
- multiple independently generated persons;
- durable interaction continuity;
- absence/return and independent life;
- experiential quality;
- privacy/access constraints;
- operational failure recovery;
- model/cost envelope;
- no systematic assistant-default collapse.

The physical weld is a necessary integration milestone, not the product.
