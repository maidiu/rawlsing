A **sourcefree technical chain** exists from a two-actor material history through a test-key C8 occurrence, a TEST_ONLY E1/CAN008 RULE_A/separate CAN011 RULE_T target, a later performed E2, a C10 read, a SQLite C12 store, and a thin R31J or R31E A0–A3 product. ```text
GM01 B SHARE_TOOL / REFUSE_TOOL source
  -> PreC9Producer.stage_world sets historical life/occurrence
  -> stage_c8 commits C8 with gm01_pre_c9_source in the occurrence payload
  -> stage_out9 verifies the C8 receipt
  -> stage_c9 binds E1 from OUT9, evaluates TEST_ONLY CAN008 RULE_A
     and separate TEST_ONLY CAN011 RULE_T/target or NO_CHANGE

## 4. The actual expression chain (R31E)

```text
R30A/R29P C12 + M6 perceptions + world/material state
  -> compile_contract (actor-authorized fields; user attention excluded)
  -> propose (bounded strategies/templates)
  -> validate (re-render, facts, knowledge refs, private tokens, scene/clock/contact/capacity)
  -> admit (exact SPEECH/REPAIR/MESSAGE/SILENCE world/C12 occurrence + EXPRESSION_ADMISSION)
  -> user phenomenal compose (admitted events + U perceptions only)
```

Key positives:

- Same text “What are you working on?” yields `EXPLAIN_WORK`, `DEFER_WORK`, `RECALL_WORK`, or a different formulation depending on actual availability/prior help.
- “Can I have your number?” yields grant/defer/refuse depending on help/contact/turns and availability.
- Private cash, forced love, coercion, unsupported promise, unknown topic, unobserved B → boundary/refusal/defer/`UNKNOWN_B`; no private values in speech.
- Attention contrast: same event ids/hashes; surface changes only.
- 6/6 faults: committed utterance tamper, recomputed identity, attention-only surface, private boundary, unsupported memory, chronological rewrite.
- Cold reopen preserves exact text/admission.
