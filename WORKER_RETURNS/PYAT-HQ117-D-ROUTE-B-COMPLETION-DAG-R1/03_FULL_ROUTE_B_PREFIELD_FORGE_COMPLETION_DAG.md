## Dependency order

### Phase 0 — inherit current floors
Do not rebuild current decoder, Route-B facade, I03, I05, replay audit, lifecycle, adaptive-discovery successor, or positioned-subject successor.

### Phase 1 — BUILD_NOW_CORE
Implement HQ116-C's thin production compositor and deterministic exact-object export. Simultaneously preserve typed nonpositive states and explicit no-authority states.

### Phase 2 — source-free hostile court
Prove no semantic ownership leakage, no projection inference, deterministic replay manifests, exact frontier propagation, typed-negative preservation, and no accidental structural/Field-Forge promotion.

### Phase 3 — SOURCE_SPECIFIC_BINDER + POPULATION_WORK
Bind exact LiTS/WVS/current source semantics, then expand only under source-specific authority. Source family resemblance is not a binder.

### Phase 4 — REAL_SOURCE_PROOF_GATE
Run the minimal real-source proving pair, then additional population specimens needed by concrete product scope. Prove source→C11→I03/I05 equivalence/replay and failure paths.

### Phase 5 — BUILD_AFTER_CORE / authority activation
For operations requiring validation, comparability, composition, accepted learned relation, or higher-order discovery, constitute/bind the exact authority first, then implement/compose that node. Do not make universal wrappers merely to fill boxes.

### Phase 6 — learned release/currentness
Use the current lifecycle owner. Bind exact product determinants, release, supersession/invalidation/recompile/replay. Do not infer semantic permission from currentness.

### Phase 7 — Field Forge ingress
Select the lawful producer grain by claim family. Direct exact I03/I05 objects are lawful only where the current Field Forge producer owns the transformation and no missing validation/comparability authority is bypassed. Otherwise ingress begins from validated/accepted learned relation objects.

### Phase 8 — completion declaration
Only after every universally required row has owner+implementation+proof and every claim-conditional row has a fail-closed activation path may HQ call B pre-Field-Forge complete. Product-wide completeness additionally requires population/source-capable proof.

## Why this is not stage nostalgia

The DAG nodes are semantic responsibilities, not mandatory physical persistence stages. Several may be functions, receipts, authority-bound services or direct producer calls. Route B specifically forbids turning the conserved responsibilities back into a mandatory R5/V553–V558 fossil chain.
