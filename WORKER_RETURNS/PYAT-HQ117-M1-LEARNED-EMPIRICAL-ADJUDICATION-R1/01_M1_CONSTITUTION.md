# PYAT HQ117 — M1 LEARNED EMPIRICAL ADJUDICATION CONSTITUTION R1

## 1. Jurisdiction

M1 owns exactly:

`exact I05 discovery/evidence -> exact typed learned-empirical disposition`

It does not own:
- source decoding or source truth;
- I03/I05 discovery semantics;
- invention of validation thresholds/formulas;
- learned-product publication/release (M2);
- learned-product lifecycle/current-selection (M3);
- Field Forge structural relation formation;
- I04 structural admission;
- consumer-use permission;
- V553+ temporal meaning;
- actor/V3 state.

The jurisdiction is generic **only** in orchestration, closure, dispatch, state conservation and receipt production.

## 2. Exact M1 input object set

A lawful M1 call consumes one closed `M1AdjudicationInputBundle@1.0.0` consisting of:

### Required common inputs
1. one exact `DiscoveryResultReceipt@1.0.0` preimage;
2. its exact `DiscoveryAuthority@1.0.0` preimage;
3. every referenced `EmpiricalFact@1.0.0` needed by the selected family rule;
4. every referenced `EmpiricalQuerySpec@1.0.0` and `EmpiricalPredicate@1.0.0` needed to recover constitutive claim meaning;
5. exact evaluated-frontier / coverage identity and the discovery replay root;
6. exact source-universe, risk-set, topology and measure identities already carried by the governed empirical objects;
7. exact authority snapshots and dependency closure needed to verify those objects;
8. one explicit `M1FamilyRuleBinding@1.0.0`.

### Conditional inputs
Only when the selected family rule declares them premises:
- validation fact refs distinct from support fact refs;
- uncertainty method/result refs;
- weight/design/estimand authorities;
- source-relation/comparability authorities;
- composition/pooling/backfill authorities;
- time/geography applicability authorities;
- negative/denial/noncomparability authority refs;
- operation-scoped prerequisite-universe completeness receipt;
- other exact family-specific semantic authorities.

### Forbidden substitutes
M1 may not substitute:
- raw survey bytes;
- labels, prose names or observed frequency patterns for semantic identity;
- a diagnostic score for an empirical fact;
- a historical/candidate rule for a current/adopted rule;
- a discovery `rule_id` string for learned-validation authority;
- support/provenance abundance for validation authority.

## 3. Exact output object

The M1 output is `LearnedEmpiricalDisposition@1.0.0`.

It is a typed adjudication result whose identity is intentionally distinct from:
- the underlying relation proposition;
- any truth-bearing semantic claim;
- the governing authority instance;
- later release identity;
- later current-selection identity;
- later structural admission.

Because it is an adjudication receipt, changing the validator authority or binding may lawfully change the disposition object identity even when P1 says the underlying semantic claim is the same.

## 4. Two-axis disposition law

M1 must not force evidence states and adjudication outcomes into one scalar.

### Axis A — adjudication outcome
Finite outcome family:
- `RULE_SATISFIED`
- `RULE_NOT_SATISFIED`
- `ABSTAINED`
- `BLOCKED`
- `UNRESOLVED`
- `INTEGRITY_FAILURE`

### Axis B — conserved evidence/authority state
The exact upstream states remain separately carried, including:
- `SUPPORTED`
- `OBSERVED_ZERO`
- `ZERO_SUPPORT`
- `VALID_EMPTY`
- `LOW_SUPPORT` / insufficient support
- `NONCOMPARABLE`
- `COVERAGE_LIMITED`
- authority denied/missing/conflicting/out-of-scope
- `UNKNOWN` / `UNRESOLVED`
- `INTEGRITY_FAILURE`

A family rule can return `RULE_SATISFIED` on an `OBSERVED_ZERO` witness if and only if that exact zero is substantively satisfying under that bound rule. M1 itself never assigns that meaning.

## 5. Truth-bearing claim law

P1 governs claim identity. Therefore:

- `RULE_SATISFIED` does not by itself define semantic polarity.
- The bound family validator must state whether it emits a truth-bearing semantic claim and, if so, its exact `RELATION_PROPOSITION_IDENTITY`, assertion polarity/state, and family-specific constitutive payload.
- `RULE_NOT_SATISFIED` is an adjudication result, not automatically an exact negative claim.
- `BLOCKED`, `UNRESOLVED`, `VALID_EMPTY`, `NONCOMPARABLE`, and `INTEGRITY_FAILURE` are never silently converted into negative truth.

## 6. Universal M1 hard gates

These are jurisdiction/integrity gates, not universal substantive validation criteria.

A positive `RULE_SATISFIED` result is forbidden when:
- no exact family rule binding exists;
- the rule binding is ambiguous;
- the rule authority is missing, denied, conflicting or scope-mismatched;
- object/ref/replay integrity fails;
- the selected validator does not match the declared claim family/rule;
- a validator-required prerequisite channel is unavailable or blocked;
- a validator-required comparability/composition/measurement premise is absent;
- the validator attempts inference above its declared semantic ceiling.

Coverage-limited evidence may still be adjudicated for a bounded claim whose rule explicitly permits that scope; it may not authorize a stronger completeness/global-absence claim.

## 7. Generic API theorem

One generic API is lawful if it acts as a typed dispatcher:

`adjudicate(bundle, exact_rule_binding) -> LearnedEmpiricalDisposition`

The generic layer may:
- verify exact identity/authority/replay closure;
- verify rule-family/scope applicability;
- dispatch to the exact named validator;
- preserve negative/evidence states;
- bind determinants and explanation;
- produce deterministic disposition identity.

The generic layer may not:
- select substantive rules by heuristic/default;
- define universal support thresholds;
- interpret numerical patterns into relation meaning;
- manufacture comparability;
- manufacture measurement portability;
- manufacture composition;
- convert provenance into truth;
- mint structural admission or product release.

Thus semantic rules remain distributed while the adjudication jurisdiction is common.

## 8. Semantic ceiling

Every M1 disposition carries an explicit ceiling. Default M1 ceiling:

`LEARNED_EMPIRICAL_DISPOSITION_ONLY__NO_PRODUCT_RELEASE__NO_CURRENTNESS__NO_STRUCTURAL_ADMISSION__NO_CAUSAL_PROMOTION__NO_POPULATION_GENERALIZATION_BEYOND_BOUND_SCOPE__NO_PERSON_OR_V3_STATE`

A narrower family ceiling overrides only by narrowing. Widening requires separately competent authority.

## 9. Replay and explanation

Replay must re-resolve the exact:
- input object refs/preimages;
- discovery authority/frontier/coverage;
- validator authority and rule binding;
- family-specific prerequisite authorities;
- deterministic validator identity/parameters;
- output determinant set.

Explanation is determinant-complete, not narrative:
- what proposition was adjudicated;
- which exact rule governed;
- which exact evidence and scope were used;
- which uncertainty/coverage/negative states were present;
- why the rule returned its result;
- what semantic ceiling remains.

A replay mismatch yields `INTEGRITY_FAILURE`, never fallback adjudication.

## 10. Boundary with M2, M3 and Field Forge

M1 produces a disposition that M2 may later publish if M2 law permits.

M1 does not:
- make the disposition a release;
- make any release current;
- select latest/current;
- admit structure;
- create Field Forge relations;
- authorize a downstream use.

Freeze:

`M1_DISPOSITION_IDENTITY != M2_RELEASE_IDENTITY != M3_CURRENT_SELECTION_IDENTITY != I04_STRUCTURAL_ADMISSION_IDENTITY`

## 11. Success holding

The generic jurisdiction is lawfully constitutable without semantic overreach because existing law already separates:
- P1 typed claim identity from authority/disposition identity;
- P2 explicit currentness from chronology;
- I05 discovery evidence from downstream truth;
- C07 architecture from missing rule authority;
- FF02/Field Forge empirical evidence from structural promotion.

Therefore M1 passes constitutionally at documentary grain.
