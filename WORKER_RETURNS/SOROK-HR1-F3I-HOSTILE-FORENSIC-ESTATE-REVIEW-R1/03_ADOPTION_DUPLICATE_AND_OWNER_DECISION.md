## 1. Distinguish four claims rather than pretending they are interchangeable

**PATH_PRESENT**: exact string path exists at one commit. A code file at a nested \`WORKER_RETURNS/\` copy is not necessarily the actual runtime import.

**BLOB_IDENTICAL**: the exact Git blob SHA at an exact source path matches another commit. This supports physical source/content equivalence for that file only, not runtime dependency closure, rule authority, test target version or person product.

**COMMIT_ANCESTOR**: Git compare proves one commit was included in another history. If source changed afterward, original tests for the ancestor do not review descendant bytes. Conversely F07 content was reintroduced via another path even though branch does not ancestor PRE-MAIN.

**SOURCE_AND_FIRST_CONSUMER_ACCEPTED**: requires actual import/call, exact source+runner+writer/reader compatibility, negative severance on *that* later consumer and independent authority. None of the above three properties individually establishes this fourth one. **NATIVE_SCIENCE/ADOPTION** requires still additional original owner grants and human/actor evidence.
