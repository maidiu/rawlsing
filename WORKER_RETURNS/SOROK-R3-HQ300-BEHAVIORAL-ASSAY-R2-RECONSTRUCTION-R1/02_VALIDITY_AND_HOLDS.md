The primary estimand is the effect of three implemented information-processing representations on lawful joint typed responses within a fixed synthetic corpus. A forms owner state by admitted-history scan. B derives an event-local, non-ranking descriptive compilation from the same facts. C retrieves a rebuild-checked cache with an index of actual accessible parent slots; inaccessible origins are marked without content. Every arm has the same underlying lawful facts. The treatments are meaningful code/input interventions, but neither B nor C is a new durable psychology owner. Cache verification scans are counted, so this implementation does not claim a net cache efficiency gain. Changing admitted history, capacity or ratification changes factual owner outputs in sourcefree intervention tests.

Forced-choice success would still be evidence about the pinned model's responses to supplied options and typed owner facts. It would not by itself establish human developmental causality, psychological necessity of state, internal model beliefs or stable personhood. The corpus fixes formative events, state vocabulary and lawful sets by hand. Generalization, long histories, arbitrary language, real sources and real actors are excluded. The auxiliary free-text channel implements a deliberately small fixture rubric; arbitrary prose becomes unscorable, requiring a separately commissioned blind coding process.

These are objective fixture state and **reported** belief measures, not an assay of inaccessible model-internal beliefs. The schedule crosses every offered menu rotation with all six execution permutations, then shuffles whole matched blocks with fixed seed 942011 independent of arm/outcome. Six constructed settings contain 126 factorial cells; the implementation-visible development/heldout-template split has no independent test-set custody. More independent scenario authorship and a prospective sampling plan are needed for broader claims.

Analysis checks exact pairs and aggregates nuisance repetitions to family means, per K, with 12-comparison multiplicity handling. The conditional bounded-mean interval uses `sqrt(2*log(2*m/alpha)/n)` for differences in [-1,1]. At n=6 it is broad; the precision calculation requires thousands of independently sampled clusters for ±5pp. This is a conservative precision calculation, not achieved power or an equivalence result. It assumes independently sampled bounded units, which this convenience corpus does not establish. No software output can promote this corpus to population evidence. The independence requirement follows the original bounded-variable inequalities. [Hoeffding 1963](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830).
