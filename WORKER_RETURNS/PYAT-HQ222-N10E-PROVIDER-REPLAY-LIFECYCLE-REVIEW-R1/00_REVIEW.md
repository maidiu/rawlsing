## 6. Decisive defect — the graph does not carry the full consumed determinant set

The candidate's own registration records:

- authority determinant: model authority;
- exact determinants: empirical query, predicate, consumer query, conditioner-binding witness.

But `AnalyticalDependencyRegistry.build_graph()` does this:

- creates `authority_edges` only from `determinant_authority_refs`;
- creates `dependency_edges` only from `dependency_edges_from`;
- does **nothing** with `determinant_exact_refs`.

HQ221's `_register()` leaves `dependency_edges_from` empty.

Therefore the graph used by AT19 has exactly one relevant direct root:

`model authority v1 -> N10E provider product`.

The exact query/predicate/consumer/witness refs are retained in registration metadata but are not lifecycle graph edges. Release refs are not registered in `AnalyticalProductRegistration` at all.

The court itself demonstrates the gap:

- `test_h04` proves that changing a query or conditioner determinant reidentifies the provider product;
- but it never drives that changed exact determinant through `SemanticDeterminantGraph.affected` or an accepted lifecycle transition;
- `test_10` drives only a model-authority promotion;
- `test_h07` removes only that model-authority edge and uses the court-side closure checker to catch the omission.

So the claim in `03_DEPENDENCY_LIFECYCLE_REPLAY_COURT.json` that `graph_edges_are_consumed_determinants_only = true` is true only in the weak "no foreign determinant edge" sense. It is not proof that **all consumed determinant classes capable of changing the product are represented in lifecycle reachability**.

This leaves the residual only partially closed. HQ needs either:

1. an exact authority statement that AT19/lifecycle invalidation at this stage is intentionally **authority-revision-only**, with query/predicate/witness/release changes governed by a different named currentness owner; or
2. a bounded repair/extension that connects every lifecycle-relevant consumed determinant to the accepted invalidation graph without inventing a second owner.

Until one of those is established, the candidate cannot claim full determinant-custody lifecycle restoration.
