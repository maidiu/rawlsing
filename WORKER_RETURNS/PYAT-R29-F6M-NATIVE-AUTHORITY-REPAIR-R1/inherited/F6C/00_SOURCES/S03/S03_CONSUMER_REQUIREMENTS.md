# S03_CONSUMER_REQUIREMENTS@1

This adapter-neutral interface supplies descriptive source-indexed tables and an optional inferred categorical joint. It does not publish, resolve or select a world.

1. Bind Worker 1's exact S00 scope identity and target share provenance. Population/unit, boundary version, historical applicability, asked/eligible risk set and exclusions must agree. The module is conservative about geography/date: no automatic cross-country or inter-year extension. A new scope law belongs to the competent producer.
2. Obtain admitted source-native exhaustive joint summary products from current empirical owners. For every stratum provide raw counts, weighted mass when authorized, eligible/excluded counts, support/risk/coadministration refs and intact native category vector/order. Keep nonresponse/not-asked/eligibility semantics upstream and accessible. Never complete a suppressed or unvisited joint table from marginals.
3. Provide reviewed item/construct/category, response meaning, instrument, scale and polarity metadata and their exact review preimages. Atlas candidates alone do not qualify. Preserve source-local meanings in the baseline. Pairwise source overlap reviews must establish disjointness; overlapping products require an upstream adjudicated deduplication/design product, which this module does not create.
4. Supply one explicit policy with target support, invariance assumptions, positive contribution weights, minimum source-stratum support and sensitivity radii. No precision-weighted pooling is implied. Target shares must sum to one and numeric identity uses rational strings/integers. The fixture is an executable input schema example; its `synthetic-*` refs are never real authority.
5. For real input, pass an external `admit(source, target, operation)` callback. `SOURCE_INDEXED_BASELINE` and `TARGET_JOINT_STANDARDIZATION` are separate operation checks. The callback must independently verify the exact source body/release, provenance, use rights, scope, mapping, support, design/weights, current/as-of mode and lifecycle through their existing owners. Returning true from a test stub demonstrates no permission, scientific acceptance or production authentication. The `test_origin` flag is evidence labeling, not a protected trust boundary; caller-controlled flags cannot authorize real use.
6. Consume `baseline`, `candidate`, `evidence_graph`, `refusals`, `overlap_diagnostics` and `replay` together. Baseline counts are measured source facts; recoded tables are transformed; the target joint and its conditionals are inferred. An absent candidate or incomplete target support must propagate as unavailable/source-indexed backoff. Preserve rare cells and outstanding joint/frontier obligations. Conditional mass is not an observed numerator/denominator or a new person.
7. Worker 1's existing adapter must wrap lawful values in its own selection/world/possibility envelope and retain source parents, policy/method refs, uncertainty, support and actual value-read receipts. `conditional` demonstrates a cumulative predicate against one modeled joint and checks the content hash; it is not the accepted service or a currentness/permission validator. Report actual empirical condition support via the native owner in parallel when available. Unknown conditional uncertainty stays explicit.
8. Require separate source/semantic/design review and service integration review before any real candidate is preferred. Freeze held-out target/partition, subgroup/rare-pattern criteria and expected effects independently where required. Retain the unpooled baseline even when a modeled candidate is accepted. No V3 or actor-state consumer belongs in this integration.

Bundle identity includes exact input preimages and policy; input source order is canonicalized. No stochastic seed is needed. Code/environment identities live in the worker's evidence/resource manifests and must be added to the integrating owner's replay determinants. Content integrity does not prove external custody, revocation, currentness or authority.
