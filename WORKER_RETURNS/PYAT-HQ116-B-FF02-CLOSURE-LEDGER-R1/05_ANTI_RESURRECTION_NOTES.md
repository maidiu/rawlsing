# FF02 anti-resurrection notes

These notes are binding recommendations for HQD-116 adoption. They exist to prevent shorthand closure language from reviving states A–E explicitly did not create.

## 1. "FF02 closed" must be grain-qualified

Allowed:

> `FF02_SEMANTIC_COURT_CLOSED_AT_EXACT_GRAIN`

Forbidden shorthand inference:

> `FF02_CLOSED -> RELATIONS_INSTANTIATED`

Freeze:

`SEMANTIC_COURT_CLOSED != MATERIALIZATION_COMPLETE`

## 2. 49 positive does not mean 49 structural objects

Current fact:

`49_POSITIVE_RELATION_FAMILY_DISPOSITIONS`

Not current facts:

- 49 relation object refs;
- 49 relation current-selection receipts;
- 49 PRE-V3 admissions.

Freeze:

`49_ELIGIBLE != 49_INSTANTIATED != 49_CURRENT_SELECTED != 49_PREV3_ADMITTED`

## 3. P3 remains genuinely nonpositive

Current documentary finding:

`VALID_EMPTY__NO_POSITIVE_RELATION`

Do not convert it into:
- a zero-valued positive relation;
- `OBSERVED_ZERO`;
- zero effect;
- negative causation;
- missing data;
- PRE-V3 admission.

## 4. P4 remains 25 independent joints

Do not resurrect:
- a branch set;
- alternative set;
- minority ontology;
- complete possibility set;
- topology/geometry;
- one 25-member relation object.

Freeze:

`25_P4_RELATIONS != ONE_SET_LEVEL_RELATION`

unless a later separate set-level authority is adopted.

## 5. Never genericize STRUCTURAL_MEDIATION_INPUT

Freeze exact wording:

`STRUCTURAL_MEDIATION_INPUT = CLAIM_SPECIFIC_MEDIATION_PERMISSION__NOT_GENERIC_FIELD_FORGE_RELATION_PERMISSION`

It must never be used as:
- a neutral Field Forge target-use token;
- a compatibility placeholder;
- a required token merely because current M1 code expects it;
- a default permission for support/dependence/conditioned-difference/joint relations.

Mediation requires separately competent authority.

## 6. Relation current-selection and PRE-V3 admission remain separate

Freeze:

`FIELD_FORGE_RELATION_TRUTH != RELATION_CURRENT_SELECTION != PREV3_TARGET_USE_ADMISSION`

A current-selected relation may lawfully have:

`PREV3_TARGET_USE_ADMISSION = NONE_CURRENTLY_GRANTED`

No downstream use is implied.

## 7. D2 is not failed semantics

Do not rewrite D as:
- failed empirical closure;
- invalid checkpoint;
- failed relation adjudication;
- missing source evidence.

`EXACT_CHECKPOINT_CUSTODY_LOCATION_FAILURE`

`D2_BLOCKS_EXACT_LITS_RELATION_MATERIALIZATION__NOT_ROUTE_B_PIPELINE_CONSTRUCTION`

`pre553_structural_admission.py` remains current compatibility code in its own jurisdiction.
