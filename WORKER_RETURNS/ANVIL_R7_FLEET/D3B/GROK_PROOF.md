## 5. Why can matching survey marginals conceal different true three-way respondent patterns? Show distinct F2 denominators and typed missing/routing problems.

Matching univariate (and even pairwise) marginals do not determine the three-way joint. **Explicit valid two-distribution witness** (binary A,B,C; all entries nonnegative and each distribution sums to 1; computed values in `EVIDENCE/PROBE5_WITNESS.json`):

|---|---:|---:|
| 000 | 0.25 | 0 |
| 011 | 0.25 | 0 |
| 101 | 0.25 | 0 |
| 110 | 0.25 | 0 |
| 001 | 0 | 0.25 |
| 010 | 0 | 0.25 |
| 100 | 0 | 0.25 |
| 111 | 0 | 0.25 |

Both distributions have `P(A=1)=P(B=1)=P(C=1)=0.5` and every pairwise joint `P(A,B)=P(A,C)=P(B,C)=0.25` for all four cells. Yet `P(A=1,B=1,C=1)` is `0` in D1 and `0.25` in D2, and the full triple supports are disjoint. A marginal-only F4/FF consumer must return the same answer for both and is therefore invalid.

**Forward/reverse denominators:** in the same witness, let D=1 for patterns 000/011 and D=0 for 101/110 (8 equal respondents, two per pattern). Then `P(Y=000 | D=1) = 2/4 = 0.5` (denominator = four respondents with D=1), while `P(D=1 | Y=000) = 2/2 = 1.0` (denominator = two respondents with Y=000). The denominators and estimands are different; neither may be substituted for the other. The full computed table is `EVIDENCE/PROBE5_WITNESS.json`.

**Distinct F2 denominators:** `P(Y=y | D=d, U, W)` uses the eligible/asked/observed respondents in position `d` as its denominator; reverse `P(D=d | Y=y, U, W)` uses the respondents with that response pattern as its denominator. Weights/design and missingness alter both non-equivalently. A third denominator is the full target population `U`; a fourth is the source's released respondent set. They are not interchangeable.

**Typed missing/routing:** `NOT_ASKED`, `NOT_RELEASED`, `NOT_ELIGIBLE`, `ASKED_REFUSED`, `DONT_KNOW`, `HOUSEHOLD_MEASURE`, `MODELED_PROXY`, `INCOMPARABLE_WAVE` are different states; a routed skip is not a zero and a design stratum is not an individual answer.
