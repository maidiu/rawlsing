## What structural checks cannot possibly verify

A worker can type a plausible SHA, mark a fabricated synthetic receipt `independent_checked=true`, or write fluent nonsense about scientific source meaning. The included fixtures deliberately use synthetic receipts to exercise structure. Their validation **does not** authenticate external measurements, original survey rights, source-native scale, independent scientific comparison, actual local writer leases, current code parity or a real accepted C/H1 decision. The actual campaign must freeze source and experiment first, run lawful matched A/B evidence, and let nonauthor C inspect original raw material.

The `DESIGN_READY_SCOPED` string in a synthetic SPINE is only an **author proposal** under structural tests. It is not an accepted winner or an excuse to bypass C. If the real right, actual competitor, good source, full width, first effect, unmeasured potentially decisive cell, independent cold builder or competent owner is absent, return a conditional/exact scope hold rather than claim victory.

## Why no more administrative campaign rounds are justified by default

The R6 deliverable is a finite launchable **research and decision procedure**, not the research results. Once the prompts are accepted by the actual user/owner, its next useful step is to make A/B encounter the current code and real demanding workloads and make a choice or identify the single missing discriminator. A sixth review-of-a-review with no newly reproduced defect is not actual product progress. Only material bounded defects in these R6 controls should be repaired, never a new blanket historical or theoretical census.
