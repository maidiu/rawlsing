`contracts/policy.json` freezes **W-S** sparse, **W-D** dense, **W-R** routed/rostered/multiselect, **W-O** repeated independent distinct operations, **W-J** ≥3 joint/recursive minority and conditional, **W-U** world/field repeated first-consumer demands, **W-X** cold/rights/recovery; with a compact non-Cartesian representative metric matrix rather than all 7×9. The named selected scope determines what is justified. In a claim of architecture-wide superiority, ALL mandatory representative dimensions must be assessed, or an explicit independently accepted scoped limitation is carried in the verdict; one build-time metric repeated seven times is not a complete comparison.

The plan must record actual respondent count, question opportunities (≥600 when claimed), mean/p95 actual events per respondent, actual eligible/routed/answered/repeated distribution, row/option width, codebook/science/source/country/wave identity, sourcefree-vs-native grade, concurrent/dissimilar query count, reuse/invalidations, output materialization and source reads. The 100k historical sparse 3.245-events/person proof must **never** be extrapolated as a dense real survey benchmark. The 6GiB rule concerns total process tree, not a single child.

Physical metrics include build wall, first cold-open, query 1/10/100 and true full-result output wall, peak process-tree RSS, retained/scratch size, and repeated across-world/first-consumer reuse where selected. Scientific and negative semantics are non-numeric hard vetoes with positive/denied/restore witnesses. Matched A/B values must use same admitted source/fixture/rights/grant and comparable runner; A-only `MEASURED` vs B `UNRUN_HELD` is a hold, not a win. Cached warm query without source/currentness recheck is not authenticated cold query.

**Exclusion** is not a convenience. The comparator intentionally cannot report broad complete-scope winner when exclusions remain. A valid exclusion may justify a narrower scoped result if the owner actually accepts the limited claim. `NONDECISIVE` is not a worker Boolean that beats an unrun competitor; unknown materiality remains conditional until evidence/review.

## Evidence and comparator

For each frozen cell, provide an actual A/B numeric interval (prefer repeated runs and dispersion) or exact model/unrun hold; attach matched source/runner and immutable raw receipt. A self-authored `independent_checked=true` field does not authenticate a GitHub SHA; C physically rereads run receipt, runner conditions, source rights and bounded semantic outputs. `r6.py compare PLAN.json MEASUREMENTS.json` enforces declared matrix, evidence identity, matched inputs/runner and interval comparison. It returns only **scope-bound advantage/tradeoff/uncertainty**, NEVER grants source/science or independently certifies an architecture. The spine must bind every chosen PHYSICAL decision to actual frozen material comparator cells and known dependencies, or mark it HOLD.

A credible A/B tradeoff must explicitly consider engineering migration, accepted-code reuse, source/rights proof cost, cold indexing, recomputation, full-result lower bound, output member list materialization, time/branch and multi-world cache invalidation. Least-disruption tie-break applies only when the rival is genuinely measured/economically adequate at the controlling scope and there is NO possibly important open rival advantage; otherwise report an exact unresolved tradeoff or obtain the principal's legitimate priority ruling. No invented arbitrary numeric utility weights.

## Bounded proof and early stop

A source-static proof is enough to rule out a semantically impossible design or prove information preservation *where actual code validates it*. Physical superiority requires matched physical receipts. Inspect current executable code first. A disposable single-mechanism sourcefree probe may be prepared only under lawful already verified execution authority and strict isolated scope, to resolve an actual winner-reverser; no full rival implementation fleet, no unqualified host/source use, no new production subsystem by default.

If a real hard veto or complete matched comparison decisively eliminates the rival, **stop probing and finish the handoff**. If unmeasured differences might reverse a decision, do not call it a win; give the smallest next discriminator and how both alternatives would respond. R6's job is to select what the actual builders should do, not to become those builders.
