# ANVIL R4 — Terminality, evidence grade, and non-self-referential chronology

## Correct order (not additional review bureaucracy)

1. **H0** freezes exact currentness, existing authority, R4 policy and workload hashes, source accessibility, writer noncollision and actual model/runtime capabilities. It does not appoint HQ or grant a worker.
2. **A0 / B0**, blind and parallel: A constructs the best incumbent adaptation and exact decision reversers; B independently derives downstream requirements, prosecutes one underlying framing assumption, and engineers the strongest feasible competing arrangement. Freeze each from external Git readback, never write a commit SHA into the payload it identifies.
3. **A1 / B1** one reciprocal challenge; preserve genuine disagreement and smallest tests.
4. **P1.5** runs the *smallest discriminating proof*: existing code/source instrument first; if genuinely decisive and no suitable existing implementation, a separately authorized disposable proof-of-mechanism (no new canonical code/public API) may be commissioned from the SAME qualified workstream and pinned to one hypothesis. If no rights/runner or if bounded POC cannot settle the choice: exact conditional/blocked outcome, not a new general campaign.
5. **A P2** freezes one author `SPINE.json`, global graph and deterministic outputs. Its `builder_cold_start.cold_start_result` must be `PENDING_INDEPENDENT_C`. `DESIGN_READY_SCOPED` in P2 is an *author proposal* only, NEVER a completed independent review or builder certificate.
6. **Independent C**, AFTER immutable P2, prosecutes A/B comparison, source semantics, output composition, meaningful S2 receipts where warranted, and actual **cold** builder work on the highest-risk current ready card and a selected difficult future edge. C emits an external receipt separately. Its builder status is graded `SPECIFICATION_CONSTRUCTION_READY`, `EXECUTED_FIRST_READER_PROOF` or `EXACT_BUILDER_HOLD`; the first requires inspectable source/ABI/positive-denied-restored test path, while only the second means an actually executed first-reader proof at the stated grade. A conditional owner-held handoff is NOT builder-ready.
7. **H1** alone combines the immutable P2 proposal, independent C verdict and actual authority into `H1_RECEIVED_SCOPED`, `H1_RECEIVED_CONDITIONAL` or `HQ_CURRENTNESS_HOLD`. Ready at **FF_FIRST_EFFECT_DESIGN** requires actual FF first-effect evidence; `C11_QUERY_DESIGN` cannot be described as FF-ready. H1 may update canonical PROGRAMMA/current progress only with proper writer lease and authority, otherwise exact proposed update + currentness hold.

## Binary terminal Y/N definitions

- `COMMISSION_COMPLETE_YN`: all correctly scoped investigations, frozen source records, adversarial claims, comparisons and exact holds returned. `YES` may coexist with `ARCHITECTURE_DECIDABLE_YN=NO`.
- `ARCHITECTURE_DECIDABLE_YN`: a specific **selected operational boundary**, lawful evidence-veto, comparison alternatives, unresolved discriminators, correct workload and end-to-end qualified graph support a winner at *that grade*. No owner-side science is inferred.
- `ENGINEERING_ACCEPTED_YN`: independently executed and received actual first-consumer integration, NOT an author design selection or partial fixture.
- `SCIENTIFIC_GRANTED_YN`, `SOURCE_RIGHTS_GRANTED_YN`, `ACTOR_GRANTED_YN`, `PROTECTED_RECEIVED_YN`: separate competent authorities only.
- `DOWNSTREAM_BUILD_READY_YN`: independent C cold-read demonstrated at the named **exact** builder card; conditional held cards are `NO` for their own interfaces, even if the whole documentary campaign is complete.

## Outcomes

- `DESIGN_READY_SCOPED` + C `C_ACCEPT_SCOPED` + H1 `H1_RECEIVED_SCOPED` can authorize the *architecture decision at exact claimed scope* only; no automatic implementation, scientific issuer, native source or protected code merge.
- `CONDITIONAL_CANDIDATE` + C `C_ACCEPT_DOCUMENTARY_HOLD` + H1 `H1_RECEIVED_CONDITIONAL` is a successful **finite investigation** with open explicitly named discriminators; not selected physical architecture.
- `DECISION_BLOCKED_EXACT` returns both possible outcomes, the one smallest future evidence and owner, and independently lawful ongoing work.
- `INCUMBENT_REJECTED_SCOPED` records measured veto, eligible alternative and owner-bound remediation without presuming every future topology.

**The independent review is not an additional author-owned field.** A submitted author artifact never includes a future C review result. C's verdict cannot be manufactured by an author writing `independent_review=ACCEPTED`; exact external reviewer identity/head/readback is the H1 receiving input. A changed selected graph triggers *transitive* affected-subgraph re-review; if broad, exact STOP/owner scope, not a cosmetic delta pass.
