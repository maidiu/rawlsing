No new fleets, no 118-item reaccreditation, no source-use assumption, no unilateral HQ accession. The workflow is **H0 → independent blind A0/B0 → reciprocal A1/B1 → one bounded P1.5 evidentiary contest → author P2 → genuinely nonauthor C → competent owner H1**. C is not another controller. H1 is not a ChatGPT author receipt. One bounded same-author repair is available for an exact defect; a design-changing repair must revalidate its affected dependency closure. Current C11 sourcefree engineering may proceed in parallel where its worker lease/permissions allow.

Read live canonical PYAT/shared PROGRAMMA first-contact HQ OATH **if acting as HQ**, paired MD+JSON progress, #909/#960/#1097, #997/#1006/#998/#1009/#1011, existing protected K3 29/26/14, source rights, active writer leases and current code/host capabilities. Obtain owner pre-result priority preferences if tradeoffs could genuinely arise; do not invent monetary weights or pick priorities after results.

### A0 and B0: genuinely independent designs

**A**: from actual current code and historically accepted functions, design the strongest least-disruptive incumbent adaptation; inspect code provenance, source/permission, disk and in-memory costs, semantic operators and exact first consumer. Compare reuse/adapt/compose/repair/new/do nothing by the adopted historical five-part law; a missing legacy path is not a current requirement absent actual necessity and unmet current successor.

**B**: from downstream and source science **blind to A's substantive findings**, construct a technically viable alternative over the **same** scientific/first-consumer scope; not merely objections to A. B must independently challenge a problem-framing premise and present the strongest mechanism by which A could lose, including new decision metrics or information constraints if grounded in actual source/consumer evidence. B is not ordered to build a second production backend. Freeze immutable A0/B0 exact 40-hex heads before exchanging substantive arguments.

### A1/B1 reciprocal adversarial exchange

One exchange: A attacks strongest B alternative; B attacks A and its frame/measurements. Each returns 3–7 **decision-changing** issues with source identity and smallest falsifier, not an exhaustive style review. One finite reply where a real objection is unresolved. If B discovers a missing discriminator, controller issues a **pre-result** canonical amended `ANVIL_R7_PLAN_1` with immutable parent digest and B source/head, adding the requisite material comparison cells, or returns `EXACT_HOLD_PENDING_C`. A mere prose `NOT_DECISIVE`, `PROVED_IMMATERIAL` or a hidden B benefit cannot extinguish the challenge. Once first results exist, no in-place retroactive reframing: hold or explicitly start a new source/result epoch with user-aware approval; retain old evidence without selective deletion.

### C: independent architectural and builder review

C must independently reopen source, A/B arguments, measured raw A/B receipt files, coverage of selected scope, B-discovered discriminator, legal source-claim transitions, named future routes and integrated graph, and the **frozen P2**. C must supply the **single strongest surviving architecture objection** and either demonstrate with actual frozen cells/qualified evidence why it is not reversing or return a hold. For owner-priority tradeoffs, C must separately adjudicate the pre-result preference and its bounded regressions. C also cold-reads one actual implementer card and one future-owner-held interface; reject placeholders, lost negative semantics and nonexistent source first readers. Builder proof grade: `SPECIFICATION_CONSTRUCTION_READY`, `EXECUTED_FIRST_READER_PROOF`, or `EXACT_BUILDER_HOLD`. Static specification readiness is **not** a claim that code was executed.

C's `C_ACCEPT_SCOPED` can be used only after validating and recomputing the **same plan, raw measurement receipts, comparator and frozen spine** at the same pinned source. Distinct nonauthor status and actual resource rights must be independently checked outside the Python file. A `C_ACCEPT_DOCUMENTARY_HOLD` preserves honest author completion while architecture remains unresolved. No separate C-review-of-C commissioned by default.

Unknown owner, held rights, absent real first effect, unreviewed big repair or false live snapshot ⇒ `HQ_CURRENTNESS_HOLD` / `H1_REJECT_EXACT_DEFECT` as appropriate; lawful sourcefree engineering continues outside the precise hold. After substantive development, update existing PROGRAMMA and paired progress through authorized receiving; no silent stale handoff.
