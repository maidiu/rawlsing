## Residual dangers deliberately not hidden

1. **Actual external authenticity is not a property of a local SHA.** A fake but internally consistent JSON file can be generated by a malicious author. R7 checks identities and content consistency, *not* a runner's existence, scientific source truth, owner credential, nonauthor status, GitHub CAS or permissions; C and H1 must check externally. `H1_RECEIVED` from local tests is always synthetic, never accreditation.
2. **Benchmark representativeness is a substantive scientific/engineering judgment.** 22 required C11 cells do not span all possible surveys, source routes, 13-family complexities, cache regimes, conditional branches or actual future worlds. B may add a new real reverser. No perfect finite matrix is possible. C must challenge source selection and inferential generalization.
3. **True best architecture may exhibit tradeoffs.** Lexicographic owner priority with frozen loss ceilings permits rational choice without fake numerical dominance but could itself be badly chosen; B challenge, recorded source and C independent review are essential. Hold if owner preference unissued or a material loss beyond ceiling.
4. **The selected storage engine cannot itself issue scientific/actor rights.** Even an accepted sourcefree C11 remains sourcefree, not original35, new institution ownership science, fabricated survey psyche or independent human/actor permission. Unissued future consumers remain held but must remain technically feasible and source-reversible.
5. **Historical source lineage:** full original R5 preserved; K3 documentary 29/26/14 scoped received at noted cut. Verify live HEAD before real launch. The Oct28 architecture Git blob is retrievable but one cited enclosing commit had a failed lookup, not to be silently upgraded.
6. **An author created and tested this R7.** It has not undergone independently credentialed C receipt. Test fixtures simulate both candidates, C and H1 only to challenge local validators. Qualify as `R7_AUTHOR_COMPLETED__LOCAL_ADVERSARIAL_PASS__INDEPENDENT_RECEIVING_PENDING` after a real archive quality pass, not design READY or protected adopted.
