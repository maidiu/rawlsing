# D15 — Deferred and maximal-later program

ASTRA_NEW_RECOMMENDATION. Deferral preserves the maximal vision while preventing noncritical research from blocking a falsifiable generated-person demonstration.

| Frontier | Why defer | Specific reentry trigger |
|---|---|---|
| Causal attractor latent state | Incremental value and non-double-counting unknown | Graph/history baseline fails a preregistered held-out contrast; richer model wins fairly |
| Enneagram regularization | No measured added causal value; type bias risk | Independent research warrant and comparative gain; interpretation remains optional |
| Unlimited ancestor/social recursion | Unbounded search/calls; not necessary for every causal query | Specific consequential antecedent cannot be represented at current sparse boundary |
| Global historical/material coverage in each scene | Every query need not consume all estate | Real consumer proves missing required context; scoped productive source expansion |
| Arbitrary geography/open-world materialization | High consistency/admission burden | Bounded product succeeds and observed user demand needs broader scope |
| Rich autonomous supporting societies | Width can overwhelm focal depth | Sparse agenda/promotion policy fails A3 independent-life criteria |
| Fully adaptive phenomenal/user model | Leakage and manipulation of objective occurrence risk; not core initial proof | Simple faithful projection fails A5 comprehension/experience under authorized study |
| Long-horizon production scale | F3/F4 integrated evidence absent | Several generated lives and histories pass, measured workload justifies infra |
| General learned population pairing model | Data/linkage/calibration and use authority may be absent | A concrete V3 selection estimand needs it and suitable evidence is warranted |
| Universal retrospective biography solver | Nonidentifiability, selection bias and computational explosion | Bounded K11 demonstrates value and exposes a specific generalization demand |

Do not defer constitutive focal-person depth, material world conditioning, mother's whole history, selected second parent's independent personhood, actual relation evolution, memory/access distinctions or live historical consequence. Those are part of the first valid proof. A local refusal is sometimes correct, but permanent refusal-only operation is not the product.
