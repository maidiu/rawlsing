## 0. Common design law (from 04 §4)

Every K test that claims causal or scientific meaning needs: matched worlds with fixed model versions and declared RNG receipts; one preregistered primary contrast per test; expected direction or permissible outcome set frozen before generation; machine state evaluated before prose; judges blinded to architecture and condition; paraphrase/order and equal-retrieval-budget controls; a declared irrelevant change that must remain invariant; and enough repeated seeds to estimate variance. ## K1 — Same structure, different generated persons

**Question:** Can stochastic/generated history produce meaningfully different lawful actors under the same PRE-V3 context without arbitrary LLM fiction?

**Design:** Two generated focal persons under an identical frozen WorldSnapshotReceipt and identical bounded social width, differing only in declared generation seeds. Compare admitted state deltas against the same world: distinct commitments/strivings/relationship histories are required; identical outcomes indicate the substrate cannot differentiate; divergences that cite no admitted events indicate fiction.

**Kill/revise conditions:** Kill the claim “generated history yields distinct lawful persons” if identity or arbitrary prose differences are the only differences. Revise toward richer recruitment semantics if both persons converge to the same response profile despite divergent admitted episodes. Kill any implementation where a divergent output cites no parent events.

**Ordered go/no-go threshold:** GO only if ≥2 of 3 seed pairs show distinct admitted state histories and at least one behavioral divergence traceable to those histories under blinded judges. Primary contrast: state divergence rate at matched world. NOT_EXECUTED.

## K4 — Corrective recurrence
