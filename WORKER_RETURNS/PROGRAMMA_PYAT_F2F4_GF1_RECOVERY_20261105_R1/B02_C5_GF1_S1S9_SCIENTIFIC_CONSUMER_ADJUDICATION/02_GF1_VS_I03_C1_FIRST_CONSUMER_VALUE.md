## Numerical discrimination: the same joint has two lawful statistical directions

For a sourcefree *illustrative* 2×2 table, X rows and Y columns `[[2,0],[1,0]]`, with three jointly eligible responding persons:

- Forward: `P(Y=0|X=0)=2/2=1`; `P(Y=0|X=1)=1/1=1`. Both X levels have positive denominators, so current GF1 labels the sample `NO_PAIR_SEPARATION`.
- Reverse: transpose rows to Y and columns to X, `[[2,1],[0,0]]`. Now `P(X=0|Y=0)=2/3`, `P(X=1|Y=0)=1/3`, while `P(X|Y=1)` is undefined due to a **zero denominator**. A reverse relation that merely relabels forward counts is false, even if it hashes consistently.
- Repaired GF1 rejects swapped request up front. A separately permitted C1/I03 reverse query must still prove it uses the correct joint risk, scope, conditioning predicate, numerator/denominator and explicit zero-denominator status.

For `[[9,1],[1,9]]`, current GF1 would also say `NO_PAIR_SEPARATION`, because both target values occur in both rows; nevertheless the observed conditional proportions are **0.9 versus 0.1**. Therefore `NO_PAIR_SEPARATION` is not evidence of statistical independence, no association, no class distinction or absent pressure. Conversely the two-person diagonal `[[1,0],[0,1]]` produces `EXACT_PAIR_SEPARATION` but cannot establish population determinism or a human-type law.

## Why pair evidence cannot replace F4 true clouds

Construct two eight-respondent, three-binary-item worlds: (A) each of `000,011,101,110` occurs twice (XOR parity), (B) all eight triplets occur once (uniform independence). **Every 2×2 pair table in A and B has counts `[[2,2],[2,2]]`**, yet A has four observed 3-way configurations and B has eight. No number of pair-support signatures can distinguish their real higher-order co-occurrence. F4's actual same-person k-way table or an explicitly disclosed probabilistic model is required. No artificial product of pair marginals may be called an observed cloud.
