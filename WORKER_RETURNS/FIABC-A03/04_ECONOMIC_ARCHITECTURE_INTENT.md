# FIABC-A03 — Economic Architecture Intent

## Holding

The project means **faster/lighter/more economical under equal semantic work**, not "perform less governed work and call the result faster."

No production benchmark is invented here.

## 1. Remove repeated transit, not semantic obligations

Dva's direct-DAG law makes exact upstream reuse the preferred solution when an earlier producer still owns the meaning. This reduces repeated serialization, duplicated ownership surfaces and consumer-side reconstruction without reducing the semantic workload.

Trii D14 distinguishes semantic exactness/coverage from physical traversal/precomputation/cache/layout. D15 allows exact bounded caches and derive-on-demand products while keeping deep queryability/replay.

- keep source/authority/replay roots durable;

## 4. Selective invalidation / recompilation

C08's independent holding is:

`minimum lawful recompilation = changed exact determinant scope + transitive exact dependency closure`.

Optional cache loss changes performance only. Historical learned releases and generated life remain immutable.

The accepted HQ genealogy leaves three lawful physical families:
- A: persistent canonical empirical carrier;
- B: source-backed virtual carrier;
- C: source-backed hybrid with bounded regenerable accelerators.

This is a physical fork under one semantic contract. It is not three semantic systems.
