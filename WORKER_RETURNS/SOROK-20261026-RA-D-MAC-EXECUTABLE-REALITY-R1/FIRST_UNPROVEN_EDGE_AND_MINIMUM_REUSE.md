## 3. Minimum scientific decision

Before a new psychological positive, a competent original-rule authority must decide **one** concrete, context-bounded rule (not a fixture choice, not a scalar, not a generic “learning rate”):

1. Which actual encounter/attempt/feedback counts as the formative input, and which supports/access/relationship conditions are required.
2. What actor-owned operation/state is constructed, retained, revised, or explicitly not changed (CAN011 CREATE/TRANSFORM/NO_CHANGE), with causal parents and scope.
3. What memory (ADP016) and epistemic (ADP017) side effects are permitted/forbidden, and how access/forgetting/contradiction are represented.
4. How the state propagates through the wider actor organization and through intervening time without arbitrary drift or years-as-learning.
5. How a later event semantically recruits the state, and what must remain invariant (support withdrawn, nonreceived, irrelevant, inaccessible memory, same hash without semantic change).
6. How the settled 3–5-event batch computes impressions across sequential events and how the retrospective half-call forms fallible memory/meaning without overwriting the person.

If the authority cannot issue this, the correct status is `SCIENCE_RULE_UNISSUED` and the positive is not executed. Do not inject `CONCEPT_ACQUIRED`, a guessed motive, generic weights, mood drift, invented events or LLM prose to force a green K1/K2/K4/K8.

Reuse only at demonstrated scope:

- **S44 root/ledger/snapshots**: generated A/B material, G18 histories, objective event, actor ledgers. `TEST_ONLY_SOURCEFREE`; not a psych constitution.
- **S45 encounter/language**: user event, admitted speech/action, language mediation/equivalence. The S45 `do_help` material change and `attend=NO_CHANGE` are real objective event paths.
- **S47 objective interval→C9 conditioner**: real source-in-readset and material eligibility. Not learned psychology.
- **S39 finite option machinery**: real pairwise selection from validated sources, OPEN/conflict, label neutralization. Sources are model premises unless a competent producer supplies actor-owned values.
- **S49 independent-B source adapter**: real access witness and finite generation; real root B sources are currently empty.
- **S51 historical object recovery**: real G18 object/parents/route witnesses; the one-event hypothesis is test-only and must not be treated as current purpose.
- **S48 envelope/caching/transport**: useful transport only; not the batch loop and not an admitted internal act.
- **S52 paid option/candidate**: useful conditional-option and material-state plumbing; the performer is unaccepted and the verifier is defective.

Do not reuse the S50 fixture as the current actor, the S52 controlled performer as an independent action, or the S48 one-event turn as the batch recursion.

## 5. Minimum build / decision sequence

1. **Science decision** (owner: original V3/CAN/ADP authorities): issue the concrete formation/retention/recruitment/coupling/memory rule above. Record exact rule identity, scope, supports, causal parents and negative cases.
2. **Engineering cell** (owner: existing Sorok actor/development implementer): compose actual G18/S44 history + received event/access + actor attempt/support/feedback + counterpart behavior; emit a typed actor-owned state event or explicit NO_CHANGE; admit it through the existing CAN011/state owner; persist causal parents and memory/epistemic side effects.
3. **Later consumer**: make a later same-person event read the semantic values (not a hash, label, prompt summary or LLM narrative) into S39/S49 recruitment, changing a typed option/eligibility/reason under the preregistered positive.
4. **Controls**: same actor/world/later event with (a) qualified construction+feedback, (b) sign-only/no construction, (c) missing feedback, (d) support withdrawn, (e) irrelevant later event, (f) source hash changed without semantic change, (g) inaccessible/false memory. Nulls must remain null; cold replay and branch/access cuts must hold.
5. **Then the settled batch loop**: implement one call N proposing 3–5 events; Rawlsing sequentially realizes them with interconnected impressions and intervening time; no intervening ordinary LLM call; first half of call N+1 retrospectively handles the realized batch and second half opens the next. The loop must use the proven actor-owned state/coupling/memory rules, not a scheduler/receipt demo. S48 transport is not this loop.
6. **Separately**: fix the S52 verifier so a later episode cannot bypass state lineage, and decide whether the S52 performer is accepted or withdrawn. This is not a developmental positive.

## 6. Largest smallest next operation

The largest **smallest** next operation is a single finite, sourcefree, same-person cell:

> one actual G18 actor + one received encounter with actual attempt/support/feedback + one competent CAN011 rule decision + one admitted actor-owned operation or NO_CHANGE + one later event that semantically consumes it, with positive/sign-only/no-feedback/support-withdrawn/irrelevant controls and cold replay.
