## Holding

The hostile court freezes four independent propositions:

1. **Canonical raw SHA is necessary but not sufficient.** Same filename, shape, row count, variable count, labels, or queried outputs cannot substitute for hashing the actual raw bytes opened.
2. **Derivative self-assertion is not parentage.** A derivative that contains the canonical `source_sha256` and even self-hashes correctly is unproved until an immutable external receipt binds derivative identity -> governed producer/operation/config/currentness -> canonical source SHA.
3. **Whole-source physical equivalence is stronger than workload equivalence and orthogonal to I05 semantic parity.** A subset/cache may be lawful for a bounded workload while failing whole-source equivalence.
4. **`PHYSICAL_EQUIVALENCE PASS` does not imply `SEMANTIC/CERTIFICATION PASS`.** Compatibility decoding, topology preservation, weight carriers, routing carriers, raw/display distinction, and physical metadata are physical evidence only. Documentary/semantic authority remains separately adjudicated.

The court therefore refuses the false implication:

```text
I05_SEMANTIC_PARITY
        or
CANONICAL_SOURCE_SHA
        or
DERIVATIVE_SELF_HASH
        =>
WHOLE_SOURCE_PHYSICAL_EQUIVALENCE
```

and also refuses:

```text
PHYSICAL_EQUIVALENCE_PASS
        =>
SEMANTIC_PARITY_PASS
        or
SOURCE_CERTIFICATION_PASS
```
