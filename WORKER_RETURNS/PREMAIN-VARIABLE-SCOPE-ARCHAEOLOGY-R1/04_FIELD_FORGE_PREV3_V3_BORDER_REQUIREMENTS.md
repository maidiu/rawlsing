## 3. What did not survive as universal requirement

Field Forge R2 explicitly does **not** adopt:

- one universal master respondent carrier;
- mandatory local full-state persistence;
- one universal geometry primitive;
- one common world-space;
- mandatory motif/repertoire tables;
- automatic position-role authority;
- automatic weight/estimand authority;
- automatic strong nouns such as FIELD, CAPITAL, HEGEMONY, HOMOLOGY or causal mechanisms.

A stronger retained object must be justified by a named starvation witness or separate claim-specific authority.

Therefore early Field Forge aspiration should enlarge future pruning tests by **function**, not by blindly preserving every historically proposed variable.

## 8. Consequence for variable-scope archaeology

Later Field Forge/PRE-V3/V3 work both enlarges and disciplines the old variable picture:

- **enlarges** it by requiring richer positional, relational, joint, minority, topology, routing and temporal functions than a small driver-proxy map;
- **disciplines** it by rejecting universal geometry/carriers and requiring claim-specific authority;
- **narrows terminal direct consumption** because V3 normally consumes compiled structural products rather than raw survey rows;
- **does not authorize global pruning** because upstream empirical/learned-world consumers remain distinct.

The correct succession question for any variable is therefore:

> Which current producer-owned function, relation, replay obligation, source-local analysis, discovery path, structural admission, or terminal consumer can still lawfully require this information?

Not:

> Does the current FIABC benchmark happen to touch it?
