# PYAT HQ116-C — Field Forge Refinement Wake Contract

## Default state

`FIELD_FORGE_REFINEMENT = ASLEEP`

The adopted Field Forge R2 architecture is already current. The Route-B implementation campaign is not authorized to redesign it abstractly.

Field Forge wakes only from an **actual current Route-B output**.

## Definition: actual B output

For this wake contract, an actual B output must be produced by:

1. an exact real source identity;
2. the current physical decoder;
3. an exact source-specific governed projection/authority package;
4. the **live current** `pre553_source_backed_c11_facade.py` implementation or an explicitly adjudicated current successor;
5. the current common `pre553_carrier_execution` executor;
6. exact I03/I05 owners;
7. an exact retained pre-Field-Forge object graph with deterministic replay.

It is not satisfied by:

- ASTRA D04 compact products;
- a Candidate A/B/C output;
- an FIABC oracle wrapper using a compatibility-pinned historical facade;
- a synthetic fixture alone;
- an R1M logical-release replay that did not perform the fresh source->live-facade path.

## Wake predicate

Field Forge refinement is authorized only when all conditions W1-W5 hold.

### W1 — exact B packet exists

The packet exposes, by exact ref/preimage or lawful dereference:

- source/universe/risk-set scope;
- queries and predicates;
- facts;
- discovery receipts and typed terminal states;
- exact permission/authority closure;
- dependencies;
- replay.

### W2 — the relevant upstream evidence is not itself unresolved

The proposed Field Forge claim cannot be blocked merely because Route B lacks:

- source meaning;
- response/routing meaning;
- measure/weight/estimand authority;
- relation/comparability authority;
- exact query/predicate identity;
- replay integrity.

If one of those is missing, return the upstream typed blocker. Do not wake Field Forge to repair an upstream authority hole.

### W3 — current Field Forge law is actually exercised

Present the exact B packet to the existing Field Forge ingress/admission machinery.

A wake-worthy witness exists only if the current Field Forge surface cannot lawfully do one of the following **despite complete upstream inputs**:

- dereference the exact producer-owned evidence;
- preserve its exact relation/query identity;
- preserve exact unit/scope/risk set;
- preserve permission/negative authority;
- preserve dependency/replay closure;
- carry an existing typed negative without laundering;
- emit the weakest lawful actor-independent relation/refusal already within Field Forge ownership.

### W4 — the failure is Field-Forge-owned, reproducible and minimal

The failure must be reproducible source-free from the retained B packet.

Classify it exactly as one of:

- `FF_INGRESS_ADAPTER_GAP` — current inputs are sufficient, but the ingress adapter cannot consume their exact current form;
- `FF_RELATION_REPRESENTATION_GAP` — current Field Forge ownership covers the relation, but no current representation preserves required identity/order/cardinality/topology;
- `FF_TYPED_NEGATIVE_GAP` — upstream emits a lawful negative/refusal state that Field Forge cannot preserve distinctly;
- `FF_REPLAY_OR_DEPENDENCY_GAP` — current relation owner cannot retain/dereference exact dependencies/replay determinants;
- `NAMED_STARVATION_WITNESS_FOR_STRONGER_RETAINED_OBJECT` — a concrete downstream lawful use cannot be served by direct dereference/current weak object at equal authority/replay grain.

Anything else routes back to its competent owner.

### W5 — least repair is named

The wake packet must name the smallest repair and prove why a weaker one fails.

Repair ordering:

1. adapter only;
2. exact relation representation extension;
3. exact typed-negative extension;
4. exact replay/dependency extension;
5. claim-conditional stronger retained object after named starvation witness.

Do not jump directly to a master graph, universal geometry, motif ontology, structural world carrier, or new strong noun.

## Non-wake outcomes

These do **not** wake Field Forge by themselves:

- `VALID_EMPTY`;
- `OBSERVED_ZERO`;
- `NONCOMPARABLE`;
- `OUT_OF_SCOPE`;
- missing/denied authority;
- unsupported upstream topology;
- unresolved source semantics;
- a different current live-facade release hash from a historical golden hash;
- absence of a generic learned-product current-selection receipt;
- performance inconvenience;
- desire for prettier packaging;
- old D04/FF01 schema mismatch when current producer-owned objects are already sufficient.

A typed refusal is a successful Field Forge result when current law requires refusal.

## Strong-noun firewall

Actual B output does not itself authorize:

- FIELD;
- FIELD_SPECIFIC_CAPITAL;
- mechanism CONVERSION;
- HEGEMONY / SUBHEGEMONY;
- HOMOLOGY;
- strong PRESSURE_FOOTPRINT/PATHWAY;
- STRUCTURAL_MECHANISM;
- actor position, belief, memory or uptake.

Those remain separately authorized or `BLOCKED_EXPLICIT_AUTHORITY`.

## Required wake packet

A Field Forge refinement commission must receive:

- exact Route-B output packet identity;
- source/release/replay identities;
- exact query/predicate/fact/discovery refs;
- exact authority/permission/negative closure;
- exact typed state;
- exact existing Field Forge function/test that fails or loses information;
- proof the same failure replays source-free from retained B output;
- owner classification;
- least-repair proposal;
- hostile test that fails before the repair and passes after it;
- statement of what remains explicitly out of scope.
