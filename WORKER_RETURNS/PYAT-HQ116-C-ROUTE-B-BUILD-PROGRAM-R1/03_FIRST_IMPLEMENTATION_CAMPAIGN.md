2. **source SHA mismatch** — fails before learned output;
3. **projection/source mismatch** — fails closed;
4. **missing or substituted projection authority** — fails closed through existing facade law;
5. **runtime catalog exact-ref substitution** — fails closed;
6. **query/predicate mismatch** — fails closed;
7. **discovery-authority mismatch** — fails closed;
8. **catalog order permutation** — does not change exact frontier/receipt identity;
9. **cache delete/rebuild** — changes cost/materialization only, not semantic output identity;
10. **typed VALID_EMPTY** — remains nonpositive and is exported intact;
11. **typed NONCOMPARABLE / UNAVAILABLE / unsupported topology** — preserved, never zero-filled or promoted;
12. **raw vs weighted distinction** — never defaults absent weight to one;
13. **same-count/different-risk-member distinction** — exact risk-set identity remains constitutive;
14. **replay** — second exact run under identical determinants reproduces exact release/fact/receipt/replay identities;
15. **tampered replay/source/authority** — fails under `pre553_replay_audit`;
16. **no lifecycle minting** — no supplied current-selection authority means no current-product claim;
17. **no structural effect** — all composition/execution receipts preserve false structural/causal/V3 effect;
18. **static anti-resurrection** — compositor imports/calls no Candidate A/B/C, FIABC winner logic, ASTRA D04 packaging, or historical stage router.
