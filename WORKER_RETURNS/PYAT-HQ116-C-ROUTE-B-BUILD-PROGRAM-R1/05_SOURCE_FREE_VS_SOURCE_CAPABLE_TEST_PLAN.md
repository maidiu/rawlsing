## B. First source-capable proving court — only after A passes

### Source-read budget law

For each proving specimen authorize **one governed source materialization transaction**.

The court must meter:

- source opens;
- bytes read;
- decoder invocations;
- rereads;
- source hash;
- source shape.

No second full source pass is permitted merely for convenience. If the decoder internally performs more than one physical read to satisfy its exact format contract, the receipt must expose that fact; the worker may not silently add an independent second decode/reread.

No raw bytes are committed.

After both proving paths close, do **not** run 35 sources.

## D. Expansion trigger

Add another source/wave only if one of these is proved:

1. a current Route-B component branch is not exercised by Q01-Q06;
2. a CLOSED35 physical edge class is not covered by existing source-free tests plus Q01-Q06;
3. a source-specific binder requires a representation not present in the current minimal set;
4. an actual B output exposes a new Field Forge ingress starvation witness;
5. an exact regression is source-specific and cannot be reproduced source-free.

Otherwise, extra source runs are certification theater and are out of scope.
