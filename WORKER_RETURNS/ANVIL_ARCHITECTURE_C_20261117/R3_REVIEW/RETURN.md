## 3. Consequential gaps requiring correction

### G1 — FF01 k>2/reverse-distribution claim is not supported by the actual code

`R3_ARCHITECTURE_DECISION.md` §6.4 and `R3-CAP-04` claim the existing
`ExactConditionalSupportProfile` route extends to `P(Y1..Yk|D,U,W)` and reverse
`P(D|Y,U,W)`, with role/position contrasts and branch/recursive conditionals.
The actual `field_forge_conditional_support.py` is a **two-target** GT2 count
relation with fixed `Q86B` conditioner / `Q86A` target, `participant_cardinality
= 2`, and an explicit “does not calculate ratios” rule. It cannot supply the
claimed k>2/reverse distribution. The R3 ledger itself (`R3-RES-008`) only says
FF01 is a conditional association/profile. **Smallest correction:** split
`FF01-2` (existing exact count profile) from a versioned `FF01-k` derived
product contract with exact roles/keys, reverse risk basis, ratio/coverage and
first consumer; otherwise grade k>2/reverse `CONDITIONAL_EXTENSION`/`OWNER_HELD`.
Add a falsifier and `R3-RES` entry.

### G2 — C11 source-preservation claim is overbroad at field level

`R3_ARCHITECTURE_DECISION.md` §6.1 says C11 preserves native
item/option/form/routing/version and respondent/household namespace;
§6.3/§7 says design/uncertainty material. The actual persisted schema:
`QuestionVariableBinding` has native question ref/version/canonical-component
refs/authorities but no option/form/routing field; `RoutingEligibilityFact` has
routing rule/state refs; `EmpiricalUniverse` has `respondent_namespace`,
`sampling_design_regime` and `target_population_and_sample_frame` but no
household/roster namespace; `WeightMeasureFact` has weight/design/estimand
authority refs but no PSU/strata/variance; `EmpiricalFact` has
`uncertainty_method_or_typed_state`, not numeric variance. The capability row
does mention an external codebook, but the decision asserts C11 preservation
and does not map which meaning is C11 byte, external source/codebook, or
unavailable. **Smallest correction:** add an exact `INSPECTED_CODE` field map
(and `R3-RES` entry): C11 native refs/version/routing states; external
source/codebook/questionnaire for original-language option/form/ballot;
household/roster not canonical unless a source-specific projection exists;
PSU/strata/variance/numeric uncertainty external or typed-absent. Correct
§6.1/§6.3/§7 and R3-CAP-01/03.
