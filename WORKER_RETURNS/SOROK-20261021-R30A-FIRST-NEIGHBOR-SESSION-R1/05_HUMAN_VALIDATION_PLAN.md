# A4/A5 technical readiness and future human-validation plan

**Status:** `PROPOSED_NOT_EXECUTED__NO_HUMANS_RECRUITED__NO_PSYCHOLOGICAL_CLAIM`.

This return reaches A4 only as **additional product flow** and A5 only as **readiness to design a consented study**. It does not claim human validation, attachment, therapeutic benefit, personality change or empirical equivalence.

## What the technical alpha can already support

- a stranger enters an already ongoing bounded scene;
- the person has independent material projects/obligations and another actor with offscreen life;
- user SAY/DO/ATTEND are proposals, not commands;
- help can be refused, contact can be denied, silence is legitimate;
- exact actor utterances are bound before user composition;
- attention changes phenomenal selection but not occurrence;
- the same persisted C12 person is reopened cold;
- a later meeting is possible only through the world/channel.

## Future independent study (proposal only)

**Population:** consenting adults, recruited through an explicit research/alpha invitation with no claim that a real friend vouched for them. Start with a small qualitative cohort; no minors, no dependent/vulnerable recruitment, no real personal data ingestion.

**Design:** a within-participant first-session + delayed-return protocol using the same seed person/world and the same code. Participants are told truthfully that the neighbor is a simulated sourcefree technical actor, not a human. They complete one first encounter and one later return after a fixed simulated offscreen interval. A separate control condition may vary only the user's attention profile or the actor's material availability, not hidden psychology.

**Methods:** think-aloud/exit interview, stimulated recall of specific moments, free-response comparisons against a generic chatbot transcript, and optional structured ratings used only as research descriptions—not product scores. No deception, no hidden relationship meter, no engagement optimization.

**Ethics:** informed consent, withdrawal, data minimization, no real contact IDs, no recording without explicit consent, independent ethics review where required, immediate stop for distress or coercion, and a clear statement that the actor has no feelings or suffering.

## Falsification criteria

A future study should count as a **failure to establish the core experience** if any of the following recur beyond a pre-registered tolerance:

1. participants describe the neighbor as a generic assistant/chatbot or interchangeable character;
2. the actor accepts every user request or changes stance to please the user;
3. user wording/attention visibly changes the actor's objective action, not merely what is noticed;
4. the supposed prior encounter has no causal effect on the later meeting;
5. contact/message appears without a lawful channel or actor decision;
6. private actor state, hidden motive or omniscient world truth leaks through the surface;
7. the experience depends on forced romance, guilt, crisis or retention bait;
8. latency/fidelity is so poor that ordinary presence cannot be sustained;
9. participants cannot distinguish their interpretation from an observed occurrence without the surface helping them do so;
10. the actor's silence/absence is experienced only as a bug or punishment rather than a legitimate boundary.
