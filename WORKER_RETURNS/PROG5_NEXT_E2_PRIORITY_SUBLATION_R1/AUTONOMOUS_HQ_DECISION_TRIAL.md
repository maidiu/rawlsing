## Reusable HQ decision rule (a human-readable method, not a runtime orchestrator)

1. Receive terminal PRE-V3/N11 result target. Look up its existing Sxx/child/GAP and original **MUST**, **IF predicate**, **AND join** and **ALTERNATIVE** choices in [82 edges](https://github.com/maidiu/rawlsing/blob/ed9c882a0683375bad70ee4abd1d662a61f1756b/PYAT_CONTROL_ROOM/PROGRAMMA_PYAT/05_ROADMAP/CURRENT_SEAM_STATES.jsonl).
2. Walk backward only through applicable branches; select a lawful supported alternative if it achieves the same contract. Leave inapplicable IF legs explicitly NOT_APPLICABLE and do not delete the gap.
3. Subtract current protected sourcefree composed functions, identical payload/version/first reader and separately qualified native scope. A static import is *not* a tested call; a historical PASS on another commit is not current code green; rejection survives version changes until exact replacement proven.
4. At the earliest unresolved demanded leaf, require **actual producer + emitted contract + first importing/acting consumer + version + permission + proof grade**. Use the five-test court on every historical option.
5. If engineering-ready with scope/custody/reader resolved, choose highest-impact bounded ready compare/repair and appoint the competent executor/reviewer. If original respondent, item, frame, weight, FF/F6/F7 meaning, N11/N12, host R09 or actor rights missing, **STOP** and send exact decision packet to owner. No autonomous source/science grant.
6. After an independently reviewed receipt at exact scope, return to the same 49-gap/82-edge guide to mark only the justified status. This E2 file is a **candidate navigation aid**; E-R receives, E-F cold reviewer accepts or rejects. Neither happened in E2.

Outcome in these cold chains: **1 scoped already-present sourcefree path, 2 S1-ready ABI comparisons, 1 branch-only engineering RED, 4 original science/source holds, and 1 N11/N12 terminal stop**; cases overlap by purpose, not an additive machine completeness count.
