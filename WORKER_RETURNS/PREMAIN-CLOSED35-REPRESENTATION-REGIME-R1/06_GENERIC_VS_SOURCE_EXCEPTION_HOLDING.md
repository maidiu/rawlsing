# Generic vs Source Exception Holding

## Controlling distinction

CLOSED35 now separates three layers:

1. **generic physical representation law** — reusable exact rules about decoder output, R5 typed identity, missing-state/source-declaration preservation, and physical metadata;
2. **source applicability** — exact source SHA + decoder/config + governed variable/storage surface;
3. **bounded bridge/exception** — finite authority used only where a historical/current key-law boundary or source-local locator defect requires it.

No layer may be silently promoted into another.

## Deduplicated generic law gap

Nine governed surfaces across Afrobarometer R5, Arab Barometer W5, and GSS2010 show the same qualified shape:

- rule owner emits Python `int` literals;
- qualified SAV decoder emits Python `float`;
- exact physical-key intersection is absent;
- no numeric coercion was used.

This is **one** generic law gap, `G01_SAV_NATIVE_INT_RULE_TO_FLOAT64_PHYSICAL_BINDING`, not nine adapters.

This court does not close G01 by declaring numerical equivalence. A future repair must either construct a new exact representation authority from independent evidence or keep those surfaces blocked.

## Existing bounded bridges

LiTS-I and WVS7 remain bounded. Numeric resemblance to other waves is not applicability evidence.
