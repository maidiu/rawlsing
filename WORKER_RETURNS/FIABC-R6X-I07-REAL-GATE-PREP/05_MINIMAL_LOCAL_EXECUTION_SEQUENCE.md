# Minimal Local Control / Admission Sequence

## Boundary

This is the **smallest mechanics-only local sequence** after HQ has accepted the sibling returns and produced one exact final execution head.

It does not authorize Candidate A/B/C execution by itself and does not run measured P2X. The later candidate stages remain governed by the existing P2 driver.

The sequence deliberately distinguishes:

- **pre-candidate controls** that must close before any candidate process starts; from
- **R35 physical admission** that may consume the same physical realization produced at S01 and therefore must not be forced into a duplicate prebuild.

## Preconditions supplied by browser/HQ fan-in

Before touching the local host, require exact accepted returns for:

1. R1K R15/R16:
   - strict real common C11 PASS;
   - R01–R18 all green;
   - fresh WVS oracle frozen;
   - candidate outputs/processes = 0.
2. post-R1J live rebind:
   - final R1J R6S material transposed into live P2 runtime;
   - source-independent successor qualification PASS;
   - exact final current-court/runtime identities frozen.
3. LiTS-A parentage recovery:
   - either browser-recovered generic R35 parentage PASS, or exact minimal local verification packet;
   - no Candidate-A rebuild authorized.
4. one final repository head:
   - contains the accepted live runtime/control fan-in;
   - is the exact head the local I07 manifest will bind.

If any of these is unresolved, STOP before local candidate mechanics.

# R35 admission during the governed cell sequence — no duplicate build

R35 cannot honestly be fully closed for a candidate until that candidate's current physical realization exists.

Therefore use the following admission law when the separately authorized six-cell court begins.

## A. LiTS-I/A preserved R5

Before consuming the preserved R5 at S02:

- Worker-3 generic parentage must PASS;
- current derivative identity/config/currentness must match;
- build an R35 candidate realization descriptor from the preserved R5's already-existing governed physical evidence;
- do not rebuild it solely for R35.

If the preserved R5 cannot supply all expectation dimensions without rereading/rebuilding, STOP with exact missing dimensions and return to HQ. Do not invent equivalence.

## B. Fresh S01 realizations

For cells whose S01 is a fresh physical realization:

1. S01 creates/opens exactly the candidate state already required by the measured court;
2. freeze the R35 realization descriptor from that same state/evidence;
3. no throwaway preliminary copy/build;
4. preserve the S01 performance observation but mark it **inadmissible** pending physical + semantic parity;
5. when A/B/C descriptors for the source all exist, call the source-local T6 guard;
6. after both source guards exist, call the two-source T6 wrapper.

R35 verdict is physical-only.

## C. Admission ordering

A candidate's performance evidence enters HQ synthesis only if all of the following eventually close:

- source identity / parentage as applicable;
- R35 physical-equivalence PASS;
- complete I03/I05;
- independent oracle PASS;
- T4 accounting/lifecycle;
- fresh-process replay;
- I08 full terminal.

No timing observation becomes truth merely because it was captured earlier.
