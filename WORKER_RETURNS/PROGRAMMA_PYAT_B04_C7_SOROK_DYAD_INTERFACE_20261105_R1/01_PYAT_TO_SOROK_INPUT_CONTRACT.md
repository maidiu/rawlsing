# 01 — Pyat → Sorok input/permission/root/first-reader contract (candidate, not selected ABI)

**Finding:** a qualified Pyat *possibility* envelope can constrain opportunities and actor-position candidate courts; it cannot instantiate an actor, a specific pair, a genealogy, a dyad's private state or later action. This is a semantic/interface court, **not** an implementation schema or permission grant.

## Grades and common envelope

`SOURCE_DEFINED` means a rule/source exists; `CODE_PRESENT_SOURCEFREE` means scoped code is actually present; `REVIEW_ACCEPTED_TEST_ONLY` is exact reviewer-limited sourcefree proof; `PROPOSED_READER` is not an importer; `NONE_NATIVE` means no qualifying native first reader observed; `OWNER_HELD` does not mean intrinsically impossible. Never promote a historical or synthetic sourcefree read to native original-person evidence.

Any future interface must bind at least: `(producer_authority/version, exact source release and rights/use, immutable repository/branch/world root, source objects and respondent/person/household unit, epoch/as_of/effective and observation time, target population and spatial/temporal support, item/condition and risk set, source weighting/design/uncertainty, evidence/negative/missingness/alternative model status, selected reader authority and actor-visible scope, revocation/retention policy, readset hash and replay receipt)`. Missing required fields **block** a positive decision. The following names (`F2F4_SUPPORT_ENVELOPE`, `DYAD_EVIDENCE_ENVELOPE`) are descriptive proposals, not registered format IDs.

### The no-leak invariant

Pyat-to-Sorok transport may include `structural_context_ref`, alternative support and permitted constraints; it **must not** send `assigned_personality`, `chosen_partner_actor_id`, `predestined_child_id`, `respondent_as_actor`, `actor_believes`, `future_action`, or `history_already_occurred` as empirical facts. Such a field is an interface rejection irrespective of a successfully sampled number. A real dyad probability, even if later qualified, ranks *modelled* options or hazards only; Sorok separately admits actor-owned causal history and refusal.
