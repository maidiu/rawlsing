## Test of a real semantic match

A continuing transformation is an **input with a selected governing rule that changes meaning**, not merely an old document title, code symbol, schema field, authority reference or similar string. A P→C mapping can be equivalent despite different representation/algorithm/stage if every downstream demanded invariant is preserved:

1. **Scope**: source edition, question/component, respondent universe, source wave, target use and temporal as-of.
2. **Selection**: competent issuer, rule/version, precedence, applicable conditional predicate and withdrawal status.
3. **Change**: actual before/after semantics, including what is overwritten, retained, transformed, or refused.
4. **Information**: identity, multiplicity, ordering, statistical design, provenance and negative decision distinctions.
5. **Result**: typed output/negative and traceable replay boundary.
6. **Use**: a real first non-test consumer demands and correctly interprets that result, rather than a test, dormant function or metadata.
7. **Court**: licensed source/actor and competent science/owner approval remain separate. Engineering evidence cannot grant them.

A different stage is acceptable **only if** it preserves these. Applying routing after aggregation, for example, can change the eligible denominator even if the same fields exist. Applying permission after an unauthorized reader is too late. Producing a role label where a use-permission decision was required is not equivalent.
