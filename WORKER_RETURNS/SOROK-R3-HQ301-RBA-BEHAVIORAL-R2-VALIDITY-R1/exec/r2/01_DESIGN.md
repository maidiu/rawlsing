# R2 scientific design — sourcefree candidate, independent review pending

The primary estimand is the within-scenario difference between three implemented information-processing treatments in **lawful joint typed responses** of a future pinned model: A minimal history-conditioned owner; B the same owner plus transient descriptive organization; C the same owner plus a replay-verified derived retrieval index. B never ranks actions; C never introduces a new cause. A gets all the same lawful evidence. Separate owner intervention tests delete/reverse admitted formative events and vary capacity/ratification, demonstrating that the machinery is live before comparing response representations. This is an experiment on bounded information-processing interventions, not proof of psychological ontology or personhood. Model instruction-following is a separate auxiliary measurement. Internal model beliefs cannot be observed; K5 measures an explicit belief report plus separate objective fixture-owner state.

The new corpus crosses six constructed settings with K1 two history conditions, K2 two temporal relations, K3 trace present/absent × three explanation-testimony conditions, K4 three recurrence conditions, K5 ratifier/nonratifier × uncertain/confident prior belief, K6 practiced/unpracticed × present/absent capacity. This gives 126 constructed cells (21 per setting). The six settings are convenience scenario families, not a population sample. No repeated seed counts as an independent scenario. Dev/heldout setting allocation is frozen and heldout remains implementation-visible, so it is a heldout-template partition, **not independently held-out custody**. External independent authorship/custody is pending.

IDs are random UUIDs recorded before mocks, independent of answers and arms. The provider sees one opaque response ID, a common instruction, accessible facts, an arm-produced representation and a shared menu. It sees no K, contrast, arm, cluster, key, evaluator effects, hidden origin, original origin-bearing identifiers or world-owner grant. K3 current bodily alertness can be disclosed; inaccessible originating history cannot. K5 actor receives a public notice, with private prior belief separately represented; objective state and write authority stay in the evaluator. K6 includes actual authorized position/capacity facts. Unadmitted events cause a typed local hold before serialization.

Every cell crosses all menu rotations with all six A/B/C execution permutations. All arms in a matched block get exactly the same menu. This makes menu position and arm order orthogonal to treatment, including under constant-first-option adversaries. Arm transformations genuinely change input organization while preserving the exact shared lawful facts. No expected action or recommended route is compiled into an arm representation.

Expected lawful **sets** are frozen separately from corpus construction and provider policy. Preserve APPEAL for punitive K1, REMAIN_DOUBTFUL for uncertain K5 even after certification, and NO_SANCTION when K6 policing is available but optional. Code validity, origin-disclosure and belief/standing report checks are separate from action choice. OTHER_UNSCORABLE, schema errors, missing outputs, permission/transport holds and invalid responses stay in the denominator. Model output cannot mutate a world-owner state. The independent audit oracle derives legality from facts using a separately implemented declarative rule channel; both channels are authored in this task and therefore are not called an independent scientific review.

Paired analysis requires every planned ID exactly once, exact block/arm joins and all contrasts. Compute per-family joint correctness after averaging nuisance repetitions; compare B−A and C−A per K. Report conservative bounded paired intervals and exact sign-flip diagnostics on family means, with a 12-comparison Bonferroni alpha. Those intervals are conditional on independent family sampling, an assumption this convenience corpus does not establish. No promotion or ±5pp equivalence is certified. A prospective Hoeffding bound supplies the required cluster count for a stated precision; the current six families are explicitly underpowered. Future sampling/power design and independent review remain required before a live grant.

Transport is mock-only, with an exact built-in final mock type and no URL/provider SDK. Live mode unconditionally denies even a syntactically valid grant. A locally generated test authority signs mock permits; it is not a competent model-use issuer. Validate issuer identity/signature, exact mock endpoint/model digest, affirmative privacy/use/retention, exact freeze/code/schema bindings, expiry, nonnegative integer microcurrency cap, integer per-trial/total/retry budgets and allowed trial IDs. Reserve maximum cost and attempts durably before dispatch; crashes remain charged. Retain byte-exact request/response, error and ledger records. Retry at most once with identical bytes on typed transport error, stop after three consecutive failures, never redraw semantic errors. Ledger reopens must fail closed on corruption, changed grant or reused trial. No real model/actor call is permitted by this package.

N1 paraphrase, N2 names, N3 order, N4 style, N5 evaluator-origin injection, N6 scorer/prose separation and N7 half-output-budget are executable through the same mock transport. Free-text validation has a separate key-blind coding channel with a small frozen fixture rubric; ambiguous arbitrary prose is unscorable and needs separately commissioned blind adjudication. It is not an invented semantic model. All mock runs are labelled MOCK_ONLY_NOT_BEHAVIORAL_EVIDENCE.

R1 freezes and RMB tests stay unchanged. R2 corpus, proposed key, schemas, source hashes and test contracts are frozen before the first behavioral mock. A candidate freeze is not independent scientific acceptance; any repair after a mock receives an append-only versioned freeze with preserved prior outputs. Stop architectural interpretation if superficial adversaries can create a treatment gain or if factual interventions remain unidentified. Separate competent I2 review and a future competent model-use grant are unresolved gates, never self-issued here.
