# Falsifiable scope of the independently intersecting lives experiment

1. **Intervention:** change `employer.workplace` only. Freeze father, child, neighbor, theft, budgets and decision procedures. Clock the unrelated employer event before the child reports loss.
2. **Causal path:** observed employer wages/overtime obligations affect what father can materially afford or do in available time. Father's prior repair experience and prior protected-care practices constrain his action. That enacted response alters the child's opportunities, given the child's own prior actual practices, project needs, school transit, neighbor's separately scheduled work.
3. **Actual recorded outputs:** exact timestamped actor actions, content-hashed parented events, repair-session counts, and a later practical action chosen by an **authored toy rehearsal rule**. Nothing claims to infer father motive, child mental state, a clinically meaningful trait or latent disposition.
4. **Crucial no-effect controls:** father interactions can differ while the child still takes the bus in both worlds. That must remain legal. Prior protected-care practice can change father response to the *same* overtime shock. An unrelated neighbor's shift is *not* a causal parent of child action unless an actual neighbor interaction occurs.
5. **Potential falsifiers:** (i) employer workplace event depends on stolen bicycle; (ii) child reads father workplace before father receives it; (iii) child learns from action that was never enacted; (iv) children mechanically get prescribed personalities from employer outcome labels; (v) all scenarios must change the child; (vi) protected care magically creates available time without recorded work obligation displaced; (vii) independent counterpart's project is silently overwritten.
6. **External validity unanswered:** father decision procedure is an artificial material feasibility rule, `practical_bicycle_episodes>=3` is a convenience threshold, the stochastic work-category prior is nonempirical, and neither acts nor psychological uptake are calibrated. A real developmental mechanism requires independently justified learning/practice, affect, language/interpretation, and social structural constraints. This is a causal-DAG feasibility experiment, not a Rawlsing actor or psychometric validation.
