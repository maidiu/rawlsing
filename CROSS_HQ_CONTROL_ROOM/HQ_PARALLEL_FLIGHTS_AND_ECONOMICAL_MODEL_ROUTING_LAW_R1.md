## 1. Parallel flight is the default; serial only for an actual dependency

At **every fresh/resumed HQ grok, every material worker return and before every new material commission**, HQ must refresh and publish a **WHOLE-MACHINE FLIGHT BOARD**, not merely handle the most recent branch. - **ACTIVE_VERIFIED:** actual worker/session plus exact branch/runtime state established; do not reset, replace or duplicate because a cheap alternative appears.
- **PUBLISHED_NOT_LAUNCHED:** commission exists, but do not invent worker execution.
- **RETURNED_NEEDS_HQ_DECISION:** adjudicate without suspending unrelated ready work.
- **DEPENDENCY_HELD:** name the *specific required predecessor/issuer or shared writer*; dependency blocks that edge **only**.
- **RESOURCE_HELD:** identify which verified resource is exhausted/limited and keep other feasible lanes moving.

**A flight is a coordinated set of genuinely independent commissions, not a mandatory number.** Inspect at least **four distinct possible critical-path workstreams** (or enumerate every genuinely available one if fewer); usually dispatch several **READY_PARALLEL** lanes together subject to real permissions, independent reviewer separation, noncolliding write surfaces and verified capacity.
