## 1. Returns must contain interpreted scientific judgment alongside reproducible evidence

An executable return is not merely `PASS/RED + paths`. Preserve an accountable **RETURN_JUDGMENT** section, inside the ordinary existing `00_RETURN.md`:
1. **Question/claim and intended end-product consumer:** exact original promised function, current candidate and acceptance grain, upstream and downstream owner/source, person/world/actor effect.
2. **FINDINGS:** reproduced observations, exact baseline/contrast, false-positive counterexamples, independent original, current test and unresolved REDs, method/environment and source-ref custody; mark observation versus worker claim.
3. **INTERPRETATION:** *why* each material result occurred; causal/mechanism hypothesis with competing explanations, evidence for/against, where strength is limited by fixtures, sources, samples, coverage, clock or trust; what good mechanisms survived.
4. **SCIENTIFIC SIGNIFICANCE:** which scientific proposition is falsified/retained/unproven and its boundary, including law/model/provider, source-native versus sourcefree distinction, effect on legitimate alternatives, population/actor/life formation, post-hoc grammar and posterior/calibration validity if relevant. Negative tests cannot by themselves establish a positive scientific representation.
5. **ENGINEERING SIGNIFICANCE:** executed positive and dependency-severance proof, real joining consumer, operational correctness, fail-closed and held-old preimage/compatibility, source import closure, technical API fixes and implementation risks; do not substitute sourcefree grade for native acceptance.
6. **AUTHORITY SIGNIFICANCE:** named holder/issuer of each permission, existing accepted authority and missing grant, whether capability is executable but unissued, reviewer independence, exact downstream denied/allowed uses.
7. **DECISION REQUEST:** specific recommended `ACCEPT_SCOPED / REVISE / HOLD / REJECT / RETURN_REQUIRED` by distinct claim, candidate repairs versus separately competent owner adjudications, alternative positive route and limits on next action. Worker proposes; HQ/issuer decides.
8. **TERMINAL_HAND_BACK:** DONE / REMAINING / BLOCKED / CHANGED vs full product, exact receiving consumer and handoff interface, priority and cheapest qualified next actor; do not make every issue a new commission.
9. **CONFIDENCE/EVIDENCE_LACUNAE:** distinguish original facts, external report text inaccessible, known unknown, out-of-scope, not-run, user-reported, and test assertions incapable of supporting a claim.

Require machine-readable references or a compact structured summary **inside existing return**, not a second mandatory report file or new approval. Preserve author judgments alongside contradictory reviewer judgments without retroactively editing original return.
