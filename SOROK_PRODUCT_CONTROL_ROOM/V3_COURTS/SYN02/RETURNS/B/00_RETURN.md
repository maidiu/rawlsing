## 2. What changed in the architecture question

The commission's central finding is not “rewrite V3.” It is that the recovered machine is a **mixed reservoir**: persistent state, explicit ordered execution, route/trace/transaction, hysteresis, surface isolation and provenance carriers are real; the causal semantics around acquisition, impression, rupture, metabolization, memory, readiness and world/coactors are missing or wrong. The adaptation therefore proceeds by **carrier reuse + semantic replacement + explicit migration**, not by relabeling old fields.

The reconstructed machine is a layered actor/world/event architecture:

```text
C0/C8/ADP019 world + independently sourced coactor
 -> CanonicalEventV1 / EpisodeV1 / SourceEnvelope
 -> actor access/reception (ADP017)
 -> CAN008 immediate Rule A response / transient impression
 -> CAN011 durable mediator/tension/practice or NO_CHANGE
 -> next event reads semantic actor state; interval activity in between
 -> ADP016/017 retrospective actor-accessible memory/meaning
 -> one-way V2/A0–A5 surface
```

The actor is a sparse `ActorSnapshotV1` plus an append-only event ledger and typed middle-state records. Derived values are pure views. Surfaces are one-way. `FunctionalConnectionRecord` is only a candidate for SYN02-C; no automatic relation graph, Hebbian rule or all-to-all wiring is adopted.

## 8. Design-grade positive / NO_CHANGE / severed fault

These are **SPECIFICATION_ONLY** unless explicitly marked otherwise.

- **Positive:** one actor receives a source-owned E1 care/activity event with independent B and actor access; CAN008 Rule A yields an immediate response; CAN011 Rule T/NO_CHANGE yields a scoped durable record; later E2 under fixed world/B/access reads the semantic value/scope and shows a different considered response or action. No hash-only or narrator-only proof.
- **Lawful NO_CHANGE/alternative:** no later access/rule or external support-only change yields `NO_CHANGE_EVALUATED` or a separate external-support receipt, not a fabricated internal transition. Missing rule/source yields `HELD_MISSING_RULE`/`DENIED_CAUSAL_USE`, not `NO_CHANGE`.
- **Severed edge:** remove only the earned-state→E2 semantic read (or exact formation parent), holding world/B/E2/current code fixed; the semantic difference disappears or a precise missing-conditioner/integrity status appears. A different SHA is not enough.
- **Batch fault:** reverse/alter event 1 with event 2 template fixed; event 2 must read the altered actor/world/interval state or no-change; old premerge/order-invariance fails.
- **Prose-only fault:** change only the surface; new architecture must show no actor-state difference. Old active-process narrator feedback is a historical defect, not a model.
- **Malformed/unknown fault:** missing/synthetic/default legacy fields are archived/UNKNOWN/HELD; no optimistic 0/50/100 or clean-ready.
