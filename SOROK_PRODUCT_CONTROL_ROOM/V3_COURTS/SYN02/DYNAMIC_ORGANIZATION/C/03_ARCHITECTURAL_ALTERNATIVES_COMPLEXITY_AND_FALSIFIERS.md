# SYN02-C / 03 — Alternative architectures, cost, limits and hostile causal tests

**Decision grade:** recommend HYBRID CAPABILITY ENVELOPE (not a predetermined hybrid implementation) to SYN02-S after independent review. Each candidate must support coherent/stable lives, contradictorily organized lives **if historically warranted**, actor-world distributed arrangements, no-change and honest uncertainty. These are design alternatives, NOT source-executed implementations or authorized scientific laws.

## 1. Candidate A — finite existing relation topology, context gates and qualified changing values

**Representation.** Typed fixed functions/conditioners known to C9; source-qualified state fields alter which eligible existing operation is selected/expressed. Historical M21 prior grooves feed future conductance and route-induced values may influence subsequent channel choice; M11 acute/chronic, M14 topology and boundary transitions are fixed-law examples with original legacy assumptions. All exact formulae remain quarantined.

- **Operation/effects:** event→Rule A updates admitted scalar/category/history; current context/read-set determines already existing gate → actual action options/output. Persistent history influences *weights/activation of existing connections* rather than inventing them.
- **Scientific niche:** empirically indistinguishable from apparent new relation in simple cases, so should be **first null alternative** before claiming architectural creation. Stable actor with familiar practice often modeled parsimoniously.
- **Strengths:** bounded state/easy serialization, deterministic replay under qualified source, simple provenance of read-sets, lower overfitting, readily reuses existing V3 route/value code after scientific repairs.
- **Limit:** cannot represent a *genuinely novel* operation, operand pairing or compositional function without predeclaring every future possibility or embedding unknown distinctions in opaque scalars. Unbounded universal fixed gates merely conceal the dynamic relation problem in a large static enumeration.
- **Falsifier:** demonstrate a new domain-specific operation/relation whose semantic inputs/outputs are not expressible as any existing gate/value change, under identical objective context and endpoint values. Do not claim this from different prose.
- **Implementation disposition:** REUSE/adapt historical routing computation *as technique*; remove universal scores, single-winner and auto-seeding as psychology. COMPETENT CAN008/C9 semantic reader needed, not granted.

## 2. Candidate B — sparse dynamically created, context-qualified, actor-owned typed functional relation records

**Representation.** Only a source-qualified historically acquired relation is stored, with endpoints, direction/mode, valid activity/scope, original formation rule, causal event and provenance, active/dormant/inhibited states, alternative explanations, later use. A typed sparse index enables event-local retrieval.

- **Operation/effects:** person×event response and independent Rule T qualify creation of \`RECRUITS(A,B)\`, \`INHIBITS(A,B)\`, \`TRANSFORMS_OUTPUT(A,B)\` or other owner-defined types. A later event reads relation semantics to constrain eligible operations; unused edges are not automatically active. A new edge is not formed merely because A and B co-occur.
- **Strengths:** directly records individual-specific historical structure, contradictory context-dependent pathways, successor revisions and dormancy; clear sever-only-edge faults.
- **Limit:** naive “everything psychologically relevant is a node” creates category errors and explosion. New state-kind authority needed if CAN011 v1 role/payload cannot legally represent it. Multiple distinct edges often reflect one learned practice/procedure more parsimoniously; graph is **not** a neurophysiological interpretation.
- **Falsifier:** held endpoints, source, support and qualified contextual read-set produce no change when edge severed; or preexisting gate explains full behavior just as well. A changed graph hash absent C9 semantic read is failure.
- **Implementation disposition:** CREATE sparse relation registry/index **only if** competent owner finds procedure/state projection insufficient; first attempt CAN011 v1 typed mediator/practice representation under original semantic review. No new V3MS_RELATION by investigator fiat.

## 3. Candidate C — historically composed practical and conceptual procedures

**Representation.** Actor-acquired operation compositions: ordered/conditional recipes for attending, acting, recollecting, interpreting, asking for assistance, coordinating with a real other, and checking outcomes. Named suboperations, dependencies, preconditions, practical object and evidence are versioned; a *new composed capability* is not multiplied into all pairwise edges.

- **Operation/effects:** a source-qualified teaching episode or practice formation yields an operation such as “when faced with unfamiliar work, ask another for a worked example, compare it against the task, retry autonomously”; this may recruit discomfort regulation, goal memory and planning only as permitted by actual domain semantics.
- **Strengths:** matches Leontiev activity/goal/operation distinction, Luria historical organization by language, Sève acquired capabilities and their actual use; natural n-ary joint behavior, inhibition/sequence, comprehension from a single sign. Reuse via composition reduces graph size. Enables stable coherent organization.
- **Limit:** can become a huge list of idiosyncratic scripts or a story-planner if formal input/output semantics and external-world feasibility are absent. Harder to represent diffuse simultaneous competing pressures or reversible interaction if reduced to fixed step chains; cycles need owner-bounded semantics.
- **Falsifier:** later performance seems due to new procedure but is entirely generated by teacher at E2 (scaffold) or a fixed preexisting strategy. Remove teacher/tool with other conditions appropriate; actor independently performs or not. Also test different opportunities where procedure should NOT transfer.
- **Implementation disposition:** ADAPT V3 operation/computation reuse, CREATE owner-governed composition records and calls where required. May live in approved CAN011 V3MS_PRACTICE, but meaning/transition issued separately.

## 4. Candidate D — situated distributed actor-world functional configurations

**Representation.** A contextual dependency configuration identifies the actor, the particular activity object, real tools, institution, other independently acting people and actor-owned component abilities. Joint actions/capabilities emerge through actual availability without being entirely stored as a private psyche edge.

- **Operation/effects:** a person can accomplish a previously impossible task because of an aunt's assistance, working hours, a new material tool, cooperative co-worker or altered institutional access. Some later action may acquire an internalized practice, but **external enablement is not automatically internal learning**.
- **Strengths:** faithful to Dreier translocal participation, Elder changing household roles, Archer actual structural enablement, historically material social reproduction. Prevents fabricating “caregiving feeling” from aggregate money or “B desire” from narrator.
- **Limit:** a strictly situation-only explanation cannot represent persistently transformed individual capabilities retained and used when context changes. Dependence on a huge world graph, continual retrieval of other actors, and unclear world/actor ownership can be expensive.
- **Falsifier:** after objective aid is removed and other conditions fixed, actor retains and deploys a qualified new procedure: situation-only model incomplete. Conversely, if outcome disappears with tool and there is no qualified retained ability, private graph claim not warranted.
- **Implementation disposition:** REUSE C4/C8/world/ADP019/SDTF original source and actual B owner where qualified; CREATE event-level configurations; do not duplicate the coactor's psyche in A or write world changes from A's internal state.

## 5. Candidate E — multi-representation hybrid (provisional preferred *capability*, not enforced individual graph)

A practical architecture can maintain **(i)** ordinary owner-issued operation outputs and changing values, **(ii)** sparse qualified conditional relation records only when necessary, **(iii)** named contextual composed procedures, and **(iv)** real actor-world activity configurations. The **actual person owns only what has genuinely formed**; the world and other actors separately own tools, participation and action. The explanation can therefore remain entirely fixed-gate or external-support where facts warrant; the hybrid is a *type-capability ceiling*, not a command that every person's state contain all four.

**Candidate selection by parsimony and evidence (not fit to a target biography):**
1. Check whether world/coactor change alone explains outcome.
2. Check existing context gate and eligible fixed operation values.
3. Check new context-specific use of an already acquired operation.
4. Check qualification for genuinely learned composed operation.
5. Only if necessary, propose new typed relation/scope update, with exact source and owner decision.
6. When two representations are observationally equivalent, retain a marked ambiguity/model-choice with no invented definitive psychological claim. Do not assume higher complexity always means better personhood.

**A failure of A is not automatically proof of B.** A might fail due to a missing operation (C) or genuine distributed support (D). The burden of proving a new edge persists after controlling those possibilities. Domain authorities may prefer one stable representation in a constrained subsystem without adopting the full hybrid.

## 6. Complexity, boundedness and observability

Let O = number of *qualified person-owned operation identities* potentially relevant to this actor; E = number of **admitted sparse relations**; P = number of composed procedures; L = total component references/steps in all such procedures; W = world/coactor refs needed by current qualified activity; H = committed actor/event timeline receipts.

| Criterion | Static gated A | Sparse relations B | Compositions C | Distributed D / conditional E |
|---|---|---|---|---|
| Space (gross conceptual) | O + fixed gate count G + values; potentially G~O² if universal map | O+E; unbounded all-to-all degenerates E~O² | O+P+L; procedure cross-products can also explode if unconstrained | O+W + actual local config; E adds only qualified actor edges in hybrid |
| Event evaluation | Qualified current read-set against fixed G; not necessarily loop all O | Indexed relation candidates by typed endpoint/context, not scan all E unless needed | Execute only eligible named procedure components; may require bounded dependency resolution | Check actual world and B with source, then only eligible actor operations; external owner calls cost is independent |
| Formation | Value/gate update, no new topology | Rule-qualified addition/successor, replay and referential integrity | New versioned compositional operation, context/scope | No actor formation required for support-only; actual use may later form under separate Rule T |
| Risks | Too rigid; huge predeclared universal gates hide complexity | False-positive edges; identity/lineage proliferation; graph cycles | Script/story overfit; unlimited branching/combinatorial tasks | State ownership confusion, coactor provenance, nonlocal cache freshness, world simulation cost |
| Actual observability | Fixed read-set/value traced | Edge visible and later semantic read/effect traced | Procedure invocation and component outputs traced | Objective support and independently sourced other-actor action audited |

**Bound proposed engineering, NOT human science**: instantiate only refs demanded by a legitimate current operation/qualified history; type-check endpoints, require source/owner and scope; index sparse by activity/actor; avoid all-pairs materialization; deduplicate proposals with identity+lineage; cap work by general resource/process integrity policy rather than issuing a **psychological threshold**; handle cycles as explicit owner-resolved dependency class; preserve valid empty; maintain retention/archival retrieval without proactive universal decay; checkpoint only changed admitted actor-owned records. Event-local upper resource limits are engineering safeguards, not truth about human learning frequency.

**False positives dominate if over-flexible.** If a generator may create an arbitrary edge for each apparent difference in one character's story, it can fit any biography, resist falsification and magnify tiny narrated changes into self-reinforcing psyche. Demand disconfirmable alternatives and **held equality comparisons**; independently review any new allowed endpoint/mode. More representation does not necessarily yield richer valid causality.

**Contradiction without chaos:** coexisting relations scoped to different objects/practices/people may be nonconflicting; genuinely competing current motivations can constrain each other; a stable actor need not have an arbitrarily fixed globally dominant state. When multiple qualified relations are simultaneously eligible, the actual original C9 response rule owns joint evaluation, not a blanket highest-score winner nor a free-flowing unbounded recursive “cognitive network.”

**Dormancy vs loss:** actor may have retained ability but no practice context, may lose tool but retain procedure, may lose current accessible episodic memory but retain nondeclarative trace, may acquire a different operation that supersedes one method, or may genuinely no longer be capable. Each requires different receipts; no universal time-decay law. The source owner's negative counterexample is as important as a positive.

**Potential metaplasticity:** a learning-to-learn procedure can alter later ability to take up instruction or organize practice, but the seductive neural word “metaplasticity” is not a license to store an actor-wide adaptive gain, elasticity scalar or every-edge tunability. Require actual historical access, meta-procedure use and qualification; leave as SCIENCE HYPOTHESIS otherwise.
