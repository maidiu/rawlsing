## 2. Actual behavior

- `count_seed = (year*31 + int(money) + int(alienation)) & 0x7fffffff`; `n_events = count_seed % (max_events+1)` — 0–3 default.
- Each event kind is `seed % 13`, selecting frameworks, domains, cracks, practice, field, infrastructure, coherence, topology/boundary, style deltas. `source="pseudo_random_mechanical"`; `conditioning_inputs` record year/slot/seed/capacity/job/alienation/stability/insulation.
- No actor access, no other actor, no relationship, no actual activity, no source-owner event identity, no causal parent; event IDs are `event_{year}_{slot}_{seed}`.
- The sampler overwrites `state.events_this_year`; it does not mutate domains/peak routing (architecture test).
- A 0-event year is possible; `run_one_year` still executes all annual steps, age/year increment and pressure flow. There is no typed no-event/continuity record.
- Events are consumed by later annual steps (field, reproduction, capacity, buffers, frameworks, domains, cracks, etc.); event types do not carry actor meaning.
- `apply_puncture_counters` reads event `puncture`/`implicated_domains`; these are not generated by `_one_event`, so this path is effectively dormant for mechanical events.

## 3. N06/N11 differential

N06 needs actual ordinary activity, time-use, co-care, no-encounter and social reproduction. N11 needs conditional, concrete, causally sufficient events with independent coactors and intervening life. M33 provides:
- deterministic event IDs/serialization and a few conditioning inputs (reusable infrastructure);
- generic random deltas with no lived source, actor, relationship, access or consequence semantics.

**Coverage:** `REPLACE` for event causality; retain event record shell/IDs/conditioning blocks as serialization template; create source-grounded event/interval/coactor realization.
