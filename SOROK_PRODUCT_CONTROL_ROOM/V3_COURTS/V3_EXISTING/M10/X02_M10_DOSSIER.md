## Actual behavior

Buffer strengths/costs are real data structures and annual updates, but in the normal identity path `state.buffers` is empty. `update_buffers` no-ops without buffers. If buffers exist, strength only pays costs into material capacity; strength is not used to inhibit charge, select a channel, or reduce trace. `compute_insulation_score` is top-3 buffer strength + money and affects **readouts** (vitality profile, insulation labels, stability/autonomy elsewhere) but not the pressure-flow route. Reviewer probe: buffer strength 0 vs 100 with zero cost profiles leaves current charge, conductance and trace identical.

## Differential

N02/N04/N07/N08 require regulation as **activity with resources, support, relation, cost, timing and possible failure**; caregiver repair can stabilize without resetting the event. Old code has:
- a cost-accounting record and a top-3 scalar index;
- no source of buffers from care/activity/relationship;
- no relationship or timing/scope;
- no route-level inhibitory effect;
- no repair operator;
- labels (`buffer_type`) that map to insulation modes but are not generated by actual support.

**Coverage:** `INFRASTRUCTURE_ONLY` — data structures/cost accounting and labels; not the required regulatory mechanism.

## Dispositions

- **Retain:** resource/cost accounting as a candidate; `Buffer` as a typed record; cost caps.
- **Adapt:** generate buffers from actual routines/support/relationships; add activity, timing, access, failure and repair; make strength causally inhibit/route only under an issued rule; distinguish resilience from cost.
- **Replace:** top-3 scalar as “insulation” psychological claim; empty-buffer default as if regulation existed; cost-only model.
- **Create:** relational/activity regulation operators; support withdrawal/repair transitions; owner-issued thresholds. No new coefficient proposed.

## Falsifiers / limits

- If buffer strength is claimed to reduce current charge/route, source shows no such read; reviewer probe identical.
- If insulation score is claimed to be a regulatory gate in pressure flow, it is only a readout input to vitality/insulation metadata.
- If standard identity development is claimed to produce buffers, no seeding path was found; `state.buffers` defaults empty.
