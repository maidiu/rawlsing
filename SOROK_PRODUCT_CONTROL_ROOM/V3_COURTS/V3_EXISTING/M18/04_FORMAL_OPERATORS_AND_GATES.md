## No-effect and alternative explanations

- **No-effect:** no relevant generated/admitted episode, no actor access, no support, no rule, or an explicit unrelated/benign exception. State remains unchanged; `NO_CHANGE` is a complete outcome, not a failure.
- **Alternative A:** the observed behavior is current situated action, not a durable stored state. A correct model must be able to return this.
- **Alternative B:** the behavior is a narrative/analyst description, not a causal psychological operation. Rendered prose cannot become a causal input merely because it contains a keyword.
- **Alternative C:** contradictory records coexist; no dominant winner, midpoint, or scalar merge is required.
- **Alternative D:** missing historical evidence is unknown, not `0`, `50`, neutral, hopeful, or average.

## Discriminating cases

**Positive:** Two actors receive the same objective event; only one has the specific prior basis; only that actor admits a rupture (or the other has a lawful different outcome). A later matching event may reactivate; a benign exception does not.

**Genuine NO_CHANGE / continuity:** Same event but no prior basis, no access, or successful repair; no rupture record, or a different declared outcome. An unrelated strong event does not force rupture.

**Hostile alternative:** Age 14/24/30 band; intensity=malheur without basis; one adverse label; global RNG; direct wound bump; LLM proposal alone.

**Source-edge fault / falsifier:** Hold objective event and later scene fixed; sever only the actor-specific rupture basis or admission receipt. A correct system must change admission/status or return valid-empty. The old age path cannot pass because age alone triggers; the event path cannot pass because it has no wound/target rule.
