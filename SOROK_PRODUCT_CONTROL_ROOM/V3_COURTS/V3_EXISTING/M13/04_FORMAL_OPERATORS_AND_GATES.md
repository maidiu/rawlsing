## Causal preconditions and operation families

- A practice is a historically acquired, repeatable, object-mediated activity with actual episodes, social support, context, and scope.
- Acquisition/reinforcement requires effective activity and support; exposure/opportunity/label alone is insufficient.
- Maintenance, transfer, loss of support, interruption, and relinquishment must be representable without guaranteed decay or mastery.
- Multiple practices may coexist; no dominant-practice rule or fixed six-axis ontology is required.
- No SES/age/religion direct seed; valid-empty practice set is lawful.

The operation families to consider are `CREATE`, `REINFORCE`, `TRANSFORM`, `SET_DORMANT`, `REACTIVATE`, `END`, and `NO_CHANGE`, but the names supply no semantics. The owner must define what qualifies as an episode, support, contradiction, use, or loss, and what the first real consumer reads.

## No-effect and alternative explanations

- **No-effect:** no relevant generated/admitted episode, no actor access, no support, no rule, or an explicit unrelated/benign exception. State remains unchanged; `NO_CHANGE` is a complete outcome, not a failure.
- **Alternative A:** the observed behavior is current situated action, not a durable stored state. A correct model must be able to return this.
- **Alternative B:** the behavior is a narrative/analyst description, not a causal psychological operation. Rendered prose cannot become a causal input merely because it contains a keyword.
- **Alternative C:** contradictory records coexist; no dominant winner, midpoint, or scalar merge is required.
- **Alternative D:** missing historical evidence is unknown, not `0`, `50`, neutral, hopeful, or average.

## Discriminating cases

**Positive:** Actor repeatedly performs supported care work or organizing with actual materials and recognition; a later comparable situation shows a supported practice difference; a same-age/demographic actor without those episodes does not.

**Genuine NO_CHANGE / continuity:** No supported episodes; no practice change. Existing practice may persist as a projection, but no hidden gain from a label or age.

**Hostile alternative:** High SES/age seed; one `practice` event label; a mentor label; a routed psychic charge; a high scalar without an activity history.

**Source-edge fault / falsifier:** Hold actor, event, and later scene fixed; sever the actual activity/support edge. A correct system must change the practice result or return NO_CHANGE. The old code cannot pass because the value is already seeded and labels/routes mutate it.
