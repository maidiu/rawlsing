## Findings

- **FINDING:** The operator path is real. `update_framework_weights` chooses `chronic_delta` when `half_life_years > 0` and `tenure_years >= half_life_years`, otherwise `acute_delta`; effective delta is `raw_delta * (weight/100) * 0.3`, capped at ±2 per field per year. The probe on a synthetic weight-100 framework showed binding +1.5 in years 1–2, then −1.5 in year 3 after the half-life switch.
- **FINDING:** Frameworks are not acquired. They are seeded from religion, religiosity, SES, minority status, and age. Age sets `tenure_years` directly: a 40-year-old middle/dominant persona starts with meritocracy tenure 34 and institutional-trust tenure 32, so both are already chronic at first update. A 35-year-old religious/working/minoritized persona starts with age-based tenures and may be acute or chronic by arithmetic, not by lived duration of an acquired commitment.
- **FINDING:** Event changes are positional: `framework_deltas[i]` changes `state.frameworks[i]`; there is no stable framework ID in the event. No path creates a new framework from instruction, participation, conversion, contradiction, or social use; no path reactivates a dormant framework.
- **FINDING:** `failure_mode`, `enemy_requirement`, and `institutional_affinities` are stored but not read by the update or by the domain step. `framework_switch_sensitivity` only changes the event-delta cap; it does not select, switch, or acquire a framework.
- **FINDING:** `enforce_framework_caps` moves any weight<5 framework to a dormant dict and caps that list at 10. There is no active-count enforcement of the declared `max_active=6`, no reactivation, and dormant entries are not full Framework objects.
- **FINDING:** The step-order `domains_update` description says it uses frameworks, insulation, intensity, and practices; the actual `update_domains` applies only event `domain_deltas`. A probe with identical events but framework weight 5/practice 5 versus 95/95 produced exactly the same A=28, V=5, S=0, Aim=0 domains.

- **ENGINEERING RED:** A framework is an age/class/religion-derived recipe, not a historically acquired and used concept.
- **ENGINEERING RED:** Tenure is inferred from chronological age at initialization, producing an already-chronic adult stance.
- **ENGINEERING RED:** No acquisition, instruction, participation, scope, conflicting framework, use, dormancy/reactivation rule, or domain consumer exists.
- **ENGINEERING RED:** The domain step ignores frameworks, so the stated metabolic influence on A/S/V/Aim is absent even though capacity effects exist.
