## Discriminating cases

**Positive:** Actor actually receives instruction or participates in a practice community; a later relevant situation recruits the acquired framework; a second actor with the same age/demographic but no exposure does not.

**Genuine NO_CHANGE / continuity:** No acquisition or use; no framework mutation, or lawful persistence of an existing framework without reinforcement.

**Hostile alternative:** Religion -> devout frame; working class -> survival frame; age 40 -> chronic; high weight alone; same label but no acquired operation; framework dormant -> automatically reactivated.
