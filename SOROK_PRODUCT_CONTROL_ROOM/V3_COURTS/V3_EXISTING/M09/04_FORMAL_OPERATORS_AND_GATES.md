## Causal preconditions and operation families

- A contradiction must be linked to actual episodes in which the actor encountered incompatible demands, care, recognition, threat, or practical impossibility.
- Scope and support matter: the same contradiction may be active in one relation/domain and quiescent in another.
- Lifecycle requires evidence: formation, activation, intensification, deactivation, dormancy/latent preservation, reactivation, and possible resolution/transformation. None is mandatory from age or a count.
- Filler cracks, demographic seeds, and a universal minimum are invalid; `VALID_EMPTY_TENSION_SET` is lawful.
- A crack is not automatically pathology, trauma, or a conscious belief; it is not a generic negative event label.

The operation families to consider are `CREATE`, `REINFORCE`, `TRANSFORM`, `SET_DORMANT`, `REACTIVATE`, `END`, and `NO_CHANGE`, but the names supply no semantics. The owner must define what qualifies as an episode, support, contradiction, use, or loss, and what the first real consumer reads.

## No-effect and alternative explanations

- **No-effect:** no relevant generated/admitted episode, no actor access, no support, no rule, or an explicit unrelated/benign exception. State remains unchanged; `NO_CHANGE` is a complete outcome, not a failure.
- **Alternative A:** the observed behavior is current situated action, not a durable stored state. A correct model must be able to return this.
- **Alternative B:** the behavior is a narrative/analyst description, not a causal psychological operation. Rendered prose cannot become a causal input merely because it contains a keyword.
- **Alternative C:** contradictory records coexist; no dominant winner, midpoint, or scalar merge is required.
- **Alternative D:** missing historical evidence is unknown, not `0`, `50`, neutral, hopeful, or average.

## Discriminating cases

**Positive:** Actor has an actual, repeated contradiction between care and material necessity; a later scoped episode activates only that tension; an unrelated domain episode does not.

**Genuine NO_CHANGE / continuity:** Actor has no relevant contradiction or episode; no tension record is created, and an existing unrelated orientation remains unchanged.

**Hostile alternative:** Religious/working/minoritized/young identity alone; a high structural-pressure score; one generic adverse label; a fourth active crack; a placeholder count. None establishes a contradiction.

**Source-edge fault / falsifier:** Hold actor, world, later episode, and source edge fixed. Create an actual contradiction history and remove it; a correct consumer must show a scoped difference. Replace the contradiction episode with a same-label but non-contradictory event; a correct system must yield NO_CHANGE or a different explicit outcome. The old code cannot distinguish these because it uses identity presets, placeholders, and event deltas.
