## No-effect and alternative explanations

- **No-effect:** no relevant generated/admitted episode, no actor access, no support, no rule, or an explicit unrelated/benign exception. State remains unchanged; `NO_CHANGE` is a complete outcome, not a failure.
- **Alternative A:** the observed behavior is current situated action, not a durable stored state. A correct model must be able to return this.
- **Alternative B:** the behavior is a narrative/analyst description, not a causal psychological operation. Rendered prose cannot become a causal input merely because it contains a keyword.

## Discriminating cases

**Positive:** Actual supported participation in a practice/relation makes an object actionable and recognized; a later relevant opportunity recruits it; an actor of the same age without that participation does not.

**Genuine NO_CHANGE / continuity:** No object/activity/support; no striving created, or an existing object persists without a new formation. A forbidden/imposed target may be represented without becoming a wish.

**Hostile alternative:** Age 14 bracket; forbidden/hopeless baseline -> proxy map; one label; random feasibility/support; retirement probability; high investment alone.

**Source-edge fault / falsifier:** Hold actor and later event fixed; sever only the activity/support/recognition edge. A correct system must change object formation/action or return NO_CHANGE. The old code cannot pass because the same age/baseline yields a map object with random support.
