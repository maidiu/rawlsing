- Represent activation, inhibition, recruitment, and cross-links among interdependent motives/relations under conditions, with scope and support.
- Allow multiple contradictory configurations and persistence; no single winning global topology is required.

## No-effect and alternative explanations

- **No-effect:** no relevant generated/admitted episode, no actor access, no support, no rule, or an explicit unrelated/benign exception. State remains unchanged; `NO_CHANGE` is a complete outcome, not a failure.
- **Alternative A:** the observed behavior is current situated action, not a durable stored state. A correct model must be able to return this.
- **Alternative B:** the behavior is a narrative/analyst description, not a causal psychological operation. Rendered prose cannot become a causal input merely because it contains a keyword.
- **Alternative C:** contradictory records coexist; no dominant winner, midpoint, or scalar merge is required.
- **Alternative D:** missing historical evidence is unknown, not `0`, `50`, neutral, hopeful, or average.

## Discriminating cases

**Positive:** Two time points show an actual relational change (support/recruitment/inhibition) that alters a later same-person response; the transition is scoped to the relationship and preserved as history.

**Genuine NO_CHANGE / continuity:** Scalar conditions change but no relation/action changes; the configuration stays the same; no event is received; NO_CHANGE is lawful.

**Hostile alternative:** Network density 60 + organizing 60 alone = reciprocal; one boundary-label event; repression scalar; high coherence alone; age/type scene preset.

**Source-edge fault / falsifier:** Hold actor and later event fixed; vary only an actual relation/participation edge. A correct system must show a scoped configuration/response difference or NO_CHANGE. A scalar threshold alone cannot distinguish that from a fixed regime switch.
