## 5. Temporal, atomicity and recursion rules

1. **Chronological commit:** `snapshot_0 -> E1 -> response1 -> interval1 -> E2 -> response2 ... -> En -> interval_terminal -> snapshot_end`; all effective times monotone under the owner scheduler, but a proposal might be rejected, re-timed or converted to an explicit nonoccurrence. Do not silently shuffle specs, invent missing encounters or claim event 3 caused event 1's original response.
2. **Dependent state reads:** E(k+1) reads the actual after-interval person/world state after E(k) and its qualified causal updates. This is the only way the batch is developmental rather than 3–5 independently simulated anecdotes. Exact prestate/poststate hashes plus semantic field reads must be proved, not only event count.
3. **No generic LLM call inside batch:** source-admitted stochasticity and qualified deterministic algorithms may run; owner-only machinery can refuse or defer. Missing Rule A/T, no B performer, memory/actor/transport integrity failure are **HOLD/REFUSE**, never fallback-generated psychology.
4. **Fail-closed transaction:** partial prefix is a real committed prefix if atomicity is designed that way. A failed E(k) cannot leave unreceipted intermediate actor changes or permit later E(k+1) to run against a snapshot that falsely claims success. Historic RX02 reports some pre-route writes outside route-object rollback; do not import that behavior unquestioned. Dedicated C12 transactional policy remains separately owned.
5. **Later significance without time travel:** an event's later *meaning* may change when a source-qualified E3 or post-batch reflective act generates a new stance. Store `reinterpretation_at_t3(parent_ref=E1)` as a new event/stance, not mutate objective E1, replace infant's original impression or pretend infant had adult language.
6. **Retrospective limited view:** call N+1 receives ordered trajectory **for analytic verification/selection of actor-safe fields**, but actual model first-person input must be ADP016/ADP017 constrained. Without actor-safe envelope, `ACTOR_ACCESS_HOLD`; giving it analyst-only contents and instructing 'don't mention them' is not sufficient.
7. **No automatic narrative → state:** retrospective half outputs expression and separately typed candidate future self-interpretation. Only a competent SCI05/internal-event and CAN011/ADP017 owner can commit resulting causal change, with later effective time and receipt; otherwise display-only or HELD.
8. **Same-call causality caveat:** if call N+1 is a *single uninterrupted LLM generation*, Rawlsing cannot in general inspect and admit a free-form retrospective internal-act result **mid-generation** before the model writes the prospective second half. Thus no unsupported assertion that the latter half's model tokens were conditioned on a just-approved internal act. Two lawful options *within the settled single-call boundary*: (a) the latter half offers explicitly conditional event possibilities, and **Rawlsing validates them against the post-retrospection actual state before resolution**, or (b) future tool-mediated/streaming interleaving only if independently proved available and user-authorized, with no ordinary extra model call. Default specification is (a). Proposals are *not* already realized consequences.
9. **Bootstrap / terminal / replay:** bootstrap no invented prior batch; terminal no mandatory next batch; replay fixed exact authoritative source order/canonical parent hashes/stochastic receipts/clock reproduces committed realized trajectory. LLM text may vary if not exactly pinned, but only previously authorized admitted state is replay-authoritative.
10. **3–5 error modes:** `BATCH_COUNT_OUTSIDE_RANGE`, `NO_SOURCE_OWNER`, `COACTOR_RIGHTS_MISSING`, `EVENT_PROPOSAL_NOT_CAUSAL_FACT`, `PRESTATE_HASH_MISMATCH`, `TIME_ORDER_CONFLICT`, `RULE_A_MISSING`, `RULE_T_MISSING`, `ACTOR_MEMORY_SOURCE_UNAVAILABLE`, `ACTOR_CLAIM_PERMISSION_MISSING`, `SCI05_INTERNAL_ACT_HOLD`, `RENDER_CAUSAL_MUTATION`, `PARTIAL_PREFIX`, `C12_NATIVE_NOT_PROVED`.
