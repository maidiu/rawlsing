Log date, exact SHA, source and person/consumer grain; UNKNOWN is not ABSENT.

## Per-folder deepening files, create only with actual evidence
01_DIRECT_SOURCE_MAP.md — source revision/blob, line-level function/class/input/output, caller/callee, mutation, parameters/formulae, tests.
02_PHENOMENON_AND_CAUSAL_CLAIMS.md — what human phenomenon the code says it models, conceptual weakness, primary literature, competing interpretation.
03_DIFFERENTIAL_REQUIREMENTS.md — existing true/false/unknown vs needed, exact old/new code path, missing operations and native owner.
04_FORMAL_OPERATORS_AND_GATES.md — explicit causal preconditions, typed relations, no-effect, rival alternatives, support/context, no arbitrary coefficient.
05_IMPLEMENTATION_PLAN_AND_SEAM.md — precise retained/adapted/new functions, call edge, input, output, falsifier, scope/perms.
06_COURT_RETURN.md — immutable remote SHA, findings/interpretations/HQ actions/owners, evidence grades, tests actual vs NOT_RUN, limitations.
07_REVISIONS/ — later independent deepening, including adverse interpretations, never silent overwrite.

## Independent reviewer
Source/call behavior must be independently challenged against exact return SHA. Theoretical adequacy differs from literal implementation. A green synthetic test cannot issue CAN008/CAN011 or discover an actual human developmental law. Original source permits may not be inferred from branch existence.

## Terminal demands per claimed new function
C12-backward current consumer, input→operation→typed output, a lawful positive, an alternative/NO_CHANGE and an actually falsifying severed upstream source edge. Sourcefree and native evidentiary grades separate. Preserve objective world event, actor-access, felt impression, memory, reflection, expression. A recorded story is not actor psychological development.

Authors have exclusive write terrain; author does not self-review/adopt or modify top-level atlas. Independent reviewer and competent owner disposition required.
