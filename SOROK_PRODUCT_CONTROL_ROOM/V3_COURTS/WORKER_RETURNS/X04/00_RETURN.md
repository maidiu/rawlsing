## 3. Actual scheduler and LLM dataflow

### 3.1 Annual spine

`run_one_year` (`yearly_step.py:12-99`) executes the configured steps (19 core ids; 20 actual with `active_magnets_update`), clamps after each, checks top-level/step-local derived declarations, copies scheduled derived fields, resets yearly integrity/micro trace, increments `year/age` **after** the steps, then runs `run_pressure_flow_cycle`. `render_layer` (`phenomenology.render_year` without packet) is the 19th core step, before `active_magnets_update` and before age increment. `run_n_years` loops years only.

The server/runner then calls `run_llm_band_year` at selected ages **after** `run_one_year` (`server/generation/simulation.py:538-549`; `v3/run_and_print.py:123,130-139`). The LLM band:

```text
state_summary -> Pass1 LLM -> CandidatePacket
 -> parse (fallback if empty) -> score/select
 -> delta_from_event/magnet for all selected
 -> merge_deltas -> apply_deltas_to_state (all at once)
 -> compute_all_derived
 -> build_render_packet -> Pass2 LLM -> render_year -> rendered_output
```

Selected LLM events are **not** appended to `state.events_this_year`; the server's `year_record.event_ledger` remains the mechanical event sampler list, while LLM selections appear only in `llm_band_ledger`. The band mutates capacity/domains/wounds/practice and may create shards/ruptures; it is not render-only.

### 3.2 Mechanical sampler

`sample_events` (`event_engine.py:127-155`) overwrites `events_this_year` with 0–3 generic events. `_pseudo_seed` uses year/slot/money/time/job insecurity/alienation; `_one_event` picks one of 13 generic kinds and writes small deltas. There is no participant, access, source-owner event identity, causal parent, interval or coactor. A 0-event year still runs all steps, increments age/year and pressure flow.

### 3.3 Selection/application

`score_event_candidate` uses fixed weights and soft fit scores (age/channel/salience/hostage/capacity/wound/boundary/rupture assumption); no hard admissibility. `select_candidates` picks up to 2 major, 2 minor, 1 surprise (10% `rng.random()`), no hard threshold; `rng` defaults to a new `random.Random()`, and server/run-and-print pass unseeded `random.Random()`. If selection yields nothing, first candidate is forced. `delta_from_event` maps kind/intensity/offers/hooks to fixed numbers; `merge_deltas` sums; `apply_deltas_to_state` applies all at once. The old band thus **premerges arbitrary psychological deltas before any actor-level sequential computation**.

### 3.4 Pass 2

`render_year` (`phenomenology.py:55-160`) sets only `rendered_output` and never backbone fields; test `test_llm_no_backbone_mutation` and reviewer probe confirm `backbone_hash` unchanged. It parses/validates, can make a corrective **retry LLM call**, and falls back to `[This year had no recorded scene.]`. `run_llm_band_year` is not render-only because it applies deltas before Pass 2. `persona_sheet`/V2 consumes the surface; no C9/C12 semantic state consumer.

### 3.5 Structural years, derived schedule and rupture

- Non-LLM server years set `structural_placeholder_used=True`; significant deltas produce an annotation scene (`server...:554-575`). The annotation lacks `[Structural year]`; `persona_sheet.real_scenes` filters markers but the `elif scene` fallback and `_previous_scene` do not filter annotations; distillation filters only markers. The card's “stubs are quarantined” is too strong.
- `compute_all_derived` writes `state.metabolic_style` and `state.registers`; `_compute_derived_after_step` can trigger this at scheduled steps. The fail-fast equality is real; the “no derived in backbone” check only covers a fixed six-name set. This is a stored/derived violation.
- `maybe_inject_rupture_at_band_age` (`metabolization_effects.py:273-332`) uses exact band ages/probabilities and module-global `random` to create rupture shards/processes and directly mutate wounds, outside the annual event ledger; it runs after `run_one_year` and before the band. `create_rupture_shard_from_event` has no canonical event parentage either.
