## 4. Cross-mechanism factual findings

1. **Fixed historical transitions are real only in part.** The framework acute→chronic switch, topology consecutive-year hysteresis, boundary one-step reversal gate, and holding-drain arithmetic are actual code. The metabolization status ladder, rupture admission, crack activation, practice acquisition, and relation-edge change are not.
2. **Scheduled age/demographic/scene presets are widespread.** Cracks and frameworks are seeded from religion/SES/minority/age; practices are seeded from SES/age/religiosity; strivings spawn by age and static proxy map; ruptures inject by age band. These are not historically acquired capacities.
3. **The strongest fixed regime switch is not a learned relation.** Frameworks can switch from acute to chronic by age-derived tenure; topology can switch after two scalar-threshold years; boundary can move one step after a label/shock. None creates a new relation edge. This preserves RX02’s correction: route value changes can alter later channel selection, grooves alone increase conductance, and fixed topology/framework switches exist, but they do not prove newly learned coupling.
4. **The source frequently applies values without the required support/history.** Practice changes from SES/age, labels, magnets, or routed psychic charge; strivings get random feasibility/support; narration support is scraped from rendered prose; rupture severity becomes a wound increment. The actor’s actual activity, access, care, recognition, and relation are not the input.
5. **The step-order contract overstates the implementation.** `domains_update` declares frameworks, insulation, intensity, and practices as inputs, but `update_domains` applies only event `domain_deltas`. `practice_and_infrastructure_update` declares cracks/field/mis-aim, but the practice body reads only events. `striving_update` says it updates from baseline/age, not actual activity. `plasticity` says it derives support from narrators, but narrators are never set.
6. **Metabolization status vocabulary is not a lifecycle.** All generated processes remain `"raw"`. No read code writes `working`, `provisionally_narrated`, `integrated`, `sealed`, or `chronic`; IRR and `intrusive_return_rate_prev` never change; `narrators`, `provisional_frame`, `meaning_attempts`, `reactivation_triggers`, `sealed_candidate_years`, and `post_plasticity_years` are never populated.
7. **Rendered narrative is causally wired back into the psyche.** `_analyze_narrative_for_support_quality` scores `state.rendered_output` text for accuracy/warmth/coercion; `narration_support` then modulates metabolization deltas. This violates the source’s own render-only contract and CAN_012’s boundary. In the probe, a warm scene changed warmth 20→30 and aperture 54→55 relative to neutral prose for a fixed process.
8. **Rupture paths contradict each other.** The event/LLM path creates a shard/process but does not bump wounds. 3. **How do prior experiences modify the next event?** They enter through stored scalar capacities, event deltas, a fixed topology/framework regime, and (for old pressure-flow) value-mediated route selection. They do not create a durable new relation edge. Grooves alone change conductance, not channel selection; route values can change later selection. Delayed metabolization is declared but not implemented; repair is not a distinct operation.

Neither proves a newly learned relation. The M14/00 findings do not call a scalar regime change a learned relation.
5. **RS correction?** Preserved. Motives are formed in real activity; plurality is contingent, not universal; latent dispositions require formation evidence; language/instruction can create an operation in some circumstances. The old age/proxy/random machinery does not satisfy this.
