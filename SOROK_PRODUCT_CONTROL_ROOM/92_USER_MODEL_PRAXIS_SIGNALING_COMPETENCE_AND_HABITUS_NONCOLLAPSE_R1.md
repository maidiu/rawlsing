## 0. Problem

A user can deploy language or references that suggest knowledge, status, milieu proximity or competence without actually possessing the competence another observer may infer.

Rawlsing must not collapse:
- lexical availability;
- recognition;
- social-signaling competence;
- sustained domain knowledge;
- procedural skill;
- social origin/class position;
- actor-local attribution.

## 1. Core noncollapse

LEXICAL FAMILIARITY
!= RECOGNITION
!= SOCIAL-SIGNALING / REFERENCE-DEPLOYMENT COMPETENCE
!= SUSTAINED DISCURSIVE COMPETENCE
!= PROCEDURAL / DOMAIN COMPETENCE
!= ORIGIN / MILIEU
!= NADIA'S BELIEF ABOUT ANY OF THE ABOVE.

A user may competently use a reference from Italian Renaissance poetry, quantum mechanics, astrology, luxury travel, automobiles, wine, art or any other domain to perform a social-semantic function without being capable of an expert discussion in that domain.

The system should record only what the interaction actually demonstrates.

## 2. Social-performance competence is itself real

A user may know:
- what a reference connotes;
- what audience it will affect;
- how it signals breadth;
- how to use it humorously;
- when it risks intimidation;
- when to scale it back;
- when to allow another person to overestimate their competence;
- when to disclaim expertise.

This can be a genuine medium-native social capacity.

Compact:

> KNOWING WHAT A REFERENCE CAN DO SOCIALLY IS NOT THE SAME AS KNOWING THE DOMAIN THE REFERENCE CAME FROM.

## 3. Nadia may infer wrongly

Rawlsing's internal user model and Nadia's model must remain separate.

Example:

User repeatedly deploys Renaissance-poetry references appropriately in conversation.

System may conservatively store:
> demonstrated ability to deploy references from domain X appropriately in contexts Y/Z.

Nadia may infer:
> the user is highly knowledgeable about Italian Renaissance poetry.

Or:
> the user is pretentious and namedropping.

Or:
> the user knows just enough to sound impressive.

Her inference depends on her own knowledge, insecurity/confidence, social history, bullshit sensitivity, status orientation, prior relationship and current context.

Her inference may be false.

Later contradictory evidence can create:
- embarrassment;
- disillusionment;
- accusation of misleading implication;
- humor;
- revised respect;
- no consequence.

This is a lawful relational event, not a failed stat check.

## 4. User signaling can be intentional or habitual

The user may:
- deliberately project expertise;
- enjoy an overestimate without explicitly lying;
- preemptively disclaim expertise;
- scale down display to avoid intimidation;
- intensify display in hostile argument;
- casually signal milieu familiarity without realizing it;
- use borrowed cultural markers with no direct milieu membership.

Rawlsing should not need omniscient access to the motive.

It can preserve:
- realized signal;
- context;
- downstream actor inference;
- later user self-report;
- system uncertainty.

## 5. Habitus-like user inference

The lawful target for long-run modeling is not:
> what class is this user really?

More defensible targets are recurring practical dispositions such as:
- what kinds of distinctions appear effortless;
- what kinds of objects are recognized without prompting;
- what kinds of authority are treated informally/formally;
- what forms of cultural capital are conversationally ordinary;
- what price/status distinctions are noticed;
- which institutional processes appear familiar;
- which forms of privacy/reciprocity are presumed;
- which forms of disorder/maintenance are salient;
- how the user responds to conspicuous consumption;
- what appears tacky, authentic, pretentious, ordinary, sacred, comic, risky or wasteful;
- what kinds of spaces produce ease/hesitation.

These remain hypotheses about play behavior and practical disposition, not diagnoses or demographic truth.

## 6. Structural position remains separate

Under homologous-peer mode:

CARRIED PRACTICAL DISPOSITIONS / HABITUS-LIKE PATTERNS may persist,

while:

PURCHASING POWER / INSTITUTIONAL LEVERAGE / HOUSING SECURITY / LABOR POSITION / TRANSPORT / NETWORK REACH

are structurally homologized according to the local field.

Therefore user-model inference must not be used to recreate the user's external structural privilege inside the generated world.

Compact:

> INFERRED HABITUS EVIDENCE != AUTHORITY TO RECONSTRUCT REAL-WORLD CLASS POSITION.

## 7. Player, system and actor models

At minimum preserve:

### A. System model of user praxis/perception
Bounded behavioral hypotheses used only for authorized product functions.

### B. User model of Nadia/world
The user's own inferred understanding, which may be wrong.

### C. Nadia's model of user
Actor-local inference from what Nadia perceives.

No one of these becomes omniscient truth.

Candidate broader theorem:

> NO PARTICIPANT IS EXHAUSTED BY ANOTHER PARTICIPANT'S MODEL OF THEM—INCLUDING THE PLAYER.

This is a kernel-relevant symmetry but remains provisional.

## 8. Reflection discipline

Good:
> In the last eight encounters, you spontaneously used technical or literary references from several domains, but only twice did play require sustained domain explanation.

Good:
> You often downshifted your displayed expertise after another person showed uncertainty.

Bad:
> You are highly cultured.

Bad:
> You come from an upper-middle-class background.

Bad:
> You are pretending to know things.

Reflection remains:
- evidence-linked;
- contextual;
- uncertain;
- nonessentializing.

## 9. Competence promotion requires evidence at the right grain

A capability may not be promoted merely because the user:
- names the capability;
- uses one domain word;
- recognizes one object;
- makes one correct reference;
- is perceived as competent by Nadia.

If Rawlsing needs an internal execution prior for a capability, the authority for that prior must come from an explicit transposition/setup rule or sufficiently direct demonstrated performance—not actor belief.

## 10. Strongest current theorem

> Rawlsing should maintain a provenance-bearing historical model of what the user has actually demonstrated in play—attention, distinctions, recognition, signaling, sustained reasoning, action and recurrent practical dispositions—while refusing to collapse those observations into unearned expertise, social origin, personality essence or Nadia's beliefs about the user. Social overestimation and underestimation by Nadia remain lawful relational phenomena.
