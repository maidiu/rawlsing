# Sorok — User-Specific Regimes of Attention and Ahead-of-Attention World Depth R1

Status: `PROVISIONAL_PRODUCT_DIRECTION__REFINES_59_SEMANTIC_PERSONALIZATION_FIREWALL`

Date: 2026-10-01

Currentness note (2026-10-03): read the ahead-of-attention sections through artifacts 80–81 and SPD-0237/0239. Detail levels are truth/materialization strata, not a user-access ladder. User ATTEND is one materialization trigger; any lawful actor/world causal dependency may also require bounded hidden resolution.

Further currentness (2026-10-03): apply SPD-0246/0247. Recognition evidence carries source provenance: narrator/actor-supplied terminology does not prove prior user expertise, though it may become acquired knowledge. Progressive ambient coverage is nonexhaustive: time/spare attention can enrich the sample but waiting never guarantees a full visual inventory.

## 0. Correction

Artifact 59 was correct to forbid:
- user-tailored world truth;
- hidden narrative curation;
- self-confirming psychographic steering.

But its firewall against user-specific semantic salience was too coarse.

Humans with equal sensory access do not notice or recognize identical things.

A person who knows audio gear, plants, knives, books, fashion, engines, architecture, religious iconography, insects, dirt, typography or cooking equipment may lawfully experience a different phenomenal surface from another attentive person in the same room.

Therefore:

> **PERSONALIZED PERCEPTION != PERSONALIZED REALITY.**

Rawlsing may model user-specific regimes of attention and recognition, provided the world/person remains causally independent of that model.

## 1. Noncollapse

`WORLD TRUTH`
!= `PERCEPTUAL AVAILABILITY`
!= `USER ATTENTION REGIME`
!= `USER RECOGNITION REPERTOIRE`
!= `CURRENT ATTENTIONAL LOAD / TASK`
!= `NARRATED PHENOMENAL SURFACE`
!= `USER INTERPRETATION`.

The user's attention regime may influence the probability that an already-available detail enters awareness.

It may not:
- create the detail;
- make Nadia own that object;
- change the object's history;
- change Nadia's relation to it;
- make a hidden fact true;
- optimize dramaturgy for the user;
- select details because the system wants a psychological reaction.

## 2. Attention regime

A user-specific attention regime is a bounded predictive model of what kinds of perceptual features the user tends to register under particular conditions.

Candidate components:
- spatial scanning habits;
- floor / hygiene / disorder attention;
- faces / posture / evaluation cues;
- text / labels / handwriting;
- books / music / media objects;
- brands / quality / craftsmanship;
- tools / technical objects;
- plants / animals / food;
- religious / cultural symbols;
- clothing / wear / repair;
- social-status markers;
- practical hazards / affordances;
- children / third-party cues;
- patterns / anomalies;
- sound / smell / tactile cues;
- novelty versus familiarity.

These are not personality traits and are not necessarily stable across contexts.

They are predictive observation parameters.

## 3. Recognition repertoire is separate from attention

Noticing an object and knowing what it is are different.

The narrator must not lexicalize directly from canonical object identity.

Example:

Canonical truth:
`VITAMIX 5200`.

Ordinary perception may warrant only:
> a blender

or:
> a large, powerful-looking blender

if that characterization is grounded in visible form.

Closer ATTEND may make lettering readable:
> a blender with VITAMIX printed on the base.

That still does not supply:
- brand significance;
- model number;
- price/status;
- domain interpretation.

Only where the user's recognition repertoire is already warranted may narration lawfully say:
> a Vitamix

or, with sufficient evidence/expertise:
> a Vitamix 5200.

Preserve:

`CANONICAL OBJECT IDENTITY != USER-FACING LABEL`.

`TEXT EXISTS ON OBJECT != USER HAS READ TEXT`.

`VISIBLE FORM != READABLE MARKING != OBJECT/BRAND/MODEL IDENTIFICATION != DOMAIN KNOWLEDGE != INTERPRETATION`.

Description specificity is epistemically gated.

See SPD-0166 / SPD-0246 / SPD-0248 / RISK-204 / artifact 87.

## 4. How the attention regime may be learned

Strong evidence:
- explicit `ATTEND` targets initiated by the user;
- repeated spontaneous questions about a feature class;
- user identification of objects/works/brands/styles without narrator prompting;
- corrections demonstrating knowledge;
- repeated allocation of scarce attention under competing possibilities;
- explicit user-selected perceptual assistance/preferences.

Weaker evidence:
- response to details the narrator itself surfaced;
- one-off comments;
- behavior under unusually constrained scenes.

Do not update a strong attention prior merely because the system showed a detail and the user reacted to it.

This prevents self-confirming exposure loops.

## 5. Provenance of attention evidence

Each attention-evidence event should retain whether the relevant feature was:

- `USER_TARGETED` — user deliberately sought it;
- `AMBIENT_UNBIASED` — surfaced without user-model weighting;
- `REGIME_WEIGHTED` — surfaced partly because of the current attention model;
- `PHYSICALLY_DOMINANT` — effectively unavoidable;
- `ACTOR_DIRECTED` — another actor called attention to it;
- `TASK_REQUIRED` — needed for the current action.

Learning strength should depend on this provenance.

A regime-weighted exposure is weak evidence for strengthening the same regime.

## 6. Exploration mass / anti-lock-in

The attention model must never become a closed tunnel.

Automatic scene sampling retains nonzero probability for:
- physically salient features outside the user's learned regime;
- neutral ambient details;
- novel categories;
- features made salient by current action/world change.

Conceptually:

`NOTICE SCORE`
=
`PHYSICAL SALIENCE`
× `ACCESS`
× `ATTENTION CAPACITY`
× `CURRENT TASK FIT`
× `USER ATTENTION PRIOR`
× `RECOGNITION POSSIBILITY`
+ `EXPLORATION MASS`.

This is not required to be one literal scalar implementation.

The governing point is:
> learned attention can weight perception without monopolizing perception.

## 7. Slow learning, easy revision

Attention regimes should:
- update gradually;
- retain uncertainty;
- decay where evidence stops supporting them;
- remain context-specific where appropriate;
- admit contradiction.

A user may be:
- highly attentive to cleanliness in kitchens;
- indifferent to it in workshops;
- attentive to brands in music gear but not clothing;
- attentive to books only when titles are readable;
- newly learning a domain.

Do not collapse into:
`USER CARES ABOUT CLEANLINESS = TRUE`.

## 8. Current attention is event-specific

Durable regime is only one input.

Current noticing also depends on:
- what the user is doing;
- where they are looking;
- conversation load;
- urgency;
- fatigue if modeled;
- whether another actor is speaking;
- whether the user is carrying something;
- novelty;
- changes since last visit;
- user-directed ATTEND.

A knife expert carrying a crying child through a kitchen may not inspect the knives.

## 9. User-specific phenomenal divergence

Two users can lawfully encounter the same canonical room and receive different initial/peripheral details.

User A may notice:
- dirty dishes;
- fry under fridge;
- worn Birkenstocks;
- laundry chair.

User B may notice:
- Nabokov titles;
- festival photos;
- a handmade-looking rug;
- mandolin;
- Japanese knives.

If the underlying room is the same, neither surface is "the true Nadia."

They are different epistemic trajectories through the same independent person/world.

This is desirable.

## 10. Shared-world versus copied-world distinction

For future comparative/research use:

### Identical seeded fork / copy
Two users may begin from the same initial Nadia/world state but separate continuities.

Their attention regimes may expose different surfaces.

After interaction begins, the Nadia instances diverge because each continuity acquires different history.

They are counterfactual twins, not literally one continuing person after the fork.

### Shared Nadia / multi-user world
Two users interacting with one continuing Nadia would require:
- one shared objective world/history;
- separate player-participant states;
- separate Nadia models of each user;
- separate user perceptual trajectories;
- shared network consequences.

This is a much larger multiplayer/social problem and remains post-alpha.

## 11. Ahead-of-attention world depth

Rawlsing should keep world resolution ahead of the user's current epistemic frontier.

Not every detail of Nadia's house must be generated at birth.

But the engine should avoid:

`USER ASKS ABOUT X`
→ `MODEL INVENTS WHATEVER X BACKSTORY IS MOST INTERESTING NOW`.

Instead use a rolling **ahead-of-attention closure frontier**.

Before or when an object/space becomes likely to enter perception, resolve enough adjacent facts that deeper inspection reveals an already-constrained reality.

## 12. Layered truth/materialization depth — not a user-access ladder

The levels below describe **what Rawlsing may have resolved as canonical truth**, not a sequence the user can simply climb by ATTENDing harder.

Candidate strata:

### L0 — space / structural facts
- room geometry;
- major furniture;
- exits;
- gross condition.

### L1 — ordinary visible inventory
- objects/classes;
- approximate placement;
- visible clutter;
- surface condition.

### L2 — inspectable physical particularity
- brands;
- wear;
- stains;
- handwriting;
- contents visible under lawful inspection;
- repair marks;
- object-age cues.

### L3 — objective provenance / history
- acquisition;
- giver;
- ownership history;
- repair event;
- travel;
- prior uses;
- who else interacted with it.

### L4 — actor-specific epistemic relation
- what Nadia actually knows;
- what she remembers;
- what she misremembers;
- what she infers;
- what is inaccessible to her;
- current actor-local associations/significance.

### L5 — present relational recruitment / expression
- what the object recruits now in this encounter;
- whether Nadia notices the user's attention;
- what she wants to reveal or conceal;
- what she says, implies, jokes about, evades or lies about;
- how the current relationship/context changes outward response.

These strata are **ontic/causal depth classes**, not one disclosure staircase.

A user may inspect deeply into L2 while receiving zero direct access to L3–L5.

Conversely, Nadia may voluntarily tell the user an L3 fact they could never infer from visual inspection.

A child/third party may know an L3 fact Nadia does not know, or may hold a false belief about it.

Preserve:

`CANONICAL TRUTH DEPTH != USER ACCESS DEPTH != ACTOR KNOWLEDGE DEPTH != ACTOR DISCLOSURE DEPTH`.

## 13. Rolling dual-frontier closure rule

Rawlsing should maintain at least two conceptually distinct frontiers:

### A. Materialization frontier

How much canonical truth has been resolved behind the visible surface.

This frontier should normally remain **ahead of the user's epistemic frontier** by a bounded amount.

When a target becomes ambiently available or is deliberately ATTENDed, Rawlsing may resolve:
- the next inspectable physical layer;
- additional hidden physical structure;
- objective provenance/history;
- causally necessary dependencies;
- relevant actor-memory/knowledge state derived from existing person/history;

even when none of that deeper material is immediately disclosed.

### B. User epistemic/disclosure frontier

What this user can presently know through:
- lawful perception;
- physical interaction;
- prior acquired knowledge;
- another actor's testimony;
- inference.

ATTEND advances this frontier **only along channels actually available to inspection**.

It does not convert hidden provenance, actor memory or objective history into narrator knowledge.

Compact:

> **ATTEND MAY ADVANCE MATERIALIZATION FARTHER THAN DISCLOSURE.**

And:

> **GENERATED TRUE != USER KNOWS TRUE.**

### Birkenstock example

At room-entry time the user may receive only:

> sandals by the front door.

Behind that surface, Rawlsing may already resolve:

`brown Birkenstocks`
→ `old`
→ `heel worn unevenly`
→ `cork darkened`
→ `one strap repaired`.

It may also resolve, without disclosure:
- that they are Nadia's;
- acquisition date/context;
- who repaired the strap;
- whether they appear in older canonical photos;
- whether Nadia owns newer shoes;
- what Nadia remembers or misremembers about them.

When the user walks over and ATTENDs, lawful visual inspection may reveal:

> old brown Birkenstocks, unevenly worn at the heel, cork darkened, one strap repaired.

It does **not** narrate:

> Nadia has owned them for years.

unless the user possesses lawful evidence supporting that proposition.

It does **not** narrate:

> she reaches for them automatically despite owning newer shoes.

unless the user has actually observed enough behavior/history to know that.

It does **not** narrate their acquisition story merely because the story has now been generated.

The act of ATTEND may nevertheless cause Rawlsing to materialize still deeper hidden truth behind the newly exposed surface, keeping the world ahead of the gaze.

### Communication does not become truth lookup

If the user asks Nadia about the shoes:

`USER QUESTION`
→ exact admitted interaction
→ Nadia's actor-local access / memory / belief / motive
→ CAN-008 R2 coupling
→ response choice / expression.

Not:

`USER QUESTION`
→ `WORLD.TRUTH[birkenstocks]`
→ Nadia recites answer.

Nadia may:
- tell the truth;
- tell only part of it;
- misremember;
- say she does not know;
- evade because she does not want to talk about it;
- joke;
- invent something playfully;
- lie deliberately;
- confidently state something false.

A child or other actor can independently do the same from **their** actor-local epistemic state.

Thus:

`OBJECTIVE PROVENANCE`
!= `NADIA KNOWLEDGE`
!= `NADIA TESTIMONY`
!= `CHILD KNOWLEDGE`
!= `CHILD TESTIMONY`
!= `USER INFERENCE`.

This is the practical meaning of actor opacity inside lazy world generation.

## 14. Curiosity invariance at depth

`QUERY DETERMINES LOCUS OF RESOLUTION`
!=
`QUERY DETERMINES SUBSTANTIVE TRUTH`.

If the user inspects the laundry pile, the query makes buried laundry detail relevant to resolve.

It must not make the laundry contain psychologically convenient underwear because the query makes that narratively juicy.

If the underwear already exists by prior closure, reveal may eventually expose it.

If it remains unresolved, completion must derive from Nadia/world/history priors independently of the user's desired implication.

## 15. Nadia's private reaction may recruit invisible detail

An important consequence:

A detail can affect Nadia even when the user does not perceive it.

Example:
- the user offers to carry clean laundry;
- buried lingerie is already canonical or lawfully resolved;
- Nadia remembers the recent hookup and discomfort;
- she anticipates the user possibly seeing it;
- that recruited material alters her immediate response.

The user may receive only:
- hesitation;
- a change of wording;
- a decision to take the basket herself;
- or no outward cue at all.

This is exactly the existing:
`OBJECTIVE HISTORY != NADIA UPTAKE != NADIA RESPONSE != V2 EXPRESSION != USER KNOWLEDGE`
law applied to environmental detail.

## 16. Why deep pre-resolution should be bounded

Full eager generation of every room/object biography would explode:
- storage;
- inference cost;
- contradiction surface;
- irrelevant determinacy.

Therefore use **bounded causal overhang**:
- enough already-resolved depth to make immediate inspection query-invariant;
- deeper lazy completion only when approached;
- completion constrained by already-admitted facts and the central relational/world spine.

The world should feel deeper than the user's gaze without requiring omniscient precomputation.

## 17. Perceptual personalization firewall — refined

Forbidden:
- create objects because user likes them;
- make Nadia share interests because user notices them;
- surface details because they would manipulate this user emotionally;
- alter object history to reward inquiry;
- use engagement optimization to choose semantic detail;
- treat attention regime as identity truth.

Allowed:
- weight which already-perceptible details enter awareness based on demonstrated attentional habits;
- apply established recognition/knowledge where warranted;
- preserve nonzero neutral/exploratory noticing;
- alter prose density/accessibility transparently;
- use current explicit attention as a strong perceptual input.

## 18. Research value

This architecture improves research validity because Rawlsing can record:

- canonical available feature set;
- what was physically perceptible;
- which details were neutrally surfaced;
- which were attention-regime weighted;
- what the user explicitly sought;
- what they recognized;
- what they interpreted;
- what they acted on.

Then a later analysis can distinguish:
- attention regime effects;
- narrator exposure effects;
- user-driven discovery;
- recognition competence;
- interpretation.

This is far richer than treating every omission as "the user failed to notice."

## 19. Product theorem

> **The world is independent of the user, but perception need not be generic.**

And:

> **Rawlsing should let different users develop different epistemic relationships to the same person without changing who that person was in order to produce the difference.**

And:

> **The simulation should maintain enough latent causal depth ahead of attention that inspection feels like discovery rather than co-authorship.**
