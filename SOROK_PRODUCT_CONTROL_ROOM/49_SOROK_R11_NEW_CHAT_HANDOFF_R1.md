- `SOURCE EVIDENCE != BIOGRAPHY`
- `STRUCTURAL POSSIBILITY != ACTOR FACT`

Personhood is historically accumulated, path-dependent organization under structural and relational pressure, not trait essence and not mechanical determinism.

`USER CLAIM != VERIFIED EXTERNAL-HUMAN TRUTH`.

## 7. Native player skill

Rawlsing's real player skills are capacities the user ACTUALLY exercises through the medium:
- attention;
- inquiry;
- inference;
- memory;
- judgment;
- timing;
- explanation;
- persuasion;

- speech.

Declared abilities such as piano virtuosity or physical strength are represented capabilities, not native game skill.

Core law:

> **You can invent what your portaled body can do. You cannot invent understanding of another person into existence.**

## 8. Task-entry / interaction law

Do not resolve high-level verbs like `help`, `teach`, `comfort`, `persuade` as successful outcomes when their meaningful causal content is something the user can actually perform through the interface.

Return control before Rawlsing would have to fabricate the user's meaningful contribution.

Current ordinary-task default:

`ENTER → REVEAL → CHOOSE → RESOLVE`.

Broad task language usually buys access to the concrete task-state before completion.

Example:
`I help with the groceries`
→ reveal actual bags/weights/stairs/what Nadia is carrying
→ user chooses method
→ world resolves feasibility
→ Nadia reacts to realized action.

Explicit delegation / learned routine / genuinely low-salience continuation may compress.

`OMISSION != CHARACTER EVIDENCE`.

## 9. Tasks are substrate, not the game

Laundry, dinner, homework, errands, etc. are relational carriers.

Top-level game:

> **coming to know a particular independent person through life and relation over time.**

The user learns through talk, inquiry, shared activity, remembered history, invitations, refusals, changing access, conflict, repair, ordinary presence.

Nadia is not a lore tree.

## 10. Beginning-to-know layer

`KNOWING HER` and `BECOMING KNOWN BY HER` develop together.

## 16. Disclosure / lying

Disclosure is not `TRUST >= threshold → deeper lore`.

Current direction:

> **Disclosure is something a person does with another person under a particular relational pressure field.**

Inputs may include broad relational cathexis/investment, shame, face threat, desire for recognition/affiliation, expected reception, self-accessibility, defensive organization, current goal, fatigue, context, sideways activity, etc.

Possible outputs include truth, partial truth, refusal, joke, evasion, strategic omission, lie, sincere inaccurate self-narrative.

Nadia is allowed to lie.

Underlying history remains separate from memory/belief/self-narrative/utterance.

## 19. Time: elastic present

Default is NOT exact wall-clock capture.

> **Optimize for cognitive persistence, not calendar capture.**

Nadia/world remain present-coupled.

- user may have a broad product window to play that scene;
- from Nadia's perspective it still occurred Friday 7pm;

- neutral descriptive framing;
- never called `true`, `hardcore`, `full`, or morally superior;
- never affects warrant/access/progression.

Some genuine relation-specific guilt from absence is lawful.
Platform-manufactured guilt is forbidden.
