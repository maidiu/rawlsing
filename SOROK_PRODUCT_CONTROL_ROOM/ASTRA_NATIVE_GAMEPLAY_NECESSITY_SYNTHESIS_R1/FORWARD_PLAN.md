# Finite forward plan

This return recommends **three local adjudications and three linked prototype studies**, followed by one bounded Astra review. It does not authorize production work, close any canonical question, or prescribe a new game system. Prototype design choices below are proposed experimental bounds, not new product law.

## 0 — Freeze the common evidence contract

Sorok/Vozhd should approve a small synthetic fixture package before evaluating any player experience. Use existing owner semantics and explicit fixture facts; do not claim a toy fixture is a validated generated person or evidence about a country. No raw respondent data is needed.

For each tested interaction, retain audit evidence for:

- pre-existing world/actor facts and their provenance;
- what was perceptually available, actually surfaced and deliberately acquired;
- user input and parsed attempt, realized operation, duration and interruption;
- what each involved actor could perceive, take up and express;
- exact occurred event and any rejected candidate;
- immediate versus durable effects, their competent owners and later retrieval;
- what the user could lawfully learn about the effects.

These are **receipt obligations**, not a demand for new monolithic stores. Reuse existing owner references and derived views under SPD-0232. Missing authority is explicit, not silently treated as zero effect. The fixture should include ordinary facts with no special significance and hidden facts that affect actor/world behavior before the user inspects them.

This bounded foundation draws from G4 and supplies a common basis for all three studies. A separate adversarial lazy-materialization trace tests query invariance and historical reconciliation; full generator completion is not a prerequisite for the first interaction test.

## 1 — Adjudicate the smallest usable act, then test one encounter

**Local adjudication A:** resolve a bounded slice of G1 together with G2's minimum agenda/uptake contract. The required answer is one executable or manually adjudicable trace contract: initial frame → intended operation → realized operation/time → actor reception → lawful output → control return. Specify where the system asks for clarification, where it compresses routine action, and where it must return control. Do not invent the user's meaningful words or interpretation.

**Questions:** Q-SCENE-001, Q-SALIENCE-001, Q-NARR-001, Q-CHANNEL-001, Q-PARSER-002, Q-TIME-002, Q-TIME-003, Q-CONTROL-001; bounded Q-AGENDA-001, Q-PERCEPT-001, Q-ATTNACTOR-001, Q-EFFORT-001 and Q-EXPR-002.

**Prototype P1 — One ordinary encounter:** use a person with an existing purpose and a plausible player-access route. The user can speak, inspect, participate, decline or leave. Include a quiet case, a busy case and a case where offered help is unnecessary. Do not assign the user a hidden correct role or goal. A practical activity may exist because the person is doing it; it must not be manufactured around a diagnosed user weakness.

Test fixed-state paraphrases, changed-state identical utterances, compound actions, a low-significance inspection, a recognition-dependent label, a partial interruption, and a meaningful contribution that cannot be completed by declaration. The fixture can be text-only; it must let users inspect enough actual material to exercise reasoning. State language/accessibility limitations.

**Technical gate:** causal distinctions survive; input is legible; no hidden-state or identity leakage; actor responses depend on authorized determinants; parser ambiguity is visible as such. A scripted demonstration passes only this bounded seam, not production feasibility.

**Experience gate:** users can explain what they knew, attempted and learned, identify at least some choices that felt worth making, and distinguish actor resistance from interface obstruction. Compare the same situation under alternative lawful frame/control policies. Preserve counterexamples and disengagement; do not count evocative prose or agreement with project philosophy as evidence of agency.

**Stop/repair condition:** if understanding the controls still leaves no worthwhile participation, return to the specific failed seam. Do not add quests or crises to rescue the trial.

## 2 — Adjudicate history's causal return, then test recurrence

**Local adjudication B:** close a bounded G3 path from exact occurrence to appropriate memory/convention/expectation/access effects and their later consumption. Carry objective convention and each actor's interpretation separately. Preserve actual player commitments without inferring them from kindness, presence or ambiguous assent.

**Questions:** Q-MEM-001, Q-MEM-002, Q-PROMOTE-001, Q-MODEL-001, Q-RELFACT-001, Q-RELSIGN-001, Q-ACCESSIMPL-001, Q-KNOW-001 and Q-ASSERT-001. Q-MEANINGSTRATA-001 may contribute an ordinary interpretation case; a complete theory of self-rereading is unnecessary.

**Prototype P2 — Three encounters in one peripheral continuity:** include an ordinary shared practice, a misunderstanding about what it means, and a later occasion where that history changes the possibilities. Hold intimacy constant. Include a refusal/boundary and one event of no durable significance. The actor's own offscreen life also changes some context.

This is a fixture family, not a three-act story template. Run variants in which the player notices the mismatch, misses it, declines involvement or leaves. Include an event whose effect persists without explicit recall and an interpretation that is wrong but becomes causally influential when held.

**Technical gate:** the later trace references real admitted history and correct owners; an ablated earlier event changes only its supported descendants; an un-emitted candidate changes nothing; forgetting does not erase occurrence; no relationship-stage scalar is needed.

**Experience gate:** the later encounter feels meaningfully different for identifiable historical reasons, not merely because the actor recites a callback. Users can find value without closeness, disclosure or a guaranteed repair. Local prediction and contextual differentiation may be evaluated as SPD-0234 hypotheses; they are not moral scores.

**Stop/repair condition:** if the only visible development is more affection, confession or personalized prose, return to G3. Do not promote “become important” into a solution.

## 3 — Adjudicate offscreen continuation, then test a humane return

**Local adjudication C:** compose the already constrained absence and rendezvous rules with the specific history path. Specify one bounded background-advancement, message and pending-scene lifecycle; do not reopen full real-time synchronization as the default.

**Questions:** Q-MSGTIME-001, Q-ABSENCE-001, Q-PENDINGSCENE-001, Q-WORLDEV-001, Q-LIFETOPO-001, Q-DUALUI-001, Q-INVITE-001 and Q-TETHERHEALTH-001.

**Prototype P3 — Return with notifications disabled:** an actor may originate contact from their own plan, or no contact may be forthcoming. Exercise attended, canceled, rescheduled, expired and long-absence paths. Background life can continue within lawful closure; no meaningful player speech, consent, promise or apology is invented. Product controls do not become actor evidence.

**Technical gate:** no downstream future leaks across a pending scene; message timing and world time reconcile; commitments remain causally specific; independent world changes have support; return is possible through known lawful routes where such routes exist.

**Experience gate:** users who want to return can do so without calendar servitude, guilt or social comparison, and can state a reason grounded in the actual person/situation/history. Users who do not want to return are evidence, not automatically failures of attention. A natural ending is distinguished from an incomprehensible or empty product.

**Stop/repair condition:** if the only working return stimulus is a crisis, flirtation escalation, countdown or community discussion, the claimed solo mechanism has failed its test.

## Evaluation discipline across P1–P3

Keep two ledgers of results: **causal/epistemic integrity** and **experience**. Both are necessary for a positive product claim; neither implies the other. Prototype receipts belong to a later authorized study, not to this conceptual return.

Before recruiting a study, set the comparison conditions and the evidence needed to advance. This report does not invent a retention percentage or a statistically supported sample size. Initial exploratory observations should identify failure mechanisms; broader generalization requires an appropriate study design and the product's privacy/consent constitution.

Inspect whether actual user contributions matter, whether available choices are intelligible, whether history changes later interaction, whether ordinary/peripheral cases work, and whether users voluntarily want another encounter without engineered pressure. Record exposure/settings under SPD-0244, assistance where known, and the self-selected sample limit under SPD-0245. Do not infer morality, spirituality, unaided expertise or population prevalence from product behavior.

Add one contrasting local context before claiming transfer beyond the first convenient fixture. This need not become a country survey or an exhaustive generator test. It should target a particular assumption that could otherwise have been mistaken for a universal rule.

## Explicitly deferred

Cross-persona commissions, universal existential questions, relationship levels, achievements, persona marketplace and best-route competition are rejected as present design directions. Warrant/succession (Q-SUCCESSION-001), persona introduction (Q-PERSONSHARE-001), broad flourishing (Q-HEALTH-001), language/assimilation (Q-LANG-001, Q-ASSIM-001), universal long-term benefit and a final kernel ruling remain open rather than being resolved by rhetoric.

Full self-retcon/meaning architecture and U3 theory should re-enter only if a concrete required prototype distinction cannot be represented through existing state and CAN-008 R2. None of this authorizes a new owner or production shortcut.

## Return to Astra once, with discriminating evidence

Consult Astra after P1–P3 have traces and observations, or earlier if one local adjudication produces a **specific contradiction or starvation case**. Bring the fixed fixture facts, exact displayed evidence, action/uptake/occurrence trace, later owner effects, failure cases, and observed reasons to continue or stop.

The next Astra question should be: **which derived interactions survived, which failed, and what minimum revision follows?** It should not be another unbounded search for game loops. If the three studies cannot support the solo proposition, report that directly and revisit the grounded product hypothesis before expanding the social or gamification layers.
