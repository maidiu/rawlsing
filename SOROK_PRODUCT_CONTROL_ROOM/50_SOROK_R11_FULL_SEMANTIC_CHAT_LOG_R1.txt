2. USER CORRECTION: RAWLSING CANNOT KNOW WHETHER USER IS LYING
================================================================================

User emphasized that Rawlsing and the LLM cannot know whether user claims about themself are true. Preventing lying/self-invention is a fool's errand. Design should create intrinsic incentives for truthful participation rather than a lie detector.

Example challenge:
- user claims concert-level Chopin;
- perfect Arabic Qur'an recitation;
- 200 pushups;
- Rawlsing cannot independently know external truth.

Result:
- `USER CLAIM != VERIFIED EXTERNAL-HUMAN TRUTH`;
- self-claims can govern the run's represented player without becoming external fact;
- no authenticity/honesty score;
- persona reacts to realized in-world events, not hidden external truth;
- reflection may describe what happened in the interaction but may not diagnose deception.

3. USER DISCOVERY: NATIVE PLAYER SKILL IS WHAT TEXT CAN REALLY CARRY
================================================================================

User: `playing Chopin` does not actually require the human user to play anything. What the user can really do through Rawlsing is pay attention, infer, take educated guesses, inquire, remember, speak, explain, and receive response.

Result:
- distinguish declared/represented capability from medium-native player capacity;
- no Perception/Empathy/Charisma stats for core relational capacities;
- if user wants to be perceptive, they must actually notice;
- if user wants to reach another person, they must actually find words/timing;
- central reward should attach to capacities actually exercised through the medium.

Core theorem:
`You can invent what your portaled body can do. You cannot invent understanding of another person into existence.`
