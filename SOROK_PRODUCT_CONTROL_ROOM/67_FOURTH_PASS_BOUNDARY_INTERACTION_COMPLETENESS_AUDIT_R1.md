- `RISK-148`.

### C9 — shared-person identity requires root versioning

Cross-user discourse only has a stable referent if "Nadia" is a version-stable pre-contact root.

A material change to the root cannot silently preserve the claim that later users met the exact same starting person.

Corrected by:
- `SPD-0192 PROVISIONAL_SEED_PERSON_VERSION_IDENTITY_LAW`;
- `RISK-149`.

Corrected by:
