## 1. Corrections found

### C13 — shared-root compatibility is not enough; branches need causal closure

A later-resolved pre-contact fact can be propositionally compatible with an old branch while still being causally incompatible.

Example:
- later resolution establishes that a pre-contact object/history fact was always true;
- had that fact been active in Nadia's earlier person/event processing, she would have behaved differently;
- silently inserting it as an antecedent cause rewrites the branch without contradicting any already-narrated proposition.

Corrected by:
- `SPD-0196 PROVISIONAL_SEED_FORK_CAUSAL_CLOSURE_LAW`;
- `RISK-153`.

Final law:
> every branch binds an exact seed-person root/version and causal-closure snapshot at fork time. Later root facts cannot become retroactive causes inside already-closed branch history.

### C14 — root-resolution timing must not make "same Nadia" user-order dependent

Lazy shared-root detail may be resolved at different wall-clock times.

Without an explicit reproducibility rule:
- an early user may fork before detail X exists in the resolved root state;
- a later user may fork after another user's query caused X to be resolved;
- both may nominally receive "Nadia v1" while causally starting from different persons.

Corrected by:
- `SPD-0197 PROVISIONAL_ROOT_RESOLUTION_STATE_REPRODUCIBILITY_LAW`;
- `RISK-154`.

Final law:
> same-root comparisons bind relevant root-resolution/closure state; material closure changes require deterministic equivalence or explicit lineage/version distinction.

### C15 — community/shared-person exposure is a research confound

Identical-root research is not clean if some users already know Nadia through:
- community discussion;
- spoilers;
- strategy guides;
- another user's branch report;
- previous play in another context/account.

Corrected by:
- `SPD-0198 PROVISIONAL_SHARED_PERSON_RESEARCH_EXPOSURE_LAW`;
- `RISK-155`.

Final law:
> prior external/shared-person exposure is an experimental-provenance variable, not invisible noise. Research must segment, control, exclude or model it.

### C16 — no canonical hidden-truth Nadia dossier

Shared-person discourse plus a finite common seed pool creates pressure toward:
- wikis;
- master biographies;
- hidden-root encyclopedias;
- completion percentages;
- canonical "everything about Nadia" references.

That would convert a person whose reality exceeds any one relation into a finite collectible knowledge object.

Corrected by:
- `SPD-0199 PROVISIONAL_NO_CANONICAL_PERSON_DOSSIER_LAW`;
- `RISK-156`.

Final law:
> Rawlsing does not expose hidden root truth as a canonical live-person dossier. User-facing recaps may summarize that user's own lawfully acquired branch knowledge/history.

### C17 — anti-commodification must be nonmoralizing

The product's anti-porn/anti-commodification purpose can itself fail if implemented as:
- scolding;
- shame;
- purity gates;
- arbitrary punishment for sexual interest;
- moralizing narration about attachment/intensity.

The chat's intended mechanism was thickness and independent consequence, not prudish authorial discipline.

Corrected by:
- `SPD-0200 PROVISIONAL_NONMORALIZING_ANTICOMMODIFICATION_LAW`;
- `RISK-157`.

Final law:
> person/world causality and relational consequence do the anti-commodification work. Nadia may judge the user according to Nadia's own person/history; the platform does not become a purity narrator.

### C18 — versioning cannot become a restart loophole

Earlier laws established:
- abandoned Nadia cannot be reissued fresh to the same user;
- material root changes create a new Nadia version.

Combined naively, Nadia v2 could become a technical loophole for meeting Nadia "again for the first time."

Corrected by:
- `SPD-0201 PROVISIONAL_SEED_PERSON_LINEAGE_NONREENTRY_LAW`;
- `RISK-158`.

Final law:
> abandoned-person exclusion follows the recognized seed-person identity lineage, not merely one exact root hash/version.

### C19 — learned attention regime needs an explicit scope/lifetime

The conversation treats attentional adaptation as belonging to the user across encounters, not to Nadia.

But leaving scope implicit creates two opposite failures:
- reset it for every persona, losing longitudinal reflexive attention;
- persist it forever as a hardened personality dossier.

Corrected by:
- `SPD-0202 PROVISIONAL_USER_ATTENTION_REGIME_SCOPE_LAW`;
- `RISK-159`.

Final law:
> the attention regime is a bounded user-level presentation/perception hypothesis: cross-continuity capable, context-tagged, uncertain, revisable, resettable/deletable, and never canonical personality truth or persona-owned user state.
