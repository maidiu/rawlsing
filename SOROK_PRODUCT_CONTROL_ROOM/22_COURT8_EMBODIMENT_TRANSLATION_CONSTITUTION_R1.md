# Sorok Court 8 — Embodiment Translation Constitution R1

Status: OPEN_COURT__HOMOLOGOUS_PEER_DEPENDENCY__NOT_ADOPTED

Date: 2026-09-29

## 0. Question

If the actual user remains psychically themself but is socially/materially transposed into a homologous peer position, what happens to the user's body and socially legible identity?

This cannot be treated as cosmetic.

Embodiment changes:
- how others read the player;
- what spaces are safe/available;
- authority and vulnerability;
- work and family expectations;
- ordinary social friction;
- attraction/sexualization;
- policing/institutional treatment;
- religious/cultural legibility;
- bodily affordances.

Therefore embodiment translation is part of causal ontology.

---

## 1. Four distinct operations

Do not ask one global question: 'does identity carry over?'

For each dimension, distinguish:

### CARRY
The user's actual dimension remains socially legible in the world.

### HOMOLOGIZE
Translate it to a locally analogous position/function.

### BRACKET
Do not instantiate it unless causally necessary.

### USER-SELECT
Allow bounded setup choice among lawful options.

Different dimensions may use different operations.

---

## 2. Candidate dimensions requiring separate adjudication

- age;
- sex/gender presentation;
- bodily ability/disability;
- height/build/appearance;
- ethnic/racial legibility;
- nationality/foreignness;
- accent/dialect;
- language competence;
- religion/nonreligion as socially known;
- education markers;
- occupation/professional prestige;
- legal/citizenship status;
- family/marital status;
- class-coded dress/objects;
- health constraints;
- migration history.

No single translation rule should govern all of these.

---

## 3. Preserve causal selfhood

A dimension should tend to CARRY when changing it would erase a major part of the actual user's lived formation and therefore alter what their behavior means.

Example class:
- disability experience;
- gendered social formation;
- religious/nonreligious identity if deeply carried;
- language repertoire;
- significant embodied history.

But carrying may reintroduce outsider privilege or alter local peerhood.

That tension must be explicit rather than hidden.

---

## 4. Preserve homologous field position

A dimension should tend to HOMOLOGIZE when its primary role in the simulation is structural access/power rather than preserving the user's present subjectivity.

Candidate examples:
- purchasing power;
- institutional leverage;
- occupational rank;
- housing security;
- transport access;
- local network reach;
- credential power.

Again, homologization must not fake developmental history.

---

## 5. Social legibility may need two layers

Possible design distinction:

### INTERNAL USER CONTINUITY
What the user knows themself to be and remembers being.

### LOCAL SOCIAL LEGIBILITY
How actors in the generated field classify/read the player's presented body/status.

These need not be identical.

This creates metaphysical strangeness but may be the cleanest way to preserve actual-user consciousness while producing peer-level local reception.

Open question:
how explicit should this fiction be to the player?

---

## 6. Foreignness is a design variable, not a default fact

Some modes may retain obvious foreignness.

Main homologous-peer mode currently leans toward reduced foreignness so the user cannot externalize every conflict as outsider mismatch.

But total social unmarkedness may require changing too much.

The court must find the **minimum translation needed to remove structural privilege/explanatory escape hatches without replacing the user.**

---

## 7. Language deserves its own constitution

Language affects both competence and identity.

Possible models:
- preserve actual languages only;
- interface translates transparently while actors hear locally fluent speech;
- user receives homologous local competence but retains stylistic/pragmatic foreignness;
- staged learning over time;
- translation device fiction.

Each produces different habitus effects.

Need to separate:
- propositional understanding;
- vocabulary/grammar;
- accent;
- pragmatic fluency;
- cultural references;
- code-switching.

---

## 8. Hard anti-fraud rule

Do not give the user locally native pragmatic fluency merely because the interface needs easy conversation.

If the pedagogical mechanism depends on learning local relational grammar, the interface cannot silently solve it.

Likewise do not make language frustration so dominant that the game becomes a language-learning simulator unless that is an intended mode.

---

## 9. Comparison cases

Case A:
actual user is materially privileged relative to focal persona but otherwise similar in age/gender.

Case B:
actual user differs in gendered social position.

Case C:
actual user has a disability with major relational consequences.

Case D:
actual user speaks none of the local language.

Case E:
actual user belongs to a religion locally rare or stigmatized.

Case F:
actual user's nationality would ordinarily confer huge outsider privilege.

For each, test carry / homologize / bracket / user-select.

---

## 10. Exit condition

Produce an embodiment-translation matrix that says, by dimension:
- why the dimension matters;
- default operation;
- what user agency exists;
- what local actors perceive;
- what is preserved as actual-user history;
- what risks of privilege or self-erasure arise;
- what evidence could reopen the rule.

Do not implement before this matrix exists.
