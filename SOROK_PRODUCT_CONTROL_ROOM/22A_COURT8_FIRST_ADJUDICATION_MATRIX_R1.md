# Sorok Court 8 — First Adjudication Matrix: What Crosses the Veil? R1

Status: PROVISIONAL_COURT_FINDING__NOT_GOVERNED_ARCHITECTURE

Date: 2026-09-29

## 0. Court holding

Homologous-peer mode should not translate 'the user' as one indivisible object.

Separate at least four layers:

1. **EXTERNAL HUMAN USER** — the actual person outside Rawlsing; Rawlsing does not own their psyche.
2. **USER-CARRIED SUBJECTIVITY** — whatever the human actually remembers, believes, notices, values, knows and chooses to express; this is not automatically machine-readable truth.
3. **HOMOLOGOUS PLAYER EMBODIMENT / LEGIBILITY** — the locally coherent body/status presentation through which generated actors encounter the user.
4. **LOCAL PEER POWER / RESOURCE ENVELOPE** — canonical in-world money, time, housing, transport, legal/institutional access, tools and obligations.
5. **ADMITTED PLAYER WORLD HISTORY** — what the user actually does/says in the generated world after causal admission.

These layers must not collapse.

Core law:

`ACTUAL USER != DIEGETIC EMBODIMENT != LOCAL MATERIAL POSITION != MACHINE MODEL OF USER != PLAYER EVENT HISTORY`.

---

## 1. Homology target

Main-mode homologization should **not require the user's real income, wealth, employer or social graph**.

The player resource/power envelope can instead be generated relative to:
- the focal persona's local field;
- the plausible peer set around that persona;
- the encounter substrate;
- the local opportunity/power distribution.

The player gets an independent local peer position, not a clone of the persona.

This preserves the veil and avoids collecting real financial data.

Candidate rule:

> Whatever material power the user's real-world position gives them remains outside the veil. Rawlsing assigns the material position from which they act here.

## 3. Social peerhood does not require total demographic sameness

Important refinement:

`HOMOLOGOUS PEER != DEMOGRAPHIC CLONE`.

The main mode needs to neutralize **external structural dominance** and obvious visitor privilege enough for local habitus friction to matter.

It does not necessarily need to erase every embodied difference.

Therefore Court 8 should search for the **minimum translation necessary** to achieve:
- local causal comparability;
- non-dominant material power;
- plausible repeated adjacency;
- reduced outsider explanatory shield;

while preserving enough actual-user continuity for the experience to bear upon the user.

## 4. Language membrane — provisional direction

Language should be decomposed:

`SEMANTIC INTELLIGIBILITY != LOCAL PRAGMATIC FLUENCY != CULTURAL KNOWLEDGE != ACCENT / SOCIAL MARKING`.

Strong candidate for main mode:

- interface mediates propositional meaning into a language the persona can understand;
- preserves the user's intended register/tone attempt as far as possible;
- does **not** optimize the utterance into locally ideal etiquette;
- does **not** gift local references, euphemisms, family grammar or social timing;
- therefore a semantically fluent statement can still land as socially strange.

This keeps the game about relational learning rather than vocabulary failure.

## 5. Autobiographical transport is a major unresolved seam

The hardest remaining Court 8 problem is not money. It is autobiographical truth.

If the user is socially local but remembers a real life elsewhere, what happens when someone asks:
- where did you grow up?
- what did your parents do?
- where did you go to school?
- why do you know this?

Bad solutions:
- fabricate a local childhood;
- force the user to roleplay a false biography;
- import literal external geography and thereby restore outsider identity by default.

Candidate direction for further court:

**semantic autobiographical transport**:
- carry relational/psychological meaning of actual memories;
- homologize or abstract externally identifying/material coordinates only when needed;
- treat user autobiographical statements as user testimony, not automatic objective world facts;
- never generate a fake developmental history for the user.

This remains unresolved and needs hostile examples.

## 6. Player setup authority requirement

Ordinary SAY/DO text cannot create stable user facts.

Need an explicit bounded setup/admission surface capable of establishing:
- selected carried facts;
- homologous embodiment facts;
- local material/resource facts;
- declared capabilities;
- privacy choices;
- mode-specific identity translation.

Candidate product-level object:

`VEILED_PLAYER_EMBEDDING_PROFILE`

with conceptual families:
- external-user continuity refs / consented claims;
- homologous local structural-position refs;
- embodiment/legibility refs;
- material-resource envelope refs;
- communication/language mediation refs;
- explicit unknown/bracketed fields;
- provenance/version.

This is a product requirement, not yet an adopted current owner.

## 7. Architecture compatibility finding

Existing V3 law strongly supports the anti-shortcut direction:

- ADP-007: demographic/structural input does not become psychological initialization;
- ADP-009: structural position is generated through its own authority;
- ADP-015: relationship formation does not arise from demographic compatibility;
- ADP-017: system truth does not become actor self-knowledge;
- ADP-019/CAN-025: caller/user assertion can create an observable assertion event, not objective identity truth.

Therefore homologous-player embedding should remain **world/participant binding**, not generated psyche.

---

## 8. Court 8 provisional verdict

Current preferred main-mode architecture is:

`REAL USER SUBJECTIVITY (external)`
+ `VEILED/HOMOLOGOUS LOCAL EMBODIMENT`
+ `LOCALLY GENERATED PEER POWER/RESOURCE ENVELOPE`
+ `ADMITTED IN-WORLD ACTION HISTORY`.

Do not ask Rawlsing to generate the user's psyche.

Do not ask the user to roleplay a generated psyche.

Do not import the user's real material privilege into the veil.
