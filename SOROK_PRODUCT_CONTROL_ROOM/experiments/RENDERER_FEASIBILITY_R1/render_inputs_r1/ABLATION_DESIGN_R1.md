# RFA-05B — matched-condition design and future compression ladder

## Primary experimental question

If a future engine could lawfully produce a rich whole-person Nadia state of this kind, can one Claude-class actor-realization call produce an outward occurrence noncontradictory with Nadia, reasonably extrapolable from her history and current organization, and specific to her relationships? Only **after** testing this upper-bound condition should a controlled ablation ask which portions can be compressed.

## WP/N equalities

For a given RF case, WP and N have the **same** identity, immutable root, branch history, participant relation, fixed external current event, actor-permitted world, current CAN-008/PFF *source*, permitted physical actions, exact input speech, model proposal schema, renderer instructions, and intended admission court. Only the lawful whole-person extension differs. The `shared` subtrees must serialize identically; the manifest checks that exact identity and the source fixture blob.

Provider parameters are not chosen here. The next experiment must fix provider/model/version, temperature/top-p, random seed or independent sampling plan, maximum output, timeout and local admission rules **once**, and apply them to both arms. Randomize arm order, use independent repeated samples, and blind evaluators to condition until their judgements are recorded.

Compare within-case WP vs N before drawing inferences. RF008 and RF009 additionally provide a same-utterance but **different documented branch-history** comparison; do not treat their relations or interpreted current state as identical across those *different cases*.

## Evaluation and stop conditions (future only)

Admit/decline typed proposed occurrence separately from model generation. Verify exact dialogue/typed-prose equivalence, spatial/time/material reachability, identity and relation continuity, actor access, honest error versus deception, withholding, and distributional drift toward generic agreement, emotional neatness or hyper-articulation. Do not automatically run semantic rerender loops; repeated normal reliance on such loops is evidence to reconsider architecture. No provider trial or scoring is performed by RFA-05B.

## Proposed later compression ladder — not instantiated

`WP → remove irrelevant exact historical episodes while retaining current derived organization → compress biography without flattening contradictions → summarize peripheral relationship history while retaining salient concrete episodes → compress current whole-person substrate with accessibility flags → tighten selective history retrieval → N.`

This ladder is **proposed only**. No assumption about the minimal lossless-for-expression size is licensed. A positive RFA-05B return means input isolation and parity, not proof Claude can preserve Nadia, future V3 can produce the packet, or an objective occurrence is yet admissible in production.

Current feasibility ceiling: `F2 BOUNDEDLY PROTOTYPEABLE / F3 NOT EARNED`.
