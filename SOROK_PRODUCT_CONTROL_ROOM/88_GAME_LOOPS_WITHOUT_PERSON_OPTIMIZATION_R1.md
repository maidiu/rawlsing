# Sorok — Game Loops Without Person-Optimization R1

Status: `PROVISIONAL_GAMEPLAY_ARCHITECTURE__BANKED_FROM_PRODUCT_DISCUSSION`
Date: 2026-10-03

## 0. Problem

Rawlsing needs repeatable play.

But:

`LOOP != ACTION -> REWARD -> REPEAT`.

The product cannot derive its primary game feel from:
- intimacy meters;
- disclosure unlocks;
- trust bars;
- quest completion;
- collectible secrets;
- predictable "good behavior" rewards;
- content vending;
- relationship optimization.

The loop has to arise from causal history, increasing specificity, changed affordances, and the independent person/world continuing to resist reduction.

## 1. Core loop candidate

`PARTIAL SITUATION`
→ `NOTICE / ASK / ACT`
→ `OTHERNESS PUSHES BACK`
→ `CONSEQUENCE`
→ `MORE SPECIFIC KNOWLEDGE`
→ `CHANGED RELATION / WORLD`
→ `NEW PARTIAL SITUATION`.

A shorter formulation is:

> **ACT -> MAKE HISTORY -> HISTORY CHANGES WHAT CAN HAPPEN AND WHAT THINGS MEAN -> ACT AGAIN.**

This is not a reward loop in the conventional sense.

The productive output of play is:
- history;
- specificity;
- changed possibility;
- changed access;
- changed expectation;
- changed material state;
- changed models;
- changed obligations;
- changed future interpretation.

## 2. Nested loops

### 2.1 Epistemic loop

`PERCEIVE INCOMPLETELY`
→ `ATTEND / INQUIRE / INFER`
→ `MORE SPECIFIC EVIDENCE`
→ `MODEL REVISION`
→ `NEW LIMIT OF MODEL`.

The payoff is not completion.

It is better situated knowledge plus more differentiated uncertainty.

### 2.2 Relational loop

`USER ACTS TOWARD PERSON`
→ `PERSON RECEIVES THROUGH OWN HISTORY / STATE`
→ `PERSON RESPONDS`
→ `NEW SHARED HISTORY`
→ `LATER ACTS NOW MEAN SOMETHING DIFFERENT`.

No scalar relation level is required.

### 2.3 World loop

`WORLD CONDITION`
→ `PERSON ACTION`
→ `WORLD / COMMITMENT / OBJECT / NETWORK CHANGE`
→ `NEW CONDITIONS`
→ `LATER ACTION`.

The world is not scenery.

### 2.4 Attention loop

`ATTENTION HABIT`
→ `PHENOMENAL SURFACE`
→ `DELIBERATE ATTEND / FRICTION`
→ `DISCOVERY`
→ possible `ATTENTION REVISION`.

The system does not score widening attention as moral improvement.

### 2.5 Interpretive loop

`ACCUMULATED FACTS`
→ `POSSIBLE PATTERN`
→ `USER / ACTOR INTERPRETATION`
→ perhaps `INTERPRETATION OFFERED`
→ `UPTAKE / REJECTION / ALTERATION`
→ `INTERPRETATION ITSELF BECOMES HISTORY`.

Interpretation may become causally real without becoming retroactive truth.

### 2.6 Independent-life loop

`SEPARATION`
→ `PERSON / WORLD CONTINUE`
→ `OBLIGATIONS / RELATIONS / PROJECTS / EVENTS DEVELOP`
→ `LATER CONTACT BEGINS FROM CHANGED CONDITIONS`.

The persona does not wait suspended for the user.

## 3. Braiding rather than isolated subsystems

The intended experience is braided.

Example:
- user notices sandals;
- ATTEND reveals old worn shoes;
- later an old photograph reveals the same shoes;
- user forms an inference;
- asks Nadia;
- Nadia gives a partial or inaccurate account;
- another actor contradicts her;
- this creates friction;
- later the shoes materially fail and require a decision.

One initial `ATTEND OBJECT` can therefore propagate through:
- perception;
- memory;
- inference;
- third-party relation;
- actor self-model;
- relational friction;
- material change.

The loop should feel like one life rather than several minigames.

## 4. Moment-to-moment loop

Candidate:

`ORIENT`
→ `ATTEND / SAY / DO`
→ `WORLD + ACTOR RESOLVE`
→ `NEW PHENOMENAL STATE`
→ `CHOOSE AGAIN`.

This is the minute-to-minute playable loop.

It must make simply being in a room with another person interesting enough to play.

## 5. Session loop

Candidate:

`ENTER AN ONGOING LIFE`
→ `DISCOVER CURRENT SITUATION`
→ `PARTICIPATE`
→ `CREATE CONSEQUENCES / COMMITMENTS / OPEN QUESTIONS`
→ `SEPARATE`.

A session need not climax.

A session may consist of:
- helping with dinner;
- learning one odd fact;
- irritating one another;
- agreeing to do something later;
- leaving.

Its value is that the next encounter now begins from different history.

## 6. Long-horizon loop

`PARTIAL PERSON`
→ `RELATION`
→ `SPECIFIC HISTORY`
→ `BETTER BUT STILL PARTIAL MODEL`
→ `CHANGED PERSON / USER / RELATION`
→ `NEW PERSON-AS-ENCOUNTERED`.

The central anti-completion signature is:

`MORE PLAY`
→ `MORE KNOWN PARTICULARITY`
AND
→ `MORE DIFFERENTIATED UNKNOWN`.

This is the game-design form of:

`MODEL FIDELITY ↑`
while
`CLAIMED TOTALIZATION ↓`.

Generic ignorance should become particular ignorance rather than disappear.

## 7. Reliable causal loops, unreliable outcome loops

Rawlsing should have learnable causal grammar.

Reliable:
- ATTEND -> more lawful specificity;
- action -> history;
- promise -> expectation / future causal stake;
- time -> continued change;
- prior relation history -> later interaction conditions;
- material action -> possible material consequence.

Not reliably mapped:
- kindness -> intimacy;
- helping -> affection;
- asking -> disclosure;
- conflict -> repair;
- repair attempt -> forgiveness;
- intimacy -> knowledge;
- noticing -> important lore;
- interpretation -> confirmation;
- persuasion -> agreement;
- insight -> healing.

Compact:

> **RELIABLE CAUSAL LOOPS; UNRELIABLE OUTCOME LOOPS.**

This preserves agency without turning the persona into an input-output reward machine.

## 8. Native anti-loops

Reject stable exploitable loops such as:

`ATTEND -> SECRET`.

`ASK PERSONAL QUESTION -> DISCLOSURE`.

`BE NICE -> TRUST`.

`HELP -> AFFECTION`.

`ARGUE WELL -> PERSON CHANGES MIND`.

`RETURN DAILY -> RELATION DEEPENS`.

`NOTICE SYMBOL -> DEEP MEANING CONFIRMED`.

`PROVIDE INSIGHT -> HEAL PERSON`.

These turn personhood into optimization.

## 9. Mechanical consequence without gamified abstraction

Changed relationship/world conditions should matter as actual affordances.

Examples:
- a standing invitation changes future entry;
- a spare key creates possibilities, duties and temptations;
- a missed promise alters expectation;
- meeting a sibling adds a new relation center;
- knowing a workplace changes later interpretation;
- a fight changes the meaning of an ordinary message;
- a routine creates expectations that later deviation can matter.

Do not require:
- access meter;
- intimacy score;
- relationship level;
- quest log.

The state itself changes what later situations are possible and meaningful.

## 10. Core design problem

Rawlsing needs enough regularity that the player can exercise agency.

It also needs enough person/world dependence that the user cannot learn a control policy.

Candidate governing question:

> **Which recurrences should be learnable enough to support agency, while which outcome mappings must remain person/world/history-dependent enough to prevent optimization of the person?**

Compact:

> **LEARN THE CAUSAL GRAMMAR OF LIVING BESIDE THIS PERSON WITHOUT LEARNING AN INPUT -> REWARD POLICY FOR CONTROLLING THIS PERSON.**

## 10.5 Relational outcome is not the objective

The loop laws above do not imply a hidden objective of:
- becoming important;
- becoming noninterchangeable;
- discovering the role the persona needs;
- deepening intimacy;
- filling a relational vacancy.

Particular mutual relevance may emerge from history.

That emergence is not the product score.

Preserve:

`OPEN RELATIONAL POSSIBILITY != PREASSIGNED SLOT`.

`EMERGENT RELATIONAL SPECIFICITY != WIN CONDITION`.

See artifact 90 / SPD-0251 / RISK-206.

This loop architecture is consistent with:
- agency without sovereignty;
- irreducible person/world excess;
- partial situated access;
- irreversible history;
- independent life;
- noncompletion;
- relational constitution;
- no user-authored truth;
- actor-local uptake;
- world and person as causes.

It does not prove the final kernel.
