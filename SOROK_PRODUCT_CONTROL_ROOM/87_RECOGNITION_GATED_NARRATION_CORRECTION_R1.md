# Sorok R12 — Recognition-Gated Narration Correction R1

Status: `PROVISIONAL_CORRECTION__NARRATOR_LEXICALIZATION_MUST_NOT_LEAK_CANONICAL_OBJECT_IDENTITY`
Date: 2026-10-03

## 0. Correction

The prior recognition-provenance audit was downstream of a stronger requirement.

It is not enough to say:
> if Rawlsing taught the user the label, do not later mistake reuse of that label for prior expertise.

Rawlsing should normally **not supply the expertise-dependent label in the first place**.

The world may canonically contain:

`OBJECT = VITAMIX_5200`.

That does not mean the narrator may say:

> a Vitamix 5200.

Canonical identity is not automatically phenomenal/user knowledge.

## 1. Recognition-gated lexicalization

Narration should use the most specific description justified by:

- current sensory access;
- current ATTEND depth;
- ordinary category recognition;
- demonstrated user recognition repertoire;
- lawfully acquired prior knowledge.

Example:

### Canonical truth
`VITAMIX 5200`.

### Ordinary room-level perception
> a blender

or, if perceptually warranted:

> a large, powerful-looking blender

where "powerful-looking" is a visible-form characterization, not hidden domain knowledge.

### Closer inspection where lettering becomes available
> a blender with VITAMIX printed on the base

This reveals visible text.

It still does not automatically assert:
- Vitamix is a premium brand;
- model 5200;
- prosumer status;
- price;
- what owning it says about Nadia.

### User with established recognition repertoire
> a Vitamix

or, where model-level expertise and visible evidence warrant it:

> a Vitamix 5200.

The narrator therefore must not lexicalize from canonical database identity merely because the system knows the object.

Compact:

`CANONICAL OBJECT IDENTITY != NARRATOR LABEL`.

And:

> **DESCRIPTION SPECIFICITY IS EPISTEMICALLY GATED.**

## 2. Readable markings are also gated by perception

A visible marking is not automatically user-acquired text.

If "VITAMIX" is too small, occluded, outside the current sightline, or below current attention resolution, narration should not surface it.

Only when the physical/perceptual conditions support reading it may Rawlsing expose:

> VITAMIX printed on the base.

Thus:

`TEXT EXISTS ON OBJECT != USER HAS READ TEXT`.

## 3. Evidence, classification, and interpretation remain separate

Preserve:

`VISIBLE FORM`
→ perhaps `GENERIC OBJECT CLASS`
→ perhaps `READABLE MARKING`
→ perhaps `USER IDENTIFICATION`
→ perhaps `DOMAIN KNOWLEDGE`
→ perhaps `USER INTERPRETATION`.

The narrator may provide physically available evidence.

It should not perform expertise-dependent classification on the user's behalf.

## 4. Relationship to recognition provenance

SPD-0246 still matters downstream.

If Rawlsing or another actor lawfully teaches the user the word "Vitamix," that becomes acquired knowledge and may affect future recognition.

But the primary firewall is upstream:

> **DO NOT TEACH THROUGH NARRATION WHAT THE USER HAS NOT YET LAWFULLY PERCEIVED OR RECOGNIZED, EXCEPT WHERE AN ACTOR/RECORD/HELP SURFACE ACTUALLY TEACHES IT.**

## 5. Product consequence

This preserves a real pleasure of recognition.

A knowledgeable cook may see:
> a heavy blender with a squared pitcher

and think:
> that's a Vitamix.

Another user may simply see:
> a blender.

Rawlsing should not erase that difference by solving the recognition task in narration.

The same law applies to:
- books;
- art;
- knives;
- religious objects;
- fashion;
- audio equipment;
- cars;
- plants;
- tools;
- architecture;
- medicines;
- technical machinery.

## 6. Compact laws

> **CANONICAL OBJECT IDENTITY != USER-FACING LABEL.**

> **DESCRIPTION SPECIFICITY IS EPISTEMICALLY GATED.**

> **TEXT ON AN OBJECT != TEXT READ BY THE USER.**

> **NARRATION MAY EXPOSE EVIDENCE; IT MUST NOT IMPERSONATE THE USER'S EXPERTISE.**
