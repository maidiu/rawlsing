# D002 — Counterfactual Hinge, Causal-Neighborhood Entry and Decision Ownership R1

Status: PROVISIONAL_D002_REFINEMENT__READY_FOR_HOSTILE_REVIEW_AND_PROTOTYPE
Date: 2026-10-06

## 0. Correction to anti-tedium criterion

The relevant question is not:

> Can the user describe this more specifically?

The better question is:

> **CAN ANYTHING HINGE ON HOW THIS PROCEEDS?**

A broad action may remain compressed when its plausible low-level realizations are causally equivalent at the grain Rawlsing cares about.

It should expose a new decision surface when multiple plausible continuations differ materially in a way that can affect:
- physical outcome;
- time;
- resources;
- privacy;
- safety;
- access;
- another actor's perception;
- another actor's model;
- what becomes known;
- ownership/boundary;
- future possibility;
- admitted history.

This is a counterfactual-sensitivity test, not a demand for maximal description.

## 1. No scalar Nadia-responsiveness threshold

Do not create a single:
NADIA_RESPONSIVENESS = X

to decide whether an interaction matters.

The hinge is jointly produced by:
- world state;
- Nadia's current agenda;
- Nadia's attention;
- Nadia's knowledge;
- current load;
- local norms/routines;
- relation history;
- object/resource/access state;
- third parties;
- the user's stated action.

A choice can matter even if Nadia never notices it.

A choice can fail to matter even if the user describes it in great detail.

## 2. Broad intent may enter a causal neighborhood

Example:

User:
> I help with the groceries.

This does not author successful grocery-help.

It may lawfully function as:
- offer;
- willingness;
- task-entry intent;
- request to participate.

Nadia may respond:
> Oh, would you? Great. Car's out back.

and toss over the keys.

The broad input has now caused a new, concrete causal neighborhood to become relevant without forcing a menu.

The user has not yet specified:
- whether they catch the keys;
- whether they inspect the fob;
- whether they walk to the car;
- whether they snoop;
- whether they open trunk/back seat;
- how many bags they take;
- whether they ask;
- whether they delegate routine carrying.

## 3. DO can demand materialization just as ATTEND can

Earlier law:
ATTEND may force deeper canonical materialization because perception requires a more concrete world.

Current extension:

> **DO / PARTICIPATE MAY FORCE DEEPER CANONICAL MATERIALIZATION BECAUSE CAUSAL REALIZATION REQUIRES A MORE CONCRETE WORLD.**

Example:
once the user actually needs to retrieve groceries, Rawlsing may need to resolve:
- which car;
- where it is parked;
- key/fob affordances;
- where groceries are stored;
- trunk/door mechanism;
- bag count;
- heavy/fragile/wet items;
- relevant physical constraints.

This does not mean the user automatically perceives all resolved truth.

Preserve:

CAUSAL MATERIALIZATION
!= USER PERCEPTION
!= USER KNOWLEDGE.

Thus action can deepen reality while ATTEND governs what the user actually learns.

## 4. The counterfactual hinge test

For a broad intended act, the engine may conceptually evaluate a bounded set of locally plausible continuations.

Question:

> Are there materially different continuations whose differences can alter a competent causal owner?

If no:
- compress.

If yes:
- determine who owns the difference.

No exhaustive branching simulation is required.

A bounded prospective sensitivity analysis is sufficient in principle.

## 5. Decision ownership

Four broad ownership classes:

### USER OWNED
The hinge depends on:
- judgment;
- semantic content;
- interpretation;
- preference;
- strategy;
- attention;
- social stance;
- whether/when/how to intervene;
- choice among meaningfully different affordances.

Return control.

### WORLD / BODY / CHANCE OWNED
The hinge depends on:
- physics;
- represented embodiment;
- execution reliability;
- resource limits;
- lawful stochasticity.

Resolve through world/body machinery.

### ACTOR OWNED
The hinge depends on:
- what Nadia/another actor perceives;
- their uptake;
- their interpretation;
- willingness;
- response;
- independent agenda.

Resolve through actor-local machinery.

### INTERFACE OWNED
The interface may:
- expose lawful phenomenal evidence;
- clarify parser uncertainty;
- return control;
- render realized outcomes.

It may not convert its own ambiguity into world resistance.

Hard law:

> **PARSER UNCERTAINTY IS NOT DIEGETIC DIFFICULTY.**

## 6. Examples

### Walking to the car
If nothing significant can vary during the walk:
compress.

If a person calls to the user, a gate is locked, or the user sees something that materially changes feasible action:
return control.

### Three ordinary bags versus four ordinary bags
If equivalent under current body/load/time:
may compress.

If one contains eggs, one is wet, one is very heavy, or load choice changes breakage/effort:
the distinction may become a hinge.

### Hot cast iron on wood
The action is materially consequential.

World/material authority resolves heat/table risk.

Nadia may notice and intervene according to her own state.

The user then owns their response.

### Snooping in the car
Not equivalent to retrieving groceries.

Privacy, actor model, future discovery and knowledge can differ.

Expose/realize as a meaningful choice if the user attempts it.

## 7. Conditional density without scripted branches

This architecture may produce a Disco-Elysium-like phenomenology of dense conditionality without authored choice trees.

Instead of:
AUTHORED BRANCH + SKILL STAT + DICE + FLAG

Rawlsing may use:
GENERATED SPECIFIC WORLD
+ PARTIAL PERCEPTION
+ REAL USER COGNITION
+ PORTALED EMBODIMENT
+ ACTOR-LOCAL CAUSALITY
+ HISTORY
+ WORLD STATE
+ BOUNDED STOCHASTICITY.

This comparison is design-reference only, not authority.

## 8. Anti-tedium law

Do not make the user micromanage procedure merely because procedure can be described.

Hard rule:

> **IF NOTHING COMPETENTLY HINGES ON THE DIFFERENCE, COMPRESS IT.**

Conversely:

> **IF A MEANINGFUL DIFFERENCE BELONGS TO THE USER, EXPOSE IT BEFORE THE ENGINE CHOOSES FOR THEM.**

This refines the prior:
COMPRESS MECHANICS; RETURN BEFORE SUBSTITUTING FOR JUDGMENT.

## 9. P1 implication

The first bounded prototype/trace should test broad-intent entry into a causal neighborhood.

A groceries case is useful because it can exercise:
- broad offer/intent;
- actor initiative;
- keys as concrete object;
- possible chance event;
- movement;
- world materialization;
- optional ATTEND;
- privacy possibility;
- physical execution;
- task delegation;
- actor observation;
- control return.

But the case is a test fixture, not a prescribed Rawlsing activity.
