# D002 — Alpha Core Loop / Action Surface

Status: `OPEN__P0`

## Question

What is the minimum implementable interaction loop that creates genuine relational stakes beyond open-ended chat?

## Product theorem under test

Earned relationship with an unchosen, causally coherent person can itself provide directionality, tension and return motivation while training attention and care.

## Current loop hypothesis

`ENCOUNTER → ATTEND → INFER → ACT → CONSEQUENCE → REMEMBER → REPAIR / DEEPEN → NEW SITUATION`

## Problem

Conversation alone underdetermines action.

If the user can only send text, practical care, competing commitments, material assistance, invitations and failures may remain theater.

If the action system is too broad, the LLM becomes an ungoverned world simulator.

## Candidate alpha action families

Investigate the minimum useful subset:
- talk / ask / disclose;
- promise / commit;
- remind / follow up;
- offer help;
- choose among competing time commitments;
- perform bounded practical tasks through structured interfaces;
- give / spend bounded simulated resources;
- decline;
- wait / give space;
- introduce / contact another generated person;
- attend / miss an event;
- apologize / attempt repair.

## Scenario test set

The alpha loop should survive at least:
- mundane overload (dinner / homework / work);
- a remembered future commitment;
- misreading an indirect need;
- boundary refusal;
- conflict and repair;
- a practical request;
- an invitation carrying social meaning;
- absence and return;
- a situation where helping too much reduces agency;
- a situation where the persona dislikes the user's action but benefits from it;
- a situation where the persona likes the user's action but is harmed by it.

## Deliverable

A minimum action ontology, 10–20 canonical scenario probes, and an alpha surface small enough to implement without pretending to simulate arbitrary physical reality.

## Current D002 convergence

The alpha interaction surface is no longer “open-ended chat plus choices.”

Current hypothesis:

`LIVE SCENE`
→ `FINITE ATTENTION`
→ `SAY / DO / ATTEND ATTEMPT`
→ `VARIABLE TIME + WORLD FEASIBILITY`
→ `DISTRIBUTED PERCEPTION`
→ `PERSON×EVENT RESPONSE`
→ `SESSION / PRESENTATIONAL CONSEQUENCE`
→ `POSSIBLE DURABLE PROMOTION`
→ `USER-PERCEPTIBLE SURFACE`
→ `INFERENCE + NEXT ACTION`

The principal remaining D002 work is to specify the minimum implementable action ontology and prototype these laws against hostile/ordinary scenarios.
