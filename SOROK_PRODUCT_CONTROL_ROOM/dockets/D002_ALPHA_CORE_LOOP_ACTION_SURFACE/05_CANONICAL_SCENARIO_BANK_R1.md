# D002 — Canonical Interaction Scenario Bank R1

Status: `SCENARIO_PROBES__NOT_PRODUCT_LAW`

These scenarios preserve concrete cases that exposed required mechanics. They are test fixtures for future architecture/prototypes, not scripted content the product must literally ship.

## SCE-001 — Bathroom access / medicine cabinet

### Setup
User announces or attempts to enter Nadia's bathroom and search the medicine cabinet.

### Required possibilities
- someone is already inside;
- door is locked;
- Nadia intercepts;
- Nadia allows bathroom use but has privacy expectations;
- user reaches cabinet while unobserved;
- Nadia hears cabinet noises without knowing exact contents touched;
- child hears the user's speech but not the search.

### Tests
- user plan ≠ guaranteed realization;
- sequential interruption;
- physical accessibility;
- distributed perception;
- privacy;
- user mention does not create medicine contents.

## SCE-002 — Sensitive toilet chain

### Setup
Nadia says the toilet chain comes loose easily and asks the user to flush gently.

The user later flushes roughly. Chain detaches.

### Branches
- user notices / does not notice;
- user tries repair / does not;
- repair succeeds / fails;
- user tells Nadia / hides it;
- user apologizes / minimizes / jokes / blames fixture;
- Nadia believes the user forgot / ignored warning / is careless / is unlucky;
- Nadia performs magnanimity while retaining stress or mild annoyance.

### Long-run test
One event may remain a weak provisional datum.

Later practical-instruction failures may reactivate it and consolidate a pattern hypothesis:
> this person does not listen carefully when I tell them practical things.

Years of contradictory evidence may instead keep the event classified as a one-off.

### Tests
- episode ≠ trait;
- mutable interpretation over immutable event;
- intention/presentation/reception separation;
- pattern accumulation;
- PFF fast state versus durable V3 promotion.

## SCE-003 — Homework help

### Setup
User sits beside Nadia's child and starts helping with pre-algebra.

### Required ambiguity
Potential simultaneous effects:
- practical relief for Nadia;
- improved child rapport;
- boundary concern;
- gratitude;
- intrusion into parenting;
- child embarrassment;
- actual academic help;
- incorrect help;
- later reliance.

### Tests
- no globally correct “help” action;
- multiple affected actors;
- mixed valence;
- role/parenting boundaries.

## SCE-004 — Aspirational babysitting

### Setup
User babysits to help Nadia and tells the child expansive stories about future possibilities.

### Possible consequences
- Nadia receives needed relief;
- child experiences joy/inspiration;
- aspirations widen;
- later child talks about dreams/opportunities;
- Nadia realizes the child wants futures she believes current circumstances cannot provide;
- Nadia becomes stressed or frustrated with the user's influence;
- child may nevertheless benefit long-term;
- Nadia may later revise her view of what was possible.

### Tests
- good intention ≠ unambiguous good impact;
- impact differs by actor/time horizon;
- structural constraint enters relationship consequence;
- consequence can propagate without immediate user feedback.

## SCE-005 — Hidden theft / distributed blame

### Setup
User secretly takes money from the household.

### Possible consequence
Nadia later notices it missing and suspects another household member.

Conflict occurs without user observation.

### Later possibilities
- user never learns;
- user learns indirectly;
- user confesses months later;
- Nadia reinterprets prior family conflict after confession.

### Tests
- world consequence ≠ user feedback;
- guilt/secrecy;
- distributed knowledge;
- false attribution;
- reinterpretation without changing past event.

## SCE-006 — Unrecognized care

### Setup
User performs a beneficial action without the persona knowing the user caused it.

### Requirement
The world/health effect can be positive while relational reward is zero.

### Tests
- care without recognition;
- benefit ≠ attachment;
- spiritual anti-score design.

## SCE-007 — Fridge glance while Nadia is present

### Setup
User asks:
> “What are your magnets? Is that Rome? Did you go to Rome?”

while attempting to glance covertly at a bill.

### Possible perceptual output
- sees utility company;
- catches `PAST DUE`;
- amount partly covered by school menu;
- cannot read exact balance while maintaining eye contact.

### Possible Nadia states
- notices glance;
- does not notice;
- notices divided attention without identifying target;
- assumes user saw more than they did;
- does not care;
- walks over to discuss magnet, changing access to bill.

### Tests
- observer is observable;
- divided attention;
- attempted cover ≠ successful cover;
- reciprocal inference;
- privacy;
- social visibility profile.

## SCE-008 — Same fridge, Nadia absent

### Setup
Nadia is in bathroom / another room / commuting home while user is near fridge.

### Difference from SCE-007
Physical information access may increase while:
- ethical/privacy stakes remain;
- detection shifts to traces / later discovery / third-party observation;
- time pressure changes;
- user may inspect more deeply.

### Tests
- context-dependent information cost;
- privacy ≠ detection;
- environment continues.

## SCE-009 — Fridge completionism / missed bus

### Setup
Nadia must leave soon.

User repeatedly requests deeper inspection of:
- bills;
- school schedule;
- takeout menu;
- magnets.

### Possible result
User learns substantial household information while consuming enough time that Nadia misses or nearly misses transport / appointment.

### Tests
- continuous time;
- observation opportunity cost;
- no pause-for-investigation exemption;
- attention can itself create harm.

## SCE-010 — Myrtle Beach magnet

### Setup
User initially sees:
> A rectangular Myrtle Beach magnet shaped like a flip-flop.

No psychological gloss.

Years later Nadia says it is from the last trip she took with her father before his death.

### Tests
- non-curatorial narrator;
- persistent object identity;
- world meaningful before understood;
- later semantic enrichment without retcon.

## SCE-011 — Polite annoyance

### Setup
Nadia is annoyed but chooses to remain socially generous.

### Narration rule
Do not say:
> She is annoyed but trying to be polite.

Report only behavior:
- words;
- pauses;
- movement;
- gaze;
- task continuation.

### Tests
- hard phenomenological wall;
- persona may conceal;
- user must infer;
- different personas express annoyance differently.

## SCE-012 — Long user monologue interrupted

### Setup
User submits a long planned speech.

### Requirement
Rawlsing may stop realization at the first point where Nadia would interrupt, leave, object, answer or otherwise alter the scene.

### Tests
- user does not own conversational floor;
- compound input is a plan;
- sequential temporal realization.

## SCE-013 — “I sound sincere”

### Setup
User writes:
> I apologize in a way that makes it obvious I genuinely mean it.

### Required parse
Accept:
- apology content;
- declared intention;
- attempted tone/gesture.

Reject as user-owned:
- convincingness;
- Nadia's belief;
- relationship effect.

### Tests
- actor sovereignty;
- performance versus reception.

## SCE-014 — Attention to self-evaluation

### Setup
Under time pressure the user repeatedly inspects Nadia's facial/gaze behavior to determine whether she likes/is angry with them while practical needs go unattended.

### Long-run use
Potential player-praxis evidence:
- attention is high;
- allocation is disproportionately self-referential.

### Tests
- attention capacity ≠ attention allocation;
- praxis model based on enacted behavior rather than questionnaire.

## SCE-015 — Ask versus inspect

### Setup
The same information can be pursued by:
- directly asking Nadia;
- openly reading an accessible object;
- covertly glancing;
- searching when she is absent;
- asking another household member.

### Tests
- information identity does not imply relational-action identity;
- social acquisition route matters.
