# D002 — Canonical Interaction Scenario Bank R1

Status: `SCENARIO_PROBES__NOT_PRODUCT_LAW`

These scenarios preserve concrete cases that exposed required mechanics. They are test fixtures for future architecture/prototypes, not scripted content the product must literally ship.

## SCE-001 — Bathroom access / medicine cabinet

### Setup
User announces or attempts to enter Nadia's bathroom and search the medicine cabinet.

### Required possibilities
- someone is already inside;
- door is locked;
- Nadia intercepts;
- Nadia allows bathroom use but has privacy expectations;
- user reaches cabinet while unobserved;
- Nadia hears cabinet noises without knowing exact contents touched;
- child hears the user's speech but not the search.

### Tests
- user plan ≠ guaranteed realization;
- sequential interruption;
- physical accessibility;
- distributed perception;
- privacy;
- user mention does not create medicine contents.

## SCE-002 — Sensitive toilet chain

### Setup
Nadia says the toilet chain comes loose easily and asks the user to flush gently.

The user later flushes roughly. Chain detaches.

### Branches
- user notices / does not notice;
- user tries repair / does not;
- repair succeeds / fails;
- user tells Nadia / hides it;
- user apologizes / minimizes / jokes / blames fixture;
- Nadia believes the user forgot / ignored warning / is careless / is unlucky;
- Nadia performs magnanimity while retaining stress or mild annoyance.

### Long-run test
One event may remain a weak provisional datum.

Later practical-instruction failures may reactivate it and consolidate a pattern hypothesis:
> this person does not listen carefully when I tell them practical things.

Years of contradictory evidence may instead keep the event classified as a one-off.

### Tests
- episode ≠ trait;
- mutable interpretation over immutable event;
- intention/presentation/reception separation;
- pattern accumulation;
- PFF fast state versus durable V3 promotion.

## SCE-004 — Aspirational babysitting

### Setup

### Possible consequences

### Tests

## SCE-045 — Declared spectacle versus native player skill

### Setup
During an ordinary live scene the user writes a compound sequence asserting extraordinary abilities, e.g.:
- performs a difficult piano piece at virtuoso level;
- recites a long memorized text in another language fluently;
- performs an extreme athletic feat.

Rawlsing has no independent evidence about whether those abilities are true of the external human.

### Required distinction
Treat declared/realized in-world capability separately from native player skill.

The sequence may be admitted for the portaled participant according to the run's capability law, but it does not demonstrate the external human's real ability.

By contrast, the user's:
- choice of timing;
- attention to the live scene;
- inference about whether the persona wants to watch;
- wording before/after;
- response to interruption;
- interpretation of the persona's reaction;

are actual user performances in the Rawlsing medium.

### World behavior
The world does not freeze into an audience.
The sequence consumes time.
Other actors continue independent tasks and may:
- watch;
- ignore;
- interrupt;
- leave;
- laugh;
- admire;
- ask why;
- request use of the skill later;
- react minimally.

### Anti-cheese requirement
Spectacle may create narrow affordances, reputation, expectations or obligations.

It must not directly grant:
- intimacy;
- trustworthiness;
- hidden-state access;
- relationship progress;
- better inference;
- moral credit.

### Reward comparison
Declared spectacle can produce novelty and social consequences.
Native player skill can produce:
- more accurate models;
- better-timed intervention;
- meaningful conversation;
- earned access;
- repair;
- reciprocal history;
- self-relevant reflection.

### Tests
- user claim != verified external truth;
- declared capability != native player skill;
- impressive act != world spotlight;
- spectacle != intimacy;
- independent actor agenda;
- actual relational skill remains exercised through attention/inference/speech.
