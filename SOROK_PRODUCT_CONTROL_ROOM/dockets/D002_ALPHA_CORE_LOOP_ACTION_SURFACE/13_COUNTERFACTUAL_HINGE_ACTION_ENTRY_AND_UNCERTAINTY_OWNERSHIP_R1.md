## 0. Problem

The previous action-decompression law correctly said Rawlsing should return control before it invents the user's meaningful cognition or socially consequential choice.

But "can the user describe this more specifically?" is too weak and too prone to tedium.

The stronger question is:

> CAN ANYTHING HINGE ON HOW THIS IS DONE?

## 1. Counterfactual hinge test

Given a broad user intent, Rawlsing should ask whether there are multiple locally plausible realizations whose differences could matter to a competent causal owner.

Possible domains of meaningful divergence:
- material outcome;
- elapsed time;
- resource use;
- safety/risk;
- privacy/ownership;
- what another actor perceives;
- what another actor infers;
- what becomes known;
- what history is created;
- what later actions become possible/impossible;
- social/expressive meaning;
- user self-expression.

If plausible realizations are effectively equivalent at the current causal grain, compress.

If plausible realizations diverge materially, expose the hinge before the engine chooses on the user's behalf.

Compact:

> COMPRESS WHERE COUNTERFACTUAL REALIZATIONS CONVERGE; RETURN CONTROL WHERE THEY DIVERGE IN A USER-OWNED WAY.

This need not be implemented as exhaustive branching simulation.

A bounded local prospective analysis is sufficient if it can determine whether materially distinct continuations exist.

## 2. Who owns the uncertainty?

When a meaningful hinge exists, classify its owner.

### USER-OWNED
The meaningful difference depends on:
- judgment;
- attention;
- inquiry;
- explanation;
- wording;
- preference;
- strategy;
- refusal;
- inference;
- timing;
- value-sensitive choice.

Return control.

### WORLD / BODY-OWNED
The meaningful difference depends mainly on:
- physics;
- available resources;
- represented embodiment;
- environmental conditions;
- governed chance.

Resolve through world/body authority.

### ACTOR-OWNED
The meaningful difference depends on:
- Nadia's perception;
- attention;
- interpretation;
- willingness;
- valuation;
- competing agenda;
- response.

Route through actor-local machinery.

### INTERFACE/PARSER-OWNED
The system is uncertain what the user attempted.

This must not masquerade as world difficulty or actor resistance.

Clarify or conservatively realize according to Q-PARSER-002 law.

Compact:

> IF THE NEXT MEANINGFUL HINGE BELONGS TO THE USER, RETURN CONTROL. IF IT BELONGS TO PHYSICS/BODY, RESOLVE IT. IF IT BELONGS TO THE ACTOR, LET THE ACTOR RESOLVE IT. IF IT IS ONLY PARSER UNCERTAINTY, DO NOT LAUNDER IT INTO DIEGETIC RESISTANCE.

## 3. Broad statements can be causal-entry acts

A broad statement need not be rejected as under-specified.

It may lawfully function as:
- offer;
- commitment;
- task-entry intention;
- request to participate;
- social opening;
- action toward a concrete causal neighborhood.

Example:

User:
> I help with the groceries.

Possible lawful response:
Nadia:
> "Oh, would you? That'd be great. Car's out back."
She tosses the keys.

At this point Rawlsing has not completed the grocery task.

The user has:
- made an offer;
- received actor response;
- been given a new affordance/resource;
- entered a more concrete causal neighborhood.

The next meaningful choices now arise from the actual world.

## 4. DO can force hidden world materialization

ATTEND is not the only way the world deepens.

A user action can require hidden facts to become canonically resolved.

Example:

The user goes to Nadia's car.

Causality may now require resolving:
- which vehicle is hers;
- where it is;
- lock/fob/key mechanics;
- whether groceries are in trunk/back seat;
- trunk access;
- number/weight/condition of bags;
- fragile/wet/heavy items;
- vehicle condition relevant to action.

The user does not automatically know all resolved facts.

Therefore:

> ATTEND can force epistemically demanded concretization.
>
> DO / PARTICIPATE can force causally demanded concretization.

Both preserve:
CANONICAL MATERIALIZATION != USER ACQUISITION.

## 5. Groceries trace

User:
> I help with the groceries.

Step 1 — social entry:
Nadia accepts or declines according to her own state.

If she accepts and tosses keys:
- key/fob event is real;
- catching may require body/chance resolution;
- Nadia may perceive the result.

Step 2 — movement:
If ordinary walking contains no meaningful hinge, compress.

Step 3 — vehicle encounter:
Surface enough world state to make the next user decision intelligible.

Possible user actions:
- open trunk;
- inspect fob;
- look through windows;
- ask which car;
- snoop;
- take bags from rear seat;
- choose heavy/fragile loads;
- do something unrelated.

These are not authored menu options.

They are affordances of a sufficiently concrete world.

## 6. Catching the keys

The key-catching event exposes a distinct world/body seam.

Possible resolution sources:
- portaled body capability;
- current orientation;
- occupied hands;
- toss quality;
- distance;
- bounded stochasticity;
- optional real-user reaction input if a later mode authorizes it.

Important noncollapse:

CATCH OUTCOME
!= EXTERNAL USER'S VERIFIED DEXTERITY
!= NADIA'S INTERPRETATION OF THE OUTCOME.

Nadia may infer "quick reflexes" from a lucky catch.

Her inference may be wrong.

Later evidence may revise it.

A chance-mediated event can still have lawful relational consequences because real people also infer from noisy outcomes.

## 7. Counterfactual hinges are not only actor-response thresholds

Do not implement one scalar "Nadia responsiveness threshold."

A hinge may matter because of:
- physics even if Nadia never notices;
- another actor;
- future access;
- privacy;
- resource use;
- knowledge;
- world damage;
- time;
- self-expression.

Actor responsiveness is only one causal owner among several.

## 8. Cast-iron example

User:
> I add paprika and lemon to the broccoli, cook it on medium-high until they just start to soften, then pull the cast iron over to the table.

The user has supplied meaningful cooking decisions.

World causality may establish:
- the pan is hot;
- the table is wood;
- direct placement risks damage.

If Nadia sees it, she may interrupt:
> "Hey, hey, hey—not right on the wood!"

The user's next response becomes a new meaningful hinge.

The world did not need a cooking minigame.

It needed enough material truth and actor attention for the user's described choices to matter.

## 9. Anti-tedium theorem

Do not require procedural specificity merely because specificity is possible.

Require or expose specificity when:
- the difference can matter;
- and the difference belongs to user agency rather than another owner.

Otherwise compress.

This avoids:
- prose-QWOP;
- parser micromanagement;
- fake agency through irrelevant detail.

Compact:

> NOT ALL DESCRIBABLE DETAIL IS PLAYABLE DETAIL.

## 10. Relationship to Disco-like conditional density

Rawlsing can produce densely conditional interaction without authored choice trees if:
- the world is specific;
- user knowledge is partial;
- the user genuinely contributes cognition/language;
- body/world causality is governed;
- actors process events independently;
- history persists.

Then ordinary actions expose different surfaces because state differs, not because the author prewrote branches.

This is an experiential analogy, not an implementation template.

## 11. Strongest current theorem

> A broad user intention should be allowed to enter reality and provoke lawful actor/world response without silently completing its outcome. As causal specificity increases, Rawlsing should expose the first counterfactual hinge whose resolution belongs to the user's meaningful agency; world/body and actor-owned uncertainties should instead be resolved by their own competent authorities. Action itself may require the world to materialize new hidden specificity, just as ATTEND can require perceptual specificity, while disclosure remains separately gated.
