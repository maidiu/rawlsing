## 1. Core theorem

Objective event does not equal actor experience.

For every affected actor, Rawlsing must preserve the semantic equivalent of a noncollapsed path such as:

`OBJECTIVE EVENT`
→ `SENSORY / OBSERVATIONAL ACCESS`
→ `CAN-008 RECEIVABILITY / UPTAKE-APPRAISAL + SITUATED RECRUITMENT`
→ `IMMEDIATE MULTI-STREAM RESPONSE / METABOLISM`
→ `PRESENT ACTOR EXPERIENCE / AWARENESS / SELF-INTERPRETATION WHERE LAWFUL`
→ `CURRENT INTENTION / INHIBITION / DEFENSE / PRESENTATION CONSEQUENCES`
→ `V2 ACTOR-LAWFUL OUTWARD ACTION / EXPRESSION`
→ `ACTUAL OCCURRENCE / POSSIBLE RE-ENTRY`
→ `DURABLE MEMORY / RELATIONSHIP / SELF-MODEL EFFECT ONLY THROUGH COMPETENT V3 OWNER`

This is conceptual decomposition, not a claim that every arrow is a separate stored object or that the process is strictly linear. PFF explicitly established valid nonlinear paths, including expression preceding self-recognition.

## 2. Perception is actor-specific

Nadia may:
- hear cabinet doors;
- hear the user shout from the bathroom;
- not see which bottle was touched.

The child may:
- hear the joke;
- not hear the cabinet;
- see Nadia's later expression.

Another actor may perceive none of it.

Each actor receives their own lawful perceptual packet.

## 3. Sensory access is graded, not binary

Perception may vary by:
- distance;
- walls/doors;
- noise masking;
- current orientation;
- visual obstruction;
- attention;
- divided attention;
- expectation;
- current task;
- sensory ability where represented.

Possible states include:
- clear;
- partial;
- ambiguous;
- misheard;
- unnoticed.

## 4. Actor attention is finite

Nadia at the stove is not an omnidirectional recorder.

She may:
- half-hear the user's comment;
- miss a glance;
- notice the cabinet sound only after a delay;
- prioritize a boiling pot or her child.

Non-player-centricity therefore requires not only independent agenda but finite actor attention.

## 5. Uptake is not equivalent to conscious proposition — inherited law

An event can alter current response without the actor explicitly formulating:

> He doesn't listen to me.

A mild annoyance may remain:
- affectively present;
- behaviorally influential;
- weakly associated with the event;
- not yet consolidated into a conscious judgment.

Do not force every causal state into explicit inner monologue.

## 6. Internal response ≠ outward expression — inherited law

Nadia may:
- feel annoyed;
- believe the user probably forgot;
- appreciate their forthrightness;
- decide not to make a problem of it;
- outwardly say, “It's okay, don't worry about it.”

The expression is one causal output of the internal response, not a transparent readout.

PFF/CAN-008 ownership must preserve this gap.

## 7. Self-access can also be partial — inherited law, not a new Sorok hypothesis

The persona need not possess perfect introspective access to their own state.

Potentially:
- Nadia knows she is irritated but not why;
- she consciously forgives the incident while a weak pattern trace remains;
- she later recognizes that multiple incidents had accumulated;
- she misattributes a feeling.

This is already constrained by inherited PFF laws:

- causal activity != conscious presence;
- felt != named;
- recognized state != correct causal explanation;
- actor self-explanation != machine causal account;
- hidden cause may produce conscious effect without becoming actor knowledge;
- defense may act before, within or after awareness;
- leakage is possible but not mandatory;
- full inhibition without detectable leakage is lawful;
- expression may trigger later self-recognition;
- renderer wording cannot retroactively prove prior hidden cause.

Therefore this is not a license for arbitrary “mystery unconscious” invention. Hidden influence must be generated through lawful person/event causality and actor-access boundaries.

## 8. Memory encoding is selective

Not every event becomes equally durable.

Candidate determinants:
- intensity;
- novelty;
- relevance to active concerns;
- repetition;
- relational importance;
- current stress;
- later reactivation.

Some events may:
- fade;
- retain gist but lose detail;
- remain vivid;
- be misremembered;
- be reinterpreted.

Objective history and actor memory remain separate.

## 9. Pattern hypotheses need confidence and counterevidence

A pattern such as:
> the user does not listen to practical instructions

should support:
- weak initial evidence;
- confidence growth through repetition;
- counterevidence;
- context specificity;
- possible decay;
- later reinterpretation.

This is richer than a trait toggle.

## 10. Each affected actor processes independently

If the user influences Nadia's child, the child receives their own:
- perception;
- appraisal;
- immediate response;
- memory/significance;
- later action trajectory.

Nadia later encounters those downstream actions as new events.

Do not compute the child merely as “effect on Nadia.”

## 11. Narrator boundary

None of these private layers become user-visible merely because they exist.

The user gets:
- outward behavior;
- speech;
- perceptible physical changes;
- later disclosures;
- consequences.

The private causal machinery exists precisely so that the surface can remain opaque without becoming random.
