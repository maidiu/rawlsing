# D008 — User Model, Signaling, Competence and Model Noncollapse R1

Status: PROVISIONAL_PRODUCT_LAW__OPEN_EXACT_REPRESENTATION
Date: 2026-10-06

## 0. Problem

A user's language and behavior can suggest forms of knowledge, class formation, cultural capital, practical familiarity, status orientation or expertise without proving them.

Rawlsing must not collapse:
- lexical familiarity;
- social signaling skill;
- actual sustained knowledge;
- procedural competence;
- structural origin;
- another actor's impression of competence.

This is essential both for truthful user modeling and for social misunderstanding to remain real.

## 1. Core noncollapse

Preserve:

LEXICAL FAMILIARITY
!= RECOGNITION
!= SOCIAL-SIGNALING COMPETENCE
!= SUSTAINED DISCURSIVE COMPETENCE
!= PROCEDURAL / DOMAIN COMPETENCE
!= ORIGIN / MILIEU.

Example:
a user may invoke Italian Renaissance poetry correctly as a breadth-of-field marker without being able to discuss the field knowledgeably.

Likewise references to Aston Martins, truffle oil, Seychelles, astrology or quantum uncertainty may be pragmatically apt while proving little about domain mastery or lived milieu.

What may actually be demonstrated is:

> the user knows what social-semantic work this reference can do here.

That is itself a capacity.

## 2. Competence signaling is playable behavior

Users may:
- imply greater knowledge than they possess;
- knowingly allow another actor to overestimate them;
- downplay knowledge to avoid intimidation or expectation;
- strategically signal breadth in a hostile environment;
- use references as irony, class performance, humor, threat or affinity.

These are real social actions.

Rawlsing should preserve them rather than collapsing every display into a true capability stat.

## 3. Nadia may be wrong about the user

Strong law:

USER SOCIAL PERFORMANCE
→ NADIA PERCEIVES PERFORMANCE
→ NADIA FORMS HYPOTHESIS OF USER.

That hypothesis can be:
- accurate;
- overestimating;
- underestimating;
- skeptical;
- hostile;
- admiring;
- indifferent.

Depending on Nadia's own history, education, insecurity, skepticism, experience with status performance, relationship history and current mood/agenda.

Later evidence may produce disillusionment or awkwardness.

This is not a failed “knowledge check.”

It is a relational event generated by:
PAST PERFORMANCE + NADIA'S MODEL + USER'S AWARENESS/NONAWARENESS + LATER CONTRADICTORY EVIDENCE.

## 4. System model and Nadia model stay separate

Rawlsing may have provenance showing:
- the user deployed a reference correctly;
- no sustained competence has been demonstrated;
- the user often downshifts display when expected to perform;
- the user's actual knowledge remains uncertain.

Nadia need not possess that analytic separation.

Therefore:

SYSTEM USER MODEL != NADIA USER MODEL.

## 5. Habitus-like inference without class essentialism

Rawlsing may maintain uncertain, longitudinal hypotheses about practical dispositions demonstrated in play:
- what distinctions appear effortless;
- what the user treats as ordinary;
- what they recognize rapidly;
- what they classify as tacky/pretentious/expensive/normal;
- what kinds of authority they challenge;
- what institutions they treat as navigable;
- what forms of privacy they presume;
- what practical tasks feel familiar;
- where cultural references are used as ordinary language.

But:

PRACTICAL-DISPOSITION EVIDENCE != TRUE CLASS ORIGIN.

Do not infer exact income, childhood class, education history, family culture or occupation without separate user-supplied authority.

The model may say:
> the user repeatedly treats bureaucratic procedure as navigable.

It may not say:
> therefore the user is upper-middle-class.

## 6. Homologous-peer relationship

This composes with Court 7:

CARRIED PRACTICAL DISPOSITIONS
× HOMOLOGIZED STRUCTURAL POSITION
× INDEPENDENT LOCAL FIELD
→ possible HABITUS FRICTION.

Rawlsing need not reconstruct the user's original class position in order to expose habits formed under it.

## 7. User-model symmetry

Strong principle:

> NO PARTICIPANT IS EXHAUSTED BY ANOTHER PARTICIPANT'S MODEL OF THEM—INCLUDING THE PLAYER.

Thus:

USER != RAWLSING'S BEST MODEL OF USER

just as:

NADIA != USER'S BEST MODEL OF NADIA.

The system-side user model should remain behavioral, provenance-bearing, probabilistic, revisable and purpose-limited.

## 8. Privacy / misuse firewall

The practical-disposition/user-lens model is sensitive.

At minimum:
- narration personalization may use only the subset authorized by D008/01;
- reflective surfaces require user-facing provenance/uncertainty;
- the model must not silently become advertising segmentation;
- deletion/export/disable controls inherit Q-PRIV-001;
- behavioral hypotheses may not become hidden eligibility, worthiness or moral scoring.
