# D001 — Relational Ontology / V3 Boundary

Status: `OPEN__P0`

## Question

What is the minimum ontology necessary to represent a historically produced person in relation, and which parts belong to V3 versus a downstream dyadic/network runtime?

## Why this is first

Storage, time, messaging, game mechanics and player modeling will all ossify the wrong design if the canonical objects are wrong.

## Current hypothesis

V3 should own person-internal developmental organization and relational priors.

A later runtime should own actual user↔persona dyadic history, mutual models, trust/injury/repair, commitments and network consequences.

This boundary is provisional.

## Required distinctions to adjudicate

- disposition;
- relational prior;
- role-conditioned tendency;
- developmental residue;
- self-model;
- generalized other-model capacity;
- specific model-of-user;
- dyadic state;
- network state;
- health potential versus realized health trajectory;
- objective event;
- actor memory;
- actor interpretation;
- expression.

## Key tests

1. Can two identical V3 persons develop materially different relationships with different users without V3 mutation becoming arbitrary?
2. Can one person behave differently by relational role without contradiction being treated as drift?
3. Can dyadic history alter the person over time without erasing the distinction between person state and relationship state?
4. Can the ontology represent isolation as formative relation?
5. Can the LLM remain expressive rather than ontological?

## Repo / architecture review required

Crosswalk against:
- governing spirit;
- PRE-V3 terminal demand;
- deferred PRE-V3→V3 seam;
- current V3 / CAN-008 / PFF / V2 inheritance;
- genealogy / family / relationship-history provisions already preserved.

## External research candidates

Developmental, attachment, relational psychoanalytic, interpersonal, family-systems and social-cognition literatures may inform the model.

The N-M-L child-development work should be reviewed for developmental continuity, adult contraction, attachment/dependence and non-alienated relational development. It is not automatically product law.

## Deliverable

A finite ontology table:
`OBJECT | OWNER | CREATED_FROM | MUTATED_BY | OBSERVABLE_TO | PERSISTENCE | DOWNSTREAM_CONSUMERS | MUST_NOT_MEAN`

plus an exact proposed V3/dyad seam and alternatives rejected.
