# D001 — Inherited Temporal-Grain Architecture R1

Status: `INHERITED_ARCHITECTURE_CONTEXT__MUST_NOT_BE_REDISCOVERED_AS_GREEN_FIELD`

## 1. Purpose

Sorok product ideation must begin from the already-developed V3/PFF/SDTF architecture rather than collapsing “V3” into one generic recursion layer.

The product work may reveal missing semantics or ownership problems. It must not manufacture those gaps by forgetting the temporal-grain decomposition already established.

## 2. Existing decomposition

### SDTF / upstream structural-developmental transduction

Upstream structural reality does not become psyche directly.

SDTF-style transduction exists to convert structural/material/social reality into actor-legitimate developmental conditions, opportunities, constraints, mediations and causal inputs at the proper grain.

It must preserve the prohibition:

`STRUCTURE ≠ PSYCHE`

and the developmental chain by which possible conditions become actual lived history.

### Durable / formative V3

The many-recursion, from-birth / life-course side owns the actor's generated developmental history and durable person state.

This includes, at the appropriate accepted owner grain:
- realized developmental biography;
- persistent change;
- durable memory / causal traces;
- long-run relational histories;
- genealogy;
- path dependence;
- developmental middle states;
- rupture / metabolization where separately governed;
- attractor history;
- durable self/world/other organization.

The product's new relational emphasis should change what this layer is eventually required to represent, not erase its temporal role.

### CAN-008 person×event coupling

CAN-008 supplies the shared transaction logic by which an already-developed person encounters a current event/input.

The important inherited distinctions include:
- event/exposure ≠ response;
- response ≠ persistent change;
- simultaneous response streams ≠ one scalar net pressure;
- immediate actor-level response may buffer, amplify, deflect, reroute, transform or block already-generated causal effects without rewriting upstream structural truth;
- path dependence may recruit prior response history without converting history into a universal trait scalar.

For Sorok, CAN-008 is the natural place to ask how the current user event is:
- perceived / receivable;
- taken up;
- appraised;
- routed through currently active person organization;
- converted into immediate response effects.

It is not by itself the entire durable relationship.

### PFF interaction-fast / session grain

Prior Psychic Field Forge work already separated faster interaction/session phenomena from durable developmental V3 state.

Sorok must preserve the distinction among:
- turn-ephemeral state;
- session-live / RAW interaction state;
- durable V3 person state.

PFF is therefore the first inherited candidate owner for:
- interaction-fast ambiguity;
- current presentation/defense;
- user-opacity;
- temporary recruitment;
- immediately live relational configuration;
- session-local self/other modeling;
- transient salience before durable promotion.

PFF must not become a second biography generator.

### V2 expression

V2 renders actor-safe phenomenal/expression surfaces.

It does not acquire causal sovereignty merely because it produces words.

Rendered text/action becomes causal life only through the accepted admission path.

## 3. Sorok relational-placement test

For every newly proposed relational semantic, D001 should ask in order:

1. Is this an **objective PRE-V3 world fact**?
2. Is this a **durable developed property/history of the actor**, belonging to durable V3?
3. Is this a **current actor×event uptake/response**, belonging to CAN-008?
4. Is this **interaction-fast/session/user-opacity state**, belonging to PFF?
5. Is this merely **phenomenological/expression rendering**, belonging to V2?
6. Is it genuinely a **relationship/network object that remains ownerless** after those tests?

Only step 6 can justify proposing a new owner.

## 5. Key temporal law

A single event such as “the user broke the toilet chain after a warning” may produce:

`current event`
→ `CAN-008 immediate person×event response`
→ `PFF live presentation / session configuration`
→ `possibly no durable change`

while leaving an episodic trace that later events can reactivate.

Repeated or sufficiently important events may eventually justify:

`episodic accumulation → pattern consolidation → durable developmental/relational reorganization`

The exact promotion owners/rules remain an open D001 question.

## 6. Anti-regression warning

Do not introduce a generic “live V3” abstraction that blurs these already-developed temporal grains.

Do not infer that every conversational turn should rerun the entire from-birth developmental biography.

Do not infer that because a fact is interaction-relevant it belongs in PFF.

Do not infer that because a reaction is psychologically deep it is immediately durable.

Sorok's job is to sharpen the existing architecture against the product, not replace it with a simpler architecture by forgetting what already exists.
