## 3. Seven mutually exclusive source-grain labels

| Value | Sufficient source evidence | Prohibited inference |
|---|---|---|
| `SPINE_CURRENT` | Current governing C/A/S/Neo concept, primary controlling law, **or** specifically accepted implementation at its **stated** scope | A governing *requirement* does not mean accepted code, issued science or operational human proof |
| `SPINE_REQUIRED_UNBUILT` | Independently established contemporary obligation with missing scoped native/owner/actor/reader/implementation evidence | Missing obligation ≠ permission or ticket to implement new code |
| `HISTORICAL_SUBLATED` | Exact old behavior visibly absorbed or replaced by accepted current **consumer** at matching scope, with proof | Similar name, broad schema/section placement or unreviewed proposed port |
| `HISTORICAL_CANDIDATE` | Old or unmerged function/code/theory viable for comparison against an already established current duty | Auto-port, automatic priority or fitness to govern psychology |
| `HISTORICAL_REJECTED` | Exact negative/unsuitable/REVISE proof at the reviewed source/claim scope | Erase all historical utility or extend one rejection to other versions |
| `REFERENCE_ONLY` | Source/evidence/idea/guide edge/review/packet important for context without independent architectural standing | `READY`, `REQUIRED`, source link or package name as new law |
| `UNRESOLVED` | Inadequate qualified content/consumer/owner to assign a stronger meaning | Guess at missing source's contents; invent a build |

A category applies **to the row at the granularity stated**. A single source can carry a current normative principle and an old implementation candidate. The latter does not inherit the former's authority. There are four additive target-specific override records to exemplify this.

## 4. The six evidence axes are not interchangeable

`I/source occurrence` → `T/scientific or normative determination` → `A/interface and source contract` → `E/executable code` → `C/actual first-reader consumption` → `V/independent exact-scope authority/human validation`. Every `KNOW → SPECIFY → BUILD → INTEGRATE → VERIFY → ACCEPT` phase must also retain its **claim grade** (`DOCUMENTARY`, `SOURCEFREE`, `NATIVE`, `HUMAN`) and its exact source/actor/branch/mode. A `READY_TO_SPECIFY` source row may authorize a **request for a decision**, but never authorizes a source grant, actor rule or `ACCEPT`.

For `ALL_OF`, all active same-target members must qualify; for `ANY_OF`, an actual alternative must be selected and evidenced; an `IF` with no selected predicate is `MODE_UNSELECTED` rather than satisfied. Reverse edges are syntactic until every other active target predicate/member/owner condition is checked.
