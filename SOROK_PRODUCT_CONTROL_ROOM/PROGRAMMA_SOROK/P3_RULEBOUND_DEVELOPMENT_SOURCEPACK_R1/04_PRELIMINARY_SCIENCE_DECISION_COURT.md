# 04 — Pre-implementation theoretical and scientific decision court

**Purpose:** identify the *remaining* intellectual questions P3 cannot solve by routine coding. This is a **nonissuing deliberation dossier**. It does not reopen user-settled October 26 recursion, closed V3/V2 semantic boundaries, or CAN/ADP canonicalized constitutions. See [03](03_RUNTIME_FIRST_CONSUMER_AND_SUPERSESSION.md) for code and supersession, [02](02_GATE_AND_HISTORICAL_FUNCTION_CROSSWALK.json) for exact O/C/S gates.

## A. Already settled — DO NOT solicit new theory as if no decision exists

1. **Recursion architecture**: a prospective 3–5-event half-call, sequential actual events and intervening time, retrospective half of following call completing prior cycle, then new prospective batch. Source: October 26 user decision, received PR #704.
2. **Ontology separation**: world/structural conditions, admitted event, actor access, CAN-008 response, CAN-010 need/expectation/striving, CAN-011 middle state, ADP-016 memory, ADP-017 knowledge, expression and narrative are distinct. No structural/demographic direct psyche mapping.
3. **Middle-state families**: exactly three CAN-011 terminal kinds `MEDIATOR`, `TENSION`, `PRACTICE`, with multiple coexisting/contradictory instances, including valid empty. Not six permanent modules and not Enneagram states.
4. **Responses**: CAN-008 streams preserve independent conflicting parents; operators are `BUFFER`, `AMPLIFY`, `DEFLECT`, `REROUTE`, `TRANSFORM`, `BLOCK`, but these do not themselves create target-state content or numbers.
5. **Memory**: ADP-016 distinguishes event-referential and causal-trace memory, objective history, actor-accessible memory and ADP-017 knowledge. LLM retrospective prose alone cannot mint memory.
6. **Time and emptiness**: no universal year-based decline, reinforcement, healing, memory loss, practice mastery or implicit absence-based mutation. Silence may mean persistence; `MISSING_RULE` is not an evaluated `NO_CHANGE`.
7. **Contradiction**: unresolved expectations, tensions, causal streams and incompatible strivings need not be narratively or numerically harmonized.

The package **must not send Codex on a hunt for new overarching personality theory**. It must also not treat semantic canonicalization as an already-existing executable psychological law.

## B. Five genuinely open decision fronts

### D-P3-01 — What *minimal lawful event→response rule* exists in the original sources?

**Question:** Given a generated/admitted actor-experienced event and prior state, what exact reproducible rule can produce a CAN-008 response *without* equating a social category with a personality or putting an LLM in charge of outcome?

**Existing law:** CAN-008 supplies transaction structure and effect grammar; CAN-010/011/017 bound targets. It does **not** license `PRESSURE=0.8 → SHAME+10`, a generic adversity→wound conversion or a fixed emotional category.

**Work needed:** original rule provenance and input readsets; candidate registration; stable stream/parent IDs; state/history predicate; validated target-authority effects; rival possible responses; all target state receipts; counterfactual/severance; original issuer and consumer acceptance.

**Possible scientific direction — NOT AN ISSUED RULE:** first try explicitly evidenced actor *activity* and material constraints rather than abstract event taxonomies. The same event is not guaranteed to produce the same response in two differently situated actors. Work already supports a transaction shell and valid-empty response; whether a positive result is justified remains an issuance decision.

**Status:** SCIENTIFIC_RULE_OPEN. Mechanical transaction ABI may proceed at TEST_ONLY with sourcefree fixtures.

### D-P3-02 — What distinguishes an acquired *practice* from an exposed, attempted, temporarily enabled or merely performed act? (O05)

**Question:** What exact evidence supports `V3MS_PRACTICE` creation/revision, such that the later event consumes a new acquired operation—not simply different tools, free time, permission, social pressure or a one-time performed movement?

**Existing law:** CAN-011's `CREATE/REINFORCE/...` is a generic typed transition grammar. `O05@ACCEPT` requires an original positive Rule-T discriminator and exact C4/C8 owners. `O15` requires a later *actual semantic E2* consumer; an offered option is insufficient.

**Candidate rival cases to distinguish:**
- **H0**: same actor has not acquired the practice; changed opportunity, teacher, equipment or assignment alone explains later performance.
- **H1**: actor has undergone documented, situated practice formation; controlled later E2 demands the operation and produces a different lawful outcome.
- **H2**: initial response/temporary assistance, no durable acquisition; later under comparable conditions reverts or refuses.
- **H3**: performance is accomplished by a different actor/institution or external aid; no first-person acquired capacity.

Require tests that preserve material role, actor identity, comparable task affordances and access readsets. An experiential narrative saying “now I know how” is not Rule T.

**Status:** ORIGINAL_ISSUER_DECISION_REQUIRED. An engineering fixture can demonstrate machinery but not a genuine acquired human practice.

### D-P3-03 — What counts as positively evaluated *NO_CHANGE*, without converting scientific ignorance into inertia? (O07)

**Question:** Which original consumer predicates can *actually evaluate* the relevant post-event state and conclude that the actor persisted unchanged in the target property?

**Existing law:** `G-O07-NOCHANGE-ACCEPT` is separate from `G-O05-POSITIVE-ACCEPT`. A missing rule, missing source, unknown actor, ungrounded target, open choice set or inaccessible event is not a no-change observation.

**Preliminary decision proposal:** use a four-way separation:
- `UNISSUED_RULE / MISSING_RULE`: no qualified evaluator exists; no science conclusion.
- `UNEVALUABLE`: qualified evaluator exists but a necessary source/current state absent.
- `EVALUATED_NO_CHANGE`: qualified rule evaluated exact causal candidate and returned no target update with receipt.
- `CHANGE_COMMITTED`: exact qualified positive transition consumed and persisted.

These status labels are **analysis vocabulary**, not invented canonical reason codes; map to existing owner codes before implementation.

**Status:** ORIGINAL_ISSUER_DECISION_REQUIRED. The historical sourcefree C9 `NO_CHANGE` must not be escalated to original O07 acceptance.

### D-P3-04 — Can an actor's retrospective impression become a *formed causal memory*? (ADP-016)

**Question:** What is the lawful trigger and content for `EVENT_REFERENTIAL_MEMORY` or `CAUSAL_TRACE_MEMORY`, and does it occur during event effects, subsequent internal activity, later re-exposure or an explicit memory consolidation rule?

**Existing law:** an experienced event is *eligible*, not sufficient. ADP-016 requires owning source rule to request a typed memory effect; `NO_MEMORY_FORMED` is itself a rule outcome, not fallback. Forgetting requires a governed transition. Actor claim permission is separately ADP-017.

**Preliminary design constraint:** the LLM retrospective half of call N+1 may propose semantic articulation, but that text must never become the source event, formed memory or actor belief without an independently admitted transition and actor-rights check.

**Decision alternatives to investigate, not silently select:** memory formation as an explicit immediate event effect; as a later, actor-mediated internal activity triggered by previous accessibility; or as separately qualified slower consolidation. An implementation may support all as typed issuer-provided effects; it may not choose an always-form generic model.

**Status:** ACTUAL_FORMATION_RULE_OPEN; ADP-016 *object identity, retention/access and replay contract* substantially specified.

### D-P3-05 — What is the physically grounded object of 'persistent character'?

**Question:** How do we distinguish evolving relational/practical organization from a latent fixed disposition, and preserve social contradiction and different conduct across contexts?

**Existing law:** CAN-011 functional kinds, CAN-010 distinct desires, ADP-015 relation state and CAN-008 independent streams already reject universal personality modules. Historical V3 may nevertheless include attractive but superseded numeric defaults and ideology/trauma label shortcuts.

**Preliminary theoretical stance for adjudication (not a new science grant):**
- What persists is a *historically acquired, condition-sensitive capacity/constraint or mode of activity*, not an innate type or a psychological scalar detached from material relations.
- The same actor can carry contradictory mediators, expectations and practices across institutions and relationships; no global consistency requirement.
- Practice formation should be tested through participation across changing objective opportunities, not inferred from moral meaning or verbal declaration.
- The actor's knowing, misrecognizing or failing to articulate an effect is distinct from the effect's causal persistence.
- A lived relation can be causally formative without becoming a self-explanation; nondeclarative causal trace and memory must remain distinguishable.

**Open:** How narrow should the first issuer-qualified transition family be? One concrete practice under repeated situated action, one evidenced response mediator, or one causal-memory transition? The choice changes source requirements, acceptance witnesses and whether P3 can prove a genuine downstream psychological delta.

**Status:** USER + ORIGINAL SCIENTIFIC OWNER ADJUDICATION NEEDED before calling any specific positive rule 'native'. No need to reopen the settled ontology.

## C. Research/validation standard for any proposed positive rule

A useful scientific candidate needs more than philosophical elegance or working historical code:

1. Define the typed candidate *causal unit* and actor activity, not an inferred demographic essence.
2. Show why the parent event/trace was *experienced* by that actor, distinguishing objective fact from perception.
3. Provide an actual intervening causal mechanism: participation, mediation, contradiction, repeated enactment, changed access, relation or capacity.
4. State scope and exceptions; do not universalize case-specific studies or social strata.
5. Separate observable performance from capability, interpretation, testimony and retrospective narration.
6. Name rival mechanisms (changed resources, institutional pressure, another person's action, stochastic selection, mere recall).
7. Demonstrate a later differently-timed first consumer that reads committed state and changes its actual permitted/action result.
8. Identify which quantity, if any, is really measurable and its unit/source authority; no normalized psychological number by convention.
9. Show negative and conservation cases: event with no change, missing source, actor without access, conflicting mediators, cross-branch, wrong rule version.
10. Supply original source/issuer qualification; independent engineering review by itself is not scientific validity.

The preflight research fleet should *produce candidate discriminators and reject unsupported mappings*, not issue CAN/ADP production rules.

## D. Preliminary highest-level question for user deliberation

**Should P3's first *positive* original-science target be acquired practical competence (O05), a history-conditioned response mediator (CAN-008→CAN-011), or event-referential/causal-trace memory (ADP-016)?**

These are not merely three implementation orders. Each asserts a different first scientifically demonstrable transition and demands a different original evidence basis. My current **provisional** preference is to investigate acquired *practice* first because performance under rival material conditions and later E2 gives the clearest external falsifier. But it may require substantially more source qualification than a bounded, actor-experienced memory transition. The choice should not be baked into a P3 worker commission without adjudication.
