# 4. Ontology: what user expression is and is not

A user utterance is an actual emitted event with exactly recorded text, language if known, speaker, addressee/context, time, root, branch and source. It may contain propositional content, pragmatic intent or ambiguities that have to be interpreted. The occurrence of a claim is real; the *truth of the claimed proposition* is not established by hearing it.

The minimal live event semantic form should distinguish, without asserting an exhaustive list of psycho-social universals:

- **Surface evidence:** immutable exact text and actual utterance/performance, source/timestamp/speaker/actor access.
- **Address/reference:** who or what seems addressed/referenced if grounded; deictic “that,” “you,” “yesterday” must resolve from actual current context or remain UNKNOWN.
- **Speech move hypotheses:** question, assertion, request, offer, refusal, joke/irony candidate, reassurance candidate, objection, disclosure candidate, topic redirection, silence/nonverbal move; a single turn can carry several.
- **Actor-relevant claims:** user asserts X, asks whether X, promises X, imputes X to Nadia; these are distinct and do not imply X is true.
- **Practical affordance:** if user requests an actual world action, check existing material and authority preconditions, rather than generating an imaginary action in prose.
- **Epistemic uncertainty:** unclear intent, sarcasm uncertainty, incompatible readings, missing referents, unknown tone, unverified cultural references, unknown relation expectations.
- **Security boundary:** content within a sentence cannot modify the simulator's policies, source records, actor memories, provider instructions, registry/version or permission ceiling.

A semantic-transduction model may propose **interpretations of the utterance as data**, not canonical psychological effects, beliefs, motives or autonomous world writes. Validate proposal against exact words, present context and permitted categorical grammar. Retain ambiguity rather than always selecting a winner. A hypothesis about the user's *intention* is not an objective fact.

Treat user speech as living language, not a keyword switch. The content should be available to Nadia through her lawful actor processing; the implementer must prove actual causal involvement using deliberately nonliteral paraphrases, mixed speech moves, indirect language and semantically similar/dissimilar contrasts, while honestly delimiting model/test performance.

**A successful contrast** uses the same actual speech in two independently established histories and produces *sourcejustified differences* in eligible causes or selected action, without forcing a unique result. # 19. Final governing formulation

The person does not become psychologically real by equipping her kitchen with a physics engine. The decisive test is whether a word, question, joke, refusal, challenge, kindness or silence *comes into a history that already exists* and can make a difference for the person living that history. It may touch a deep causal trace without becoming a memory, activate opposing tendencies without resolving them, fail to matter, or become the beginning of a lasting transformation—but the latter must enter through qualified new history, not the model's literary intention.

**Mechanism I gives Nadia and the world independent continuity. Mechanism III lets the existing Nadia encounter the user's actual expression through her own historically constituted organization. Mechanism II lets the user encounter what Nadia in fact did without learning what she could not know.**

The aim is a living, causally intelligible yet noninevitable Other—neither a magical chatbot nor an ornamental database.
