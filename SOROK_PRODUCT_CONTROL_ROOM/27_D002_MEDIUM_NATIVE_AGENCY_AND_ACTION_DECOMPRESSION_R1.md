# Sorok D002 / Court 8G — Medium-Native Agency and Action Decompression R1

Status: PROVISIONAL_CORE_GAMEPLAY_LAW

Date: 2026-09-29

## 0. Core theorem

Rawlsing's deepest player agency lies in capacities the user can actually exercise through the interface.

Therefore:

> **When an attempted action's causal content is made of attention, inquiry, interpretation, explanation, persuasion, judgment, timing, memory or speech, a goal-level summary cannot simply instantiate successful completion. The interaction must decompress until the user reaches the points where those capacities are actually exercised.**

Examples:

`I help the kid with homework`
is a goal/intention, not a completed pedagogical event.

`I comfort Nadia`
is a goal/intention, not proof that comfort occurred.

`I convince him`
is a goal/intention, not persuasion success.

`I explain why`
requires content sufficient for another actor to receive/process.

---

## 1. Native agency versus simulated capability

Distinguish:

### SIMULATED / DECLARED CAPABILITY
Actions the text interface cannot directly test in the external human:
- piano performance;
- running speed;
- pushup count;
- carpentry dexterity;
- cooking technique;
- physical strength.

These may be represented through lawful portaled capability and world-resolution rules.

### MEDIUM-NATIVE PLAYER ACTION
Capacities the user actually performs inside Rawlsing:
- selecting what to attend to;
- asking questions;
- remembering prior facts;
- explaining an idea;
- choosing examples;
- recognizing misunderstanding;
- revising an explanation;
- making an inference;
- choosing timing;
- negotiating;
- apologizing;
- joking;
- deciding whether to intervene;
- speaking under uncertainty.

The second class is where the game's strongest rewards should live.

---

## 2. Homework prototype

User input:

> I go over to help the kid with the homework.

Lawful realization:

1. User approaches / enters the homework interaction if physically/socially permitted.
2. World exposes the immediate phenomenal surface:
   - actual textbook/workbook page;
   - problem currently attempted;
   - visible work already written;
   - child posture/attention only as observable;
   - what the child says;
   - surrounding time pressure / Nadia's ongoing agenda.
3. Control returns.

The user may then:
- ATTEND to the written work;
- ask the child what they tried;
- read the textbook explanation;
- identify a mistake;
- ask a diagnostic question;
- give an example;
- explain a concept;
- draw an analogy;
- let the child try;
- correct too quickly;
- confuse the child;
- become impatient;
- notice that the child understands more than expected;
- realize the problem is not conceptual but attentional;
- decide they do not know how to help.

Time continues.

The child processes the actual interaction through their own perception/knowledge/attention state.

---

## 3. No semantic fast-forward through core relational work

Forbidden default shortcut:

> I help her understand fractions.

→ `HELP_SUCCEEDED`

when the intended causal path is the user's actual explanation and the child's actual uptake.

Likewise:

> I reassure her.

cannot directly set reassurance received.

> I apologize sincerely.

cannot directly set belief or repair.

> I get him to see my point.

cannot directly set persuasion.

These inputs may establish:
- intention;
- attempted action class;
- opening move;
- desired outcome.

They do not author reception/effect.

---

## 4. Action decompression rule

Candidate parser/runtime rule:

`HIGH-LEVEL ATTEMPT`
→ determine whether completion depends mainly on:

A. physical/world state + represented capability;
or
B. medium-native user contribution.

If A:
- engine may resolve at appropriate physical grain.

If B:
- realize only enough to enter the task;
- surface decision-relevant evidence;
- return control before the meaningful user contribution;
- let the user perform that contribution through SAY/ATTEND/DO.

Mixed actions may alternate between both.

---

## 5. Examples

### 'I carry the groceries upstairs.'
Mostly physical/world-capability dependent.
May resolve substantially if access, load, body and time permit.

### 'I fix the sink.'
Mixed.
If repair knowledge/dexterity is represented, engine may model diagnosis/repair steps at bounded grain; if user knowledge itself is intended as gameplay, decompress further.

### 'I teach the child fractions.'
Strongly medium-native.
Decompress into actual pedagogical interaction.

### 'I make Nadia feel better.'
Outcome claim.
Not user-owned; user must actually speak/act and Nadia's response is independently processed.

### 'I persuade her not to quit.'
Outcome claim.
Decompress into actual conversation and decision context.

### 'I make a funny joke.'
User may provide the joke.
Funny-to-recipient is not user-owned.

## 6. The game can present real epistemic objects

To make native skill genuine, Rawlsing must sometimes expose concrete material the user can reason about:
- textbook problems;
- bills;
- schedules;
- messages;
- recipes;
- maps;
- forms;
- household constraints;
- conflicting testimony;
- remembered conversation history;
- observable object states.

The user can inspect these and actually think.

This is not mere flavor text.

The material becomes the substrate for real player cognition.

---

## 7. Pedagogical interaction requires child epistemic state

For homework to be real rather than theatrical, the child needs enough state to support:
- current knowledge;
- misconception/error;
- attention/effort;
- memory of explanation;
- confidence where relevant;
- ability to answer;
- partial understanding;
- later learning/use.

The child is not a prop for Nadia's reaction.

User explanation must be processed against the child's actual current state.

---

## 8. The reward loop

Native relational/cognitive skill produces rewards unavailable through mere capability declaration:

`NOTICE`
→ `FORM HYPOTHESIS`
→ `ASK / TEST`
→ `GET RESPONSE`
→ `REVISE`
→ `ACT / EXPLAIN`
→ `SEE PARTIAL CONSEQUENCE`
→ `ACCUMULATE HISTORY`.

Examples of palpable rewards:
- the child suddenly uses the user's own analogy correctly;
- months later the child remembers a phrase or method;
- Nadia later trusts the user specifically with school help;
- the user realizes their first explanation was wrong;
- the child asks for the user rather than another adult for a specific kind of problem;
- the user learns how this particular child thinks;
- the user notices when help would embarrass the child and changes approach.

These are history-dependent and cannot be instantiated by saying `I am good with kids`.

---

## 9. Fantasy capability is intrinsically thinner

A declared spectacular ability may still be fun and consequential.

But because the text medium cannot directly make the external user perform that ability, its game meaning is necessarily mediated:

`USER CLAIM / RUN CAPABILITY`
→ `SIMULATED PERFORMANCE`
→ `ACTOR RESPONSE`.

By contrast:

`USER ATTENTION / INFERENCE / SPEECH`
→ direct input content
→ `ACTOR/WORLD PROCESSING`
→ `RESPONSE`.

The second route carries more of the actual user into the causal chain.

This is why honest situated play can feel more real without any honesty detector.

---

## 10. Do not over-decompress mundane life

Not every action must become a parser minigame.

Do not require:
- individual footsteps;
- dishwashing micro-actions;
- every arithmetic operation when not relationally meaningful;
- tedious procedural detail.

Decompression criterion:

> **Would skipping this step bypass a capacity the game intends the actual user to exercise or erase a consequential choice another actor can respond to?**

If no, compress.

If yes, return control.

---

## 11. Accessibility / assisted mode

Assistance may scaffold native player action without replacing it.

Possible assistance:
- summarize visible material;
- remind user of prior facts with provenance;
- reformat text;
- translate language;
- offer neutral clarification of a math concept;
- expose available action categories.

Do not silently choose:
- what the user believes;
- what inference to adopt;
- what persuasive line to use;
- what relational goal is correct.

Assistance should reduce interface friction, not automate the relational cognition.

---

## 12. Product consequence

Rawlsing should invest heavily in surfaces where the user can actually bring real cognition into play.

Examples:
- schoolwork;
- practical planning;
- interpreting documents;
- resolving conflicting accounts;
- helping with decisions;
- ordinary conversation;
- social inference;
- remembering promises/details;
- noticing changing patterns;
- collaborative tasks.

These create genuine user-persona co-activity rather than narrated competence.

---

## 13. Deep theorem

> **Fantasy is thinner in Rawlsing precisely where the medium cannot require the user to perform it. Reality becomes thick where the user's actual attention, thought and language enter the causal chain.**

And:

> **The game should not ask 'what is your character good at?' when it can instead create situations in which the user must actually be good at something the medium can carry.**
