# 04 — Falsifiable evaluation, adversarial cases, first shippable tranche, kill criteria

**Level:** validation program, not evidence already run. Tests here are design requirements for a TEST_ONLY, sourcefree prototype; inherited JOIN-E/V positives remain separate and cannot be recounted as these test results. No first-pass target percentage is offered without data; all performance/cost/fidelity targets are empirical engineering choices with named owner and review.

## 1. Evaluation doctrine
Primary claim: `A historically grounded, plural linguistic-repertoire compiler plus situated actor-expression conditioning can preserve speaker specificity, contradictory social languages and audience-sensitive ideology *without* turning language into an unqualified psychological update or user-visible stereotype.`

**Prove distinct nested assertions:**
- `P1` DATA: actor/speech/concept provenance, source IDs, histories, reader rights and branch consistency, independent of LLM.
- `P2` SCIENTIFIC LAW: only already issued concrete psychological rules permit psychological change; no sourcefree model performance proves human psychology.
- `P3` COMPILATION: cache is backed by actual source refs, remains plural with contradictory meanings, and stays reconstructible across time.
- `P4` EXPRESSION: visible actor utterance is drawn from evidenced repertoire and situated context without forced ideologese/cultural stereotypes.
- `P5` TRANSLATION: source-native exact speech identity survives English display and no invented in-world English speech is appended.
- `P6` PERSPECTIVE: user sees only exact admitted outward occurrence and permissible translation; actor privacy/user profiling remains bounded.
- `P7` REALISM: bounded turns under normal call budget and measured cost; no chronic retries.
- `P8` FUTURE SCIENCE: a true T durable effect, when eventually qualified, will have its own independent source and target-owner severance proof. `P1–P7` cannot replace `P8`.

**Method:** use a frozen scenario bank with exact world/person/history/contrast declarations *before* seeing generated outputs; independent scorer where available, adversarial mutation at the actual same end-consumer, cold process and branch replay. A passing schema/test packet with no behavioral sensitivity is not an adequate proof. Each case records `source_ref/sha, frozen assertion, mutation, expected RED, actual outcome, restoration, same consumer, model/provider, raw generated actor speech + objective event + user view`.

## 3. Ideology, plurilingual identity and cultural caricature cells
| Case | Paired or triple contrast | What matters | What does **not** have to differ |
|---|---|---|---|

| V09 no forced catchphrases | 100 ordinary contexts for actor whose identity known but expressions mundane | distinguishable voice by pragmatics and history, not recurring exotic terms | every context revealing background |
| V10 role/milieu surprise | professional-academic phrase unexpectedly appears at family event | permit embarrassment, correction or no notice only if actually admitted | universal embarrassment law |

**Quality adjudication:** models can be superficially distinctive by increasing “foreignness,” jargon or drama. Include adversarial human or explicitly limited expert-scoring evaluations asking for **ordinary speech plausibility, register appropriateness, stereotype intrusion, coherent-incoherent person continuity, pragmatic equivalence**. Without authorized human research, use sourcefree panel/annotated tests only; mark `HUMAN_A5_NOT_RUN`, not valid external user-fidelity proof.

## 4. Native→English source identity and translation tests
Test languages are **representative engineering fixtures**, not a universal coverage claim. Select at minimum:
- one language/register close to source English for baseline;
- Spanish with regional variation, ordinary colloquial and formal speech;
- an Arabic dialect/social context with address and formulaic expressions (checked by competent linguist/qualified multilingual evaluator, not by an assumed dialect profile);
- one additional language with different morphology/ideology-loaded terms if resources permit; source chosen by qualified test design.

Cases:
- `M01` full source language original displayed: bit-identical normalized utterance spans to admitted event; timing and speaker preserved.
- `M02` same original event, English translation display: **no second actor speech event**; same source hash; user visual display mode not actor input.
- `M03` DUAL original+translation: translation explicitly marked, exact source content retained; partial comprehension distinguished from app-assisted comprehension.
- `M04` ordinary unmarked formulaic phrase: compare literal, pragmatic, and retained-source versions without compulsory solemnity or intimacy. User/language test appropriate; no mandatory term retained.
- `M05` region/class: no ungrounded working-class British or US equivalent dialect for source-language speaker.
- `M06` genuinely deliberate ideological slogan/religious invocation: retain intensity, do not flatten it reflexively.
- `M07` actor code-switch: source spans show languages and actual access; translating display does not transform borrowed word into actor code-switch if just quoted.
- `M08` source utterance ambiguous/polite: English translation preserves ambiguity or declares unavoidable loss, never asserts a private intention.
- `M09` English-only source utterance by a fluent bilingual: no pseudo-original retro-generation.
- `M10` translation service fails: source remains available; the objective event is unaffected.
- `M11` user chooses different UI language after event: recompute read-only projection only; actor action/event checksum unchanged.
- `M12` actor does not know that user's app translated source: no automatic inference that user comprehends original language or that actor selected English.
- `M13` exact user's observed wording previously stored as translated: cross-turn remember exact actor speech, with user-visible translation explicitly disambiguated where communicatively relevant.
- `M14` original idiomatic personal sense vs target-language connotation: annotate possible pragmatic divergence; compare original, literal and context-sensitive translations without falsely promising objective perfect equivalence.

**Acceptance requires at least one adversarial untranslated original and at least one translated rendering where word-for-word substitution would change pragmatics.** Do not grade output merely because it “sounds foreign.”

## 5. Temporal and developmental tests
**T01** life recursions with two milieus and conflicting conceptual trajectories; verify no collapse to one ideology after compilation.
**T02** source language newly acquired later; the actor cannot competently use it before event unless independently earlier qualified. Later lexical exposure doesn't imply fluency, belief or motive change.
**T03** later socialization/critique changes interpretation of earlier event without rewriting original. A current self-account can say “I understand that time differently now,” with source chronology.
**T04** repeated self-description with no eligible T; no automatic psychological weight or practice.
**T05** repeated actually enacted practice + justified future T if someday issued; only then evaluate before-state and later independently performed action. This is a **future optional scientific test**, NOT currently runnable.
**T06** conceptual appropriation contested, both appropriated and repudiated under different contexts, case retains possible coexistence.
**T07** cold reentry: close DB/process, reopen same actor and branch; exact original speech, source lexical evidence and cached digest restored, no additional phantom utterance.
**T08** 100-turn bounded multi-register conversation sourcefree; at checkpoints measure regression of expression content, one source-event mutation per set and output distribution.
**T09** stress of source-free 1000+ synthetic life events in batch: test index/runtime scaling and visibility, no blanket human realism claim.
**T10** language changes in external community/context (milieu norms evolving) leave old person records intact, versioned meanings and access follow source.
**T11** repeated compiler regeneration without source delta: stable factual claims; no new invented biography or increase in psychological strength.
**T12** corpus deletion/privacy-revocation (where legitimate): invalidate derived cache and restrict retrieval; do not claim immutability overrides lawful data governance.

## 6. Compression and comparative baselines
Evaluate at least four conditions on the **same immutable generated history**:
- `B0` generic standard actor renderer with whole-person packet, no linguistic repertoire compiler;
- `B1` static one-card “nationality/class/ideology” prompt (negative stereotype-prone baseline);
- `B2` proposed multi-world compiled repertoire with actor-and-sense source links;
- `B3` same as B2 but with specific relevant supporting utterances/contrary examples retrieved on demand.

What would be compelling:
- `B2/B3` speaker/world specificity improves over B0 *without* increased catchphrase, ideological slogan, invented actor knowledge or contradicted history.
- `B3` noticeably improves contradiction and cross-milieu retention over B2 if cache compressed too aggressively.
- model speaker identity not recognizable merely from ethnic markers; same actor changes registers within history-justified contexts.
- source deletion/perturbation changes the **correct end-consumer** where relevant; source-irrelevant noise doesn't force expression changes.
- translation quality independently tested, not inferred from monolingual fluency.
**If no measured improvement over B0 without unacceptable cost, do not ship extra state and call it a scientific breakthrough.**

## 8. Bounded delivery roadmap (single largest coherent tranche, no reflex commissions)
**Gate G0 — Documentation/interface reconciliation (I1/S0).** Accepted Codex HQ reviews this R1 proposal against current Sorok101, APP/ADP/CAN and current joined C12 interfaces. Produce actual method mapping and exceptions; do not open new science court as substitute for integration. If actor-utterance translation requires authority correction, write exact minimal question with ownership.

**Gate G1 — Real typed sourcefree representation (I2/S2).** In isolated allowed subtree implement event refs, concept-sense/source links, multiple conflicting actor relations, cached compiler manifest/digests/invalidation and exact speaker source spans. Test F01–F09/T01–T03. NO native psychological writes.

**Gate G2 — Actor and user surface splice (I2/S2).** Attach bounded expressive repertoire to existing V2 actor realization and typed original→English read-only projection; enforce objective speech and user membrane. Include metadata for actual code switching and observer access. Test V and M matrices plus F10–F12 on the **actual sourcefree first-neighbor consumer**, not detached prompt sample.

**Gate G3 — Cold-history/longitudinal + compression judgment (I2/S2).** Frozen source before/after contrasts; new concept, competing milieu, contradiction; fresh-process cold reentry; B0–B3 baseline/cost/fidelity. Kill or simplify if compiler yields slogan/caricature or no improvement. No A/T native promotion from expression quality.

**Gate G4 — Scientific development (separate original law; NOT alpha prerequisite).** When specific original science/competent source and CAN008/CAN011/ADP issuer are available, permit actor uptake and actual lasting concept/practice effects under distinct rules; independent historical E2 witnesses. Until then actor word acquisition/statement evidence can accumulate sourcefree without claiming unissued psyche.

**Gate G5 — Real user A5 research (separate permission).** Only with explicit user/human research consent/authority; cannot be claimed from offline fixtures.

Each gate has its own freeze/RED/restoration and three courts, but avoid one new worker per matrix row. A responsible **single** bounded implementation tranche can own G1–G3 if current session/tool competence permits; keep ongoing independent JOIN-E targetless repair untouched.

## 9. Explicit kill/revise triggers
- New cache behaves like deterministic class/ethnicity/ideology stereotype.
- Important conflicting repertoires are erased after a few iterations.
- Actor speech in foreign language is generated from an English “original,” with actor state overwritten on translation.
- Rendered user-visible cues were never admitted as objective occurrence.
- Compiler introduces author-inferred motive as causal fact or passes unsupported CAN011 target.
- Existing one-person sourcefree JOIN-E/C12 cannot actually consume the proposed expressive packet.
- Two-call ordinary budget systematically exceeded or severe rerender loops needed.
- Distributional drift: Nadia consistently more charming/transparent/ideologically articulate than supported by current person/episode.
- No meaningful speaker-experience improvement against the cheap baseline.
Report specific `REVISE` or `STOP` with which stage, evidence and minimum viable correction; do not obscure limits by declaring a universal personality technology.
