**Origin:** ZAK03:T:0012 cross-commission omitted-T discovery. **Status:** NEW_DISTINCT_PROVISIONAL_T at S1, OPEN historical discovery, no original35 run or source issuer acceptance. **Selected historical file:** [`data/ddm_build_copy/ddm_v550_position_distribution.py`](https://github.com/maidiu/rawlsing/blob/9253064bc9423a0f0ccda4fbdea43c2f54f800c6/data/ddm_build_copy/ddm_v550_position_distribution.py#L12-L132) at `9253064bc9423a0f0ccda4fbdea43c2f54f800c6`, Git blob `651329254244e9f42a8d88c2721ccae6bd768073`, identical protected `6a5c12f04323d74001f9632063ec907f4fc4468e`.

## 1 — Functional identity and original science

Compute marginal position-category representation among distinct source/wave/country respondents with nonblank values in an `INDICATOR_FIELDS` coordinate. It answers **how common is position category X among respondents with that position field observed?**, not which position feature predicts response or how source demographics determine personhood. T0018 source `build_position_signature_rows` uses response-conditioned feature associations; neither is equal to the other. This is not an additional ZAK03 canonical T.

## 2 — Original inputs, structure, data grain and risk set

`country_frames: dict[str, pd.DataFrame]` keyed by country_code, with source/source_family/wave/canonical_wave, respondent_id,country_code,var_code,question_id, optional weight_value, and `INDICATOR_FIELDS`. `_respondent_slice` sorts by respondent_id/country_code/var_code/question_id (when present), keeps the first row per respondent_id+country_code, else full-row dedup. Each observed position field's nonblank values define its own population; missing field or no observed values contributes no output. No response value is present in the output category grain.

## 3 — Historical transformations individually

1. `ZAK02:S:20:RESPONDENT_DEDUP`: stable first-respondent extraction, so respondent is counted once rather than each question; if rows disagree in position/weight, first-row selection has a **source-level** conditional representativeness question, not an observed defect (EV0154).
2. `ZAK02:S:20:FIELD_SPECIFIC_DENOMINATOR`: `values.fillna('')` and trim; string `nan` treated missing, blank omitted. Group by `position_field,position_value`; for each field denominator `total_unweighted=len(all nonblank)`, `n_category=len(group)`, `pct_unweighted=n_category/total`. Field denominators may differ; there is **no P(response|position)** (EV0155/0156).
3. `ZAK02:S:20:WEIGHT_STATUS_AND_SUPPRESSION`: `classify_weight_status` checks finite strictly positive values. Only `weight_status='weighted'` allows group weighted n and share divided by sum of valid respondent weights within that same observed-field mask. Partial, invalid, missing or unweighted_only status yields NA weighted columns while retaining unweighted (EV0157). A field with zero valid total also has NA weighted.
4. `ZAK02:S:20:MARGINAL_PRODUCERS_REPLAY`: the wave-shard compiler prepares `question_row_cache` before the optional per-question resume/checkpoint skip loop, and later calls the marginal on that shared cache. Source-level distinct from the order-sensitive V550 *paired attitude cloud* question-history cache. Additional producers: repository `build_determinicity_repository_v550.py` and `rebuild_v550_bridge_from_checkpoints.py`; all three source-level only (EV0158–0160).
5. `ZAK02:S:20:POSITION_CONTEXT_REFUSAL`: V550 outputs table `position_distribution` in determinicity layer; V551 bridge maps source to POSITION_COORDINATE/`position_context` and `v551_position_coordinate_eligible`, while `v551_relation_evidence_eligible` must remain false (EV0161/0162).

## 4 — Original outputs, exact field names and scientific limits

`POSITION_DISTRIBUTION_COLUMNS`: run_id, shard_id, source, source_family, wave, canonical_wave, country_code, position_field, position_value, n_unweighted, n_weighted, pct_unweighted, pct_weighted, weight_status, semantic_role, created_at. Emits a typed empty frame if no categories. Observational illustration, **NOT a real executed output**: if field F observed for 80 deduplicated respondents and category X for 20, `pct_unweighted=0.25`; those counts make NO claim about an answer. This can be useful as a descriptive survey-position prior, not direct directional/causal atom.
