## A concrete data journey

**V549b:** Imagine a question coded `1`, `0`, `present`, and missing for four respondents. Literal `1` can form the answer-presence anchor; a missing anchor is not an observed `0`. Yet, when calculating Cramér's V against another observed response, that missing-anchor respondent can be in the boolean False comparison cohort. Keeping only observed `1`/`0` people would change the historical association, even if anchor counts match (EV0001, EV0004). This is an important old transformation and a test of real current functional equivalence, not a justification to preserve an accidental bias without scientific issuer review.
