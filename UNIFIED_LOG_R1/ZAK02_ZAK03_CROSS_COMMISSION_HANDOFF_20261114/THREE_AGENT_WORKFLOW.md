Each agent's handoff must state:

- Original commission and owner, exact frozen PR HEAD and historical/current source cut.
- Seam ID(s) from `SHARED_SEAM_REGISTER.tsv` or `NEW_SEAM_PROPOSAL`; historical T and S/M aliases; original identity alias vs separate function.
- Exact `path@commit#blob:line`, selected source/row/role/denominator, input/decision/output/refusal/stop and first source+consumer.
- Evidence grade: `PINNED_SOURCE`, `STATIC_CALLSITE`, `SYNTHETIC_FIXTURE_NOT_RUN`, `EXECUTED_WITNESS` only if actual logs and executor can be checked, or `OWNER_DECISION_REQUIRED`.
- Change/negative A/B/A or worked illustration explicitly `NOT_EXECUTED` where applicable; no fake successes.
- Verdict as `CROSS_REFERENCE`, `SUBSTANTIVE_NEW_T_CANDIDATE`, `SOURCE_CORRECTION`, `CURRENT_FIRST_READER_OPEN`, `ISSUER_HOLD`, `INAPPLICABLE_WITH_EVIDENCE`, or `DISPUTED`. Explicit anti-join and next competent owner.
- Document GitHub link with exact commit; no silent source cherry-pick or history rewrite.
