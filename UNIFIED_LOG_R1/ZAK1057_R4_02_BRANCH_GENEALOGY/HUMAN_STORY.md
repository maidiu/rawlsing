# HUMAN STORY — what happened to recursive branch discovery between V550 and Long Memory

The old V550 tree was a small greedily grown diagnostic: pick the position indicator that most reduces uncertainty about a survey answer, follow only the two commonest categories, stop at depth three or when support runs out, and write a node table. It was useful for seeing strong splits and dominant subgroup answers, but it was never an exhaustive partition and its node paths were not exact respondent membership.

The previously accepted return already showed what Trii and Chetiri did with that table: they treated the table as diagnostic/stranded/superseded implementation while keeping branch-conditioned distributions, recursive subgroup discovery and exact branch membership as terminal capability obligations. This round asked the question before Trii/Chetiri: what did the intermediate eras do?

The answer is a genealogy of capability refinement, not artifact continuity. Pre-Vozhd authority only put the pre-550 discovery components into a conservation sweep. The Vozhd-era synthesis concluded that a discovered child must be handed off through a governed public contract, not reconstructed privately, and kept exact exhaustive discovery separate from adaptive partial search. Verkhovod then named the hole explicitly: `RECURSIVE_BRANCH_TOPOLOGY_SUCCESSOR_NOT_PROVED` for recursive branch/cohort membership, branch-conditioned same-respondent cotravel and recursive child replay. Its MX01 experiment was designed to test exactly that; MX01 R1 failed closed for lack of a public handoff, and MX01R2 closed the bounded depth>1 handoff contract. Dva did not revisit the question; it assumed the governed V550–V552J producer world and moved downstream. Long Memory recovered the fuller function grain of a recursive multi-label positional response tree and crosswalked it to inherited obligations rather than minting a new function. It proved exact fresh-process child handoff and membership replay at bounded MX01R2 grain, but kept complete branch-conditioned higher-order/co-signature composition and destructive membership replay open.

So the old table did not come back. The capability did: first as a governed handoff problem, then as an explicit unproved successor, then as a bounded exact replay mechanism plus open composition debt. That is the intermediate genealogy Trii/Chetiri inherited. It is a source-qualified documentary result, not a native run or an independent acceptance.
