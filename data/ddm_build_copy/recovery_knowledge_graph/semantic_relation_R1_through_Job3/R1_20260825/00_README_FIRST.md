# Historical knowledge graph

This is a machine-readable map of how the S14 relation-reconstruction work evolved, failed, repaired itself, split ontologies, and reached Job3-R3. It is not a substitute for the source artifacts. Edge types distinguish sequence, correction, supersession, re-certification, preservation, and composting.

The point is institutional memory: a future compiler should be able to ask not only what is true now, but what analogous mistake/repair Rawlsing has encountered before.
