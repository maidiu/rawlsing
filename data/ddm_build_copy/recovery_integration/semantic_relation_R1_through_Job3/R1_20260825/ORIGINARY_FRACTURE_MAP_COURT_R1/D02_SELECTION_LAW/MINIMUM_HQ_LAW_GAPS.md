# D02 — MINIMUM HQ LAW GAPS

Status: `BOUNDARY_RECOVERED__NO_CRITERIA_INVENTED`

This document states only the minimum semantic law that HQ must supply before a result-driven fracture-map controller may autonomously promote exact empirical facts into predictor/branch decisions.

It does **not** recommend metrics, thresholds, constants, model classes, or architecture.

## Governing boundary

The current evidence is enough to enforce:

`FACT ENUMERATION -> EXACT EVIDENCE`

but not yet enough to authorize every:

`EXACT EVIDENCE -> SELECTED SEMANTIC WINNER -> NEW BRANCH FRONTIER`.

Current PRE553 can evaluate exact supplied candidates. MX01R2 can transport an already discovered authorized child into the next recursion context. The missing law lies between those two surfaces.

## Gap 1 — Modal / morphology decision law

### Already binding

- preserve the full governed response distribution or multi-label response-pattern distribution;
- preserve weighted and unweighted support, missingness, exact response semantics, and exact alternatives;
- preserve minority-supported configurations;
- expose modal/multimodal and branch-shape structure where lawfully measurable;
- do not collapse residual/category-failure or source-semantic negative states.

### HQ must still govern

1. Which governed measure controls operational modality when weighted and unweighted rankings differ?
2. What happens under an exact tie for top response configuration?
3. Is a unique top cell always sufficient for a “dominant” branch, or can a near-tie be classified as split/multimodal?
4. What exact classifier maps empirical distributions into `stable minority`, `split/multimodal`, `fragmented/multimodal`, `polarization`, `smooth gradient`, or `category-collapse`?
5. Which classifier parameters, if any, are owner-tunable rather than globally fixed?

### Classification

Numeric cutoffs under an adopted classifier: `OWNER_TUNABLE_PARAMETER_REQUIRED` unless HQ explicitly fixes them.

- it is not an attitude, personality, causal essence, or actor belief;
- source/wave/universe/routing/measure/response authority survives;

4. How do source routing, country applicability, noncomparability, missingness, and measure authorization remove or restrict candidates?
5. Must candidate enumeration be exhaustive over the governed eligible set, or may a bounded generated subset be used?
6. If bounded, what authority defines that bound?

## Gap 5 — Recursive branch promotion / continuation law

### Already binding

The four semantic branch roles exist exactly once modal configuration and predictor condition are lawful:

- conformer;
- predictor-violating deviant/exit;
- predictor-absent converger;
- predictor-absent alternative/minority.

Supported minority/alternative/residual branches must not disappear merely because they are nonmodal. Secondary positional predictors must be sought inside supported branches. Recursion may continue from any discovered supported branch under support/stop law.

### HQ must still govern

1. Does every supported branch enter secondary-predictor enumeration, or can some be retained without expansion?
2. If expansion is bounded, how are branches prioritized?
3. How are coequal branches handled?
4. What distinguishes `retain`, `expand`, `stop`, `pruned_by_authority`, `underpowered`, `noncomparable`, and `unresolved` at the controller boundary?
5. What improvement/stability law promotes a branch-local secondary predictor?
6. When no secondary predictor is promotable, how is the branch preserved as a terminal learned-world object?
7. May a previously nonselected minority branch later become a parent because new exact evidence changes its support/stability state?

## Parameters versus law

D02 recovers an important two-level distinction.

HQ must first adopt the **form of the decision law**. Only then may numerical constants inside that law be treated as owner-tunable parameters.

Therefore this court does not convert historical values such as V547 minimum-N, MI thresholds, pair-gain thresholds, or confidence constants into owner-tunable defaults automatically. Their historical existence proves only that earlier code needed operational values.

Correct sequence:

`HQ DEFINES DECISION SEMANTICS -> OWNER-TUNABLE PARAMETERS ARE DECLARED WITHIN THAT SEMANTICS -> CONTROLLER USES VERSIONED PARAMETER AUTHORITY`.

Incorrect sequence:

`OLD CODE CONTAINED NUMBER -> NUMBER BECOMES CURRENT LAW`.

## No-new-law list

HQ does **not** need a new semantic selection law merely to:

- enumerate exact response cells/patterns;
- retain weighted/unweighted support and missingness;
- preserve source-semantic special/negative states;
- run an exact supplied predicate/query;
- evaluate an exact supplied interaction;
- construct four exact branch memberships after mode/predictor/condition selection;
- preserve exact respondent/risk-set/replay lineage;
- transport an already selected authorized child to recursion depth N+1.

Those are evaluation, representation, or transport surfaces—not the missing promotion judgment.
