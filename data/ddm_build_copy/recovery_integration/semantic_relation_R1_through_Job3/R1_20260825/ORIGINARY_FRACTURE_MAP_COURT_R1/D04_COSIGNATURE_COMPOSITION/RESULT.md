## Governing holding

The minimum lawful composition is:

`EXACT DISCOVERED BRANCH REF`
`-> GOVERNED FINITE SUBSTANTIVE-TARGET ENUMERATION`
`-> CANONICAL SAME-RESPONDENT TARGET PAIRS`
`-> BRANCH-CONDITIONED EXACT J=2 QUERY / DISCOVERY EXECUTION`
`-> EXACT FACT + DISCOVERY RECEIPT REFS`
`-> REF-ONLY TOPOLOGY CLOSURE`
`-> LEARNED BRANCH CONTEXT`

The composition must never reconstruct branch membership privately and must never require a caller to nominate which attitude question “ought” to co-travel. Demographic/position coordinates can define or condition the branch but are excluded from the co-signature target graph.

## Why this is the minimum common design

L01 freezes the originary distinction `POSITIONAL_PREDICTOR != ATTITUDE_NODE` and requires same-respondent cross-question substantive-response cotravel inside each supported branch. G02 proves the current object/query/discovery substrate can represent and execute exact branch-conditioned cotravel when exact inputs are supplied, but lacks autonomous target enumeration. G03 proves pairwise cotravel, joint-pattern membership, and recursive parent transport are individually present while the full branch-conditioned topology composition is not closed. G05 locates the controller leak precisely: the current caller supplies the other question/template. MX01R2 closes exact discovered-child transport/replay but does not choose the N+1 target surface.

Therefore D04 does not invent another empirical warehouse, resurrect historical V549/V549b tables, or define a new attitude ontology. It closes the composition seam around already-governed exact refs.

## Target enumeration law

The target inventory must exist before empirical co-signature outcomes are inspected. It is a finite, governed set of substantive response targets/questions derived from exact source/instrument metadata and positive response-semantic authority, not from demographic coordinates and not from post-hoc result inspection.

Eligibility requires all of the following:

- target is a governed substantive response/question surface;
- target belongs to an authorized source/universe compatible with the branch operation;
- target routing/applicability semantics are exact and resolvable;
- target response topology/state semantics are exact;
- target is not an empirical demographic/position coordinate;
- target is not a derived actor/persona/belief/causal label;
- target is not the branch predicate merely retyped as an attitude target;
- duplicate exact target refs collapse canonically;
- exclusions are explicit and replayable.

The controller canonically sorts eligible target refs by exact ref key/hash and generates the complete authorized target-pair frontier. No ranking, semantic relevance model, LLM choice, or manually named “interesting other question” may control reachability.

## Pairwise and exact joint use

Pairwise marginal association is not allowed to stand in for joint structure.

For each target pair the lawful evidence surface includes, as authorized:

- target-specific branch-conditioned marginals;
- exact same-respondent joint cells/pattern membership;
- pairwise cotravel/dependence validation;
- exact target-cell support;
- typed empty/underpowered/noncomparable/missing-authority states.

This is sufficient to represent two-target cases where global or branch marginals are equal while the exact joint differs. It also represents two-target XOR/exactly-one configurations when the exact pair topology and cells are authorized. It does **not** authorize inferring a 3+ target XOR/parity structure from pair projections.

Stable-minority configurations remain visible because the declared frontier is evaluated completely and supported nonmodal/joint cells are not removed merely for being non-top. Minority support is evidence state, not a personality label.

## Denominator conservation

The following quantities are distinct and must never be silently substituted:

1. **source/risk denominator** — governed respondents in the relevant universe/risk set before branch conditioning;
2. **branch denominator** — exact replayed members of the discovered branch inside the governed risk set;
3. **target-question denominator** — branch members for whom a specific target is routed/applicable/evaluable under exact response-state law;
4. **joint/pattern denominator** — same branch respondents for whom all targets in the exact J=2 configuration are jointly evaluable under the declared topology;
5. **joint-cell numerator/support** — respondents in the joint denominator satisfying the exact pattern/cell predicate.

Weights remain a separate governed measure projection. Raw and weighted support must not overwrite one another. Missing, source-specific special, refusal/DK/inapplicable and substantive response states remain typed. `OBSERVED_ZERO`, `ZERO_SUPPORT`, `LOW_SUPPORT`, `VALID_EMPTY`, `UNDERPOWERED`, `NONCOMPARABLE`, uncertainty and authority failure remain distinct according to current exact object/query law.

## Provenance and ancestry conservation

Authority and dependency are different dimensions.

**Authority refs** answer what operation/topology/source/risk/routing/measure semantics are permitted.

**Dependency/ancestry refs** answer which exact branch, immediate parent, earlier ancestors, target refs, source artifacts and replay objects this result depends on.

The closure must preserve both without treating ancestry as authority or authority as empirical ancestry.

At minimum preserve:

- immediate parent branch ref;
- full canonical ancestry refs;
- discovered branch predicate ref;
- branch replay/member-set binding ref;
- source release and empirical universe refs;
- risk/routing refs;
- target response/question refs;
- response topology/semantic refs;
- measure/weight refs;
- exact query specs;
- exact fact refs;
- exact discovery result receipt refs;
- execution/replay ref.
