## A1 — Single-label versus multi-label discovery law

### Holding

`RECOVERED__BINDING`

Where source semantics establish one mutually exclusive response, categories may form an exclusive partition. Where the instrument is multi-select, option presences overlap and cannot be treated as a mutually exclusive label partition.

For multi-label surfaces the learned world must preserve both:

1. **response presence/absence** for every governed option; and
2. **exact response-pattern morphology** for the respondent.

The originary examples are explicit:

- `SES only`;
- `SES + religion`;
- `religion without SES`;
- `none without SES/religion`;
- `SES + nationality`;
- multi-frame respondents.

Wave VIII Q873 independently verifies the source morphology: `SELECT ALL THAT APPLY`, with `None of these` separately constrained to be exclusive.

## A2 — Presence/absence versus exact pattern branches

### Holding

`RECOVERED__BOTH_REQUIRED__NON_SUBSTITUTABLE`

Presence answers “does this frame become selected/available for this respondent?” Pattern answers “what exact combination of governed frames did this respondent select?”

`SES_PRESENT != SES_ONLY`

`RELIGION_PRESENT != RELIGION_WITHOUT_SES`

A machine conserving only marginals loses the multi-frame topology; a machine conserving only full patterns loses the clean per-option presence/absence fracture question. Both are binding.

## A3 — Majority/minority vocabulary under overlap

### Holding

`RECOVERED__PREDICATE_QUALIFICATION_REQUIRED`

The originary language of majority consensus versus positionally structured minority deviation remains valid only when the branch predicate is explicit.

On a multi-label item:

- “dominant response” may mean dominant option presence or dominant exact pattern and those are different claims;
- “non-SES minority” means respondents satisfying `NOT selected_SES`, not `N - SES marginal count` as a synthetic dataset;
- a respondent can belong to several presence branches at once;
- a minority pattern can be structurally important even when one of its component options is globally common.

The originary law is emphatic that a supported minority branch is not noise; it may be the visible contradiction.

## A4 — Residual search law

### Holding

`RECOVERED__EXACT_PREDICATE_CONTINUATION`

After a dominant configuration is characterized, Rawlsing must continue into exact residual/minority branches where support permits.

For multi-label data:

`RESIDUAL != TOTAL_MINUS_MARGINAL_COUNT`

The branch is defined against the original respondent records, for example:

- `NOT selected_SES`;
- `NOT selected_SES AND NOT selected_religion`.

The source universe is not destructively reduced. The dominant branch remains part of the learned empirical world while residual branches are additional conditioned views over the same respondent authority.

## A5 — NONE / OTHER / DK / REFUSED / MISSING / NOT_APPLICABLE

### Holding

`RECOVERED__SOURCE_SEMANTIC_DISTINCTION_BINDING`

These states are irreducible unless exact source authority establishes an equivalence:

- `NONE_OF_THESE`: explicit response rejecting supplied substantive choices where the instrument defines it so;
- `OTHER`: source-defined other/specify or other-category, whose exact role is instrument-specific;
- `DK`: explicit don't-know;
- `REFUSED`: explicit refusal/decline;
- `MISSING`: no recorded response under governed representation;
- `NOT_APPLICABLE` / `NOT_ASKED`: routing/risk-set state, not a substantive negative answer;
- `SOURCE_SPECIFIC_SPECIAL`: exact special state awaiting/retaining source-specific meaning;
- unresolved semantics must fail closed.

Wave VIII Q881A is especially discriminating because it separately exposes `None of these`, `Other-specify`, `Don't know`, and `Refused` on the same multi-select surface.

## A6 — When none-of-these is a valid branch

### Holding

`RECOVERED__VALID_EMPIRICAL_BRANCH_WITH_INTERPRETATION_CEILING`

Where the source defines `None of these` as an explicit response and the branch satisfies governed support law, it may be learned as a valid empirical branch.

The originary Lebanon example shows none-of-these becoming especially salient after conditioning away SES and religion in some branches. That is useful empirical structure and must not be flattened into junk.

But the token alone does not prove *why* it was selected. The originary discussion names several possible explanations—weak category fit, refusal, confusion, opacity, non-salience, unmeasured grammar, danger around explicit naming—while explicitly requiring the system to preserve rather than collapse those possibilities.

Therefore without separate transformation authority:

`NONE_OF_THESE_SELECTED` is fact;

“respondent is confused/distrustful/depoliticized/afraid” is not.

## A7 — Support / weight / missingness / uncertainty law

### Holding

`RECOVERED__BINDING_DIMENSIONS__PARAMETERS_GOVERNED`

At every node the originary grammar requires, at minimum:

- unweighted `n`;
- weighted `n` where an exact weight is authorized;
- response count per option/pattern;
- missingness/special-response accounting;
- uncertainty/confidence;
- multi-select overlap qualification/penalty;
- maximum depth;
- branch stability;
- exact risk-set/denominator authority.

An underpowered branch may remain reportable as a distribution while splitting, channel inference, or substantive interpretation is blocked under the governed rule. Insufficient support is a typed limitation, not permission to erase the branch.
