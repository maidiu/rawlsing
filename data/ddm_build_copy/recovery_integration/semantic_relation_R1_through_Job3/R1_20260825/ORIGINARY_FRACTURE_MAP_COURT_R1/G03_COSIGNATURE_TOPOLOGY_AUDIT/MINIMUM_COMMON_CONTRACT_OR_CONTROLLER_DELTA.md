# Minimum Common Contract or Controller Delta

## Audit conclusion

The smallest lawful repair is composition, not storage.

Current Rawlsing already has:
- exact content-addressed predicate/query/discovery objects;
- same-respondent pairwise query execution;
- source-native same-respondent joint-pattern signatures and membership;
- MX01R2 exact recursive parent transport and fresh-process membership replay.

The missing common function is an authority-owned controller/closure that composes those primitives without privately reconstructing branch identity or flattening topology.

## Minimum pairwise closure

For a branch-specific pair cotravel case, no new empirical object family is presently proved necessary.

A minimum common DiscoveryAuthority/candidate-grammar extension can be sufficient if it:

1. consumes an exact MX01R2 RecursiveBranchHandoff winning_predicate.ref as the branch condition;
2. preserves the handoff ref/ancestry and immediate parent separately;
3. binds exact source releases, empirical universe, risk/routing scope, RAW/governed measure and response/operator authority;
4. supplies an exact EmpiricalQuerySpec for the cotravelling target;
5. instantiates BRANCH_CONDITIONED_COTRAVEL in the governed frontier;
6. preserves typed valid-empty, underpowered, noncomparable and coverage-limited outcomes;
7. emits deterministic receipt/replay material and can reproduce membership/result identity in a fresh process.

The accepted official AS3R2 frontier does none of this because it has zero branch-conditioned rules and no ancestry-bearing atom.

## Minimum higher-order closure

Full originary topology needs additional positive law beyond the pairwise closure whenever target arity exceeds two or the semantic object is a response-pattern/set rather than a scalar question pair.

The minimum common contract/controller must bind:

- branch_handoff_ref;
- branch_predicate_ref;
- immediate_parent_ref;
- full ancestry refs;
- source_release_refs;
- universe/risk/routing/weight/measure authority;
- governed target member refs;
- member role, order, cardinality and multiplicity;
- topology kind such as PAIRWISE, JOINT_N, XOR_EXACTLY_ONE, MULTISELECT_PATTERN;
- exact target arity and permitted maximum;
- branch denominator;
- each target/question denominator where applicable;
- joint/pattern denominator;
- exact same-respondent membership evidence or content-addressed information-equivalent;
- support and typed negative state;
- deterministic completion/enumeration law;
- producer/replay root;
- exact result refs.

A ref-only BranchCosignatureTopology closure receipt is one possible minimal representation, but this audit does not require a new family if an existing governed DiscoveryResult/receipt can carry all fields above without semantic loss.

## Explicit J=2 boundary

The accepted official AS3R2 topology has maximum_target_arity_J=2. K=18 is maximum conditioner arity and does not authorize 18-way target topology.

Therefore a 3+ target co-signature cannot be claimed by relabeling existing BOUNDED_K_WAY rules.

HQ must later choose one of two lawful semantic closures:
- positively authorize a larger exact target topology with matching query templates and validation rules; or
- adopt an exact information-equivalent higher-order pattern/topology object whose semantics, membership, denominators and replay are explicit.

No choice is made here.

## What is not required by this audit

This audit does not support:
- a new empirical warehouse;
- route-specific A/B/C semantics;
- resurrection of V549/V549b physical output tables;
- personality/profile inference about actors;
- treating Cramer's V, NMI, lift or pairwise covariance as a proof of higher-order topology;
- treating MX01R2 transport as co-signature generation.

## Stop condition

The gap closes only when a sibling-independent hostile test can, in a fresh process, start from an exact branch handoff plus governed target-set authority and reproduce the same branch-specific pair/joint/XOR/multi-select topology result with exact respondent membership or exact information-equivalent evidence, typed negatives, denominators, ancestry and refs.

Until then:
