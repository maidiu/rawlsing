## Historical function and current succession

### V549

V549 recursively evaluates parent branch masks and the four majority/minority convergence/divergence branch types, then evaluates candidate question responses in the same respondent cohort and ranks pairwise association. This is real branch-conditioned same-respondent execution, but it is pairwise association, not a complete higher-order topology object.

### V549b

V549b expands anchors to single answers, multi-select/split-block presence/absence, and recursive branch nodes. It again scores each candidate item against an anchor using Cramer's V and caps the cloud to top candidates. Presence/absence marginals therefore do not by themselves preserve a multi-select response-pattern topology.

### V550 cloud successor

Current ddm_v550_clouds.py performs exact respondent-id merges for question pairs and computes response-pair overlap, conditional probability, lift, NMI and Cramer's V under governed response contracts. It labels the output diagnostic/prototype and it is pairwise. Its branch relation signature rows use a question-shaped branch key, not an MX01R2 recursive learned branch ancestry object. It is a stronger governed pairwise successor, not a higher-order branch-topology successor.

### V550J joint-pattern machinery

Current V550J machinery groups respondent rows by exact raw/semantic pattern signatures, creates pattern IDs, retains respondent_id membership, weighted/unweighted counts and pattern probabilities, and supports association to outside-family context. This proves current code can execute exact same-respondent multi-question pattern membership when the source-native family/configuration authority exists.

It does not prove that those pattern objects are conditioned on a recursively discovered branch with exact branch ancestry, nor that current I05 generates the required branch-conditioned pattern topology.

### PRE553 exact discovery

The generic discovery engine can compile same-respondent Boolean conditions, including XOR-exactly-one and branch-family concepts, and can execute exact query/validation rules under an adopted DiscoveryAuthority. That is a genuine executable primitive, not only a schema.

However the accepted official I05 frontier currently supplies no branch-conditioned or recursive rule and no ancestry-bearing atom. Thus a capability present in generic code is not the same as an authorized/current production candidate.

### MX01R2

MX01R2 is accepted only as recursive parent transport evidence for this audit. It persists the winning predicate, immediate parent, source releases, exact scope/replay material and ancestry-bearing N+1 atom; it can replay exact respondent membership after process exit.

MX01R2 does not itself generate co-signatures, joint response topology, clouds, covariance, clusters, or relation vectors.
