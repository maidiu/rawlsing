## 1. Disposition

The historical Rawlsing lineage **did implement meaningful pieces of the originary fracture-map grammar**, but it never positively proves the complete Authority35 machine.

The strongest historical implementation is a three-stage functional chain:

1. **V547** — bounded autonomous positional determinicity discovery:
   - unary predictor salience;
   - exhaustive unordered pair-interaction search among the finite non-country predictors;
   - question-level shape classification;
   - a real 184-row historical execution receipt across five survey families.

2. **V548** — bounded recursive breakage:
   - persists each node's response distribution and modal response;
   - selects a predictor and one majority-carrying predictor value;
   - emits four explicit branch types:
     `majority_position_conformity`,
     `majority_position_deviation`,
     `minority_position_convergence`,
     `minority_position_divergence`;
   - computes branch-local next-predictor diagnostics;
   - **recurses only through the majority-position-deviation branch**.

3. **V549 / V549b** — same-respondent branch cotravel:
   - reconstruct V548 branch membership from exact branch recipes over respondent-indexed source data;
   - use that exact branch mask against other respondents' cross-question responses in the same respondent matrix;
   - emit branch-conditioned pairwise co-signatures / attitude-cloud rows;
   - V549b also creates single-answer and binary presence/absence anchors.

That chain is genuine historical implementation capital. It is more than schema.

But the full originary grammar was **not** historically reached:

- no autonomous recursion from every discovered branch;
- no exact multi-label pattern morphology beyond per-item presence/absence;
- no typed residual/none/category-failure product;
- no Authority35-style typed state lattice;

## 3. Intended historical grammar versus implementation

### V526c → V547

V526c explicitly intended:
- predictor salience;
- interaction salience;
- shape classes.

V547 materially implements all three, within a narrow fixed universe.

For each bound question it computes unweighted discrete MI for positional fields and exhaustively considers every finite unordered pair among six non-country predictors. With all six usable, the pair frontier is 15 pairs.

It retains only:
- top predictor;
- top predictor score;
- top pair;
- top pair gain;
- a coarse shape;
- heuristic confidence.

It does **not** retain:
- all predictor scores;
- all pair scores;
- exact pair cells;
- respondent membership;
- minority configurations;
- response topology.

Its `analysis_mode="within_country"` is stronger than the executable filter: the preserved response fetch is source + variable-code scoped and does not itself filter country/wave. Therefore V547 is a real discovery implementation but not Authority35-grade exact-scope evidence.

The historical report is positive evidence that V547 produced 184 rows across five source families. It does not cure the information-loss or scope ceiling.

### V526d → V548

V526d intended:
- majority indicator;
- majority-position deviation;
- category failure;
- deeper breakages.

V548 is not a generic decision tree. It defines a specific modal-response fracture grammar.

At each expandable node:
- compute the complete node response distribution;
- identify the modal response;
- choose a predictor;
- choose one predictor value maximizing modal-response conformity/lift/support;
- split into the four quadrant branches.

This is a strong historical implementation of R03-R06.

However, only `majority_position_deviation` can call the recursive builder again. Every other branch is materialized with `allow_recursive=False`.

So:

`V548_RECURSION_EXISTS`

but

`V548_RECURSION != AUTH35_ANY_DISCOVERED_BRANCH_RECURSION`.

V548's node outputs are useful cohort recipes. They do not persist respondent IDs. Exact membership can be reconstructed only by replaying the ancestor conditions against the original respondent substrate.

The preserved code also contains a material execution defect at the curated point: the default non-append main path references `OUT_DUCKDB` while the defined path symbol is `DUCKDB_PATH`. D02 could not positively prove a successful historical clean run from the preserved code/receipt set. G01 therefore classifies V548 as:

`IMPLEMENTATION_LOGIC_PRESENT__MATERIAL_DEFAULT_ENTRYPOINT_DEFECT__HISTORICAL_CLEAN_RUN_NOT_POSITIVELY_PROVED`.

This does not mean V548 never ran elsewhere.

### V526e → V549 / V549b

V526e intended three outputs:

- `branch_co_signature_summary`;
- `profile_cluster_summary`;
- `profile_relation_vector`.

Only the first family is positively realized in this recovered lineage.

V549 rebuilds actual V548 branch membership by walking each node's parent chain and replaying the parent predictor/value/modal-response branch condition. It aligns that branch mask to respondent-indexed question responses and computes Cramer's V between binary branch membership and a candidate question's categorical response.

That proves a real historical capability:

`RECURSIVE_BRANCH_COHORT -> SAME_RESPONDENT_CROSS_QUESTION_COTRAVEL`.

V549b preserves branch-node anchors and broadens the anchor family to:
- single answer;
- answer presence;
- answer absence;
- recursive branch node.

V549b then scans candidate attitude/opinion items and ranks pairwise cotravel per anchor.

The branch-cohort membership is used exactly at compute time, but respondent IDs are not written into the learned output. Thus the output is not itself an exact membership ledger.

No positive generator/product for `profile_cluster_summary` or `profile_relation_vector` was recovered. Their presence in V526e required outputs is **intent**, not implementation.

## 4. Autonomy ruling

The historical chain was neither purely caller-scripted nor fully autonomous.

### V547

`BOUNDED_AUTONOMOUS_DISCOVERY`

The caller supplies a question universe and fixed predictor vocabulary. Within that scope, V547 discovers the strongest unary predictor and strongest pair interaction without the caller naming the winner.

### V548

`BOUNDED_AUTONOMOUS_WITH_PREDECLARED_RECURSION_GEOMETRY`

The algorithm chooses node predictors/indicator values, but the branch grammar and recursive successor are fixed. It cannot decide that convergence, divergence, conformity, residual, or a newly discovered branch deserves further recursion.

### V549 / V549b

`AUTONOMOUS_CANDIDATE_SCAN_OVER_PRECOMPUTED_OR_PREDEFINED_ANCHORS`

They can scan and rank other responses once a V548 branch or an allowed anchor type exists. They do not discover a new fracture topology and then recursively feed that new topology back into the controller.

Therefore the historical machine did not implement an autonomous controller satisfying:

`DISCOVER_BRANCH -> INSPECT_ALL_BRANCHES -> CHOOSE_SECONDARY_SPLITTER_PER_BRANCH -> RECURSE_ANYWHERE -> DISCOVER_COSIGNATURE -> RECURSE_FROM_NEW_STRUCTURE`.

## 5. Multi-label ruling

The historical implementation recognized multi-select risk but did not close multi-label morphology.

V526d explicitly says a single-label tree applied to a multi-select item is a stop condition.

The preserved V548 implementation does not enforce that stop. It detects 0/1 response surfaces as presence/absence and contains a defect where coded missing values become NaN and can map to `absent` in presence mode.

V549b later implements binary `answer_presence` and `answer_absence` anchors for multi-select/split-block item columns.

That supports:

`ITEM_A_PRESENT`
versus
`ITEM_A_ABSENT`.

It does **not** supply Authority35 pattern morphology such as:

`A+B`
versus
`A only`
versus
`B without A`
versus
`none`.

Disposition:

`MULTILABEL_PRESENCE_PARTIALLY_IMPLEMENTED__MULTILABEL_PATTERN_FRACTURE_NOT_IMPLEMENTED`.

## 6. Minority / residual ruling

V548 makes minority structure visible better than a single modal summary because it emits both:
- minority-position convergence;
- minority-position divergence.

But those branches are complements of one selected predictor value. Distinct nonselected predictor categories are pooled.

A stable third-category minority can therefore disappear as an identifiable route even while aggregate minority mass remains visible.

The historical design named `category failure`, but no separate typed category-failure / residual / none product is positively recovered. Fixed response missing codes are largely removed, and binary absence is not equivalent to residual/category failure.

Therefore:

`MINORITY_AGGREGATE_BRANCHES_IMPLEMENTED__EXHAUSTIVE_MINORITY_ROUTE_IDENTITY_NOT_IMPLEMENTED`

and

`TYPED_RESIDUAL_CATEGORY_FAILURE_NOT_POSITIVELY_IMPLEMENTED`.

## 7. Same-respondent cotravel ruling

This is the strongest historical positive finding.

V549 and V549b do not infer cotravel from shared metadata or marginals. Their preserved code uses respondent IDs to build a respondent-indexed response matrix, reconstructs exact branch masks, and evaluates candidate responses on that mask.

Thus:

`SAME_RESPONDENT_BRANCH_COTRAVEL = HISTORICALLY_IMPLEMENTED`.

But:

`EXACT_RESPONDENT_MEMBERSHIP_PERSISTENCE = NOT_IMPLEMENTED`.

Membership must be replayed from:
- original respondent substrate;
- question response values;
- position fields;
- V548 branch recipes.

And:

`PAIRWISE_CLOUD != RECURSIVE_BRANCH_COSIGNATURE`.

V549/V549b are branch-conditioned only when the anchor is a reconstructed branch node. A generic pairwise response cloud without that cohort is not equivalent. Pairwise Cramer's V also cannot preserve XOR/k-way topology.
