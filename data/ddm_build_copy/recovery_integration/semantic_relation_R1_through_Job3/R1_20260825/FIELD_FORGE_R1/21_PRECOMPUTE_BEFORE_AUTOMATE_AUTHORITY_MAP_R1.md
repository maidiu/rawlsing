# FIELD FORGE R1 — PRECOMPUTE-BEFORE-AUTOMATE AUTHORITY MAP

Status: **EXPLORATORY / NON-BINDING / AUTHORITY-PLANNING NOTE**

Rawlsing has already learned that some finite semantic adjudications are substantially more reliable when performed once by high-intelligence agents and frozen as governed authority rather than recreated dynamically by ordinary code.

FIELD FORGE applies that lesson prospectively.

Core law:

```text
IF THE DECISION CHANGES WHAT RAWLSING SAYS THE WORLD MEANS,
AND THE CURRENT DECISION SURFACE IS FINITE/ENUMERABLE,
DEFAULT TOWARD MANUAL AGENTIC ADJUDICATION + FROZEN AUTHORITY.

AUTOMATE CONSUMPTION, VALIDATION, AND REPLAY.
```

# 1. DEFINITELY PRECOMPUTE MANUALLY

## A. POSITION ROLE AUTHORITY

Question:

> What structural/analytical role may this exact survey variable play in this exact context and operation?

Do not infer dynamically.

## B. POSITION-SPACE AXIS / REGION INTERPRETATION

Question:

> What, if anything, does this robust empirical dimension/region mean sociologically?

Geometry computes; agents interpret.

## C. DISPOSITION-COMPLEX SEMANTIC INTERPRETATION

Question:

Do not let embeddings/cluster labels mint ideology.

## D. FIELD / FORMATION ADMISSION

> Does this empirical packet substantiate a Bourdieusian field, a broader formation, a local arena, or merely a position region?

Manual court.

## E. CAPITAL VALUE / CONVERSION INTERPRETATION

Question:

> Is a differential empirical valuation pattern genuinely evidence that a resource/disposition functions as capital in this arena and converts/devalues across arenas?

Manual court.

## F. HEGEMONY / SUBHEGEMONY INTERPRETATION

Question:

> Does the multidimensional profile support a claim of hegemonic, subhegemonic, counterhegemonic, or merely prevalent/local dominance?

Manual court.

## G. SYMBOLIC / MORAL BOUNDARY INTERPRETATION

Question:

> Do these exact attitude complexes represent a boundary grammar of worth/exclusion/dignity rather than generic policy preference?

Manual court.

## H. TEMPORAL STRUCTURAL INTERPRETATION

Question:

> Does an exact comparable trajectory represent persistence, drift, rupture, residuality, emergence, or something else?

Manual court after measurement comparability.

# 3. WHERE MANUAL AUTHORITY MAY NOT BE FINITE ENOUGH

Some decisions may arise continuously as new generated persona queries arrive.

The solution is not unrestricted runtime inference.

Instead:

```text
PRECOMPUTE THE FINITE STRUCTURAL GRAMMAR / AUTHORITY SURFACE
+
ALLOW RUNTIME TO COMPOSE / QUERY WITHIN THAT SURFACE
+
FAIL CLOSED ON NOVEL SEMANTIC PROMOTION.
```

Example:

Runtime may locate a generated profile in an already-governed position space.

Runtime may not invent a new capital type because the generated profile contains an unusual attribute combination.

# 5. AUTHORITY OBJECTS VS EMPIRICAL OBJECTS

Keep separate:

```text
EMPIRICAL OBJECT
    what the data geometry/statistics show

SEMANTIC AUTHORITY
    what Rawlsing is permitted to call/mean by that object
```

Example:

```text
EMPIRICAL:
resource R has strong positive association with local high-status region F,
but negative association with region G.

AUTHORITY:
this pattern is admitted as FIELD_SPECIFIC_CAPITAL_VALUE / NEGATIVE_CONVERSION.
```

The first can be recomputed mechanically.

The second should remain governed semantic capital.

# 6. REPLAY / INVALIDATION

Every manual authority must record the empirical determinants it depends on.

If those determinants change because:

- source semantics corrected;
- routing corrected;
- J authority changes;
- respondent universe changes;
- position geometry materially changes;
- measurement portability changes;

then affected structural authority becomes stale and must be re-adjudicated.

C5 maintenance law applies.
