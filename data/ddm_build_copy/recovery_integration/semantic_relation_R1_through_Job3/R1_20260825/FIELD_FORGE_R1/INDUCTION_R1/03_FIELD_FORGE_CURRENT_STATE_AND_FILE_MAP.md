## Settled direction within FIELD FORGE vs still exploratory

### Strongly stabilized exploratory principles

These are not automatically HQ law, but FIELD FORGE should not casually reopen them without evidence:

- fixed-source constraint;
- stable analytical grammar + context-specific empirical manifestation;
- `strata` demoted from assumed primitive ontology;
- independent position/capital and disposition/attitude empirical constructions before homology/pressure analysis;
- configuration-dependent pressure footprints rather than universal demographic coefficients;
- pressure coupling/nonadditivity is descriptive before it is structural articulation;
- pressure footprint != ultimate causal mechanism;
- hegemony != majority prevalence;
- field != cluster;
- differential resource association != capital conversion;
- capital value is field/context/time relative;
- capital composition matters independently of scalar resource volume;
- contradictory dispositions are information, not noise to be cleaned into one ideology;
- difficult finite semantic judgments should be candidates for manual governed authority rather than runtime heuristic rediscovery;
- source-native semantic identity != analytic position role;
- canonical respondent slot != cross-source equivalence authority;
- question present in a context != respondent exposed to question;
- measurement nonresponse != measurement nonexposure;
- same-respondent J/coadministration authority is part of disposition metric admissibility;
- no common empirical metric should be manufactured across respondent-disjoint measurements;
- no weight should be selected without an explicit representation target/estimand;
- questionnaire/source block organization != sociological ontology;
- final 553+ ontology must be tested against diverse held-out current contexts before freeze;
- PRE-V3 remains a population/world possibility engine rather than realized-person psychology.
