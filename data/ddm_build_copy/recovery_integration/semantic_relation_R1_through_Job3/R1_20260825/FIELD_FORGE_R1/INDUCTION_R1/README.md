# FIELD FORGE R1 — NEW-CHAT INDUCTION COURSE

## Purpose

This course exists so a fresh ChatGPT agent can enter FIELD FORGE cold and recover the current conceptual, constitutional, empirical, and engineering state without depending on an earlier chat transcript.

FIELD FORGE is an exploratory design room for the PRE-V3 → 553+ structural/social-world layer of Rawlsing. It asks: given the source-governed survey universe Rawlsing already possesses, how can the machine recover the strongest feasible relational account of social position, disposition, patterned pressure, hegemony, field-specific capital, and downstream persona possibility without inventing facts the evidence cannot support?

FIELD FORGE is NOT current global Rawlsing architecture merely because a file exists here. It is a prospective court/design laboratory. Later HQ authority must adopt, supersede, narrow, or retire its proposals.

## Fixed mission law

NO NEW SOURCES.

The corpus is fixed for this exercise. Theory is used to make the most of the materials Rawlsing already has: the governed CLOSED_35 survey families, their source-native documentation, existing external structural assets already admitted elsewhere in Rawlsing, and the current semantic/routing/J/fracture machinery.

## Core maxim

Rawlsing's goal is not to explain every ultimate cause in society before it can generate a plausible person. It is to build a learned world capable of representing how social reality presses upon persons without mistaking pressure for destiny.

FIELD FORGE therefore tries to move difficult semantic adjudication leftward into governed authority where the finite decision surface permits it, while leaving arithmetic, joins, geometry, enumeration, replay, and validation to deterministic computation.
