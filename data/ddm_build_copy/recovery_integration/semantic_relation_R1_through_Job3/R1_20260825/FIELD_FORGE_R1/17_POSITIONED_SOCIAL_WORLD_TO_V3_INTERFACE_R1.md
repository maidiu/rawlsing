# FIELD FORGE R1 — POSITIONED SOCIAL-WORLD → V3 INTERFACE

Status: **EXPLORATORY / NON-BINDING / PROSPECTIVE CONSUMER CONTRACT**

FIELD FORGE is only justified if it improves Rawlsing's central product: plausible, socially grounded persons whose biographies remain irreducible to population statistics.

This document specifies what PRE-V3 may hand to V3 after the social-space/pressure architecture exists.

---

# 1. HARD NONCOLLAPSE

```text
POSITIONED SOCIAL POSSIBILITY
!=
INDIVIDUAL BELIEF
!=
ACTOR MEMORY
!=
ACTOR CHOICE
!=
REALIZED LIFE.
```

PRE-V3 supplies a socially structured possibility field.

V3 supplies biography and realization.

---

# 2. ADULT / PARENT GENERATION CASE

If a parent profile includes known attributes such as:

- country/context;
- age/cohort;
- sex;
- education;
- income/resource position;
- occupation/employment;
- religion/sect/ethnicity/race/caste where known;
- region/urbanity;
- migration/mobility where known;

PRE-V3 may compute a probabilistic relational location in the relevant local position space.

From that location it may retrieve:

- applicable disposition-complex distributions;
- pressure-footprint distributions;
- local majority/minority repertoires;
- hegemonic/subhegemonic environment profiles;
- field/formation contexts where admitted;
- uncertainty and observability limits.

It must not return one deterministic worldview.

# 4. CONDITIONAL GENERATION, NOT MAP LOOKUP

The parent generator should sample/construct from the **joint conditional landscape** rather than find the nearest respondent and copy them.

Hard law:

```text
NEAREST OBSERVED RESPONDENT
!= GENERATED PERSON.
```

Potential sequence:

```text
profile constraints
-> position posterior / neighborhood
-> supported disposition-repertoire distribution
-> sample or synthesize a coherent joint worldview
-> preserve minority-path possibility
-> pass to V3/persona realization
```

---

# 5. CONTRADICTION MUST SURVIVE GENERATION

A generated parent may lawfully contain apparently tensioned views if the joint respondent evidence supports them.

Do not impose global ideological consistency as a cleanup step.

Example shape:

```text
strong welfare support
+ conservative family morality
+ anti-elite institutional distrust
+ national pride
+ selected tolerance on unrelated dimension
```

If such a repertoire is empirically supported, it is more realistic than a cleaner synthetic ideology.

---

# 6. HEGEMONY AFFECTS ENVIRONMENT, NOT DESTINY

A hegemonic/common-sense profile tells V3 what kinds of positions are:

- widely normalized;
- broadly circulating;
- locally dominant;
- power-aligned;
- counterposed;
- socially narrow.

It does not say the actor accepts them.

For a child especially, V3 can treat these as different **availability / cost / legitimacy environments** rather than direct beliefs.

---

# 7. CHILD / DEVELOPMENTAL CASE

The current survey corpus is adult-heavy.

Therefore PRE-V3 should not fabricate fine-grained child peer culture from absent data.

It can still provide a rich developmental environment derived from the adult/family/social world:

```text
parental disposition repertoire
family class/resource position
religious/sectarian common-sense environment
regional/national hegemonic complexes
minority/counterhegemonic pathways
education/status aspirations where observed
likely adult institutional trust/distrust landscape
```

V3 then develops the actual child through encounters, relationships, institutions, peers, media, pain, opportunity, and contingency.

The theoretical insight that children inhabit age-specific fields remains an ontology constraint:

```text
DO NOT ASSUME ADULT FIELD VALUE
= CHILD LOCAL FIELD VALUE.
```

Where PRE-V3 cannot observe child-local valuation, leave it to V3/context construction rather than fabricating a population authority.

---

# 8. TRAJECTORY / MOBILITY

Where parental-origin or repeated-position information exists, PRE-V3 may expose trajectory evidence such as:

```text
origin_position
current_position
origin-current distance
capital composition shift
subjective-class mismatch
```

Potential V3 relevance:

- hysteresis;
- cleft/contradictory disposition possibility;
- incomplete conversion into destination norms;
- retained origin repertoire.

Hard law:

```text
MOBILITY
!= INSTANT HABITUS REPLACEMENT.
```

The survey evidence may support increased probability of mismatched or plural dispositions. It cannot dictate the individual's psychic experience of mobility.

---

# 9. GENERATED PARENTS VS GENERATED CHILDREN

## Parents

Rawlsing can use cross-sectional survey evidence relatively directly to construct a plausible adult disposition repertoire conditioned on social position.

## Children

Rawlsing should primarily use the parent/household/social-world packet to define the initial possibility environment, then let V3 development create the child.

This distinction protects the project from using adult population survey distributions as if they were child personality distributions.

---

# 10. PERSONA QUALITY CANARY

FIELD FORGE should eventually compare two generation strategies on identical profiles:

```text
A. independent marginal attitude sampling / older structural model
B. relational position + repertoire + pressure-footprint model
```

Hostile human/agentic evaluation should test:

- does B produce more internally plausible adults?
- does B preserve empirically common contradictions?
- does B avoid stereotypical identity determinism?
- does B generate meaningful minority paths?
- does B distinguish commonness from local/power dominance?
- does B behave differently when the same identity is embedded in different class/education/geography configurations?
- does B expose uncertainty rather than false precision?

The new architecture earns its complexity only if it improves these outcomes.

---

# 11. ANTI-STEREOTYPE LAW

A profile category may alter probabilities only through exact empirical evidence and governed structural relations.

Do not emit:

```text
Shia -> belief X
Black -> belief Y
poor -> morality Z
high education -> liberal
```

Prefer:

```text
within exact context K,
configuration C changes the observed distribution
of repertoire R by amount/profile D,
with minority alternatives preserved.
```

This is both sociologically stronger and safer against caricature.

---

# 12. V3 CONSUMER LAW

V3 must be allowed to:

- instantiate a common path;
- instantiate a supported minority path;
- alter salience through biography;
- introduce context-specific experiences not directly present in PRE-V3 survey evidence;
- carry contradictory dispositions;
- resist hegemonic pressure;
- convert one acquired resource into another context;
- change through time.

It may not pretend PRE-V3 said something it did not.

All borrowed empirical authority should remain traceable.

---

# 13. CURRENT RECOMMENDATION

The proper FIELD FORGE output is not a giant structural label attached to a person.

It is a **positioned social-world packet** rich enough that V3 can generate a person inside a historically structured possibility landscape without confusing that landscape with the person.
