# FIELD FORGE R1 — FIXED SOURCE CONSTRAINT

This campaign does **not** acquire new survey families or external datasets.

Hard constraint:

```text
FIELD FORGE MUST MAXIMIZE THE STRUCTURAL / SOCIOLOGICAL INFORMATION
DERIVABLE FROM THE EXISTING RAWLSING SOURCE UNIVERSE.

NO NEW SOURCE ACQUISITION CAMPAIGN.
```

The purpose of theory work is therefore to improve:

- selection of variables already present;
- separation of position-space from attitude/disposition-space;
- context-relative interpretation of existing indicators;
- lawful use of joint structure, fracture maps, response morphology, temporal recurrence, and demographic configuration;
- construction of field-relative capital proxies from existing variables;
- derivation of empirical pressure footprints;
- hegemony/subhegemony inference from existing surveys plus already-adopted structural sources such as EPR/GeoEPR where available;
- manual/agentic semantic adjudication where code would otherwise invent ontology;
- explicit epistemic limits where the existing corpus does not observe a desired phenomenon.

If the existing sources cannot directly observe a phenomenon (for example, rich school-age peer-field capital), FIELD FORGE must **not** solve that by proposing a new acquisition wave. Instead it must:

1. determine what the existing adult/family/context surveys can legitimately say;
2. separate that from what remains unobserved;
3. design PRE-V3/V3 boundaries so unobserved detail is not fabricated;
4. use theory to avoid overclaiming from proxies.

This constraint supersedes any exploratory source-acquisition suggestion elsewhere in the FIELD FORGE draft materials.
