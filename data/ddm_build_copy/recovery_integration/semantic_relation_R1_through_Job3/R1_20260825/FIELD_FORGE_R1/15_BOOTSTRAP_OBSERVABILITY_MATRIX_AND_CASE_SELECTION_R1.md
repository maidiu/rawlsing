# FIELD FORGE R1 — BOOTSTRAP OBSERVABILITY MATRIX / CASE-SELECTION CONTRACT

Status: **EXPLORATORY / NON-BINDING / EXECUTION-PREPARATORY**

FIELD FORGE must not wait for every possible PRE553 residual to close before testing whether the proposed social-space architecture works.

It also must not prototype on one convenient survey and then mistake local success for a universal ontology.

The solution is a finite **bootstrap observatory court** over a deliberately diverse subset of the existing CLOSED_35 corpus.

No new source acquisition is permitted.

---

---

# 2. WHY OBSERVABILITY MUST BE SEPARATE FROM ONTOLOGY

If Arab Barometer exposes sect and region richly while LiTS exposes material position richly, that difference is not a problem to normalize away.

It is part of what the current evidence can observe.

Hard law:

```text
MISSING MEASUREMENT
!= ABSENT SOCIAL STRUCTURE.
```

The bootstrap should test whether a common grammar can operate over **unequal observability** without requiring every context to instantiate every dimension.

---

# 3. DESIGN CONTEXT SELECTION

Choose bootstrap design contexts to maximize diversity along properties the current corpus already possesses.

Selection criteria may include:

- source-family diversity;
- region/cultural-system diversity;
- richer vs thinner position observability;
- stronger vs weaker identity observability;
- different economic-position measurement styles;
- different attitude battery structures;
- different routing/J complexity;
- availability of repeated waves for a subset;
- presence/absence of parental-origin variables;
- presence/absence of politically salient group identities.

Do **not** select contexts because they are theoretically convenient.

Do not use one family as the ontology template.

---

# 4. HELD-OUT CONTEXTS

Reserve several current contexts that are **not used** to design the first structural grammar.

After candidate grammar emerges, apply it to held-out contexts.

Success requires:

```text
NO CONSTANT SPECIAL-PLEADING
NO FORCED VARIABLE ROLES
NO COLLAPSE OF LOCAL DIFFERENCE
NO INVENTED MISSING DIMENSIONS
```

If a grammar works only on the design contexts, revise the grammar.

Do not patch the held-out survey to save the theory.

---

# 5. MINIMUM BOOTSTRAP PRODUCTS PER DESIGN CONTEXT

Each design context should produce as much of the following as lawful:

```text
1. exact Position Role Authority subset
2. Local Position Space
3. supplementary subjective-status/identity projections
4. governed Disposition Complexes / Repertoires
5. Position ↔ Disposition Pressure Footprints
6. Empirical Motif packet
7. Hegemony-relevant evidence profile where existing power evidence applies
8. explicit observability/authority limits
```

A context lacking one product may still be useful if the absence itself stress-tests the grammar.

---

# 6. DIVERSITY BEFORE VOLUME

For ontology bootstrapping, a smaller number of structurally diverse contexts is initially more informative than hundreds of redundant cases.

But bounded discovery must not be mistaken for global completeness.

The bootstrap answers:

> Is this grammar plausible and engineerable?

It does not answer:

> Has the whole CLOSED_35 structural world been exhaustively computed?

---

# 7. EMPIRICAL MOTIF COMPARISON

Once local outputs exist, compare motifs using **structural signatures**, not raw variable identity.

Possible signature dimensions:

```text
position dimensions involved
identity/resource configuration involved
disposition-complex topology
minority branch structure
nonadditive interaction pattern
cross-position reach
high-position alignment
local dominance
capital-value reversal candidates
temporal recurrence where comparable
```

Then ask manually:

```text
SAME STRUCTURAL FAMILY?
ANALOGOUS BUT CONTEXT-DIFFERENT?
COMPLETELY DIFFERENT?
INSUFFICIENT COMPARABILITY?
```

---

# 8. BOOTSTRAP SUCCESS CRITERIA

FIELD FORGE may recommend moving to a formal 553+ structural grammar court only if:

```text
A. multiple distinct current source families produce lawful local position spaces;
B. disposition complexes can be mapped onto those spaces without circularity;
C. configuration-dependent pressure footprints are empirically nontrivial;
D. the same grammar represents both additive and nonadditive/contextual patterns;
E. missing dimensions remain typed rather than invented;
F. held-out contexts do not require wholesale ontology rewriting;
G. at least some candidate structural concepts can be grounded in repeatable empirical motifs;
H. the new objects materially improve persona-generation possibility packets compared with independent-question sampling.
```

---

# 9. FAILURE IS INFORMATIVE

Possible bootstrap findings:

```text
POSITION GEOMETRY TOO THIN IN MANY SOURCES
DISPOSITION COMPLEXES TOO ROUTING-BLOCKED
MCA NOT ROBUST FOR CERTAIN FAMILY
FIELD CONCEPT TOO STRONG FOR SURVEY EVIDENCE
HEGEMONY DIMENSIONS MOSTLY UNOBSERVED
PRESSURE FOOTPRINTS USEFUL WITHOUT FIELD ONTOLOGY
CAPITAL COMPOSITION ONLY RECOVERABLE IN SOME CONTEXTS
```

These results should reshape the architecture rather than be hidden.
