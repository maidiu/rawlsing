```text

OUT_OF_SCOPE
```

No semantic role may be inferred from a variable name alone.

# FF-B1 — POSITION-ROLE AUTHORITY PILOT

For selected current contexts, manually adjudicate which variables are lawful active position-space coordinates, supplementary descriptors, attitude variables, administrative fields, or ambiguous.

This should be treated like semantic/directional authority work: finite, high-consequence, manually reasoned, provenance-bearing, then machine-consumed.

# FF-B2 — DESIGN-ATLAS CONTEXT SELECTION

Do not pick contexts by convenience or prestige.

Select a small but deliberately diverse design atlas based on the observability matrix.

Selection objective:

```text
maximize variation in
- source family
- position-variable composition
- identity structure
- economic/material measurement style
- geographic granularity
- attitude-battery structure
- available trajectory proxies
while remaining inside current governed scope
```

Reserve materially different contexts as held-out tests.

# FF-B8 — THEORY COURT

Use Bourdieu as primary relational geometry and test additional concepts only where they improve representation of real atlas objects:

- Gramsci: hegemony/common sense/relation of forces;
- Hall: articulation/conjuncture/nonessential positional effects;
- Lahire/Swidler: plural repertoires and contradictory co-possession;
- Lamont: symbolic/moral boundaries and classed worth;
- Williams/Mannheim: temporal/cohort structure where lawful;
- Thornton/Eckert/Willis/Lareau: hostile constraints against universal capital valuation and linear socialization, not source-acquisition demands.

Every proposed primitive must answer:

```text
WHAT EMPIRICAL OBJECT DOES THIS HELP REPRESENT
THAT A SMALLER GRAMMAR CANNOT REPRESENT?
```

# FF-B9 — HELD-OUT CROSS-CONTEXT FALSIFICATION

Apply the candidate grammar to reserved current contexts.

Reject/revise if it requires:

- arbitrary universal meanings for local variables;
- constant new primitives;
- forced measurement equivalence;
- silent loss of minority/contradictory structures;
- treating unavailable evidence as negative evidence;
- causal stories unsupported by the surveys;
- persona outputs determined by theoretical labels rather than empirical distributions.

FIELD FORGE does not require every current routing/J residual to close before prototyping.

This allows useful theory/engineering work to proceed without lowering semantic standards or freezing the final ontology prematurely.
