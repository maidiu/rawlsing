# FIELD FORGE R1 — 553+ STRUCTURAL GRAMMAR FREEZE COURT

Status: **EXPLORATORY / NON-BINDING / PROSPECTIVE ADMISSION DESIGN**

This document specifies when Rawlsing should be permitted to turn empirical observatory outputs into a durable post-PRE553 structural grammar.

The purpose is to prevent two opposite errors:

```text
THEORY-FIRST FOSSILIZATION:
we like Bourdieu/Gramsci/etc.
-> hardcode their nouns before seeing the data

COMPUTE-FIRST ONTOLOGY:
clustering/MCA/models produce patterns
-> algorithm silently decides what society consists of
```

The grammar court must sit between those extremes.

---

# 1. INPUTS TO THE COURT

The court should receive:

- FIELD FORGE theory-engineering stack;
- design-context observability matrix;
- Position Role Authority;
- local position spaces;
- disposition complexes/repertoires;
- pressure-footprint atlas;
- empirical motif atlas;
- hegemony evidence profiles where available;
- field/capital-conversion candidacy packets;
- held-out context results;
- exact epistemic limits;
- current PRE553/V553 inheritance requirements.

No theoretical concept may be admitted merely because a theorist is prestigious.

No empirical pattern may be admitted as structural meaning merely because it is statistically stable.

# 3. ADMISSION TEST FOR EACH PRIMITIVE

For every proposed grammar object ask:

```text
1. What irreducible information does this object preserve?
2. Can that information already be represented losslessly by existing objects?
3. What exact empirical/authority inputs can produce it?
4. Which parts are computation and which are semantic adjudication?
5. Can the object represent multiple current survey families without special pleading?
6. What happens when a source cannot observe one dimension?
7. What is the typed negative/unresolved state?
8. Who consumes this object downstream?
9. What would break if it were omitted?
10. What hostile case prevents semantic overreach?
```

Possible decisions:

```text
ADMIT_GRAMMAR_PRIMITIVE
ADMIT_WITH_RESTRICTED_SCOPE
DERIVED_VIEW_ONLY
EXPERIMENTAL_ONLY
REDUNDANT_WITH_EXISTING_OBJECT
UNDERENGINEERED
INSUFFICIENT_EMPIRICAL_SUPPORT
REJECT
```

# 4. SPECIAL STATUS OF `STRATA`

Historical `strata` should be challenged directly.

Possible outcomes:

```text
STRATUM = RETAIN AS PRIMARY PRIMITIVE
STRATUM = RETAIN AS DERIVED HIERARCHICAL VIEW
STRATUM = RETIRE, FUNCTIONS ABSORBED BY POSITION/FIELD/FORMATION GRAPH
STRATUM = RETAIN ONLY FOR SPECIFIC DOWNSTREAM COMPATIBILITY
```

The court must identify every irreducible function previously assigned to strata and prove its successor.

No semantic function may disappear merely because the new model is cleaner.

# 5. THEORETICAL ADMISSION RULE

Theories enter Rawlsing as **constraints and candidate interpretations**, not automatic authorities.

Examples:

## Bourdieu

Admit if the empirical observatory supports relational position, capital composition, field-relative valuation, trajectory/hysteresis, or homology objects that materially improve representation.

Do not admit `FIELD` everywhere simply because Bourdieu uses fields.

## Gramsci

Admit a hegemony grammar only if the profile preserves prevalence/power/reach distinctions unavailable in ordinary attitude prevalence.

## Hall

Likely admit as a hard anti-essentialist relation law:

```text
POSITION ATTRIBUTE EFFECTS ARE CONTEXTUAL/ARTICULATED,
NOT UNIVERSAL CONSTANTS.
```

## Lahire / Swidler

Admit repertoire/contradictory-disposition representation if same-respondent evidence shows meaningful plural co-possession.

## Lamont

Admit symbolic/moral boundary objects if survey complexes repeatedly support evaluation/exclusion/dignity structures not reducible to position alone.

The court should be willing to reject or narrow any theorist-derived primitive.

---

# 6. HELD-OUT CHALLENGE

A candidate grammar should be applied to held-out current contexts.

Reject or revise grammar if it requires:

- forced role assignment;
- invented missing variables;
- universalized local semantics;
- collapsing context-specific difference;
- treating source absence as social absence;
- field/class labels with no corresponding empirical packet.

The goal is not identical outputs across contexts.

The goal is **the same grammar handling different worlds honestly**.

---

Before final freeze, compare persona-generation inputs under:

```text

vs
FIELD FORGE CANDIDATE GRAMMAR
```

The new grammar should demonstrably improve at least some of:

- joint worldview coherence;
- contradiction preservation;
- context sensitivity;
- minority-path preservation;
- class/identity nonessentialism;
- field-specific valuation;
- hegemony/local-dominance distinction;
- uncertainty honesty.

If the structural ontology does not materially improve the persona-generation possibility field, its complexity may not be justified.

Do not pretend ontology freeze means eternal ontology.
