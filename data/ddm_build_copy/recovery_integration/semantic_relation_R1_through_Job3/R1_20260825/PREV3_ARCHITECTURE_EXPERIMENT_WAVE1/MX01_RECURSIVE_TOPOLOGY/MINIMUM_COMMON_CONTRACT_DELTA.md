# MX01 — Minimum Common Contract Delta

Status: `DELTA_REQUIRED__NO_PRODUCTION_IMPLEMENTATION_AUTHORIZED_HERE`

## Holding

The current common PRE553 objects are sufficient for:

- an exact predeclared derived branch cohort;
- one-generation branch-constrained predicate composition;
- branch-conditioned same-respondent cross-question querying;
- exact typed `VALID_EMPTY` and `INSUFFICIENT_SUPPORT` discovery outcomes;
- deterministic one-generation frontier/receipt/replay identity.

They are not sufficient for the complete historical recursive function because a discovered child branch cannot be handed forward as a canonical, role-preserving parent for another discovery generation through the current public contract.

This is the first irreducible gap. MX01 stops here.

## Minimum delta required

HQ should strengthen the **common recursive branch handoff/lineage contract**. No carrier-specific implementation is justified by MX01.

The minimum contract must provide all of the following without relying on caller reconstruction or private compiler functions:

1. **Resolvable child predicate identity**
   - the exact compiled child `EmpiricalPredicate` must remain resolvable from its `winning_predicate_ref`, or its complete canonical semantic projection must be durably bound to a replay object;
   - a bare ref whose object is not available to the next public discovery invocation is insufficient.

2. **Role-bearing immediate-parent edge**
   - preserve `immediate_parent_branch_ref` separately from earlier ancestors;
   - do not encode recursive lineage only as an unordered/set-like ancestry collection.

3. **Replay-equivalent cohort membership**
   - bind either the exact member respondent refs or a complete deterministic membership-replay contract sufficient to reproduce the exact cohort from source + governed authority;
   - membership must not be inferred from a question key, marginal, diagnostic score, or label.

4. **Next-generation consumption law**
   - a public/common invocation must be able to consume the discovered child as the baseline/parent for a later recursive generation;
   - the handoff must retain exact source/universe, risk-set, predicate grammar, same-respondent binding, topology/measure scope, discovery authority/frontier, and replay identity.

5. **Fresh-process closure**
   - after process exit, generation N+1 must be reconstructible from committed authority/source/replay material without hidden in-memory `_Candidate` or private `_compile_frontier` state.

## Reuse before invention

The existing internal `DiscoveryBranchReplayBinding` already contains useful fields including `parent_branch_ref_or_typed_absence` and `winning_predicate_ref_or_typed_absence`. HQ should first test whether strengthening and actually materializing that existing carrier, together with a public role-bearing handoff ref from `DiscoveryResultReceipt`, can close the gap.

MX01 does **not** prove that a new public object family is necessary. It proves that the existing executed/public handoff is insufficient as currently constituted.
