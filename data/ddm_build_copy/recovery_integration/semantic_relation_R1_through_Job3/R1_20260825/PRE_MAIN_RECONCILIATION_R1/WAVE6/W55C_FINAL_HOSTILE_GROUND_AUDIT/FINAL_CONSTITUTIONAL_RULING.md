# FINAL CONSTITUTIONAL RULING

Overall ruling: `BLOCKED__VALIDATOR_FAIL_OPEN`.

The Rawlsing Ground/central-state/no-stranding constitution is conceptually strong enough for a fresh Vozhd, compact enough for progressive grounding, and centrally sweepable. It should not be globally adopted yet because the W55B validator does not mechanically enforce the constitution it purports to seal.

Root bypasses include:

- mutually consistent stale packet/receipt heads can pass without comparison to the actual canonical ref;
- shallow grounding can self-assert scope completion without scope-relevant evidence;
- empty relevant/touched-obligation sets pass via subset/vacuous-truth logic;
- bounded execution requires no exact grounded-parent receipt/ref or inherited ceiling relation;
- unknown agent/reintegration values can pass;
- successor return targets are not validated per successor;
- obligation dispositions are semantically unchecked, allowing blocked/unknown state to be falsely closed;
- project-closure claims can hide in ignored fields while an unreconciled reintegration status passes;
- anti-resurrection acknowledgement is satisfied by any nonempty list, including `['none']`.

These bypasses directly fail the intended guarantees behind GC-G3, GC-G4, GC-G6, GC-G7, GC-G8 and GC-G9, with GC-G11 as the root blocking gate.

The repair should be bounded and mechanical rather than another Ground rewrite: validate schemas; bind canonical head/version to an external/current canonical source rather than packet self-assertion; require declared relevant/touched sets where the mode/action requires them; validate bounded-parent receipt/ref and ceiling; enumerate agent/reintegration/disposition semantics; prove per-successor return edges; couple project-closure claims to reintegration/obligation state; and validate anti-resurrection acknowledgements against relevant constraints.

No global adoption is authorized by W55C.
