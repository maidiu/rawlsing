# Fixture / mutation quality audit

W56A's corpus is nontrivial: 66 fixtures (10 expected pass, 56 expected fail) and 65 mutations, with reported agreement under both schema engines. That is useful regression coverage.

It is insufficient to certify the hostile gates because it does not encode the decisive attacks found by code audit: laundering a specialized subject through GENERAL_PROJECT_DECISION; unknown nested authority-effect class; existing-but-irrelevant/mutable evidence refs; exact successor mapping combined with parent closure; schema-valid but substantively shallow bounded parent; or governance self-modification.

The fixture generator and validator share assumptions, so zero mismatches is corroboration of intended mechanics, not proof that the mechanics implement the constitution. R2A-G19 fails as a PASS gate.
