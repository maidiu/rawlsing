# Bootstrap noncircularity

## G11 — PASS as constitutional sequence; not sufficient for terminal PASS

The one-time bootstrap decision does not require:
- the candidate validator to declare itself accepted;
- candidate schemas to validate their own adoption authority;
- candidate branch authority to move PRE-MAIN;
- candidate-generated hostile evidence;
- audit-worker integration authority.

The authorization is a sibling of the candidate rooted directly at `8b13...`; this audit branch begins at the authorization commit; the candidate is inspected by immutable SHA. The only movement contemplated by the written bootstrap law is an external VOZHD/HQ canonical-ref act after hostile PASS.

Therefore the bootstrap *governance sequence* is noncircular.

Terminal readiness nevertheless fails because the post-install predecessor gate has an unclosed Git executable trust dependency. Noncircular constitutional sequencing cannot substitute for executable trust closure.
