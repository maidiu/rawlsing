# ADOPTION AND BANKING GATE R1

No significant Rawlsing result acquires project acceptance solely from its own worker return.

Before campaign/HQ/global adoption, prove:

- `GROUNDING_RECEIPT_VALID`;
- `CANONICAL_BASE_MATCH`;
- `GROUND_VERSION_MATCH`;
- `AUTHORITY_CEILING_VALID`;
- `TOUCHED_OBLIGATIONS_DISPOSITIONED`;
- `NEW_OBLIGATIONS_REGISTERED`;
- `SUCCESSOR_RETURN_PATHS_REGISTERED`;
- `CENTRAL_STATE_DELTA_DECLARED`;
- `ANTI_RESURRECTION_PASS`;
- `REINTEGRATION_STATUS_DECLARED`;
- competent adopting authority identified.

Missing required data fails closed for project adoption. The result may remain preserved evidence, local work, campaign work, or exploration at its actual status.

Worker PASS, mergeability, test success, physical presence, downstream use, newest timestamp and branch ancestry are insufficient substitutes.
