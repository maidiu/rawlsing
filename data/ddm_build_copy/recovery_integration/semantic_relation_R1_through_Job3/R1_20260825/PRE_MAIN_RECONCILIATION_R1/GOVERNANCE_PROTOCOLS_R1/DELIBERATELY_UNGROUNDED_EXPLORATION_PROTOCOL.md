# DELIBERATELY UNGROUNDED EXPLORATION PROTOCOL R1

Rawlsing permits intentional clean-room exploration when inheritance itself could overconstrain discovery.

The work must begin with:

```text
MODE = DELIBERATELY_UNGROUNDED_EXPLORATION
NO_PROJECT_AUTHORITY = TRUE
NO_ADOPTION_POWER = TRUE
NO_CLOSURE_POWER = TRUE
```

Such work may generate hypotheses, alternative architectures, conceptual vocabularies, prototypes or attacks on inherited assumptions. It may not claim `CURRENT`, `ACCEPTED`, `ADOPTED`, `CLOSED`, `PROJECT_ARCHITECTURE`, or `HQ_BANKED` on its own authority.

Its central reintegration state is `EXPLORATORY_UNRECONCILED` until a then-current grounded competent agent compares it against binding law, must-factor inheritance, open obligations, tensions and unknowns.

Tests, novelty, elegance, user enthusiasm or downstream experimentation do not waive grounded reconciliation.
