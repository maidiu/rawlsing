# PRE-MAIN FINAL ADMISSION GATE

Source constitution: W10. There is **no legitimate existing single global omnibus “cold validation” executable**. Do not manufacture one. Admission composes real executable tests with binding ledger/manual/semantic courts.

A candidate is `PREMAIN_ADMISSIBLE` only if PM-G1 through PM-G8 all satisfy their minimum pass condition.

## PM-G1 — Git / reachability integrity

Mode: executable + ledger.

Pass:
- candidate descends from the declared canonical base;
- every delta claimed as ancestry is actually reachable;
- every off-tree accepted delta is represented by the exact ledger action specified by W26 rather than silently claimed reachable;
- `git fsck --full`, `git diff --check`, and exact base verification pass;
- changed paths are all adjudicated integration paths.

Failure: BLOCK.

- J01-A remains exactly 1,879 source structures / 1,411 candidates / 9 families / 35 scopes with frozen carrier hashes;

Failure: BLOCK.

- PM-G1..PM-G8 all PASS;
- no unresolved integration-node blocker affects required current accepted capital;
