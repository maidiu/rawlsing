# RAWLSING WHOLE-SPINE BUILD CONSTITUTION CANDIDATE R1

## 1. Build law

Design bidirectionally from downstream requirements and upstream authority; execute semantic authority forward from producer to consumer.

`NEVER_FINISH_A_LAYER_IN_ISOLATION`.

Build capabilities through the full stack and keep one end-to-end thread executable at all times.

A component owns only new meaning it lawfully creates. Reference, query, publication, persistence, reconstruction, cache, co-location and rendering do not transfer ownership.

No `latest/default/fuzzy/nearest` authority or semantic fallback is lawful.
