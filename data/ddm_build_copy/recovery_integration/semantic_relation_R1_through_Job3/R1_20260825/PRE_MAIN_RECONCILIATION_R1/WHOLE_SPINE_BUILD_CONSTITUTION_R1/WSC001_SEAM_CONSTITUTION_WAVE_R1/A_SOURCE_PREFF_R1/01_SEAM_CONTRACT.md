## 1. Jurisdiction

This contract owns only the interface by which exact current source/current-empirical authority becomes lawfully consumable by PRE-FF empirical/query/discovery machinery.

It does **not** own source semantics, source candidacy, routing truth, measurement portability, structural meaning, FIELD FORGE semantics, PRE-V3 structural admission, actor state, or V3 realization.

The seam must preserve:

`CURRENT_SOURCE_IDENTITY`
`+ CURRENT_CANDIDACY_IDENTITY`
`+ ROUTING/APPLICABILITY_STATE`
`+ SOURCE_NATIVE_MEANING/TOPOLOGY`
`+ SAME_RESPONDENT_INFORMATION_WHERE_REQUIRED`
`+ WEIGHT/DESIGN/ESTIMAND_IDENTITY`
`+ EXACT QUERY/PREDICATE/RISK_SET/MEASURE/SOURCE_SCOPE`
`+ OPERATION_SCOPED_SOURCE_RELATIONS_WHERE_REQUIRED`
`+ EXACT AUTHORITY/PERMISSION CLOSURE`
`+ TYPED NEGATIVE/EMPTY/UNKNOWN STATES`
`+ DETERMINISTIC REPLAY/PROVENANCE`.

## 7. Permissions

1. **Exact use only.** Authority existence does not imply universal downstream use.
2. **Monotone narrowing.** A consumer may narrow a producer permission but cannot widen it.
3. **No source-relation entailment.** Every relation kind required by an operation must be separately present and exact-bound.
4. **No implicit composition.** Multi-source data remain source-indexed unless exact pooling/composition/nonduplication/estimand authorities license composition.
5. **No measurement-portability borrowing.** Semantic equivalence, common labels/scales, weighting, pooling or harmonization do not grant measurement equivalence/portability.
6. **No retirement by equivalence module.** Source→carrier equivalence certification can establish only its stated semantic/replay equivalence; it cannot authorize source retirement, cutover or pooling.
7. **No repository-presence permission.** Physical availability in C11/cache/Parquet/DuckDB/source-backed facade does not authorize query or use.
8. **No provenance-as-permission.** Provenance/alias material is descriptive unless a competent authority explicitly grants the required operation.

The minimum future Golden Thread 0 path through WSC001A is:

Select one exact source/candidate already present in J01-A's current freeze. Bind the exact current C06 row for the same current identity. The route must be positive/applicable for the intended query, or the path terminates in the exact typed nonpositive routing state.

### Step B — exact single-source empirical universe

Bind one exact `EmpiricalUniverse@1.0.0` plus exact source artifact/release/instrument, native question/component meaning, response topology/special states, respondent-event/risk-set semantics, and measure/weight/design authority actually required by the query.

### Step C — exact query

Bind one authorized `EmpiricalPredicate@1.0.0` and `EmpiricalQuerySpec@1.0.0` with:

- `SINGLE_UNIVERSE` source scope;
- exact risk-set ref;
- exact measure-basis ref;

- exact authority closure.

Execute through current `pre553_empirical_query.py` over an accepted exact C11 logical release or an exactly equivalent lawful source-backed realization. No latest/fuzzy release resolution is allowed.

### Step D — preserve result state

Return one or more exact `EmpiricalFact@1.0.0` refs. Positive `SUPPORTED`, observed zero, low-support, valid-empty, unavailable, noncomparable and integrity states remain distinct.

### Step E — replay closure

Bind exact source-content/release refs, exact historical authority refs and deterministic replay root. If replay closure cannot be established, emit replay/integrity failure rather than positive handoff.

### Step F — handoff without semantic reownership

Create the non-semantic `WSC001A_PREFF_EMPIRICAL_HANDOFF@1` reference envelope over the exact producer-owned refs and permission ceiling. The next seam may consume those refs; it may not infer FIELD FORGE structural meaning from their mere presence.

This path is sufficient to make the seam executable in principle while preserving all five generalized open gates.
