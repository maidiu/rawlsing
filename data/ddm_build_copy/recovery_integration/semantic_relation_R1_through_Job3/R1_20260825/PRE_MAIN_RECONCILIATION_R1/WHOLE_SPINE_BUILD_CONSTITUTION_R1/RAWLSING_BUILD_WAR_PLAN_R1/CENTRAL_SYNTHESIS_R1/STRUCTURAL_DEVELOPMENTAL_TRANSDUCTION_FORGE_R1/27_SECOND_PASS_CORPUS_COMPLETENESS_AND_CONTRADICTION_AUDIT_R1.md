## 6. Defects found in Candidate R2

The second pass found real contract weaknesses in File 24. They do not require D4, but they are significant enough that R2 should not be treated as final without correction.

### F1 — primitive class is not an executable mechanism rule

R2 §0 says an exact typed mechanism rule is required, but its formal input/output tuples retain only `MECHANISM_PRIMITIVE(S)`.

That is insufficient.

`P1`–`P5` are architecture **classes**, not executable derivation laws. Without a separately governed exact rule identity, they can become new black boxes.

Required correction:

```text
MECHANISM_CLASS
+
MECHANISM_RULE_REF / VERSION / AUTHORITY
```

with explicit input schema, applicability law, output schema, realization witness law, temporal scope, source/evidence status, boundary conditions and negative ceiling.

Binding firewall:

`THEORY MECHANISM CARD != EXECUTABLE ACTOR-FACT RULE`.

### F2 — realization needs an exact witness, not merely a status field

R2 correctly says qualification != realization, but `QUALIFICATION_OR_REALIZATION_STATUS` is too weak by itself.

The independent review's A6 ruling is stronger:

```text
D1' QUALIFICATION MAY NOT MINT REALIZATION.
```

Whenever a D1' output is `ACTIVE` or `REALIZED`, exact competent `REALIZATION_WITNESS_REF(S)` must be present.

Examples:
- resource transfer/receipt: actual source-owned transfer/state receipt;
- enforceable authority/obligation: occupied relation + operative/enforceable rule/state;
- recurrent activity: actual participation/recurrence evidence, not schedule/opportunity;
- gate treatment: actual gate decision/treatment receipt;
- information/support/contact: actual transfer/contact/channel-use evidence.

D1' may derive the actor-relative consequence **of** a witnessed state/event. It may not author the occurrence because the structural rule predicts it.

### F3 — linked-life source state is too broad

R2's `SOURCE_REALIZED_STATE_OR_TRANSITION` could be misread to permit private V3 psychology to flow directly into another actor's objective ecology.

Required narrowing:

Only an externally admitted/source-owned **social/world** state, action, contribution, availability, resource, obligation, presence/absence, or transition may be a D1' cross-person source.

```text
PARENT DISTRESS != CHILD OBJECTIVE CONDITION

PARENT REALIZED ABSENCE / WITHDRAWAL / ACTION / RESOURCE CHANGE
+ EXACT RELATION
-> POSSIBLE CHILD ECOLOGY CONSEQUENCE
```

Private motive, belief, distress, appraisal or trait cannot directly become another actor's social fact.

### F4 — P2/P3 overlap around autonomy/discretion

R2 lets P2 own control and P3 emit discretion. That risks duplicate causal ownership.

Required sharpening:

```text
P2 owns formal/enacted decision rights, control scope, supervision,
   obligations, rights and sanctions.

P3 owns task/activity content, complexity, routinization, schedule,
   duration, intensity, recurrence and time organization.

EXERCISED AUTONOMY / DISCRETION
= P2 control scope
+ P3 task organization
+ actual participation/realization witness.
```

### F5 — title/role decomposition needs to be generalized

Existing R2 explicitly says occupation title != work content, but the same law must cover nominal roles more generally:

```text
ROLE/TITLE LABEL
!= ACTUAL POSITIONAL RELATION
!= AUTHORITY SCOPE
!= OBLIGATION
!= TASK CONTENT
```

unless an exact governed rule and context establish the relation.

### F6 — objective “strain” language risks psychology leakage

The atlas can use “strain” as source vocabulary, but D1' should emit objective demand/resource/control/time/uncertainty conditions, not an unqualified psychological `STRAIN` fact.

Required:

```text
OBJECTIVE DEMAND / RESOURCE SHORTFALL / CONTROL CONSTRAINT
!= PERCEIVED STRAIN / DISTRESS
```

Perceived strain/distress remains V3.

### F7 — D1' history input needs an objective-social firewall

`HISTORY_BINDING` must not become a covert route for V3 state back into D1'.

D1' may consume source-owned external/social history such as:
- prior position;
- prior institutional record/mark;
- prior resource/relationship state;
- prior admitted transition;
- externally realized activity/contact history where relevant.

It may not consume private belief/motive/distress/trait/capacity as though these were social source facts. Person-side action influences later world facts only through the governed external-response route.

### F8 — developmental phase belongs in D1' only when socially constitutive

Mortimer/Elder show phase/timing can alter developmental consequences. That does not mean D1' may use developmental phase as a generic causal modifier of objective social facts.

Phase/age may qualify D1' only when an external social/institutional rule actually depends on it (school eligibility, legal age, age-graded institutional trajectory, etc.). Otherwise heterogeneous developmental effect belongs downstream V3.

### F9 — non-event V3 ingress remains an explicit downstream interface obligation

CAN-008 R2 is project-current semantic authority for **person×event** receivability/appraisal/recruitment/immediate response.

D1' also produces objective persistent conditions, directed relations and recurrent activities. Live OBL062 still states that important V3/PFF connective transition semantics are canonicalized/partial/unimplemented and requires two-ended reconciliation.

Therefore:

```text
D1' ADOPTION
!= PROOF THAT EVERY NON-EVENT D1' FACT HAS A CURRENT COMPLETE V3 INGRESS PATH.
```

This does not create D4 and does not reopen the theory question. It is a named downstream interface/adoption obligation: for each D1' temporal form, prove the exact competent V3 conditioning/receipt path without converting persistent states into fake OEE events or duplicating psychology.
