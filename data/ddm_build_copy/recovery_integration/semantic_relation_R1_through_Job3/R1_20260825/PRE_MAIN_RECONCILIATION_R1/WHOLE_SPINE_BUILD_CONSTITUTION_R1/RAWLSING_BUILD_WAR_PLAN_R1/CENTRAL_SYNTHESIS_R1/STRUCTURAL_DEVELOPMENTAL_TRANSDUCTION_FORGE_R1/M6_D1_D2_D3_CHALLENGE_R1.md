## 0. Challenge standard

M6 does not ask whether the source can be made to fit D1-D3. It asks whether exhaustive inspection exposes a causal function that D1-D3 omit, whether one of the three is overbroad, or whether any frozen semantic edge contradicts the book's measurement/identification structure.

A new D4 is warranted only if a source-required connective function cannot be represented by composition of D1-D3 plus existing V3 owners.

## 1. D1 challenge — typed actor-relative social ecology derivation

### 1.1 Frozen D1 claim

D1 derives actor-relative social conditions from admitted structural facts, exact actor/position/context bindings and typed mechanism rules.

### 1.2 Strongest Kohn/Schooler test

The source repeatedly separates remote structural labels from proximal job conditions:

```text
CLASS / STRATIFICATION / ORGANIZATIONAL POSITION
-> SUBSTANTIVE COMPLEXITY
-> CLOSENESS OF SUPERVISION
-> ROUTINIZATION
-> PROTECTIONS / RISKS / TIME / PHYSICAL PRESSURES / INCOME
```

These are not interchangeable outputs. Chapter 7 shows that much apparent class/status association with psychological functioning is accounted for after concrete occupational self-direction is modeled.

This is a direct positive test of D1: the structural category must produce typed actor-relative work conditions before any developmental claim is possible.

### 1.3 D1 survives

Verdict:

`PASS__D1_REQUIRED`.

Kohn/Schooler strongly rejects a direct structural-category -> psychological-trait edge and instead requires a derivation from position to concrete work ecology.

### 1.4 D1 sharpening: occupation title is never realization

D1 must carry a hard invariant:

```text
OCCUPATION_TITLE / OCCUPATIONAL_STATUS
MAY INDEX OR QUALIFY POSSIBLE WORK CONDITIONS
BUT MUST NOT INSTANTIATE
SUBSTANTIVE_COMPLEXITY / SUPERVISION / ROUTINIZATION /
EXERCISED_CONTROL / RECURRENT_ACTIVITY
WITHOUT ACTOR-SPECIFIC EVIDENCE OR A GOVERNED DERIVATION.
```

The book's own measurement strategy and its warning about occupation-level DOT proxies make this more than a stylistic preference.

### 1.5 D1 sharpening: latent OSD is not an output mechanism

D1 should not emit a black-box scalar `occupational_self_direction` when provenance-bearing first-order conditions are available. OSD is a useful second-order measurement construct, but the causal seam requires the typed ingredients:

- task complexity;
- supervisory constraint;
- routinization/predictability;
- possibly other risk/resource/pressure conditions.

Thus:

`LATENT_COMPOSITE != ACTOR_RELATIVE_SOCIAL_FACT` unless its first-order derivation remains inspectable.

### 1.6 D1 sharpening: control needs enactment

The frozen constitution already gives `formal autonomy -> enacted task/supervision state -> exercised autonomy condition` as a realization example. M6 strongly confirms this exact separation.

Required work-domain specialization:

```text
FORMAL AUTHORITY/CONTROL CONFIGURATION
-> ACTOR-SPECIFIC DISCRETION / SUPERVISION / TASK DEMAND
-> ACTUAL EXERCISED JUDGMENT IN WORK
```

This is not a new D4. It is a concrete D1 realization rule whose history is carried by D2.

## 2. D2 challenge — interval, recurrence and transition rebinding

### 2.1 Frozen D2 claim

D2 prevents chronic conditions, recurrent practices and transitions from being collapsed into isolated events. It preserves duration, recurrence quality and rebinding across transitions.

### 2.2 Strongest Kohn/Schooler test: substantive complexity

The book's core mechanism is unintelligible if work is represented as a title or one-time exposure. Substantive complexity means that performance repeatedly requires thought and independent judgment under complex contingencies.

The developmental candidate is therefore:

```text
ACTIVE COMPLEX-WORK CONDITION
-> REPEATED ACTS OF ANALYSIS / JUDGMENT / PROBLEM SOLVING
-> DEVELOPMENTAL CONSEQUENCE
```

The source does not continuously measure every act, but its job-content classifications define the activity quality with unusual precision.

Verdict:

`PASS__D2_REQUIRED`.

### 2.3 D2 sharpening: recurrence needs typed activity quality

A counter alone is insufficient. Repetition of mechanically fixed work and repetition of complex problem solving are both recurrent, but the source predicts different consequences.

D2 must therefore preserve at minimum:

```text
RECURRENCE_IDENTITY
ACTIVITY_TYPE
QUALITY/COMPLEXITY
CONTROL/DISCRETION CONDITION
FREQUENCY OR DENSITY WHERE KNOWN
DURATION/VALID INTERVAL
PROVENANCE
```

No source-derived universal numeric dose threshold is available.

### 2.4 D2 sharpening: persistent relation versus recurrent episode

Closeness of supervision is simultaneously:

- a persistent authority/discretion relation; and
- recurrently realized through instructions, pace control, obedience expectations and disagreement constraints.

Rawlsing should not force either layer to stand in for the other.

```text
ACTIVE_SUPERVISORY_RELATION
!=
EACH SUPERVISORY_EPISODE
```

The relation qualifies the activity ecology; realized episodes/history establish what was actually exercised or constrained.

### 2.5 D2 sharpening: transition identity

Person -> later work feedback commonly implies job change, promotion, transfer, ownership change or task redesign. These must rebind work conditions. A later occupational title alone is inadequate.

A lawful work transition needs before/after state:

```text
OLD_POSITION + OLD_JOB_CONDITIONS
-> ADMITTED TRANSITION/GATE
-> NEW_POSITION + RE-DERIVED NEW_JOB_CONDITIONS
```

### 2.6 Timing uncertainty must remain uncertainty

Chapter 13 explicitly leaves onset, threshold, accumulation and habituation unresolved. D2 must carry interval/recurrence structure without pretending the source supplies exact timing laws.

Thus M6 supports D2's representational capacity, not a universal work-exposure kernel.

## 3. D3 challenge — provenance-preserving reciprocal social-world update

### 3.1 Frozen D3 claim

The frozen constitution requires:

```text
ACTOR-GENERATED ACTION
-> REALIZED EXTERNAL ACTION/EVENT
-> INSTITUTIONAL/COUNTERPART/GATE RESPONSE
-> ADMITTED CHANGE IN RELATION/POSITION/RESOURCE/RULE
-> NEW SOCIAL FACT
-> LATER ECOLOGY DERIVATION
```

### 3.2 Strongest Kohn/Schooler test

Prior ideational flexibility strongly predicts later substantive complexity. Several self-directed orientations also predict later OSD. The effect is predominantly lagged, consistent with selection or job molding over time.

This is exactly the kind of reciprocal path D3 is intended to represent.

### 3.3 D3 survives

Verdict:

`PASS__D3_REQUIRED`.

The book would be misrepresented by a one-way structure -> person architecture.

### 3.4 D3 sharpening: explicit organizational/labor-market gate

The source does **not** observe the exact selection mechanism. Therefore D3 must prevent an implementation from turning a lagged SEM association into a direct world update.

Binding specialization:

```text
PERSON CAPACITY / ORIENTATION
-> ACTION / PERFORMANCE / SEARCH / PERSISTENCE / NEGOTIATION
-> ORGANIZATIONAL OR LABOR-MARKET GATE
-> ADMITTED JOB/POSITION/TASK CHANGE
-> D1 RE-DERIVATION OF JOB CONDITIONS
```

The gate may represent promotion, hiring, exit, transfer, job redesign or another externally realized process, but one must exist.

### 3.5 D3 sharpening: selection and molding remain unresolved alternatives

The book cannot distinguish cleanly between moving to a different job and changing the content of the current job. D3 must permit both without inventing either in an individual case.

### 3.6 D3 sharpening: feedback is target-specific

Reverse paths from distress, anxiety, trustfulness and some values are weak/null. D3 should be a lawful possibility mechanism, not a universal rule that any person-state change generates structural mobility.

Required:

`ELIGIBLE_FEEDBACK_PATH + REALIZED_ACTION + EXTERNAL_GATE`, not `PERSON_CHANGED => WORLD_CHANGED`.

## 4. Does M6 require D4?

Potential candidates considered:

### 4.1 `EXERCISED_CONTROL_HISTORY`

At first glance the separation between formal autonomy and actual exercised judgment might warrant a fourth capability. It does not. D1 already owns type-specific realization from formal authority/control to actor-specific enacted condition, and D2 owns the recurrent activity history.

Composition:

```text
D1: STRUCTURAL CONTROL -> ACTOR-SPECIFIC DISCRETION/TASK CONDITION
D2: CONDITION -> RECURRENT EXERCISED JUDGMENT HISTORY
V3: HISTORY -> DEVELOPMENT IF EARNED
```

No independent connective owner is required.

### 4.2 `LEARNING_GENERALIZATION`

The source argues that work experience generalizes to nonwork activity. But this is downstream of realized activity and belongs to existing V3 learning/practice/change mechanisms. Creating a seam-level `GENERALIZATION` owner would duplicate psychology.

No D4.

### 4.3 `OCCUPATIONAL SELF-DIRECTION`

OSD is a measurement/theoretical summary, not a new architectural operator. D1 + D2 can represent its first-order causes and enacted history.

No D4.

### 4.4 `JOB_SELECTION`

Selection requires action plus gate plus world update, already D3. The work domain gives D3 a concrete specialization but not a fourth generic capability.

No D4.

### 4.5 `CUMULATIVE_AMPLIFICATION`

The proposed loop is composition of repeated D1/D2/D3 cycles. The source observes only a limited longitudinal span and does not justify a generic cumulative scalar.

No D4.

## 6. Apparent class -> person claims after decomposition

The source's mature model makes the direct shortcut progressively less necessary:

```text
CLASS / STRATIFICATION
-> DIFFERENTIAL OCCUPATIONAL POSITION
-> DIFFERENTIAL COMPLEXITY / SUPERVISION / ROUTINIZATION /
   RISK / PROTECTION / PRESSURE / INCOME
-> DIFFERENTIAL REALIZED WORK ACTIVITY / CONDITION HISTORY
-> PSYCHOLOGICAL CHANGE
```

Much of the relationship between class/stratification and values, ideational flexibility and self-directed orientation is substantially attributable to occupational self-direction. Some education/income effects remain; mediation is substantial rather than total.

Therefore the correct architectural lesson is not “class has no effect.” It is:

`CLASS EFFECT MUST BE DECOMPOSED THROUGH PROVENANCE-BEARING SOCIAL CONDITIONS BEFORE DEVELOPMENTAL USE`.

```text
D1 = PASS_WITH_SHARPENING
D2 = PASS_WITH_SHARPENING
D3 = PASS_WITH_SHARPENING
D4 = NOT_REQUIRED_BY_M6
```

Smallest M6 consequence:

1. make `OCCUPATION_TITLE != WORK_CONTENT` binding at the seam;
2. require first-order typed work-condition outputs, not a latent OSD black box;
3. ensure D2 carries recurrent activity **quality** and duration, not merely occurrence count;
4. specialize D3 with an explicit organizational/labor-market gate before any person-driven work/position update;
5. preserve existing V3 ownership of psychological uptake, learning and durable change.

M6 does not overturn the frozen synthesis. It materially strengthens the empirical/theoretical case for its three-delta topology while narrowing how those deltas may be implemented.
