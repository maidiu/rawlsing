# M9 — LURIA MECHANISM CARDS R1

STATUS: `MECHANISMS_DECOMPOSED__NO_BUNDLED_CULTURE_CAUSE_ADMITTED`

These are **candidate pathways supported to different degrees by Luria's observations**. None is licensed as an isolated causal effect by this study alone.

Evidence labels:

- `OBSERVED_ASSOCIATION`: directly visible in the study;
- `PLAUSIBLE_MEDIATION`: mechanism consistent with process evidence but not isolated;
- `AUTHOR_INTERPRETATION`: asserted by Luria beyond identification;
- `NOT_IDENTIFIED`: cannot be causally separated in this design.

## MC-01 — FORMAL INSTRUCTION -> TASK-CONVENTION FLUENCY

```text
recurrent school instruction
-> practice treating verbal directions / categories / stipulated premises as task-authoritative
-> easier categorical grouping, hypothetical inference, word-problem solution
```

SUPPORT: schooling-exposed groups very consistently use the requested taxonomic/hypothetical conventions; unschooled participants often shift after explanation or conditional reframing.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: schooling is bundled with age, literacy, selection, institutional contact, and often collective-farm role. Do not infer schooling's independent effect or a new global cognitive faculty.

RAWLSING RELEVANCE: D1 `ACTIVITY_ORGANIZATION` / `INFORMATION_CHANNEL_OPPORTUNITY`; downstream performance remains task-context-bound V3/behavioral evidence.

## MC-02 — LITERACY PRACTICE -> SYMBOLIC / METALINGUISTIC ROUTINE

```text
reading-writing practice
-> recurrent segmentation / symbol encoding / decontextualized language operations
-> easier use of explicit verbal categories and relations
```

SUPPORT: Luria explicitly proposes this route and literacy-program groups occupy intermediate positions in several tasks.

GRADE: `AUTHOR_INTERPRETATION + PLAUSIBLE_MEDIATION`.

CEILING: literacy is not independently manipulated and often co-occurs with schooling, course participation, new information sources, and collective work.

## MC-03 — COLLECTIVE PLANNING / ACCOUNTING -> DECONTEXTUALIZED COORDINATION PRACTICE

```text
planning production
+ distributing labor
+ accounting for output
+ comparing plans/results
-> recurrent explicit representation of absent/future states and rule-governed coordination
-> greater fluency with planning/comparison discourse
```

SUPPORT: collective-farm leaders are described as repeatedly performing these activities; their task responses are often more compatible with experimental categorical/hypothetical demands.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: leadership is selected, not assigned; education and network breadth covary. Do not translate `KOLKHOZ_MEMBER` directly into a mental disposition.

## MC-04 — COLLECTIVE DISCUSSION / SOCIAL EVALUATION -> SELF-DESCRIPTION VOCABULARY

```text
recurrent meetings / mutual evaluation / work criticism
-> exposure to explicit evaluations of self/others against shared norms
-> richer lexicalization of personal qualities in interview
```

SUPPORT: Chapter 7's strongest mechanism-specific process evidence. Participants embedded in collective evaluation often cite others' judgments and behavioral norms.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: the outcome is interview self-description. "formation of a new inner world" is an author causal interpretation not identified from these data.

## MC-05 — WIDENED COMMUNICATION ECOLOGY -> REMOTE / VERBAL INFORMATION USE

```text
broader counterpart network
+ institutional meetings / courses / external contacts
-> more frequent receipt and exchange of information not grounded in immediate personal observation
-> greater willingness/familiarity using verbally supplied premises
```

SUPPORT: Luria repeatedly contrasts isolated practical experience with systematic instruction and "more complex forms of communication"; farm officials had broader interpersonal contact.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: no communication-frequency measure, network reconstruction, or independent intervention. Treat "communication" as a concrete channel/history requirement, never a group label.

## MC-06 — PRACTICAL EXPERTISE -> DOMAIN-SPECIFIC PERCEPTUAL / SEMANTIC ORGANIZATION

```text
recurrent skilled practical activity
-> fine-grained functional/object distinctions and task-relevant categories
-> object-linked naming and situational grouping
```

SUPPORT: ichkari women use a rich, differentiated object/embroidery vocabulary for colors and forms; farmers reason effectively about familiar agricultural/practical relations.

GRADE: `DIRECTLY_OBSERVED_PATTERN + PLAUSIBLE_MEDIATION`.

SIGNIFICANCE: this is a direct antidote to a deficit model. Non-school categories can encode expertise rather than cognitive absence.

## MC-07 — EPISTEMIC-WARRANT NORM -> SYLLOGISM ACCEPTANCE / REFUSAL

```text
problem premise outside direct knowledge
+ norm against asserting what one has not witnessed / verified
-> refusal to endorse conclusion

conditional reframing ("from my words")
-> acceptance of temporary premise
-> formal inference may appear
```

SUPPORT: repeated Chapter 4 protocols.

GRADE: `DIRECTLY_OBSERVED_WITHIN_SESSION_PROCESS`.

CEILING: do not classify refusal as logical incapacity. This mechanism may concern discourse/epistemic norms rather than stable reasoning competence.

## MC-08 — TASK-FRAME ACCEPTANCE -> CONFLICT-PROBLEM PERFORMANCE

```text
real-world knowledge conflicts with verbal stipulation
-> participant treats problem as false / malformed
-> no requested calculation

explicit hypothetical / operation framing
-> some participants compute successfully
```

SUPPORT: Chapter 5; simple arithmetic competence often coexists with conflict-problem rejection.

GRADE: `DIRECTLY_OBSERVED_WITHIN_SESSION_PROCESS`.

CEILING: local assisted performance is not durable learning or general cognitive development.

## MC-09 — GUIDED ASSISTANCE -> IMMEDIATE TASK REORIENTATION

```text
experimenter explanation / example / counterargument / imaginary scenario
-> changed interpretation of demand
-> changed current-task response in some cases
```

SUPPORT: explicit learning-task design; color grouping, classification, syllogisms, word problems, and question formulation all include examples where prompting changes performance.

GRADE: `DIRECTLY_OBSERVED_LOCAL_RESPONSE_CHANGE`.

CEILING: because prompting is not standardized and transfer is not systematically quantified across all domains, the study cannot identify a general zone-of-proximal-development parameter or durable acquisition.

## MC-10 — INFORMATION ACCESS -> QUESTION CONTENT / REMOTE-KNOWLEDGE ORIENTATION

```text
literacy / courses / meetings / institutional contact / newspapers or newly supplied information
-> access to nonlocal topics and new knowledge gaps
-> questions about agriculture, industry, America, schooling, social institutions
```

SUPPORT: Chapter 6 protocols and group distributions.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: question content reflects both access and experimental demand; no isolated information-channel treatment.

## MC-11 — GEOMETRY/SCHOOL CATEGORY PRACTICE -> FIGURE NAMING / GROUPING

```text
formal geometric labels and classification practice
-> category-first naming of circles/triangles/quadrangles
-> grouping across surface variants
```

SUPPORT: large gradients in categorical shape naming and grouping.

GRADE: `PLAUSIBLE_MEDIATION`.

CEILING: does not prove a global change in visual perception. The safer target is category deployment in a naming/classification task.

## MC-12 — HISTORICAL / INSTITUTIONAL TRANSITION -> ACTIVITY-ECOLOGY REBINDING

```text
new school / course / farm-office / meeting / administrative role
-> actor acquires new recurrent activity, counterpart, schedule, information, and obligation bindings
-> new task histories become possible
```

SUPPORT: the historical descriptions make these rebinding processes plausible and often concrete at group level.

GRADE: `PLAUSIBLE_SOCIAL-ECOLOGY_REBINDING`; individual temporal sequence is generally not measured.

D2 SIGNIFICANCE: supports the **need to represent persistent/recurrent activity and role ecology if such facts are independently established**, but does not validate a general developmental effect or provide within-person transition estimates.

## MC-13 — POPULATION / CIVILIZATION LABEL -> PSYCHOLOGY

```text
"backward" / "traditional" / "primitive" / "socialist"
-> cognitive structure
```

GRADE: `REJECT`.

REASON: these are bundled historical labels, sometimes carrying explicit evolutionary hierarchy. They do no causal work at actor level.

## MC-14 — RELIGION LABEL -> COGNITIVE INDEPENDENCE

```text
Islamic identity/influence -> lack of independent thought
```

GRADE: `REJECT`.

REASON: Luria's political/historical claim is not tested as an independent contrast. Any usable pathway must be decomposed into actor-relative institutional authority, mobility constraints, schooling access, obligations, information channels, or sanctions with evidence.

## MC-15 — COLLECTIVIZATION / SOCIALISM -> GLOBAL COGNITIVE RESTRUCTURING

GRADE: `REJECT_AS_CAUSALLY_UNIDENTIFIED`.

The book cannot distinguish collectivization itself from schooling, literacy, occupational selection, administrative work, network broadening, generational change, state contact, technical knowledge, interviewer familiarity, or task-practice effects.

## Cross-card synthesis

Luria is strongest for a Rawlsing architecture when read as:

```text
SPECIFIC RECURRENT ACTIVITY / INSTRUCTION / COMMUNICATION / ROLE HISTORY
-> SPECIFIC TASK-RELEVANT EXPERIENCE AND INFORMATION ECOLOGY
-> OBSERVED PERFORMANCE UNDER A SPECIFIED TASK CONTEXT
```

He is weakest when read as:

```text
GROUP / CIVILIZATION / MODE-OF-PRODUCTION LABEL
-> TOTAL PSYCHOLOGICAL TYPE
```
