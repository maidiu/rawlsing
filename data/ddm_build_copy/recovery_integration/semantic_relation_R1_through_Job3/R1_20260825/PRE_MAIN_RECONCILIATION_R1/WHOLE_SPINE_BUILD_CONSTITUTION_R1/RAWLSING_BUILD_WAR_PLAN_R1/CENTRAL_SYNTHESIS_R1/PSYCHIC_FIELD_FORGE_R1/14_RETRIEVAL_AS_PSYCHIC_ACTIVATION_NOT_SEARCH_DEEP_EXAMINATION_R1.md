## 0. Purpose

This file deeply examines PFF frontier pocket 16, `retrieval as psychic activation, not search`.

The core problem is that a generated person contains vastly more durable history, memory, motive, relation, expectation, self-model structure, and developmental organization than can be placed into one prompt or made consciously available at every turn.

Yet psychologically relevant material often becomes live for reasons that are not captured by ordinary semantic similarity.

The central questions are:

1. How can V3-owned durable material become causally relevant to a live PFF interaction without PFF duplicating V3 memory ownership?
2. How can material influence current psyche without becoming actor recall or conscious recollection?
3. What kinds of relevance exist beyond topic/word similarity?
4. How can Rawlsing preserve non-obvious associative and relational resonance without allowing a model to invent causal history?
5. What must remain outside the final renderer even when it shaped retrieval/recruitment?

Current conclusions:

`SEMANTIC_SEARCH != MEMORY_RECALL`

`MEMORY_RECALL != MEMORY_ACCESSIBILITY`

`MEMORY_ACCESSIBILITY != PSYCHIC_RECRUITMENT`

`PSYCHIC_RECRUITMENT != CONSCIOUS_RECOLLECTION`

`MACHINE_LOCATED_CAUSAL_SOURCE != ACTOR_REMEMBERS_SOURCE`

`PSYCHIC_RELEVANCE != NEAREST_SEMANTIC_SIMILARITY`

`MULTI_ROUTE_PERSON_SPECIFIC_RELEVANCE = MUST_FACTOR`

`HISTORY_CAN_SHAPE_CURRENT_RECRUITMENT_WITHOUT EXPLICIT_MEMORY_RETRIEVAL = MUST_FACTOR`

`WHOLE_PERSON_OUTSIDE_PROMPT / PROMPT_AS_BOUNDED_CACHE = MUST_FACTOR`

`NEW_UNIVERSAL_DEEP_RETRIEVAL_ENGINE = NOT ADMITTED`

## 1. Governing V3 memory/accessibility boundary

ADP-016 already owns V3 causal memory formation, forgetting, retention/degradation, recall/reactivation, and current memory-accessibility transitions.

Its non-collapse includes:

`OBJECTIVE_GENERATED_EVENT_HISTORY != GENERATED_MEMORY_STATE`

`GENERATED_MEMORY_STATE != CURRENT_MEMORY_ACCESSIBILITY`

`CURRENT_MEMORY_ACCESSIBILITY != ACTOR_KNOWLEDGE_OR_CLAIM_PERMISSION`.

ADP-017 then separates current memory accessibility from actor epistemic stance and first-person claim permission.

Historical/current V2 law additionally rejects transcript/session persistence, keyword hooks, rendered wording, persona/backstory prose, and analyst explanation as authority to create V3 memory or actor knowledge.

Therefore PFF retrieval cannot mean:

> Find a plausible past item and inject it into the actor's mind.

Nor can it mean:

> Anything semantically retrieved is now remembered.

Hard law:

`PFF_RELEVANCE_DISCOVERY -/-> V3_MEMORY_ACCESSIBILITY_WRITE`.

## 2. First major distinction: locating relevant durable material versus changing actor access

The machine may need to locate durable V3 structures that are causally relevant to the present interaction.

That is different from making them consciously accessible to the actor.

Example:

V3 contains a generated relationship history in which A repeatedly experienced ridicule when showing enthusiasm.

Current B lightly teases A's enthusiasm.

The historical organization may become causally relevant because the current interaction matches a learned relational structure.

Possible consequences:

- vigilance rises;
- shame/defense is recruited;
- enthusiasm becomes inhibited;
- A interprets the tease as more threatening than a neutral observer would;
- explicit old memories may or may not become accessible.

The machine can therefore use the old history as **causal provenance for current recruitment** without asserting:

`A consciously remembers event E`.

This yields a core distinction:

`CAUSAL_SOURCE_LOOKUP / BINDING`
`!= ACTOR_RECALL`
`!= ACTOR_CONSCIOUS_MEMORY`.

## 3. The “asshole story” phenomenon generalized

Originating example:

An interlocutor resembles, in a psychologically meaningful way, someone from the actor's past. The actor unexpectedly tells a story about an “asshole” from years earlier without consciously recognizing that the current person activated the association.

A shallow system might implement:

`current words -> embedding similarity -> retrieve old story -> insert into prompt`.

That is insufficient because the relevant relation may not be lexical or topical.

A more faithful conceptual chain is:

1. B's current behavior carries several observable interaction features.
2. A's receiver-specific reading interprets some of those features through current relationship context.
3. Those features resonate with durable V3 organization/history around another person or motif.
4. That durable material becomes recruited or increases readiness/accessibility through lawful V3/PFF interaction.
5. The associated story becomes comparatively available/salient for expression.
6. A may consciously know the story itself while remaining unaware of **why it came to mind now**.
7. A tells the story.
8. Hearing themself tell it may become new evidence for self-output feedback.

Thus several levels can coexist:

`ACTOR_REMEMBERS_STORY = YES`

`ACTOR_KNOWS_CURRENT_TRIGGER_OF_STORY = NO`

`MACHINE_CAUSAL_ACCOUNT_OF_CURRENT_RELEVANCE = YES`.

This is a core PFF success case.

## 4. Relevance has multiple routes

No single relevance function should be assumed.

At least the following routes must remain conceptually possible.

### 4.1 Topic-semantic relevance

Current discourse explicitly concerns the same person, place, event, object, or concept.

This is the easiest case and is not sufficient by itself.

### 4.2 Entity/interlocutor identity relevance

Material is relevant because the current person is the same relationship object or directly linked to it.

### 4.3 Relationship-history relevance

Past episodes with the same counterpart alter current expectation/recruitment even when the present topic is unrelated.

### 4.4 Relational-structural resemblance

A current interaction resembles the **pattern** of an older interaction:

- teasing while vulnerable;
- authority withholding approval;
- someone becoming silent after conflict;
- intense early idealization;
- reassurance followed by withdrawal;
- public correction;
- being needed by a dependent person.

No shared words are required.

### 4.5 Motive/need relevance

Current input bears on an active or durable striving/need:

- attachment;
- autonomy;
- status;
- competence;
- safety;
- intimacy/eros;
- justice;
- belonging;
- meaning;
- etc., as already represented/owned upstream.

### 4.6 Expectation violation/confirmation relevance

Something becomes important because it confirms, contradicts, or destabilizes what the actor expected.

### 4.7 Threat relevance

A cue matters because it threatens safety, attachment, status, self-model, secrecy, bodily integrity, future plan, or another actor-specific concern.

### 4.8 Affordance/reward relevance

A cue matters because it opens a desired possibility:

- intimacy;
- recognition;
- escape;
- advancement;
- reconciliation;
- play;
- competence demonstration;
- revenge;
- belonging.

### 4.9 Shame/exposure relevance

The cue touches content the actor feels must not be seen or known.

### 4.10 Attraction/charge relevance

The current person/interaction becomes disproportionately attention-worthy because of attraction, fascination, status charge, novelty, or other actor-specific motivational recruitment.

### 4.11 Self-model contradiction relevance

Material becomes live because it threatens or supports who the actor thinks they are.

### 4.12 Unresolved motif relevance

A past theme remains unfinished or repeatedly reappears across different life contexts.

### 4.13 Defensive relevance

Material becomes relevant because a defense needs to suppress, reinterpret, displace, or compensate for it.

### 4.14 Prospective relevance

Material matters because of what the actor expects could happen next, not because of current similarity.

### 4.15 Body/organismic-state relevance

Current bodily/organismic condition may change which memories, threats, motives, or responses become recruitable, subject to exact upstream ownership.

### 4.16 Current-live-state relevance

What is already active in PFF changes what becomes relevant next.

A cue that would ordinarily be trivial may become powerful after recent shame, attraction, conflict, fatigue, or metaperceived exposure.

These are routes of potential relevance, not a required taxonomy or fixed retrieval channels.

## 5. Psychic relevance can be indirect and compositional

The current cue may not itself match a durable item strongly.

Example:

`B praises A's independence`.

For one actor this is pleasant.

For another actor, the compliment recruits:

`independence self-image`
+
`hidden dependency need`
+
`current attraction to B`
+
`fear B would reject neediness`.

The old memory that becomes relevant may concern a caregiver mocking dependence, even though no present words resemble that memory.

The relevance emerges through the **current configuration**, not direct item-to-item similarity.

Therefore:

`CURRENT_CUE -> LIVE_CONFIGURATION -> DEEP_RELEVANCE`

may be as important as:

`CURRENT_CUE -> MEMORY_SIMILARITY`.

## 6. Recruitment can occur without explicit content retrieval

PFF must preserve at least three cases.

### 6.1 Explicit recall

A consciously remembers event E.

V3 accessibility/actor-access authority governs this.

### 6.2 Implicit structural recruitment

Event/history-derived organization changes current perception/response, but no explicit memory content enters consciousness.

### 6.3 Partial/fragmentary access

A feeling, image, phrase, person, or fragment becomes accessible without complete event reconstruction or causal understanding.

These must not be collapsed.

`HISTORY_EFFECT != AUTOBIOGRAPHICAL_RECALL`.

## 7. PFF must not create a shadow duplicate memory store

A tempting architecture would copy selected V3 memories into a PFF “deep memory” database with new scores for emotional charge/relevance.

That risks:

- duplicating canonical identity/provenance;
- divergence between V3 and PFF copies;
- accidental independent accessibility semantics;
- hidden reclassification of memory;
- arbitrary decay/boosting;
- turning PFF into a second causal-memory owner.

Current strong hypothesis:

> PFF should preferentially **reference and recruit from V3-owned durable structures**, adding only live, scoped relations/effects that are genuinely PFF-specific.

`PFF_REFERENCE_TO_V3_MATERIAL > PFF_COPY_OF_V3_MATERIAL` as a current design preference, not architecture adoption.

## 8. Memory relevance and memory accessibility must be independently representable

A memory can be:

- highly causally relevant but inaccessible;
- accessible but irrelevant to the present interaction;
- accessible and relevant but not salient;
- salient but intentionally not expressed;
- consciously recalled for the wrong reason;
- retrieved by the machine for causal analysis but not actor-accessible.

Therefore:

`RELEVANT != ACCESSIBLE`

`ACCESSIBLE != SALIENT`

`SALIENT != EXPRESSED`

`MACHINE_RETRIEVED != ACTOR_RECALLED`.

## 9. Machine-side causal retrieval must carry an epistemic/visibility ceiling

If machine analysis locates a hidden causal source, that source must remain tagged conceptually as machine-side unless exact actor-access authority permits more.

The expression-firewall examination requires:

`AUDIT_CAUSAL_PROVENANCE != RENDERER_SEMANTIC_CONTEXT`.

This applies equally to retrieval.

Example:

Machine-side finding:

`current B behavior structurally resonates with V3 relation episode E`.

Possible PFF effect:

- increased threat recruitment;
- increased defensive readiness;
- changed attention;
- changed memory-accessibility request/candidate pathway where V3 law permits.

Forbidden direct result:

- insert event E into final renderer prompt as something A “remembers” unless independently accessible.

## 10. Multiple candidate sources may coexist

A present state may have several plausible historical contributors.

Example:

A becomes guarded when B challenges competence.

Potential contributors:

- earlier parental criticism;
- workplace humiliation;
- current self-model instability;
- relationship history with B;
- general status striving;
- recent failure earlier that day.

PFF must not force a single explanatory winner merely for narrative neatness.

`MULTIPLE_CAUSAL_RELEVANCE_CANDIDATES MAY COEXIST`.

`CAUSAL_UNCERTAINTY != ERROR`.

Where exact causation is not established, machine-side hypotheses must remain hypotheses.

## 11. Retrieval itself can alter live state and must therefore be governed

Finding/reinstating material is not necessarily psychologically neutral.

If a memory becomes actor-accessible, that access can:

- change affect;
- recruit new motives;
- alter self-model;
- change metaperception;
- create new conflict;
- change disclosure willingness;
- affect expression.

Therefore retrieval cannot be treated as a passive convenience layer if it changes actor experience.

V3 ADP-016 already owns memory accessibility transitions; PFF must consume those results rather than silently performing the transition itself.

Hard law:

`PFF_CAN_REQUEST / USE LAWFUL ACCESS`

but

`PFF_CANNOT SELF-AUTHORIZE MEMORY_ACCESSIBILITY`.

Exact request/response mechanics are architecture questions, not adopted here.

## 12. Relevance can affect non-memory durable structures too

The “retrieval” label is misleading if it implies only memory documents.

Current interaction may recruit references to:

- needs;
- strivings;
- expectations;
- mediators;
- tensions;
- practices;
- self-model structures;
- relationship-specific expectations;
- attractor organization;
- current durable condition;
- causal memory traces;
- explicit episodic/declarative memories.

Thus a broader term such as `deep relevance / recruitment` may ultimately be more accurate than `retrieval`.

No terminology is frozen here.

## 13. Whole-person-outside-prompt law

PFF cannot depend on placing the generated person's entire history/psychology into the context window.

The prompt must be treated as a **bounded working cache**, not the identity database or canonical psyche.

Therefore:

`PROMPT_CONTENT != PERSON`.

`NOT_IN_PROMPT != NOT_IN_PERSON`.

`MODEL_CONTEXT_WINDOW != MEMORY_ACCESSIBILITY`.

A person-specific relevance process must be capable of selecting/binding only what is currently required while preserving canonical truth outside the prompt.

## 14. Prompt caching must not become hidden actor consciousness

Material may need to be available to machine components for computation while remaining unavailable to the actor/renderer.

Therefore future architecture must distinguish at least conceptually:

- machine working context;
- PFF causal context;
- actor-conscious context;
- renderer-visible context.

A memory or motive present in machine working context is not automatically actor-conscious.

## 15. Relationship analogy requires structural caution

“B reminds A of C” is psychologically plausible but dangerous if generated by unconstrained LLM analogy.

A lawful analogy should require evidence of a recognized relationship/interaction structure rather than narrative plausibility alone.

Potential dimensions of structural resemblance might include, without freezing them:

- power relation;
- approval dependency;
- intimacy trajectory;
- pursuit/withdraw pattern;
- teasing/humiliation relation;
- caretaking/dependency relation;
- unpredictability;
- moral judgment;
- competition;
- abandonment/reassurance pattern;
- public versus private exposure;
- authority/obedience;
- idealization/disappointment.

The architecture must later determine which structures are actually machine-defined and how uncertainty is represented.

Hard negative:

`LLM_SAYS_THESE_RELATIONSHIPS_FEEL_SIMILAR -> CAUSAL_RECRUITMENT` is insufficient.

## 16. Associative chains can be multi-step

Human-like relevance may proceed through chains:

`B says X`
-> `A thinks of person C`
-> `person C evokes event E`
-> `event E activates shame`
-> `shame increases relevance of self-model issue S`.

But unconstrained chaining can explode combinatorially or become narrative invention.

Current pre-architecture requirement:

- multi-step relevance must be possible;
- each step should have typed/provenanced justification;
- chain depth should be relevance-bounded;
- uncertainty should accumulate/persist rather than disappearing;
- no chain may create new historical facts.

No graph-search architecture is adopted.

## 17. Negative relevance / active avoidance is real

Something can be highly relevant precisely because the actor is trying not to access or discuss it.

Examples:

- avoiding mention of a former partner;
- refusing to think about humiliation;
- changing subject around grief;
- suppressing attraction;
- avoiding a memory because current company makes exposure risky.

Therefore:

`AVOIDED != IRRELEVANT`.

`LOW_EXPRESSION != LOW_PSYCHIC_RELEVANCE`.

Defense can increase causal relevance while decreasing conscious/surface availability.

## 18. Relevance can be generated by contradiction

A current cue may matter because it does **not** fit expected history.

Examples:

- a usually critical parent praises A;
- a guarded partner suddenly discloses;
- a rival offers help;
- a trusted person lies;
- a feared authority behaves warmly.

These expectation violations may recruit more processing than familiar similarity.

Thus a pure similarity search misses psychologically central novelty.

## 19. Relevance can be generated by absence and silence

No positive token match is required.

Examples:

- B fails to answer a normally answered message;
- expected reassurance does not arrive;
- a name conspicuously goes unmentioned;
- an apology omits responsibility;
- a partner does not react to disclosure.

The absence itself can recruit durable expectations/history.

`NO_OBSERVED_SIGNAL != NO_PSYCHIC_EVENT`.

This links retrieval to anticipation and dyadic chemistry.

## 20. Relevance can be actor-condition dependent

The same cue can retrieve/recruit different material at different durable or local operating conditions.

A flexible/open condition may permit contradictory memories and corrective examples.

A captured/defensive condition may preferentially recruit confirmatory threat history.

The Enneagram Levels material is useful as source logic for this possibility:

`SAME_CUE + DIFFERENT_OPERATING_CONDITION -> DIFFERENT_RELEVANCE_LANDSCAPE`.

No “health retrieval multiplier” is adopted.

## 21. Relevance and salience are not the same jurisdiction

PFF may determine that a durable structure is causally participating in current live psyche.

CAN-016 separately owns V2 expression salience among actor-safe candidates.

Therefore:

`PFF_CAUSAL_RELEVANCE != V2_EXPRESSION_SALIENCE`.

A hidden cause can be highly causally relevant while forbidden from becoming an expression candidate at all.

Likewise an actor-accessible topic may be salient for expression without being a deep causal driver.

## 22. Relevance can be plural across modalities of personhood

At one turn, PFF may need:

- one relationship-history component;
- one current striving;
- one memory fragment;
- one self-model tension;
- one current body-state constraint;
- one recent session residue.

This argues against a monolithic “top-k memories” retrieval model.

The necessary context is heterogeneous and jurisdiction-bound.

## 23. Retrieval should be purpose-bound

A component should not receive deep material merely because it might be interesting.

Potential purposes include:

- explain/compute current recruitment;
- update present conscious field through lawful access;
- assess relation-specific relevance;
- form bounded expression effects;
- evaluate defense/conflict;
- support replay/audit.

Different purposes may require different visibility/authority ceilings.

Hard principle:

`RETRIEVAL_PERMISSION = PURPOSE / OWNER / VISIBILITY BOUNDED`.

Exact policy is architecture work.

## 24. Retrieval results must preserve absence and uncertainty

The system may legitimately find:

- no relevant durable source;
- several weak candidates;
- one source with uncertain relation;
- relevant history but inaccessible memory;
- relevant motive with no associated episodic memory;
- insufficient authority to inspect a class of data.

It must not invent a psychologically satisfying answer to fill the gap.

`NO_CAUSAL_SOURCE_FOUND != SOURCE_MUST_EXIST`.

`MISSING_AUTHORITY != ACTOR_FORGOT`.

## 25. The renderer should not receive the retrieval trace

The expression-firewall law applies directly.

The final renderer may receive:

- actual discourse;
- actor-lawful explicit memory/content where permitted;
- bounded surface effects/constraints derived from hidden causal material.

It must not receive unrestricted machine-side retrieval rationale such as:

`this person reminds you of your humiliating father, though you do not know it`.

That would collapse hidden causation into renderer omniscience.

## 26. Self-output can become a retrieval cue

Once A says something, their own output can:

- make a memory more accessible;
- reveal a recurring motif to them;
- create metaperception (`B now knows X`);
- cause self-surprise;
- recruit a previous similar utterance/event;
- change what becomes relevant next.

This is a major seam into the next self-output-feedback examination.

## 27. No universal retrieval ontology yet

This examination does not adopt:

- one embedding model;
- one graph;
- one vector store;
- one relevance score;
- one top-k policy;
- one associative distance;
- one fixed list of channels;
- one global emotional-charge field;
- one retrieval threshold;
- one prompt-packing algorithm.

Those are architecture choices to be derived from the semantic obligations.

## 28. No-gadget semantic remainder test

Before architecture introduces a dedicated `PsychicRetrievalEngine` or shadow deep-memory store, attempt to preserve the required behavior through:

1. V3 canonical person/memory/relationship structures;
2. V3-owned current accessibility;
3. exact references to durable needs/expectations/strivings/mediators/tensions;
4. PFF live recruitment relations;
5. current dyad/situation/interlocutor identity;
6. recent PFF residue/path dependence;
7. machine-side relevance analysis with strict actor/renderer visibility ceilings;
8. existing V2 salience only after actor-safe candidate formation.

Only a surviving semantic remainder may justify new storage or subsystem ownership.

## 29. Hard negatives

Reject unless independently justified:

- nearest-neighbor embedding similarity treated as psychic relevance;
- top-k memory chunks treated as the current person;
- retrieved machine material treated as actor recall;
- keyword hit treated as V3 memory accessibility;
- transcript hit treated as wound/motive truth;
- LLM free-association treated as causal history;
- copying V3 memories into an independently mutating PFF store;
- one universal emotional charge score on every memory;
- inaccessible memory injected into renderer prompt;
- no-result retrieval filled with plausible invented backstory;
- session transcript used as canonical memory;
- all relevant history forced into consciousness;
- all causal recruitment forced to point to an explicit episodic memory;
- semantic similarity required for relational resonance;
- relationship analogy inferred solely from type labels;
- prompt-context inclusion treated as actor awareness;
- prompt absence treated as person-level absence.

Any successful PFF architecture must eventually preserve:

1. canonical V3 ownership of durable memory/history;
2. machine causal-source location distinct from actor recall;
3. psychic recruitment distinct from memory accessibility;
4. explicit recall, implicit structural recruitment, and fragmentary access as distinct cases;
5. multiple person-specific relevance routes;
6. relational-structural resemblance beyond lexical similarity;
7. expectation violation and absence as relevance generators;
8. target/domain/current-condition dependence;
9. multiple uncertain causal-source candidates;
10. heterogeneous durable inputs, not only episodic memory;
11. negative relevance/avoidance;
12. purpose- and visibility-bounded retrieval;
