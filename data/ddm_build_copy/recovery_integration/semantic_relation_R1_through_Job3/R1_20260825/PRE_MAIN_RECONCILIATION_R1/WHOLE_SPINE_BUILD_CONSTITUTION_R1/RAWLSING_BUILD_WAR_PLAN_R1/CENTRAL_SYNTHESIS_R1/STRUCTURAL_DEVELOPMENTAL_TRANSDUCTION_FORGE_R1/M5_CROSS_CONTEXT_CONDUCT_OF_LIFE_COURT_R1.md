# M5_CROSS_CONTEXT_CONDUCT_OF_LIFE_COURT_R1

STATUS: `COURT_COMPLETE`

SOURCE BASIS: Dreier, *Psychotherapy in Everyday Life*, especially Ch. 5 pp. 84–108, Ch. 8 pp. 181–197, Chs. 9–11 pp. 198–286.

## 1. Central question

Does Dreier require a general cross-context conduct mechanism?

**THEORY VERDICT:** `YES`.

**ARCHITECTURE VERDICT:** `GENERAL FUNCTION REQUIRED__NEW D4 NOT PROVED`.

Dreier’s theory cannot be faithfully represented by treating each context as an independent stream of events. A person actively conducts one life through several differentiated practices. However, the cross-context coordinating function is an **actor-side practical achievement**, not another upstream structural ecology generator.

The smallest faithful Rawlsing composition is:

```text
D1: MULTIPLE TYPED ACTOR-RELATIVE CONTEXT/POSITION ECOLOGIES
        +
D2: OVERLAPPING INTERVAL / RECURRENCE / TRANSITION BINDINGS
        +
V3: CONCERNS / STANCES / PLANNING / PRACTICE / ACTION / LEARNING
        ↓
PERSONAL CONDUCT ACROSS CONTEXTS
        ↓
REALIZED EXTERNAL ACTIONS
        ↓
D3 WHEN EXTERNAL ARRANGEMENTS ACTUALLY CHANGE
```

## 2. What conduct of everyday life is

Dreier’s `conduct of everyday life` is the person’s practical composition of participation across multiple contexts. It includes:

```text
LINKING
SEPARATING
BALANCING
SEQUENCING
SCHEDULING
ROUTINIZING
PRIORITIZING
DEFERING
MAINTAINING
IMPROVISING
PURSUING CONCERNS ACROSS PLACES
COORDINATING WITH OTHER PERSONS' SCHEDULES/OBLIGATIONS
```

It is not a sovereign plan. Persons conduct lives under arrangements, dependencies and schedules they only partly control.

It is also not a latent personality factor. What appears as consistency can partly be produced by a stable conducted arrangement of life.

## 3. Multi-context person special court

### Required case

```text
ONE PERSON
SIMULTANEOUSLY OCCUPIES MULTIPLE SOCIAL PRACTICES
WITH COMPETING OBLIGATIONS, TIMES, RESOURCES AND RELATIONS
```

Dreier makes this the normal condition of modern everyday life rather than an edge case.

Examples across the book include:

- child + family member + student + friend + therapy participant + rider/worker;
- parent + worker + spouse + caregiver + therapy participant + friend;
- family member schedules coordinated with school, work, transport, shopping and treatment institutions.

### Court result

A Rawlsing model that stores only one current `context`, one actor-global position, or one current obligation bundle would be insufficient.

What is required is:

```text
ACTOR A
  ├─ binding C1 × P1 × interval/recurrent schedule × relations
  ├─ binding C2 × P2 × interval/recurrent schedule × relations
  ├─ binding C3 × P3 × interval/recurrent schedule × relations
  └─ typed cross-context dependency/propagation edges
```

This is an implementation/composition invariant on D1+D2, not proof of D4.

## 4. Competing demands mechanism

Dreier gives a concrete alternative to generic “role conflict.”

```text
CONTEXT A OBLIGATION/TIME CLAIM
+ CONTEXT B OBLIGATION/TIME CLAIM
+ LIMITED ACTOR TIME/MOBILITY/RESOURCE
-> PRACTICAL COORDINATION PROBLEM
-> ACTOR PRIORITIZES / NEGOTIATES / DELAYS / REFUSES / RESCHEDULES / SEEKS HELP
-> REALIZED PARTICIPATION PATTERN
```

The conflict must be expressed in terms of the actual resources, schedules, obligations and counterpart relations. A role label alone is insufficient.

## 5. Cross-context effect court

Dreier does not license `SPILLOVER` as a causal primitive.

Every cross-context effect must be normalized through an explicit carrier. Examples:

### Time/schedule

```text
WORK SCHEDULE CHANGE IN A
-> AVAILABLE TIME / FATIGUE / PRESENCE WINDOW CHANGES
-> CARE / FAMILY / THERAPY PARTICIPATION POSSIBILITY IN B CHANGES
```

### Resource

```text
JOB/INCOME CHANGE IN A
-> RESOURCE / TRANSPORT / EXIT OPTION CHANGE
-> ACTIVITY OR DEPENDENCY POSSIBILITY IN B CHANGES
```

### Obligation

```text
CHILD/DEPENDENT TRANSITION IN A
-> CARE / ESCORT / SUPERVISION OBLIGATION CHANGES
-> PARENT'S WORK / LEISURE / TREATMENT POSSIBILITY IN B CHANGES
```

### Relation/counterpart

```text
NEW FRIEND/ALLY/CONFLICT IN A
-> SUPPORT / INFORMATION / MOTIVE-RELEVANT OR COUNTERPART CHANNEL CHANGES
-> PARTICIPATION POSSIBILITY IN B CHANGES
```

### Mobility

```text
LEARNED/AVAILABLE TRANSPORT ROUTE IN A
-> REACHABLE CONTEXT SET EXPANDS
-> FRIEND/WORK/LEISURE PARTICIPATION IN B BECOMES POSSIBLE
```

### Stance or learning

```text
EXPERIENCE/REFLECTION IN A
-> ACTOR'S STANCE/UNDERSTANDING CHANGES [V3]
-> DIFFERENT ACTION IN B
```

The last chain contains a psychological mediator and must stay V3-governed. The first chains may be objective actor-ecology propagation before any subjective uptake.

## 6. Therapy as an intervention test

Therapy is valuable architecturally because it exposes a common mistake:

```text
SESSION CONTENT
-> CLIENT CHANGE
```

Dreier replaces this with:

```text
SESSION PARTICIPATION
-> SELECTIVE ACTOR UPTAKE / REINTERPRETATION
-> LATER SITUATION OPPORTUNITY
-> CONTEXT-SPECIFIC USE / ACTION / NONUSE
-> COPARTICIPANT / ARRANGEMENT RESPONSE
-> POSSIBLE CHANGE IN EVERYDAY PRACTICE
-> REPEATED/GENERALIZED CONSEQUENCE IF EARNED
```

What was talk in the session may become a very different action or silence elsewhere. The same session material can be irrelevant in a later context. Other causes combine with it. Therefore no `TRANSFER_EFFECT` packet is warranted.

## 7. Pursuit rather than fixed goal

Dreier’s use of `pursuit` matters. Cross-context action often has direction without a fully specified endpoint. Pursuits can be:

- discontinuous;
- resumed after interruption;
- modified as conditions change;
- enacted differently in different contexts;
- hidden in one place and explicit in another;
- abandoned when costs/possibilities change.

Rawlsing implication: V3 striving/practice/action mechanisms should be able to operate over D1/D2 context facts without requiring a single immutable goal state.

No new seam object follows.

## 8. Personal practice court

### Dreier meaning

A personal practice is the person’s situated, cross-context way of participating and conducting life. It is personal because the person links participation across contexts and biography; it is practice because it exists in actual social activity, not inside an isolated mind.

### Jurisdiction verdict

`SEAM-SPANNING COMPOSITION__PRIMARY OWNER V3`.

Why:

- its **conditions** come from D1 actor-relative ecology;
- its **temporal structure** relies on D2 intervals/recurrence/history;
- its **stance, concern, reason, coordination and chosen action** belong in V3;
- its **objective realized social consequences** become external history and may invoke D3.

Rawlsing should not mint `PERSONAL_PRACTICE` upstream as a social fact that already contains actor intention or meaning.

## 9. Routines and rhythms

Dreier’s conduct is not a sequence of isolated choices. It depends on recurrent routines and institutional/family rhythms.

```text
ROUTINE != MERE REPETITION
```

A routine can:

- economize attention/coordination;
- establish familiarity and trust;
- preserve a practical ordering;
- carry personally significant continuity;
- be adjusted after illness, travel, conflict or transition.

The objective recurrence pattern is D2-compatible. Its personal significance, trust and meaning remain V3.

## 10. Cross-context learning

Dreier repeatedly emphasizes that persons compare participation, experiences and understandings across contexts. Difference between contexts can itself become a learning resource.

Rawlsing chain:

```text
REALIZED PARTICIPATION IN A
+ REALIZED PARTICIPATION IN B
-> V3 COMPARISON / REFLECTION / LEARNING
-> CHANGED STANCE / CAPABILITY / PRACTICE IF EARNED
```

The seam need only preserve source context, position and history provenance. It must not perform the psychological comparison.

## 11. Conduct under asymmetrical command

Dreier prevents conduct-of-life from becoming voluntarism. Persons coordinate lives through conditions they often do not command:

- work schedules;
- school timetables;
- therapy appointments;
- care needs;
- transport availability;
- household task divisions;
- legal/institutional rules;
- other people’s commitments and refusals.

The concept therefore requires both D1 constraints and V3 agency. Either half alone is inadequate.

## 12. Family is not a super-agent

Chapter 11 is decisive:

```text
FAMILY CONDUCT
!= ONE FAMILY MIND
```

Family life is the partially overlapping coordination of members’ distinct conducts and trajectories. Joint arrangements emerge through task distribution, timing, permission, dependence, negotiation and conflict.

For Rawlsing, collective/family change must be represented through persons, relations, arrangements and external facts—not a collective psychological subject.

`D4_NOT_REQUIRED`.

The missing requirement is smaller:

`CONCURRENT_MULTI_CONTEXT_BINDING_AND_CROSS_CONTEXT_EDGE_COMPOSABILITY`

This should be imposed as an invariant/test over D1+D2 and existing V3, not adopted as a fourth positive seam capability.

## 15. Strongest cross-context anti-shortcut law

```text
WHAT HAPPENS OR IS SAID IN CONTEXT A
DOES NOT BECOME AN EFFECT IN CONTEXT B
UNLESS A TYPED MATERIAL / TEMPORAL / RELATIONAL / INFORMATIONAL
OR ACTOR-MEDIATED ROUTE ACTUALLY CONNECTS THEM.
```

And, for psychotherapy specifically:

```text
SESSION CHANGE != EVERYDAY-LIFE CHANGE
```
