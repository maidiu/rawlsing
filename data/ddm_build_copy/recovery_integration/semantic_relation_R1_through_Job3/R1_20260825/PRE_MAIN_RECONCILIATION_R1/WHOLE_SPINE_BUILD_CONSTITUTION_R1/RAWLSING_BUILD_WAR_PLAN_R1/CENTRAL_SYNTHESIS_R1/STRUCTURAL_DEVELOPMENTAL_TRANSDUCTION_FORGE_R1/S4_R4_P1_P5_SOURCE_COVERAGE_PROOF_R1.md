# S4 R4 — P1–P5 SOURCE COVERAGE PROOF R1

STATUS: `ALL_FIVE_R4_RULE_CLASSES_SOURCE_GROUNDED__NO_SIXTH_PRIMITIVE_LICENSED`

## 0. Question proved

This court asks a narrower question than whether every future concrete rule is already authorized:

> Is each R4 P1–P5 **rule-class shape** independently grounded in the completed theory/evidence corpus, with enough source support to justify retaining the class as a lawful normalization target?

Answer: **YES for P1–P5.**

This is not a claim that every concrete rule instance, coefficient, calibration, portability scope or actor fact is already licensed.

## 1. P1 — MATERIAL_ACCESS_DEPENDENCY

### Independent source convergence

- Wright: property/productive-asset relations, exploitation/dependency and credential scarcity are relational, not class-label essences.
- Elder: economic deprivation matters through actual income loss, father's worklife, family maintenance strategy, children's economic/domestic roles and changed household resources.
- SRT volume: wages, public provision, pensions, services, debt, legal status and household transfers concretely alter material possibility/dependency.
- T3/M10/M11 normalization repeatedly converges on exact property/resource/service/transfer relations rather than demographic priors.

### Licensed rule-class shape

```text
EXACT MATERIAL / PROPERTY / BENEFIT / SERVICE / DEBT / TRANSFER RULE OR STATE
+ ACTOR'S SOURCE-OWNED POSITION / ELIGIBILITY / DEPENDENCY RELATION
+ CONTEXT / TIME / COUNTERPART WHEN NEEDED
-> OBJECTIVE ACCESS / ENTITLEMENT / RESOURCE / DEPENDENCY / EXIT-CONSTRAINT CONSEQUENCE
```

### Source ceiling

```text
CLASS_LABEL != RESOURCE_STATE
POVERTY_LABEL != EXACT RESOURCE CONSEQUENCE
ENTITLEMENT != RECEIPT
RESOURCE_AVAILABILITY != USE
RESOURCE_CONSEQUENCE != PSYCHOLOGICAL EFFECT
```

### Verdict

`P1_SOURCE_GROUNDED = YES`.

No new primitive is required for household resources, wages, pensions, public services, debt or property; they are P1 rules or compositions with other classes.

## 2. P2 — DIRECTED_AUTHORITY_OBLIGATION_SANCTION

### Independent source convergence

- Wright: organizational authority must be represented through actual control rights/scopes, not manager titles.
- Kohn/Schooler: closeness of supervision and occupational control are actual job conditions, distinct from occupation/class labels.
- Merton: one status creates multiple counterpart-specific expectations and powers, not one monolithic role effect.
- Dreier: positions in practices carry differentiated possibilities and obligations.
- SRT: employer, household, care and institutional relations generate directed obligations only through concrete arrangements.

### Licensed rule-class shape

```text
OPERATIVE AUTHORITY / DUTY / SANCTION / ROLE RULE
+ EXACT SOURCE / TARGET / POSITION / SCOPE
+ CONTEXT / TIME
-> OBJECTIVE AUTHORITY SCOPE / OBLIGATION / RESPONSIBILITY / SANCTION EXPOSURE
```

### Source ceiling

```text
TITLE != AUTHORITY
STATUS != ONE ROLE EFFECT
OBLIGATION != PERFORMANCE
SUPERVISION != SUBJECTIVE CONTROL
AUTHORITY != COMPLIANCE
```

### Verdict

`P2_SOURCE_GROUNDED = YES`.

Authority, care duties, role expectations and sanctions do not require separate primitives so long as directionality and scope are explicit.

## 3. P3 — ORGANIZED_ACTIVITY_TIME

### Independent source convergence

- Kohn/Schooler: actual substantive complexity, routinization and supervision matter; job title is inadequate.
- Mortimer: adolescent work differs in task quality, time allocation, intensity and ecology; work itself is not homogeneous.
- Elder: actual child economic/domestic tasks and role changes are developmentally relevant exposures; macro deprivation is not the task.
- Marxist/activity/Sève corpus: socially organized acts/practices and use-time motivate explicit activity/time decomposition while stopping before direct psychological effects.
- SRT: paid work, care, commuting, school and recovery compete for finite time; M11 requires schedule/duration/frequency proof for actual crowd-out.

### Licensed rule-class shape

```text
ORGANIZATION / TASK / SCHEDULE / ACTIVITY RULE
+ EXACT ACTOR POSITION
+ ACTUAL PARTICIPATION / REQUIRED PARTICIPATION AS APPLICABLE
+ INTERVAL / RECURRENCE / DURATION
-> OBJECTIVE TASK / ACTIVITY / SCHEDULE / TIME-COMPETITION CONSEQUENCE
```

### Source ceiling

```text
OCCUPATION != TASK CONTENT
EMPLOYMENT != WORK QUALITY
SCHOOL MEMBERSHIP != ACTUAL INSTRUCTION/PRACTICE
SCHEDULE POSSIBILITY != PARTICIPATION
ONE OBSERVATION != CURRENT RECURRENT ACTIVITY
TASK CONDITION != CAPACITY / MASTERY / PERSONALITY
```

### Verdict

`P3_SOURCE_GROUNDED = YES`.

Finite-time competition is a P3 rule composition over objective activities and schedules, not a sixth primitive.

## 4. P4 — INSTITUTIONAL_GATE_TREATMENT

### Independent source convergence

- Wright: credentials/skills/authority map to positions only through institutionally specific rules and operationalizations.
- SRT: pension, welfare, migration, school/service and legal eligibility mechanisms require explicit policy/gate rules.
- Bertrand & Mullainathan: randomized résumé-name manipulation causally affected callback treatment in sampled hiring contexts.
- Pager: matched audit design identifies bounded employer gate penalties tied to presented criminal-record condition and race presentation.
- Correll/Benard/Paik: lab and field audit evidence identifies bounded motherhood-status cue effects on evaluation/recommendation/callback.

### Licensed rule-class shape

```text
OPERATIVE GATE / EVALUATION RULE
+ ACTOR ELIGIBILITY / APPLICATION BINDING
+ PRESENTED / RECOGNIZED RECORD OR CUE WHEN RELEVANT
+ ACTUAL GATE ENCOUNTER
-> OBJECTIVE EVALUATION / DECISION / TREATMENT CONSEQUENCE
```

### Mandatory ladder

```text
ATTRIBUTE
!= PRESENTED CUE
!= RECOGNIZED CUE
!= CLASSIFICATION
!= ELIGIBILITY
!= APPLICATION
!= EVALUATION
!= DECISION
!= DOWNSTREAM RESULT
```

### Source ceiling

The experimental literature strengthens causal identification for specific cue→decision relations under study conditions. It does not license a universal demographic treatment prior, a scope-free probability, or any developmental consequence.

### Verdict

`P4_SOURCE_GROUNDED = YES__STRONGEST_BOUNDED_CAUSAL_IDENTIFICATION_IN_CORPUS`.

No separate discrimination primitive is needed; differential treatment is a P4 process with explicit presented/recognized information and gate evidence.

## 5. P5 — COUNTERPART_CHANNEL_RELATION

### Independent source convergence

- Feld: organized foci alter who repeatedly encounters whom; focus is not itself a tie.
- Granovetter: actual bridging relations can expose nonredundant information; weak tie is not automatically a bridge.
- Burt: brokerage changes information/opportunity context; networks are contexts for action, not actors.
- Coleman: information channels, obligations, closure-enabled sanctions and appropriable organization decompose generic social capital.
- Dreier: persons participate in multiple contexts with distinct counterparts and interdependencies.
- Elder/T5: linked lives require a concrete source→target relation and channel.
- SRT Ch.7: church ties can realize referrals/material support, but religion label does not equal support.

### Licensed rule-class shape

```text
EXACT RELATION / CHANNEL / COUNTERPART CONFIGURATION
+ ACTOR AND COUNTERPART BINDINGS
+ CONTEXT / TIME
-> OBJECTIVE REACHABILITY / COPARTICIPATION / CHANNEL / RELATION CONSEQUENCE
```

and, only with an appropriate occurrence witness:

```text
CHANNEL + ACTUAL TRANSACTION / CONTACT / DELIVERY
-> OBJECTIVE TRANSFER / SUPPORT / INFORMATION / CONTACT FACT
```

### Source ceiling

```text
FOCUS != RELATION
TIE != TRANSFER
WEAK_TIE != BRIDGE
BRIDGE != INFORMATION DELIVERY
CHANNEL != RECEIPT
NETWORK_POSITION != BENEFIT
RELATION != SUBJECTIVE MEANING
```

### Verdict

`P5_SOURCE_GROUNDED = YES`.

Support, linked-life effects, information access and counterpart ecology require P5 and compositions, not generic social-capital or linked-lives primitives.

## 7. Sixth-primitive court

A sixth primitive would be justified only if an important retained **objective-social transformation** could not be expressed without semantic distortion as P1–P5 or their composition.

The audit found no such case.

Rejected P6 candidates and dispositions:

```text
SOCIAL_REPRODUCTION          -> composition P1-P5
HOUSEHOLD_CARE               -> composition P1/P2/P3/P4/P5
CLASS                        -> analyst-level relational composition
DISCRIMINATION               -> P4 + downstream access/resource consequence
NETWORK_CAPITAL              -> P5/P2 decomposed channels/obligations/sanctions
LIFE_COURSE_TIMING           -> qualification/history binding
CUMULATIVE_DISADVANTAGE      -> repeated typed rules/history, not scalar
TURNING_POINT                -> derived trajectory predicate
CULTURE                      -> not a primitive; exact institution/practice/channel required
AGENCY                       -> outside D1' subjective/action selection; externalized consequences require separate owners
RECIPROCAL_WORLD_UPDATE      -> outside R4 world-writer jurisdiction, not P6
SUBJECTIVE_PREMISE           -> downstream V3 boundary, not P6
CALIBRATION                  -> governance/evidence companion, not P6
```

`P6_VERDICT = NOT_REQUIRED__NOT_LICENSED`.

## 8. D2 / D3 / D4 ownership court

The older pre-R3 corpus sometimes described temporal preservation as D2 and reciprocal social-world update as D3. R3/R4 lawfully narrowed those away from the D1' constitution.

S4 source audit finds **no source that reverses that narrowing**.

- Persistent/recurrent objective consequences need temporal/lifecycle bindings and witness currentness, but no separate S4-licensed D2 primitive is required inside R4.
- Reciprocal action→world change requires an external competent response/world writer. It is real as a source mechanism, but it is outside D1' ownership. R4 can consume the new external fact later.
- Household, production/reproduction interlock, life-course accumulation and networks do not require D4; they decompose into P1–P5 plus existing history/witness/boundary machinery.

`D2_REQUIRED_BY_SOURCE_FOR_R4 = NO`.

`D3_REQUIRED_BY_SOURCE_FOR_R4 = NO__RECIPROCAL_WORLD_UPDATE_REAL_BUT_OUTSIDE_D1_PRIME`.

`D4_REQUIRED_BY_SOURCE = NO`.
