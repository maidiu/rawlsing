## 1. Source-level verdict

Wright does **not** support a runtime edge `CLASS LOCATION -> PERSONALITY / BEHAVIOR / EXPERIENCE`.

The book's strongest durable contribution is a relational decomposition:

```text
PRODUCTIVE-ASSET / PROPERTY / ORGANIZATION / CREDENTIAL RELATION
+ COUNTERPART POSITION
+ INSTITUTIONAL RULES
        -> OBJECTIVE MATERIAL STAKES / CAPACITIES / DEPENDENCIES
        -> CONCRETE OPTIONS, CONTROLS, SANCTIONS, CLAIMS, RISKS
        -> REALIZED PRACTICE / RELATION / CONDITION ONLY THROUGH FURTHER MEDIATION
        -> CONSCIOUSNESS / MOTIVE / DURABLE PERSON CHANGE ONLY THROUGH SEPARATE SUBJECT PROCESS
```

`CLASS` survives principally as an analyst-level name for patterned bundles of relations, not as an executable scalar.

## 3. Evidence ceilings

1. **Theoretical architecture:** strong for separating structural relation, objective stake, formation and subjectivity.
2. **Empirical operationalization:** useful but deliberately compromised; unsuitable as direct runtime ontology.
3. **Causal person inference:** weak. The book repeatedly concedes mediation and survey limits.
4. **Temporal inference:** suggestive rather than longitudinally decisive; cohort/career confounding is explicit.
5. **Collective action:** strong conceptual evidence for organization/political mediation; not a complete computational model of mobilization.
6. **Skill exploitation:** explicitly less secure as a fully constituted class relation; retain as typed scarcity/rent mechanism, not dogma.
