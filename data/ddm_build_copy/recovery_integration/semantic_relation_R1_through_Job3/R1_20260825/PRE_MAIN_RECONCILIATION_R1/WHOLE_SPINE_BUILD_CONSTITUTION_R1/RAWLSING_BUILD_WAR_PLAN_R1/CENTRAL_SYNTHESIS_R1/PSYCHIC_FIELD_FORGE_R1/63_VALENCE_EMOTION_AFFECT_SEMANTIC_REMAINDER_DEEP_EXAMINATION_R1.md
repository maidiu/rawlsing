## 0. Executive verdict

The affect frontier survives the no-duplication test, but again as a **semantic relation problem rather than a new architecture family**.

Rawlsing already has substantial capital around emotion-adjacent phenomena:

- actor-specific appraisal;
- need-relevant pressure;
- threat / safety interpretation;
- attraction / aversion;
- approach / avoidance conflict;
- conscious felt state;
- hidden causal activation;
- shame, fear, anger, grief, relief, attraction, dread, hope, resentment, guilt, and similar affect terms used in examples;
- coactivation and ambivalence;
- defense and regulation;
- leakage and expression constraint;
- persistence, inertia, residue, sensitization, rebound, and hysteresis;
- anticipation of future affective consequences;
- target- and relationship-specific recruitment.

Therefore Rawlsing does **not** presently justify:

- a fixed emotion taxonomy;
- one categorical current emotion winner;
- one positive/negative valence scalar;
- a universal arousal axis;
- an affect vector whose coordinates are treated as psychological truth;
- a one-step appraisal -> emotion label -> behavior pipeline;
- imported basic-emotion doctrine as project ontology;
- a new `EmotionState` database merely because emotion words recur in the theory.

A real semantic remainder nevertheless exists.

Rawlsing repeatedly uses affect labels as causal shorthand, but the project has not yet explicitly preserved the **internal relations that make affect psychologically meaningful**.

The minimum surviving requirement is:

> A live affective episode must be able to differ along several non-collapsible relations — what is appraised, for whom/what, with what desirability or aversiveness, bodily/felt quality, urgency/activation, action tendency, accessibility, self-interpretation, temporal carryover, and expression consequence — without requiring those relations to be reducible to one emotion label or one scalar state.

Current holding:

`RICHER_AFFECT_SEMANTICS = REQUIRED`

`NEW_EMOTION_ONTOLOGY = NOT ESTABLISHED`

`EMOTION_LABEL = POSSIBLE_SUMMARY / ACTOR_CONCEPT / ANALYST_HANDLE`

`EMOTION_LABEL != COMPLETE_CAUSAL_STATE`

`VALENCE != AFFECT`

`AFFECT != APPRAISAL`

`AFFECT != ACTION_TENDENCY`

`AFFECT != EXPRESSION`

`AFFECT != CONSCIOUS_SELF_EXPLANATION`

## 1. Exact question

File `62` leaves the next finite-person frontier as:

`VALENCE / EMOTION SEMANTICS AS RICHER INTERNAL VOCABULARY`.

The required no-gadget question is:

> Does existing Rawlsing vocabulary already provide enough semantics for lifelike person-specific affective metabolism, or does a real relation-level remainder remain beneath the existing use of emotion words?

A shallow answer would be:

```text
EVENT
-> APPRAISAL
-> EMOTION_LABEL
-> ACTION
```

or:

```text
CURRENT_VALENCE = -0.7
CURRENT_AROUSAL = 0.8
-> RESPONSE
```

Both are too coarse for the phenomena PFF has already committed itself to preserving.

The stronger question is:

> What must remain distinguishable so that fear, shame, anger, grief, attraction, relief, pride, guilt, dread, hope, tenderness, contempt, resentment, and mixed states can arise as person-specific consequences without becoming canned labels or direct behavior switches?

## 2. Existing Rawlsing capital already covers much of the terrain

### 2.1 Actor-specific appraisal is already upstream

File `28` establishes the general continuity shape:

```text
LAWFUL OCCURRENCE / OBSERVABLE INPUT
-> ACTOR-PERCEIVABLE / ACTOR-AVAILABLE BASIS
-> ACTOR-SPECIFIC APPRAISAL / INTERPRETATION
-> RECRUITMENT / RESPONSE METABOLISM
-> FAST OR DURABLE CONSEQUENCE ACCORDING TO REGIME
```

This is already a strong guardrail.

Rawlsing should not map objective event labels directly to emotion.

The same external event can be appraised differently because of:

- actor knowledge;
- uncertainty;
- prior expectations;
- relationship history;
- self-model;
- current need pressure;
- motivational priority;
- remembered consequences;
- social position;
- perceived controllability;
- moral meaning;
- anticipated future.

Therefore:

`OBJECTIVE_EVENT != ACTOR_APPRAISAL`

and:

`ACTOR_APPRAISAL != AFFECTIVE_EPISODE`.

Appraisal helps constitute affect but does not exhaust it.

### 2.2 Present conscious field already protects felt-but-unnamed affect

File `10` distinguishes:

- causally active but inaccessible;
- felt but unnamed;
- focal nonpropositional affect/body state;
- peripheral/background affect;
- fringe signals;
- conceptual naming;
- self-attribution;
- causal self-understanding.

Therefore Rawlsing already rejects:

`FEELING = EXPLICIT EMOTION WORD`.

A person can experience:

- dread without naming fear;
- shame heat without accepting shame;
- agitation without knowing whether it is anger or anxiety;
- bodily attraction without conceptual recognition;
- relief without knowing what prior threat has released;
- grief as fatigue or emptiness rather than articulated sadness.

The affect frontier must reuse that conscious-field distinction rather than create a separate awareness model.

### 2.3 Conflict work already proves affect can be plural and contradictory

File `09` explicitly preserves:

- attraction + shame;
- anger + fear of abandonment;
- grief + relief;
- suspicion + longing for reassurance;
- desire + aversion toward the same object;
- affect hidden by strategy or defense;
- cross-conversion into another accessible state;
- nonmonotonicity.

Therefore:

`ONE_CURRENT_EMOTION = REJECT`.

`MIXED_AFFECT = NORMAL_REPRESENTABLE_CASE`.

`OPPOSITE_VALENCES_CAN_COEXIST_TOWARD_SAME_OBJECT`.

### 2.4 Defense already changes affect access and interpretation

File `11` establishes that defense can operate:

- before awareness;
- at access;
- at self-interpretation;
- at expression.

It also distinguishes defense from emotion regulation, strategy, performance, and posture.

This means Rawlsing already needs cases such as:

```text
CAUSAL_SHAME
-> ACCESSIBLE_IRRITATION
```

or:

```text
DEPENDENCY_THREAT
-> DEFENSIVE_ANGER / DISTANCE
```

without treating these as universal mappings.

The affect frontier therefore cannot assume the actor's emotion label is a transparent report of the underlying affective organization.

### 2.5 Time work already proves affect is not a single decaying scalar

File `12` distinguishes:

- continuation;
- inertia;
- residue;
- priming/readiness;
- sensitization;
- habituation/attenuation;
- suppression maintenance;
- rebound;
- refractory/depleted response;
- accumulation;
- dormancy;
- hysteresis/path dependence.

For affect this is decisive.

A person may no longer feel consciously angry while:

- criticism sensitivity remains elevated;
- approach remains inhibited;
- defensive readiness remains high;
- the counterpart remains unusually salient;
- later cues re-enter anger more easily.

Therefore:

`AFFECT_ENDED != ALL_AFFECTIVE_CONSEQUENCES_ENDED`.

`PERSISTED_EFFECT != PERSISTED_EMOTION_LABEL`.

### 2.6 Anticipation already creates affect before events occur

File `17` establishes that predicted futures can have current psychic effects.

Thus:

- feared rejection can recruit shame before rejection occurs;
- hoped-for repair can recruit warmth or relief before repair occurs;
- anticipated humiliation can recruit defensive anger;
- expected loss can recruit grief-like or dread-like states before the loss is final;
- uncertain reciprocation can sustain attraction/tension.

Therefore:

`AFFECT != ONLY_REACTION_TO_COMPLETED_EVENT`.

Prospective affect is already required.

### 2.7 Expression work already prevents affect labels from becoming rendering commands

File `13` establishes:

`PFF_TO_V2_HANDOFF != ONE_EMOTION_LABEL`.

It also requires hidden causes to become bounded expression effects rather than renderer-visible causal propositions.

Therefore the affect frontier is **upstream semantic enrichment**, not a route to prompts like:

`emotion=angry -> sound angry`.

## 3. First major semantic remainder: valence is too thin by itself

Valence can usefully describe whether something is experienced/appraised as desirable, aversive, rewarding, painful, welcome, unwelcome, or mixed.

But a single positive/negative dimension collapses crucial differences.

Examples of negative-valence episodes:

- fear of being harmed;
- shame about being seen as inadequate;
- grief over irreversible loss;
- anger at obstruction or violation;
- guilt about one's own wrongdoing;
- disgust or revulsion;
- loneliness;
- envy;
- dread of a future event;
- resentment over an unresolved relational claim.

These are not interchangeable merely because all may be unpleasant.

Similarly positive-valence episodes include:

- relief;
- tenderness;
- pride;
- attraction;
- excitement;
- contentment;
- gratitude;
- triumph;
- belonging;
- amused playfulness.

Again, not interchangeable.

Therefore:

`VALENCE = USEFUL_RELATION`

but:

`VALENCE != EMOTION_IDENTITY`

`VALENCE != APPRAISAL_STRUCTURE`

`VALENCE != ACTION_TENDENCY`

`VALENCE != NEED_RELEVANCE`

`VALENCE != AROUSAL / URGENCY`

`VALENCE != MORAL_MEANING`

`VALENCE != TARGET`.

No scalar valence architecture is authorized.

## 4. Affect requires an object / target / scope relation where applicable

Many affective states are about or toward something.

Examples:

- angry **at** B;
- afraid **of** losing the job;
- ashamed **before** a particular audience;
- proud **of** one's child;
- grief **for** a person or lost future;
- attraction **toward** B;
- contempt **for** an institution;
- guilt **about** one's action;
- anxiety **about** an uncertain outcome;
- relief **that** a feared outcome did not occur.

Target and scope can be:

- person;
- relationship;
- self;
- action;
- event;
- memory;
- anticipated future;
- institution;
- group;
- social audience;
- role;
- world condition;
- diffuse/unknown.

Therefore:

`AFFECT_WITH_SAME_LABEL + DIFFERENT_TARGET != SAME_LIVE_CONFIGURATION`.

A person can be:

- angry at B but protective of the relationship;
- ashamed of one action but proud of another;
- afraid of public exposure but not private disagreement;
- attracted to B while averse to the social consequences of that attraction.

Global mood labels are too coarse to represent this.

## 5. Appraisal content and affective consequence must remain separable

Affect is not merely another name for appraisal.

Two actors can make broadly similar propositional appraisals and still differ affectively because of:

- different need pressure;
- different motivational priority;
- different relationship meaning;
- different memories;
- different self-model stakes;
- different expected consequences;
- different operating condition;
- different defensive organization;
- different bodily/current state;
- different perceived agency or controllability.

Likewise one actor can experience a strong affect before achieving a stable explicit appraisal.

Therefore:

`APPRAISAL_CAN_CONTRIBUTE_TO_AFFECT`

but:

`APPRAISAL != AFFECT`

and:

`EXPLICIT_APPRAISAL_NOT_REQUIRED_FOR_ALL_AFFECTIVE_CAUSATION`.

A useful pre-architecture question for any affective episode is:

> What did the event mean to this person, and how did that meaning recruit a felt/action-organizing response?

The answer may remain partly nonpropositional.

## 6. Felt quality / bodily character is a real distinction, not proof of a separate subsystem

File `10` already admits nonpropositional bodily/felt presence.

This matters because two episodes can share a rough appraisal but differ in felt character.

Examples:

- threat may be experienced as racing agitation, freezing numbness, or cold vigilance;
- attraction may be warm, excited, anxious, calm, or embarrassing;
- anger may feel hot and urgent or cold and controlled;
- grief may feel piercing, heavy, empty, dissociated, or intermittently absent;
- shame may involve heat/exposure, collapse, self-attack, or defensive hardening.

Rawlsing does not need to simulate physiology literally unless later architecture independently requires it.

But it must preserve the semantic possibility that:

`FELT_QUALITY != EMOTION_LABEL`

and:

`FELT_QUALITY_CAN_SHAPE_CONSCIOUS_FIELD / ATTENTION / EXPRESSION`.

The body-state source may itself come from V3/current-world authority rather than PFF inventing physiology.

## 7. Urgency / activation / intensity must remain distinct from valence and category

Affect can differ in how much immediate claim it exerts.

Examples:

- mild irritation versus consuming rage;
- background grief versus acute grief wave;
- faint attraction versus intrusive preoccupation;
- quiet dread versus panic-like urgency;
- calm pride versus exuberant triumph.

But intensity is not enough either.

A highly intense state can be behaviorally inhibited.

A low-intensity state can have durable interpretive consequences.

A moderate state can become focal because of motivational priority or relationship context.

Therefore:

`AFFECTIVE_INTENSITY != BEHAVIORAL_CONTROL`

`AFFECTIVE_INTENSITY != ATTENTIONAL_PRIORITY`

`AFFECTIVE_INTENSITY != EXPRESSION_STRENGTH`

`AFFECTIVE_INTENSITY != DURABLE_IMPORTANCE`.

No one universal intensity scalar is adopted.

## 8. Action tendency is part of affective meaning but not deterministic behavior

Affect often changes readiness for certain classes of action.

Candidate examples:

- fear may recruit withdrawal, freezing, vigilance, appeasement, or defensive confrontation;
- anger may recruit confrontation, boundary assertion, retaliation fantasy, withdrawal, repair demand, or controlled inhibition;
- shame may recruit concealment, appeasement, self-attack, anger, withdrawal, repair, or overperformance;
- grief may recruit withdrawal, seeking closeness, memorialization, rumination, numb functioning, or meaning-making;
- attraction may recruit approach, attention, playfulness, self-consciousness, avoidance, concealment, or testing;
- guilt may recruit confession, repair, avoidance, rationalization, or self-punishment;
- pride may recruit display, confidence, generosity, protection, dominance, or private satisfaction.

The variation is the point.

Therefore:

`EMOTION_LABEL -/-> FIXED_ACTION`.

Action tendency must remain conditioned by:

- appraisal;
- competing motives;
- principle/obligation;
- anticipated consequence;
- relationship stakes;
- self-model;
- defense;
- available opportunity;
- current operating condition;
- actor intention.

Affect can bias action without owning final action selection.

## 9. Named emotion and causal organization are not identical

Emotion words can enter Rawlsing in at least several distinct roles.

### 9.1 Actor concept

The actor consciously thinks:

`I am angry.`

This is part of actor-accessible self-interpretation.

### 9.2 Analyst/system summary

The system may use `anger-like` as a compact explanatory label for a richer causal configuration.

This summary must not automatically become actor knowledge.

### 9.3 Generated social interpretation

The actor may think:

`B seems angry.`

That is an actor hypothesis about B, not B truth.

### 9.4 Expression description

A response may appear angry to an observer while the actor is consciously afraid, strategically firm, or emotionally mixed.

### 9.5 Cultural vocabulary

Different actors may have different learned concepts for classifying similar felt states.

Therefore:

`ACTOR_EMOTION_LABEL != SYSTEM_CAUSAL_SUMMARY`

`SYSTEM_CAUSAL_SUMMARY != COUNTERPART_PERCEPTION`

`COUNTERPART_PERCEPTION != OBJECTIVE_INTERNAL_TRUTH`

`EMOTIONAL_EXPRESSION != INTERNAL_AFFECT_IDENTITY`.

This is a direct extension of Rawlsing's epistemic and perspective laws.

## 10. Mixed affect is relational structure, not averaging

Rawlsing must preserve cases such as:

```text
LOVE + RESENTMENT
ATTRACTION + FEAR
GRIEF + RELIEF
ANGER + GUILT
PRIDE + SHAME
HOPE + DREAD
TENDERNESS + DISTRUST
RELIEF + SADNESS
CURIOSITY + AVERSION
```

A shallow valence system may average these into neutrality.

That destroys the phenomenon.

Mixed affect can instead produce:

- oscillation;
- ambivalence;
- compromise expression;
- alternating approach/withdrawal;
- self-confusion;
- defensive relabeling;
- selective disclosure;
- unstable attention;
- delayed action;
- heightened monitoring.

Therefore:

`POSITIVE + NEGATIVE != ZERO`.

`MIXED_AFFECT != LOW_AFFECT`.

`AMBIVALENCE != UNCERTAINTY_ONLY`.

A person can be highly certain that they both love and resent someone.

## 11. Affect can be diffuse, object-uncertain, or object-misassigned

Not every affective state has an explicit known target.

Possible cases:

- generalized unease;
- diffuse irritability;
- dread without a precise forecast;
- grief-like heaviness with no current focal memory;
- bodily excitement the actor misattributes;
- shame whose public audience is only vaguely represented;
- anger displaced onto a safer target;
- attraction interpreted as annoyance.

Therefore architecture must not require every affective episode to contain a fully articulated proposition or correctly known target.

Useful distinction:

`CAUSAL_TARGET`

may differ from:

`ACTOR_ATTRIBUTED_TARGET`.

That difference is especially important for defense, displacement, and self-understanding.

## 12. Threat / safety is not synonymous with fear

Rawlsing uses threat/safety language broadly in appraisal and relationship contexts.

But:

`THREAT_APPRAISAL != FEAR`.

A perceived threat can recruit:

- fear;
- anger;
- shame;
- contempt;
- vigilance;
- strategic calm;
- numbness;
- defiance;
- excitement;
- mixed affect.

Likewise felt fear can arise around:

- physical danger;
- rejection;
- status loss;
- moral failure;
- intimacy/exposure;
- uncertainty;
- loss of control;
- anticipated grief;
- identity destabilization.

Therefore the theory should preserve:

`APPRAISAL_CLASS != AFFECT_CLASS`.

This prevents a threat detector from becoming an emotion engine by fiat.

## 13. Shame / pride require self-and-audience semantics, not just negative/positive valence

Shame and pride illustrate why richer semantics matter.

A shame-like episode may involve relations among:

- self-evaluation;
- perceived norm/standard;
- believed audience evaluation;
- exposure / being-seen dynamics;
- belonging/status stakes;
- concealment pressure;
- repair possibility;
- anger/defiance counter-reaction;
- self-model threat.

A pride-like episode may involve:

- achievement;
- recognition;
- self-coherence;
- audience validation;
- group identification;
- moral satisfaction;
- status display;
- private contentment.

Therefore:

`SHAME != NEGATIVE_SELF_VALENCE`.

`PRIDE != POSITIVE_SELF_VALENCE`.

Metaperception and social meaning can be central without being required in every case.

## 14. Anger requires obstruction / violation / claim semantics without one universal theory

Anger examples across existing PFF work show that anger can arise around:

- obstruction;
- perceived injustice;
- humiliation;
- betrayal;
- boundary violation;
- loss of control;
- threatened attachment;
- shame defense;
- accumulated frustration;
- moral outrage.

The project should not choose one universal anger theory now.

But it must not reduce anger to:

`negative valence + high activation`.

Affectively similar activation can organize very different meanings depending on what claim the person believes has been violated or blocked.

Thus:

`ANGER_REQUIRES_PERSON_SPECIFIC_MEANING_RELATION`

without implying:

`ONE_CANONICAL_ANGER_CAUSE`.

## 15. Grief / loss exposes temporal and counterfactual structure

Grief is not only sadness intensity.

It may involve relation to:

- an irreversible loss;
- a lost person;
- a lost role;
- a lost possible future;
- a lost version of self;
- a relationship that no longer exists in the same form;
- repeated expectation violation as the world fails to match the prior lived model.

This means grief can remain active even when no explicit memory is focal.

It can coexist with:

- relief;
- anger;
- guilt;
- gratitude;
- numbness;
- practical functioning;
- new attachment;
- hope.

Therefore:

`GRIEF != GLOBAL_NEGATIVE_MOOD`.

Its temporal/counterfactual organization matters.

Durable grief-related person change remains V3-owned where earned; live waves, residue, and expression consequences may be PFF-relevant.

## 16. Anxiety / uncertainty must remain separable

Uncertainty can be causally active without producing anxiety.

Anxiety can also persist where the actor's explicit uncertainty is low.

Examples:

- actor knows an unpleasant event will occur and still dreads it;
- actor has many plausible social readings and becomes anxious;
- actor is uncertain but curious rather than anxious;
- actor consciously claims certainty while hidden defensive uncertainty sustains vigilance.

Therefore:

`UNCERTAINTY != ANXIETY`.

`ANXIETY != LOW_CONFIDENCE`.

`ANXIETY != FEAR_OF_ONE_EXPLICIT_OBJECT`.

File `17` already establishes that uncertainty can increase prospective activation. Affect semantics must preserve that without laundering uncertainty into emotion or vice versa.

## 17. Attraction / aversion require more than approach / avoidance behavior

Attraction can increase:

- attention;
- curiosity;
- proximity-seeking;
- self-consciousness;
- imagined futures;
- memory retrieval;
- concern with counterpart evaluation;
- playfulness;
- concealment;
- avoidance when exposure risk is high.

Aversion can similarly coexist with attention, fascination, obligation, approach, or strategic engagement.

Therefore:

`ATTRACTION != APPROACH_ACTION`.

`AVERSION != AVOIDANCE_ACTION`.

`APPROACH / AVOIDANCE = ACTION-ORIENTATION RELATIONS`

not complete affect identities.

Same-object attraction and aversion may be simultaneously high.

## 18. Emotion regulation changes affect without becoming defense by definition

File `11` already distinguishes regulation from defense.

A person may lawfully:

- reappraise an event;
- direct attention elsewhere;
- seek reassurance;
- breathe/slow down;
- choose distance;
- seek social support;
- suppress expression;
- accept the feeling without acting on it;
- reinterpret future consequence;
- deliberately expose themselves to a feared but valued situation.

These can change:

- felt intensity;
- duration;
- focality;
- action tendency;
- interpretation;
- expression.

But regulation can fail, partially succeed, rebound, or create new affect.

Therefore:

`REGULATED_AFFECT != ERASED_AFFECT`.

`EXPRESSION_SUPPRESSION != INTERNAL_AFFECT_REDUCTION`.

`SUCCESSFUL_REGULATION != DEFENSIVE_DISTORTION`.

No single regulation coefficient is authorized.

## 19. Affect can alter appraisal as well as result from it

The relation is not necessarily one-way.

A currently active affective state can change which ambiguous readings become recruitable.

Examples:

- fear increases threat-consistent interpretation;
- shame increases sensitivity to judgment;
- attraction increases attention to reciprocation cues;
- anger increases accessibility of obstruction/violation readings;
- grief increases relevance of loss-linked memories;
- relief may reopen alternative interpretations.

Therefore a more realistic conceptual loop is possible:

```text
APPRAISAL
-> AFFECTIVE CONSEQUENCE
-> ALTERED ATTENTION / RECRUITMENT / EXPECTATION
-> NEW APPRAISAL
```

This is explanatory prose only, not a runtime loop specification.

Hard law:

`AFFECT_CAN_PARTICIPATE_IN_FUTURE_APPRAISAL`.

## 20. Affect and motivational priority interact without collapsing

File `62` banks `PREFERENTIAL_CONCERN_CLAIM` as a connective relation.

That relation can shape affect by altering which meanings obtain motivational access.

Example:

The same ambiguous group cue may more readily become:

- belonging threat for one person;
- autonomy threat for another;
- recognition opportunity for another;
- epistemic uncertainty for another.

Those appraisals can recruit different affective organizations.

But affect can also override ordinary priority under sufficiently strong events.

Therefore:

`MOTIVATIONAL_PRIORITY MAY BIAS AFFECTIVE RECRUITMENT`.

`CURRENT_AFFECT MAY TEMPORARILY REORDER CONCERN PRIORITY`.

Neither is reducible to the other.

## 21. Affect and attractor organization interact without making emotion a type

Files `54-57` establish recurrent problem/pursuit/frustration organizations, attractor gravity, and secondary participation.

A recurrent attractor can make some affective transitions easier to enter or harder to leave.

Examples might include repeated:

- shame -> overperformance;
- fear -> reassurance-seeking -> shame;
- anger -> control -> counter-resistance;
- grief -> withdrawal -> isolation;
- attraction -> exposure fear -> coolness;

when supported by generated history.

But Rawlsing should reject:

`TYPE -> EMOTION_PROFILE`.

The same recurrent organization can produce different affective episodes under different contexts, and similar affect can arise from different organizations.

Equifinality and multifinality remain controlling.

---

## 22. Social and dyadic affect must preserve actor-locality

Affect is often relationally recruited, but one actor's state must not become reciprocal relationship truth.

Examples:

- A feels intimate; B may not;
- A feels betrayed; B may not recognize any shared commitment;
- A is attracted; B may be neutral;
- A feels judged; B may not be judging;
- A feels safe; the situation may still contain objective risk;
- A feels unsafe; B may not intend harm.

Therefore:

`A_AFFECT_ABOUT_B != B_AFFECT_ABOUT_A`.

`A_FEELS_RELATIONSHIP_X != OBJECTIVE_RELATIONSHIP_IS_X`.

Dyadic exchange can nevertheless alter each actor's affective configuration through reciprocal interaction.

---

## 23. Culture and biography may shape affect concepts without demographic psychologizing

Rawlsing's PRE-V3 -> V3 bridge forbids demographic profile -> psychology shortcuts.

That remains controlling here.

Culture, institutions, family practice, language, social role, and biography may shape:

- what situations are appraised as threatening/honorable/shameful;
- which affect words are available;
- what expression is permitted;
- how self-evaluation is organized;
- which forms of regulation are practiced;
- which affective consequences become sensitized over time.

But:

`DEMOGRAPHIC_CATEGORY -/-> EMOTION_PROFILE`.

`CULTURAL_CONTEXT != FIXED_AFFECT_SCRIPT`.

The generated person's affective organization must be earned through lawful world-position, encounter, uptake, history, and person-specific metabolism.

---

## 24. Emotion labels may be useful summaries but must remain decomposable in explanation

Rawlsing need not ban emotion words.

They are valuable because humans use them and because they can compress recurring organizations.

But when causally important, a label should be explainable through the richer relation network rather than treated as an atomic oracle.

For example, an `anger` summary may be supported by some configuration involving:

- a target;
- an appraisal of obstruction/violation/status injury;
- high or low urgency;
- bodily/felt activation;
- confrontation or boundary pressure;
- competing attachment concern;
- conscious recognition or defensive relabeling;
- residue from earlier turns;
- inhibited or transformed expression.

Not every anger episode needs every relation.

The point is:

`EMOTION_LABEL = COMPRESSIVE HANDLE`

not:

`EMOTION_LABEL = SUFFICIENT INTERNAL CAUSAL DESCRIPTION`.

## 25. Candidate minimum affect-semantics dimensions — semantic only

Architecture later should test whether existing Rawlsing relations can jointly preserve at least these questions when relevant:

1. **Trigger/basis:** what occurrence, memory, anticipation, body state, or internally generated content participated?
2. **Actor appraisal:** what did it mean to this person?
3. **Target/object/scope:** toward/about whom or what is the affect organized?
4. **Valence relation:** desirable, aversive, mixed, ambiguous, or changing?
5. **Felt/bodily quality:** what nonpropositional experience is present, if any?
6. **Activation/urgency:** how strongly does it press now, without equating that with control?
7. **Action orientation:** what forms of approach, withdrawal, confrontation, repair, concealment, monitoring, or inhibition become easier?
8. **Need/motive relation:** what concerns, strivings, or preferential concern claims participate?
9. **Conscious accessibility:** hidden, felt-but-unnamed, named, self-attributed, or causally understood?
10. **Competing affect:** what other affective organizations remain active?
11. **Regulation/defense:** what transforms access, interpretation, intensity, or expression?
12. **Temporal status:** continuing, residual, sensitized, rebounding, anticipated, or newly recruited?
13. **Expression consequence:** what lawful surface-level pressures/prohibitions follow without revealing hidden causes?
14. **Epistemic provenance:** which parts are actor-known, system-inferred, or merely candidate interpretation?

These are **questions architecture must be able to answer**, not a required fourteen-field object.

## 27. Synthetic-person test obligations

The semantic remainder earns its keep only if it improves generated personhood under courts like these.

### Test A — same valence, different affective meaning

Two negative episodes of equal rough unpleasantness produce distinct organization because one is shame/exposure and one is grief/loss.

### Test B — same appraisal, different person-specific affect

Two actors interpret the same event similarly but recruit different affective consequences because of history, self-model, needs, relationship meaning, or current condition.

### Test C — same affect label, different causal organization

Two actors both report `I am angry`, but one anger is primarily obstruction/boundary pressure and the other is defensive transformation of shame.

### Test D — hidden affect / conscious substitute

A causal affective organization influences attention and expression while the actor consciously reports a different state.

### Test E — mixed affect without averaging

Love + resentment or grief + relief remains simultaneously strong rather than becoming neutral.

### Test F — action non-determinism

Strong fear does not force withdrawal; strong anger does not force confrontation; attraction does not force approach.

### Test G — temporal residue

A consciously ended affect leaves altered readiness or interpretation without being represented as a decaying copy of the original emotion.

### Test H — prospective affect

A feared or hoped-for future changes current psyche before the event occurs without being treated as objective fact.

### Test I — relational asymmetry

A's felt intimacy, shame, attraction, or betrayal does not become B's state or reciprocal relationship truth.

### Test J — actor vocabulary difference

Two persons with similar nonpropositional affective consequences may label or understand them differently without the machine erasing that difference.

### Test K — regulation versus erasure

A person successfully suppresses expression or redirects attention while underlying affect remains causally relevant.

### Test L — culture without stereotype

Cultural/biographical history shapes appraisal and affect expression through actual generated history, not demographic payload.

If a proposed architecture cannot pass these courts without an emotion enum doing unexplained causal work, it has not preserved the semantic remainder.
