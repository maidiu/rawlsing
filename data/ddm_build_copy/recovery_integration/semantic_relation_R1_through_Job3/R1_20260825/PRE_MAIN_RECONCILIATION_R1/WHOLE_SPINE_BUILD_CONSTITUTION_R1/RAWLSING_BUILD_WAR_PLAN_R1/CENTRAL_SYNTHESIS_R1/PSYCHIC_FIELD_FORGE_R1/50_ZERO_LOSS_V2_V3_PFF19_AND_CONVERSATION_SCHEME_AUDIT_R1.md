## 4. Historical V2 grains outside any one original priority

### 4.1 Coherent selectivity / partial reception

Preserved in `48` and `49` as actor uptake plus situated recruitment.

`MAXIMAL_MACHINE_COMPREHENSION != MAXIMAL_ACTOR_RECEPTION`.

`PARTIAL_RECEPTION != RANDOM_DEGRADATION`.

### 4.2 Anti-assistant posture

Historical V2 explicitly rejected comprehensive service completion, perfect attunement and smooth all-thread coverage.

This survives as a #20 success/failure criterion and renderer anti-rescue law.

But it must not become a crude instruction to be unhelpful.

`ANTI_ASSISTANT_POSTURE != RANDOM_NONRESPONSIVENESS`.

It means the generated person responds from their lawful subjectivity rather than optimizing semantic completion as a service agent.

### 4.3 Effort / capacity / conversational fatigue — elevated by this audit

Historical V2 explicitly included:

- conversational fatigue;
- limited effort;
- attention filtering;
- non-full response coverage.

`48` preserved this as `effort/attention budget`, but later uptake work could make partial response look too exclusively like **perception/appraisal selection**.

A person may instead:

- understand several threads;
- recognize them correctly;
- care about several of them;
- yet have limited willingness, energy, attention or communicative effort for responding to all of them.

Therefore preserve:

`ACTOR_UPTAKE != RESPONSE_COVERAGE_CAPACITY`.

`SALIENCE != EFFORT`.

`EFFORT != DEFENSE`.

`EFFORT != INTEREST`.

`UNDERSTOOD_BUT_NOT_WORTH_RESPONDING_TO = LAWFUL`.

`UNDERSTOOD_BUT_TOO_TIRED_OR_OVERLOADED_TO_ELABORATE = LAWFUL_WHERE_GROUNDED`.

Existing PFF #9/#13 and downstream V2 boundary/face-risk/effort/attention jurisdictions are the likely home; no new effort subsystem is justified here.

### 4.4 Imperfect speech compression / reality-smelling jaggedness — elevated by this audit

Historical V2 wanted responses that could be incomplete, uneven, digressive, oddly focused or slightly off because humans compress thought imperfectly.

The correct modern preservation is:

`JAGGEDNESS = CONSEQUENCE_OF_PERSON + CURRENT_STATE + EFFORT + DEFENSE + INTENTION + RENDER_REALIZATION`.

Not:

`JAGGEDNESS = RANDOM_STYLE_NOISE`.

A fluent renderer must not polish away every lawful incompleteness, hesitation, asymmetry or compression.

But the system also must not inject grammatical damage or confusion solely to seem human.

### 4.5 EnergeticField / ActiveStream

Preserved as phenomena, not resurrected objects:

- live B-state;
- residue/hysteresis;
- recurring topic gravity;
- unresolved social hypotheses;
- relationship-specific readiness.

`ACTIVE_STREAM != HIDDEN_PSYCHIC_TRUTH`.

`TOPIC_GRAVITY != DURABLE_MEMORY_OR_CONCERN`.

### 4.6 Relationship memory

Correctly decomposed into:

- V3 durable relationship facts/history where admitted;
- actor-local memory/view where governed;
- PFF fast relation-specific live state;
- session transcript/shared references.

Callbacks and familiarity do not by themselves manufacture durable trust/intimacy truth.

### 4.7 Transcript/render audit — elevated by this audit

Historical V2/Dva preserved transcript/render audit as a useful boundary.

Combined with current V3 replay/provenance, later architecture must make it possible to answer questions such as:

- which observable user material entered machine-side interpretation;
- which actor-specific meanings/recruitments became operative;
- which content was actor-accessible;
- what bounded expression constraints reached V2;
- what the renderer introduced as surface variation;
- what was actually emitted;
- whether omitted/system-only nuance was illegally restored by rendering.

This is not actor-visible psychology.

It is validation/replay infrastructure.

`AUDIT_TRACE != ACTOR_SELF_KNOWLEDGE`.

### 4.8 Detailed discourse binding

The originating vision preserved magnitude/intensity, direction, confidence, target, participant role, discourse scope, temporal scope, relational scope, ambiguity and multiplicity as potentially non-collapsible dimensions.

Later work has preserved the semantic burden without freezing numeric coordinates.

Especially retain:

`INTENSITY != CONFIDENCE`.

`TARGET_BINDING_MUST_SURVIVE_TRANSFORMATION`.

`QUOTED_OR_REPORTED_CONTENT != DIRECT_USER_COMMITMENT`.

`MULTIPLE_READINGS_MAY_REMAIN_CAUSAL`.

### 4.9 Renderer discourse re-entry

Still required.

The renderer needs actual surface discourse to answer coherently, but `49` adds the critical anti-rescue complement:

`SURFACE_RE_GROUNDING != PERMISSION_TO_RESTORE_ANALYST_COMPREHENSION`.

### 4.10 Whole person outside prompt

Still binding.

`WHOLE_PERSON != PROMPT`.

A prompt/context packet is a bounded working cache over canonical personhood, not the source of the person's existence.

CAN-008's independent causal streams, path dependence and transform grammar strongly align with PFF nonlinear conflict.

Retain:

- simultaneous contradictory influence;
- no compulsory winner;
- no automatic cancellation;
- no default arithmetic psyche.

### 5.8 Valid-empty / rollback / integrity

Later architecture sharing CAN-008-like response semantics must not lose:

- valid-empty outcomes;
- fail-closed unbound semantics;
- atomicity/rollback where durable targets are affected;
- exact causal parentage;

### 5.9 Durable V3 owners remain owners

- CAN-010 need/expectation/striving semantics;

- CAN-012 durable rupture/metabolization;
- ADP-016 memory;

### 5.10 Parent/co-parent / genealogy possibility remains secondary

Historical V3 preserved:

`Parent1 + Parent2 independent development -> encounter -> relationship -> household -> ChildGenerated -> child development`.

`GENERATED_PERSON <-> USER`.

## 9. Additional #20 synthetic-personhood obligations added by this audit

In addition to the obligations in `47`–`49`, #20 must test:

### 9.1 Valid low-significance / no-effect behavior

A real person is not deeply moved by every message.

Failure:

- every turn produces a psychologically rich event;
- every ambiguity activates a wound;
- every topic triggers a memory;
- every interaction advances intimacy/conflict.

Required possibility:

`NOT_MUCH_HAPPENS` for lawful person-specific reasons.

### 9.2 Effort-limited but correctly understood response

The actor may understand several threads and still answer only one because of:

- fatigue;
- overload;
- boredom;
- low willingness;
- competing priorities;
- limited current communicative effort.

This must be distinguishable from misreading, defense and lack of comprehension.

### 9.3 Imperfect compression without manufactured confusion

Surface response may be:

- terse;
- overlong;
- digressive;
- compressed;
- uneven;
- strangely selective;

when grounded in person/current state.

Random degradation to create a human aesthetic fails.

### 9.4 Session continuity without off-screen biography

Test:

- callbacks;
- reinforced boundaries;
- avoided topics;
- changed expectation of user;
- tone drift/familiarity;
- live trust/guardedness candidate;

without inventing unseen days, jobs, relationships or aging.

### 9.5 Auditability of renderer anti-rescue

A successful run must make it possible later to determine whether the renderer:

- lawfully realized actor-bounded expression;
- or reintroduced omitted machine-level comprehension.

### 9.6 Valid-empty durable return

A strong interaction need not become durable V3 change.

Repeated transcript/session presence is not itself proof of durable relationship, belief, memory or attractor change.
