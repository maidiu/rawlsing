## 2. Top retained mechanisms

### A. Focus-organized counterpart formation

Feld supplies the clearest positive answer to why an actor repeatedly encounters one social set rather than another:

`ORGANIZED SETTING / ACTIVITY FOCUS -> RECURRENT CO-PRESENCE / INTERACTION POSSIBILITY -> COUNTERPART SET / POSSIBLE TIE FORMATION`

This is distinct from merely storing an interaction topology.

### B. Bridge/brokerage-conditioned information and opportunity

Granovetter and Burt jointly show why network ties differ causally:

`CROSS-CIRCLE BRIDGE / BROKERAGE POSITION + ACTUAL CHANNEL OR BROKER ACTION -> NONREDUNDANT INFORMATION / OPTION VISIBILITY / TRANSLATION OPPORTUNITY`

Binding ceilings: weak ties are not automatically bridges; networks do not act by themselves.

### C. Closure-conditioned obligation, sanction and support

Coleman is retained only after decomposition:

`NETWORK CONFIGURATION -> OBSERVABILITY / REPUTATION / OBLIGATION / INFORMATION / SANCTION / ORGANIZED SUPPORT FEASIBILITY`

No generic scalar “social capital” is required.

### D. Role-set expectation/sanction ecology

Merton prevents `STATUS -> ROLE EFFECT` compression:

`STATUS -> MULTIPLE COUNTERPART-SPECIFIC EXPECTATIONS / POWERS / SANCTIONS / CONFLICTS -> ACTOR-RELATIVE OBLIGATION AND MANEUVER SPACE`

### E. Classification/mark-conditioned institutional gate treatment

Bertrand–Mullainathan, Pager, and Correll–Benard–Paik provide strong experimental/audit evidence for a mechanism Rawlsing should represent without demographic psychological priors:

`CLASSIFICATION CUE OR PRIOR INSTITUTIONAL MARK + SPECIFIC GATE -> REALIZED EVALUATOR/GATEKEEPER TREATMENT -> DIFFERENTIAL OPPORTUNITY / CONSTRAINT`

Pager adds the path-dependent form:

`PRIOR INSTITUTIONAL HISTORY -> CARRIED MARK -> LATER INSTITUTIONAL GATE TREATMENT`.

### F. Cross-setting indirect transduction

Bronfenbrenner is retained for the explicit causal-route requirement, not ecological labels:

`EXTERNAL SETTING EVENT/CONDITION -> LINKED PERSON/RESOURCE/SCHEDULE/POLICY -> ACTOR'S IMMEDIATE ACTIVITY/RELATION ECOLOGY -> REALIZED HISTORY -> DEVELOPMENT IF EARNED`

### G. Temporally situated agency and reciprocity

Emirbayer & Mische provide a non-trait grammar for concrete action under constraint: past-pattern iteration, future projection and present practical evaluation. Sewell adds a bounded reciprocal mechanism: unequal resources plus schema mobilization/transposition can sometimes reproduce or alter relations.

No unconstrained “agency” module is licensed.

## 5. Temporal-form return

T6 confirms that one generic “exposure” form is insufficient.

- **EVENT:** gate decision, sanction, information transfer, discrete encounter.
- **CONDITION:** persistent eligibility, closure, role-monitoring or resource/schedule condition.
- **RELATION:** tie, obligation, role-set or brokerage relation.
- **RECURRENT ACTIVITY/PRACTICE:** repeated co-participation, brokerage, support exchange, compliance/resistance.
- **TRANSITION:** role/organization entry/exit, acquisition of an institutionally carried mark, successful gate crossing.
- **TRAJECTORY:** ordered sequence of gates, role/activity histories, evolving networks.
- **TURNING POINT:** realized transition/action that redirects later ecology; not merely a large event.
- **CUMULATIVE PROCESS:** repeated differential treatment, support/sanction, or network opportunity that changes later exposure chances.
