## 1. Governing separation

This court separates three questions that must not be collapsed:

1. Is the objective social consequence a lawful `D1'` fact?
2. Is there a current lawful carrier/ingress path by which that fact can be presented to V3?
3. What does the person phenomenally take up, appraise, recruit or do with it?

R3 owns only question 1. Current CAN-008 R2 and neighboring V3/PFF owners govern question 3 and bounded portions of question 2. OBL062 records the unresolved two-ended non-event ingress seam.

## 2. Event-shaped ingress

A consequence that is genuinely event-shaped may use existing event/encounter/OEE/CAN-008 paths only where the exact carrier contract and authority are satisfied. The fact that an objective consequence could be narrated as an event is not enough.

Examples that may be event-shaped when exact source evidence exists:

- a dismissal decision is issued;
- a benefit payment arrives;
- a gate decision is rendered;
- a counterpart provides a discrete material/informational transfer;
- a competent institution authors a new external response to an actor's action.

Even here:

```text
D1' REALIZATION != PHENOMENAL UPTAKE
EVENT RECEIVABILITY != APPRAISAL
APPRAISAL != RESPONSE
RESPONSE != DURABLE DEVELOPMENT
```

## 3. Mandatory non-event firewall

The following forms must **not** be laundered into fake events solely to obtain V3 ingress:

- continuing material conditions;
- authority/obligation relations;
- counterpart relations and reachability states;
- recurrent organized activities;
- persistent resource dependency/security states;
- continuing institutional classifications or treatment states;
- objective-social-history states whose relevance persists without a new occurrence.

`NON-EVENT V3 INGRESS VERDICT: PASS__R3_CORRECTLY_REFUSES_EVENT_LAUNDERING`

The semantic fact may be lawful at D1' while its downstream current ingestion route is not yet proved. That is an interface dependency, not permission to broaden D1' and not evidence that the fact must be deleted.

## 5. Cross-person psychology firewall

A private psychological state of actor A does not become an objective social fact of actor B.

Forbidden shortcut:

```text
A.private_distress / belief / motive / trait
→ B.objective_resource_task_authority_channel_fact
```

Lawful route requires an externally admitted social/world fact:

```text
A externalizes action / withdrawal / communication / provision / absence
+ competent source admits that external state/action
+ exact A↔B relation / obligation / task-allocation / resource rule applies
+ required realization evidence exists
→ B objective consequence may be derived
```

Thus hidden distress that never externalizes cannot increase another household member's objective task load. Observed withdrawal from tasks can, if the task-allocation rule and witness support the shift.

`CROSS-PERSON/HISTORY FIREWALL VERDICT: PASS`.

## 6. Objective social history firewall

R3 lawfully admits prior **external** social/world history such as:

- prior position;
- prior resource/receipt state;
- recorded relation;
- admitted transition;
- prior externally realized activity/contact;
- rule/configuration validity history.

It must not admit private belief, motive, appraisal, distress, trait, self-model, private capacity or private memory as objective-social-history input.

A prior external transition may remain relevant history after it ceases to be an active current condition. Historical relevance does not by itself reactivate the old consequence.

Verdict: `PASS__EXTERNAL_HISTORY_ONLY`.

## 7. P2/P3 autonomy-control court

`P2` owns exact directed authority/control/obligation/responsibility/sanction relations.

`P3` owns exact organized task/activity/time facts: task content, complexity, routinization, recurrence, duration, scheduling, intensity and finite-time competition.

Therefore:

- managerial title != actual P2 authority scope;
- occupation title != P3 task organization;
- formal discretion != exercised autonomy;
- exercised autonomy requires an actual control/decision scope plus participation in the relevant task/activity, under adequate realization evidence.

`P2/P3 VERDICT: PASS__DISTINCT_AND_COMPOSABLE`.

## 8. P4 classification/treatment court

The mandatory P4 ladder is:

```text
INSTITUTIONAL RULE
!= RULE APPLICABILITY
!= GATE ENCOUNTER / APPLICATION
!= ATTRIBUTE PRESENTATION / RECOGNITION
!= EVALUATION / DECISION / TREATMENT
!= DOWNSTREAM RESOURCE / AUTHORITY / TASK / CHANNEL CONSEQUENCE
```

A stigmatized or categorized attribute that no relevant institution/counterpart recognizes and acts on cannot generate a P4 treatment fact. A recognized classification that actually alters an admission/evaluation/treatment decision can, with a competent treatment witness.

`P4 VERDICT: PASS__RULE_BOUND_GATE_TREATMENT_ONLY`.

## 9. Stochastic / population truth court

A source report such as `40% probability of denial` is group/population evidence. It is not the current actor's denial outcome.

Where the world/institution is stochastic, the competent world/institution owner must issue an actor-specific external result. Only that issued result can support D1' realization.

`STOCHASTIC/POPULATION VERDICT: PASS__GROUP_RATE_NEVER_ACTOR_OUTCOME`.

## 10. Phase / age court

Age, developmental phase and historical timing may constrain applicability, rule/configuration validity and sequence. They do not directly generate psychological or developmental conclusions.

A turning point is derived from an admitted transition plus its later course/history; it is not a primitive actor consequence.

`PHASE/AGE VERDICT: PASS__QUALIFIER_NOT_MECHANISM`.

## 11. Objective strain/support boundary

Objective finite-time load, material scarcity/security, obligations, task burden, channel availability and actual provision can be D1' facts through P1-P5.

Felt strain, mastery, perceived support, appraisal, meaning and coping are downstream person-side matters.

A support tie != reachable counterpart != actual assistance != perceived support.

Verdict: `PASS__OBJECTIVE_ANTECEDENT_AND_SUBJECTIVE_METABOLISM_REMAIN_SEPARATE`.

## 12. World-write reciprocity court

There is no direct person/V3-to-structure write.

Lawful loop:

```text
V3/person action or intention
→ externally admitted action if one actually occurs
→ competent counterpart/institution/world response
→ competent source authors the new external fact
→ structural/social admission where the fact has that meaning
→ invalidation / lifecycle update / rule rerun
→ possible new D1' consequence
```

An intention alone is not a world change. An externalized action alone is not the counterpart's response. A response is not structural truth until a competent source/owner admits it under the relevant schema.

`WORLD-WRITE VERDICT: PASS__RECIPROCAL_LOOP_REQUIRES_NEW_EXTERNAL_SOURCE_FACT`.
