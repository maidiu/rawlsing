## 0. Purpose

This file preserves the current PFF design synthesis concerning the Enneagram, especially type, wing, Levels of Development / health, instinctual variation, dynamic movement, defense, relational organization, and Core Dynamics.

The governing intent is **not** to add an Enneagram subsystem to Rawlsing.

The governing intent is:

> Use the Enneagram as a mature source of internal psychological logic so Rawlsing does not have to invent every theory of personality organization, defensive dynamics, developmental condition, relational response, and self-reinforcing pattern from scratch.

The Enneagram material is therefore treated as:

- design evidence;
- conceptual prior;
- hypothesis generator;
- source of distinctions;
- source of candidate causal/dynamical relations;
- source of negative lessons about flattening personality into labels;
- source of testable pre-architecture questions.

It is **not** treated as:

- project-current semantic authority;
- a type classifier;
- a runtime lookup table;
- a response-style generator;
- a causal shortcut around V3;
- a substitute for actor history;
- a justification for deterministic type assignment;
- a reason to introduce new machinery when existing V3/PFF/V2 structure can express the same phenomenon more directly.

This bank must be read together with:

- `00_VISION_BANK_R1.md`;
- `04_ZERO_LOSS_CONVERSATIONAL_VISION_APPENDIX_R1.md`;
- current V3 developmental / attractor / memory / accessibility authority;

## 3. Central holding

The current best PFF interpretation is:

> The most valuable Enneagram contribution is not a set of labels. It is a theory of recurring internal organization, variable developmental condition, characteristic defensive capture, relational recruitment, frustration response, and movement between more flexible and more constricted modes.

The target Rawlsing outcome is therefore not:

`V3 -> ENNEAGRAM ENGINE -> PFF -> V2`

The target is closer to:

`ENNEAGRAM SOURCE THEORY`
`-> extract useful distinctions / causal hypotheses / negative laws`
`-> improve V3 semantics where V3 already owns the phenomenon`
`-> improve PFF live-mediation semantics where PFF owns the phenomenon`
`-> improve V2 expression semantics where V2 owns the phenomenon`
`-> disappear as separate machinery wherever possible`

The strongest success case may be that no Enneagram runtime component remains at all, while Rawlsing's native person model becomes substantially more psychologically coherent because the source theory helped clarify its internal logic.

## 4. Core anti-gadget law

For every Enneagram construct, apply this order:

1. Translate the named construct into a **phenomenon claim** with type numbers/names removed.
2. Map the phenomenon onto current V3, PFF, and V2 concepts.
3. Determine whether Rawlsing already has the required state but lacks a relation, distinction, or transition law.
4. Determine whether Rawlsing already has the relation but lacks a useful interpretation or test.
5. Identify the smallest semantic remainder not representable by existing machinery.
6. Only if a true representational remainder survives may a new construct be proposed.

Formal planning law:

`ENNEAGRAM_CONSTRUCT`
`-> PHENOMENON_CLAIM`
`-> EXISTING_RAWLSING_COVERAGE`
`-> MISSING_DISTINCTION_OR_RELATION?`
`-> TRUE_REPRESENTATIONAL_GAP?`
`-> ONLY_THEN_NEW_MACHINERY`

Burden of proof:

`NEW_GADGET_REQUIRES_DEMONSTRATED_REMAINDER`

## 5. Three contribution classes

All findings should be classified as one of:

### A. `ALREADY_PRESENT__BETTER_NAME_OR_DISTINCTION`

The Enneagram sharpens a distinction Rawlsing substantially already possesses.

Expected effect: documentation, constitution, test coverage, or clearer ownership. No new state object required.

### B. `ALREADY_PRESENT__RELATION_MISSING`

Rawlsing already possesses the nouns but has not yet constituted the relation among them.

Expected effect: transition law, dependency, invariant, interaction rule, or responsibility clarification. Usually no new layer.

### C. `TRUE_SEMANTIC_REMAINDER`

A psychologically relevant phenomenon cannot be represented by existing V3/PFF/V2 state and relations without distortion.

Expected effect: bounded proposal for a new native Rawlsing concept. Enneagram naming is optional and generally disfavored unless the object is specifically an interpretation artifact.

## 7. Family 2 — wing as persistent secondary organization

### 7.1 Source-theory intuition

Wing is not merely decorative flavor. The source theory treats it as a secondary neighboring organization that can complement, counterbalance, intensify, or otherwise materially alter the primary pattern.

It also allows variation in wing strength and suggests the wing may itself manifest at different developmental conditions.

### 7.2 Rawlsing-native translation

Candidate phenomenon claim:

> A developed person may contain a stable secondary recurrent organization that participates in the realization of a stronger primary attractor, without becoming a second complete personality and without being reducible to a transient current-state fluctuation.

### 7.3 Existing Rawlsing coverage

Potentially already covered by:

- competing/coexisting attractor evidence;
- contradictory middle-state mediators;
- multiple persistent tensions/practices;
- multi-prong disposition topology;
- relationship-specific recruitment of different parts of the person.

### 7.4 Key unresolved question

Does V3 already represent **persistent secondary attractor participation** cleanly, or does it currently tend toward premature winner-selection / one-attractor compression?

### 7.5 Provisional disposition

`WING = LIKELY_EXISTING_MULTIPLICITY_PLUS_POSSIBLE_SMALL_SEMANTIC_REMAINDER`

Do not create `WingState` unless V3 cannot otherwise preserve stable secondary organization.

## 8. Family 3 — Levels of Development / health / bandwidth / center of gravity

### 8.1 Source-theory intuition

The nine Levels are not merely nine values of goodness/badness.

They function as an ordered developmental continuum within the same personality organization, involving changes in:

- identification;
- flexibility/freedom;
- defensive constriction;
- motivations;
- interpersonal orientation;
- self-awareness;
- automaticity/compulsion;
- access to broader capacities;
- progression toward increasingly painful or disorganized states.

The source theory further distinguishes:

- momentary condition;
- a commonly traversed bandwidth;
- a slower-moving center of gravity.

Mood is not identical to developmental Level.

### 8.2 Rawlsing-native translation

Potentially important distinction:

`ATTRACTOR_IDENTITY != ATTRACTOR_CONDITION`

`DURABLE_ATTRACTOR_CONDITION != CURRENT_PFF_RECRUITMENT`

`CURRENT_PFF_RECRUITMENT != MOOD`

`CENTER_OF_GRAVITY != MOMENTARY_EXCURSION`

### 8.3 Existing Rawlsing coverage

V3 already intends slow developmental evolution, reinforcement, destabilization, rupture/metabolization, and attractor trajectory.

PFF already requires:

- turn-ephemeral state;
- session-live state;
- multiple persistence timescales;
- hysteresis;
- suppression;
- rebound;
- nonlinear activation;
- relationship-specific recruitment.

### 8.4 Important possible conceptual gain

The source theory may give Rawlsing a useful distinction between:

1. **durable organizational condition** — the slower developmental regime in which an attractor usually operates;
2. **reachable bandwidth** — conditions the person can plausibly traverse without a durable transformation;
3. **relation-specific excursion** — a current dyad temporarily recruits a more constricted or more integrated portion of that range;
4. **mood/affect** — a separate immediate state.

### 8.5 Degree of attractor capture

High-value hypothesis for exploration:

> What the Levels partially encode may be the degree to which the person's characteristic attractor monopolizes perception, interpretation, motivation, and response.

Potential decomposable dimensions include:

- rigidity / flexibility;
- defensive recruitment speed;
- self-observation capacity;
- affect tolerance;
- perceptual distortion;
- motive monopolization;
- internal integration;
- compulsivity;
- corrective permeability / reality contact;
- relational reciprocity;
- rebound / hysteresis;
- self-model congruence.

These are hypotheses, not adopted axes.

### 8.6 Thresholds and regime changes

The source theory gives special significance to certain downward/upward transitions, including a characteristic temptation/lock-in and a remaining saving capacity.

Rawlsing should investigate whether the underlying truth is:

- nonlinear threshold crossing;
- self-reinforcing basin entry;
- direction-dependent hysteresis;
- residual recovery capacity;
- qualitative regime change rather than smooth scalar worsening.

### 8.7 Provisional disposition

`LEVELS = HIGH_VALUE_STRUCTURING_OF_EXISTING_V3_PLUS_PFF_TIMESCALE_AND_CAPTURE_CONCEPTS`

Do not adopt `health_level: 1..9` as a primitive unless later architecture proves it useful after decomposition.

## 12. Family 7 — attachment / frustration / rejection relational organization

### 12.1 Source-theory intuition

The source theory groups personality organization around different relational-affective problems involving attachment, frustration, and rejection.

### 12.2 PFF relevance

This intersects directly with the PFF requirement that the interlocutor is a specific relational object and that the same signal can be transformed differently by receiver history.

Candidate distinctions:

- **attachment problem:** preserving/obtaining connection with the relational object;
- **frustration problem:** the object/world fails to supply the needed quality or state;
- **rejection problem:** reaching toward the object is organized around anticipated rejection, depletion, harm, or exclusion.

### 12.3 Existing Rawlsing coverage

Already partly present in:

- attachment need;
- relationship history;
- expectations;
- memory/resonance;
- rejection sensitivity;
- attraction/aversion;
- receiver distortion;
- current relational activation.

### 12.4 Why this may be a true gain

Rawlsing may possess the ingredients without yet having a strong theory of **relational problem-form**: what kind of relational failure the actor's organization is trying to prevent, obtain, or manage.

This could improve:

- perception transforms;
- expectation violations;
- defense selection;
- dyadic chemistry;
- hidden interpersonal demands;
- relational escalation loops.

### 12.5 Provisional disposition

`RELATIONAL_AFFECT_ORGANIZATION = HIGH_PRIORITY_DECOMPOSITION__POSSIBLE_TRUE_CONCEPTUAL_GAIN__LIKELY_NOT_NEW_LAYER`

## 13. Family 8 — defenses, latent claims, and hidden complaints

### 13.1 Source-theory intuition

Defenses should not be treated as surface styles. They are configurations connecting:

- what threatens the organization;
- what the person cannot tolerate or acknowledge;
- how internal material is transformed or blocked;
- how the self-concept is protected;
- how the interpersonal field is manipulated or managed;
- what observable behavior results.

The source theory also includes the idea of latent/hidden interpersonal claims that can differ from the actor's consciously endorsed motive.

### 13.2 Direct PFF fit

PFF already requires:

- causal activation outside awareness;
- partial/mistaken self-interpretation;
- suppression;
- concealment;
- defensive transformation;
- posture/fronting/coyness/toughness/piety/status performance;
- leakage;
- hidden-cause quarantine;
- actor self-surprise.

### 13.3 Rawlsing-native defense questions

For any defense-like event, distinguish:

- what is being defended;
- against what;
- from whose perception;
- which activated material is suppressed or transformed;
- what substitute interpretation becomes consciously available;
- whether the actor knows the operation is happening;
- what behavioral/postural consequence is produced;
- what leaks despite the defense;
- whether the defense changes only PFF live state or later becomes durable V3 material.

### 13.4 Latent claim distinction

Preserve:

`CONSCIOUS_STATED_MOTIVE`
`!= LATENT_INTERPERSONAL_EXPECTATION_OR_CLAIM`
`!= MACHINE_CAUSAL_ACCOUNT`

Example form:

`"I am only helping"`
may coexist with an unrecognized interpersonal demand for appreciation, dependence, validation, or closeness.

### 13.5 Provisional disposition

`DEFENSE_AND_HIDDEN_CLAIM = STRONG_STITCH_INTO_EXISTING_PFF__LIKELY_RELATION_LAWS_NOT_NEW_GADGETS`

- how residual capacities can interrupt deterioration;

### 14.2 Rawlsing-native translation

### 14.3 Important caution on arrows

Do not adopt Enneagram diagram arrows as causal law merely because the source theory asserts them.

> under stress or increased integration, one recurrent organization may recruit capacities that resemble another recurrent organization, possibly while preserving some global condition such as constriction/flexibility.

This must be decomposed independently of the symbol.

## 15. Core Dynamics as a cross-cutting stitching device

The source theory's Core Dynamics are potentially more useful than its type descriptions because they try to explain why a characteristic pattern coheres.

The valuable form is roughly:

`FEAR / THREAT MODEL`
`-> DESIRE / NEEDED CONDITION`
`-> ATTITUDE / EXPECTATION`
`-> DEFENSE / STRATEGY`
`-> BEHAVIOR`
`-> INTERPERSONAL CONSEQUENCE`
`-> REINFORCEMENT OR CORRECTION`

Rawlsing already has richer native primitives and can potentially produce a more rigorous chain:

`generated history`
`-> need`
`-> expectation`
`-> striving`
`-> mediator / tension / practice`
`-> relational perception transform`
`-> live activation`
`-> conscious availability`
`-> self-interpretation`
`-> defense / inhibition / posture`
`-> expression trajectory`
`-> observable response`
`-> dyadic consequence`
`-> if causally admitted: V3 event / relationship / memory / expectation / attractor update`

The Enneagram's value here is primarily to reveal where Rawlsing may already have the nouns but insufficient connective theory.

`ENNEAGRAM_CORE_DYNAMICS = QUESTION_FOR_RAWLSING_CONNECTIVE_LOGIC__NOT_REQUIRED_RUNTIME_OBJECT`

## 16. Refinement of the four PFF depth bands

The Enneagram/Levels analysis suggests conceptual distinctions currently compressed inside the existing D/C/B/A scheme.

This does **not** adopt additional architecture layers.

### D — deep generated person

Potentially contains conceptually distinct:

- **D1 durable organization:** actual V3 history, attractor structure, wounds, needs, expectations, strivings, mediators, tensions, practices, relationship histories;
- **D2 durable organizational condition:** slower flexibility/capture/integration regime, reachable developmental bandwidth, persistent secondary organization if real.

### C — standing conscious self

Actor's relatively stable self-model, autobiographical interpretation, recognized motives, values, goals, ordinary sense of identity.

This may diverge materially from D1/D2.

### B — relation-specific live recruitment

Potentially contains conceptually distinct:

- **B1 recruitment:** which deep structures this interlocutor/situation activates;
- **B2 live organizational condition:** how open/constricted, mutually inhibiting, amplified, distorted, or defended those recruited structures become now.

### A — expression

Conscious choice, suppression, defense, posture, strategic presentation, involuntary leakage, and rendered behavior.

Preserve:

`DURABLE_ORGANIZATION`
`!= DURABLE_ORGANIZATIONAL_CONDITION`
`!= STANDING_SELF_MODEL`
`!= RELATION_SPECIFIC_RECRUITMENT`

## 17. RAW implication

This analysis increases the caution against turning PFF RAW into a duplicate personality database.

V3 owns the deep durable person.

A better conceptual possibility is that PFF live state primarily represents **activation/recruitment relations over V3-owned structures**, plus genuinely session-live state.

Candidate interpretation:

- V3 object A remains durable upstream;
- PFF records that A is strongly recruited now;
- V3 object B remains durable upstream;
- PFF records that B has become accessible/peripheral/suppressed;
- PFF records live relation between A and B, current inhibition, rebound, relational charge, defense, posture, leakage pressure, and current origin;
- the actor's conscious interpretation may attribute the resulting state to something else entirely.

Planning law:

`PFF_LIVE_STATE != SECOND_PERSONALITY_DATABASE`

`PFF_SHOULD_REFERENCE_OR_RECRUIT_V3_STATE_WHERE_POSSIBLE`
