## Additional adversarial cases

### A. Formal autonomy but no exercised autonomy

A job description says the actor has discretion, while supervisor behavior and workflow effectively remove it.

Required result: formal rule is structural possibility; actual exercised control relation/activity is actor-relative realized condition. Developmental consequences may be based only on the latter history.

`VERDICT: PASS`; proves need to separate formal authority from enacted authority.

### B. Weak tie with no useful information

Actor has a weak tie across circles but receives no relevant information.

Required result: bridge/brokerage position can create opportunity for nonredundant information; transfer is separate realization; use is separate actor mediation.

`VERDICT: PASS`; generic social-capital benefit rejected.

### C. Discriminatory classification cue but fair gatekeeper

Classification cue exists, but a particular gatekeeper does not discriminate.

Required result: classification changes neither opportunity nor biography absent realized differential treatment. Population audit evidence may influence possibility calibration but cannot mint actor treatment.

`VERDICT: PASS`; `CLASSIFICATION != TREATMENT`.

### D. Gate denial without actor awareness

Actor is filtered out before being told.

Required result: objective eligibility/treatment consequence can alter opportunity ecology despite actor misperception/nonknowledge; psychological uptake waits for actor-accessible experience where relevant.

`VERDICT: PASS`; objective and subjective paths remain separable.

### E. Parent loses job; child never directly observes event

Job loss changes household income, parental schedule/stress and child-care arrangements.

Required result: parent event propagates through typed linked-life/resource/time/care routes into child's ecology; no direct parent-event→child-trait edge.

`VERDICT: PASS_ONLY_WITH_MC13+MC16`.

### F. High-status actor trapped by debt/care obligation

Broad status suggests resources, but debt and linked care obligations sharply reduce exit/time options.

Required result: exact resource/dependency/obligation relations override coarse status tendency.

`VERDICT: PASS`; demonstrates why category priors are insufficient.

### G. Recurrent complex task ends before capacity stabilizes

Actor receives two weeks of complex autonomous work then leaves.

Required result: activity opportunity/realization recorded, but durable capacity change is not guaranteed; duration/quality/history reach V3 and existing durability rules decide.

`VERDICT: PASS`; no seam-level trait update.

### H. Collective action fails

Workers organize but employer/state blocks their demand.

Required result: collective action event/history is real; structural condition remains or changes only where an external response is causally admitted.

`VERDICT: PASS`; agency != success.

## Court-level attack on proposed architecture

A single monolithic `SOCIAL_ECOLOGY` score would fail nearly every case because it would erase relation type, counterpart, provenance, timing and realization status. A theory-name module would likewise fail because identical theoretical vocabulary can correspond to different executable routes.

The court therefore requires typed outputs while remaining neutral on whether implementation uses one generalized resolver or several existing carrier families.
