# M11 SRT EVIDENCE LIMITS AND NEGATIVE CEILINGS R1

STATUS: `EVIDENCE_CEILINGS_ENFORCED__ARCHITECTURE_NOT_ALLOWED_TO_OUTRUN_SOURCE`

## 1. Global source ceiling

This volume is primarily a **theoretical and historical-synthetic** collection. It is excellent for discovering what variables must be decomposed and for generating mechanism hypotheses. It is not a source of randomized or quasi-experimental identification for most claims, and it is not a general developmental-psychology evidence base.

## 2. Chapter-specific ceilings

| Chapter | Ceiling |
|---|---|
| Bhattacharya Intro | Totality/unitary-process claims may motivate decomposition; they do not identify actor-level effects. |
| Fraser | Macro “contradiction/crisis” is historical theory. Encode actual service cuts, debt, hours, wages, care transfers, migration rules—not the contradiction as operator. |
| Mohandesi/Teitelman | Historical sequences are rich secondary evidence. Do not infer one universal welfare/class-formation effect across periods/populations. |
| Bhattacharya Class | Relational class analysis blocks job-label essentialism. Strategic claims about class struggle do not create solidarity/mobilization facts. |
| McNally | Philosophical co-constitution/totality is not causal identification. Do not create `CO_CONSTITUTION` or retrocausal back-write. |
| Ferguson | Childhood/school/work relations structure activity ecology, not guaranteed psychological development. |
| Teeple Hopkins | Original qualitative evidence is narrow: 28 interviews overall, four domestic workers, two central vignettes. No prevalence/general-effect inference from Marie/Dawn. |
| Oran | Political-economy premises about surplus value/tax incidence are theoretical. Encode pension rules and resource flows independently of accepting those premises. |
| Sears | Embodiment/sexuality claims are theoretically mediated and often based on cited literatures; no gender/work→psychological/sexuality shortcut. |
| Arruzza | Political strategy and movement interpretation are not causal effect studies; mobilization must pass through an external response. |

## 4. Development ceiling

Only the following source-compatible chain is permitted:

```text
STRUCTURAL / INSTITUTIONAL / RELATIONAL FACT
-> ACTOR-RELATIVE RESOURCE / TIME / OBLIGATION / ACTIVITY / ACCESS / COUNTERPART ECOLOGY
-> REALIZED ACTIVITY / CONDITION / RELATION / EVENT
-> EXISTING V3 UPTAKE / LEARNING / MEMORY / PRACTICE PROCESS
-> DEVELOPMENTAL CHANGE IF EVIDENCE AND V3 LAW EARN IT
```

The SRT volume itself does not establish a generic law from care, class, schooling, migration, gender, race, or sexuality to durable psychological change.

## 5. Race/racialization ceiling

The source repeatedly supplies historically concrete mechanisms: exclusion of domestic/agricultural workers from social insurance; occupational segmentation; colonial dispossession; racialized policing/incarceration; migration/citizenship rules; differential wage/job allocation. Those are admissible when represented as rules/treatment. `RACE` as a person attribute is not the mechanism.

## 6. Gender ceiling

Likewise, gendered care/work patterns must pass through wage differentials, normative/legal rules, benefit design, household dependency, care infrastructure, employer allocation, or counterpart expectations. The source itself is strongest when it gives those mediators and weakest when it shifts directly from “women” to generic care or embodiment.

## 7. Causal-identification ceiling for collective change

Historical narratives can license **possible mechanism structure** and documented sequence. They generally cannot establish the unique causal effect of one movement on one policy without further design. D3 should preserve multiple possible contributors and authority provenance rather than assigning sole causation where the source does not.
