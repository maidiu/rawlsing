## 3. Source evidence versus downstream outcome evidence

Some of the strongest empirical sources in the corpus study downstream psychological or developmental outcomes. Their lawful S4 use is twofold:

1. they can show why preserving an objective exposure/activity/relation distinction matters; and
2. they can provide downstream evidence that a candidate pathway deserves study.

They do **not** redefine D1'.

Examples:

```text
KOHN: task/supervision condition -> downstream self-direction/flexibility evidence
MORTIMER: work-quality/time -> downstream adolescent outcome evidence
ELDER: deprivation/role/task pathway -> downstream life-course outcome evidence
LURIA: schooling/activity histories -> downstream task-performance differences
```

The D1' governed rule still ends before the downstream arrow.

## 4. Objective-social history admissibility

R4 lawfully permits prior **objective social history** as a D1' input when the current rule depends on it:

- prior position;
- prior institutional mark/record;
- prior entitlement/resource state;
- prior external relation;
- prior admitted transition;
- prior externally witnessed activity/contact;
- prior external rule/configuration state.

S4 source audit confirms this is needed by Pager-type institutional marks, Elder/Mortimer trajectories, linked lives and cumulative inequality.

Forbidden direct history inputs remain private V3 states:


If such a private state leads to an external action, D1' may consume only a separately authorized externalized action/result after a competent owner has authored it.

## 5. World-update boundary

The source corpus clearly supports reciprocal selection and action-mediated changes in later circumstances. That does not mean D1' should write structure.

Required boundary topology:

```text
V3 PERSON / ACTION
-> EXTERNALIZED ACTION OR EVENT UNDER COMPETENT OWNER
-> EXTERNAL COUNTERPART / INSTITUTION / WORLD RESPONSE
-> AUTHORIZED OBJECTIVE WORLD FACT OR EXPLICIT NO_CHANGE
-> LATER D1' INPUT
```

This preserves source-recognized agency/reciprocity without creating a second psychology or an ungoverned world writer.

## 8. Companion-law admission gates

A governed rule may not become source-authorized for executable D1' use unless all applicable gates pass:

1. **Source locator gate** — source and exact location when available are bound.
2. **Claim-status gate** — theory/qualitative/observational/longitudinal/experimental/review status is explicit.
3. **Identification gate** — design strength is explicit; observational evidence cannot masquerade as experiment.
4. **Mechanism gate** — normalized mechanism maps to P1–P5 without source-label black box.
5. **Input gate** — structural/world and actor/context/position facts are typed.
6. **Realization gate** — witness schema specifies what converts qualification to realized fact.
7. **Portability gate** — source scope and runtime scope are compatible or separate transport authority exists.
8. **Negative-ceiling gate** — forbidden inferences are machine/audit-visible.
9. **V3-stop gate** — objective consequence endpoint is explicit.
10. **Causal-use gate** — competent authority states whether the source evidence may support this executable rule; source prestige is insufficient.
11. **Calibration gate** — numeric coefficient/probability/threshold requires separate current calibration authority; absent calibration means no invented number.
12. **Currentness gate** — trace, governed rule, application inputs and realization evidence must each be current under their own owners.

Failure of gates 1–10 yields:

`UNLICENSED / NEEDS SEPARATE RULE AUTHORITY`.

Failure of gate 11 prohibits numeric production calibration but need not invalidate an otherwise lawfully admitted qualitative/constitutive rule.
