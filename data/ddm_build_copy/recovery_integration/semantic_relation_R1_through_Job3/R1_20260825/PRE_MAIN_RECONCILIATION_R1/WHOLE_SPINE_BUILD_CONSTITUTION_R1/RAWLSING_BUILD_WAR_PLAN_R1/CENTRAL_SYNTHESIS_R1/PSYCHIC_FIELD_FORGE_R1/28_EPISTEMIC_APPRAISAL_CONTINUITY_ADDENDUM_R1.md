## 0. Purpose

This file performs the continuity update required after `27_OBSERVATION_INTERPRETATION_EPISTEMOLOGY_DEEP_EXAMINATION_R1.md`.

It records how interaction epistemology changes the one-person V3/PFF model.

## 1. New central continuity requirement

The generated person should not be modeled as responding directly to system/analyst truth.

The likely general person-level chain is:

```text
LAWFUL OCCURRENCE / OBSERVABLE INPUT
-> ACTOR-PERCEIVABLE / ACTOR-AVAILABLE BASIS
-> ACTOR-SPECIFIC APPRAISAL / INTERPRETATION
-> RECRUITMENT / RESPONSE METABOLISM
-> FAST OR DURABLE CONSEQUENCE ACCORDING TO REGIME
```

This is relevant to both periodic V3 and interactive PFF.

## 2. Existing V3 capital already protects most epistemic boundaries

ADP-016/017 already separate:

- objective generated fact;
- causal memory;
- memory accessibility;
- actor epistemic stance;
- claim accessibility;
- first-person claim permission.

This means PFF does not need to create a duplicate knowledge/belief ontology.

The likely missing/shared layer is **event-time appraisal and current interpretation**, not another durable epistemic database.

## 3. Periodic V3 enrichment candidate

A future V3 developmental response should generally avoid:

`OBJECTIVE EVENT LABEL -> PSYCHIC EFFECT`.

Where perception/interpretation matters, it should instead be able to account for:

- what the actor can perceive;
- what they know/believe;
- what memories/mediators are relevant;
- what they expect;
- what the event means to them;
- uncertainty/misrecognition where generated.

This does not authorize one universal appraisal engine yet.

## 4. Interactive specialization remains stronger

PFF requires richer fast epistemics because the user is externally opaque and discourse is ambiguous.

Interaction-specialized elements include:

- pragmatic/discourse candidate readings;
- target/scope/quotation handling;
- user hidden-intention opacity;
- message-level ambiguity;
- actor model of user;
- metaperception;
- fast actor hypotheses;
- actor confidence distinct from system confidence;
- probing/testing expression.

These should not be generalized backward into V3 unless the same phenomenon exists in developmental events.

## 5. No single privileged message meaning

The continuity model now needs an explicit distinction between:

`SYSTEM EVIDENCE/INTERPRETATION`

and:

`ACTOR-SPECIFIC RECEIVED MEANING`.

The shared psychological transition should consume actor-specific received/appraised meaning rather than blindly consuming the encoder's preferred reading.

## 6. Causal provenance and actor self-understanding remain separate

The machine may know exactly which generated states/rules participated in a transition while the actor does not know why they reacted.

This is likely a general Rawlsing property, not chat-only.

Thus periodic V3 should also preserve:

`SYSTEM DEVELOPMENTAL CAUSAL ACCOUNT != ACTOR SELF-EXPLANATION`.

PFF makes this distinction visible because first-person rendering creates a severe leak risk.

## 7. Uncertainty preservation becomes shared design law

Uncertainty should not disappear merely because a candidate is consumed downstream.

General law:

`INFERENCE STATUS MUST SURVIVE CAUSAL USE`.

In PFF this prevents uncertain user-reading -> certain user fact.

In V3 it prevents uncertain actor interpretation/proposal -> objective or durable truth without authority.

## 8. Actor desire/history may alter actor interpretation, not external evidence

A person's motivations and history can change what they believe an event means.

That is psychologically causal in both regimes.

But:

`ACTOR BIAS / HOPE / FEAR != CHANGE TO OBJECTIVE EVIDENCE`.

This distinction should be preserved wherever person-specific appraisal is used.

## 9. Updated continuity classification

### Shared person logic strengthened

- actor-specific appraisal;
- uncertainty-aware interpretation;
- separation of observer truth and actor meaning;
- generated misrecognition without forced correction;
- response to actor-perceived meaning;
- hidden causal provenance distinct from conscious explanation.

### PFF-fast/interactions only

- discourse encoder;
- user-intention opacity semantics;
- metaperception of user;
- rapid user-model hypothesis;
- conversational scope/quotation/pragmatics;
- fast confidence/probing dynamics.

### Durable V3 ownership retained

- actor epistemic stance;
- durable memory/accessibility transitions;
- durable relationship history;
- objective generated event truth;
- durable self-belief changes.

## 11. Consequence for two-LLM intuition

The epistemic result supports separation of:

- LLM-assisted observable interaction interpretation;
- governed actor-specific metabolism;
- LLM surface rendering.

But the deep reason is epistemic jurisdiction, not a magic requirement that the number of calls be exactly two.

7. periodic V3 can use actor-specific appraisal where needed without duplicating PFF's discourse-specialized machinery.
