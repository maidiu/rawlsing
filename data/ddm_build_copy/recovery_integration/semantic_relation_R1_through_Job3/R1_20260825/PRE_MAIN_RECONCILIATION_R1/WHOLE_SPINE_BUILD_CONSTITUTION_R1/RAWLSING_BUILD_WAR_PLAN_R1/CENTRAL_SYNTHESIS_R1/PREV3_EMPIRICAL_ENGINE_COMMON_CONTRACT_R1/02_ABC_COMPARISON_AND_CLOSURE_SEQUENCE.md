1. `01_EMPIRICAL_ENGINE_COMMON_CONTRACT_R1.md` is the equal-work semantic denominator.
2. Every candidate must expose the same logical empirical/query/discovery/replay/learned-world interface.
3. Exact validators must be positively bound for the product families included in the comparison workload.
4. Exact named-source semantics/routing/universe/replay authority must be available for every empirical-universe cell included in the comparison.
5. Missing authority produces a typed excluded/blocked cell, not a candidate performance penalty.
6. WVS7 and LiTS remain distinct universes; they need not and must not be pooled merely for parity.
7. Candidate results must first pass semantic/result/receipt parity; only then are physical metrics interpreted.

## B. What may legitimately differ among A/B/C

Candidate implementations may differ in:

- eager vs virtual materialization;

## C. Production comparison workload

The final physical comparison should contain at least these workload classes where exact authority is available:

### W1 — named-source cold decode / logical incidence

For each proving universe:

- exact source bytes;
- exact decoder;
- exact semantic/routing bindings;
- same logical incidence/output identity;
- same acceptance oracle.

### W2 — exact query suite

Include representative:

- marginal;
- conditional;
- same-respondent joint;
- subgroup/branch-conditioned;
- higher-order/joint configuration;
- typed-empty/noncomparable/authority-limited cases.

### W3 — autonomous discovery

Use a frozen declared frontier with:

- identical candidate set/order;
- identical validator set;
- identical search/coverage law;
- identical output/receipt requirements;
- no route-specific pruning.

### W4 — repeated workload economics

Execute the same governed workload at least under:

- cold session N=1;
- repeated N=2;
- repeated N=5.

Measure whether persistent/hybrid decoded state actually amortizes cost.

### W5 — incremental invalidation

Repeat after exactly one controlled determinant changes:

- one source/release determinant;
- one semantic/routing authority determinant.

Measure invalidated dependency closure, bytes rewritten, and recomputation cost.

### W6 — delete/rebuild replay

Where a representation is claimed regenerable:

1. create accepted release/output;
2. record exact semantic/replay identities;
3. delete transformed/regenerable carrier;
4. rebuild from authoritative source + durable side material;
5. assert exact promised semantic identity/receipt parity.

### W7 — downstream serviceability

Prove that the route can satisfy the carrier-neutral interfaces needed by:

- DDM analytical work;
- Field Forge ingress;
- later positioned-subject empirical possibility service.

This is an interface/capability proof, not a requirement that the final positioned-subject inference model already be chosen.
