## 2. Exact jurisdiction of D1'

D1' answers one question only:

> Given admitted actor-independent social/structural facts plus this actor's exact position, context, time, relevant history and counterpart/institution bindings, what **objective actor-relative social consequence** follows, under which typed mechanism, with which realization status, validity and provenance?

It does **not** answer:

- what the consequence means to the actor;
- whether the actor notices it;
- whether it becomes a premise/reason;
- whether the actor accepts/resists it;
- what motive/expectation/striving it recruits;
- what response occurs;
- whether learning/memory/practice/personality changes;
- whether durable development results.

Those remain V3 jurisdictions.

Binding boundary:

```text
ACTOR_RELATIVE_OBJECTIVE_SOCIAL_FACT
!= SUBJECTIVE POSSIBILITY SPACE
!= SUBJECTIVE PREMISE
!= REASON/GROUND
!= APPRAISAL
!= RESPONSE
!= DURABLE DEVELOPMENT
```

CAN-008 R2 is now verified HQ-adopted current semantic authority for the bounded person×event receivability/uptake/appraisal/recruitment/immediate-response sequence. D1' may not shadow or duplicate it.

## 5. Full-book conformance requirements that survive normalization

The M1–M11 returns do not create new owners. They establish binding conformance requirements for D1' and its compositions.

### C1 — typed vector, never social scalar

From Mortimer/Kohn-Schooler/SRT:

```text
EMPLOYMENT != HOURS != WORK QUALITY != ACTIVITY HISTORY
JOB QUALITY is not a causal scalar
SOCIAL ECOLOGY is not a scalar
```

D1' emits independently typed objective facts.

### C2 — category must decompose before actor consequence

From Luria/Wright/Kohn-Słomczyński/SRT:

```text
CLASS / RACE / GENDER / RELIGION / COUNTRY / SYSTEM / POVERTY / OCCUPATION TITLE
-X-> ACTOR CONSEQUENCE OR PSYCHOLOGY
```

A source-coded category can contribute only after an exact relation/rule/mechanism is established.

### C3 — institutional configuration provenance is nonerasable when constitutive

From M7:

A mechanism may be portable while upstream institutional production, magnitude, component mix, downstream reach or historical validity differs. Preserve the institution/system configuration as provenance/boundary metadata when it constitutes the mechanism.

Residual category/system coefficients remain `UNEXPLAINED_RESIDUAL`.

### C4 — one actor may occupy multiple concurrent contexts/positions

From Dreier:

```text
LOCATION != POSITION
ONE_ACTOR_ONE_CURRENT_CONTEXT is rejected
```

D1' must permit simultaneous context-position bindings and type-specific consequences.

### C5 — linked-life propagation is explicitly directed

From Elder/M2/SRT:

No cross-person effect without:

```text
source actor
source realized state/transition
exact relation/context
mediating withdrawal/transfer/obligation/channel
focal actor
exact focal ecology delta
valid time
provenance/evidence ceiling
```

Kinship/category labels are insufficient.

### C6 — finite time and activity competition are representable

From Sève/Mortimer/SRT:

If simultaneous required/available activities compete for finite actor time, the representation must preserve interval/schedule/duration and permit explicit crowd-out or sequencing effects.

No standalone `USE_TIME` owner is required.

### C7 — objective work/activity content must replace titles

From Kohn/Schooler/Mortimer:

```text
OCCUPATION_TITLE != JOB_CONTENT
FORMAL_AUTONOMY != ENACTED/EXERCISED CONTROL CONDITION
```

D1' must derive first-order actor-relative work conditions where work is causally used.

### C8 — objective output stops before first-person premise/appraisal

From Holzkamp and current CAN-008 R2 authority:

```text
D1' OUTPUT != SUBJECTIVE PREMISE / REASON / APPRAISAL / RESPONSE
```

### C9 — task/test performance is context-bound evidence

From Luria:

```text
OBSERVED_TASK_PERFORMANCE(task, instruction, prompt_history, context)
!= GENERAL/DURABLE CAPACITY
```

This constrains calibration/evidence use rather than D1' runtime ontology.

### C10 — turning point remains derived

From Elder/Dreier/Mortimer:

A transition/event is a turning point only if later ordered history demonstrates sustained redirection. No standalone turning-point causal carrier.

### C11 — reciprocal world-update outcomes include failure/no-change

From M2/M11/Wright:

Action may produce:

- rule/resource/relation change;
- partial change;
- temporary alternative;
- network/route/resource creation without rule change;

- no relevant world change.

D3 is therefore not an SDTF world-writer; competent external authorities determine the resulting fact.
