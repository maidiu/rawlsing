# D1 — TYPED_ACTOR_RELATIVE_SOCIAL_ECOLOGY_DERIVATION

## What D1 already gets right

The volume repeatedly validates the candidate's insistence on:

```text
STRUCTURAL / INSTITUTIONAL FACT
+ EXACT ACTOR POSITION / RELATION / HISTORY
+ MECHANISM RULE
-> TYPED ACTOR-RELATIVE RESOURCE / DEPENDENCY / OBLIGATION /
   ACTIVITY / ACCESS / COUNTERPART / TIME CONSEQUENCE
```

The strongest examples are not category effects but institutional relations:

- Repo: work-pass criteria -> eligible worker -> permit -> checkpoint route -> employment/wage access, ch.7 pp.117–118.
- Repo: medical permit -> distinct patient/companion decisions -> crossing/delay -> treatment access, pp.115–116.
- Bhattacharya: water-installation permit -> installation opportunity -> water-resource access, ch.4 p.57.
- Bhattacharya: road/license/checkpoint rules -> actor-specific route/delay -> workday/wage history, p.59.
- Ch.9: same-religion egg-donation rule -> recipient classification only because the explicit legal rule uses it -> feasible donor/counterpart set -> treatment opportunity, p.160.
- Taha: movement organization -> actual household/logistics assignments -> recurrent food/water/message/equipment work, ch.8 pp.139–143.

These cases affirm the candidate firewall:

`SOCIAL/DEMOGRAPHIC CATEGORY != ACTOR SOCIAL FACT != ACTOR PSYCHOLOGY`.

## D1 pressure point 1 — linked-person contribution withdrawal and task transfer

Repo's original interviews supply the hardest D1 case in M2:

```text
WORK-PERMIT/CHECKPOINT SCHEDULE APPLIES TO ACTOR_A
-> A'S COMMUTE/WORK CONSUMES PRESENCE TIME
-> A'S ACTUAL HOUSEHOLD CONTRIBUTION BECOMES UNAVAILABLE/REDUCED
-> NECESSARY HOUSEHOLD TASK/OBLIGATION REMAINS
-> TASK/OBLIGATION IS PERFORMED BY LINKED ACTOR_B
-> B'S TIME / CARE / ACTIVITY / COUNTERPART ECOLOGY CHANGES
```

The frozen candidate already contains `LINKED_LIFE_TRANSMISSION`, `HOUSEHOLD_CARE_DEPENDENCY`, `ROLE_OBLIGATION`, and G5's generic typed dependency path. M2 does **not** find a new top-level function. It does find that G5 should explicitly permit a relational transformation whose intermediate is **withdrawal/loss of one linked actor's contribution followed by task/obligation transfer**, not merely “actor A changed, therefore actor B changed.”

Proposed subtype/rule pattern:

```text
LINKED_ACTOR_CONTRIBUTION_WITHDRAWAL_AND_OBLIGATION_TRANSFER(
  source_actor_constraint,
  household_or_dependency_relation,
  contribution_or_task,
  persistence_of_need,
  substitute_actor_binding
)
-> typed focal_actor_time/activity/obligation update
```

This is a D1 mechanism rule, not D4.

## D1 pressure point 2 — counterpart availability after formal eligibility

The egg-donation chapter demonstrates that:

```text
FORMAL ELIGIBILITY
!= ACTUAL COUNTERPART AVAILABILITY
!= REALIZED SERVICE
```

A rule can make a treatment legally possible while the actual donor pool makes it practically unavailable. D1 already owns `COUNTERPART_REACHABILITY` and institutional eligibility; M2 requires tests that compose them rather than treating eligibility as sufficient realization.

## D1 pressure point 3 — service-capacity propagation

Infrastructure destruction matters through a chain:

```text
FACILITY / POWER / SUPPLY / STAFF CONDITION
-> INSTITUTIONAL SERVICE CAPACITY
-> ACTOR-SPECIFIC ACCESS / WAIT / SUBSTITUTE ROUTE
-> HOUSEHOLD/ACTIVITY CONSEQUENCE
```

The source does not license `INFRASTRUCTURE -> PSYCHOLOGY`. D1's `CROSS_DOMAIN_PROPAGATION` and typed resource/gate families can express the chain if intermediate service capacity is preserved as a social/institutional fact.

## D1 pressure point 4 — multiscale organizational chains

Nahman's Romanian oocyte case and Taha's logistics networks show:

```text
STATE/POLICY
-> ORGANIZATION/FIRM/MOVEMENT
-> LOCAL RECRUITER/ROLE
-> DYAD/COUNTERPART
-> ACTOR ACTIVITY/RESOURCE
```

D1 need not create a special “macro context” operator; it must permit multiple explicit derivations/relations in sequence with provenance.

## D1 verdict

`D1_SURVIVES__GENERALIZE_LINKED_ACTOR_TRANSFER_AND_REQUIRE_EXPLICIT_MULTI_STAGE_COUNTERPART/SERVICE_CAPACITY_CHAINS`.

No source forces replacement of D1. The architectural addition is **specificity inside its governed mechanism registry/G5**, not a new top-level seam.

# D2 — INTERVAL_RECURRENCE_AND_TRANSITION_REBINDING

## What D2 already gets right

The book is unusually strong evidence against an event-only representation. Many of its central causal states are continuing or recurrent:

- checkpoint/permit validity and daily commute;
- queue/wait and uncertain delay;
- curfew/closure intervals;
- electricity-service windows;
- household care and provisioning recurrence;
- continuing displacement/co-residence;
- repeated raids and repair;
- imprisonment/no-conjugal-access condition;
- school interruption and alternative-class recurrence;
- repeated rebuilding and resource depletion;
- policy/authority transitions and partial reopenings.

## D2 required semantic coverage

M2 requires D2 or existing carriers generalized under D2 to represent at least:

```text
ACTIVE_INTERVAL
VALIDITY_INTERVAL
WAIT_DURATION
OPEN/CLOSED_SERVICE_WINDOW
DAILY/WEEKLY_RECURRENCE
RECURRENCE_IDENTITY_WITH_CONTENT/QUALITY/DURATION
SCHEDULE_COUPLING_ACROSS_LINKED_ACTORS
DEADLINE
UNCERTAIN_DELAY
INTERRUPTION
BEFORE_AFTER_REBINDING
PARTIAL_REBINDING
RECURRENT_REPAIR
ORDERED_TYPED_CUMULATIVE_UPDATE
```

### Schedule coupling

Repo's case cannot be reduced to independent actor schedules. Actor A's recurring commute changes Actor B's feasible schedule through a household relation. D2 should preserve the temporal dependency while D1 owns the relation/task-transfer semantics.

### Deadline / viability

Two source domains expose real deadlines:

- work-pass expiry/required return time;
- sperm specimen viability/rapid transfer to clinic in the prison-IVF route.

A timestamped event without the valid interval/deadline loses the mechanism.

### Partial transition

Education authority transfer and permit reopening show that transitions can change some powers/actors while leaving others unchanged. Rebinding must be typed and component-specific rather than replacing an entire context wholesale.

### Cumulation

Repeated destruction/rebuilding and land-access/noncultivation cases require:

```text
STATE_t
+ REALIZED LOSS/ACTIVITY_t
-> TYPED STATE_t+1
```

No generic cumulative disadvantage scalar is licensed.

## D2 verdict

`D2_SURVIVES_STRONGLY__GENERALIZE_TESTS_FOR_WAIT_DEADLINE_SCHEDULE_COUPLING_PARTIAL_REBINDING_AND_TYPED_RECURRENCE`.

The volume provides no evidence for a separate temporal D4. It instead makes D2's non-event semantics mandatory.

# D3 — PROVENANCE_PRESERVING_RECIPROCAL_SOCIAL_WORLD_UPDATE

## Strongest tests

The volume provides multiple cases where realized action changes later social facts without necessarily changing the governing rule:

1. AbuMezied: local cultivation/nursery -> actual food/seedling resource creation; later suppression/fragility.
2. Ferguson: Popular Committees -> alternative classrooms/services -> outlawing/raids -> underground continuation.
3. Ferguson: teacher strike -> firing/transfers -> participant employment-position change without successful grievance resolution.
4. Taha: household logistics/resource network -> recurrent provisioning of movement participants.
5. Taha: pass regime + boycott -> alternative production/transport -> temporary market/resource network while pass rule persists.
6. Ch.9: prison reproductive restriction -> sperm-smuggling/clinic route -> successful birth for some -> paternity recognition can remain denied.
7. Ch.9: domestic egg-donation shutdown -> clinic relocation/recruiter network -> new transnational treatment route.

## D3 pressure point — what counts as “later social-world update”

If D3 were interpreted narrowly as:

```text
ACTION -> FORMAL RULE CHANGE
```

it would fail. Source-supported feedback outcomes include:

```text
RULE_OR_POLICY_CHANGE
POSITION_OR_RELATION_CHANGE
RESOURCE_CREATION_OR_DESTRUCTION
NETWORK/COUNTERPART_CREATION
ALTERNATIVE_INSTITUTION_OR_PRACTICE_CREATION
ROUTE_CREATION_OR_CIRCUMVENTION
PARTIAL_SUCCESS
TEMPORARY_SUCCESS
SUPPRESSION_OR_SANCTION
EXTERNAL_NONRECOGNITION
NO_RELEVANT_CHANGE
```

These are result classes, not new operators.

## D3 pressure point — exact update level

A temporary market is a changed exchange/resource network, not abolition of the pass regime. A makeshift school is a changed service/practice fact, not repeal of closure policy. Sperm smuggling can change a couple's reproductive route without changing prison policy. The exact level of the world update must be stored and later re-enter D1 at that level.

## D3 pressure point — heterogeneous collective actors

Taha's chapter shows movement organizations may provide food/support while also imposing gendered directives contested by some women. “The resistance” cannot be one collective subject. D3 must bind exact organizations, participants, merchants, authorities, households, and responses.

## D3 verdict

`D3_SURVIVES__GENERALIZE_OUTCOME_TAXONOMY_AND_EXACT_UPDATE_LEVEL__PRESERVE_SUPPRESSION_AND_NO_CHANGE`.

No direct action→structure edge is licensed.
