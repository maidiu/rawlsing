## 1. Jurisdictional invariants

```text
PRE-V3 STRUCTURAL POSSIBILITY != ACTOR-RELATIVE ECOLOGY
ACTOR-RELATIVE POSSIBILITY != ACTIVE/REALIZED SOCIAL FACT
ACTIVE/REALIZED SOCIAL FACT != ACTOR UPTAKE
ACTOR UPTAKE != DURABLE DEVELOPMENT
DURABLE DEVELOPMENT != DEMOGRAPHIC PRIOR
```

No rule may contain an edge of the form:

```text
CLASS/RACE/GENDER/POVERTY/RELIGION -> PSYCHOLOGICAL TRAIT
```

A demographic/classification field can participate only through an admitted structural, institutional, relational or empirical rule that produces a concrete social consequence and preserves provenance.

## 2. Inputs

Every derivation requires all applicable inputs explicitly:

1. `STRUCTURAL_SOURCE_FACTS` — PRE-V3 admitted structural/empirical possibilities, pressure, affordance/applicability, routes, topology, institutional/property/authority rules.
2. `ACTOR_BINDING` — actor activation plus exact developmental phase, world, time and context.
3. `POSITION_BINDING` — actor's actual role/location/relation/eligibility-relevant position; no inference from demographic category alone.
4. `MECHANISM_RULE` — typed mechanism that says how the structural relation changes an actor-relative social ecology dimension.
5. `HISTORY_BINDING` where required — prior positions, transitions, institutional marks, relationships, resources or realized actions relevant to applicability.
6. `COUNTERPART/INSTITUTION_BINDING` where relational — exact other actor, organization, gate, household or state relation.

All inputs must be provenance-bearing and authority-valid under current Rawlsing law.

## 6. Stage-A derivation law

A structural possibility may become actor-relative only through an explicit rule:

```text
DERIVE(
  admitted_structural_fact,
  actor_binding,
  position_binding,
  mechanism_rule,
  context/time/history qualifiers
)
-> actor_relative_qualified_fact
```

The rule must identify the concrete consequence. Examples:

```text
property separation + active wage-labour position
-> material dependency / exit constraint

supervisory relation + bound worker position
-> authority/control/sanction applicability

credential rule + application/gate position
-> institutional eligibility applicability

organized activity focus + actor participation
-> counterpart reachability set

linked person's transition + dependency relation
-> focal actor resource/time/obligation update applicability
```

A statistical group association without a mechanism and position binding cannot satisfy `DERIVE`.

## 7. Type-specific realization law

`QUALIFIED != REALIZED`.

Each family must define what additional fact activates or realizes it. Examples:

```text
eligibility -> actual application/gate decision -> realized treatment
counterpart reachability -> actual copresence/contact -> ADP-019/OEE event
information channel -> actual transfer -> realized information exposure
support channel -> actual provision/receipt -> realized support process
formal autonomy -> enacted task/supervision state -> exercised autonomy condition
activity opportunity -> actual repeated performance -> recurrent activity history
```

Objective social consequences may be realized without correct actor perception. Actor knowledge/belief/access remains separately governed by ADP-017 and downstream V3.

## 9. Transition rebinding

A realized transition must be able to update multiple ecology dimensions atomically or with an auditable ordered transaction:

```text
TRANSITION
-> deactivate/modify prior bindings
-> activate new position/relation/resource/obligation/activity/context facts
-> preserve before/after provenance
```

This generalizes existing phase/world/context binding without turning a transition into a psychological change.

## 10. Reciprocal world-update law

Actor action cannot directly rewrite structure.

Required form:

```text
V3-GENERATED OR ACTOR-GENERATED ACTION
-> REALIZED EXTERNAL ACTION/EVENT
-> INSTITUTIONAL / COUNTERPART / COLLECTIVE RESPONSE OR GATE
-> CAUSALLY ADMITTED CHANGE IN RELATION / POSITION / RULE / RESOURCE / NETWORK
-> NEW STRUCTURAL/SOCIAL FACT WITH PROVENANCE
-> LATER ACTOR-ECOLOGY DERIVATION
```

The same law applies to collective action without creating a collective psychological subject. Organization, coordination, resources and external response must be explicit.

## 11. Cumulative feedback law

No generic cumulative-disadvantage scalar is admitted. Iteration must remain domain-specific:

```text
REALIZED_HISTORY_t
+ RULE/GATE/RELATION_t
-> ECOLOGY_UPDATE_t+1
-> NEW REALIZATION_t+1
-> ...
```

Protective support, resource mobilization, institutional change and nonmodal actor action can alter the chain.
