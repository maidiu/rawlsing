# T6 NORMALIZED FINDINGS AND RAWLSING MAPPING R1

STATUS: `T6_NORMALIZATION_READY_R1`

## 0. Normalized lane answer

T6 finds that Rawlsing’s Phase-0 seam is lawful but underdescribes four positive production domains:

1. how organized activities/settings generate an actor’s counterpart ecology;
2. how network configuration changes information, obligation, support and sanction ecology;
3. how classifications, role expectations and institutional histories become realized gate treatment;
4. how linked settings and actor/collective action recursively alter later relation/position/exposure.

These are connective semantics, not theory-name objects.

The normalized causal grammar is:

```text
PRE-V3 STRUCTURED WORLD / INSTITUTIONAL ARRANGEMENT
        ↓
ACTOR STRUCTURAL POSITION / SETTING MEMBERSHIP / ROLE / NETWORK LOCATION
        ↓
POSITIVE SOCIAL-ECOLOGY TRANSDUCTION
    focus-organized counterpart formation
    bridge/brokerage-conditioned information access
    closure-conditioned obligation/sanction/support
    role-set expectation/sanction configuration
    classification/mark-conditioned institutional gate treatment
    cross-setting dependency propagation
        ↓
ACTOR-RELATIVE POSSIBILITY / CONDITION
    counterpart set
    information set
    obligation/support/sanction set
    eligibility/gate status
    schedule/resource/activity change
        ↓
REALIZED RELATION / PRACTICE / CONTACT / GATE EVENT / CONDITION
        ↓
SUBJECT MEDIATION / ACTION
    uptake, response, iteration, projection, practical evaluation
        ↓
V3 MEMORY / LEARNING / RELATIONSHIP / BIOGRAPHY / DEVELOPMENT IF EARNED
        ↘
REALIZED ACTOR OR COLLECTIVE ACTION MAY ALTER LATER RELATIONS,
POSITION OR EXPOSURE UNDER LAWFUL WORLD-UPDATE AUTHORITY
```

## 2. Mechanism-family normalization

### NF-T6-01 — Counterpart ecology is produced by organized activity, not topology alone

**Comparator basis:** Feld.  
**Normalized finding:** an actor’s counterpart set can be a function of institutionally/organizationally structured participation in foci of activity. This is more specific than an interaction graph existing. It explains why some actors repeatedly become mutually available for contact while others do not.

**PRE-V3 fit:** structural affordance/applicability + interaction topology can state possible settings and counterpart relations.  
**Actor-indexing point:** actual membership/participation/schedule binding.  
**Realization surface:** recurring co-presence/contact/relationship event.  
**Missing connective function candidate:** `FOCUS_ORGANIZED_ACTIVITY_TO_ACTOR_COUNTERPART_SET_DERIVATION`.  
**Disposition:** `MISSING` pending lane-R proof of an equivalent owner.

### NF-T6-02 — Network relations differ by what they make available

**Comparator basis:** Granovetter + Burt.  
**Normalized finding:** topology must be able to distinguish redundant local ties from bridges/brokerage positions that expose the actor to different information, practices or opportunities. Brokerage additionally requires actor action such as translation/transfer/synthesis.

**PRE-V3 fit:** interaction topology + mediation-route possibility.  
**Actor-indexing point:** realized tie/channel and actor’s cross-group action.  
**Realization surface:** information transfer, referral, coordination, opportunity discovery.  
**Missing/generalized function:** `NETWORK_POSITION_TO_NONREDUNDANT_INFORMATION_OPPORTUNITY_ECOLOGY`.  
**Disposition:** `GENERALIZE` existing route/topology/opportunity semantics.

### NF-T6-03 — Closure changes obligation, sanction and support feasibility

**Comparator basis:** Coleman.  
**Normalized finding:** network configuration can change observability, reputational enforcement, obligation reliability, information circulation and collective support. These must remain decomposed.

**PRE-V3 fit:** structural relation/topology and affordance.  
**Actor-indexing point:** actor is party to concrete obligations, support or sanctionable relations.  
**Realization surface:** communication, repayment, sanction, support, organizing.  
**Missing/generalized function:** `NETWORK_CONFIGURATION_TO_OBLIGATION_SANCTION_SUPPORT_ECOLOGY`.  
**Disposition:** `GENERALIZE`; `GENERIC_SOCIAL_CAPITAL` is `REJECT`.

### NF-T6-04 — A social role is a relation-set, not a psychological prior

**Comparator basis:** Merton.  
**Normalized finding:** status occupancy should resolve to multiple counterpart-specific expectations, obligations, monitoring relationships, sanction capacities and potentially conflicting demands. Structural conflict among role-set members can itself create room for maneuver.

**PRE-V3 fit:** structural relation/topology.  
**Actor-indexing point:** exact status-holder and counterpart role-set at a time/context.  
**Realization surface:** demand, monitoring, sanction, compliance, resistance, support, exit.  
**Missing function candidate:** `STATUS_TO_COUNTERPART_SPECIFIC_EXPECTATION_OBLIGATION_SANCTION_SET`.  
**Disposition:** `MISSING` pending equivalent owner proof.

### NF-T6-05 — Classification becomes causal only through concrete recognition/treatment

**Comparator basis:** Bertrand & Mullainathan; Pager; Correll, Benard & Paik.  
**Normalized finding:** social classification, stigma or legitimacy should never directly modify generated-person traits. They can matter when a gatekeeper/institution receives a classification cue or prior institutional mark, interprets it under a decision context, and produces differential treatment that changes the actor’s opportunity/constraint ecology.

**PRE-V3 fit:** positioned-subject empirical possibility may support population-level evidence; structural applicability can encode gate relevance.  
**Actor-indexing point:** application/encounter enters a specific institution/gate.  
**Realization surface:** evaluation, callback, eligibility decision, exclusion, sanction or allocation.  
**Missing function candidate:** `CLASSIFICATION_OR_MARK_TO_REALIZED_INSTITUTIONAL_TREATMENT`.  
**Disposition:** `MISSING` as connective semantics, with empirical support.

### NF-T6-06 — Institution-produced marks can propagate across later gates

**Comparator basis:** Pager.  
**Normalized finding:** actor biography may contain an institution-generated classification/record that later becomes applicable in another institutional gate. This is a path-dependent social mechanism, not a personality attribute.

**PRE-V3/V3 seam fit:** prior realized history is V3-side biography; later structural gate applicability is actor-relative context.  
**Realization surface:** record disclosure/recognition → later treatment.  
**Missing/generalized function:** `PRIOR_INSTITUTIONAL_HISTORY_TO_LATER_GATE_APPLICABILITY_AND_TREATMENT`.  
**Disposition:** `GENERALIZE` gate semantics with explicit path dependence.

### NF-T6-07 — External settings require an explicit cross-setting route

**Comparator basis:** Bronfenbrenner.  
**Normalized finding:** an event in a setting where the actor is absent can matter only if it alters a linked person/resource/schedule/policy/process in the actor’s immediate ecology, which then generates realized actor experience. Ecological scale labels alone have zero causal force.

**PRE-V3 fit:** structural possibility + mediation-route possibility.  
**Actor-indexing point:** linked dependency reaches actor’s immediate setting.  
**Realization surface:** changed activity, relation, schedule, resource or recurring condition.  
**Missing function candidate:** `CROSS_SETTING_DEPENDENCY_PROPAGATION_TO_ACTOR_RELATIVE_ECOLOGY`.  
**Disposition:** `MISSING/GENERALIZE` subject to lane-R equivalent-owner proof.

### NF-T6-08 — Agency must be temporally situated, not added as a free-floating power

**Comparator basis:** Emirbayer & Mische.  
**Normalized finding:** given the same current constraint, actors may act differently because action draws on selectively reactivated past patterns, projected possible futures and practical evaluation of the present. These are dimensions of action, not durable trait priors.

**V3 fit:** campaign-named needs/expectations/strivings, mediators/tensions/practices, response/metabolism and history machinery are likely reuse surfaces, exact allocation for lane R/Vozhd.  
**Missing function:** no independent T6 owner required if existing V3 action selection already carries history/future/present context.  
**Disposition:** `REUSE / GENERALIZE`.

### NF-T6-09 — Reciprocity requires resources and lawful realized action

**Comparator basis:** Sewell.  
**Normalized finding:** actors/collectives can sometimes alter later relations because they mobilize unevenly distributed resources and transpose schemas/rules across contexts. Intention alone cannot update structure.

**PRE-V3/V3 fit:** current structural affordance/resource conditions constrain action; realized action is actor-indexed; any later world/position update must obey existing jurisdiction.  
**Missing/generalized function:** `REALIZED_ACTOR_OR_COLLECTIVE_ACTION_TO_LATER_RELATION_POSITION_EXPOSURE_UPDATE`.  
**Disposition:** `GENERALIZE`; no new universal structure ontology.

## 3. Temporal-form court

T6 explicitly adjudicates the eight required temporal forms separately.

| Temporal form | T6 mechanism examples | Required semantic distinction | T6 judgment |
|---|---|---|---|
| EVENT | application callback decision; information transfer; sanction episode | discrete realized occurrence at a gate/relation/channel | `EXPLICITLY_REQUIRED`; OEE/event carriers may suffice for discrete realizations |
| CONDITION | persistent network closure; institutional eligibility state; role-monitoring environment; schedule/resource condition | can exist across an interval without being reduced to repeated identical events | `UNDERDESCRIBED_IF_EVENT_ONLY`; preserve interval state |
| RELATION | tie, brokerage relation, obligation relation, role-set relation | durable or recurrent actor-counterpart structure with specific powers/resources/expectations | `BOOKENDS_PRESENT__CONNECTIVE_CONTENT_NEEDED` |
| RECURRENT ACTIVITY/PRACTICE | co-participation in focus; brokerage/translation; compliance/resistance; support exchange | repeated structured activity is itself a causal form and generator of counterpart/skill/history | `POSITIVE_T6_MECHANISMS_SUPPLIED` |
| TRANSITION | entering/leaving organization or role; acquiring record; job callback→employment pathway | state change reconfigures later opportunity/counterpart ecology | `REQUIRES_STATE_CHANGE_SEMANTICS` |
| TRAJECTORY | cumulative job-search gates; career network evolution; repeated role/activity history | ordered sequence with path-dependent future exposure, not unordered event bag | `T6_SUPPORTS__LIFE_COURSE_LANE_TO_NORMALIZE` |
| TURNING POINT | role exit, successful gate crossing, collective action altering relation | event/transition that redirects later ecology; cannot be defined by magnitude alone | `POSSIBLE__DO_NOT_CREATE_T6_SPECIFIC_OWNER` |
| CUMULATIVE PROCESS | repeated discrimination gates; repeated support/sanction; network opportunity accumulation | effects can compound through changed later opportunities/relations | `POSITIVE_INTERINSTITUTIONAL_AND_NETWORK_PATHS_IDENTIFIED` |

## 4. Reciprocity court

T6 requires reciprocal arrows to stay explicit but bounded:

```text
ACTOR ACTION
    != STRUCTURAL CHANGE

ACTOR/COLLECTIVE ACTION
+ ACTUAL RESOURCE MOBILIZATION
+ COUNTERPART/INSTITUTIONAL RESPONSE
+ LAWFUL WORLD/RELATION UPDATE
    -> MAY CHANGE LATER POSITION / RELATION / EXPOSURE
```

Examples:

- accepting a bridge-supplied job lead may change organization and later network ecology;
- actors can create new shared foci or ties;
- peers can organize to counter role-set pressure;
- collective organization can change institutional rules or gate practice;
- brokerage can create new cross-group coordination and thereby reduce/relocate structural holes;
- prior institutional treatment can alter later actor strategy, but strategy does not erase gate constraints by fiat.
