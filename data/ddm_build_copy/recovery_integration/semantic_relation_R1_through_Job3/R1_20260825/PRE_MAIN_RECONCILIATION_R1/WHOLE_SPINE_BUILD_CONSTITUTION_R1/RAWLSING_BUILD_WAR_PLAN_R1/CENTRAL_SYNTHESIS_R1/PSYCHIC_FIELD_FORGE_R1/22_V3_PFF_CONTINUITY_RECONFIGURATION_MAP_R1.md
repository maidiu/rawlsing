# PSYCHIC FIELD FORGE R1 — V3/PFF CONTINUITY AND RECONFIGURATION MAP R1

**Status:** `PRE_ARCHITECTURE_CONTINUITY_MAP__BANKED__MUST_FACTOR__NO_ARCHITECTURE_ADOPTION__NO_RUNTIME_AUTHORITY`

## 0. Purpose

This file corrects the misleading mental model that Psychic Field Forge must be conceived primarily as a psychology layer that begins only after V3 has finished developing the person.

The current stronger hypothesis is:

> Rawlsing should aim for one recursively developing person whose durable developmental recursions and live conversational recursions share as much valid person-specific psychological transition logic as possible, while preserving different state ownership, timescales, admission requirements, and expression responsibilities.

The central design question is therefore:

> How do we reconfigure already-valid V3 person mechanisms so they can operate at interaction timescale; which PFF discoveries validly enrich the same person's periodic developmental recursion; and which PFF phenomena are genuinely interaction-with-user-only and must not be pushed back into V3?

This file is a pre-architecture conceptual map. It does not freeze modules, classes, state schemas, scheduler design, call count, or implementation topology.

## 2. Grounding in recovered/current V3 design capital

Historical V3 reconciliation preserved a two-pass pattern in which:

- an optional first LLM pass could propose;
- governed/deterministic admission decided what became causal;
- an accepted typed event could enter V3 history;
- a later pass was render-only;
- causal conversation feedback could re-enter admission.

Current minimum V3 constitution separately preserves:

- exact generated-person identity;
- actor-specific causal history;
- transition proposals and typed dispositions;
- durable event admission only under exact positive authority;
- sparse actor-state checkpoints;
- a read-only actor runtime snapshot for later mediation;
- no requirement for a universal annual tick;
- explicit effective-time/cursor semantics;
- quiescence as lawful;
- phenomenology and rendered expression outside V3 ownership.

These facts make it conceptually plausible that the same person's transition logic can operate under more than one temporal regime.

No claim is made here that historical two-pass implementation or old V3 code is current production authority.

## 3. Two temporal regimes over one person

### 3.1 Periodic / developmental recursion

Conceptual purpose:

`CURRENT_DURABLE_PERSON`
`+ GENERATED/ADMITTED LIFE INPUTS`
`+ CURRENT DEVELOPMENTAL CONTEXT`
`-> PERSON-SPECIFIC METABOLISM`
`-> DURABLE CONSEQUENCE IF AUTHORIZED`
`-> NEXT DURABLE PERSON`

This regime may involve:

- generated encounters and exposures;
- material/organismic changes;
- relationships;
- expectations and strivings;
- middle-state change;
- rupture/metabolization;
- memory change;
- attractor development;
- other separately governed durable transitions.

Life-course time, scheduler cadence, age, and slow processes are independent governance questions.

### 3.2 Interactive / conversational recursion

Conceptual purpose:

`CURRENT_DURABLE_PERSON`
`+ CURRENT_FAST/LIVE INTERACTION STATE`
`+ ACTUAL USER CONTRIBUTION`
`-> PERSON-SPECIFIC PERCEPTION/RECRUITMENT/METABOLISM`
`-> CURRENT CONSCIOUS/EXPRESSION CONSEQUENCES`
`-> PERSONA RESPONSE`
`-> SELF-OBSERVATION + USER NEXT CONTRIBUTION`
`-> NEXT FAST/LIVE INTERACTION STATE`

This regime advances interaction sequence/cursor while ordinarily leaving age and unrelated off-screen life progression unchanged.

The primary product interaction is:

`GENERATED_PERSON <-> USER`

The user's hidden psyche remains opaque. Rawlsing may consume observable user contributions and context, preserve ambiguity, and form actor-local hypotheses; it may not claim access to the user's actual hidden motives or state.

## 4. Classification vocabulary

Each mechanism should be examined under five nonexclusive classifications.

### `V3_DURABLE_OWNER`

The durable person-state/history meaning belongs in V3 when separately governed.

### `SHARED_PERSON_TRANSITION_LOGIC`

The psychological relation or transformation appears valid both during life-course development and during interaction, even though inputs, timescale, persistence, and admission differ.

### `PFF_FAST_LIVE`

The phenomenon is necessary for the live user interaction and may change turn-to-turn without becoming durable personhood.

### `V2_EXPRESSION_ONLY`

The phenomenon concerns bounded expression/presentation/surface realization rather than person-state transition.

### `V3_ADMISSION_SEAM`

A live/chat consequence may become durable only by a separately governed causal return/admission into V3.

These are conceptual jurisdictions, not adopted software components.

## 6. Reconfiguration principle: expose/reuse before duplicate

For every candidate PFF capability, architecture later must first ask:

1. Does V3 already own the durable semantic object/state?
2. Can PFF consume an exact reference/view rather than copy it?
3. Is the missing thing only a **live activation relation** over the V3 object?
4. Is the missing thing a **shared transition rule** that should also improve V3 periodic development?
5. Is it genuinely interaction-only?
6. Is it only an expression consequence downstream?
7. Does any live consequence require a causal return seam rather than direct mutation?

Only after these questions fail to represent the phenomenon may new independent PFF durable machinery be proposed.

## 7. Candidate shared psychological kernel — concept only

The investigations increasingly point toward a common conceptual kernel such as:

`CURRENT PERSON ORGANIZATION`
`+ CURRENT EVENT/INPUT AS PERCEIVED BY THIS PERSON`
`+ ACTIVE HISTORY/EXPECTATION/STRIVING/MEDIATION`
`+ CURRENT CONDITION`
`-> SELECTIVE RECRUITMENT`
`-> CONFLICT / INHIBITION / AMPLIFICATION / TRANSFORMATION`
`-> RESPONSE/METABOLISM CONSEQUENCES`

This could inform:

- periodic developmental recursions;
- generated social encounters;
- rupture/metabolization;
- user-interaction recursion.

But this file does **not** adopt a `SharedPsychicKernel` software component or require one implementation path.

## 8. What should plausibly enrich V3 from PFF discoveries

High-value candidates for cross-timescale enrichment include:

- actor-specific perception rather than event-label determinism;
- multiple simultaneous motivational recruitments;
- nonlinear conflict and inhibition;
- distinction between durable condition and local excursion;
- defense/regulatory transformation as connective psychology;
- memory resonance without explicit recollection;
- self-model pressure/exposure versus new creation;
- anticipation/future consequence as current causal input;
- hysteresis, sensitization, threshold, lock-in and recovery;
- own-action/self-output feedback;
- relationship-specific recruitment where V3 simulates real interpersonal experience;
- separation of machine causal account from actor self-explanation.

Each candidate must still be reconciled with exact current V3 ownership and transition authority before architecture or production.

## 9. What should remain interaction-fast or downstream unless separately justified

Likely interaction-specific or downstream phenomena include:

- turn-level discourse ambiguity and conversational move interpretation;
- user-specific metaperception at chat timescale;
- live session residue/guardedness/playfulness/interaction charge;
- conversational disclosure/concealment decisions;
- leakage in language;
- current response-move formation;
- expression register/style realization;
- renderer context and wording;
- user-message sequencing;
- turn-specific self-observation of rendered output.

Some underlying principles may generalize to life development, but their conversational representation should not be injected into V3 merely for symmetry.

## 10. Two-LLM-call relationship

The two-call conversational design remains a strong candidate because it cleanly supports:

1. discourse observation / bounded interpretation proposal;
2. governed person-specific psychic transition outside LLM authority;
3. later surface rendering from actual discourse plus bounded actor-conscious/expression consequences.

Historical V3 two-pass design capital is relevant because it already separates proposal/admission/render concerns.

However:

`TWO_LLM_CALLS = ARCHITECTURE_CANDIDATE`, not constitutional law.

The deeper law is:

`INTERPRETATION_PROPOSAL != PERSON_TRANSITION != SURFACE_RENDER`.

## 11. Time law for conversational recursion

The interaction may be a real sequence of experiences without automatic life-course progression.

Preserve:

`TURN_SEQUENCE_ADVANCES`

`LIVE_PSYCHIC_STATE_MAY_CHANGE`

`SELF_OUTPUT_BECOMES_NEXT_INPUT`

while ordinarily:

`AGE_UNCHANGED`

`UNRELATED_WORLD_STATE_UNCHANGED`

`NO_AUTOMATIC_SLOW_TICK`

`NO_AUTOMATIC_OFFSCREEN_EVENT GENERATION`

If an interaction has durable significance, that significance is submitted through V3 admission rather than smuggled in by session persistence.

## 12. Critical failure modes

Reject architectures in which:

- V3 has one crude psychology and PFF has a second richer incompatible psychology;
- PFF copies all V3 person state into a second canonical store;
- user interaction rewrites durable V3 state every turn;
- chat state cannot affect later turns unless promoted durably;
- V3 life events use simplistic direct deltas while chat uses sophisticated person-specific metabolism for the same phenomenon;
- everything discovered in PFF is pushed upstream into V3 even when it only makes sense in conversation;
- everything remains downstream in PFF even when it reveals a general psychological law V3 development needs;
- two LLM calls are mistaken for the psychology itself;
- renderer output is treated as causal self-truth;
- age/time progression is conflated with interaction recursion.
