## 1.2 Smallest positive PFF jurisdiction

PFF interaction specialization is constitutionally required for five things:

1. **interaction evidence mediation** — convert actual modality-bound observable user contribution into bounded, provenance-bearing candidate readings without claiming hidden user truth;
2. **user-opacity preservation** — keep machine interpretation, actor uptake, actor model, metaperception, user claim and user hidden reality non-equivalent;

5. **own-output occurrence recursion** — allow actually emitted output, and only actually emitted output, to become a possible next actor-facing event.

Everything else should be pulled toward an existing shared or durable owner until an exact loss is proved.

## 2.2 Survivor A — current actor-local interaction hypotheses

### Definition

A bounded, perspective-bound, non-durable set of actor-side hypotheses whose current causal use extends beyond the single evaluation in which they arose.

Examples include, when actually generated for the actor:

- `maybe the user was mocking me`;
- `I think they may be flirting`;
- `they probably think I am nervous`;
- `I may have shown too much`;
- `they might reject me if I say this directly`;
- `I expect they will ask again`.

This family can include first-order user readings, metaperception and immediately relevant prospective hypotheses because they share the same constitutional property:

```text
ACTOR_HYPOTHESIS
!= USER_TRUE_STATE
!= MACHINE_CANDIDATE_READING
!= DURABLE_ACTOR_BELIEF
```

### Durable V3 conditioning owners

Depending on the exact hypothesis, lawful conditioning may include:

- ADP-015 relationship state/history;
- CAN-010 expectation/striving state;
- CAN-011 mediators/tensions/practices;
- ADP-016 memory/causal traces;
- ADP-017 durable actor epistemic/access state;
- CAN-012 rupture/metabolization state where applicable;
- MUST-018 attractor/trajectory state where applicable;
- other exact competent V3 owners.

### Why this does not duplicate V3

The survivor is not a durable belief or relationship fact. It is the actor's **current interaction-scoped hypothesis** whose next-turn causal effect can disappear, reverse or remain unresolved without any V3 write.

If a hypothesis becomes durably believed/known/remembered, that transition is not performed here; it must return through the exact V3 owner.

### Lifetime

Permitted temporal scope:

- one turn if still needed after formation;
- multiple turns;
- at most bounded session-live continuity under this constitution.

No cross-session durable persistence class is authorized by PFF prework.

### Causes

Only lawful current causes, such as:

- CAN-008 actor uptake/appraisal from an actual event;
- subsequent actual user evidence;
- actor observation of their own occurred output;
- currently accessible durable person material;
- current response residue.

### Update

A later actual event may:

- strengthen;
- weaken;
- split;
- contradict;
- resolve;
- replace;
- leave ambiguous

the hypothesis through the next shared person×event evaluation.

No free-running hypothesis tick is required.

### Expiry

A hypothesis expires when:

- resolved or contradicted so it is no longer causally live;
- no longer relevant to current interaction context;
- the session-live context is lawfully closed/reset;
- or a later evaluation produces no continuing hypothesis consequence.

Architecture may later define exact retention mechanics; this constitution does not define a decay formula.

### Semantic type

`ACTOR_LOCAL_INTERPRETIVE / PROSPECTIVE EPISTEMIC FAST STATE`.

### How it conditions next CAN-008

It may enter the next evaluation as bounded current actor context, perspective-bound and explicitly non-durable, never as user truth.

### Why it does not become biography

Persistence in a conversation is not V3 admission. Repetition alone does not convert the hypothesis into durable belief, memory, relationship truth, self-model, expectation or attractor state.

## 2.3 Survivor B — current non-durable response residue

### Definition

The **smallest bounded causal carryover from prior actual person×event responses needed to make the next interaction evaluation path-dependent when durable V3 change has not occurred**.

This is not one scalar and not a new taxonomy. It may preserve only those current differences that would make the next response wrong if discarded.

Examples of possible residue content at phenomenon level:

- unresolved activation or conflict;
- target/domain-specific guardedness or opening;
- lingering shame/anger/attraction/relief consequence without an emotion object;
- altered recruitment readiness after recent activation;
- temporary sensitization or attenuation;
- continuing inhibition/control demand;
- rebound potential where causally supported;
- local attention bias or preoccupation caused by the prior interaction;
- current response fatigue/effort consequence caused by the exchange;
- unresolved prospective pressure caused by what just occurred.

The container phrase `response residue` is a semantic family, not authority for one generic `residue_vector`.

### Durable V3 conditioning owners

Any durable source remains owned upstream, potentially including:

- CAN-010;
- CAN-011;
- ADP-015;
- ADP-016;
- ADP-017;
- CAN-012;
- MUST-018;
- relevant current organismic/material condition owners;
- other exact competent V3 owners.

### Why this does not duplicate V3

The survivor exists precisely for cases where:

```text
PRIOR ACTUAL INTERACTION CHANGED THE NEXT TURN
AND
NO DURABLE V3 CHANGE HAS YET BEEN AUTHORIZED
```

A durable expectation, mediator, memory, relationship state or attractor is therefore not copied into residue. Only the current transient consequence of the prior response survives.

### Lifetime

Possible scope:

- next-turn only;
- multi-turn;
- bounded session-live persistence.

The constitution does not authorize indefinite relationship-episode persistence outside session context. Any such future proposal must prove a remainder that V3 durable state + actual interaction history + fresh CAN-008 evaluation cannot preserve.

### Causes

Response residue is caused only by:

- bounded non-durable consequences of an actual CAN-008 evaluation;
- actual occurred output re-entering as a next event;
- actual later user events modifying the current configuration;
- lawful current conditions such as fatigue/load where they actually change the response state.

A renderer draft, machine-only interpretation or hypothetical event cannot create it.

### Update

The next CAN-008 evaluation may:

- continue it;
- transform it;
- resolve it;
- suppress it;
- reactivate another component;
- leave no residue.

### Expiry

It expires when the next lawful evaluation no longer needs it to preserve causal path dependence, or when session-live context closes under later implementation policy.

There is no universal decay constant.

### Semantic type

`CAUSAL NON_DURABLE RESPONSE CARRYOVER`.

### How it conditions next CAN-008

It enters only as current interaction/session conditioning evidence/state, never as a new durable person owner. It can alter current readiness, inhibition, attention, effort, local valence or response route without claiming that the person's biography changed.

### Why it does not become biography

`SESSION HYSTERESIS != V3 DEVELOPMENT`.

Repeated residue can generate actual actions/consequences that later qualify for V3 update, but the conversion is never automatic and is never performed by PFF.

## 2.4 Explicitly eliminated fast-state gadgets

### No separate present-conscious-field store

Current awareness remains a required distinction but can be constituted event-time as an actor-access/focality relation over:

- CAN-008 current response/recruitment;
- ADP-017 accessibility ceilings;
- current actor hypotheses;
- current response residue.

If a recognition/focality result itself changes the next turn, only that resulting causal consequence needs to persist, inside the minimum survivor families.

Therefore:

```text
PRESENT_CONSCIOUS_FIELD_PHENOMENON = PRESERVED
PERSISTENT_CONSCIOUS_FIELD_OBJECT = REJECT
```

### No separate focality state

Focality is distinct from accessibility, but distinction does not imply storage. It is normally event-time. Persisted preoccupation is represented only by the relevant response residue or actor hypothesis.

### No effort subsystem

File 50 establishes:

```text
UPTAKE != RESPONSE_COVERAGE_CAPACITY
SALIENCE != EFFORT
EFFORT != DEFENSE
```

That grain survives. But current effort can be supplied by current condition/context, and turn-caused effort/fatigue can survive as response residue. No independent PFF effort owner is justified.

### No defense state

Current defense is a functional response transformation/recruitment using V3 durable mediators and shared response logic. Lingering regulation demand survives, if necessary, only as response residue.

### No leakage state

Leakage is possible downstream manifestation of incomplete/competing regulation, not a persistent state kind.

### No activation state duplication

Current activation is a CAN-008 result. Only cross-turn causal residue persists.

### No sensitization/hysteresis subsystem

These are temporal properties of response residue and subsequent recruitment, not new durable psychology.

### No anticipation store

Durable expectations remain CAN-010. Current actor expectations about the immediate interaction are either event-time CAN-008 products or actor-local interaction hypotheses when they persist.

### No metaperception object family

Metaperception is a perspective-bound actor hypothesis. Nested perspective must survive; a new object family is unnecessary.

### No chemistry object

Fast chemistry is a derived interaction phenomenon from actor-local state + actual sequence + current hypotheses/residue + durable relationship context. It does not establish reciprocal user state or a third pair-mind.

### No self-feedback state

Actually occurred output becomes a new event. Any following fast consequence is ordinary actor hypothesis or response residue.

# 3. `PFF_CHAT_INGRESS_AND_USER_OPACITY_CONSTITUTION_R1`

## 3.1 Four-way noncollapse

The ingress constitution begins with:

```text
ACTUAL USER EVENT
!= MACHINE DISCOURSE INTERPRETATION
!= ACTOR UPTAKE
!= USER TRUE INTERNAL STATE
```

This distinction is hard.

### Actual user event

The event basis is the lawfully occurred interaction artifact/action and its objective source/order/modality/context evidence.

At minimum, where available and lawful:

- source identity/role;
- exact utterance/action artifact;
- occurrence/order identity;
- modality-observable cues;
- quotation/reporting scope;
- explicit user claims;
- actual interaction context.

PFF may not replace this event with a paraphrase or interpretation.

### Machine discourse interpretation

PFF may generate bounded candidate evidence such as:

- linguistic/discourse structure;
- interaction-act possibilities;
- candidate targets/scopes;
- pragmatic possibilities;
- ambiguity and multiple simultaneous readings;
- relational signals;
- apparent emphasis/intensity;
- user-model hypotheses;
- modality-specific observations;
- uncertainty/confidence;
- exact provenance back to observable event basis.

These are evidence **about how the event may be read**, not event truth.

### Actor uptake

The generated person's actual received event/appraisal is produced by the shared CAN-008 person×event coupling, conditioned by the durable person, actual event, bounded PFF evidence, current context and minimal PFF carryover.

PFF ingress does not declare what the actor heard merely because the machine recognized it.

### User true internal state

Ordinarily inaccessible.

User self-report changes the evidence basis but does not grant omniscient hidden-state access.

## 3.2 Mandatory epistemic laws

```text
PFF_INTERPRETATION != EVENT_TRUTH
MACHINE_READING != ACTOR_UPTAKE
PLAUSIBLE_USER_MODEL != USER_TRUTH
USER_SELF_REPORT != OMNISCIENT_HIDDEN_STATE_READ
ACTOR_MODEL_OF_USER != USER_TRUE_STATE
METAPERCEPTION != USER_ACTUAL_VIEW
PAIR_PATTERN != RECIPROCAL_MOTIVE
```

## 3.3 Ambiguity is a valid output

PFF ingress must be able to return:

- several plausible readings;
- unresolved target/scope;
- low confidence;
- contradictory evidence;
- no meaningful pragmatic enrichment beyond literal content;
- valid-empty / low-significance evidence.

It must not force one interpretation simply because downstream computation prefers a single label.

## 3.4 Provenance requirement

Every nonliteral PFF interpretation supplied toward CAN-008 must remain semantically bound to:

- the exact event basis it interprets;
- the modality/source from which the evidence came;
- whether it is observation, reported content, inference or hypothesis;
- uncertainty where not exact;
- target/scope/perspective where material.

Exact serialization is deferred.

## 3.5 No biography by ingress

User text cannot directly write:

- durable actor belief;
- durable relationship trust/intimacy;
- memory;
- motivation;
- mediator/tension;
- attractor;
- self-model;
- user reciprocal state.

The interaction must proceed through lawful occurrence, shared person×event metabolism and exact durable-return authority.

# 6. `PFF_SELF_OUTPUT_RECURSION_AND_DURABLE_RETURN_LEDGER_R1`

The self-output constitution is:

```text
CANDIDATE OUTPUT != OCCURRED OUTPUT
REJECTED OUTPUT != CAUSAL EVENT
EMITTED OUTPUT
    -> occurrence/admission
    -> possible next actor-facing event
    -> possible next CAN-008 person×event evaluation
```

A draft or rejected renderer candidate cannot:

- embarrass the actor;
- bind the actor publicly;
- alter what the user heard;
- create a relationship event;
- create memory of saying it;
- become evidence in the actor's life.

## 6.2 What may happen after actual emission

Once actually emitted, the exact output occurrence may lawfully produce next-turn consequences such as:

- self-surprise;
- embarrassment;
- relief;
- defensiveness;
- guilt;
- changed focality;
- current commitment pressure;
- changed actor model of what the user now thinks/sees;
- curiosity about one's own motive;
- repair pressure;
- doubling-down;
- changed current interaction hypothesis;
- changed response residue.

No separate self-feedback mechanism is required.

## 6.3 Forward-only renderer evidence

```text
RENDERER VARIATION
!= PRIOR HIDDEN CAUSAL TRUTH
```

But after the wording actually occurs:

```text
OCCURRED RENDERER VARIATION
= POSSIBLE NEW FORWARD EVENT DETAIL
```

The actor can react to what they actually said without the system rewriting why they had said it.
