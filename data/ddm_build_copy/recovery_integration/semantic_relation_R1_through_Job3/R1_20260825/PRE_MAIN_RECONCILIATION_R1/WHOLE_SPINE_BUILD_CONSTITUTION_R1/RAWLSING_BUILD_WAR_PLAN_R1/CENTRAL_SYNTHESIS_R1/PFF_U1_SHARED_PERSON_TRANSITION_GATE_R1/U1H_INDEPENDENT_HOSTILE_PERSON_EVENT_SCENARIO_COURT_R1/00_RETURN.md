## 3. Authority-grounded failure surface

### A-F1 — Native composition has inputs but no governed received-event relation

TD-R05 provides generated events/history. CAN-010 provides exact expectations and strivings. CAN-011 provides mediators, tensions and practices. ADP-015 provides objective and actor-perceived relationship state. ADP-016 provides event-referential and causal-trace memory. ADP-017 provides epistemic stance, accessibility and first-person permission.

None of those authorities owns the event-time proposition:

> this exact observable/admitted event acquired these perspective-bound meanings/significances for this actor under these exact bases.

CAN-008 owns response transactions over governed inputs. Its current operator grammar cannot make an unowned appraisal lawful merely by embedding it inside a concrete response rule. That would hide the missing authority boundary rather than compose it.

This exact gap causes A's failures in scenarios 1, 2, 3, 9 and 12.

### A-F2 — Current bounded effort is not inferable from omission

Scenario 8 requires three states to remain distinct:

```text
ACTOR DID NOT RECEIVE THREAD X
ACTOR RECEIVED X BUT DEFENDED/INHIBITED IT
ACTOR RECEIVED X BUT DID NOT SPEND CURRENT EFFORT ON IT
```

CAN-008 valid-empty and partial effects do not alone establish which occurred. Treating all omission as one response result would collapse causation. A therefore fails until the shared interface can consume a bounded current-condition/effort constraint without turning it into durable health or capacity.

### C-F1 — General-person homology defeats PFF-only ownership

The following have exact non-chat homologs:

- two actors receive the same public correction differently;
- the same actor receives the same words differently from supervisor, lover or stranger;
- a causal trace shapes later conduct without recall;
- attachment and autonomy strivings remain simultaneously active;
- a regulatory/protective mediator transforms a response before self-explanation.

TD-R05 requires actor-specific causal history in ordinary development; CAN-008, CAN-010, CAN-011, ADP-015, ADP-016 and ADP-017 already own the durable participants. A PFF-only receiver would either leave ordinary V3 at objective-event→psychic-effect or duplicate those owners in chat. This causes C's failures in scenarios 1, 2, 4, 5 and 6.

### Renderer failure is independently blocked

ADP-017's actor-safe envelope allows downstream narrowing but forbids widening or inferred hidden claims. CAN-025/ADP-019 make rendered candidates noncausal until admitted. PFF Files 31, 42, 43, 46, 49 and 51 add the necessary interaction-side conclusion:

## 4. Minimum capabilities shared by every whole-court passing model

Because B is the sole complete passing model, these are the minimum capabilities its success demonstrates. They are semantic obligations, not adopted field/module names.

1. **Exact event basis with preserved epistemic class.** Generated/admitted event, external assertion, machine candidate interpretation, user true intention and actor received meaning remain distinct.
2. **Perspective-bound actor uptake.** Holder, target/counterpart, evidence/source, time/scope and uncertainty remain attached through causal use.
3. **Lawful partial or empty reception.** High machine confidence does not require actor reception; valid empty is not an error or invitation to invent drama.
4. **Heterogeneous situated recruitment.** Exact existing expectations, strivings, mediators, tensions, practices, causal traces, perceived-relationship state, current condition and prior response history can participate without conversion into a common scalar or duplicate store.
5. **Multiple simultaneous causal roles.** Several recruited sources can amplify, buffer, deflect, reroute, transform or block without compulsory winner/cancellation.
6. **Discovery/recruitment/access noncollapse.** Machine binding is not live recruitment; live recruitment is not actor access; actor access is not focality, correct self-explanation or renderer permission.
7. **Current condition and effort constraint.** Response coverage may be narrower than comprehension for a bounded present reason without minting a durable incapacity/health score.
8. **Occurrence gate.** Only actual generated/admitted events—including an emitted self-output—may cause the next turn or durable history. Rejected/draft renders have zero causal effect.
9. **Fast/durable firewall.** Current recruitment, affect, self-model pressure, metaperception and session residue do not automatically mutate durable V3 state.
10. **Exact target-owner return.** Durable memory, belief, relationship, expectation, striving, middle state, rupture or attractor effects require ADP-019 occurrence where external plus the separately competent V3 transition authority.
11. **Renderer anti-rescue.** Surface realization may preserve linguistic coherence but may not widen actor access, recover omitted system nuance or narrate hidden provenance.
12. **No type/emotion/instinct shortcut.** Affect, history and recurrent organization may influence the episode only through exact person-event relations; no type label, emotion enum or instinct rank causes the response.
