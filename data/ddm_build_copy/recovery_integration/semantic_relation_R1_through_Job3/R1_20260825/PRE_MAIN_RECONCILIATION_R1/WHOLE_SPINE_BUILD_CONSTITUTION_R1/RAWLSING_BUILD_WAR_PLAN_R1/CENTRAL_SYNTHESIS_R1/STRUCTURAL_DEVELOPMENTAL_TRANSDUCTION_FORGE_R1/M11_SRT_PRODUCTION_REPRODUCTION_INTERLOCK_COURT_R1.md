## 4. Why the loop is not a special causal object

A “loop” is simply a temporally ordered chain in which a later ecology can become input to another institutional relation:

```text
WORK RULE / WAGE / SCHEDULE_t
-> ACTOR/HOUSEHOLD CARE-TIME-RESOURCE ECOLOGY_t
-> REALIZED CARE / JOB SEARCH / EDUCATION / PARTICIPATION_t
-> EXTERNAL GATE OR EMPLOYER RESPONSE_t+1
-> POSITION / WAGE / SCHEDULE / SERVICE STATE_t+1
-> UPDATED CARE-TIME-RESOURCE ECOLOGY_t+1
```

The first two arrows are D1/D2. The external-response arrow is D3 only when an actor/collective action actually elicits an institution/counterpart response that changes a social fact. Ordinary household allocation changing an individual's feasible labor supply does not itself require D3; the later hiring decision is an institutional gate already represented through D1 realization.

## 5. Best hostile examples

### Ford home inspection
The production owner literally entered the household through inspectors and job sanctions (`SRC:L680-L685`). This destroys any excuse to represent “production” and “reproduction” as independent zones. Yet the mechanism remains ordinary authority/sanction + household role requirements.

### Live-in migrant care
Workplace and residence are spatially identical, but Teeple Hopkins still shows temporally differentiated paid work and the worker's own unpaid reproduction (`SRC:L1578-L1604`, `L1620-L1688`). Spatial overlap does not collapse task identity.

### Welfare/workfare
State benefit rule changes can simultaneously remove household resources and impose labor-market activity requirements (`SRC:L803-L812`). This is a policy/gate transition with cross-domain propagation, not a mystical production/reproduction contradiction.
