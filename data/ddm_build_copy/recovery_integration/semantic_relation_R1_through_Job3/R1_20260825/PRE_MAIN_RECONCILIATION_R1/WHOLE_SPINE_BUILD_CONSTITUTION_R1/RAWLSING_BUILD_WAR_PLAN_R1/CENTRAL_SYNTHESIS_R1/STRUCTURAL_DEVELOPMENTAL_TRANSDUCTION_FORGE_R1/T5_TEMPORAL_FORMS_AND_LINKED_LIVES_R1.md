# T5_TEMPORAL_FORMS_AND_LINKED_LIVES_R1

STATUS: `T5_TEMPORAL_FORM_COURT_COMPLETE_R1`

## 0. Governing distinction

T5 does not infer that every noun in life-course scholarship requires a new Rawlsing carrier. The question is whether existing state/binding/recurrence/history owners can compose the literature’s causal content without semantic loss.

Required separations remain binding:

```text
STRUCTURAL POSSIBILITY != REALIZED EXPERIENCE
REALIZED EXPERIENCE != ACTOR UPTAKE
ACTOR UPTAKE != DURABLE CHANGE
TRAJECTORY DESCRIPTION != CAUSAL MECHANISM
TURNING-POINT LABEL != AUTOMATIC TRANSFORMATION
```

## 1. Temporal-form court

| FORM | T5 operational meaning | Required causal data | Existing composition plausibility | T5 judgment |
|---|---|---|---|---|
| `EVENT` | bounded occurrence at a time | actor, time, context, occurrence, counterpart/source | OEE/encounter/event history is the strongest existing surface | `REUSE` — no new T5 carrier |
| `CONDITION` | state of affairs persisting across an interval | start/end or continuing interval, actor applicability, intensity/quality where relevant | state/context/binding can carry it if interval semantics are preserved | `GENERALIZE` — must not encode chronic condition as a bag of identical events |
| `RELATION` | persistent actor-counterpart binding with role/resource/obligation/support consequences | parties, relation type, state, persistence, role/resource channels, change history | PRE-V3 topology + V3 realized relationship history are bookends | `GENERALIZE/MISSING CONNECTIVE` — linked-life cross-actor effects need lawful transduction |
| `RECURRENT ACTIVITY / PRACTICE` | repeated participation in an activity with stable enough identity that frequency, intensity, quality and learning opportunities matter | activity identity, recurrence, duration, intensity, quality/content, context | recurrence + event/activity history + V3 learning can compose it | `GENERALIZE` — preserve recurrence identity and parameters; no standalone trajectory carrier |
| `TRANSITION` | change from one role/state/binding configuration to another | pre-state, change time, post-state, changed bindings/resources/obligations | state change + context rebinding can represent it | `GENERALIZE` — explicit transition-triggered ecology rebinding is required |
| `TRAJECTORY` | ordered history of states/transitions in a domain | domain, ordered states/transitions, durations, realized history | biography/path-dependence/history carriers are sufficient in principle | `REUSE/GENERALIZE` — derived view over history, not a causal entity by itself |
| `TURNING POINT` | transition/event after which sustained trajectory organization differs materially from the prior course | transition plus demonstrable persistent rebound ecology/behavior/history | event + transition + later history can establish it | `REJECT` standalone causal carrier; `DERIVE` retrospective/trajectory predicate |
| `CUMULATIVE PROCESS` | iterative process in which realized prior states alter later risk/opportunity/resource/position ecology and are themselves updated by later realizations | update rule, actor history, resources/risks, opportunity set, realized outcomes, feedback | history carriers exist; positive iterative law is underproved | `MISSING` general feedback/update connective; no generic scalar accumulator |

## 2. Why the distinctions matter

### EVENT is not CONDITION

A plant closure, job loss, military induction, marriage, or divorce can be represented as a bounded event/transition. Poverty, occupational autonomy, caregiving burden, chronic strain, employment quality, or institutional eligibility may persist. Treating a condition as repeated “event happened” records loses persistence, intensity, and uninterrupted exposure.

T5 therefore requires that any lawful condition representation answer:

```text
FOR WHICH ACTOR?
DURING WHICH INTERVAL?
AT WHAT INTENSITY / QUALITY IF RELEVANT?
UNDER WHICH RELATION / INSTITUTION / WORLD BINDING?
```

### RECURRENT ACTIVITY is not merely a sequence of unrelated events

Mortimer’s longitudinal work shows why activity identity matters. “Employed” is too coarse; hours, learning opportunities, demands, contacts, stressors and work quality alter what is repeatedly practiced or encountered. Rawlsing may still use repeated event/activity records, but they must compose under a stable recurrent-activity identity so that frequency, duration and quality remain queryable and causally available.

### TRANSITION is not TURNING POINT

A transition occurs when bindings/state change. A turning point is earned when that transition reorganizes subsequent trajectory enough to produce persistent redirection. Elder’s military-service research and Laub/Sampson’s work on adult bonds both reject the inference:

```text
TRANSITION OCCURRED
THEREFORE
TURNING POINT
```

The lawful form is:

```text
TRANSITION
-> CHANGED RESOURCES / ROUTINES / RELATIONS / OPPORTUNITIES / CONSTRAINTS
-> RECURRENT REALIZED DIFFERENCE
-> DOWNSTREAM HISTORY DIVERGES OR REORGANIZES
= TURNING-POINT STATUS MAY BE ATTRIBUTED
```

This is compatible with deriving turning-point status from history rather than granting a new event type causal power.

### TRAJECTORY is a history abstraction, not an actor essence

A trajectory is useful to summarize ordered domain history. It must never be converted into a latent personality essence or demographic prior. Membership in an empirically estimated trajectory class is especially barred from direct actor-state assignment.

### CUMULATIVE PROCESS requires an update law

Simple accumulation:

```text
risk_1 + risk_2 + risk_3 = disadvantage_score
```

is not the strongest life-course/cumulative-inequality mechanism.

The retained process is closer to:

```text
STATE_t / POSITION_t / RESOURCES_t / RELATIONS_t
+ STRUCTURED POSSIBILITY_t
+ REALIZED EXPOSURE_OR_OPPORTUNITY_t
+ ACTOR / LINKED-LIFE RESPONSE_t
    -> CONSEQUENCE_t
    -> UPDATED HISTORY / RESOURCES / RELATIONS / POSITION
    -> DIFFERENT POSSIBILITY / RISK / OPPORTUNITY ECOLOGY_(t+1)
```

The next exposure distribution is partly produced by the prior realized history. That feedback is the mechanism that prevents “cumulative inequality” from becoming a label.

## 3. Linked-lives court

### 3.1 Exact T5 semantic object

A linked life does **not** mean that person B’s internal state is copied into person A.

The retained causal grammar is:

```text
B HAS REALIZED STATE / EVENT / TRANSITION
+ A<->B HAS A REAL RELATION / DEPENDENCY / RESOURCE OR OBLIGATION CHANNEL
    -> RELATION-SPECIFIC CONSEQUENCE
    -> A'S MATERIAL / TIME / SUPPORT / OBLIGATION / NETWORK / OPPORTUNITY / EXPOSURE ECOLOGY CHANGES
    -> A MAY ENCOUNTER / UPTAKE / RESPOND
    -> A'S BIOGRAPHY MAY CHANGE IF EARNED
```

### 3.2 Permitted cross-person channels

A linked-person state/transition may affect the focal actor only through an explicit channel such as:

- `RESOURCE_TRANSFER`: income, housing, transport, care, information, material support;
- `DEPENDENCY_CHANGE`: loss/gain of provider, caregiver, supervisor, dependent;
- `OBLIGATION_CHANGE`: new care work, household labor, financial duty, schedule burden;
- `SUPPORT_CHANGE`: emotional/instrumental support availability or withdrawal;
- `RELATION_QUALITY_CHANGE`: conflict, cohesion, supervision, trust, attachment as a realized relationship state;
- `TIME_CONTROL_CHANGE`: schedule, commuting, caregiving, shared routines;
- `NETWORK_CHANGE`: access to or loss of people/opportunities via the linked person;
- `MOBILITY/PLACE_CHANGE`: relocation or altered geographic access caused through the relation;
- `OPPORTUNITY/CONSTRAINT_CHANGE`: eligibility, introductions, sanctions, exclusions, institutional access;
- `EXPOSURE_CHANGE`: changed frequency/probability of contact with environments, institutions, stressors, practices, or information.

These are not interchangeable. The exact channel should be named.

### 3.3 Linked-life realization test

A linked-life mechanism is retained only if all of the following can be answered:

```text
1. WHOSE state/transition changed?
2. WHAT real relation binds that person to the focal actor?
3. WHAT transmissive channel exists in that relation?
4. WHAT actor-relative resource/obligation/support/time/network/opportunity/exposure changed?
5. DID the focal actor actually realize the changed condition or encounter?
6. WHAT subject mediation occurred, if any?
7. WHAT downstream V3 state changed, if any, and under what evidence?
```

If step 3 or 4 is absent, “linked lives” is descriptive rather than a causal mechanism.

### 3.4 Reciprocity

Linked lives are naturally reciprocal but not necessarily symmetric.

Example:

```text
parent job loss
-> household income loss + parental time/stress change
-> adolescent work/care obligations change
-> adolescent schedule/earnings/support changes
-> adolescent response may alter household resources and parent burden
```

The same relation can therefore carry effects in both directions while preserving separate actor states.

### 3.5 Rawlsing mapping

**Reusable bookends already present in Phase-0 map:**

- PRE-V3 interaction topology and mediation-route possibility;
- actor activation/context binding;
- V3 relationship/biography/history;
- actor-relative opportunity/constraint and realized encounter/exposure.

**Missing positive connective candidate:**

`LINKED_PERSON_STATE_TRANSITION_TO_FOCAL_ACTOR_SOCIAL_ECOLOGY_UPDATE`

Minimum semantics:

```text
INPUT:
  linked_actor B
  focal_actor A
  realized relation R(A,B)
  realized B state/transition X
  relation-specific transmission channel C
  world/time/context bindings

OUTPUT:
  bounded update to A's resources / obligations / support / time / network /
  opportunities / constraints / exposures

CEILINGS:
  no copying B psychological state to A
  no effect from relation label alone
  no guaranteed A uptake
  no guaranteed durable change
```

This may ultimately be implemented through generalized relation/binding/update owners rather than a new T5-specific carrier. T5 only finds the connective semantics necessary.

## 4. Timing and prior-history court

The commission’s required test is upheld:

```text
SAME CONDITION
+ DIFFERENT AGE
+ DIFFERENT PRIOR HISTORY
+ DIFFERENT LINKED LIVES
= POTENTIALLY DIFFERENT DEVELOPMENTAL PROCESS
```

But each modifier has a different role:

- `AGE/TIMING` selects what roles, obligations, developmental resources and transitions are concurrent;
- `PRIOR HISTORY` determines existing skills, resources, commitments, relationships, wounds, supports and path-dependent eligibility;
- `LINKED LIVES` transmit other actors’ realized transitions through real relational channels;
- `HISTORICAL TIME/PLACE` structures the institutional/resource/opportunity environment in which the transition happens.

None of these is itself a direct psychological update.

## 5. Terminal temporal-form answer

Rawlsing does **not** need eight new temporal carriers merely because life-course theory distinguishes eight nouns.

The smallest T5-positive semantic delta is:

1. preserve interval semantics for `CONDITION`;
2. preserve stable identity + intensity/quality/duration for `RECURRENT ACTIVITY/PRACTICE`;
3. support `TRANSITION -> ACTOR-ECOLOGY REBINDING`;
4. treat `TRAJECTORY` as an ordered history view;
5. derive `TURNING POINT` from sustained post-transition trajectory change;
6. add or verify a general iterative `REALIZED HISTORY/PERSON ACTION -> LATER OPPORTUNITY/RISK/RESOURCE/POSITION ECOLOGY` feedback law;
7. add or verify relation-channel-specific `LINKED PERSON -> FOCAL ACTOR ECOLOGY` updates.

Items 6-7 are the strongest T5 connective gaps. The rest are principally lawful composition/generalization of state, relation, recurrence, transition, binding and history semantics.
