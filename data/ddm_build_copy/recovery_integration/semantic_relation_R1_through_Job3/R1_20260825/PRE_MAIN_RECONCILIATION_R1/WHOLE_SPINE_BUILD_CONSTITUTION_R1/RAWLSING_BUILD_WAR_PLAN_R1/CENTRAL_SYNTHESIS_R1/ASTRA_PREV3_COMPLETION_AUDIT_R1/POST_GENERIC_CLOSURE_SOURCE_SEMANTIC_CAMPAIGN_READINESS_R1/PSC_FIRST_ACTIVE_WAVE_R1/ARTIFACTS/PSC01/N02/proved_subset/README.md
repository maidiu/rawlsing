# N02 bounded replay README

The copied files retain their upstream Git blob identities. `../replay/validate_positive_subset.py` validates exact row-count/ID conservation over this bounded subset. No absence outside this subset is interpreted as unconditionality, nonapplicability, or any other routing status.
