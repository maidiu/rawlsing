# S3 R4 EVIDENCE CEILING PROPAGATION R1

STATUS: `NO_EVIDENCE_OR_AUTHORITY_LAUNDERING_LAW_SPECIFIED`

This product narrows how D1' composition carries evidentiary and governance limits. It does not create rule-admission authority, calibrate empirical mechanisms, or authorize runtime causal rules.

---

## 1. Problem

A multi-step D1' chain could otherwise make a derived fact look more certain, more causal, more portable, or more current than the premises and rule that actually support it.

Forbidden example:

```text
OBSERVATIONAL SOURCE
-> GOVERNED RULE WITH OBSERVATIONAL CAUSAL-USE CEILING
-> DERIVED ACTOR FACT DISPLAYED AS UNQUALIFIED CERTAIN CAUSAL TRUTH
```

The seam must preserve the inferential ceiling through every derivation step.

---

## 2. Minimum propagation law

For every D1' application:

```text
DERIVED_EVIDENCE_CEILING
MUST BE NO STRONGER THAN
  THE CURRENT GOVERNED RULE'S CAUSAL/CLAIM AUTHORITY
  AND EVERY REQUIRED TRUTH-DETERMINING ANTECEDENT/WITNESS'S AUTHORITY,
WITH ALL CONTEXT/HISTORY/PORTABILITY LIMITS PRESERVED.
```

This is a no-strengthening rule, not a claim that every evidence type lives on one simple numeric scale.

Where evidence/authority dimensions are incomparable, the derived fact retains the conjunction/vector of limiting dimensions rather than inventing a stronger scalar rank.

---

## 3. Minimum fields

Every derived D1' fact must expose or resolve to:

```text
EVIDENCE_CEILING
MECHANISM_RULE_REF / exact rule version
DIRECT_DETERMINANT_REF(S)
```

The rule record in turn must expose or resolve to the R4-required:

```text
SOURCE / CLAIM STATUS
COMPETENT OWNER / AUTHORITY REF
PORTABILITY SCOPE
CALIBRATION STATUS IF ANY
BOUNDARY CONDITIONS
NEGATIVE CEILING
```

S3 does not require copying all antecedent metadata onto every fact if the direct refs are immutable/resolvable. It does require the derived fact's own effective ceiling to be available at use time so downstream consumers cannot mistake it for stronger authority.

---

## 4. Three separate dimensions that must not collapse

### 4.1 Source-fact truth authority

How strongly/currently is an objective antecedent itself established?

Examples: source-owned job termination, operative entitlement rule, observed transfer, current infrastructure outage.

### 4.2 Mechanism-rule causal-use authority

What inference is the governed rule actually licensed to make from those inputs?

```text
SOURCE CITATION
!= MECHANISM RULE CURRENTNESS
!= CAUSAL-USE AUTHORITY
```

A theory card or observational association cannot silently become deterministic actor-level causal law.

### 4.3 Realization-witness authority

For ACTIVE/REALIZED assertions, is the required type-compatible witness current, properly polarized, and interval-valid?

A strong structural rule does not strengthen a stale witness; a strong witness does not broaden a weak/limited rule.

---

## 5. Composition examples

### Observational work mechanism

```text
CURRENT JOB-CONTENT FACT
+ CURRENT OBSERVATIONAL/BOUNDED MECHANISM RULE
-> D1' OBJECTIVE CONSEQUENCE
```

The actor-specific input may be well established, while the inference remains limited by the rule's causal-use/evidence ceiling.

### Constitutive legal relation

```text
CURRENT OPERATIVE RULE
+ EXACT POSITION
-> ELIGIBILITY / OBLIGATION
```

Where the competent rule constitutively makes the relation true, the derived fact may carry that constitutive authority. It still does not imply application, treatment, performance, or receipt.

### Contingent gate treatment

```text
ELIGIBILITY
+ GATE ENCOUNTER
+ PRESENTED RECORD
+ DECISION WITNESS
+ GOVERNED P4 RULE
-> REALIZED GATE TREATMENT
```

The output ceiling includes the witness's exact scope/currentness and the rule's exact treatment semantics. It does not imply every downstream employment/resource consequence unless separately derived.

---

## 6. Portability ceiling

A fact derived under one institutional configuration may not silently gain wider portability through composition.

```text
RULE VALID IN CONFIGURATION C
-> DERIVED FACT IN C
```

may become an antecedent in a later D1' step inside the same lawful scope, but it does not authorize the same rule or fact pattern in configuration D without a separately current portable rule/binding.

`COUNTRY/SYSTEM LABEL` still cannot substitute for the actual configuration provenance.

---

## 7. Negative and unknown ceilings

Invalidation/witness failure must preserve R4 polarity law:

```text
NOT_PROVEN_REALIZED
!= NEGATIVE FACT
```

No downstream application may treat `UNKNOWN` or `NOT_PROVEN_REALIZED` as explicit negative evidence unless an exact rule is authorized to consume that epistemic status for a distinct non-world purpose. D1' itself may not translate absence of proof into actor-world negation.

---

## 8. Derived facts as later antecedents

When a D1'-derived fact becomes a determinant of a later D1' application:

```text
LATER OUTPUT CEILING
<= LATER RULE CEILING
AND
<= INHERITED EFFECTIVE CEILING OF THE DERIVED ANTECEDENT
AND
<= OTHER REQUIRED DETERMINANTS/WITNESSES.
```

Thus authority cannot increase merely by adding more derivation steps.

---

## 9. Currentness is part of authority

A once-valid high-quality source or witness that expires no longer supports a current fact.

```text
PAST STRONG EVIDENCE
!= CURRENT AUTHORITY
```

Evidence ceiling propagation therefore works together with determinant currentness and witness validity. A current derived fact must satisfy both inferential ceiling and lifecycle conditions.

---

## 10. Court verdict

The minimum seam protection is:

```text
NO-STRENGTHENING PROPAGATION
+ EXACT DIRECT PROVENANCE
+ EFFECTIVE EVIDENCE CEILING ON EACH DERIVED FACT
+ PRESERVED CONTEXT/PORTABILITY/NEGATIVE LIMITS.
```

No new evidence ontology, causal solver, D2, D3, D4, P6, or rule-admission owner is created.
