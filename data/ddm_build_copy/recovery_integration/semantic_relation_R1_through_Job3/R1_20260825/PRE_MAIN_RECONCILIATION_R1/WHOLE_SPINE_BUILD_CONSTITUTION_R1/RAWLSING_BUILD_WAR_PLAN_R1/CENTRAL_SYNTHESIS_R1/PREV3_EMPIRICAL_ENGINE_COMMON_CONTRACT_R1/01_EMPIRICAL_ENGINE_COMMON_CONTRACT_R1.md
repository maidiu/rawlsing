# PRE-V3 EMPIRICAL ENGINE COMMON CONTRACT R1

Status: `HQ_FROZEN_COMPARISON_DENOMINATOR_R1__PHYSICAL_CANDIDATE_NEUTRAL`

Purpose: define the same logical work that any production physical route A/B/C must perform before physical/economic comparison is meaningful.

Classification vocabulary:

- `SEMANTIC_PARITY_REQUIREMENT` — candidates must produce the same governed meaning/result/failure behavior.
- `DOWNSTREAM_INTERFACE_REQUIREMENT` — candidates must expose a carrier-neutral logical service needed by Field Forge, Dva, DDM analysis, or V3 seam work.
- `PHYSICAL_COMPARISON_METRIC` — candidates may differ; measure rather than normalize away.

A physical route that omits any semantic parity requirement is not cheaper/faster; it is doing less work.

---

## EE01 — Source fidelity and exact identity

Class: `SEMANTIC_PARITY_REQUIREMENT`

Every route must preserve or exactly reconstruct:

- exact source snapshot/content hash;
- source family/product/release/wave/country/society/shard/proxy identity;
- decoder identity/version/configuration;
- exact respondent/row/event/source-coordinate identity;
- native variable/item identity;
- multiplicity/order/rank/multiselect topology where source-bearing;
- raw/native values;
- system missing versus user/source-defined missing where represented;
- source semantic/documentary authority roots;
- exact replay determinants.

Source payload may be reconstructed from governed source bytes if semantic occurrence identity and every non-source-derivable determinant remain exact.

## EE02 — Governed question and response meaning

Class: `SEMANTIC_PARITY_REQUIREMENT`

Every route must expose the same governed semantic surface where authority exists:

- question/proposition semantic identity;
- measured predicate/semantic role;
- target domain/entity;
- response-category meaning;
- response direction/intensity/value semantics;
- topology/scale semantics;
- semantic authority/version/currentness;
- provenance;
- review/unresolved/prohibited states.

Forbidden shortcuts:

- label/text equality as authority;
- numeric code equality as authority;
- family resemblance as authority;
- correlation as semantic equivalence;
- compiler defaults as semantic authority.

- applicability;

Missing routing authority is not empirical absence.

## EE04 — Exact empirical query algebra

Class: `SEMANTIC_PARITY_REQUIREMENT`

Logical query identity must bind at minimum:

`target + predicate/condition + risk_set + empirical_universe + topology + measure + output_grain`.

Where governed, support:

- marginal/distribution queries;
- conditional queries;
- exact same-respondent joint queries;
- cross-question cotravel;
- subgroup-conditioned queries;
- recursively defined branch/cohort queries;
- target-cell/support queries;
- historical/source-local queries;
- comparison queries preserving exact denominator/risk-set identity.

`SOURCE_EVIDENCE != EMPIRICAL_FACT`.

## EE06 — Higher-order and adversarial empirical structure

## EE12 — Cross-wave/source/time comparability grammar

Class: `SEMANTIC_PARITY_REQUIREMENT`

Every empirical comparison must be operation-scoped and bind all material dimensions:

- compared object/result identity;
- comparison operation and output grain;
- target semantics/value/topology;
- source/wave/release universe;
- population/frame/geography;
- time scope;
- routing/risk set;
- measure basis;
- weight/design/estimand;
- semantic authority/lifecycle;
- exact positive bridge authority for every material mismatch;
- applicable negative/noncomparability authority.

Default:

`DIFFERENCE + NO_POSITIVE_BRIDGE => DISTINCT_BY_DEFAULT`.

Relation kinds do not substitute:

- respondent linkage != overlap/nonduplication;
- respondent linkage != sample pooling;
- sample pooling != measurement portability;
- estimand composition != scale equivalence;
- source semantic equivalence != value equivalence;
- weight/design/estimand authority != measurement equivalence;
- harmonization alias != composition/equivalence authority.

## EE13 — Multi-universe orchestration without implicit pooling

Class: `SEMANTIC_PARITY_REQUIREMENT`

Multiple empirical universes may participate in one governed execution while remaining exact source-indexed universes.

Lawful common form:

`JOINT_DISPATCH(U1,...,Un) -> {(Ui, RESULT_i)}`.

Not lawful without explicit composition authority:

`RESULT(UNION_ROWS(U1,...,Un))`.

A higher-order container may enumerate/query member universes while preserving identities and local denominator/design/weight/routing law.

For physical parity the primary comparison cell is:

`(candidate, universe_id, frozen_operation_id)`.

Missing universe authority returns a typed missing-authority cell; it is not a candidate failure or numeric zero.

## EE14 — Positioned-subject empirical possibility service interface

Class: `DOWNSTREAM_INTERFACE_REQUIREMENT`

Every physical candidate must preserve enough information and query power to implement the same logical service even though the final reverse-inference model law remains a later PRE-V3 semantic task.

Required input classes:

- exact query identity/purpose;
- downstream subject/generation identity for replay/correlation only;
- exact downstream-owned generated fact/position refs/hashes;
- exact positive empirical-comparability bindings for every conditioner;
- exact empirical source universe or authorized composition receipt;
- exact historical/as-of/wave/proxy coordinate;
- exact governed empirical learned-release/model identity;
- requested target/joint configuration surface;
- replay/provenance determinants.

Required output classes:

- explicit result state;
- uncertainty-bearing joint empirical possibility geometry or exact governed projection;
- addressed relations/configurations/modes;
- support/uncertainty/negative/unresolved state;
- source/time/release identity;
- conditioner-binding refs;
- explanation/provenance/replay lineage;
- explicit non-assertion of actor belief/response/disposition/choice/history/normative recommendation.

Final model semantics still require separate authority for conditioning, weighting/smoothing, sparse/unseen handling, uncertainty, multimodality, temporal selection, release versioning and replay.

Class: `DOWNSTREAM_INTERFACE_REQUIREMENT`

Field Forge must consume a carrier-neutral logical empirical interface that can provide by reference/service:

- exact empirical fact/result/release identity;
- source/universe/time/risk-set identity;
- question/response semantics;
- same-respondent/joint morphology;
- support/denominators;
- uncertainty;

Field Forge owns structural interpretation/admission at its competent grain. The empirical carrier must not force Field Forge to reconstruct source truth, and Field Forge must not gain authority merely from physical table presence.

# HOSTILE CONSERVATION SUITE

Every route claiming semantic parity must pass the same hostile/non-loss cases where the corresponding function is in scope:

1. recursive subgroup fork;
2. minority-supported structure;
3. equal marginals / different k-way joint;
4. XOR / zero lower-order signal;
5. denominator conflict;
6. source-zero vs semantic-zero scale case;
7. null vs observed-zero;
8. certified vs review lane;
9. lawful parallel target layers;
10. incomplete component vector;
11. heterogeneous component vector that cannot be scalarized;
12. routing signal without lawful executable predicate;
13. synthetic joint-family contamination;
14. ranked/multiselect topology;
15. cross-source semantic-contract incompatibility;
16. equal value in distinct source slots;
17. missing semantic/routing authority;
18. explicit noncomparability;
19. delete/rebuild replay identity;
20. selective invalidation after one exact determinant changes.

A candidate is not required to succeed where the frozen workload is itself missing authority; it is required to return the same typed authority-limited result under the same law.
