## 3. Required anti-shortcut contract

The following are constitutionally invalid for M10:

```text
CLASS -> ENNEAGRAM
CLASS -> HEALTH LEVEL
CLASS -> PERSONALITY TRAIT
CLASS -> OBEDIENCE / DEFIANCE
CLASS -> CONSCIOUSNESS
CLASS -> IDEOLOGY
CLASS -> BEHAVIOR
CLASS -> LIFE EXPERIENCE
```

A lawful path looks like:

```text
NO PRODUCTIVE ASSETS
+ ACTUAL WAGE JOB
+ EMPLOYER BINDING
-> WAGE DEPENDENCY / EXIT CONSTRAINT

AND/OR

SUPERVISORY RIGHT
+ SUBORDINATE BINDING
-> ACTIVE AUTHORITY / SANCTION RELATION

AND/OR

CREDENTIAL
+ SCARCITY RULE
+ MATCHING VACANCY/APPLICATION
-> ELIGIBILITY / BARGAINING OPPORTUNITY

THEN

REALIZED EMPLOYMENT / SANCTION / GATE / LOSS / SUPPORT / ORGANIZATION / ACTION
-> V3-ADMISSIBLE SOCIAL FACTS/GROUNDS
-> PERSON PROCESS ONLY UNDER EXISTING V3 AUTHORITY
```

Legacy generator designs that perturb a psyche directly by `class`, `economic tier`, inequality/hierarchy averages or other macro categories are therefore **not supported by Wright as causal execution**. M10 does not itself adjudicate which legacy implementation is project-current; it establishes the source-law boundary for any later owner.

## 4. Property mapping detail

Property/nonproperty must produce actor-specific consequences only through actual rights and alternatives:

- access to productive resources;
- ability/need to sell labour;
- hiring rights;
- claims on output/surplus;
- investment/disinvestment power;
- credit/market dependencies;
- exit alternatives;
- counterpart dependencies.

`PROPERTY_OWNER=true` alone is incomplete.

## 5. Authority mapping detail

Authority must separate:

- policy decision right;
- budget/resource decision right;
- task assignment;
- procedure/tool assignment;
- pace/workload control;
- promotion/pay influence;
- warning/suspension/firing powers;
- superior approval/review constraints;
- actual subordinate counterpart.

Wright's own survey collapses several of these for empirical tractability. Rawlsing should not copy the collapse when the richer facts are available.

## 6. Credential/skill mapping detail

Required sequence:

```text
CREDENTIAL_POSSESSION
!= ACTUAL_SKILL
!= SCARCITY
!= JOB_REQUIREMENT
!= ELIGIBILITY
!= VACANCY
!= SELECTION
!= TASK_ASSIGNMENT
!= BARGAINING_POWER
!= RENT / INCOME
```

Each edge needs its own authority/evidence.

## 7. Temporal mapping

D2 should carry:

- validity interval of ownership/employment/authority/credentials;
- promotion/job/asset acquisition/loss transitions;
- credential devaluation / changing gate rules;
- household member transitions that rebind resources/obligations;
- class biography as a query over typed history, not a stored causal essence.

## 8. Empirical measurement mapping

Wright's operational bins must stay measurement-side:

- `10+ employees = capitalist`, `2–9 = small employer` is a study convention;
- manager = policy decision + authority is more informative than title but still aggregated;
- supervisor bins collapse exact sanctions/tasks;
- credential categories combine occupation, education and autonomy because the data are incomplete;
- ambiguous categories mix genuine intermediacy and measurement error.

Rawlsing should carry evidence source, measurement grain, confidence/ambiguity and negative ceiling whenever importing empirical class variables.

## 9. Smallest architectural consequence

**No new architecture family.** The smallest consequence is a D1 conformance requirement:

> Any source fact carrying `class` may enter actor-relative derivation only after decomposition into the specific property, dependency, organization, authority, credential/skill, gate, household or counterpart relations that produce the claimed actor-specific consequence.

Then D2 handles relation validity/transitions and D3 handles organization/action/institutional feedback.
