## 6. K4 Path B — governed persistence-to-termination

### 6.1 Legitimate use case

Some competent external owners define a state as persisting until one of a closed set of authoritative closing events. The system need not demand a fresh observation every instant.

Example shape:

```text
STATE S competently established at t0
OWNER defines S.valid_until = explicit termination/supersession/invalidation
OWNER's relevant closing-event universe is authoritative and complete
coverage/reconciliation/source health are complete through q
no closing fact exists through q
=> S may be proved current at q
```

### 6.2 Required R4 reconciliation

Frozen R4 still requires a type-compatible competent witness whose validity overlaps the asserted consequence interval. Therefore the lawful Path B must treat owner-authorized persistence semantics as establishing the **supportable validity interval of a continuing-state witness/state**.

Required form:

```text
ESTABLISHMENT OF S
+ PERSISTENCE AUTHORITY FOR S
+ COMPLETE CLOSURE COVERAGE
+ NO CLOSING FACT
=> TYPE-COMPATIBLE STATE WITNESS S
   SUPPORTABLE/VALID THROUGH q
=> R4 OVERLAP REQUIREMENT SATISFIED
```

An initiating point event does not become current merely because it remains in history.

### 6.3 Stale-state attacks

#### Incomplete termination source

If the source is not complete for all authoritative closing events at exact grain:

`UNKNOWN_NOT_PROVEN_CURRENT`.

#### Delayed reporting / unreconciled latency

If reporting latency is open:

`UNKNOWN_NOT_PROVEN_CURRENT`.

#### Alternate termination channel

If a lawful alternate channel can close the state outside the queried universe:

`UNKNOWN_NOT_PROVEN_CURRENT`, unless the asserted proposition is explicitly source-bounded.

#### Source outage / partial extract / retention gap

Any gap intersecting closure coverage defeats Path B currentness.

#### Identity mismatch

Unresolved actor/relation/entity identity defeats Path B.

#### Configuration or constitutive rule change

A change that affects the state/persistence contract triggers ordinary re-evaluation. Old persistence authority does not override the new configuration.

#### Old establishment event + mere silence

Without explicit owner persistence semantics and complete closure coverage:

`UNKNOWN_NOT_PROVEN_CURRENT`.

#### Recurrent activity requiring new observations

A recurrence rule that requires period-specific observation/freshness cannot be bypassed by Path B. One old performance cannot become current recurrent activity.

### 6.4 Transfer-event precision

A historical transfer K3 and a persistent K4 state are different propositions.

Lawful:

```text
PAYMENT_EVENT at t0 [K3 historical]
+ OWNER explicitly defines BENEFIT_ACTIVE_STATUS established by that event
+ lawful persistence/closure proof
=> BENEFIT_ACTIVE_STATUS [K4 current]
```

Unlawful:

```text
PAYMENT_EVENT at t0
+ no termination
=> PAYMENT_OCCURRED_NOW
```

### 6.5 Path B verdict

`K4 PATH B VERDICT: PASS_WITH_NARROWING__PERSISTENCE_IS_LAWFUL_ONLY_WHEN_IT_ESTABLISHES_A_TYPE_COMPATIBLE_CURRENT_STATE_WITNESS_WITH_SUPPORTABLE_VALIDITY_OVERLAPPING_THE_ASSERTED_INTERVAL`

As currently worded, S2/Files 39/42 can be read to let a point-in-time establishment witness support later currentness without itself or a derived state witness satisfying R4 overlap. That reading is impermissible. The correction above is sufficient; Path B need not be deleted.
