## 4. Calibration law

A numeric probability, coefficient, threshold or effect size from a source may not enter a runtime rule merely because the source supports the qualitative mechanism.

Production calibration requires separate competent authority over:

```text
TARGET WORLD / POPULATION
INSTITUTIONAL CONFIGURATION
MEASUREMENT MAPPING
SOURCE-TO-RUNTIME CONSTRUCT MAPPING
TRANSPORT ASSUMPTIONS
UNCERTAINTY
HISTORICAL SCOPE
VALIDATION
VERSION/CURRENTNESS
```

Binding:

```text
EFFECT SIZE != CALIBRATION
STUDY POPULATION != TARGET WORLD
GROUP RATE != ACTOR OUTCOME
EXPERIMENTAL EFFECT != UNIVERSAL PRODUCTION COEFFICIENT
```

