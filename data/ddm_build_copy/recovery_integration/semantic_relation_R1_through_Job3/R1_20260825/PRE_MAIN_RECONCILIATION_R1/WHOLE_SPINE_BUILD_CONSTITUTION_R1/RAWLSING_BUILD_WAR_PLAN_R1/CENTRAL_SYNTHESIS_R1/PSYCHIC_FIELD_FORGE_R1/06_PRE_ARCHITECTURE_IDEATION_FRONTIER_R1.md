## 0. Purpose

This file banks the expanded PFF conceptual frontier that must be investigated before architecture is admitted.

It is intentionally broader than the currently banked architecture worker families.

The aim is to determine:

- what phenomena PFF must explain;
- which distinctions already exist in V3 or V2;
- which relations among existing concepts are missing;
- which concepts collapse non-equivalent phenomena;
- which candidate ideas should be eliminated before architecture;
- which questions can be settled now and which depend on exact V3/V2 contracts;
- what architecture must eventually be forced to preserve.

No item below is an architecture component merely because it has a heading.
