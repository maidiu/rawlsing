## 4. Minimum path to first lawful positive actor-state change

The first positive transition should be selected by central fan-in from a target state/fact class that requires the fewest additional unresolved semantics. This lane does **not** preselect that target.

The legal execution shape is fixed, however:

1. exact PRE-V3 learned-world evidence exists;
2. exact generated subject exists under D-C03 or already-current authority;
3. D-C01 yields an accepted exact comparator/predicate-ancestry receipt;
4. any operation-specific measurement/transport gates invoked by D-C01 are positively closed;
5. D-C02 yields one accepted V3 transition owner and immutable binding;
6. the current `v3_psepf_zero_positive_guard` receives the exact proposal and delegates to that owner rather than mutating itself;
7. the owner evaluates the proposal and, only on an exact positive disposition, creates one actor-owned causal event/state mutation;

A test in which the guard delegates but no accepted owner mutates is **not** a positive actor-state thread. A test in which a wrapper changes a local state variable without accepted owner authority is also not one.
