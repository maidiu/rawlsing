## 1. Required chain

The volume supports D3 only under the commissioned sequence:

```text
COMMON STRUCTURAL POSITION / ISSUE
!= COLLECTIVE IDENTITY
-> ORGANIZATION / NETWORK / COORDINATION (if realized)
-> MOBILIZATION / ACTION (if realized)
-> EXTERNAL COUNTERPART / INSTITUTION RESPONSE
-> ALTERED OR PRESERVED RULE / RESOURCE / RELATION / POSITION
-> LATER ACTOR ECOLOGY
```

A failed action must be representable with `NO_STRUCTURAL_CHANGE` while preserving the action history.

## 3. D3 law sharpened by source

D3 should require fields for:

```text
ACTION_ACTOR(S) / ORGANIZATION_REF
ACTION_TYPE + VALID_TIME
TARGET_COUNTERPART / INSTITUTION
RESPONSE_FACT (including repression, concession, refusal, nonresponse)
CHANGE_TYPE: rule | resource | position | relation | network | none
CHANGE_AUTHORITY / PROVENANCE
EFFECTIVE_TIME
LATER_ECOLOGY_REBINDING_REF
```

The source particularly demands `CHANGE_TYPE = none` because mobilization frequently fails, is repressed, or produces ambiguous outcomes.

## 4. No collective mind

The volume often speaks of “working class,” “women,” or movements as collective agents for historical narration. Rawlsing must not infer a collective psychological subject. Organization records may represent membership, resources, decisions and coordinated action, but motives/identity remain actor- or organization-process facts only where separately evidenced.

## 5. D3 sufficiency

D3 already captures the irreducible connective requirement exposed here: actor/collective action cannot directly rewrite structure; an external response must mediate the admitted new social fact. No D4 is required.
