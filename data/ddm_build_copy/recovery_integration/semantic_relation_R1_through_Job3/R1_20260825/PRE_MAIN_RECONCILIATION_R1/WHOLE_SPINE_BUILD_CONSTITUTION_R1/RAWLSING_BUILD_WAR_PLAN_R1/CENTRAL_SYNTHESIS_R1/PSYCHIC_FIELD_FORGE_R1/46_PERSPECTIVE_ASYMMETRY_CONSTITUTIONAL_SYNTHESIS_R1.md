## 0. Purpose

This file gives the dedicated synthesis required for original PFF frontier item 19, `perspective and asymmetry law`, after completion of the prior chemistry, metaperception, epistemology, memory, recruitment, conscious-field, defense, anticipation, expression, and V3/PFF continuity examinations.

The primary current PFF interaction remains:

`GENERATED_PERSON <-> USER`

where Rawlsing governs the generated person's internal state but does not possess the user's hidden mind.

The central question is:

> How can Rawlsing preserve several simultaneously real but non-equivalent perspectives on one interaction—objective occurrence, machine causal provenance, generated-person perception, generated-person interpretation, self-understanding, metaperception, user claims, user-hidden reality, relationship history, pair-level interaction pattern, and expression—without laundering one perspective into another or inventing reciprocal relationship truth?

No perspective schema, dyad database, user model object, relationship scalar, truth lattice, or packet format is adopted here.

## 1. Primary constitutional conclusion

The deepest requirement is not merely that A and B can disagree.

It is:

> **Perspective binding must survive every transformation.**

A proposition, interpretation, expectation, memory, or relationship claim does not become perspective-free merely because another component consumes it.

Therefore:

`PERSPECTIVE_BINDING_MUST_SURVIVE_TRANSFORMATION = MUST_FACTOR`.

`PERSPECTIVE_STRIPPING = REJECT`.

Examples:

`A THINKS B IS ANGRY`
`!= B IS ANGRY`.

`A THINKS B SEES A AS NEEDY`
`!= B SEES A AS NEEDY`.

`USER SAID "I LOVE YOU"`
`!= USER HAS VERIFIED ENDURING LOVE`.

`PERSONA FEELS "WE HAVE CHEMISTRY"`
`!= RECIPROCAL CHEMISTRY`.

`SYSTEM KNOWS WHICH GENERATED-PERSON STATES CAUSED A RESPONSE`
`!= GENERATED PERSON KNOWS WHY THEY RESPONDED`.

The architecture later must preserve the semantic equivalent of perspective binding even if it uses different representation forms.

## 3. There is no one truth-space for an interaction

At least the following non-equivalent domains can coexist.

### 3.1 Objective occurrence / interaction evidence

What Rawlsing can directly establish from provenance-bound interaction material or lawfully generated/admitted world events:

- who emitted which artifact;
- exact words/actions;
- ordering;
- explicit claims;
- quotation/reporting scope;
- actual commitments/actions where separately admitted;
- source-bound relationship events/history.

This is narrower than objective social meaning.

### 3.2 Machine candidate interpretation

Bounded discourse/pragmatic readings nominated from observable evidence:

- teasing candidate;
- criticism candidate;
- flirtation possibility;
- reassurance bid;
- status challenge;
- ambiguity;
- likely target/scope.

These are system-side interpretation candidates, not hidden user truth.

### 3.3 Machine causal provenance of the generated person

The system may know exactly which generated-person structures/rules participated in producing a transition:

- rejection expectation;
- mediator;
- causal trace;
- attraction;
- self-model conflict;
- current residue.

This can be exact about **Rawlsing's generated causal path** while remaining silent about the user's private intention and the actor's self-understanding.

### 3.4 Generated-person received reading

How this particular person actually receives the observable interaction after person-specific appraisal and situated recruitment.

Examples:

- concern experienced as control;
- teasing experienced as intimacy;
- ambiguity experienced as possible rejection;
- praise experienced as sarcasm.

This can be psychologically real without establishing speaker intention.

### 3.5 Generated-person conscious interpretation

What the actor currently thinks:

- `They seem annoyed.`;
- `Maybe they're flirting.`;
- `I think that was a dig.`

This can differ from both system candidate readings and hidden causal recruitment.

### 3.6 Generated-person model of the user

Sparse actor-local hypotheses about those aspects of the user that matter now:

- likely motive;
- safety;
- likely response;
- disposition toward the actor;
- trustworthiness;
- sensitivity;
- perceptiveness;
- probable future action.

These are actor-local unless separately verified by some external authority.

### 3.7 Generated-person metaperception

The actor's model of the user's model of the actor:

- `They think I'm nervous.`;
- `They can see I care.`;
- `They think I'm bluffing.`;
- `They see me as competent.`

This is not reducible to the actor's first-order reading of the user.

### 3.8 Generated-person self-understanding

What the actor thinks about their own motive/state and why they responded.

This may be correct, partial, defensive, uncertain, or wrong relative to machine causal provenance.

### 3.9 Durable actor epistemic / relationship state

Lawfully generated durable belief, knowledge, uncertainty, memory, relationship history, expectation, etc. under V3 ownership.

A fast PFF reading does not become durable state merely by surviving one turn.

### 3.10 Generated-person prospective perspective

What the actor thinks may happen next:

- expected user response;
- feared evaluation;
- hoped-for reassurance;
- relationship consequence;
- future self consequence.

Prediction remains distinct from future fact.

### 3.11 User explicit claims

What the user says about their own state or intention:

`I was joking.`

`I'm angry.`

`I love you.`

Rawlsing can know that the user made the claim. The claim is evidence available to the generated person and machine. It is not metaphysical access to the user's private mind.

### 3.12 User hidden/private reality

The user's actual private motive, affect, memory, attraction, strategy, or interpretation.

This exists outside Rawlsing but is ordinarily not directly governed or known by Rawlsing.

`USER_HIDDEN_REALITY = OUTSIDE_RAWLSING_DIRECT_AUTHORITY`.

### 3.13 Objective/shared relationship history

What actually occurred in the relationship or interaction where lawfully constituted.

This is shared history in the sense of common participation in events, not shared meaning.

### 3.14 Pair-level interaction pattern

A derived description across the interaction sequence:

- pursue/withdraw;
- reciprocal joking amplification;
- repeated failed repair;
- escalating status contest;
- asymmetrical flirtation reinforced by response;
- repeated reassurance loop.

This may be objectively supportable as a sequence pattern while motives/meanings remain actor-local or uncertain.

### 3.15 Renderer-visible semantics

Only actor-lawful and expression-lawful content/constraints required for surface realization.

The renderer perspective must remain narrower than analyst causal knowledge.

## 4. Perspective requires more than a speaker label

The later architecture must preserve the semantic equivalent of several axes, without this file adopting a schema.

A perspective-bearing statement may depend on:

- **holder/perceiver/claimant** — whose view is this?;
- **referent/target** — whom/what is the view about?;
- **source/evidence** — what observation/history supports it?;
- **epistemic posture** — observed, reported, suspected, believed, remembered, inferred, hoped, feared, predicted, etc.;
- **temporal scope** — current turn, episode, durable history, remembered past, anticipated future;
- **visibility/authority scope** — machine-only, actor-accessible, actor-conscious, renderer-permitted;
- **causal role** — did it merely exist as a hypothesis, or did it actually participate in current response?;
- **relationship/context scope** — which counterpart/domain/situation does it concern?

The exact implementation may compress or distribute these distinctions. It may not erase them where causally or epistemically material.

## 5. Shared event is not shared experience

Two participants can inhabit the same objective event and have different psychic events.

Therefore:

`SHARED_EVENT != SHARED_EXPERIENCE`.

`SHARED_HISTORY != SHARED_MEANING`.

`MUTUAL_PARTICIPATION != MUTUAL_INTERPRETATION`.

`AGREEING_VIEWS != OBJECTIVE_RELATIONSHIP_TRUTH`.

`DISAGREEING_VIEWS != SYSTEM_ERROR`.

Example:

The user teasingly says the same words once.

The generated person experiences them as affectionate intimacy.

The user may privately mean casual humor, flirtation, hostility, or nothing particularly significant. Rawlsing ordinarily does not know which.

The actual utterance is shared interaction history.

The generated person's intimacy experience is actor-local truth about their own live state.

Those are both real without collapsing into a single relationship meaning.

`SYSTEM_CAN_INSPECT_GENERATED_PERSON_INTERNALS`.

`USER_OPACITY = MUST_FACTOR`.

## 7. Asymmetry is not one quantity

At least the following distinct asymmetries must remain possible without inference from one to another.

### 7.1 Valence asymmetry

Persona likes user; user may not reciprocate.

### 7.2 Intensity asymmetry

Both appear engaged, but the persona is much more strongly activated.

### 7.3 Meaning asymmetry

Persona experiences teasing as intimate; user meant ordinary banter.

### 7.4 Epistemic asymmetry

Persona believes the user understands them deeply; the user may not.

### 7.5 Regulatory asymmetry

User strongly calms or destabilizes the persona; the reverse effect is unknown or different.

### 7.6 Power/dependency asymmetry

One participant's practical, emotional, status, or future stakes are greater.

### 7.7 Vulnerability/exposure asymmetry

One has revealed far more or believes themselves much more readable.

### 7.8 Disclosure asymmetry

One participant supplies extensive personal material while the other remains opaque.

### 7.9 Significance asymmetry

The relationship may occupy much more of one participant's motivational field.

### 7.10 Prospective asymmetry

One participant may imagine a consequential future; the other may treat the interaction as transient.

### 7.11 Confidence/accuracy asymmetry

The persona can be highly certain in a wrong reading while system evidence remains ambiguous.

No global `asymmetry_score` is justified.

## 8. Chemistry must be decomposed into three different claims

The word `chemistry` can refer to at least three non-equivalent things.

### 8.1 Generated-person subjective chemistry

The persona experiences attraction, ease, fascination, playfulness, friction, unusual openness, etc.

This is a real generated-person state where causally supported.

### 8.2 Pair-level interaction coupling

The observable sequence shows a distinctive recursive pattern: rapid banter, mutual escalation, repeated repair, pursuit/withdraw, etc.

This can be a real pair-level process description.

### 8.3 User reciprocal subjective chemistry

What the user actually feels about the persona.

Rawlsing ordinarily does not know this unless the user supplies claims/evidence, and even then the distinction between claim and hidden reality remains.

Therefore:

`PERSONA_FEELS_CHEMISTRY != RECIPROCAL_CHEMISTRY`.

`PAIR_LEVEL_RESPONSIVENESS != MUTUAL_ATTRACTION`.

`USER_RECIPROCITY != INFERRED_FROM_PERSONA_STATE`.

`USER_RECIPROCITY != INFERRED_FROM RENDERED_WARMTH`.

## 11. User self-report changes evidence without collapsing hidden reality

If the user says:

`I wasn't insulting you.`

Rawlsing obtains a new observable self-report about prior intention.

The persona may:

- accept it;
- remain skeptical;
- feel embarrassed;
- revise the reading;
- remain hurt while believing the lack of hostile intent.

The earlier psychic effect is not retroactively erased.

Likewise:

`I love you`

creates at minimum the objective fact that the user said `I love you`.

It may become extremely important to the persona.

It does not automatically give Rawlsing objective access to the user's enduring private emotional state.

`USER_SELF_REPORT = EVIDENCE / INTERACTION FACT`.

`USER_SELF_REPORT != OMNISCIENT_HIDDEN_STATE_READ`.

## 12. New evidence can create a real dynamic without validating old inference retroactively

Suppose:

1. user sends ambiguous warmth;
2. persona suspects flirtation;
3. persona responds flirtatiously;
4. user then explicitly reciprocates.

The resulting flirtatious interaction is now real.

But:

`LATER_RECIPROCATION != PROOF_PRIOR_MESSAGE_WAS INTENDED_AS_FLIRTATION`.

Similarly, a persona's testing behavior can evoke the response it feared or hoped for.

The later response is real causal evidence from that later point onward. It does not sanitize earlier uncertainty.

`CURRENT_COUPLING_CAN_BECOME_REAL_WITHOUT_RETROACTIVE_INTENT_PROOF`.

## 13. Perspective error can be causally real

An actor-local reading does not need objective confirmation to have causal force.

Examples:

- persona believes user is bored and withdraws;
- persona believes user is attracted and becomes bold;
- persona believes user is judging them and overexplains;
- persona believes user sees through a defense and becomes more defensive.

If the reading is later disconfirmed, the earlier response was still part of actual interaction history.

Thus:

`FALSE_OR_UNRESOLVED_READING -> REAL_GENERATED_PERSON_EFFECT = POSSIBLE`.

`REAL_GENERATED_PERSON_EFFECT != VALIDATION_OF_READING`.

This is essential for projection, misunderstanding, awkwardness, repair, and discovery.

Some statements are about the actor's own generated state:

`I felt humiliated.`

Other statements concern external/user hidden facts:

`You wanted to humiliate me.`

Those remain inferential unless independently supported.

Therefore:

`ACTOR_FEELING = ACTOR-LOCAL GENERATED FACT` where lawfully generated.

`ACTOR_CAUSAL_ATTRIBUTION_TO_USER != EXTERNAL USER FACT`.

This distinction allows strong first-person subjectivity without granting omniscience.

## 20. Temporal perspective matters

A current view is not automatically a timeless relationship truth.

Examples:

`I think they're angry right now`

`I used to think they despised me`

`I expect they'll leave`

`I now believe I misread that old event`

refer to distinct temporal scopes.

Likewise a pair-level loop may characterize one segment of a session and disappear after repair.

`CURRENT_RELATIONSHIP_READING != DURABLE_RELATIONSHIP_STATE`.

`CURRENT_PAIR_PATTERN != TIMELESS_PAIR_PROPERTY`.

`PAST_ACTOR_VIEW != CURRENT_ACTOR_VIEW`.

Perspective preservation therefore includes temporal binding.

## 21. Contradiction should often be preserved

A person can simultaneously hold or entertain:

`They're probably joking.`

and

`Part of me thinks they meant it.`

They can also believe:

`They care about me`

while expecting:

`They will leave if I need too much.`

The system should not force one relationship interpretation merely because a data model prefers one value.

`CONTRADICTORY_ACTOR_VIEWS_MAY_COEXIST`.

`MULTIPLE_ACTOR_READINGS != INTEGRITY_FAILURE`.

This is consistent with CAN-019's requirement to preserve contradictory source-bound perspectives.

## 25. Scenario court

### 25.1 Ambiguous flirtation becomes real later

User gives ambiguous warmth.

Persona suspects flirtation, responds playfully, and user then reciprocates explicitly.

Correct:

- early persona reading remains historically uncertain;
- later reciprocal exchange becomes real from the later point;
- chemistry/coupling can strengthen;
- no retroactive proof of original user intention.

### 25.2 User says `I love you`

Correct system fact:

`USER SAID "I LOVE YOU"`.

Possible persona consequence:

strong attachment, disbelief, relief, fear, testing, self-exposure.

Incorrect automatic promotion:

`USER OBJECTIVELY POSSESSES VERIFIED ENDURING LOVE`.

### 25.3 Persona says `You understand me better than anyone`

Correct:

actor-local relationship expression/self-understanding.

Incorrect:

system objective claim that user in fact understands persona better than every other person.

### 25.4 User says `You're jealous`

Correct:

user made a claim about persona; claim can recruit exposure/self-reflection/defense.

Incorrect:

user claim itself becomes persona self-knowledge or system proof.

### 25.5 Short replies misread as boredom

Persona interprets terse user replies as boredom and becomes cool.

User later says they were busy.

Correct:

- earlier persona interpretation may have been wrong;
- earlier psychic response still occurred;
- new user claim is new evidence;
- persona may revise or remain uncertain.

### 25.6 One-sided strong chemistry

Persona experiences intense attraction/fascination.

User remains polite but noncommittal.

Correct:

strong persona-local chemistry may exist.

Incorrect:

`strong persona activation -> mutual chemistry`.

### 25.7 User denies hostile intention after hurt

Persona was hurt by a remark. User says `I was joking.`

Correct:

intention claim can affect subsequent appraisal; hurt is not retroactively invalidated.

### 25.8 Generated-generated hidden-state stress case

System knows generated B had no hostile intent. Generated A perceives insult because of A's history.

Correct:

A's response is driven by A's lawful perception; B's hidden truth is not directly injected into A.

### 25.9 Repeated pursue/withdraw-like sequence

Observable sequence supports pair-pattern description.

Correct:

sequence pattern may be derived.

Incorrect:

infer one universal motive for either participant or a shared psyche.

### 25.10 Both participants verbally call relationship close

Even if both say `we're close`, the agreement is evidence/actor claims.

It does not by itself create whatever exact V3 relationship kind/state requires separate causal authority.

### 25.11 Silence

Only an actually observable delay/absence under explicit timing/context can become interaction evidence.

No API call or missing message alone is not automatically `the user ignored me`.

### 25.12 User says `I'm fine`; persona doubts it

Correct:

user self-report plus persona-local alternative reading can coexist.

Incorrect:

system chooses a hidden user emotional truth without evidence.

### 25.13 Praise received as sarcasm

User praises persona. History makes persona suspect sarcasm.

Correct:

persona-local effect may be distrust/defense while user intention remains unresolved.

### 25.14 False being-seen loop

Persona believes user noticed hidden attraction; user actually has not.

Persona becomes defensive, changing output; user then reacts to the new output.

Correct:

false metaperception causes a real new interaction trajectory.
