## 2. Terminology firewall court

The glossary is strong on objective/subjective disambiguation. The following terms are correctly constrained:

### `AVAILABLE`

Must be qualified as structural availability, actor-qualified K2 availability, material presence, actual receipt/use, or downstream phenomenal availability. No silent shift is allowed.

### `ACCESS`

Must name exact objective material/service/route/gate access state or process. It cannot mean felt accessibility, subjective opportunity or receipt unless the proposition says so and has the corresponding proof.

### `SECURITY`

Must be qualified, e.g. `RESOURCE_SECURITY` / `TENURE_SECURITY` / `ACCESS_SECURITY`, and never silently mean felt security.

### `SUPPORT`

Must distinguish channel/reachability, actual provision/transfer, and downstream perceived support. Transfer does not prove perception or benefit.

### `STRAIN`

Unqualified use is unsafe. Objective task/time/resource/obligation load is D1'-eligible under exact rule; felt strain/distress is V3/person-side.

### `CONTROL`

Must distinguish objective P2 decision/authority scope from perceived control/mastery. Formal scope does not prove exercise.

### `AUTONOMY`

Formal discretion, actual exercised discretion and subjective autonomy must not collapse. Exercised autonomy requires exact P2 scope + P3 participation/task evidence when that is the proposition.

### `OPPORTUNITY`

Must distinguish upstream structural possibility, actor-qualified K2 route, actual occurrence/use and subjective premise/perceived possibility.

### `EXPOSURE`

Must be typed to an exact objective encounter/contact/treatment/environment relation or event. Generic exposure must not become subjective uptake or developmental effect.

### `POSITION`

Must mean actual externally grounded relational position/binding, not role title, identity category, subjective self-positioning or location alone.

### `RELATION`

Must be exact objective directed/undirected externally grounded relation; tie/kinship label alone does not prove obligation, transfer or perceived support.

### `ACTIVITY`

Must separate scheduled/possible activity, actual occurrence, recurrent activity and subjective practice/learning. One old instance does not prove current recurrence.

### `REALIZED`

The companion's K3 usage is consistent with R4 when it means actual contingent occurrence/treatment/transfer/exercise. It does not include K1 entitlement/obligation merely because those are currently operative.

File 43 currently says bare `ACTIVE` is to be used only for K4. That cannot control frozen R4 because R4 itself uses `ACTIVE OBLIGATION` as a constitutive/deontic example and File 39 places `active duty/obligation` under K1.
