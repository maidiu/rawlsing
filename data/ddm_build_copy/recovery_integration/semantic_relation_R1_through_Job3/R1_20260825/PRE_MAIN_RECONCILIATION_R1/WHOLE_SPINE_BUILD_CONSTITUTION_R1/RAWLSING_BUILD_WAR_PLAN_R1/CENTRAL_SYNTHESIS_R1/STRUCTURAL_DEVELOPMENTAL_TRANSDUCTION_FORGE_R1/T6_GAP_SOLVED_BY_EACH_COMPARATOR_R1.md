## 0. Court question

For each comparator, ask one question only:

> What mechanism does this source add that the Phase-0 Rawlsing bridge does not already positively derive?

A comparator fails this court if it merely renames `structure`, `context`, `opportunity`, `relation`, `agency`, `culture`, or `network` without specifying a concrete transduction.

## 2. Exact gaps retained for Vozhd normalization

### GAP-T6-01 — `FOCUS_ORGANIZED_ACTIVITY_TO_ACTOR_COUNTERPART_SET_DERIVATION`

**Problem:** Phase 0 can represent possible interaction topology and realized contact but does not prove why actor A repeatedly encounters this counterpart set rather than another.  
**Comparator solution:** Feld: extra-network foci organize activities/interactions, sorting co-presence and tie opportunities.  
**Needed semantic content:** setting/activity membership + time/participation → actor-relative possible/recurrent counterpart set; realization still requires actual interaction.  
**Do not infer:** tie, friendship, support, influence, personality.

### GAP-T6-02 — `NETWORK_POSITION_TO_INFORMATION_OPPORTUNITY_DIFFERENTIATION`

**Problem:** a generic tie/route does not explain whether the actor receives redundant or novel information.  
**Comparator solution:** Granovetter bridge logic + Burt brokerage/translation.  
**Needed semantic content:** cross-group network relation + actual channel/broker action → nonredundant information exposure / opportunity visibility.  
**Do not infer:** benefit, uptake, success or development from centrality/tie strength alone.

### GAP-T6-03 — `NETWORK_CONFIGURATION_TO_OBLIGATION_SANCTION_SUPPORT_ECOLOGY`

**Problem:** “support network” is too compressed if it does not state what support, obligation or enforcement is actually possible.  
**Comparator solution:** Coleman’s decomposed mechanisms: information channels, obligations/expectations, closure-enabled reputational/sanction capacity, appropriable organization.  
**Needed semantic content:** concrete relational configuration → enforceable/available obligation, information, sanction or support relation.  
**Do not infer:** that closure is always beneficial or that “social capital” is a positive scalar.

### GAP-T6-04 — `STATUS_TO_COUNTERPART_SPECIFIC_EXPECTATION_OBLIGATION_SANCTION_SET`

**Problem:** “role” risks becoming a trait-like shorthand.  
**Comparator solution:** Merton role-set: status links actor to multiple partners whose expectations, power and observability can conflict.  
**Needed semantic content:** status-in-organization → named counterpart roles + expectations + sanction/monitoring capacity + conflict/insulation.  
**Do not infer:** compliance, internalization, personality or single deterministic role effect.

### GAP-T6-05 — `CLASSIFICATION_OR_CUE_TO_REALIZED_INSTITUTIONAL_TREATMENT`

**Problem:** classification/recognition/exclusion must not leap from category to actor state.  
**Comparator solution:** Bertrand–Mullainathan and Correll et al. show experimentally that cues/status classifications can change concrete evaluator/gate outcomes; Pager shows a prior institutional mark can condition a later gate.  
**Needed semantic content:** institution/gate + presented/recognized classification or mark + decision rule/discretion → realized treatment → actor-relative opportunity/constraint.  
**Do not infer:** evaluator belief without evidence, actor trait, or downstream durable consequence without realized history.

### GAP-T6-06 — `PRIOR_INSTITUTIONAL_HISTORY_TO_LATER_GATE_APPLICABILITY`

**Problem:** sequential institutions can compound advantage/disadvantage, but a prior record is neither a later event nor a trait.  
**Comparator solution:** Pager’s criminal-record audit demonstrates one institution-generated mark becoming salient in a later labor-market gate.  
**Needed semantic content:** prior realized institutional history → durable administratively/socially carried mark → later gate applicability/treatment.  
**Do not infer:** inevitable exclusion or psychological essence.

### GAP-T6-07 — `CROSS_SETTING_DEPENDENCY_PROPAGATION_TO_ACTOR_RELATIVE_ECOLOGY`

**Problem:** external organizational/institutional events may affect an actor even when the actor is not present in that setting.  
**Comparator solution:** Bronfenbrenner exosystem demands an explicit two-step sequence from external setting to immediate microsystem process to development.  
**Needed semantic content:** external-setting event/condition → linked person/resource/schedule/policy route → changed actor-immediate relation/activity ecology → realized history.  
**Do not infer:** any effect merely from being nested in a named ecological “level.”

### GAP-T6-08 — `TEMPORALLY_SITUATED_ACTION_SELECTION_UNDER_CONSTRAINT`

**Problem:** actor-relative opportunities do not mechanically determine action.  
**Comparator solution:** Emirbayer & Mische disaggregate agency into iterational, projective and practical-evaluative orientations within concrete action.  
**Needed semantic content:** prior pattern/history + represented/available future + present contingency/resource/sanction → actor action selection.  
**Do not infer:** stable agency trait or unconstrained free choice.

### GAP-T6-09 — `REALIZED_ACTION_TO_LATER_RELATION_POSITION_EXPOSURE_UPDATE`

**Problem:** Rawlsing’s target grammar requires reciprocity; actor/collective action may alter future position/exposure, but this cannot be voluntaristic.  
**Comparator solution:** Sewell’s resource/schema argument provides a bounded model: actors differ in access to resources and in ability to transpose schemas; realized mobilization can reproduce or alter relations.  
**Needed semantic content:** actor/collective action + mobilized resources + institutional/world-update authority → later relation/position/opportunity ecology.  
**Do not infer:** capacity from intention alone or transformation from “agency” as a label.

## 3. Duplicate / non-solution court

### `GENERIC_SOCIAL_CAPITAL`

**Result:** `REJECT_AS_ARCHITECTURAL_OBJECT`.  
Reason: collapses several distinct mechanisms with different valence and realization laws. Decompose into bridge information, brokerage, obligation, sanction, support, closure, organization.

### `GENERIC_NETWORK_CENTRALITY`

**Result:** `DEFER_OR_REJECT`.  
Reason: centrality is descriptive unless a mechanism specifies access, brokerage, dependency, sanction, support, information or counterpart exposure.

### `GENERIC_ROLE_EFFECT`

**Result:** `REJECT`.  
Reason: role/status must resolve to counterpart-specific expectations, obligations, observability, sanctions, activities and realized interactions.

### `GENERIC_DISCRIMINATION_PRIOR`

**Result:** `REJECT`.  
Reason: demographic/social category must not directly modify person parameters. Represent a gate/institution, recognized cue/classification, realized treatment, resulting opportunity/constraint and later biography.

### `GENERIC_ECOLOGICAL_LAYER`

**Result:** `REJECT`.  
Reason: “mesosystem/exosystem/macrosystem” labels without a causal route add no mechanism. Retain cross-setting linkage law only.

### `GENERIC_AGENCY_CAPACITY`

**Result:** `REJECT`.  
Reason: agency must be instantiated as actual temporally situated action under resources, knowledge, sanctions and alternatives.

### `GENERIC_CULTURAL_CLASSIFICATION`

**Result:** `REJECT_UNLESS_REALIZED`.  
Reason: classification matters only where it changes recognition, legitimacy, expectations, sanction, gate treatment, interaction or information ecology.

## 4. Minimal T6 addition hypothesis

T6 does **not** justify a generic `NETWORK_INSTITUTION_CULTURE_AGENCY_MODULE`.

The smallest theory-bearing delta is a set of connective functions that can be normalized into the existing seam grammar:

```text
STRUCTURAL / INSTITUTIONAL POSITION
+ ORGANIZED SETTING / ACTIVITY MEMBERSHIP
+ NETWORK / ROLE / GATE CONFIGURATION
        ↓
ACTOR-RELATIVE COUNTERPART / INFORMATION / OBLIGATION /
SANCTION / SUPPORT / ELIGIBILITY / TREATMENT ECOLOGY
        ↓
ACTUAL RELATION / PRACTICE / ENCOUNTER / GATE EVENT
        ↓
V3 UPTAKE / RESPONSE / MEMORY / DEVELOPMENT IF EARNED
        ↘
 REALIZED ACTOR/COLLECTIVE ACTION MAY UPDATE LATER
 RELATION / POSITION / EXPOSURE UNDER LAWFUL WORLD AUTHORITY
```

This is a semantic finding for Vozhd normalization, not an implementation authorization.
