# 5. Minimal actor-specific person-event coupling interface

U1-C rejects a required serialized `event -> uptake -> recruitment` machine chain.

The minimal shared semantic unit is a **single bounded person-event coupling evaluation** with two noncollapsed projections.

The eventual implementation name is not frozen. The semantic equivalent may be described as:

```text
PERSON_EVENT_COUPLING_EVALUATION
```

It must be evaluation/audit material, not a durable person-state family and not a new causal occurrence.

## 5.1 Required inputs

At minimum:

```text
actor_id
exact precipitating event stream ref(s)
actor-receivability / participant / exposure basis where applicable
exact event feature/payload refs the concrete rule is allowed to inspect
exact conditioning actor-state refs + hashes + effective times
prior response-history ref/hash where used
exact response rule id/version/hash
current causal time/cursor
optional modality-evidence refs + hashes
optional PFF-fast current-context ref/hash in interaction modality
```

The exact concrete rule must declare which state-owner classes it may consult. `WHOLE_PERSON_DUMP` is not a lawful substitute.

## 5.2 Event-side projection — actor uptake/appraisal

The evaluation must be able to represent, without forcing a single winner:

- which exact presented/event features became psychologically operative for this actor;
- what actor-relative significance/appraisal relations the rule establishes;
- target/scope where necessary;
- preserved ambiguity/multiplicity;
- relative salience/strength only where independently governed;
- lawful nonreceipt, attenuation, ambiguity or valid-empty outcome;
- exact state/history bases that conditioned the result.

Hard laws:

```text
EVENT_BASIS != ACTOR_RECEIVED_MEANING
SYSTEM_CAN_PARSE != ACTOR_CAN_NOTICE
MACHINE_CANDIDATE_READING != ACTOR_UPTAKE
USER_TRUE_INTENTION != ACTOR_UPTAKE
ACTOR_UPTAKE != ACTOR_CONSCIOUS_INTERPRETATION
ACTOR_UPTAKE != DURABLE_BELIEF
```

The output need not and generally should not be a prose sentence about what the actor “really thinks.”

## 5.3 Person-side projection — situated recruitment

The same evaluation must identify exact existing person-state refs that become operative in this event under the concrete response rule, including zero or multiple simultaneous bindings.

It must be able to preserve:

- multiple expectations in distinct scopes;
- incompatible strivings;
- interpretive/regulatory/sensitivity mediators;
- unresolved tensions;
- available practices;
- causal traces without forced recall;
- actor-perceived relationship state;
- prior response-path dependence;
- current-condition effects where governed;
- PFF-fast residue in interaction modality;
- inhibition/nonrecruitment where the exact rule makes that distinction relevant.

The result is **references plus rule-governed current roles**, not copied state.

Hard law:

```text
CURRENT_RECRUITMENT != DUPLICATE_DURABLE_STATE
```

## 5.4 Co-determination law

The two projections may constrain one another inside the same rule evaluation.

For example, a relationship-specific expectation may cause an ambiguous comment to be received as condescension, while that appraisal in turn makes a protective mediator and status striving response-relevant.

Therefore:

```text
UPTAKE AND RECRUITMENT MAY BE CO-DETERMINING
```

and no architecture may assume without separate evidence:

```text
COMPLETE UPTAKE OBJECT
MUST EXIST BEFORE
RECRUITMENT CAN BEGIN
```

The transaction must still be deterministic/replayable from exact inputs/rule identity where the rule is deterministic, or bind accepted causal-randomness authority where genuinely stochastic.
