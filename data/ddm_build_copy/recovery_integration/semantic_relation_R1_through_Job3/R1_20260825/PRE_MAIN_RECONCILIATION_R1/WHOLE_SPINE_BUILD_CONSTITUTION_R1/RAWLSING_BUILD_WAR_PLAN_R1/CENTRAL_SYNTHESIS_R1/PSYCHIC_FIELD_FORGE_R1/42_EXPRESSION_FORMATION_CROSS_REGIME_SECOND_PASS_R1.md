## 1. Primary conclusion

The strongest current model is:

> **Expression formation is not translation of hidden psyche into prose. It is the situated formation of an action/communicative intention under simultaneous motive, awareness, prediction, defense, inhibition, relationship, audience, and epistemic constraints; PFF then needs only enough bounded semantics to let downstream V2 owners plan and realize the act without seeing forbidden hidden causes.**

Therefore distinguish:

`DURABLE STRIVING / EXPECTATION / MEDIATOR / PRACTICE`

from:

`CURRENT RECRUITMENT / CONFLICT`

from:

`CURRENT ACTOR AWARENESS`

from:

`SITUATED ACTION_OR_COMMUNICATIVE_INTENTION`

from:

`PFF BOUNDED EXPRESSION PRESSURES / PROHIBITIONS`

from:

`V2 SALIENCE / REGISTER / RESPONSE MOVE / DISCLOSURE / RELATIONSHIP-EXPRESSION DECISIONS`

from:

`RENDERED WORDING`

from:

`ACTUALLY OCCURRED ACTION / UTTERANCE`.

These may participate in one episode without being one object or one owner.

Central laws:

`CURRENT_PSYCHIC_CONFIGURATION != EXPRESSION`.

`CONSCIOUS_CONTENT != COMMUNICATIVE_INTENTION`.

`COMMUNICATIVE_INTENTION != V2_RESPONSE_MOVE`.

`V2_RESPONSE_MOVE != RENDERED_WORDING`.

`RENDERED_WORDING != CAUSAL_OCCURRENCE`.

`ONE_SURFACE_ACT != ONE_CAUSAL_MOTIVE`.

## 2. General person action formation already exists conceptually upstream

The campaign should not pretend that only conversation requires a step from psyche to action.

A generated person in periodic V3 life can:

- confront;
- avoid;
- approach;
- wait;
- disclose something to another person;
- seek help;
- repair;
- retaliate;
- protect someone;
- comply;
- refuse;
- perform a learned practice;
- pursue one goal while sacrificing another.

Those actions should arise from the same underlying person-level connective psychology now being clarified for PFF:

`current event`
`+ appraisal`
`+ recruited strivings / expectations / mediators / tensions / practices / memories`
`+ current condition`
`+ awareness where relevant`
`+ prospective consequences`
`-> situated response tendency / intention`
`-> action where separately governed`.

PFF does not need to own a second theory of volition merely because the action happens to be linguistic.

Current continuity holding:

`GENERAL_PERSON_RESPONSE_FORMATION = SHARED_PHENOMENON`.

`HIGH_RESOLUTION_COMMUNICATIVE_FORMATION = PFF_INTERACTION_SPECIALIZATION`.

Current/recovered CAN-008 already protects immediate actor response transactions, simultaneous causal input preservation, bounded response transformations, path dependence, and the distinction between immediate response and durable update.

The PFF campaign has repeatedly converged on compatible transformation families such as:

That means much of “expression formation” should not become a new expressive psychology. The likely remainder is narrower:

This is interaction-specific, but it can be built over the same person-level response formation rather than beside it.

## 4. A situated communicative intention is a plausible semantic remainder

The first-pass expression examination used `expression trajectory` as shorthand but correctly refused to freeze an `ExpressionTrajectory` class.

The second pass suggests a more precise candidate remainder:

> a current, non-durable **communicative intention / action tendency**: what the actor is presently trying to accomplish or avoid through this act, given the live situation.

Examples:

- keep B engaged without admitting attraction;
- correct B while preserving status;
- ask for reassurance without appearing dependent;
- apologize enough to repair without accepting an accusation the actor rejects;
- change the subject to avoid exposure;
- test whether B is jealous while retaining deniability;
- reveal grief while controlling how much is visible;
- provoke B into making the first explicit commitment.

This is not necessarily one conscious proposition. Some of the function may be partially hidden or multiply caused.

Therefore:

`COMMUNICATIVE_INTENTION != FULL_CAUSAL_SELF_EXPLANATION`.

`COMMUNICATIVE_INTENTION != DURABLE_STRIVING`.

`COMMUNICATIVE_INTENTION != RESPONSE_MOVE_ENUM`.

`COMMUNICATIVE_INTENTION = POSSIBLE FAST DERIVED RELATION` rather than an admitted state kind.

---

## 5. Intention may be plural and compromise-shaped

One utterance can simultaneously:

- approach;
- test;
- protect status;
- preserve ambiguity;
- discharge irritation;
- invite reassurance;
- conceal dependence;
- maintain play.

The system should not force one “real” intention merely because downstream rendering prefers a compact plan.

A useful conceptual pattern is:

`MULTIPLE CURRENT PRESSURES`
`+ CURRENT AWARENESS`
`+ INHIBITIONS / PROHIBITIONS`
`+ PROSPECTIVE CONSEQUENCES`
`-> COMPROMISE-SHAPED COMMUNICATIVE DIRECTION`.

This preserves:

`ONE_ACT != ONE_MOTIVE`.

`ONE_ACT != ONE_INTENTION` where multiple functions remain active.

No fixed intention taxonomy is justified.

---

## 6. Conscious intention and hidden function must remain separate

A may consciously intend:

`I want to make a harmless joke.`

while the same act also functions, outside full awareness, to:

- test interest;
- defend against exposure;
- retaliate for shame;
- secure attention.

The actor's conscious intention is real and should not be erased by a machine-side deeper account.

Likewise the deeper account should not be converted into actor self-knowledge merely because it affected the act.

Therefore:

`ACTOR_CONSCIOUS_INTENTION != COMPLETE_CAUSAL_FUNCTION`.

`MACHINE_CAUSAL_FUNCTION != ACTOR_KNOWN_INTENTION`.

`HIDDEN_FUNCTION MAY SHAPE SURFACE WITHOUT BECOMING CLAIMABLE CONTENT`.

This directly inherits the hidden-cause firewall.

## 7. The firewall is a semantic transformation problem, not a secrecy prompt

The first pass correctly rejected:

`secret hidden cause -> renderer prompt -> "be subtle"`.

The second pass strengthens that conclusion.

A lawful path should look conceptually more like:

`hidden / actor-inaccessible causal material`
`-> governed person-level response effects`
`-> bounded action/communication pressures and prohibitions`
`-> downstream V2 semantic decisions`
`-> renderer realization from actual discourse`.

Example:

Machine-side causal account:

`unrecognized attraction + exposure sensitivity + status concern`.

Lawful downstream-relevant effects may include:

- remain engaged;
- monitor B's reaction closely;
- permit warmth/play;
- inhibit explicit romantic admission;
- preserve deniable ambiguity;
- avoid causal self-explanation.

The renderer does not need to know the hidden proposition `A is secretly attracted` to realize those lawful consequences.

Thus:

`CAUSE_PROVENANCE != RENDERER_SEMANTIC_CONTEXT`.

`FIREWALL = TRANSFORM + VISIBILITY DISCIPLINE`, not merely redaction.

## 8. Negative constraints remain first-class

Expression formation is not only pressure toward saying something.

The current person may also generate hard or soft prohibitions such as:

- do not disclose X;
- do not claim certainty about B's intent;
- do not reveal memory E;
- do not admit dependence;
- do not insult B despite anger;
- do not make a promise;
- do not expose another person's secret;
- do not admit a motive that remains actor-inaccessible.

Some prohibitions arise from actor knowledge/ethics/strategy; others arise from defense or presentation.

Downstream V2 owners may further narrow expression but must not widen beyond upstream epistemic/semantic ceilings.

Current law:

`NEGATIVE_EXPRESSION_CONSTRAINTS = FIRST_CLASS`.

`WITHHELD != INACTIVE`.

`UNSAID != UNKNOWN`.

---

## 9. Expression formation is target- and audience-bound

The same conscious content and same durable person can form different communicative intentions depending on who is present.

Examples:

- truth told gently to a child but directly to a peer;
- vulnerability disclosed to a partner but hidden from a rival;
- disagreement softened with a boss but sharpened with a sibling;
- attraction signaled indirectly to a desired person but concealed before a group.

This is not a reason for one global `expression_style` property.

It follows from:

`PERSON × TARGET × AUDIENCE × RELATIONSHIP × CURRENT STAKES × CURRENT CONDITION`.

Therefore:

`COMMUNICATIVE_FORMATION = SITUATED / RELATIONAL`.

`GLOBAL_RESPONSE_STYLE = INSUFFICIENT`.

## 10. Prospective psychology is constitutive of expression formation

The first-pass anticipation work shows that an actor often chooses a communicative path based on expected consequences:

- if I ask directly, B may reject me;
- if I joke, I can retreat;
- if I apologize now, the relationship may stabilize;
- if I show anger, the group may judge me;
- if I stay silent, B may pursue me.

Therefore expression formation cannot be fully closed before the anticipation second pass.

A useful relation is:

`CURRENT COMMUNICATIVE INTENTION`
`depends partly on`
`DESIRED / FEARED / EXPECTED FUTURE CONSEQUENCES`.

This does not make PFF a planner and does not authorize simulation of B.

## 12. The actual discourse must re-enter at rendering

The actor is responding to what the user/counterpart actually said, not merely to internal coordinates.

Therefore future rendering must preserve:

`ACTUAL SURFACE INTERACTION`
`+ actor-lawful explicit content`
`+ downstream semantic decisions`
`+ bounded PFF-derived constraints`
`- hidden causal propositions`.

The final renderer is therefore a realization engine, not a psyche reasoner.

Hard laws retained:

`SURFACE_DISCOURSE_REENTRY = MUST_FACTOR`.

`RENDERER_MUST_NOT_DISCOVER_PSYCHIC_TRUTH`.

`PROMPT_CONTEXT != ACTOR_CONSCIOUSNESS`.

## 13. Renderer variation creates a critical forward boundary

The renderer may legitimately choose among several natural phrasings that satisfy the semantic plan.

That variation must not become retroactive evidence that the person had a hidden motive before rendering.

But once wording is actually emitted and causally occurs, the actor may perceive it as their own action and respond to it.

Therefore distinguish:

`UPSTREAM INTENDED / CONSTRAINED SEMANTICS`

from:

`RENDERER REALIZATION VARIATION`

from:

`ACTUALLY OCCURRED OUTPUT`

from:

`POST-OUTPUT SELF-INTERPRETATION`.

This seam forces the self-output second pass.

## 14. General action and communicative expression should share one recursion law

A spoken sentence, a pause, leaving a room, sending a message, refusing to answer, touching someone, or apologizing can all be person-actions with social consequences.

The conceptual architecture should therefore avoid treating language as psychologically magical.

Shared law:

`PERSON STATE -> SITUATED ACTION FORMATION -> ACTUAL ACTION -> CONSEQUENCES -> NEXT PERSON STATE`.

PFF adds high-resolution linguistic/social mediation, but the recursion is general.

This supports one-person continuity between life-course V3 and interaction-time PFF.

## 15. No-gadget semantic remainder test

Before architecture introduces `ExpressionTrajectory`, `PFFExpressionPlan`, `CommunicativeIntentState`, or another persistent object, attempt to preserve required behavior through:

1. V3 durable strivings/expectations/mediators/tensions/practices;
2. current PFF situated recruitment and conflict;
3. current actor awareness and actor-access ceiling;
4. current prospective desired/feared outcomes;
5. a derived situated communicative/action intention where needed;
6. bounded positive and negative expression constraints;
7. existing V2 salience/register/response/disclosure/relationship/boundary owners;
8. surface discourse re-entry;
9. renderer realization;
10. lawful occurrence/admission before any durable consequence.

Only a surviving representational remainder should justify new machinery.

## 19. Next forced seam

The expression pass makes self-output feedback unavoidable.

Once an utterance/action actually occurs, the actor can perceive what they themselves did, update their model of what the counterpart now knows, become surprised or embarrassed, reinterpret their motives, double down, repair, or recruit new memory/self-model material.

The next question is therefore not how to add a feedback gadget, but:

> Can own-output feedback be constituted as the ordinary person-recursion law applied to the actor's own lawfully occurred act, while keeping renderer variation from becoming retroactive psychic truth?
