## 1. Atlas compression

The mechanism families collapse into five architecture-level functions:

```text
F1 POSITION/RELATION -> ACTOR-RELATIVE SOCIAL-ECOLOGY DERIVATION
   resource / dependency / authority / obligation / activity /
   gate / counterpart / information / support / sanction / time

F2 TEMPORAL PRESERVATION OF LIVED SOCIAL FORMS
   active condition / persistent relation / recurrent activity /
   transition rebinding / ordered trajectory

F3 REALIZATION
   available/applicable ecology fact -> actual relation/activity/
   condition/contact/event according to type-specific realization law

F4 RECIPROCAL SOCIAL-WORLD UPDATE
   realized actor/linked-person/collective action or event
   -> external gate/relationship/institution response
   -> later position/relation/ecology

F5 V3 DEVELOPMENTAL RECEIPT
   realized lived history -> existing uptake/response/memory/
   learning/practice/relationship/path-dependence owners
```

`F5` is substantially existing V3 jurisdiction and is not redesigned here. `F3` has strong narrow existing OBL055–061/OEE machinery for discrete first-canary realization. The main architectural delta lies in `F1`, typed temporal preservation in `F2`, and reciprocal update in `F4`.
