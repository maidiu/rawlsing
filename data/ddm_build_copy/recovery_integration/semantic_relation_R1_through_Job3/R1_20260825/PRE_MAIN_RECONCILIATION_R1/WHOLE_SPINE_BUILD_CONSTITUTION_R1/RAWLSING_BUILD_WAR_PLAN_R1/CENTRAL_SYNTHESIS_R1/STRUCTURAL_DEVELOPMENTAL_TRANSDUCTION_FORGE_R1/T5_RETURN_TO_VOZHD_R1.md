## 2. Top retained mechanisms

1. `HISTORICAL_CONTEXT_QUALIFICATION` — historical time/place changes the actor-relative opportunity/constraint/institutional ecology only after actor/time/position binding.
2. `TIMING_SEQUENCE_SENSITIVE_TRANSITION` — the same nominal transition can have different consequences because it interrupts or enables different prior role/trajectory configurations.
3. `LINKED_LIFE_RELATIONAL_TRANSMISSION` — another person’s realized state/transition changes focal-actor resources, obligations, support, time, network, opportunities, constraints or exposures only through a real relation-specific channel.
4. `RECURRENT_ACTIVITY_QUALITY_INTENSITY_DURATION` — repeated activity content/quality matters; structural category membership is insufficient.
5. `TRANSITION_TO_ECOLOGY_REBINDING` — a transition matters by changing routines, resources, roles, sanctions, counterpart sets, schedules, place and opportunity/constraint.
6. `TURNING_POINT_AS_EARNED_TRAJECTORY_PREDICATE` — turning-point status follows sustained redirection; it is not an intrinsic event class.
7. `ITERATIVE_CUMULATIVE_RISK_RESOURCE_OPPORTUNITY_FEEDBACK` — prior realized history changes later opportunity/risk/resource/position ecology, which recursively changes later history.
8. `RECIPROCAL_SELECTION_AND_STRUCTURAL_RESPONSE` — prior person/action influences later selection while institutional/relational gates and sanctions remain explicit.
9. `INSTITUTION_RULE_X_REALIZED_HISTORY_ACCUMULATION` — institutional rules operate repeatedly against actual position/eligibility/duration histories.
10. `POPULATION_SELECTION_AS_INFERENCE_CEILING` — mortality/attrition/cohort truncation constrain empirical inference and must not become actor psychological priors.
