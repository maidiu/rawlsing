The first pass correctly rejected `semantic search = psyche`.

The second pass goes further:

> **The core phenomenon is not retrieval of memory documents. It is situated recruitment of already-existing person organization into a current response episode.**

What may become relevant includes:

- durable expectations;
- strivings;
- mediators;
- tensions;
- practices;
- relationship history/organization;
- self-model or actor epistemic state where separately owned;
- attractor organization;
- V3 `CAUSAL_TRACE_MEMORY`;

- current organismic/material condition;
- recent live residue;
- current user/interlocutor model and metaperception;

Therefore:

`DEEP_RECRUITMENT != MEMORY_SEARCH`.

`DURABLE_STRUCTURE_RECRUITMENT != EPISODIC_RETRIEVAL`.

`CURRENT_RELEVANCE != GLOBAL_IMPORTANCE`.

`NOT_RETRIEVED_AS_MEMORY != NOT_CAUSALLY_PRESENT`.

The phrase `situated recruitment` is a current conceptual aid, not frozen architecture terminology.

## 2. Three operations must remain distinct: discovery, recruitment, actor access

A major source of collapse is treating all three as one “retrieval” operation.

### 2.1 Machine-side discovery / binding

The machine may need to identify exact V3-owned structures that are plausible or authorized contributors to the current computation.

Examples:

- expectation X;
- mediator M;
- relationship history R;
- tension T;
- causal trace C;
- event-referential memory E.

Machine-side discovery is an implementation/analysis function. It does not itself mean the structure is consciously active for the actor.

### 2.2 Current live recruitment

A durable structure may actually participate in the current situated response/configuration.

Examples:

- an expectation shapes appraisal;
- a mediator changes the received meaning of teasing;
- a tension creates approach/avoid conflict;
- a causal trace increases guardedness;
- an old relationship pattern changes anticipation.

This is a person-level psychological relation, not merely a database lookup.

### 2.3 Actor access / conscious recollection

Some recruited material may become consciously available, named, recalled, interpreted, or focal.

For memory, ADP-016/017 govern the authoritative access/epistemic boundary.

Thus:

`MACHINE_DISCOVERY != LIVE_RECRUITMENT`.

`LIVE_RECRUITMENT != ACTOR_ACCESS`.

`MACHINE_DISCOVERY != ACTOR_KNOWLEDGE`.

`MACHINE_DISCOVERY != LIVE_CAUSAL_PARTICIPATION_BY_DEFAULT`.

This three-way distinction is one of the most important results of the paired pass.

## 3. The developed person reduces the need for historical lookup

The memory second pass established:

`DEVELOPED_PERSON = HISTORY_ALREADY_PARTLY_METABOLIZED`.

This has a direct consequence for recruitment.

Suppose A was repeatedly humiliated for dependence.

Years later, a current interaction threatens dependency exposure.

If lawful V3 development has already formed:

- an expectation that dependence invites humiliation;
- a response-sensitivity mediator;
- a regulatory-protective mediator;
- an intimacy/autonomy tension;
- a self-presentation practice;
- an attractor tendency;
- a causal trace;

then the current response may recruit those **developed consequences** without searching for a childhood scene.

This suggests an anti-overretrieval rule:

> Prefer the strongest already-developed V3 representation of historical effect before requiring explicit source-episode participation.

This is not an architecture ordering rule and does not prohibit source-history use. It is a semantic burden against repeatedly reconstructing personality from old event records.

`PERSON_STATE_ALREADY_CARRYING_HISTORY > REPLAY_OLD_EPISODE_AS_DEFAULT_EXPLANATION`.

## 5. Relevance is relational and compositional

A durable structure is not simply globally “important.”

Its current relevance can depend on:

- this event;
- this counterpart;
- this relationship history;
- this actor condition;
- this already-active conflict;
- this anticipated future;
- this self-model threat;
- this need/striving configuration;
- this recent sequence of turns/events;
- this purpose of computation.

Thus:

`RELEVANCE = CURRENT_RELATION, NOT NECESSARILY DURABLE_ATTRIBUTE` is the stronger hypothesis.

A structure that is quiet in one context may be central in another.

A weak direct cue can become important through composition:

```text
B praises A's independence
+
A is attracted to B
+
A has a hidden dependency conflict
+
A expects neediness to be rejected
-> strong current exposure/defense relevance
```

The relevant old history may have no lexical resemblance to the current words.

## 6. Relevance can arise through similarity, contradiction, absence, threat or affordance

The first pass listed many routes. The second pass treats them not as a future taxonomy but as evidence that relevance cannot be reduced to semantic similarity.

Current relevance can arise because something:

- resembles prior interaction structure;
- is the same counterpart/entity;
- confirms an expectation;
- violates an expectation;
- threatens a need, self-model, relationship or plan;
- affords intimacy, status, competence, escape, repair, belonging or another striving;
- exposes disallowed material;
- contradicts the actor's standing self-understanding;
- repeats an unresolved relational pattern;
- is conspicuously absent;
- occurs in a sensitized current state;
- is linked by recent live residue;
- is produced by the actor's own immediately prior output.

Therefore:

`PSYCHIC_RELEVANCE != SEMANTIC_SIMILARITY`.

`NOVELTY / VIOLATION CAN BE MORE RELEVANT THAN SIMILARITY`.

`ABSENCE_CAN_BE_A_PSYCHOLOGICAL_CUE`.

`AVOIDANCE_CAN_COINCIDE_WITH_HIGH_RELEVANCE`.

## 8. The refined “asshole story” test

The canonical example can now be stated more precisely.

B behaves in a way that resembles an older relational pattern around C.

A does **not** need the machine to immediately load the old C episode into conscious memory.

A more lawful possibility is:

```text
B's observable behavior
-> actor-specific received reading
-> recruits durable relationship expectation / mediator / causal trace
-> guardedness + irritation + heightened attention
-> related event-referential memory becomes relevant
-> if lawfully accessible/recalled, story about C becomes available for expression
-> A tells the story
-> A consciously knows the story
-> A may not know why this story came to mind now
```

Another lawful possibility is:

```text
B's behavior
-> durable mediator / causal trace recruited
-> guardedness and topic avoidance
-> no explicit old story recalled at all
```

Both preserve historical causation.

Therefore the system must not require:

`CURRENT_TRIGGER -> EXPLICIT_OLD_MEMORY -> CURRENT_RESPONSE`.

Sometimes the correct chain is:

`CURRENT_TRIGGER -> DEVELOPED_PERSON_OR_CAUSAL_TRACE -> CURRENT_RESPONSE`.

Explicit memory is optional and separately governed.

- relevant durable expectations;

- user discourse under uncertainty;

`GENERAL_SITUATED_RECRUITMENT = SHARED_PERSON_PHENOMENON` is a strong current hypothesis.

`HIGH_RESOLUTION_USER_INTERACTION_RECRUITMENT = PFF_PRIMARY_SPECIALIZATION`.

`SHARED_PERSON_PHENOMENON != SHARED_STORAGE_OBJECT_OR_COMPONENT`.

## 10. Recruitment is not durable mutation

A durable mediator may be recruited intensely now without becoming stronger durably.

A tension may become active without being reinforced.

A striving may guide one response without changing the striving object.

A causal trace may participate without an ADP-016 accessibility transition.

A relationship memory may become current context without durable relationship update.

Therefore:

`LIVE_RECRUITMENT != DURABLE_UPDATE`.

`CURRENT_USE != REINFORCEMENT`.

`CURRENT_RELEVANCE != DURABLE_IMPORTANCE_CHANGE`.

If a current episode produces an actual durable consequence, that consequence must return through the exact V3 authority that owns the relevant change.

This is essential to preventing PFF from becoming an implicit second developmental engine.

## 12. Recruitment and ADP-016 memory cues must not be conflated

This seam is now exact enough to state clearly.

PFF may machine-side bind or live-recruit a V3 memory/trace as part of present computation.

That **does not** self-authorize an ADP-016 `RECALL`, `REACTIVATE`, `ACCESS_INCREASE`, or other memory-state transition.

ADP-016 requires its own lawful V3 causal basis/cue and transition authority. Presentation-only interaction, transcript lines, keyword hooks and renderer artifacts are explicitly insufficient direct cues.

Therefore:

`PFF_LIVE_RECRUITMENT_OF_MEMORY_REF != ADP016_MEMORY_TRANSITION`.

`PFF_MACHINE_DISCOVERY_OF_MEMORY_REF != ADP016_RECALL`.

`PFF_MESSAGE_SIMILARITY != ADP016_CAUSAL_CUE`.

If a user interaction is to durably change memory accessibility or reactivate memory under V3, the interaction must first acquire the exact causal/admission status required upstream and then pass the appropriate memory transition rule.

## 13. Recruitment should be purpose-bounded

Deep material should not become available merely because it is interesting or psychologically plausible.

Different computations may legitimately need different subsets:

- current appraisal/metabolism;
- conflict evaluation;
- defense/regulation;
- conscious-field formation;
- memory-access candidate evaluation under the lawful V3 seam;
- action/expression tendency formation;
- audit/replay.

The same durable source may be machine-visible for one purpose but actor-/renderer-invisible.

Thus:

`RELEVANCE_FOR_PURPOSE_X != UNIVERSAL_VISIBILITY`.

`DISCOVERY_PERMISSION != EXPRESSION_PERMISSION`.

No exact policy or capability architecture is adopted here.

## 15. The likely semantic remainder is a relation, not a new psyche object

After factoring existing V3 capital, the remaining conceptual obligation looks narrower than a `PsychicRetrievalEngine`.

A successful system must be able to represent or compute something equivalent to:

> In current episode/configuration Q, durable structure S participates in role R, because of current trigger/reading/context C, with uncertainty/provenance U and visibility/owner ceiling V.

This does **not** mean architecture should create a `RecruitmentRecord` with those fields.

It means the relation itself must not be lost.

Potential role distinctions include:

- appraisal-shaping;
- conflict-producing;
- protective/regulatory;
- action-affording;
- response-sensitizing;
- relationship-analogical;
- memory-associated;
- self-model-supporting/contradicting;
- consciously focal;
- consciously inaccessible but causally active.

The true semantic remainder may therefore be **connective psychology over existing durable objects**, exactly as the wider PFF campaign has increasingly predicted.
