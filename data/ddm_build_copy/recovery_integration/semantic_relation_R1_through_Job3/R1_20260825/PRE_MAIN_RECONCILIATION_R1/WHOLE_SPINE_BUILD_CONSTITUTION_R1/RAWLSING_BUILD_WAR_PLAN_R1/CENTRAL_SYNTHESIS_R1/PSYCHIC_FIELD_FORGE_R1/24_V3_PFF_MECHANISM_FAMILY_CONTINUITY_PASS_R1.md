## 4. Central discovery — CAN-008 is a major continuity bridge

- periodic V3 uses the transformation logic over admitted generated life inputs and commits only authorized durable effects;
- interactive PFF uses compatible transformation logic over lawful user-interaction readings and fast live state without automatically committing durable V3 effects.

This is **not** authority to repurpose CAN-008 as PFF runtime today.

## 5. Need axes

CAN-010 preserves ten need-axis semantic references:

`attachment / safety / belonging / status / competence / autonomy / meaning / justice / beauty_play / eros_intimacy`.

It explicitly does **not** make them actor magnitudes, birth profiles, priorities, deprivation scores, satisfaction scores, or personality labels.

### 5.1 V3 durable role

The need-axis vocabulary is V3-owned reference semantics.

A generated person may have historically formed expectations and strivings scoped to these axes, but the bare axis does not itself create actor state.

### 5.2 Shared logic candidate

PFF should be able to recognize that a user interaction is relevant to one or more need domains because the durable person's organization is organized around them.

Example:

`user teasing`
`+ actor history`
`-> status relevance + eros/intimacy relevance + belonging relevance`

This is not the same as assigning three need scores.

The shared person-level principle is:

> Present events matter partly through which historically meaningful need domains they touch.

That applies during both life development and chat.

### 5.3 PFF-fast role

PFF may hold **current recruitment toward a need axis** or current need-relevant conflict as part of live configuration.

It should not create a new permanent need object merely because a message touches attachment or status.

### 5.4 V3 enrichment from PFF

PFF's work suggests that need relevance should rarely be treated in isolation.

The same event may recruit multiple need domains whose consequences depend on expectations, strivings, mediators, tensions, relationship context, self-model, and current condition.

Periodic V3 rules should therefore be wary of formulas of the form:

`EVENT_CLASS -> NEED_DELTA`.

A more psychologically valid future V3 rule may need to ask how this actor's already-developed organization receives the event.

### 5.5 Semantic remainder

No new durable PFF need state is presently justified.

Potential missing concept is only the **fast relation of current interaction to durable need domains**, not a second need ontology.

## 6. Expectations

CAN-010 already gives actor-specific qualitative expectation postures over exact need-axis/scope:

- `ENTITLED`;
- `HOPEFUL`;
- `FORBIDDEN`;
- `HOPELESS`.

It permits sparse, historically updateable, contradictory expectation records and explicitly separates expectation from objective truth, belief, and knowledge.

### 6.1 V3 durable role

Durable expectation records belong in V3.

They are generated-history products and update only under exact V3 rules and causal parentage.

### 6.2 Shared logic candidate

Expectations appear central to both developmental and interactive metabolism.

A present input can be experienced as:

- fulfillment;
- violation;
- confirmation;
- disconfirmation;
- unexpected possibility;
- threatened loss;
- unavailable pursuit;
- permission/prohibition conflict.

The same semantics can explain why identical external content affects two actors differently.

### 6.3 PFF-fast role

During chat, PFF should be able to use durable expectations as causal context and form **fast anticipated consequences/hypotheses** about the user.

But a turn-specific thought such as:

> "If I tell her this, she'll laugh at me."

is not automatically a new durable CAN-010 expectation record.

Fast user-specific anticipation may be interaction state, conscious hypothesis, or actor epistemic content depending on exact later architecture.

### 6.4 V3 enrichment from PFF

PFF strongly suggests that expectation change should depend not only on occurrence but on **how the actor interpreted/metabolized the occurrence**.

A supportive event may fail to revise a hopeless expectation if the actor interprets it as pity, manipulation, exception, or accident.

Conversely, a single highly diagnostic event may matter more than repeated ambiguous events.

This means future V3 expectation-update rules may need to consume actor-specific response/metabolism rather than raw event category alone.

### 6.5 Semantic remainder

The likely missing shared concept is **expectation-relative appraisal/violation**, not another expectation store.

## 28. PFF discoveries that should feed back into V3 conceptual development

Current high-value feedback candidates:

### 28.1 Actor-specific appraisal before response

Periodic V3 should not let objective event labels directly dictate psychic effect.

### 28.2 Nonlinear multi-motive conflict

Durable needs/strivings/tensions should be able to coexist and jointly shape response without scalar winner selection.

### 28.3 Mediator recruitment is contextual

Persistent mediators may operate differently across relationships/situations/conditions.

### 28.4 Defense is causal transformation, not style

Defense can alter interpretation, awareness, action selection, and later learning.

### 28.5 Memory relevance != recall

Causal-trace effects can operate without conscious recollection.

### 28.6 Self-model exposure/reinterpretation

Events can expose, recontextualize, distort, or genuinely create durable self-understanding; these are different developmental outcomes.

### 28.7 Anticipated futures influence present response

Actors may respond to expected consequences, not just current event content.

### 28.8 Hysteresis is path dependence, not universal decay

History may alter readiness/routes rather than merely leave a decaying scalar.

### 28.9 Own actions feed back into development

Actor self-observation should be causally possible under proper event/admission rules.

### 28.10 Durable condition != local condition

A relationship/event can temporarily recruit a constrained or unusually open regime without immediate whole-person attractor change.

## 32. Current architecture implication — not adoption

The likely future architecture burden is to find a way for one durable V3 person to be **projected into an interaction-time causal working regime** where existing durable structures can be selectively recruited, combined, inhibited, made conscious or kept hidden, and expressed without duplicating durable ownership.

That working regime must also be able to return significant interaction consequences to V3 through exact admission rather than hidden mutation.

Whether this becomes:

- one shared transition kernel with different commit policies;
- several shared semantic rules with separate runtimes;

- a PFF-derived working projection over a V3 snapshot;

is explicitly **not decided here**.
