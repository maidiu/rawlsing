## 2. Executive source finding

The comparative evidence does **not** validate a causal grammar of:

```text
COUNTRY / SYSTEM / CLASS CATEGORY
-> PSYCHOLOGY
```

It strongly validates the more exact grammar:

```text
SYSTEM / INSTITUTIONAL CONFIGURATION
-> ACTOR'S RELATIONAL POSITION
-> CONCRETE WORK/LIFE CONDITION OR RECURRENT ACTIVITY
-> MEASURED OUTCOME
```

The book is unusually useful for Rawlsing because it contains both a successful portability case and a hostile failure case.

Successful portability:

```text
CLASS / STRATIFICATION
-> OCCUPATIONAL SELF-DIRECTION
-> VALUES / IDEATIONAL FLEXIBILITY / SELF-DIRECTED ORIENTATION
```

survives comparison between capitalist US and state-socialist Poland at the mechanism-family level.

Hostile failure:

```text
CLASS / STRATIFICATION / OCCUPATIONAL SELF-DIRECTION
-> DISTRESS
```

does not port intact. The broad class/stratification relation reverses substantially across systems, and occupational self-direction's ameliorative effect on distress disappears in Poland. The source responds by searching for concrete institutional differences—job protections, labor law, authority organization, benefits, party/manager relations—not by treating country as causal essence.

This is precisely the portability discipline SDTF needs.
