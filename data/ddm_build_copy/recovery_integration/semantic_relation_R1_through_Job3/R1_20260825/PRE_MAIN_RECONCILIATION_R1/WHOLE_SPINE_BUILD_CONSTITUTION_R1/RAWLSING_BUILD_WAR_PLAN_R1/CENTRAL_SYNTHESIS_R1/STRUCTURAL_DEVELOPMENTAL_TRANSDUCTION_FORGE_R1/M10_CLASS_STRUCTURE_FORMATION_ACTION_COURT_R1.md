# M10 — CLASS STRUCTURE / FORMATION / ACTION COURT R1

STATUS: `COURT_COMPLETE`

## 1. Mandatory distinctions

Wright's book requires the following non-collapse:

```text
CLASS STRUCTURE
!= OBJECTIVE INTEREST / STRUCTURAL STAKE
!= CLASS CONSCIOUSNESS
!= CLASS FORMATION
!= ORGANIZATION
!= COLLECTIVE ACTION / STRUGGLE
!= SUCCESSFUL STRUCTURAL EFFECT
```

### CLASS STRUCTURE

A structure of relations/positions into which specific incumbents enter. It can contain vacant positions and persists through turnover of occupants.

Runtime translation: position schemas, property/control/gate rules and active actor bindings.

### OBJECTIVE INTEREST / STRUCTURAL STAKE

A counterfactual material stake implied by the relation: changes to an asset/property/exploitation relation would alter resources, toil, consumption, capacity or exit.

Runtime/analysis translation: relation-grounded stake with provenance where useful.

### CLASS CONSCIOUSNESS

Wright decomposes subjectivity into:

1. perceived alternatives;
2. theories of consequences;
3. preferences/evaluations.

These are **not** contained in the class relation itself. They belong to subject process.

### CLASS FORMATION

Formation of organized collectivities among people occupying structural locations. Wright explicitly treats formation as variable and historically contingent.

Runtime translation: membership, network, organization, recruitment, coordination, coalition and collective-decision relations.

### COLLECTIVE ACTION / STRUGGLE

Realized practice by actors/organizations. Requires capacities/resources and a concrete target/counterpart.

### STRUCTURAL EFFECT

Change in law, property relation, organizational allocation, institutional rule, resource distribution or other world fact after response/gate. Success is not guaranteed by action.

## 2. Objective interest != subjective motive court

Terminal finding:

```text
OBJECTIVE_STRUCTURAL_STAKE
!= RECOGNIZED_INTEREST
!= PERCEIVED_ALTERNATIVE
!= EXPECTED_CONSEQUENCE
!= PREFERENCE
!= REASON_FOR_ACTION
!= MOTIVE
!= ACTION
```

Wright is explicit that objective interests can be defined independently of concrete subjectivities. He then builds a distinct theory of class consciousness precisely because perceptions/theories/preferences mediate choices.

Rawlsing therefore must not implement:

```text
capitalistically_exploited -> anti_capitalist_motive
manager -> hierarchy_preference
worker -> solidarity
credential_holder -> elitism
contradictory_location -> ideological_ambivalence
```

All are prohibited unless an existing V3 process earns them from lived facts and subject history.

## 3. Structure -> formation court

Wright rejects a one-to-one mapping. The lawful chain is:

```text
STRUCTURAL RELATIONS
-> DISTRIBUTED RESOURCES / DEPENDENCIES / OBJECTIVE STAKES / CAPACITIES
-> AVAILABLE ORGANIZATION / NETWORK / INSTITUTIONAL CHANNELS
-> RECRUITMENT / MEMBERSHIP / COORDINATION / POLITICAL MEDIATION
-> POSSIBLE COLLECTIVE FORMATION
-> REALIZED COLLECTIVE DECISION/ACTION
```

Alternative formations can be religious, ethnic, regional, occupational, national, etc. Class relation supplies a terrain, not a guaranteed identity.

## 4. Consciousness mediation court

Wright's unemployment example is decisive. The same objective event does not dictate whether it is understood as personal failure or social injustice. Parties, unions, state policy, schools and other social mediators shape available interpretive categories.

Rawlsing mapping:

```text
OBJECTIVE EVENT/CONDITION
+ REACHABLE INSTITUTIONAL/NETWORK INFORMATION CHANNELS
+ ACTUAL EXPOSURE/PARTICIPATION
-> V3-ELIGIBLE GROUNDS / INPUTS
-> SUBJECTIVE INTERPRETATION ONLY UNDER V3 AUTHORITY
```

## 5. Collective action / D3 court

Wright's class-alliance and political-conclusion analysis supports a gated feedback architecture:

```text
RELATIONAL POSITIONS
-> RESOURCES / STAKES / CAPACITY CONSTRAINTS
-> ORGANIZATION + ALLIANCE + COORDINATION
-> ACTION
-> INSTITUTION / EMPLOYER / STATE / COUNTERPART RESPONSE
-> SUCCESS / FAILURE / PARTIAL EFFECT
-> CHANGED RULE / ASSET ACCESS / ORGANIZATION / LABOUR RELATION
-> LATER ACTOR ECOLOGY
```

The source also supports **failed formation** and **failed action**. A structural position can fail to become an organization; an organization can fail to mobilize; mobilization can fail at the institutional gate. D3 must preserve each break.

## 6. Household formation warning

Wright hypothesizes household class heterogeneity may alter collective formation. That is not a direct actor rule. Rawlsing must recover the actual channels: pooled income, dependence, spouse/kin organization ties, time/care obligations, material cross-stakes, information exposure, conflict/support. Only those can become actor-relative facts.
