# IMPLEMENTATION_GRAIN_RECOMMENDATIONS_R1

STATUS: `RECOMMENDATIONS_ONLY__NO_PRODUCTION_IMPLEMENTATION_AUTHORIZED`

The theory campaign recommends implementation grains only after HQ adoption and after current project authority is re-read. These grains deliberately maximize reuse.

## Grain G0 — authority/current-state recheck

Before code changes, recover project-current status of OBL055–061, OBL062/CAN-008 reconciliation, and exact positive laws for CAN-009/012, ADP-015, CAN-025, MUST-018 if later relevant.

Reason: lane R's commissioned freeze proved semantics/current contracts but also proved that several positive first-OEE facts were absent at that time. Do not implement against stale campaign-start assumptions.

## Grain G1 — generalized actor-relative derivation rule contract

Implement or formally generalize the smallest rule interface capable of:

```text
admitted structural fact
+ actor activation / phase / world / time / context
+ exact position/relation binding
+ mechanism-family rule
+ optional history/counterpart/institution qualifiers
-> typed actor-relative qualified social-ecology fact
```

Required outputs include resource/dependency, authority/control, obligation/sanction, activity/task, gate/eligibility, counterpart, information/support channel and time/schedule qualifiers.

Prefer extending existing selector/applicability evaluation architecture if it can preserve type, provenance and negative ceilings. Do **not** mutate the exact semantics of OBL059 merely by renaming it; create a generalized contract only if explicit compatibility is proved.

## Grain G2 — persistent condition/relation/recurrence semantics

Prove whether existing state/binding/relationship/CAN-011/history carriers can exactly encode:

```text
ACTIVE_INTERVAL(condition)
DIRECTED_PERSISTENT_RELATION(counterpart, powers/obligations)
RECURRENT_ACTIVITY(identity, content, quality, intensity, duration)
```

Only create new carrier structure if exact incompatibility is demonstrated. A solution based solely on emitting repeated synthetic OEE events fails the temporal court.

## Grain G3 — transition ecology rebinder

Generalize phase/world/context binding so a realized transition can produce an auditable before/after social-ecology update:

```text
transition
-> prior binding deactivation/modification
-> new resource/relation/obligation/activity/context activation
-> provenance-preserved post-transition ecology
```

This grain must be transactionally coherent enough that linked dimensions cannot silently disagree about which position/time/world is active.

## Grain G4 — type-specific realization adapters

Reuse existing ADP-019/OBL055–061/OEE for discrete occurrences wherever competent. Add only bounded adapters for non-OEE forms:

- entitlement/applicability → active resource fact;
- formal authority → enacted/exercised relation;
- activity opportunity → realized recurrent performance history;
- information/support channel → actual transfer/exchange;
- eligibility → actual gate decision/treatment.

No adapter may mint actor uptake or durable development.

## Grain G5 — linked-life / cross-context propagation

Add a generic **typed dependency path**, not a family-specific hard-coded sociology module:

```text
source context/person change
--[resource | time | obligation | support | relation | gate linkage]-->
focal actor ecology update
```

The linkage type and endpoints must be explicit. `family`, `neighborhood`, `workplace`, or `ecosystem` labels alone are insufficient.

## Grain G6 — reciprocal external-response transaction

Implement the smallest provenance-preserving feedback interface:

```text
actor/collective realized action
-> external counterpart/institution/gate response
-> admitted change in position/relation/rule/resource/network
-> later actor binding/ecology update
```

Actor action cannot directly write a structural fact. Collective action uses ordinary actor/group organization and external response facts; no collective psychological subject is introduced.

## Grain G7 — typed cumulative update composition

Allow domain-specific update rules to iterate over history:

```text
history_t + current gate/resource/relation rule
-> ecology_t+1
```

Do not create a universal `cumulative_disadvantage` numeric state. The composition layer may expose a derived trajectory summary only after preserving all typed steps.

## Grain G8 — downstream interface conformance tests

Prove that outputs can be lawfully consumed by current V3 owners without redefining them:

- TD-R05 event/history separation;
- CAN-008 actor response boundary;
- CAN-010 motivational state only where actor mediation warrants;
- CAN-011 practices/mediators;
- ADP-016 memory/trace;
- ADP-017 objective truth vs actor knowledge/access.

No test may pass by directly assigning motive, belief, mastery, personality, capacity or attractor state from a structural fact.

## Required hostile tests for implementation

1. same class, different household/network/institution routes produce distinct ecology;
2. available opportunity never encountered;
3. chronic low-control condition exists without event spam;
4. repeated autonomous work preserves duration/quality without appraisal each iteration;
5. classification cue with no discriminatory treatment creates no penalty;
6. objective gate denial may occur without actor knowledge;
7. linked person's transition propagates only through an explicit channel;
8. personality/action enters an external gate before later job/network state changes;
9. failed collective action leaves structural condition unchanged;
10. protective support interrupts cumulative disadvantage without erasing prior history;
11. transition is not automatically a turning point;
12. replay produces identical typed provenance and interval boundaries.
