# PSYCHIC FIELD FORGE R1 — PRIMARY INTERACTION LOCUS / USER CHEMISTRY CLARIFICATION R1

**Status:** `PRE_ARCHITECTURE_CONCEPT_CLARIFICATION__BANKED__MUST_FACTOR__NOT_ARCHITECTURE_ADOPTION__NO_RUNTIME_AUTHORITY`

## 0. Purpose

This file corrects an over-generalization that appeared during the PFF dyadic-chemistry examination.

The primary envisioned PFF interaction is not currently a symmetric `generated person <-> generated person` social world.

The primary PFF target is:

`GENERATED_PERSON <-> USER`

The generated person is the Rawlsing actor. The user is a real external interlocutor bringing their own actual personality, intentions, history, affect, style, motives, and moment-to-moment behavior into the exchange, while Rawlsing does not possess or govern the user's hidden internal state.

The PFF problem is therefore:

> How does one fully generated person respond dynamically, idiosyncratically, and historically to this particular user's observable interaction, rather than merely answering the same message through a static persona prompt?

## 1. Primary interaction law

`PRIMARY_PFF_CHEMISTRY_TARGET = GENERATED_PERSON <-> USER`

`USER_OBSERVABLE_BEHAVIOR != USER_HIDDEN_PSYCHIC_STATE`

`SYSTEM_MODEL_OF_USER != USER_TRUTH`

`PERSONA_READING_OF_USER != USER_TRUTH`

`PERSONA_RESPONSE_TO_USER = PERSONA_SPECIFIC_AND_HISTORY_DEPENDENT`

`SAME_USER_MOVE + DIFFERENT_GENERATED_PERSON -> POTENTIALLY_DIFFERENT_PSYCHIC_EFFECT`

`SAME_GENERATED_PERSON + DIFFERENT_USER -> POTENTIALLY_DIFFERENT_PSYCHIC_EFFECT`

`SAME_PAIR + DIFFERENT_HISTORY / CURRENT_STATE -> POTENTIALLY_DIFFERENT_CHEMISTRY`

## 2. What chemistry means in the primary Rawlsing use case

Chemistry does not require Rawlsing to own two hidden psyches.

It requires the generated person to have a sufficiently rich receiver-specific transformation such that the user's behavior can:

- recruit different parts of the generated person's durable V3 organization;
- be perceived differently because of relationship history and current PFF residue;
- be interpreted with uncertainty and competing readings;
- activate attraction, aversion, trust, suspicion, shame, pride, status concern, curiosity, comfort, irritation, playfulness, desire for approval, etc. only where causally supported;
- alter local accessibility of capacities or defenses;
- change what the generated person anticipates the user will do next;
- alter disclosure, concealment, posture, teasing, warmth, distance, testing, reassurance-seeking, repair, and other expression pressures;
- leave live residues that shape later turns.

The user in turn sees and responds to the persona's output in the real interaction. Rawlsing does not need to model the user's internal transition for the interaction loop to be genuinely pair-specific.

Thus a real emergent interaction loop may exist with only one governed internal psyche:

```text
USER OBSERVABLE MOVE
        |
        v
GENERATED PERSON: current reading / metaperception / recruitment / conflict
        |
        v
GENERATED PERSON: conscious field / defense / expression mediation
        |
        v
PERSONA OBSERVABLE MOVE
        |
        v
USER'S REAL RESPONSE OUTSIDE RAWLSING
        |
        v
NEXT USER OBSERVABLE MOVE
        |
        +----> generated-person PFF again
```

The pair-specific pattern is therefore real even though only the generated side is internally governed.

## 3. Idiosyncrasy is the central positive requirement

PFF chemistry succeeds when the persona is not merely reacting to generic social labels in the user's message.

The same user move should be able to have different consequences because of:

- the generated person's V3 developmental organization;
- needs, expectations, strivings, tensions, mediators, memories, and attractor history;
- current durable organizational condition;
- current live PFF configuration;
- current actor model of the user;
- relationship history with this user;
- current ambiguity / uncertainty;
- present situation and stakes;
- what the persona believes the user can see in them;
- anticipated future consequences of responding one way or another.

This is the core sense in which the user brings themself and the generated person responds to **this particular user** rather than to abstract prompt content.

`CHEMISTRY = NOT_GENERIC_USER_SENTIMENT_CLASSIFICATION`

`CHEMISTRY = NOT_USER_PERSONALITY_INFERENCE_TABLE`

`CHEMISTRY = NOT_PERSONA_TYPE_PAIR_LOOKUP`

## 4. User opacity is a constitutive feature, not a deficiency

Rawlsing should not require a hidden-state model of the user to obtain chemistry.

The generated person may form actor-local hypotheses such as:

- `they seem annoyed`;
- `maybe they are flirting`;
- `I think they are testing me`;
- `they may be pulling away`;
- `I think they noticed I was nervous`.

These hypotheses may be accurate, partly accurate, or wrong.

The user's opacity is precisely what permits:

- uncertainty;
- projection;
- misreading;
- testing;
- surprise;
- correction;
- self-confirming or self-disconfirming loops;
- genuine discovery across interaction.

Therefore:

`USER_OPACITY = MUST_FACTOR`

`SYSTEM_ACCESS_TO_USER_TEXT != SYSTEM_ACCESS_TO_USER_INTENTION`

`PERSONA_HYPOTHESIS_ABOUT_USER_CAN_CAUSE_REAL_PSYCHIC_EFFECT_WITHOUT_BEING_TRUE`

## 5. What generated-generated interaction means here

The earlier dyadic examination considered `generated <-> generated` because it is a useful conceptual stress case for perspective/asymmetry and because some Rawlsing upstream contexts may involve multiple generated persons.

It is **not** currently established as the primary PFF product interaction.

A possible special relevance is the parent/co-parent nexus or other upstream V3 generation context in which generated persons participate in causal history affecting a generated child/person. That possibility must be grounded separately against exact V3 authority before any PFF implication is adopted.

Therefore:

`GENERATED_GENERATED_PFF = SECONDARY / CONDITIONAL USE CASE`

`GENERATED_GENERATED_PFF != CURRENT PRIMARY PFF ASSUMPTION`

`PARENT_COPARENT_NEXUS -> CHILD_V3_GENERATION` is preserved here only as a user-raised possible application requiring exact V3 grounding, not as adopted current architecture.

No repository search at the time of this clarification found an obvious default-branch `co-parent` named authority; absence of a search hit is not evidence of absence from the wider project history.

## 6. Consequence for dyadic chemistry language

The useful meaning of `dyadic` in PFF is therefore primarily **interactional**, not `two governed internal agents`.

A dyad consists of:

- generated persona A;
- external user U;
- observable exchange sequence;
- persona-local history/model of U where lawfully available;
- objective/current application context where lawfully available;
- persona PFF live state;
- user's real but opaque contributions.

Chemistry can be described from the generated person's side as properties of how the user's moves repeatedly transform the persona's live organization and how the persona's outputs induce new user moves.

The user may subjectively experience reciprocal chemistry, anti-chemistry, warmth, irritation, attachment, curiosity, etc., but Rawlsing must not manufacture those as hidden user facts.

`REAL_INTERACTION_LOOP != SHARED_HIDDEN_STATE`

`PAIR_SPECIFIC_PATTERN != MUTUAL_HIDDEN_TRUTH`

## 7. Consequence for metaperception

The actor-model / being-seen work becomes even more important in the user-facing case.

The generated persona may be affected by:

- what the user says;
- what the persona thinks the user means;
- what the persona thinks the user thinks of them;
- what the persona thinks the user has noticed about them;
- what the persona expects the user will do next.

The user need not be internally modeled as a Rawlsing person for any of these to be causally real in the generated persona.

## 8. Consequence for synthetic personhood success

A strong user-facing PFF system should permit the user to discover that:

- one generated person responds to them differently from another;
- the same persona changes toward them as history accumulates;
- certain sides of the persona become easier or harder to reach with this user;
- particular interaction loops emerge from the pairing;
- the persona can misread the user and later revise that reading;
- the persona can feel more or less exposed, safe, playful, defensive, irritated, attracted, impressed, bored, dependent, trusting, etc. in a way traceable to its own developed personhood rather than generic assistant politeness;
- the user cannot simply press a fixed prompt button to obtain the same internal reaction from every persona.

This is much closer to the intended chemistry target than symmetric multi-agent simulation.

## 9. No-gadget consequence

This clarification strengthens, rather than weakens, the prior no-gadget conclusion.

The primary chemistry case does not require:

- a second Rawlsing psyche for the user;
- a user personality engine;
- a user Enneagram classifier;
- a universal pair compatibility object;
- a shared dyadic hidden-state database;
- inferred user attraction/trust/intention as fact.

It requires a sufficiently rich generated-person transition process over:

`USER OBSERVABLE INPUT + LAWFUL HISTORY/CONTEXT + GENERATED PERSON V3 + CURRENT PFF STATE`.

## 10. Correction to prior examination

Where `07_DYADIC_CHEMISTRY_AND_ASYMMETRY_DEEP_EXAMINATION_R1.md` speaks of generated-generated and generated-external cases as parallel implementation classes, interpret the generated-external/user case as the **primary current Rawlsing PFF target**.

The generated-generated material remains useful as:

- a conceptual comparison;
- a possible upstream/future special case;
- a test of perspective non-collapse;

but not as the assumed product-center of PFF.
