# RAWLSING BUILD WAR PLAN R1

## Objective

Reach the smallest fully lawful end-to-end capability:

`SOURCE-BACKED EVIDENCE → STRUCTURAL WORLD → DEVELOPING PERSON → ACCESSIBLE/SITUATED CLAIM → BOUNDED EXPRESSION/ACTION → OBSERVABLE INTERACTION → V3 CAUSAL RETURN → CHANGED FUTURE PERSON`

with maximal legitimate parallelism, zero silent obligation loss, no invented authority, and no archaeology unless a current capability proves it needs exact missing history.

## Planning doctrine

### Readiness classes

- `BUILD_READY` — semantics/authority substantially exist; implement/compose/test.
- `ADAPT_READY` — accepted function exists but exact interface integration is needed.
- `CONSTITUTION_REQUIRED` — required function is known but its semantic owner/object/rule is not yet lawfully fixed.
- `EMPIRICAL_COURT_REQUIRED` — exact empirical premise must be established before execution.
- `FORENSIC_IF_TRIGGERED` — recover exact historical evidence only if an active decision cannot be resolved otherwise.
- `DEFERRED_UNTIL_FORCED` — real visible debt with no present starvation witness.
- `SATISFIED_OR_SUPERSEDED` — old planning grain has been closed or replaced by later current authority.
- `BLOCKED_EXTERNAL_OR_MISSING_EVIDENCE` — active path is starved on unavailable exact evidence.

### Work law

1. No obligation disappears; every touched item receives a disposition.
2. Current critical path is determined by the next stronger Golden Thread, not by historical campaign order.
3. Build capability through the stack; do not finish layers in isolation.
4. Constitute hard semantics exactly when a concrete vertical capability first requires them.
5. Reuse current accepted implementation capital before redesign.
6. A typed blocked/noncomparable/valid-empty outcome is a successful execution when it truthfully identifies the current ceiling.
7. Physical architecture remains neutral until a named capability cannot proceed without choosing it.
8. Exact history is pulled only by a demonstrated dependency.
9. Audit only authority promotion, architecture adoption, canonical movement, or high-risk semantic transformation.
10. After one material audit defect: bounded repair, exact rereview, stop.
