## 7. Physical architecture is not the current critical path

The explicit test requested by HANDOFF C is negative: no current first-positive capability requires a global physical winner.

A bounded relation can be:

- produced by direct deterministic query;
- materialized transiently;
- persisted as an exact object;
- reconstructed from exact source-backed inputs;
- indexed or stored through another exact carrier;

without changing its semantic owner.

Current V557/V558 code already separates logical publication/resolution from semantic ownership and permits exact content-addressed / bundle-local resolution. R2 explicitly rejects `PHYSICAL_PERSISTENCE == SEMANTIC_TRUTH`.

Therefore `OBL001/002/037` should be trigger-deferred.

### Physical-court trigger

Activate the court only when at least one of the following becomes true:

- a named Golden Thread requires restart/latency/availability/throughput/retention behavior and otherwise-equivalent physical candidates cannot all satisfy the acceptance test;
- source or carrier retirement is proposed;
- learned-product invalidation/rebuild economics materially differs by candidate and becomes decision-constitutive;
- serving deployment requires a durability/transaction/topology commitment whose semantic parity cannot remain carrier-neutral.

At that point equal-governed-workload evidence is required. Convenience, current module layout, prototype speed or source-backed feasibility are insufficient.
