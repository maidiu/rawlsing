## 1. Court posture

This court treats frozen R4 as controlling semantic authority and Files 39-43 as a proposed companion specification. The coordinator synthesis and S1-S5 returns are evidence, not proof. The question is whether the companion makes R4 mechanically explicit without changing what R4 makes true, who owns it, or what evidence is sufficient.

The package is largely sound. It preserves D1' as an objective PRE-V3 social/world consequence function, preserves P1-P5 as rule classes, keeps OBL062 open, and does not create psychology, a world writer, D2, D3, D4 or P6.

Two bounded corrections are required before the package can be called a faithful companion to the frozen R4 text:

1. K4 Path B must be stated so that it still satisfies R4's universal requirement for a type-compatible competent witness/state whose lawful validity/support interval overlaps the asserted interval. Complete termination coverage may keep an owner-declared persistent state open; it may not make an old point-event witness itself current.
2. Bare `ACTIVE` cannot be made exclusive to K4. R4 itself uses `ACTIVE OBLIGATION` as a constitutive/deontic example. `K4 ACTIVE_DURATIVE` may remain the proof-kind token, but the bare R4 word `ACTIVE` must remain an umbrella current-state descriptor whose proof may be K1 when the operative source-owned relation/state constitutes the obligation/right/scope.

Neither correction changes R4 topology. Both prevent the companion from changing R4 while purporting to specify it.


For constitutive/deontic/positional facts, the operative source-owned relation/state may itself be the type-compatible witness. R4 explicitly gives examples including legal eligibility, active duty/obligation, authority scope, entitlement and valid restriction.

```text

ELIGIBLE != APPLIED
```

and says no new owner or status ontology follows; the distinction constrains witness schemas.

These points control the companion.

## 6. K4 Path B consistency defect

File 39 currently permits:

```text
COMPETENT ESTABLISHMENT WITNESS/STATE
+ EXPLICIT OWNER-AUTHORIZED PERSISTENCE SEMANTICS
+ COMPLETE AUTHORITATIVE TERMINATION/SUPERSESSION/INVALIDATION COVERAGE THROUGH QUERY TIME
+ NO COMPETENT CLOSING FACT
=> CURRENT K4
```

This is semantically plausible, but S2 states the stronger proposition that a point-in-time establishment event may support later currentness even though that event witness does not overlap the later query interval. Read literally, that changes frozen R4 §5.1, which requires a type-compatible competent realization witness whose validity overlaps the asserted interval.

### 6.1 Lawful reconciliation

Path B is lawful **only** when the competent owner semantics establish a continuing-state witness/state whose lawful `ASSERTED_OR_SUPPORTABLE_INTERVAL` extends through the queried interval.

The proof must be representable as:

```text
COMPETENT ESTABLISHMENT OF STATE S
+ OWNER-AUTHORIZED PERSISTENCE LAW FOR S
+ COMPLETE AUTHORITATIVE CLOSING-EVENT/STATE COVERAGE
+ NO CLOSING FACT
=> TYPE-COMPATIBLE COMPETENT STATE WITNESS FOR S
   WITH SUPPORTABLE VALIDITY INTERVAL OVERLAPPING QUERY INTERVAL
=> CURRENT K4(S)
```

Not:

```text
OLD POINT EVENT E
+ CURRENT RULE
+ NO KNOWN TERMINATION
=> E ITSELF IS CURRENT
```

And not:

```text
OLD TRANSFER EVENT
+ COMPLETE SILENCE ABOUT TERMINATION
=> NEW/CURRENT TRANSFER OCCURRENCE
```

An old transfer can remain a historically true K3 event. It can establish a distinct K4 state only when the competent owner explicitly defines that state and its persistence/closure semantics.

### 6.2 Fail-closed consequence

If persistence semantics do not create/maintain a type-compatible state witness with a supportable interval overlapping the claim, currentness is:

`UNKNOWN_NOT_PROVEN`

not current positive and not negative.

Verdict: `NARROWING_REQUIRED`.



The companion must not force a K1 operative obligation into K4 merely because ordinary prose calls it active.

Verdict: `NARROWING_REQUIRED`.
