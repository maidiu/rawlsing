## 4. Modalities must remain noncollapsed

Shared semantics do not imply identical execution.

### Developmental / V3 modality

- event sources come from generated world / relationships / admitted externals;
- scheduler may span events, context changes, phases and slow ticks;
- transitions may have deep/durable developmental consequences;
- exact causal ledger/replay is authoritative;
- actor state may be persistently updated only by competent V3 rules.

### Interaction / PFF modality

- ingress begins from user discourse and bounded candidate readings;
- the user remains opaque rather than generated as analyst-known truth;
- cadence is turn/session scale;
- many consequences are live, focal, residual, inhibited or consciously partial rather than durable;
- current session state may exhibit hysteresis without becoming biography;
- actual interaction may return to V3 for durable change only through explicit admission;
- expression is handed to V2 under actor-access and anti-rescue constraints.

The design objective is:

`SAME_PERSON_LOGIC_WHERE_SEMANTICALLY_TRUE__DIFFERENT_PERSISTENCE_DEPTH_TIMESCALE_AND_INGRESS_AUTHORITY`.
