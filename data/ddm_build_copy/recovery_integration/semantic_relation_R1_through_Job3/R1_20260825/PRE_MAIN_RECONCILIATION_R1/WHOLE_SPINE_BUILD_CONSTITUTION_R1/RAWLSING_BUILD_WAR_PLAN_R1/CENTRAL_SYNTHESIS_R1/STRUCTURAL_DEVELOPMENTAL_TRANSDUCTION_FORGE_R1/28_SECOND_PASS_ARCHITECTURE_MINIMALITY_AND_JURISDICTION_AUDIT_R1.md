## 3. Five-class minimality court

The five entries are **mechanism-rule classes**, not five mandatory storage owners or five universal executable functions.

### P1 — MATERIAL_ACCESS_DEPENDENCY

Distinct causal question:

> What material resource/access/transfer/dependency consequence follows from a property, entitlement, service, transfer or resource relation?

P1 cannot be deleted into P2 because material dependency may exist without directed authority. It cannot be deleted into P5 because a channel/counterpart relation does not establish entitlement, resource state, transfer amount or exit dependency.

`P1 SURVIVES`.

### P2 — DIRECTED_AUTHORITY_OBLIGATION_SANCTION

Distinct causal question:

> What directed right, command, obligation, responsibility, sanction or decision-control scope binds source and target actors?

P2 cannot be deleted into P3 because task content/time may be organized without the same power/obligation relation. P2 cannot be deleted into P5 because a counterpart relation alone has no authority/obligation semantics.

`P2 SURVIVES`.

### P3 — ORGANIZED_ACTIVITY_TIME

Distinct causal question:

> What task/activity/schedule/complexity/routinization/time consequence follows from organized participation?

P3 cannot be deleted into P2: task organization and recurring activity content are not reducible to authority. Peer/cooperative activity and institutionally organized routines can structure activity without a simple source→target command edge.

P3 does **not** independently own formal decision rights. Exercised autonomy/discretion is composition:

```text
P2 decision/control scope
+ P3 task/activity organization
+ actual participation witness
```

`P3 SURVIVES_WITH_SCOPE_NARROWING`.

### P4 — INSTITUTIONAL_GATE_TREATMENT

Collapse attempt:

```text
P4 ?= P2 gatekeeper authority + P1/P3/P5 outcome
```

Rejected at current semantic grain.

P2 can say who has authority to decide and P1/P3/P5 can describe consequences, but neither supplies the **conditional evaluation/selection/treatment transformation** from an exact application/eligibility/record/cue context to a decision/treatment result.

That conditional decision mechanism is independently evidenced by hiring/service/credential/permit/gate literature and is necessary to keep:

`RULE != APPLICABILITY != DECISION/TREATMENT != RESULT`.

P4 may operate outside a formal bureaucracy only if an exact governed gate/evaluation process is defined; generic stigma/recognition remains P2/P5 unless a gate-treatment rule exists.

`P4 SURVIVES`.

### P5 — COUNTERPART_CHANNEL_RELATION

Distinct causal question:

> Which exact counterpart/channel/relation becomes reachable/operative, and what relation-specific transfer/contact/information/support route exists?

P5 cannot be deleted into P1 because nonmaterial information/contact/coordination relations remain meaningful. It cannot be deleted into P2 because many counterpart/channel relations are not authority/obligation relations.

`P5 SURVIVES`.

## 4. Critical correction — class identity versus rule identity

The five-class reduction is lawful only if every actual D1' derivation names an exact governed rule.

Required separation:

```text
MECHANISM_CLASS
!=
MECHANISM_RULE
!=
SOURCE EVIDENCE
!=
ACTOR-SPECIFIC APPLICATION
!=
REALIZATION WITNESS
```

A rule must define at minimum:

```text
RULE_ID / VERSION
AUTHORITY / OWNER
MECHANISM_CLASS
INPUT TYPES
OUTPUT CONSEQUENCE TYPE
APPLICABILITY / QUALIFICATION LAW
REALIZATION_WITNESS_SCHEMA
TEMPORAL / LIFECYCLE REQUIREMENTS
CONTEXT / HISTORICAL VALIDITY
BOUNDARY CONDITIONS
SOURCE / CLAIM STATUS
CALIBRATION STATUS IF ANY
NEGATIVE CEILING
```

A theory mechanism card, observational coefficient, population association or analyst summary cannot become an executable actor-fact rule merely because it maps to P1–P5.

This is the largest contract omission in R2.

## 5. Realization-authority regression

The architecture was replayed against these failure cases:

```text
formal benefit entitlement but actor never receives benefit
scheduled task but actor is repeatedly absent
supervisor title but no operative command power
network tie but no information/support transfer
legal eligibility but no application/decision
classification exists in database but gatekeeper never receives/recognizes it
household member is distressed but performs no changed external action/contribution
formal autonomy exists but actual task remains fully scripted
```

In every case, R3 must preserve a qualified/objective possibility without minting a realized fact.

Required invariant:

```text
STATUS = ACTIVE/REALIZED
=> COMPETENT REALIZATION_WITNESS_REF(S) PRESENT
```

The witness may be an active-state record rather than a discrete event where the temporal form is a condition/relation/recurrent activity. This prevents event-only reduction while still forbidding inference-by-label.

## 6. Actor-history and cross-person leakage court

D1' is an objective social-world derivation function. Therefore:

```text
PRIVATE V3 BELIEF / MOTIVE / DISTRESS / TRAIT / CAPACITY
-X-> D1' OBJECTIVE WORLD FACT
```

A V3 state can matter only by first producing an externalized action/communication/performance through its competent owner, after which competent world/counterpart/institution/source authority records the external consequence.

For linked lives:

```text
SOURCE ACTOR PRIVATE STATE
!= TARGET ACTOR SOCIAL CONSEQUENCE
```

but:

```text
SOURCE ACTOR EXTERNALLY REALIZED ABSENCE / ACTION /
RESOURCE CHANGE / CONTRIBUTION WITHDRAWAL / CARE NEED /
POSITION TRANSITION
+ EXACT RELATION
+ GOVERNED RULE
-> TARGET ACTOR OBJECTIVE SOCIAL CONSEQUENCE
```

This also protects the campaign from psychological contagion disguised as linked-life transmission.

## 7. Developmental-phase jurisdiction court

M1/M8 correctly show that timing/age can modify developmental effects. That does not automatically put developmental phase into D1'.

R3 rule:

```text
DEVELOPMENTAL PHASE / AGE MAY QUALIFY D1'
ONLY WHEN THE OBJECTIVE SOCIAL RULE ITSELF IS PHASE/AGE DEPENDENT
(e.g. school eligibility, age-graded institutional route, legal age rule).

IF PHASE ONLY CHANGES UPTAKE / DEVELOPMENTAL CONSEQUENCE,
IT REMAINS DOWNSTREAM V3 CONTEXT.
```

This distinction prevents Mortimer/Elder heterogeneity from becoming an upstream age→social-effect shortcut.

## 8. Non-event V3 ingress regression

A major boundary issue remains open outside D1' ownership.

CAN-008 R2 supplies a clear event-side ingress kernel. D1' also needs to expose persistent objective social conditions/relations/recurrent activities to the broader V3 system without:

- synthesizing fake events;
- creating a second practice/history owner;
- turning an objective condition into a subjective premise automatically.

Live OBL062 explicitly states that several V3/PFF connective rules remain under two-ended reconciliation.

Therefore the correct R3 posture is:

```text
EVENT D1' FACT
-> use exact current event ingress authority where competent.

CONDITION / RELATION / RECURRENT-ACTIVITY D1' FACT
-> require exact owner-specific conditioning/receipt interface proof.

D1' CONSTITUTION DOES NOT ITSELF CLOSE THAT DOWNSTREAM INTERFACE.
```

This is an **interface dependency**, not a new SDTF owner and not a theory blocker.

HQ may semantically adopt D1' while keeping downstream ingress implementation/owner proof separately open, provided the adoption text does not claim that receipt is already complete.

## 9. Evidence/calibration regression

D1' must not sample or instantiate actor truth from group distributions by itself.

```text
POPULATION RATE / REGRESSION COEFFICIENT / ASSOCIATION
!= ACTOR-SPECIFIC CONSEQUENCE
```

If a simulated social process is stochastic, a competent world/institution/source process must own the stochastic rule/sampling and produce a source-owned outcome/witness. D1' may derive consequences from that outcome; it does not convert evidence distributions into actor destiny.

Similarly:

```text
THEORETICAL CLAIM
!= EMPIRICAL EFFECT SIZE
!= CALIBRATION
!= EXECUTABLE RULE AUTHORITY
```
