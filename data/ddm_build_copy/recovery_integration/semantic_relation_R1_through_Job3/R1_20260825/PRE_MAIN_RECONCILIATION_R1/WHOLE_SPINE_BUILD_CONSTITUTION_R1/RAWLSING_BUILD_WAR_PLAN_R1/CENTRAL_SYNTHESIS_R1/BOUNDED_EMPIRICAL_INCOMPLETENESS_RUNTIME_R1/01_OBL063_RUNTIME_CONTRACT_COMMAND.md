## Problem proved

Rawlsing's historical vector pipeline permits missing driver values to collapse to numerical zero (the old `enneagramBatch.js` uses `countryVec[driver] ?? 0`). That is not lawful evidence semantics.

At the same time, full empirical/documentary authority cannot be required for every family/country/wave as a prerequisite for application existence.

The worker must implement the smallest exact contract that preserves both requirements.

## Exact evidence tiers

Implement exactly:

- `POPULATION_CERTIFIED`
- `SOURCE_LOCAL_CERTIFIED`
- `PARTIAL_AUTHORITY`
- `UNAVAILABLE`

No additional positive tier may be invented.

## Exact runtime fallback states

A missing intended empirical channel may resolve only through an explicitly declared per-driver rule:

- `AUTHORIZED_ALTERNATE_SOURCE`
- `AUTHORIZED_BROADER_PRIOR`
- `VERSIONED_MODEL_PRIOR`
- `WIDEN_UNCERTAINTY`
- `OMIT_CONTRIBUTION`

Any geographic/temporal/source substitution must carry an exact positive relation/backfill authority ref.

A `VERSIONED_MODEL_PRIOR` is non-empirical and must remain labeled as such in the output receipt.

## No-renormalization law

Missing evidence never causes surviving source/channel coefficients to be renormalized unless the exact driver policy contains a separately governed explicit coefficient-reallocation rule.

Default:
`NO_COEFFICIENT_REALLOCATION`.

A driver may fail only where its explicit policy declares a non-fallbackable terminal requirement.
