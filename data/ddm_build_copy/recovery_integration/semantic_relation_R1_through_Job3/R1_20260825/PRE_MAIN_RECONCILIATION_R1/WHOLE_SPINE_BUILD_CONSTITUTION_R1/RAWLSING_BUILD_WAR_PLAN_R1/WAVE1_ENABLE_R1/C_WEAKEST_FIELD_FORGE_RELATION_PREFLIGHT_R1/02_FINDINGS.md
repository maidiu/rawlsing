# WAVE 1C — FINDINGS R1

## 1. Governing semantic floor

FIELD FORGE R2 is already adopted current authority at its exact grain. This lane does not re-argue its architecture.

The relevant adopted rule is:

`PRODUCER_OWNED_FACT != FIELD_FORGE_RELATION`.

A first positive relation must therefore do two things simultaneously:

1. preserve exact upstream producer ownership; and
2. make one explicit actor-independent relation commitment that is not already merely the existence of the upstream fact.

The first thread should pay for the **least additional semantic commitment** beyond a real producer fact.

## 2. Ranking logic

The cost order is driven by new authority requirements, not mathematical sophistication.

### R01 — exact support within scope

This is cheapest when the selected empirical target is unary or otherwise already has a lawful producer-owned positive `EmpiricalFact`.

The proposed relation says only:

> this exact predicate/target has observed positive support in this exact governed scope/risk-set under the exact producer query and measure ceiling.

It does **not** say:

- the relation is causal;
- the support generalizes beyond the exact scope;
- the predicate is socially important;
- the support defines a position, field or mechanism;
- an actor experiences or knows it.

### Semantic-novelty gate

R01 is lawful only if its explicit relation commitment has downstream semantic identity distinct from the producer fact. A FIELD FORGE object that merely copies:

- `raw_numerator_support`;
- `raw_denominator_support`;
- `risk_set_ref`;
- `empirical_query_spec_ref`

and renames that bundle as a structural relation would violate the no-reownership/no-courier rule.

Central fan-in should require an exact statement of the new relation predicate and its target use before choosing R01.

If no nonduplicative relation meaning can be stated without adding stronger theory, **skip R01**.

## 3. First unequivocally relational fallback

R02 exact same-unit conjunction support is the clean fallback.

It creates a relation among two exact participant predicates/states that cannot be reduced to either marginal fact alone.

Its positive meaning is bounded:

> these exact participant predicates co-occur on the same empirical units within the declared risk-set with exact observed support under the producer's governed query semantics.

It requires exact same-unit incidence or an information-equivalent representation.

The following are not substitutes:

- source-native block membership;
- questionnaire adjacency;
- matching labels;
- two positive marginals;
- an association score whose denominator/joint carrier is not exact;
- semantic relation authority without respondent jointability.

If A/B prove a cheap exact pair is already executable, R02 is likely the safest first positive FIELD FORGE relation.

## 4. Conditional support / redistribution

R03 is still weak and explicitly supported by R2 architecture, but it costs more because it needs:

- exact condition predicate;
- exact target predicate/state;
- exact same-unit joint information;
- exact condition/risk-set denominator;
- routing/applicability evidence where the condition changes who could answer;
- explicit baseline/reference if a redistribution/difference is claimed.

A plain conditional-support relation is weaker than a redistribution relation because it does not need a second reference distribution.

If redistribution is chosen, the baseline must be a first-class semantic participant or exact rule input. No implicit "overall", "other", "past", or "normal" baseline is lawful.

Crucially:

`CONDITIONAL_REDISTRIBUTION != STRUCTURAL_PRESSURE_MECHANISM`.

## 5. Directional comparison

R04 should not be selected merely because two numbers are available.

A greater/less/equal relation is a semantic commitment to:

- comparability;
- orientation;
- order;
- measure semantics;
- scope/time compatibility.

If these are not already exact from the producer claim, R04 is more expensive than a simple support/conjunction relation.

No significance, stability, materiality, substantive importance or generalization follows from an exact descriptive difference unless separately authorized.

## 6. Alternative/branch sets

R05 can be weak where a finite exact alternative set is already producer-authorized.

But a candidate set must declare its quantifier ceiling:

- exact complete set for a bounded frontier; or
- exact known members with nonexhaustive coverage.

Do not turn discovery results into an implicitly exhaustive ontology.

Branch membership does not imply actor choice, route realization, position or life trajectory.

## 7. Position-disposition dependence

R06 is intentionally retained but ranked last for the first thread.

It becomes cheap only if the selected empirical source already has exact current role authority for both participants. Otherwise it triggers claim-specific OBL005/PRA and perhaps transformation/measurement gates.

Even if the descriptive dependence is lawfully identified:

`POSITION_DISPOSITION_DEPENDENCE != HOMOLOGY`

and:

`POSITION_DISPOSITION_DEPENDENCE != FIELD`.

The relation also says nothing about actor encounter, internalization, resistance or developmental effect.

## 8. Participant/identity discipline

For any candidate:

- participant roles are semantic;
- member order is semantic only if the relation says it is;
- cardinality is exact;
- multiplicity is exact where repeated events/components matter;
- role labels may not be inferred from source labels;
- participant substitution changes relation identity;
- risk-set/scope substitution changes relation identity;
- baseline substitution changes conditional/redistribution identity;
- transformation substitution changes identity unless an explicit equivalence authority says otherwise.

The first relation should prefer canonical role-labeled identities and avoid metric/geometric claims.

## 9. Positive premise law

A relation-positive output requires the exact upstream positive premise for the relation.

For current `EmpiricalFact@1.0.0`, the concrete runtime already distinguishes:

- `SUPPORTED` with positive denominator;
- `OBSERVED_ZERO` with positive denominator and zero numerator;
- `ZERO_SUPPORT` with zero denominator.

W1C does not collapse these states.

A relation cannot turn `OBSERVED_ZERO`, zero denominator, denied, out-of-scope, unresolved authority or integrity failure into a positive relation merely because the relation family would otherwise be convenient.

## 10. Falsifier minimum

Every final relation contract should include hostile assertions for at least:

1. upstream fact/query identity tamper;
2. participant identity substitution;
3. scope/risk-set substitution;
4. denominator/support inconsistency;
5. replay mismatch;
6. authority version/hash mismatch;
7. permission widening;
8. nonpositive upstream state promoted to positive;
9. strong-noun vocabulary injected into a neutral relation;
10. actor-indexed semantics injected upstream of V3.

Additional family-specific falsifiers:

- R02/R03: no exact same-unit carrier;
- R03: zero denominator or undeclared baseline;
- R04: missing comparability/order/measure authority;
- R05: undeclared completeness;
- R06: missing PRA/role authority.

## 11. Permission ceiling

W1C does not create a new positive consumer permission token.

The eventual relation contract must take its allowed target use from the central relation→PRE-V3 constitution/fan-in and assert:

`RELATION_PERMISSION <= UPSTREAM_PRODUCER_PERMISSION`.

No structural-observatory relation may imply actor, causal, render, transport, publication or strong-noun permission merely because a downstream consumer exists.

## 12. Information loss and representation

The first relation should be realizable without selecting storage architecture.

Preferred execution:

- exact relation/query identity;
- exact direct references to upstream `EmpiricalFact`, query, scope/risk-set, authorities and replay;
- optional cached scalar/index only as non-owning materialization.

The relation object is **not** required to persist respondent membership if the asserted relation and its exact replay can be reconstructed lawfully from the producer surface.

Conversely, if the selected relation requires same-unit incidence and that information cannot be lawfully dereferenced/reconstructed, a marginal summary is not enough. Return a blocker.

## 13. Geometry/transport avoidance

For the first thread, prefer one source/context/scope.

R01-R03 need no universal geometry.

R04 requires only its exact comparison/order semantics, not coordinates.

R05 requires membership/cardinality, not geometry.

R06 requires role authority, not geometric embedding.

No coordinate proximity or shared measurement ancestry can authorize transport or homology.

## 14. Fan-in contract

Central fan-in should evaluate A/B evidence in this order:

1. Is there a unary positive producer fact for which R01 has genuine nonduplicative relation semantics?
   - yes -> R01 candidate;
   - no -> continue.
2. Is there a pair with exact same-unit or information-equivalent jointability at no new general-authority cost?
   - yes -> R02 candidate;
   - no -> continue.
3. Is there exact conditional denominator/routing support for a condition-target pair?
   - yes -> R03;
   - no -> continue.
4. Is the selected empirical claim inherently comparative with exact measure/comparability?
   - yes -> R04.
5. Are exact bounded alternatives already authoritative?
   - yes -> R05.
6. Use R06 only if exact role/PRA authority is already present and the relation is still cheaper than commissioning upstream joint/conditional authority for another family.

If all fail:

`NO_CHEAP_LAWFUL_RELATION__RETURN_TYPED_BLOCKER__DO_NOT_REOPEN_FIELD_FORGE_R2`.

## 15. Downstream ceiling

A positive W1C relation is not itself PRE-V3 admission.

`FIELD_FORGE_EXACT_RELATION != PRE_V3_STRUCTURAL_ADMISSION`.

It must later traverse the separately governed D contract and the M1-compatible E basis contract.

W1C therefore intentionally does not define:

- admission state ownership;
- M1 basis kind;
- V554 affordance semantics;
- V557 publication permission;
- V558 resolution policy.

Those are downstream jurisdictions.
