## 2. Accepted narrowing N1 — K4 Path B overlap law

The pre-review companion synthesis allowed current K4 proof via governed persistence-to-termination.

That route remains lawful only under this stricter law:

```text
K4 PATH B CURRENTNESS
=
COMPETENT OWNER SEMANTICS
ESTABLISH A TYPE-COMPATIBLE CONTINUING STATE
+
THAT STATE HAS A LAWFULLY SUPPORTABLE VALIDITY INTERVAL
OVERLAPPING THE ASSERTED/QUERIED INTERVAL
+
COMPLETE AUTHORITATIVE TERMINATION / SUPERSESSION /
INVALIDATION COVERAGE THROUGH QUERY TIME
+
NO DEFEATING CLOSING FACT.
```

A point-in-time establishment event is not itself a current witness at later times merely because no termination record is observed.

Complete closure coverage may keep an owner-declared persistent state open; it may not manufacture a repeated occurrence or convert silence into currentness.

If the overlapping continuing-state support is not proved:

`UNKNOWN_NOT_PROVEN`.

This preserves frozen R4 §5.1-§5.5 rather than weakening it.
