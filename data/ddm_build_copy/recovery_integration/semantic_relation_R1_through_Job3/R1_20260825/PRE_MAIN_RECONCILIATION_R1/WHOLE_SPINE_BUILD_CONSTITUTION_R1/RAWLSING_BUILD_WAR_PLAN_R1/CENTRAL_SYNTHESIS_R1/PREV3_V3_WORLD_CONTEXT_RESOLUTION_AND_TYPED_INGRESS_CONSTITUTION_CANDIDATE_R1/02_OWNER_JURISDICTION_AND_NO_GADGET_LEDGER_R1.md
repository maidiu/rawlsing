## 2. Proposed new seam semantic objects

Only the following irreducible cross-jurisdiction transition meanings are proposed.

### N1 — `PREV3_V3_CONTEXT_RESOLUTION_REQUEST_R1`

Owns only the exact identity of one request to resolve objective propositions for:

`actor × world/root × effective/valid time × purpose/query × consumer/ingress purpose × permission/use ceiling`.

Why this is not already owned:

- PRE553 owns exact refs/query primitives, but not the general cross-owner PRE-V3↔V3 resolution request;
- Field Forge/SDTF own their own proposition semantics, not the aggregate transition request;
- V3 owns realization, not objective-world query composition.

N1 does not own any returned proposition.

### N2 — `PREV3_V3_RESOLVED_RESULT_BINDING_R1`

A nested receipt binding, not a reminted fact.

Owns only the transition assertion:

> this already-owned proposition/ref was selected under this request/root and is presented under this exact ingress class, owner, authority/currentness, provenance, permission/use ceiling, uncertainty/negative state and dependency binding.

Why this is not already owned:

No current producer owner owns the cross-jurisdiction ingress classification/binding for all producer families, and V3 must not infer it ad hoc.

N2 does not copy proposition content and does not become truth authority.

### N3 — `PREV3_V3_CONTEXT_RESOLUTION_RECEIPT_R1`

Owns only the deterministic manifest/index of:

- exact request ref;
- exact root/release horizon;
- exact ordered result bindings;
- coverage/negative bindings;
- dependency/currentness/replay identity;
- supersession lineage.

Why this is not already owned:

Existing owners provide the ingredients but no current object composes their cross-jurisdiction transition into one replayable receipt.

N3 does not own the truth of listed propositions.
