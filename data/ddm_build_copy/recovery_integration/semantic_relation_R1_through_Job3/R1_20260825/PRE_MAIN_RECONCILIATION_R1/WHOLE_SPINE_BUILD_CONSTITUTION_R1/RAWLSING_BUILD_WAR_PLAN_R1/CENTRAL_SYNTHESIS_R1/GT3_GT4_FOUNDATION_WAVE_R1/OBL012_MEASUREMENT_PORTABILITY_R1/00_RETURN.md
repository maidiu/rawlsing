- sample pooling does not grant respondent linkage or estimand composition;
- estimand composition does not grant respondent linkage or sample pooling;

This confirms that J2 is not obtaining portability by renaming an adjacent relation.

## Actor comparator is not measurement portability

The actor comparator seam and measurement portability answer different propositions.

The comparator asks:

> May this exact generated actor fact, under its owner/time/source-specific comparability rule, resolve to this exact empirical conditioner predicate?

Its lawful positive output is:

`EXACT_D08_EMPIRICAL_PREDICATE + COMPARATOR_PROVENANCE_RECEIPT`.

It does **not** assert:

- actor fact == respondent fact;
- source A response == source B response;
- scale A == scale B;
- measurement implementation A == implementation B;
- one source's prevalence may fill another;
- one source's weights/estimand can be reused in another.

The historical D12D court explicitly required field-specific actor->empirical comparability and rejected universal cross-source value equivalence.

So OBL031 comparator competence, whatever J1 finds, remains logically separate from OBL012 portability.

## Operation-scoped no-transfer theorem

For the immediate OBL032 prerequisite chain, the lawful operation is constrained as follows:

1. Start with one exact generated actor fact.
2. J1 comparator authority, if/when competent, maps that fact to one exact D08-compatible empirical predicate for a named empirical coordinate/source scope.
3. Construct/consume one exact PRE553 query under one exact source universe/release.
4. The query fixes one exact `measure_basis_ref`.
5. PRE553 produces one fact carrying the same exact measure basis and exact source provenance.
6. PSEPF consumes source-backed evidence only at the same source universe/release/target.
7. Any specificity walkback remains within that same universe/release.
8. No source value, response scale, weight basis, estimand, or measurement implementation is equated with or transferred into another.
9. No pooling/composite source operation is required.
10. Downstream structural/V3 use remains separately governed and cannot add a portability claim.

That operation is lawful without measurement-portability authority because **there is no measurement transfer to authorize**.

## Standing future portability obligation

The broader portability obligation survives.

A new OBL012-style portability decision/owner is still required before any future operation that does one or more of the following:

- combines respondent values from distinct measurement implementations as one variable/quantity;
- treats distinct response scales or codings as value-equivalent;
- transforms one implementation into another and claims preserved measurement meaning;
- pools/composes sources where the target estimand depends on cross-measure equivalence;
- backfills across implementations on the premise that donor and target measurements are equivalent;
- uses a source-semantic equivalence or harmonization alias as if it proved value/scale invariance.

`NO_CURRENT_GOVERNED_MEASUREMENT_PORTABILITY_OWNER_PROVED`
