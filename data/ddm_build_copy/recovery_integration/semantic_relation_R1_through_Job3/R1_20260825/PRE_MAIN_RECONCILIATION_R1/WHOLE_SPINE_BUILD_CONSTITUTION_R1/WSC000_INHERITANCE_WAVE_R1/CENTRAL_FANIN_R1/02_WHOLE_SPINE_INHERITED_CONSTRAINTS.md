# WSC000 CENTRAL FAN-IN — WHOLE-SPINE INHERITED CONSTRAINTS R1

These constraints are inheritance inputs to the next seam-constitution wave. They are not a final whole-spine architecture selection.

## Cross-spine invariants

Every seam must preserve:

- exact semantic producer identity and provenance;
- exact scope/universe/risk-set identity where applicable;
- exact relation/query identity and participant role/cardinality/order when meaning-bearing;
- consumer/use permission as a separate identity that may narrow but not widen downstream;
- typed negative/abstention/integrity states without zero/default laundering;
- exact authority/current-selection identity independent of chronology;
- deterministic replay/reconstruction closure at the asserted grain;
- an explicit declaration of information loss when a representation compresses or models upstream information.

No physical file/table/database/cache/stage acquires semantic ownership merely by holding or serving the object.

## Seam matrix

### SOURCE / CURRENT EMPIRICAL -> PRE-FF GOVERNED COMPILER

### FIELD FORGE -> PRE-V3

FIELD FORGE produces only its own actor-independent structural-observatory commitments. Downstream structural admission, transport/comparison and any stronger semantic noun require separate competent authority.

Preserve the canonical FIELD FORGE owner ceiling and `BLOCKED != FALSE`.

### PRE-V3 / LEARNED-WORLD REGION

### PRE-V3 -> V3

This is a semantic firewall, not merely a storage boundary.

A population/positioned-subject empirical possibility or structural possibility may affect V3 only through exact comparator/predicate ancestry and a governed transition/metabolism rule. Preserve `OBL031/032`.

### V3 DEVELOPMENTAL RUNTIME

`STRUCTURAL/APPLICABLE POSSIBILITY != ACTOR OPPORTUNITY != ENCOUNTER != EXPOSURE != ROUTE REALIZATION != ACTOR RESPONSE != PERSISTENT CHANGE != ATTRACTOR CHANGE`.

Do not resurrect a universal developmental ladder, scalar net pressure, route-realization rule, satisfaction rule or attractor update rule that was never returned.

### V3 -> MEDIATION -> V2

Preserve:

`OBJECTIVE GENERATED HISTORY != CAUSAL MEMORY != CURRENT ACCESSIBILITY/RECALL != FIRST-PERSON CLAIM PERMISSION != PHENOMENOLOGICAL PROJECTION != RENDERED EXPRESSION`.

Reuse/adapt current actor-safe expression and bounded rendering assets. Expression is noncausal by default.

### V2 -> V3 RETURN

Only a typed observable in-world interaction admitted by the V3 causal owner may enter generated history. Session persistence, rendered text, tone or narration is not itself V3 state.
