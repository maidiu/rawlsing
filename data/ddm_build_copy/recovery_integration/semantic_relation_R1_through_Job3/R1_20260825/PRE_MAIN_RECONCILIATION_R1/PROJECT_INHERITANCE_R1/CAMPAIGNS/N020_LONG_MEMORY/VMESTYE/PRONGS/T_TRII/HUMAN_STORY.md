# A person, an answer, a governed empirical world — Trii D00–D15

## The simplest real question

Suppose two sources record what *looks* like the same answer. Does that mean two people, two waves, two response events, and one identical eligible population? **No.** A future question like “Among eligible people with position X and question answer Y, what other answers co-occur in the same respondent?” can only be answered if the data preserve respondent membership, question/option topology, eligibility, source identity and selected authority — rather than just today's marginal distribution.

Trii's early courts D01–D04 recovered that historical pair, recursive branch and cloud capabilities are not interchangeable. D02's V548 deviation chaser cannot be reconstructed merely from the later greedy top-two tree; D03–D04 showed a cloud/association summary is neither a full joint respondent profile nor source-governed semantic truth. D05 did not certify populated source equivalence. D06 separated relation authority from universal workload permission. D07–D08 then made the key change of perspective: keep enough deep information to derive lawful future queries, **without** demanding that all potential aggregates be stored now.

D09's “different joint fact” insight survived D09A's hostile appeal, but not its unissued named population-meaning-field promotion. D10 refused survey coordinate→generated structural-position shortcuts. D11 distinguished actual downstream consumption from full terminal need. D12A–G contributed bounded terminal, comparability, possibility, discovery and source-plurality rules without each pretending to be final D12 architecture authority.

## Two outward paths, deliberately not collapsed

The [original D15 ownership graph](https://github.com/maidiu/rawlsing/blob/4450c54930533527b7bbb7ceb73a6a46b6ac9eba/data/ddm_build_copy/vozhd_trii/20260818_prechange_discovery_control/courts/D15/FINAL_DATAFLOW_AND_OWNERSHIP.md) describes:

A missing routing fact is not zero membership; missing valid weighted measure is not treated as weight 1.
2. **Query → DiscoveryService.** A named discovery authority chooses the *candidate frontier*; actual data select validated winners. Branch receipt and replay identity have to survive. An unevaluated candidate is not a negative empirical fact. The currently protected I05 code shows this producer/consumer relationship statically, but the original35-to-real-learned end product has not been certified here.
3. **Query → StructuralEmpiricalAdmissionService → structural owners.** Empirical fact becomes a bounded structural input only under explicit selection/application of an admission authority. V553–V556 produce unique necessary meanings, V557 publishes source-correct mixed-producer products, V558 resolves them; later R03 law lets conditional stages be bypassed when semantically unnecessary, without bypassing producer permission.
4. **Query + exact actor comparator → PossibilityFieldService → typed V3 inlet.** This is source-indexed *population possibility for a positioned subject*, **not** that actor's biography, beliefs or realized future. It bypasses the structural prior repository; V3 owns actor-indexed opportunity/encounter/exposure/memory/realization. Positive comparator and possibility-model authorities remain separately unproved.
