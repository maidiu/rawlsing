## 1. Finite verdict

# `UNIFIED_DEEP_EMPIRICAL_FACT_ALGEBRA_WITH_TYPED_LANES`

The unification succeeds, but only at the **deep respondent-bound empirical relation algebra**. It does **not** establish that conditional empirical distributions, historical branch cotravel, current attitude-cloud rows, V550J joint patterns, and association scores are one semantic object, one table, or one admissibility lane.

The proof has five parts.

1. A unary position conditional, a conjunction position conditional, a response-conditioned distribution, a response+position conditional, a branch-conditioned distribution, and branch+response cotravel are all the same mathematical operation once the machine has:
   - one exact empirical scope;
   - one respondent binder;
   - a typed condition predicate;
   - a separately typed denominator/risk set;
   - an exact target response topology;
   - raw and, where governed, weighted measures;
   - typed missingness/routing state;
   - authority and provenance.

2. Historical branch-conditioned cotravel does not require a separate mathematics. It can be represented as a conditional empirical fact whose condition contains an exact `DERIVED_BRANCH_COHORT` predicate. What is irreducible is the **branch-membership semantics**: the resolved branch predicate or exact member set, plus the lineage/provenance needed to know what that cohort means. A string called `branch_id` is not enough.

3. V550J joint response configurations do not require a separate empirical universe. They fit the same algebra if the target is permitted to be **multivariate**:

   `T = (Q1=x1, Q2=x2, ..., Qk=xk)`.

   But fixed pattern counts are not enough to recondition the pattern on a new variable or relate it to an outside response. Those operations require respondent membership/incidence or an exact information-equivalent higher-order contingency.

4. Association scores do **not** become conditional empirical facts merely because they are computed from the same incidence. NMI, Cramér's V, MI-like scores, lift, entropy reduction and similar quantities are **derived functionals** over a richer contingency relation. They are not invertible to that relation and therefore occupy a distinct derived-summary lane inside the common algebra.

5. Current V550 `question_response_attitude_cloud` is not one ordinary `P(Y|X)` fact. A single persisted cloud row splices together:
   - a directional event probability whose denominator is the selected anchor population;
   - a baseline probability whose denominator is the candidate-question population;
   - symmetric association statistics whose input risk set is the complete-case same-respondent overlap.

   Those are three different denominator/risk-set semantics. The current cloud row is therefore a **derived composite view/index**, and because it retains only one modal joint response cell plus scalar association summaries, it is also **lossy** relative to the deeper pairwise respondent-conditioned fact.

The governing noncollapse is therefore:

```text
DEEP EMPIRICAL ALGEBRA
    contains respondent incidence
    contains typed conditional distributions
    contains multivariate joint incidence
    can derive branch-conditioned distributions
    can derive cotravel distributions
    can derive diagnostic association functionals

BUT

CONDITIONAL DISTRIBUTION
!= BRANCH MEMBERSHIP
!= JOINT INCIDENCE
!= ASSOCIATION SCORE
!= MATERIALIZED CLOUD VIEW
!= STRUCTURAL INTERPRETATION
!= GENERATED ACTOR POSITION
!= ACTOR BELIEF
!= ACTOR DEVELOPMENTAL STATE
```

This is a semantic/information-model holding only. It does not select physical storage, workload, runtime promotion, or architecture.

# 5. The shared deep empirical algebra

## 5.1 Scope

Let `S` denote an exact empirical scope.

At minimum `S` must be able to distinguish:

- source/source family;
- raw wave;
- canonical wave;
- country/geographic scope;
- question/component identity;
- source/native identity needed for replay;
- relevant authority/provenance version.

Raw wave and canonical wave are both needed because a canonicalized identity is not proof that source-native temporal identity can be discarded.

## 5.2 Respondent binder

Let `r` denote one empirical respondent identity **within the exact governed scope**.

A same-respondent claim is represented by binding all relevant predicates and target responses to the same `r`.

This is stronger than saying two rows share source/wave/country metadata.

The algebra therefore distinguishes:

```text
P(Y | X) computed from same respondent r
```

from

```text
population marginal P(Y) compared to unrelated marginal P(X)
```

No amount of matching marginal percentages creates same-person cotravel.

D05 has not established populated respondent-ID validity or uniqueness. D08 therefore treats exact respondent identity as an **information requirement**, not an empirically verified current property.

## 5.3 Primitive empirical relations

The algebra requires the semantic capability to represent at least these respondent-scoped relations.

### A. Response event

Conceptually:

```text
Response(
    r,
    question_id,
    response_event_id,
    response_value,
    response_topology,
    typed_response_state,
    response_authority_ref,
    provenance_ref
)
```

`response_event_id` cannot be assumed to be one scalar row per respondent/question for all future topology.

For scalar single-choice questions it may collapse to one event.

For multi-select/repeated/ranked/routed structures the algebra must be capable of preserving the governed event/set/order structure or must type the topology as unsupported. It may not silently choose the first row.

### B. Empirical position atom

Conceptually:

```text
Position(
    r,
    empirical_coordinate_id,
    empirical_coordinate_value,
    typed_state,
    authority_ref,
    provenance_ref
)
```

This is an **empirical survey coordinate**.

It is not an ADP-009 generated actor position.

The same words — for example `income`, `religion`, `region`, `employment` — do not create cross-ontology identity.

### C. Routing/applicability atom

Conceptually:

```text
Eligibility(
    r,
    question_id,
    applicability_state,
    routing_state,
    authority_ref,
    provenance_ref
)
```

This relation is required because:

```text
respondent did not answer Y
```

can mean very different things:

- not asked;
- routed out;
- inapplicable;
- DK;
- refusal;
- missing/unknown;
- response physically absent;
- data loss;
- no support in the selected cohort.

Those cannot all become `NULL` and cannot all become substantive categories.

### D. Branch membership

Conceptually:

```text
BranchMember(
    r,
    branch_definition_id,
    resolved_predicate_hash,
    membership_state,
    branch_provenance_ref
)
```

This can be:

1. explicitly materialized respondent membership; or
2. a deterministic derived relation regenerated from deeper incidence plus exact branch law.

The semantic requirement is exact membership meaning, not a particular storage choice.

## 5.4 Typed predicate grammar

Let `C(r)` be an empirical condition.

D08 finds a shared condition grammar can include:

- `EMPIRICAL_POSITION_COORDINATE = value`;
- `SURVEY_RESPONSE_EVENT = value`;
- `DERIVED_BRANCH_COHORT = branch`;
- `ROUTING_APPLICABILITY_STATE = state`;
- `TYPED_RESPONSE_STATE = state` where authority explicitly permits such a query;
- conjunction/disjunction/negation of governed predicates.

Examples:

```text
income_level = low
```

```text
income_level = low AND education_level = secondary
```

```text
X_response = x
```

```text
X_response = x AND income_level = low
```

```text
branch = B
```

```text
branch = B AND X_response = x
```

The algebra must preserve **predicate type**. The strings `low`, `worker`, `religious`, or `region_1` have no semantics without their coordinate/question/branch authority.

## 5.5 Risk set is separate from condition

Let `R(r)` denote the denominator/risk-set predicate.

This is the most important noncollapse in the court.

The condition says:

> which empirical property selects the comparison cohort?

The risk set says:

> which respondents are eligible to count in the denominator at all?

They are not the same thing.

For example:

```text
C(r) = X_response = x
```

could be paired with:

```text
R1(r) = all anchor respondents
```

or:

```text
R2(r) = respondents eligible for and observed on both X and Y
```

or:

```text
R3(r) = respondents routed into Y
```

Those produce different empirical facts even if the notation is casually abbreviated to `P(Y|X=x)`.

## 5.6 Target topology may be scalar or multivariate

Let `T(r)` denote the target response object.

D08 rejects a grammar limited to scalar `Y`.

The target arity must be `1..k`.

Scalar case:

```text
T(r) = Y_response
```

Joint pattern case:

```text
T(r) = (
    Q1_response,
    Q2_response,
    ...,
    Qk_response
)
```

That is enough to represent V550J-style joint response configurations without inventing a separate empirical metaphysics.

The component ordering/set semantics and response topology remain typed.

## 5.7 Raw and weighted measures

Let `μ_m(r)` identify the measure used over a respondent risk set.

Raw measure:

```text
μ_raw(r) = 1
```

Governed weighted measure:

```text
μ_weighted(r) = authorized valid survey weight
```

A raw N and a weighted mass are not interchangeable.

The algebra therefore requires:

- raw numerator;
- raw denominator;
- weighted numerator where governed;
- weighted denominator where governed;
- weight status;
- weight identity/provenance;
- denominator basis.

D08 does not establish that every cloud/conditional lane must be weighted. D04 leaves the normative V550 cloud weighting rule unresolved. The algebra merely proves that when weighted evidence exists, its measure basis must be explicit.

## 5.8 Generic fact equation

For target value or target tuple `t`:

```text
N_m(t; S,C,R,T)
  = Σ_r μ_m(r) · 1[r∈S ∧ R(r) ∧ C(r) ∧ T(r)=t]
```

```text
D_m(S,C,R)
  = Σ_r μ_m(r) · 1[r∈S ∧ R(r) ∧ C(r)]
```

When `D_m > 0`:

```text
P_m(T=t | C,R,S) = N_m / D_m
```

The full empirical distribution is:

```text
{ t -> (N_raw, D_raw, N_weighted, D_weighted, state, provenance) }
```

over the complete governed target topology.

A modal response alone is not the distribution.

An association score alone is not the distribution.

## 5.9 Zero and undefined states

If a denominator or overlap is zero, the lawful result is not automatically “no row.”

The algebra must be able to distinguish at least:

- `ZERO_SUPPORT`;
- `ZERO_OVERLAP`;
- `NOT_APPLICABLE`;
- `NOT_ASKED`;
- `ROUTED_OUT`;
- `UNDERPOWERED_PRESENT`;
- `UNRESOLVED_AUTHORITY`;
- `NONCOMPARABLE`;
- `FORBIDDEN_INFERENCE`.

The exact enum is later architecture jurisdiction. The semantic requirement is that these meanings not collapse.

## 5.10 Fact identity

Two empirical facts are identical only if their empirical identity agrees, not merely their percentage.

At minimum fact identity needs:

- source;
- raw wave;
- canonical wave;
- country/scope;
- target question/component identity;
- response topology authority;
- exact condition predicate AST/hash;
- predicate type(s);
- exact risk-set identity;
- response value/state semantics;
- measure basis;
- branch provenance if applicable;
- source/semantic/replay provenance.

Therefore:

```text
P(Y | position=A) = 0.60
```

and

```text
P(Y | position=B) = 0.60
```

are not one fact.

Likewise:

```text
P(Y | branch=B1) = 0.60
```

and

```text
P(Y | branch=B2) = 0.60
```

remain distinct even if the entire response distributions happen to match numerically.

## 5.11 Empirical fact identity is separate from admission

The machine may possess a lawful empirical fact and still deny a particular use.

Therefore the algebra needs a separately governed admission layer carrying, at minimum:

- evidence/admissibility lane;
- admission status;
- authority version/hash;
- forbidden-inference state where needed.

This prevents the illicit implication:

```text
fact exists
=> fact may become structural interpretation
=> fact may bind to actor
=> fact may become actor belief
```

No such implication is licensed by D08.

# 7. Denominator court

## 7.1 Whole-question denominator

A baseline question distribution can use the governed respondent population for that question:

```text
R(r) = eligible/observed target-question population
C(r) = TRUE
```

This is different from every conditioned denominator below.

## 7.2 Condition-selected denominator

For ordinary position conditioning:

```text
R(r) = target question risk set
C(r) = position=A
```

The denominator is the target risk set intersected with the condition.

## 7.3 Anchor-selected denominator

Current V550 attitude cloud uses an anchor-selected denominator for its directional event probability.

For selected modal cell `(a*,b*)`:

```text
N_ab = same respondents with A=a* and B=b*
N_a  = all prepared anchor respondents with A=a*
```

and:

```text
p_cotravelling_given_anchor = N_ab / N_a
```

An `A=a*` respondent with no usable B response remains in `N_a`.

That is not the same as a complete-case pair conditional.

D04 found this arithmetic matches current implementation. D08 treats it as **implementation semantics, not normative denominator law**.

## 7.4 Candidate-question denominator

The same current cloud row computes baseline:

```text
N_b = prepared candidate respondents with B=b*
N_B = all prepared candidate respondents
```

```text
p_cotravelling_baseline = N_b / N_B
```

That denominator belongs to the candidate-question population, not the anchor-selected population.

## 7.5 Common eligible risk set

A different lawful empirical object may require:

```text
R(r) = eligible/observable for both A and B
```

or for all members of a k-way pattern.

This is the natural complete-case/common-risk-set form, but D08 does not declare it the normative replacement for current cloud arithmetic.

D04 leaves routed common-risk-set authority unresolved.

## 7.6 Routed/applicable denominator

For a routed follow-up:

```text
R(r) = respondent lawfully routed into / applicable to target question
```

This cannot be reconstructed from response labels alone unless routing authority is encoded in the evidence.

## 7.7 Branch cohort denominator

For branch-conditioned evidence:

```text
C(r) = BranchMember_B(r)
```

with target risk set separately applied.

A branch definition may itself contain response or position predicates; that does not eliminate the need for a target eligibility denominator.

## 7.8 Weighted denominator

Weighted evidence replaces respondent count measure with authorized weight mass **over an already-defined risk set**.

It does not define the risk set by itself.

## 7.9 Denominator theorem

D08 closes the following rule:

> **Denominator/risk-set identity is part of empirical fact identity.**

Two expressions written informally as `P(Y|X)` are not equivalent if they differ in:

- target applicability;
- candidate observability;
- routing;
- anchor selection;
- common-overlap restriction;
- branch membership;
- raw versus weighted measure;
- missing/special-state treatment.

This is why shared mathematical notation alone cannot unify current cloud rows with CEDs.

# 8. Current V550 attitude cloud: exact algebraic decomposition

## 8.1 Direct current implementation evidence

Current exact-base module:

`data/ddm_build_copy/ddm_v550_clouds.py`

blob:

`dfc878e87d984a1a3d7000a0c726bdc444f9945f`

The current helper:

1. prepares one response row per respondent/question by keeping the first row;
2. joins anchor and candidate frames by `respondent_id`;
3. builds the complete-case pair crosstab;
4. chooses only the globally most frequent joint cell `(a*,b*)`;
5. computes the directional event probability with the full anchor-category denominator;
6. computes candidate baseline on the full candidate frame;
7. computes NMI and Cramér's V over the complete-case joined response vectors;
8. persists the modal cell plus diagnostic statistics.

## 8.2 Component A — directional event fact

The first underlying fact is:

```text
condition = A=a*
target    = event B=b* observed
risk set  = full prepared anchor frame
```

with:

```text
N = N_ab
D = N_a
```

This is directional.

## 8.3 Component B — candidate baseline fact

The second underlying fact is:

```text
condition = TRUE
target    = B=b*
risk set  = full prepared candidate frame
```

with:

```text
N = N_b
D = N_B
```

This is a separate baseline distribution.

## 8.4 Component C — complete-case pair contingency

The third underlying object is:

```text
J_AB = joint response contingency of A and B
       among respondents appearing with usable responses in both prepared frames
```

NMI and Cramér's V are functionals of `J_AB`.

`J_AB` is not preserved by the current cloud row.

## 8.5 Why one cloud row is not one CED

A single current cloud row therefore contains values derived from:

1. an anchor-selected risk set;
2. a candidate-response risk set;
3. a common observed-pair risk set.

No one tuple:

```text
(scope, condition, risk_set, target)
```

can truthfully describe all three at once.

Therefore:

`CURRENT_ATTITUDE_CLOUD_ROW != SINGLE_CONDITIONAL_EMPIRICAL_FACT`.

It is a **composite view/index** over several deeper empirical objects.

## 8.6 Why the current cloud is lossy

The current persisted cloud does not retain:

- all pair response cells;
- the full pair contingency;
- all directional conditionals;
- all rare/nonmodal response pairs;
- respondent pair incidence;
- branch membership;
- higher-order response topology;
- k-way conjunctions.

NMI and Cramér's V do not invert to the discarded pair table.

The modal selected cell does not invert to the pair table either.

Thus retaining only the current cloud row loses empirical information.

## 8.7 D04 implementation defects remain separate from algebra

D04 established unconditional current defects including:

- nonblank special states such as DK/refusal/IAP/not-asked/inapplicable can become content;
- the current NMI function mixes nats and bits;
- checkpoint resume does not restore cross-question state.

D08 does not repair those defects and does not use them to redefine the algebra.

They demonstrate why the algebra must preserve:

- typed response state;
- metric formula/version;
- replay identity.

D04's pair-order/cardinality-gating findings remain workload-sensitive under parent adjudication and do not become a D08 workload ruling.

## 8.8 Directional conditional versus symmetric association

The algebra preserves both:

```text
P(B=b | A=a)
```

and:

```text
P(A=a | B=b)
```

as separate ordered facts because target, condition and denominator change.

At the same time:

```text
CramérV(A,B) = CramérV(B,A)
```

and NMI is symmetric under the same complete-case contingency.

Symmetric association therefore cannot substitute for the missing reverse conditional.

P(Y | B(r), R_Y, S)

A branch name is not enough.

## 11.5 Joint response patterns

# 12. Hostile fixtures

All fixtures below are synthetic information-theoretic constructions, not populated Rawlsing claims.

## A. XOR

Let `A` and `B` be balanced binary coordinates and:

```text
Y = A XOR B
```

Then:

```text
P(Y|A) = P(Y)
P(Y|B) = P(Y)
```

while:

```text
P(Y|A,B)
```

is deterministic.

### Ruling

- unary CEDs fail to preserve the interaction;
- scalar greedy marginal search may report no signal;
- respondent joint incidence or exact `A×B×Y` contingency preserves it;
- the shared algebra survives because it permits conjunction predicates and multivariate incidence.

## B. Simpson reversal

Construct strata `Z` such that the within-stratum direction of `X→Y` differs from the pooled apparent direction because the stratum composition differs.

### Ruling

The algebra survives only if:

- `Z` remains an exact predicate;
- denominators are kept per stratum;
- joint incidence is retained or reconstructible.

Pooled marginals cannot recover the reversal.

## C. Rare minority conjunction

Suppose only a small conjunction:

```text
A=a AND B=b
```

has a distinctive response distribution.

### Ruling

The empirical fact may be:

`PRESENT_UNDERPOWERED`.

Support/admission law may deny strong downstream use.

But underpowered cannot mean nonexistent.

Deleting the cell destroys historical information.

## D. Zero-overlap question pair

Suppose question A and question B have disjoint respondent sets.

### Ruling

Same-respondent cotravel has zero overlap.

The algebra must permit:

`ZERO_OVERLAP`.

It must not fabricate `P(B|A)`, and it must not make “no output row” the only representation of the condition.

D08 does not claim such pairs actually occur in populated Rawlsing; D05 remains blocked.

## E. Routed / not-asked questions

Suppose B is asked only after route condition `G`.

Then these are distinct:

```text
P(B=b | A=a)
```

with all A=a respondents in denominator,

and:

```text
P(B=b | A=a AND eligible_for_B)
```

with a routed common risk set.

### Ruling

Risk-set identity must be explicit.

D08 does not choose which one is normatively correct for a particular future lane.

## F. DK / refusal / IAP

Suppose nonblank response codes identify DK/refusal/IAP.

### Ruling

Those codes must retain typed response state.

They may not become substantive attitude values merely because they are nonblank.

Current D04 found that current cloud preparation violates this separation; the algebra does not inherit the defect as law.

## G. Multi-select / repeated response topology

Suppose one respondent can lawfully have:

```text
Q = {option_a, option_c}
```

or several repeated events.

### Ruling

A one-row scalar grammar is insufficient.

The algebra must preserve enough to distinguish:

- option membership;
- response set;
- ordering if meaningful;
- repeated event/occasion if meaningful;
- routed applicability;
- duplicate error versus legitimate multiplicity.

Otherwise the topology must be typed unsupported rather than silently collapsed.

## H. Contradictory simultaneous positions

Suppose the same respondent satisfies several empirical position predicates simultaneously.

### Ruling

The conjunction grammar preserves all of them.

No “dominant position” is required at the empirical layer.

This does not make them generated actor positions.

## I. Same answer under different branch predicates

Suppose:

```text
P(Y=yes | branch=B1) = 0.60
P(Y=yes | branch=B2) = 0.60
```

### Ruling

The facts remain distinct because `B1 != B2` and their provenance/membership differs.

Numerical equality does not merge historical cohorts.

## J. Same answer under different position predicates

Likewise:

```text
P(Y=yes | income=low) = 0.60
P(Y=yes | region=R)   = 0.60
```

are distinct conditioned facts.

## K. Same marginals, different joint incidence

Two datasets can have exactly:

```text
P(A=1)=0.5
P(B=1)=0.5
```

while one has independent joint cells:

```text
25% / 25% / 25% / 25%
```

and another has perfect concordance:

```text
50% A0B0
50% A1B1
```

### Ruling

Unary marginals cannot reconstruct same-person cotravel.

Respondent incidence or the exact pair table is irreducible for that pair.

## L. Asymmetric conditional, symmetric association

Take a 2×2 table where:

```text
A1B1 = 15
A1B0 = 25
A0B1 = 5
A0B0 = 55
```

Then:

```text
P(B1|A1) = 15/40 = 0.375
P(A1|B1) = 15/20 = 0.75
```

but Cramér's V of the same table is symmetric under swapping A and B, as is NMI under a consistent implementation.

### Ruling

The shared algebra preserves:

- two ordered conditional facts;
- one symmetric association functional.

It does not confuse them.

# 18. Joint patterns versus branch predicates

These are related but not identical.

A joint response pattern is naturally an **outcome tuple**:

```text

```

A branch is naturally a **condition/membership predicate**:

```text

```

The algebra can convert a fixed joint pattern into a cohort predicate when a later query asks:

```text
P(Y | respondent has joint pattern P)
```

But this conversion must retain:

- exact pattern component identity;
- topology;
- risk-set/completion rule;
- pattern provenance.

That is why one deep algebra is useful: outcome tuples may become predicates in later relational queries without erasing their origin.

It does not mean “joint pattern” and “branch” are semantic synonyms.

# 19. Association-summary ruling

```text
A = g(J; metric_formula, metric_version, measure_basis)
```

Examples:

- Cramér's V;
- NMI;
- MI;
- entropy reduction;
- lift;
- current V550J MI-like score;

The summary needs:

- exact input fact/contingency reference;
- exact risk-set/denominator lineage;

- formula ID/version;
- provenance.

But:

```text

```

and generally:

```text

```

Therefore association summaries are `E4_DERIVED_ASSOCIATION_FUNCTIONAL`.

This preserves D01's ruling that pair scalar scores are not joint topology, D03's ruling that current cloud association is diagnostic, and D04's demonstration that formula implementation itself can be defective.
