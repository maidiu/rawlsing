Status: **EXPLORATORY DESIGN / NON-BINDING**

This document defines the working answer to a critical Rawlsing design question:

> **What must PRE553 actually produce before Rawlsing is epistemically ready to freeze the structural grammar used by V553+?**

It does not require new sources. It does not alter current PRE553 authorities. It defines a prospective readiness court for HQ consideration.

That is an important architectural clue:

```text

!=

```

FIELD FORGE extends that principle one step further:

```text

!=

```

The structural ontology should not be frozen until PRE553 can expose enough real empirical morphology to test whether candidate structural concepts actually survive contact with the governed survey world.

# 5. REQUIRED OBSERVATORY PRODUCT C — POSITION ↔ DISPOSITION PRESSURE FOOTPRINTS

Define a pressure footprint conservatively:

```text
EMPIRICAL_PRESSURE_FOOTPRINT
=
reproducible change in the probability distribution
of a governed disposition complex across
lawfully comparable positional configurations
within exact context/scope.
```

It is descriptive/relational evidence.

It is not automatically a causal mechanism.

For candidate disposition complex A and positional configuration C:

1. define exact risk-set/respondent universe;
2. apply weights/design law;
3. preserve joint semantics;
4. estimate the conditional distribution of A under C;
5. compare to governed neighboring/reference configurations;
6. measure distributional displacement;
7. test non-additive/configuration interaction;
8. preserve heterogeneous/minority branches;
9. emit exact support and uncertainty;
10. never mint a causal or field label automatically.

Useful computational evidence may include:

- weighted conditional tables;
- distributional distances;
- conditional mutual information;
- log-linear interactions;
- multilevel estimates where lawful;
- fracture-map branch changes;
- direct J2/J3 distribution changes;
- context/wave recurrence where comparability exists.

Hard law:

```text
PRESSURE FOOTPRINT
!=
PRESSURE MECHANISM
```

For Rawlsing persona generation, pressure footprints are already valuable because they change the lawful probability landscape available to V3.

# 6. REQUIRED OBSERVATORY PRODUCT D — EMPIRICAL MOTIF ATLAS

A motif is a recurring, exact empirical morphology worthy of structural interpretation.

Example shape:

```text
MOTIF M
context = K
joint attitude complex = A
strong fracture = religion × region × education
weak main effect = income alone
minority branch = B
same-respondent support = N
recurrence = scopes S1,S2,S3
```

The machine may discover and rank motifs mechanically.

The machine may **not** automatically call M:

- a field;
- a class fraction;
- sectarian embedding;
- hegemony;
- capital conversion;
- mediation;
- causal mechanism.

Those are interpretive/admission questions.

# 8. REQUIRED OBSERVATORY PRODUCT F — FIELD-RELATIVE CAPITAL / CONVERSION CANDIDATES

Bourdieu's strongest engineering implication is that a resource or disposition has relational value only inside a field/context.

Candidate raw relation:

```text
CAPITAL_VALUE_CANDIDATE {
    resource_or_disposition
    context
    positional_region
    associated advantages / recognition / alignment observed in existing evidence
    comparison_region
    uncertainty
}
```

Candidate conversion relation:

```text
CAPITAL_CONVERSION_CANDIDATE {
    resource_or_disposition
    source_context_or_field_candidate
    target_context_or_field_candidate
    positive / weak / zero / negative conversion evidence
    exact empirical basis
}
```

These are candidate empirical objects, not automatic proof of a Bourdieusian field.

The youth/subculture example functions as a hostile ontology test:

```text
RESOURCE R MAY BE HIGHLY VALUED LOCALLY
AND DEVALUED ELSEWHERE.
```

Current surveys need not observe every such micro-field. The structural grammar must simply not make field-relative devaluation impossible.

# 10. PRE553 → 553+ READINESS GATE

Do not define readiness as `every PRE553 issue in existence is closed`.

Define it as **minimum sufficient empirical observability for structural ontology adjudication**.

Proposed gate:

## R1. semantic substrate ready

Current governed source/question semantics exist at required grain.

## R2. routing/applicability ready for observatory surface

No critical position/disposition analysis is built on counterfeit unconditionality.

## R3. same-respondent J substrate ready

The observatory can construct exact joint disposition complexes without inferring coadministration.

## R4. position-role bank ready

For a deliberately diverse set of current scopes, there is manual authority describing which observed variables may enter position geometry, in what role, with what scope and limitations.

## R5. attitude-complex machinery ready

The system can emit rich co-traveling/contradictory/minority disposition objects.

## R6. pressure-footprint prototype ready

At least several real contexts can produce exact configuration-dependent distribution shifts without causal overclaim.

## R7. motif diversity ready

The empirical atlas spans materially different survey families and societies so ontology design is not one-family overfit.

## R8. held-out falsification surface reserved

Some contexts are withheld from ontology formation and used to test whether the candidate grammar generalizes without special pleading.

## R9. observability limits explicit

Every desired theory concept is typed as observed / proxy-limited / unobserved within current fixed evidence.

## R10. structural admission interface identified

The exact seam by which admitted empirical objects may enter V553+ is known and does not allow raw discovery scores or statistical geometry to become semantic authority automatically.

Only after these are satisfied should HQ permit a serious ontology-freeze court.

# 11. WHAT SHOULD NOT BLOCK THE ONTOLOGY COURT

Do not require:

- every survey family to measure identical position variables;
- every field/capital concept to be observable everywhere;
- a universal social-class taxonomy;
- complete causal explanations;
- every routing-unresolved row in CLOSED_35 to be solved if it is irrelevant to the observatory surface;
- every possible J object to be executable if not required by the selected empirical atlas;
- new data acquisition.

The gate is **sufficient empirical richness + lawful scope**, not theoretical omniscience.
