# FIELD FORGE R1 — DUAL GEOMETRIC SPACES / GDA METHOD REFINEMENT

Status: **EXPLORATORY / NON-BINDING / THEORY-METHOD REFINEMENT**

A targeted review of the empirical Bourdieusian / Geometric Data Analysis tradition sharpens FIELD FORGE's two-space architecture.

The strongest design is not merely:

```text
position space
-> project attitudes supplementary
```

but potentially:

```text
A. independently constructed POSITION / CAPITAL SPACE

B. independently constructed DISPOSITION / ATTITUDE SPACE

C. respondent-linked HOMOLOGY / PRESSURE RELATION
between the two spaces
```

This reduces circularity and more closely matches the relational logic Rawlsing needs.

---

# 1. POSITION SPACE

Construct from Position Role Authority-approved active variables.

Candidate active blocks:

- economic/material resources;
- occupation/employment;
- education/credentials;
- origin/trajectory proxies;
- relational identity/geography where target-use authority allows;
- organizational/mobility variables where available.

Project supplementary:

- subjective class/status;
- attitudes/dispositions;
- source-specific descriptors excluded from active geometry.

Output:

```text
LOCAL_POSITION_SPACE
```

---

# 2. DISPOSITION SPACE

Separately construct a geometric representation whose active information consists of governed attitude/disposition modalities or higher-level complex states.

Possible active inputs:

- exact attitude items within lawful common respondent universes;
- source-native batteries with routing/J authority;
- directly observed J2/J3 complex states;
- manually admitted semantic disposition families;
- boundary/moral/evaluative item blocks.

Project supplementary:

- position-space regions;
- income/resources;
- education;
- occupation;
- identity positions;
- subjective class;
- other social-position descriptors.

Output:

```text
LOCAL_DISPOSITION_SPACE
```

This provides an empirical `space of dispositions` without forcing one ideology axis.

---

# 3. WHY INDEPENDENCE MATTERS

If position variables construct the only geometry and attitudes are merely projected, the model privileges the position-space coordinate system.

If attitude variables construct the only geometry and position variables are projected, the model privileges the disposition system.

Building both independently lets Rawlsing ask:

```text
WHAT STRUCTURAL RELATION / HOMOLOGY EXISTS
BETWEEN TWO EMPIRICALLY CONSTRUCTED SPACES?
```

rather than baking the relation into one coordinate system.

---

# 4. HOMOLOGY OBJECT

Candidate descriptive object:

```text
POSITION_DISPOSITION_HOMOLOGY {
    context
    position_space_ref
    disposition_space_ref

    respondent_linkage_ref
    position_region_to_disposition_region_matrix
    mutual_information_or_dependence_profile
    local neighborhood correspondence
    major_gradient_correspondence
    minority/counterpattern structure
    nonadditive_configuration_profiles

    uncertainty
    provenance
}
```

Do not assume geometric axes correspond one-to-one.

Homology can be:

- strong globally;
- strong only in some regions;
- nonlinear;
- configuration dependent;
- fractured by identity/geography;
- weak despite strong local pressure footprints.

---

# 5. SPECIFIC MCA / PASSIVE MODALITIES

The GDA tradition includes `specific MCA`, in which some modalities of active questions may be made passive so they do not create distances while preserving the overall questionnaire geometry.

FIELD FORGE should evaluate this specifically for:

- non-substantive missing/no-information modalities;
- routed/nonapplicable states that should not define social distance;
- source-specific administrative/junk modalities;
- rare states whose semantic importance should be preserved but whose geometric leverage requires caution.

Hard law:

```text
PASSIVE IN GEOMETRY
!= SEMANTICALLY DELETED.
```

The exact routed/missing state remains preserved in provenance and other Rawlsing objects even if it does not actively construct a geometric distance.

---

# 6. DISPOSITION-SPACE RISK SET

A major Rawlsing advantage over ordinary GDA is exact routing/J authority.

The disposition space must not simply complete-case-drop everyone who did not answer every item.

Candidate strategies to evaluate:

- build spaces within exact coadministration/risk-set modules;
- use specific MCA/passive modalities for lawful nonresponse states where appropriate;
- build several linked local disposition spaces rather than counterfeit one universal matrix;
- use higher-level J-authorized complexes that already encode lawful coadministration.

No statistical imputation may manufacture same-respondent authority.

---

# 7. MULTIPLE FACTOR ANALYSIS / BLOCK BALANCING

Where questionnaire design gives one conceptual block many more variables than another, investigate block-balanced methods such as Multiple Factor Analysis.

Potential use in both spaces:

```text
POSITION SPACE
    economic block
    occupation block
    education block
    identity block
    geography block

DISPOSITION SPACE
    political legitimacy block
    religious disposition block
    moral boundary block
    economic morality block
    institutional trust block
    geopolitical block
```

Block names themselves require semantic authority.

Method weighting must not silently become ontology weighting.

---

# 8. AXIS INTERPRETATION

In empirical social-space research, axes may be interpreted using modality contributions and external/supplementary variables.

FIELD FORGE should formalize this as an agentic interpretation packet:

```text
axis inertia
above-threshold modality contributions
block contributions
coordinate extremes
supplementary-variable projections
stability/sensitivity
source semantics
```

The court may conclude:

```text
CAPITAL_VOLUME_LIKE
CAPITAL_COMPOSITION_LIKE
RELIGIOUS_COMMUNAL_POSITION_LIKE
URBANITY_GEOGRAPHY_LIKE
MIXED / NONREDUCIBLE
UNSTABLE
UNRESOLVED
```

The suffix `-LIKE` matters until structural admission.

---

# 9. PRESSURE FOOTPRINTS AFTER DUAL GEOMETRY

The pressure map can now be richer.

Instead of only asking:

```text
profile C -> probability of complex D
```

Rawlsing can estimate:

```text
position region / neighborhood
-> distribution over disposition-space regions
```

and preserve fine-grained complex membership within those regions.

This produces:

```text
POSITION_REGION
-> DISPOSITION_REGION PROBABILITY
-> JOINT COMPLEX VARIANTS
```

which is useful for persona generation at several levels of specificity.

---

# 10. BOURDIEUSIAN CLASS SHOULD REMAIN A LATE INTERPRETATION

Even if local position space displays axes resembling capital volume/composition, do not immediately freeze three classes or class fractions.

A later court may ask whether recurring regions are best interpreted as:

- dominant/dominated positions;
- economic/cultural fractions;
- intermediate/petite-bourgeois positions;
- local class fractions;
- something context-specific not well described by classic French class categories.

The data may reproduce classic Bourdieusian structure in some contexts and not others.

Rawlsing should learn that difference.

---

# 11. LAMONT REFINEMENT

Do not treat every culturally patterned disposition as `cultural capital`.

Symbolic/moral boundaries may organize evaluation, dignity, exclusion, and group classification without being reducible to capital accumulation.

Therefore disposition space should permit:

```text
MORAL_BOUNDARY_COMPLEX
SYMBOLIC_BOUNDARY_COMPLEX
DIGNITY / WORTH COMPLEX
```

that can be distributed across social position independently of whether they function as capital.

---

# 12. LAHIRE REFINEMENT

A respondent's point in disposition space is not proof of one coherent habitus.

Use direct joint/repertoire objects to preserve plural dispositions and contradictions behind any low-dimensional geometric representation.

The geometry is a view.

The exact repertoire is the richer respondent-backed object.

---

# 13. CURRENT RECOMMENDATION

FIELD FORGE should prototype **dual local geometric spaces**:

```text
POSITION SPACE
+
DISPOSITION SPACE
+
RESPONDENT-LINKED HOMOLOGY/PRESSURE MAP
```

while retaining exact complex/repertoire objects beneath the geometric summaries.

This appears to be a stronger and more faithful engineering translation of Bourdieu than either a fixed strata system or a single joint clustering of demographics and attitudes.
