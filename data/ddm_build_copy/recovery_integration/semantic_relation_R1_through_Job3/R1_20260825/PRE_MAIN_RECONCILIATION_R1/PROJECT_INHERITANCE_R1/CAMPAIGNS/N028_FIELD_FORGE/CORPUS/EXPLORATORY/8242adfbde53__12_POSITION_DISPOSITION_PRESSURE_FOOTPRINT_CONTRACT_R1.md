# FIELD FORGE R1 — POSITION ↔ DISPOSITION PRESSURE FOOTPRINT CONTRACT

Status: **EXPLORATORY / NON-BINDING / PROSPECTIVE PRE-V3 PRODUCT**

This document defines the empirical object that most directly serves Rawlsing's persona-generation goal while remaining within survey jurisdiction.

The target is not a grand causal explanation of society.

The target is:

```text
HOW DOES THE PROBABILITY DISTRIBUTION
OF A GOVERNED DISPOSITION COMPLEX CHANGE
AS RELATIONAL SOCIAL POSITION CHANGES
WITHIN AN EXACT CONTEXT?
```

FIELD FORGE calls that a:

```text
POSITIONAL_PRESSURE_FOOTPRINT
```

---

# 1. DEFINITION

```text
EMPIRICAL PRESSURE FOOTPRINT
=
a reproducible, respondent-backed redistribution
of probability over governed disposition states
across lawfully comparable social-position configurations,
with exact scope, support, and uncertainty preserved.
```

It is a descriptive relational fact.

It is not automatically:

- a causal mechanism;
- a psychological force;
- a field effect;
- hegemony;
- mediation;
- structural pressure in the strongest explanatory sense.

---

# 2. WHY THIS IS ENOUGH FOR PERSONA GENERATION

Suppose profile P1 and P2 occupy different positions in the same social context.

If the observed joint disposition distribution differs systematically, Rawlsing has learned something directly useful:

```text
P(D | P1, context K)
!=
P(D | P2, context K)
```

For generation, that difference changes the lawful possibility landscape even when Rawlsing cannot establish the ultimate sociological cause.

This is exactly the level at which population structure can inform plausible persona emergence without becoming actor destiny.

---

A footprint computation requires:

```text
local_position_space_ref
```

No footprint may combine respondents who were not lawfully eligible for the compared disposition object.

---

# 4. POSITION CONFIGURATION

Do not restrict the model to additive main effects.

The position input may be:

- an exact profile configuration;
- a region/neighborhood of the local social geometry;
- a small set of active coordinates;
- a configuration of relational identities + resource/credential position;
- an interaction-defined comparison.

Hard Stuart Hall-compatible law:

```text
MEANING/EFFECT OF POSITION ATTRIBUTE A
MAY DEPEND ON B × C × CONTEXT.
```

Therefore:

```text
Shia × education × region
```

may have a different disposition topology from:

```text
Sunni × education × region
```

without requiring any universal `sect coefficient`.

---

# 5. COMPARISON GEOMETRY

The most dangerous hidden choice is the reference position.

A footprint should therefore retain multiple comparison types rather than one universal baseline.

Potential comparison classes:

```text
LOCAL_NEIGHBOR_COMPARISON
MATCHED_CONFIGURATION_COMPARISON
ONE_COORDINATE_CHANGE_COMPARISON
REGION_TO_REGION_COMPARISON
HIGH_VS_LOW_CAPITAL_COMPOSITION_COMPARISON
SOURCE_NATIVE_CATEGORY_COMPARISON
```

Each comparison must be explicit.

Do not let runtime silently choose a sociologically loaded reference category.

---

# 6. COMPUTATIONAL EVIDENCE

Useful evidence may include:

- weighted conditional distributions;
- total variation / Jensen-Shannon-like distributional displacement;
- conditional mutual information;
- log-linear interaction terms;
- multinomial/logistic/hierarchical partial pooling where design law allows;
- fracture-map branch prevalence changes;
- direct J2/J3 state redistribution;
- local neighborhood smoothing in position geometry with honest uncertainty;
- recurrence across lawful subscopes/waves where measurement comparability exists.

No metric alone is semantic authority.

The footprint should preserve a vector/profile rather than one score.

# 8. NON-ADDITIVITY IS FIRST-CLASS

The producer should explicitly test whether a configuration behaves differently from an additive approximation.

For dimensions A and B:

```text
P(D | A,B)
```

should be compared against a lawful additive/independence reference.

If the joint configuration has materially distinct topology, emit:

```text
CONFIGURATION_INTERACTION_PRESENT
```

as a descriptive statistical state.

Do not automatically call it:

- articulation;
- intersectionality;
- mediation;
- amplification;
- structural mechanism.

Those are later interpretations.

---

# 9. FOOTPRINT DIRECTION

A pressure footprint can be represented as a redistribution between position configurations without asserting causal direction.

For generation it may still be operationally useful to say:

```text
moving query from position C1 to C2
changes predicted disposition distribution from P1 to P2
```

But the object must retain:

```text
QUERY_DIRECTION
!= CAUSAL_DIRECTION.
```

---

# 10. MINORITY / COUNTER-PATTERN PRESERVATION

Never emit only the modal destination.

If position C is associated with:

```text
complex A = .58
complex B = .27
complex C = .15
```

all supported branches matter for persona generation.

A minority branch may be especially important for V3 because biography can plausibly select a less-common path.

Therefore pressure footprints must preserve:

- full supported outcome distribution;
- minority complexes;
- uncertainty;
- branch-specific position associations.

---

# 11. PRESSURE FOOTPRINT NETWORK

Multiple disposition complexes can be attached to one position configuration.

The observatory may therefore expose:

```text
POSITION C
    -> footprint on economic-moral complex
    -> footprint on religious-political complex
    -> footprint on institutional-trust complex
    -> footprint on geopolitical complex
```

These are not assumed independent.

Higher-order co-possession remains available through disposition-repertoire objects.

---

# 12. CROSS-CONTEXT RECURRENCE

A footprint pattern may recur across contexts.

The machine may compute a structural signature such as:

```text
education strongly redistributes disposition complex A
only within relational identity group G
across contexts K1,K2
but not K3
```

Do not create a universal rule until manual interpretation and measurement portability/admission establish the appropriate abstraction.

Hall's conjunctural lesson remains:

```text
RECURRENCE MAY SUPPORT A RELATION FAMILY.
NONRECURRENCE MAY BE REAL CONTEXTUAL DIFFERENCE.
```

---

# 13. HOSTILE CASES

Reject or type-limit:

- sparse cross-tabs interpreted as strong pressure;
- Simpson's-paradox-prone aggregate differences without configuration checks;
- reference-category drift across contexts;
- treating country-wide difference as individual effect;
- treating geometry distance as causal exposure;
- using attitude variables to build position geometry and then interpreting the induced association as pressure;
- discarding minority branches;
- cross-wave pooling without measurement portability;
- outputting `NO EFFECT` from underpowered or noncomparable comparisons.
