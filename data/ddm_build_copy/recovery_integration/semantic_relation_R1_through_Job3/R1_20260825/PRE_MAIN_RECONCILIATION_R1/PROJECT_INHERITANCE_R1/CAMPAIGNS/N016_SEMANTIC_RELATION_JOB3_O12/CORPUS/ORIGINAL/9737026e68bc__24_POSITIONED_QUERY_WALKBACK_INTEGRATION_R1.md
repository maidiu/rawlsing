# FIELD FORGE R1 — POSITIONED QUERY / WALKBACK INTEGRATION

Status: **EXPLORATORY / NON-BINDING / INTEGRATION NOTE**

FIELD FORGE must not invent a parallel solution to the existing Rawlsing problem of sparse positioned-subject queries.

The social-space observatory should integrate with the existing positioned-subject possibility / specificity-walkback authority rather than replacing it with generic geometric nearest-neighbor logic.

---

# 1. HARD LAW

```text
GEOMETRIC NEARNESS
!=
SEMANTICALLY LAWFUL PROXY.
```

Two profiles may be close in an MCA geometry while differing on a dimension that cannot lawfully be relaxed for the requested disposition query.

Example:

```text
same income/education/region
but different sect/caste/race
```

may be geometrically close yet semantically non-substitutable for a target disposition in a context where that identity strongly conditions the pressure footprint.

---

# 2. TWO DISTINCT OBJECTS

## A. GEOMETRIC NEIGHBORHOOD

Descriptive relationship in local position space.

## B. LAWFUL PROXY / WALKBACK

Authority-governed broadening relation specifying which position information may be relaxed, in what order, for which target use.

The former may nominate candidates for the latter.

It does not authorize them.

---

# 3. WALKBACK PATH

Potential query sequence:

```text
EXACT POSITION CONFIGURATION
-> exact local position region
-> lawful broader region retaining protected identity dimensions
-> broader resource/credential neighborhood
-> broader source-native comparator
```

Each step records:

```text
dimension relaxed
information lost
reason for permissibility
proxy authority ref
new support
change in disposition distribution
```

---

# 4. TARGET-USE SPECIFICITY

A dimension may be relaxable for one disposition complex and not another.

For example, education might be safely broadened for one institutional-trust query but not for another moral-boundary complex if the empirical pressure map shows strong educational articulation.

Therefore:

```text
WALKBACK AUTHORITY
MAY DEPEND ON TARGET DISPOSITION FAMILY.
```

This is one reason walkback cannot be a global nearest-neighbor rule.

---

# 5. DYNAMIC EVIDENCE FROM PRESSURE FOOTPRINTS

Pressure-footprint analysis can identify candidate dimensions whose relaxation materially changes outcome distributions.

This can inform manual walkback authority:

```text
IF relaxing dimension X repeatedly causes major distribution shift,
X is a poor proxy-relaxation candidate for that target.
```

Compute nominates the evidence.

Manual authority decides the lawful broadening rule.

---

# 6. PERSONA-GENERATION OUTPUT

When exact profile support is unavailable, V3 should receive:

```text
proxy_level
retained_dimensions
relaxed_dimensions
information_loss
resulting disposition distribution
uncertainty
```

rather than one unlabeled probability vector.

---

# 7. HOSTILE CASES

Reject:

- nearest-neighbor = lawful proxy;
- dropping protected identity position because it improves sample size;
- silently broadening across country/wave/source boundaries;
- using pressure-footprint similarity to assert measurement equivalence;
- broadening until a desired stable estimate appears;
- concealing proxy level from persona consumer.

---

# 8. CURRENT RECOMMENDATION

FIELD FORGE should treat local geometry as a **candidate navigation surface** and existing positioned-subject authority as the **semantic law of proxying**.

This preserves both statistical usefulness and epistemic discipline.
