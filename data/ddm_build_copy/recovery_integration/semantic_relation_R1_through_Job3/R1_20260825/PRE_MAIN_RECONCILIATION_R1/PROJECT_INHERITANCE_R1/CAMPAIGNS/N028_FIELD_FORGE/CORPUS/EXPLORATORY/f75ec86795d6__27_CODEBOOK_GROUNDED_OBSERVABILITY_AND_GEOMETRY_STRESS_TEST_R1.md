# FIELD FORGE R1 — CODEBOOK-GROUNDED OBSERVABILITY AND GEOMETRY STRESS TEST R1

Status: **EXPLORATORY / NON-BINDING / CODEBOOK-GROUNDED ARCHITECTURE REFINEMENT**

Jurisdiction: this note stress-tests the existing FIELD FORGE three-geometry architecture against actual current Rawlsing survey/instrument surfaces. It refines `09`, `10`, `11`, `12`, `15`, `19`, `22`, `23`, and `25`. It does not create current product authority, does not amend source-native semantics, and does not move the workstream into V3.

The V3-facing personal-relational-field sketch in `26_PERSONAL_RELATIONAL_FIELD_AND_EMERGENT_ATTRACTOR_R1.md` is a downstream sidecar. It is not the continuation point for this pass.

---

# 1. QUESTION BEING TESTED

FIELD FORGE currently proposes:

```text
POSITION / CAPITAL SPACE

          ↕

DISPOSITION / ATTITUDE SPACE

          ↕

POSITION ↔ DISPOSITION
HOMOLOGY / PRESSURE TOPOLOGY
```

with `PRESSURE_COUPLING / ARTICULATION_FOOTPRINT` as the empirical successor to vague `inter-strata pressure`.

The hostile question is now:

> Does this still work when the geometry is forced to respect the actual questionnaires, routing, risk sets, respondent fields, weights, source variants, and unequal observability Rawlsing really owns?

The answer after this pass is:

```text
YES, BUT NOT AS THREE UNIVERSAL MATRICES.
```

The stronger design is a family of **lawfully admissible local empirical views** whose construction is conditioned by source semantics, respondent exposure, coadministration/J authority, target estimand, and method governance.

# 3. WHAT HELD UP

Several FIELD FORGE principles survived direct source stress and should be strengthened rather than reopened casually.

## 3.1 Locality survives

The default geometry grain remains appropriately local:

```text
source family
× wave
× country / exact source scope
× lawful respondent universe
```

Merged family-wave releases are not sufficient grain when national instruments differ materially.

## 3.2 Position Role Authority survives

Actual mappings confirm that canonical labels such as:

```text
income
employment
class
religion
region
```

do not establish one semantic object or one analytic function.

Examples encountered in current material include:

- an `employment` slot represented by an occupation proxy in one Asian Barometer wave and cleaner employment-status variables in later waves;
- Arab Barometer income candidates ranging from literal respondent/household currency income to a more comparable ordinal household-income-situation proxy;
- explicit class/self-status slots that are not objective relational class coordinates;
- religion variables that vary between membership, practice, belief, strength, institutional embeddedness and other meanings.

Therefore the existing law remains essential:

```text
SOURCE-NATIVE SEMANTIC IDENTITY
!=
ANALYTIC ROLE PERMISSION
```

and the role remains operation-scoped.

## 3.3 Dual-space independence survives

The position space should not silently define the disposition metric, and the disposition space should not silently define the position metric.

The stronger correction is that either side may require **multiple lawful local views** rather than one compulsory integrated space.

## 3.4 Repertoire is richer than disposition geometry

The actual routing/J surface reinforces that a low-dimensional attitude geometry is a view over richer respondent-backed topology.

Exact J/co-possession/branch structure remains more authoritative than geometric proximity for claims about what attitudes coexist in the same people.

## 3.5 Pressure footprint / coupling survives

The definition still works:

```text
position configuration
→ redistribution over lawful disposition states
```

and:

```text
B changes the footprint associated with A
```

remains the correct empirical successor to additive `strata pressure`.

But the phrase `lawfully comparable` now needs a more explicit producer-side basis.

# 4. FIRST MAJOR REFINEMENT — OBSERVABILITY HAS TWO DIFFERENT GRAINS

`15_BOOTSTRAP_OBSERVABILITY_MATRIX_AND_CASE_SELECTION_R1.md` correctly asks what each context can observe.

That is necessary but insufficient.

There are two different questions:

```text
A. DOES THIS CONTEXT CONTAIN THIS CAPABILITY?

B. WAS THIS RESPONDENT LAWFULLY EXPOSED TO THIS MEASUREMENT?
```

They must not collapse.

## 4.1 Context capability observability

Existing object/layer:

```text
CONTEXT_CAPABILITY_OBSERVABILITY
```

Examples:

- education present/absent;
- class present/absent;
- ethnicity present/absent;
- institutional-trust battery present/absent;
- J readiness present/blocked;
- routing readiness present/blocked.

## 4.2 Respondent measurement exposure

New required pre-geometry layer:

```text
RESPONDENT_MEASUREMENT_EXPOSURE_TOPOLOGY
```

It must distinguish at minimum:

```text
SOURCE_OR_WAVE_ABSENT
COUNTRY_NOT_IN_SCOPE
FORM_OR_BALLOT_NOT_ASSIGNED
RANDOM_SPLIT_NOT_ASSIGNED
MODULE_NOT_ASSIGNED
RESPONDENT_ROUTE_INELIGIBLE
PRIOR_ANSWER_GATED_OUT
LAWFULLY_EXPOSED
EXPOSED_REFUSED
EXPOSED_DONT_KNOW
EXPOSED_SUBSTANTIVE_RESPONSE
UNRESOLVED_ROUTING_OR_EXPOSURE
```

Hard laws:

```text
QUESTION EXISTS IN CONTEXT
!=
RESPONDENT WAS AT RISK OF ANSWERING
```

and:

```text
MEASUREMENT NONRESPONSE
!=
MEASUREMENT NONEXPOSURE
```

and:

```text
PHYSICAL MISSINGNESS
!=
ROUTING AUTHORITY
```

# 5. WHY ARAB BAROMETER VIII MAKES THIS UNAVOIDABLE

The Wave VIII discrimination section is a clean hostile example.

The instrument contains all of the following within one local questionnaire surface:

- split A / split B wording variants;
- randomization of discrimination Section A and Section B;
- country-specific wording and response-option scope;
- select-all-that-apply source structures;
- follow-up questions shown only if earlier answer states permit them;
- answer-piping where the later response set is literally determined by earlier selected answers;
- personal-experience questions that branch into further reason/circumstance questions only for respondents who report discrimination.

Therefore a later item may be semantically clear and present in the dataset while still being undefined for large lawful respondent subsets.

A generic passive `NOT_ASKED` modality is not enough to govern the geometry.

The geometry needs the exact **exposure predicate**.

# 6. DISPOSITION SPACE MUST BEGIN FROM COADMINISTRATION TOPOLOGY

This pass strengthens `22_DUAL_GEOMETRIC_SPACES_AND_GDA_REFINEMENT_R1.md`.

Do not start from:

```text
ALL ATTITUDE COLUMNS IN THIS WAVE
→ ONE ATTITUDE MCA
```

Instead:

```text
SOURCE-NATIVE ATTITUDE OBJECTS
+
ROUTING / RISK-SET AUTHORITY
+
J / SAME-RESPONDENT AUTHORITY
        ↓
DISPOSITION MEASUREMENT TOPOLOGY
        ↓
LAWFUL LOCAL DISPOSITION GEOMETRIES
        +
EXACT COMPLEX / REPERTOIRE OBJECTS
```

Candidate object:

```text
DISPOSITION_MEASUREMENT_TOPOLOGY {
    context_id
    respondent_universe_ref

    measurement_nodes[]

    coadministration_edges_or_hyperedges[] {
        member_measurement_refs[]
        exact_risk_set_ref
        routing_rule_refs[]
        form_module_country_scope_refs[]
        J_authority_refs[]
        support_state
    }

    disconnected_or_noncomparable_components[]
    unresolved_exposure_relations[]
    provenance
}
```

The object is empirical/instrumental, not sociological ontology.

It answers:

> Which disposition measurements can actually inhabit one same-respondent empirical space, and under exactly what scope?

# 7. J IS PART OF METRIC ADMISSIBILITY, NOT MERELY COMPLEX ENRICHMENT

FIELD FORGE previously treated J primarily as the substrate for richer complexes/repertoires.

That remains true but is incomplete.

For disposition geometry:

```text
SAME-RESPONDENT JOINT AUTHORITY
IS PART OF THE RIGHT TO ASSERT A COMMON EMPIRICAL METRIC.
```

Hard laws:

```text
SEMANTIC SIMILARITY
!=
COADMINISTRATION
```

```text
PAIRWISE MARGINS
!=
COMMON HIGHER-ORDER RESPONDENT SPACE
```

```text
STATISTICAL IMPUTATION
!=
SAME-RESPONDENT AUTHORITY
```

Where the instrument yields disconnected or conditionally connected attitude surfaces, FIELD FORGE should prefer:

```text
DISPOSITION_GEOMETRY_ATLAS
```

or several linked local spaces over a counterfeit universal attitude matrix.

# 8. POSITION SPACE MAY ALSO BE A GEOMETRY FAMILY

The actual respondent surfaces are uneven enough that `LOCAL_POSITION_SPACE` should not be interpreted as requiring one canonical integrated space in every context.

Some contexts richly observe:

- resources;
- education;
- occupation/employment;
- class/self-status;
- identity;
- geography;
- household structure.

Others lack several of these or carry them only through proxy/partial variables.

Therefore the producer should permit:

```text
LOCAL_POSITION_GEOMETRY_FAMILY {
    context_id

    resource_position_view?
    occupation_employment_view?
    education_credential_view?
    relational_identity_view?
    full_relational_position_view?
    other_lawful_domain_views[]

    integration_status
    cross_view_correspondence
    observability_limits
}
```

Possible `integration_status` values:

```text
INTEGRATED_POSITION_SPACE_ADMISSIBLE
MULTI_VIEW_POSITION_GEOMETRY_ONLY
DOMAIN_FRAGMENTED_POSITION_OBSERVABILITY
POSITION_GEOMETRY_TOO_THIN
UNRESOLVED
```

This does **not** mean every conceptual domain becomes a new ontology object.

It means the instrument may not support one honest integrated geometry.

# 9. BLOCKS THEMSELVES NEED TYPE DISCIPLINE

`19_GEOMETRY_GOVERNANCE_AND_WEIGHTING_R1.md` correctly warns that questionnaire block size can become fake ontology weight.

The stress pass reveals three different kinds of block that must remain distinct:

```text
SOURCE_INSTRUMENT_BLOCK
    questionnaire/module/battery organization

ANALYTIC_ROLE_BLOCK
    variables grouped for a declared geometry use

EMPIRICAL_COADMINISTRATION_BLOCK
    measurements sharing a governed respondent exposure/risk set
```

These may overlap. They are not identical.

Hard laws:

```text
QUESTIONNAIRE MODULE
!=
SOCIOLOGICAL DOMAIN
```

```text
ANALYTIC ROLE BLOCK
!=
FIELD
```

```text
SOURCE BLOCK SIZE
!=
SOCIOLOGICAL IMPORTANCE
```

Block balancing/MFA may compare lawful method specifications, but the act of balancing must not silently mint the blocks' semantic importance.

# 10. SECOND MAJOR NEW CONTRACT — GEOMETRY ESTIMAND / REPRESENTATION TARGET

The phrase `weight_design_ref` is too weak by itself.

The actual sources expose different weights for different analytical purposes.

Examples in current Rawlsing authority work include:

- WVS sociodemographic adjustment weights;
- equal-country weighting;
- explicitly documented combined purposes;
- GSS baseline / combined / follow-on or experiment-specific weight domains;
- cases where no universal/default weight is authorized;
- current Rawlsing descriptive weighted evidence that does not yet authorize design-based variance claims.

Therefore every geometry must first declare **what population/object it claims to represent**.

Proposed prospective contract:

```text
GEOMETRY_ESTIMAND_CONTRACT {
    geometry_build_id
    context_id

    representation_target
    respondent_universe_ref
    exact_risk_set_or_exposure_scope_ref

    weight_purpose_ref
    weight_ref
    design_authority_refs[]

    descriptive_vs_inferential_posture
    variance_authority_state

    allowed_claims[]
    forbidden_claims[]

    provenance
}
```

Candidate `representation_target` states:

```text
SAMPLE_RELATIONAL_GEOMETRY
TARGET_POPULATION_RELATIONAL_GEOMETRY
EQUAL_CONTEXT_COMPARATIVE_GEOMETRY
OTHER_EXPLICITLY_GOVERNED_TARGET
```

No universal default is implied.

Hard law:

```text
NO WEIGHT WITHOUT AN ESTIMAND.
```

and:

```text
NUMERIC WEIGHT PRESENT
!=
AUTHORIZED GEOMETRY USE.
```

# 11. SAMPLE GEOMETRY AND POPULATION GEOMETRY MAY BOTH BE LAWFUL

FIELD FORGE should stop assuming that one weighted geometry is automatically the singular true geometry.

A descriptive sample geometry can answer:

> What relational structure exists among the observations actually collected under this exact design?

A target-population geometry can answer:

> What relational structure is estimated for the target population under this exact governed weighting purpose?

These can differ.

The difference may itself be diagnostically useful.

Do not erase it by choosing a hidden default.

# 12. PRESSURE FOOTPRINT DOES NOT NEED A NEW AUTHORITY CLASS HERE

`12_POSITION_DISPOSITION_PRESSURE_FOOTPRINT_CONTRACT_R1.md` already requires:

- exact risk set;
- weights/design authority;
- explicit comparison rule;
- support law;
- uncertainty;
- no silent reference-category choice.

Therefore do **not** create a redundant `PRESSURE_REFERENCE_FRAME_AUTHORITY` merely because this stress pass found the comparison issue again.

Instead, strengthen the producer dependency:

```text
PRESSURE FOOTPRINT
MUST CONSUME
    RESPONDENT_MEASUREMENT_EXPOSURE_TOPOLOGY
    + GEOMETRY_ESTIMAND_CONTRACT
    + existing explicit comparison rule
```

Then `lawfully comparable` becomes checkable rather than rhetorical.

# 13. DIFFERENTIAL VALUATION SHOULD PRECEDE CAPITAL-CONVERSION LANGUAGE

`14_FIELD_CANDIDACY_AND_CAPITAL_CONVERSION_CONTRACT_R1.md` already warns:

```text
DIFFERENT CONDITIONAL ASSOCIATION
!=
PROVED CAPITAL CONVERSION MECHANISM
```

The current source stress suggests the object vocabulary should become even more conservative.

Cross-sectional survey contrast most directly supports:

```text
DIFFERENTIAL_RESOURCE_VALUATION_PROFILE
```

not an observed conversion event.

Recommended ladder:

```text
DIFFERENTIAL_RESOURCE_VALUATION_PROFILE
        ↓
CAPITAL_VALUE_CANDIDACY
        ↓
CAPITAL_CONVERSION_CANDIDACY
        ↓
manual structural admission
```

`CAPITAL_CONVERSION_CANDIDACY` should require evidence beyond merely finding that association with disposition/status differs between region A and region B.

Potential stronger evidence may include, where actually observable:

- multiple resource forms with structured tradeoff/substitution patterns;
- origin/current-position or trajectory evidence;
- recurrent context-relative resource valuation;
- status/recognition gradients not reducible to one resource coordinate;
- repeated or cross-context evidence under lawful comparability.

Where those are absent, stay at differential valuation.

# 17. NEW HOSTILE TESTS

Any FIELD FORGE prototype should now fail or type-limit the following cases.

## H1 — split-sample counterfeit disposition space

Two attitude blocks are semantically related but assigned to mutually exclusive random splits.

Forbidden:

```text
merge / impute
→ one common respondent disposition space
```

unless separate lawful bridging authority exists.

## H2 — follow-up selection mistaken for population distribution

A follow-up is asked only after respondent chooses a prior answer.

Forbidden:

```text
follow-up respondent distribution
→ unconditional population disposition distribution
```

## H3 — canonical slot laundering

Wave A uses direct employment status.
Wave B uses occupation proxy in the `employment` slot.

Forbidden:

```text
slot_name == employment
→ same analytic coordinate semantics
```

## H4 — hidden weight default

Multiple weights exist with distinct source purposes.

Forbidden:

```text
pick primary / first / nonmissing weight
→ target-population geometry
```

## H5 — source module becomes ontology block

A questionnaire contains 12 governance items and 3 economic morality items.

Forbidden:

```text
12 > 3
→ governance is four times more structurally important
```

or:

```text
questionnaire module
→ sociological field
```

## H6 — absent structural dimension invented from sibling survey

Asian Barometer observes a dense harmony/family-state hierarchy battery.
South Asia does not.

Forbidden:

```text
regional/family resemblance
→ project Asian disposition geometry into South Asia
```

## H7 — differential association promoted to conversion

Education associates with high-status disposition A in region X and not Y.

Allowed:

```text
DIFFERENTIAL_RESOURCE_VALUATION_PROFILE
```

Forbidden without further evidence:

```text
PROVED CAPITAL CONVERSION
```

# 20. QUESTIONS THIS PASS OPENS

The next FIELD FORGE passes should attack at least these questions.

## Q-A — when is an integrated position space preferable to a family of domain views?

Need an empirical integration criterion, not aesthetic preference.

## Q-B — how do several disposition geometry components link without inventing a common metric?

Possible bridges may include exact shared respondents, shared J-authorized complexes, or supplementary cross-projection. No semantic-similarity shortcut.

## Q-C — what is the right representation of exposure topology?

A hypergraph may be more faithful than pairwise edges because module/routing/J compatibility is often n-ary.

## Q-D — how should source-native blocks and analytic-role blocks enter MFA/block balancing together?

Need sensitivity designs that prevent either questionnaire authorship or analyst ontology from silently dominating.

## Q-E — when does a target-population geometry materially differ from the sample geometry?

This should be measured in prototype contexts rather than assumed.

## Q-F — what evidence earns movement from differential resource valuation to capital-value candidacy?

This is now more important than defining a numeric `capital_conversion_strength`.

## Q-G — can the pressure-footprint producer remain stable when the disposition target is an atlas/component rather than one global space?

Likely yes, because exact complex/repertoire states can remain the target even when low-dimensional geometry fragments. Must test.

# 21. TERMINAL FINDING OF THIS PASS

The codebooks do **not** kill the FIELD FORGE three-geometry idea.

They kill the naive version of it.

The naive version is:

```text
DEMOGRAPHIC MATRIX
→ MCA

ATTITUDE MATRIX
→ MCA

JOIN RESPONDENT COORDINATES
→ PRESSURE
```

The stronger Rawlsing version is:

```text
WHAT WAS ACTUALLY MEASURED,
FOR WHOM,
UNDER WHAT SOURCE SEMANTICS,
UNDER WHAT ROUTING / J / WEIGHT PURPOSE,
AND FOR WHAT REPRESENTATIONAL CLAIM?
        ↓
ONLY THEN CONSTRUCT THE LAWFUL GEOMETRIC VIEW.
```

This yields the strongest new hard laws from the pass:

```text
NO GEOMETRY BEFORE OBSERVABILITY GRAIN IS GOVERNED.

NO COMMON METRIC WHERE COADMINISTRATION IS ABSENT.

NO WEIGHT WITHOUT AN ESTIMAND.

NO BLOCK WEIGHT WITHOUT BLOCK-TYPE PROVENANCE.

NO CANONICAL SLOT AS PORTABILITY AUTHORITY.

NO CAPITAL CONVERSION FROM DIFFERENTIAL ASSOCIATION ALONE.
```

That is a more feasible, more source-faithful, and more Rawlsing-consistent engineering basis for the PRE553 observatory.
