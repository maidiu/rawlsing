## 2. Immutable identity and proof model

**Identity tuple (never replace historical namespace):** `(estate_id, source_commit_40hex, source_path_or_manifest, source_composite_id, source_grain)`. An alias or target override has a separate `alias_of` / `target_id` field and may not masquerade as another native source ID. If exact row ID fields vary per source record type, explicitly store the type-specific extraction path; no delimiter-based guess or implicit name join.

**No-drop at the assigned grain:** build sets from exact input source keys and returned canonical keys, reject duplicate `identity tuple`, show `source − return`, `return − source`, `alias collisions`, `unjoined`, `ambiguous joins`, `unread source depth` separately. Empty antisets are necessary but **not sufficient** for semantic equivalence, selected authority application, first-consumer read or source-native rights.

**No denominator inflation:** never add 44+30+29+58+7, 55, 62+82+49+345, 2,416/1,314 or Sorok subsets into a supposed unique-function total. The source/namespace/grain distinguish repeated obligation carriers. Join functions only with proof of same `input → meaning-producing operation → qualified output → first consumer → consequence`; otherwise preserve alias/partial/conflict/unjoined.

**Independent dimensions, not a single PASS:**
`obligation_disposition` (historical value/modern necessity), `implementation_status` (protected/branch/history/none/uninspected), `authority_status` (issuer/available/selected/applied/refusal/consumer), `proof_grade` (S0/S1/S2 sourcefree/reviewed/native), `consumption_status` (actual non-test/test-only/planned/unknown/none), `receiving_status` (worker return/independent review/protected owner).
