## The dependency that cannot be shortened

An old source's human meaning must survive all the following checks: (1) select the actual survey/source/physical question/response grain; (2) interpret wave, country, routing, risk set and missingness; (3) select an applicable historical authority release under its exact predicate; (4) emit a response/use/relationship-bearing bridge object with refusals enforced; (5) observe the **first actual consumer and terminal effect**. A historical source blob, a recorded rule selection, a static Python call and a modern object with a similar name are four different evidence classes. This return proves many source/static seams and deliberately leaves stages 3–5 unproved as **runtime/issuer** propositions.
