Rawlsing did not arrive at its present authority constitution by designing one clean ontology once. It learned the constitution by repeatedly discovering that apparently convenient equivalences were false:

- same bytes / same row / same ID did not necessarily mean same semantic claim;
- newer did not mean current;
- source proximity, lexical similarity, shared file membership, or historical survival did not create authority;
- source structure did not imply joint configuration;
- semantic relation did not imply respondent composability;
- exact candidate REJECT did not imply negative semantic truth;
- BLOCKED did not imply false;
- a complete declared frontier did not prove the prerequisite universe was complete;
- a complete carrier did not prove source-native meaning was complete;
- a successful implementation did not imply admission;
- campaign acceptance did not imply HQ adoption;
- delegated project-current authority did not imply global sovereignty;
- preservation did not imply live promotion;
- historical mechanism, denominator, backend, or stage layout did not automatically survive as a current semantic requirement.

The present authority system is therefore best understood as a sequence of **category-error corrections** plus **information-conservation laws**.

`SOURCE-NATIVE FACT / SOURCE-WAVE IDENTITY`

## 4. How semantic proposition identity was learned — P1

P1 was forced by a specific succession problem: Rawlsing had authority IDs, carrier IDs, row IDs, hashes, source refs and policy versions, but no single lawful theorem for deciding whether two authority instances expressed the **same typed semantic claim**.

The dangerous alternatives were explicit:

- bake authority version into claim identity → evidence-only recertification creates false semantic novelty;
- exclude authority/source version everywhere → genuine semantic corrections appear identical;
- hash generic JSON → deterministic bytes masquerade as semantic substantiation;
- make source refs always constitutive → stronger evidence cannot recertify the same claim;
- make source refs never constitutive → source-bounded meaning disappears;
- treat every policy change as semantic change → use-permission narrowing rewrites history;
- treat no policy change as semantic change → ontology-definition corrections disappear;
- equate R3 row ID with semantic identity → carrier succession becomes semantic duplication.

P1 therefore separated:

1. `RELATION_PROPOSITION_IDENTITY`
2. truth-bearing `SEMANTIC_CLAIM_IDENTITY`
3. `GOVERNING_AUTHORITY_INSTANCE_IDENTITY`
4. `LIFECYCLE_CURRENT_SELECTION_IDENTITY`
5. `CONSUMER_PERMISSION_IDENTITY`

and froze the critical rule:

`EXACT_CANDIDATE_REJECT` and `BLOCKED` are adjudications **about** a proposed proposition; they are not semantic truth polarities.

P1 also preserved family-specific identity anatomy under a common envelope, rather than replacing T01-T15 semantics with one schema-less object format.

## 5. How current selection was learned — P2

Once claim identity was separated from authority identity, Rawlsing still needed to know which authority instance governed **now**.

P2 exists because chronology is seductive and wrong. It explicitly rejected:

- latest timestamp;
- newest commit;
- highest version string;
- filesystem order;
- “no newer row exists”;
- fuzzy/default fallback.

The R16F→strict-T06/T15→O12→Job3 history proved why. Different lifecycle events have different meanings:

- recertification may keep the same claim but change authority instance;
- correction changes constitutive semantics;
- completeness-only supersession may leave ordinary edge truth unchanged while invalidating absence/completeness consumers;
- ontology expansion may leave old claims true while changing lawful search space;
- reopening a BLOCKED object changes eligibility for adjudication but creates no truth;
- a differently typed successor can arise without rewriting a historical REJECT.

Thus:

`CURRENT != NEWEST`

and current selection requires explicit governed selection over exact jurisdiction, target identity, scope, and selection purpose.

- a new resolver was not proof that old authority meaning survived;

`PRESERVATION_COMPLETE != ALL_SEMANTIC_QUESTIONS_SOLVED`

`PRESERVATION != LIVE_PROMOTION`.
