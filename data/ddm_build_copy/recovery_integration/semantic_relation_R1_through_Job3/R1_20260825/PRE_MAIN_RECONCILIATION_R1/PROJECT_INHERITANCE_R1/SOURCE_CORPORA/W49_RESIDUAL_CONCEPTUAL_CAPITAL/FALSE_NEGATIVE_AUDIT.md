The failure mode under test was naming capture: assuming that the project's important conceptual ontology is exhausted by the names of the currently remembered role/campaign lanes.

W49 therefore used the frozen W01 Git universe as its search frame and treated branch names as weak discovery hints only.

## Method

The hostile audit used five complementary passes.

### Pass A — maximal-tip exclusion sweep

W49 inspected the W01 maximal-tip census and filtered away obvious named-lane identifiers. The residual set was then reviewed for hidden named-lane content in paths/subjects. This caught, among other things:
- Structural Pressure Observatory;
- Source/Wave Identity Repair;
- detached V551 directionality/promotability;
- M6 QUC blocker;
- Phase-D positioned-evidence recovery;
- information-conservation and portability bodies.

Several apparent residuals were rejected after content inspection because their paths showed that they were actually Chetiri or named authority work.

### Pass B — non-maximal but conceptually consequential contained work

A maximal-only search would itself create false negatives. W49 therefore inspected historically contained repairs whose conceptual result was absorbed into the current line.

The clearest example is the Post-G5 V550→V551 bridge repair. Its branch is an ancestor of the starting line, so it is not topologically orphaned. It is still conceptual capital because it established that an authority field can be computed correctly upstream yet be silently erased by schema-limited serialization, and that certification/promotability cannot reconstruct applicability.

Section85 is another contained/current-tree example with a still-live deferred frontier.

### Pass C — recovered pre-role architecture

## False negatives actually found

### FN-01 — role-name false negative

SWID is a project-wide identity architecture whose branch name reads like a repair campaign. Searching only role names would miss its governed identity kernel, no-silent-rehash law, cross-stage transport contract, hostile alias semantics, and deferred V553 seam.

Disposition: material false negative.

### FN-02 — helper-file false negative

ddm_v551_directionality_expectation.py looks like a local helper. Its docstring and tests encode a general authority-denominator law that prevents downstream execution success from defining eligibility.

Disposition: material false negative.

### FN-03 — hotfix false negative

The Post-G5 serialization repair looks operational. It changed a project ontology distinction: an authority state is not preserved unless the carrier schema and governed hash preserve it; applicability cannot be reconstructed from weaker status.

Disposition: material false negative despite full topological consumption.

### FN-04 — canary false negative

Section85 looks bounded and obsolete after later work, but its exact continuation still carries a deferred empirical program and a foundational distinction between proposition authority, joint-configuration authority, and respondent-level co-occurrence evidence.

Disposition: material false negative with surviving return obligation.

### FN-05 — failed-run false negative

M6's incomplete canary could be dismissed as a failed execution. It cleanly distinguishes response-option semantics from QUC enrichment and authority from derived response-map cache.

Disposition: retain boundary lesson; do not retain blocked terminal status as current.

### FN-06 — role-directory false negative

C4R2A lives under a Dva integration path, but its seven-gap producer→carrier→consumer conservation law is architecture-general and R06 later independently rediscovers the same component-loss risk.

Disposition: material cross-campaign conceptual capital.

### FN-07 — recovery-directory false negative

R06 is an archaeology/recovery body, but it earns general laws about lineage identity, package-relative absence, authority-role conservation, append-only maintenance, and stale-root chronology. Those laws are not reducible to the mechanics of recovery.

Disposition: material meta-architecture capital.

### FN-08 — old-ontology false negative

Early person-world/Structural Persona/Pax work predates the later role vocabulary. Much of its physical design is obsolete or provisional, yet it contains durable constraints about epistemic separation, generated history, structural mediation, and no-decorative-ontology discipline.

Disposition: material ideation capital; no old implementation authority.

### FN-09 — portability false negative

G1A portability appears infrastructural, but it governs how absence and derived representation may be interpreted. It proves that connector/carrier visibility is not ontology.

Disposition: material materialization/provenance capital.

### FN-10 — placeholder-room false negative

Structural Pressure Observatory is mostly unfinished placeholder text. Its value is not implementation but the fact that an independent design room explicitly identified the precondition problem for post-PRE553 social ontology.

Disposition: low implementation value, nontrivial ideation relevance, non-binding.

### FN-11 — stale-root false negative

Phase-D recovery shows a root-level BLOCKED status can be true historical evidence and still not be the latest terminal state. Exact internal receipt chronology is required.

Disposition: material lineage-method capital.

## Sibling-blindness receipt

W49 did not read W42–W48 worker returns or use their findings to select candidates. The audit was grounded in W01 topology, exact historical/current branch content, current starting tree, and older campaign surfaces.

## Court conclusion

The named decomposition is useful but not ontologically complete by itself. The main false-negative risk is not a hidden alternate sovereign architecture. It is a set of cross-cutting laws and deferred obligations that live in repair campaigns, negative results, recovered archives, and exploratory rooms.

Future W4B synthesis should therefore carry the residual bodies as conceptual capital with explicit authority ceilings. It should neither ignore them nor promote them wholesale.
