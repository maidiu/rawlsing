## Discovery method
### LiTS
Every assigned native questionnaire was reviewed across its full instrument. Discovery was then cross-checked independently against the exact current deep catalog. Two current-only mechanisms were admitted: (a) explicit source instructions/tables such as `READ OUT`, `SINGLE CODE FOR EACH`, `MULTICODE`, ranking, roster, and loop blocks; and (b) specific canonical `parent_group_id` relations in the current governed catalog. The over-broad generic `GROUP:q` aggregation was **not** treated as a source-native relation; structures hidden inside it were admitted only when independently established by the native questionnaire.

### Latinobarómetro / South Asia
Where native bytes were available, the normalized native codebook and current row authority were jointly reviewed. Where native bytes were not recovered, only the current canonical row authority and exact governed catalog were used. Repeated source stems were admitted only when their question text showed a genuine repeated relation. Same-number suffixes with divergent semantics were rejected. Latinobarómetro 2024 was handled module-safely so reused numeric roots across ST/TE/NCV/NOIJ/NINT were not falsely merged.

### Packed current fields
A packed multiselect is not counterfeit-expanded into item implementation IDs. When current source authority proves the source option set but the current catalog exposes one packed carrier, the source structure is preserved with `SOURCE_STRUCTURE_EXISTS_CURRENT_MEMBER_BINDING_INCOMPLETE`, exact option identities, and a typed gap.

## Candidacy
`CURRENT_J_CANDIDATE` means current source structure can carry irreducible joint respondent information. It does **not** authorize executable J. Context-only/source-organization groups are retained as `SOURCE_GROUPING_ONLY_NON_J`; interviewer/paradata groups as `ADMINISTRATIVE_GROUP`; the frozen R1 unresolved roster candidacy is preserved rather than silently reclassified.

## Gap law
Native-source byte gaps, source-instrument internal label-range inconsistencies, and item-level current-binding gaps are typed explicitly. Absence of current binding is never converted into absence of source structure. No neighboring-wave continuity is inferred.
