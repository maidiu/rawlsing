## Governing method: differential archaeology

The campaign does not ask merely: `WHAT OLD MATERIAL SHOULD WE IMPORT?`

It asks:

`WHAT BECOMES VISIBLE WHEN A RECOVERED BODY OF KNOWLEDGE COLLIDES WITH A LATER SYSTEM THAT WAS BUILT WITHOUT FULL ACCESS TO IT?`

The desired outputs include:
- old work directly reusable now;
- present machinery that unknowingly reinvented a weaker substitute for older knowledge;
- old machinery made obsolete by the newer architecture while its semantic/function capital survives;
- current gaps exposed by recovered canaries, negatives, roles, coverage law, provenance, or source-native structure;
- useful old distinctions that require a new crosswalk rather than resurrection;
- opportunities created only by combining old and new architectures;
- historical failure modes that should become tests, invariants, or compiler law;
- truly obsolete material that can finally be retired with positive reasons.

## PHASE / GATE LAW

### G0 — ROLE-UNIVERSE FREEZE

Each Vozhd works independently.

Before materially inspecting Layers A-D, each Vozhd must reconstruct its OWN live conceptual universe from the current governed GitHub state and bank a role-universe freeze containing:
- exact live branch / HEAD used;
- command identity and jurisdiction;
- current architecture / ontology / dependency model;
- current priorities and active gates;
- current known gaps / blockers / uncertainties;
- present assumptions about what is source authority, learned authority, derived state, runtime state, and forbidden inference;
- which historical/recovery obligations are already represented in its own system.

The coordination branch contains the launch law and inheritance, but MUST NOT be mistaken for the role's current governing branch.

`GROUND_IN_ROLE_NATIVE_GITHUB_BEFORE_READING_THE_RECOVERY_AS_AN_ANSWER`

### G1 — BLIND FIRST COLLISION

After banking G0, each Vozhd independently interrogates the R3 inheritance against its frozen current system.

Do NOT read sibling Dva/Trii/Chetiri findings, summaries, or discussion before completing G1.

For every material collision classify at minimum:
- `ALREADY_PRESENT`
- `PRESENT_BUT_LOSSY`
- `ABSENT_COMPATIBLE`
- `CURRENTLY_CONTRADICTED`
- `RECOVERED_SUPERSEDED`
- `LATENT_CAPABILITY`
- `NEW_TEST_OR_FIXTURE`
- `NEW_OPEN_QUESTION`
- `ARCHITECTURAL_ANOMALY`

G1 is non-integrative. No finding becomes new authority merely because it is interesting.

### G2 — TARGETED DEEP EXCAVATION

Each Vozhd selects the highest-value G1 anomalies and descends through Layer B, source lineage, historical graph, executable memory, and lawful external pointers as necessary.

Rabochii may be spawned only after the anomaly and proof burden are explicitly stated.

The object of G2 is not more archaeology. It is to answer a bounded question that could change understanding, avoid reinvention, expose loss, or create a testable improvement.

### G3 — COUNCIL OPENS

Only after all three G1 returns are banked does the shared council open.

Each Vozhd contributes:
- 10–20 highest-value findings;
- 3–5 findings it believes may change another role's assumptions;
- 5 questions it cannot answer within its own jurisdiction;
- exact evidence pointers;
- any proposed experiment, without claiming its result.

### G4 — RECIPROCAL CROSS-EXAMINATION

The other two Vozhdy attack each finding from their own jurisdictions.

Dva asks: architectural consequence, stage ownership, whole-machine sufficiency, historical conceptual continuity.

Trii asks: semantic/source authority, exact grain, negative-state law, information conservation, forbidden inference.

Chetiri asks: executability, discoverability, persistence/regeneration, search termination, incremental invalidation, replay, and hostile falsifiability.

Agreement by majority is not evidence.

## Three mandatory provocations

Every Vozhd must explicitly answer:

1. Where has the current system unknowingly reinvented a WEAKER substitute for something the recovered system knew more precisely?
2. Where did the recovered system spend major effort solving a problem the current architecture has made obsolete, while some function/meaning may still need preservation?
3. What becomes possible by COMBINING the recovered and current systems that neither architecture separately contemplated?
