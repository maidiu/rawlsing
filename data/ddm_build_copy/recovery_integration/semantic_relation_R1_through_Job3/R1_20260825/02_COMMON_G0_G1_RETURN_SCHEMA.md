# COMMON G0 / G1 RETURN SCHEMA

Use this schema for the first independent return. Prose is allowed, but every material finding must be recoverable into these fields.

## G0 — role-universe freeze

- `role`
- `live_governing_branch`
- `live_head_sha`
- `command_identity`
- `jurisdiction`
- `current_architecture_summary`
- `current_dependency_or_gate_state`
- `current_priority_frontier`
- `known_gaps_or_blocks`
- `current_epistemic_partition`
- `historical_recovery_already_consumed`
- `important_current_assumptions`
- `files_authorities_read`

End G0 with:

`ROLE_UNIVERSE_FROZEN_FOR_BLIND_RECOVERY_COLLISION = YES`

## G1 — collision ledger

For each material finding:

- `finding_id`
- `collision_class` — one of `ALREADY_PRESENT`, `PRESENT_BUT_LOSSY`, `ABSENT_COMPATIBLE`, `CURRENTLY_CONTRADICTED`, `RECOVERED_SUPERSEDED`, `LATENT_CAPABILITY`, `NEW_TEST_OR_FIXTURE`, `NEW_OPEN_QUESTION`, `ARCHITECTURAL_ANOMALY`
- `current_system_object_or_claim`
- `recovered_object_or_claim`
- `exact_current_evidence`
- `exact_recovered_evidence`
- `role_native_interpretation`
- `why_it_matters`
- `what_it_does_not_prove`
- `authority_status`
- `possible_present_use`
- `possible_future_use`
- `needs_deep_excavation`
- `proposed_bounded_question`
- `possible_cross_role_relevance`
- `confidence_and_reason`

## Mandatory summary

Each G1 return must include:

1. Top 10 findings by expected Rawlsing value.
2. Top 5 suspected wheel-reinventions.
3. Top 5 cases where old machinery is obsolete but old function/meaning may survive.
4. Top 5 genuinely novel synthesis opportunities created by old+new combination.
5. Top 5 items requiring G2 deep excavation.
6. Five questions the role expects another Vozhd may eventually need to answer.
7. A list of important areas searched where NO material new utility was found.

## Non-dispositive close

End G1 with:

`BLIND_FIRST_COLLISION_COMPLETE__NO_INTEGRATION_AUTHORIZED`

Do not recommend merging, rewriting current authority, selecting an architecture route, or mutating runtime/semantic law in the G1 return. Those are later gates.
