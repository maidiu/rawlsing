# C07 — MINIMAL LAWFUL HQ EMPIRICAL COMPARABILITY RULE

Status: `COURT_PROPOSAL__DERIVED_FROM_ACCEPTED_AUTHORITY__HQ_ADOPTION_REQUIRED`

This is the smallest rule the court finds derivable without creating a harmonization, portability, pooling or architecture regime.

## C07-COMP-01 — comparison is an exact governed operation

Every proposed empirical comparison MUST name:

1. exact empirical fact/result refs or exact governed result identities;
2. exact comparison operation and requested output grain;
3. exact target semantic/value/topology identities;
4. exact EmpiricalUniverse/source/wave/release identities;
5. exact target population/sample-frame and geography identities;
6. exact field/reference/effective time scopes;
7. exact routing/risk-set/condition identities;
8. exact measure basis including weight/design/estimand authorities where applicable;
9. exact governing semantic-authority/lifecycle identities;
10. every positive relation/bridge authority needed because any of 3–9 differ;
11. every applicable negative/deny/noncomparability authority.

No unnamed dimension may be silently normalized away.

## C07-COMP-02 — distinct by default

If any material comparison coordinate differs, preserve the objects as distinct.

`DIFFERENCE + NO POSITIVE RELATION AUTHORITY => DISTINCT_BY_DEFAULT`

Distinctness alone neither authorizes nor forbids a comparison. It prevents identity collapse.

## C07-COMP-03 — direct like-for-like comparison

A direct like-for-like comparison is lawful only if all operation-material coordinates are exact-equal under governed identity, or an already-positive authority explicitly establishes equivalence/survival for that exact coordinate and scope.

No heuristic resemblance is authority.

## C07-COMP-04 — exact bridge closure

When material coordinates differ, the comparison is positively authorized only if **every** required mismatch is covered by its owning exact authority kind and no blocking negative applies.

`ALL_REQUIRED_BRIDGES_POSITIVE_AND_EXACT + NO_BLOCKING_NEGATIVE => COMPARABLE_FOR_EXACT_OPERATION`

The resulting permission is scoped to that exact operation. It is not global equivalence.

## C07-COMP-05 — relation kinds do not substitute

Preserve the accepted nonimplications:

`RESPONDENT_LINKAGE != OVERLAP_NON_DUPLICATION`

`RESPONDENT_LINKAGE != SAMPLE_POOLING`

`SAMPLE_POOLING != MEASUREMENT_PORTABILITY`

`ESTIMAND_COMPOSITION != SCALE_EQUIVALENCE`

`SOURCE_SEMANTIC_EQUIVALENCE != VALUE_EQUIVALENCE`

`WEIGHT_DESIGN_ESTIMAND_AUTHORITY != MEASUREMENT_EQUIVALENCE`

`SEMANTIC_RELATION != RESPONDENT_COMPOSABILITY`

`I04_ADMISSION != GLOBAL_COMPOSABILITY`

`HARMONIZATION_ALIAS != COMPOSITION_OR_EQUIVALENCE_AUTHORITY`

## C07-COMP-06 — compositional relation preserves identity

A compositional operation is lawful only under the exact positive composition relation(s) and auxiliary premises actually required by the operation.

`COMPOSITION != MERGER_OF_IDENTITIES`

If sample pooling occurs, `SAMPLE_POOLING` authority is separately required. If overlap can double-count respondents, exact overlap/nonduplication and deduplication authority is separately required. If estimands are combined, exact `ESTIMAND_COMPOSITION` authority is required. If measures differ in a way requiring portability, a separately governed measurement-portability authority is required.

## C07-COMP-07 — explicit noncomparability wins

If exact applicable authority states `NONCOMPARABLE`, that state is blocking for the governed scope and must survive downstream.

`NONCOMPARABLE != MISSING`

`NONCOMPARABLE != ZERO`

`NONCOMPARABLE != DISTINCT_ONLY`

`NONCOMPARABLE != PERMISSION_TO_FIND_A_PROXY`

## C07-COMP-08 — missing authority fails closed without manufacturing a negative

If a required bridge authority is missing, unknown, conflicting, stale/out-of-scope, unavailable or denied, the comparison that depends on it may not execute as a positive comparable/composed/poolable claim.

Unless an existing authority explicitly assigns `NONCOMPARABLE`, preserve the more exact unresolved/denied state rather than inventing noncomparability.

`MISSING_BRIDGE != COMPARABLE`

`MISSING_BRIDGE != AUTOMATIC_NONCOMPARABLE`

`MISSING_BRIDGE => FAIL_CLOSED_FOR_THE_REQUESTED_COMPARISON`

## C07-COMP-09 — semantic authority succession is not recency

Different governing authority instances may support the same semantic claim only where typed lifecycle/current-selection authority says so for the exact jurisdiction and scope. Recertification/current-selection/correction/scope change remain distinct.

`LATEST != CURRENT`

`CORRECTION != SAME_SEMANTIC_CLAIM_BY_DEFAULT`

`RECERTIFICATION != GLOBAL_EQUIVALENCE`

## C07-COMP-10 — no implicit pooling or denominator repair

No comparison may obtain a common population, denominator, respondent set, wave set or source universe by:

- unioning source rows by convenience;
- using nonmissing/missing incidence as routing membership;
- treating an unknown risk set as its denominator complement;
- assuming respondent linkage from native identifiers;
- averaging or pooling across universes, waves, populations or designs because a numeric scale looks common;
- substituting a harmonization alias, provenance relation or common label for a positive operation-specific relation authority.

## Exact HQ effect if adopted

This rule closes the *decision procedure* for empirical comparability without closing missing *positive bridge loads*.

It does not create:

- a new semantic family;
- a new harmonization table;
- a measurement-portability authority owner;
- a temporal-comparability registry;
- a cross-risk-set equivalence registry;
- source-universe relation instances not already positively governed;
- architecture selection.

Positive bridge authorities remain separately loadable/recoverable under their existing or future lawful owners.
