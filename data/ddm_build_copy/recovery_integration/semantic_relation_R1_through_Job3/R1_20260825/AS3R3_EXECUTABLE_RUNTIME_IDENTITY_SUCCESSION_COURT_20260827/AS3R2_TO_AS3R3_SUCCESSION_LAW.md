# AS3R2 -> AS3R3 Runtime-Identity Succession Law

## 1. Historical preservation and executable supersession

Accepted AS3R2 refs remain immutable historical facts. Their status for future execution is `SUPERSEDED_NON_REPLAYABLE__CANONICAL_PREIMAGE_UNRECOVERED`. No successor may reuse an old ref unless its exact canonical projection is independently reproduced byte-for-byte and hash-for-hash, which the accepted recovery court did not achieve.

A new common catalog is lawful only as **semantic succession**, not identity recovery. HQ must adopt this law before any successor producer runs.

## 2. Authority required

HQ must issue an explicit versioned succession authority that:
- names accepted AS3, AS3R1, AS3R2 and failed preimage-recovery refs;
- declares the old 22 runtime refs historical/non-replayable for executable use;
- binds the exact invariant package in `SEMANTIC_TERRAIN_INVARIANTS.json`;
- authorizes one common successor construction mapping for all 19 predicates and 3 queries;
- positively fixes every identity-bearing field not already recoverable from reachable schema authority;
- forbids route/candidate-specific construction variants;
- requires complete canonical serialization and fresh-process exact replay before downstream authority resealing.

If HQ does not positively decide a behavior-capable field, sealing fails closed.

## 3. Identity-bearing law

Reachable code establishes canonical identity as SHA-256 of canonical JSON over `schema_id`, `schema_version`, `typed_state`, canonical `authority_snapshot_refs`, canonical `dependency_refs`, `producer_replay_locator_or_reference_root`, and complete normalized family `semantic_fields`.

Therefore hash targets are evidence of old identity only; they cannot supply missing preimages.

## 4. Experiment invariance

The successor producer may alter **identity closure only**. It may not alter any AS3 semantic definition, candidate descriptor, scope/partition, K/J/depth, completion/no-pruning law, RNG law, support law, I03 law, target oracle, measurement law, or route-common terrain. Any difference is `CANDIDATE_DEFINITION_CHANGE` and invalidates succession.

## 5. Resealing law

The 22 successor refs must be new unless exact canonical identity is independently proved. New catalog aggregate hashes follow mechanically. If DiscoveryAuthority/frontier/replay canonical material embeds old refs or aggregate hashes, those identities must also change. This is not experiment drift; it is `RUNTIME_IDENTITY_RESEALED` over `SEMANTIC_TERRAIN_PRESERVED`.

## 6. Non-circularity

An object may cite a producer commit/file that already exists. A producer commit must never be defined as the commit that contains the object whose hash requires that producer commit. Producer code and its SHA are frozen first; serialized inputs second; objects are minted only in a descendant commit.

## 7. Fairness

All routes A/B/C must consume the exact same successor 22-object catalog, exact same successor DiscoveryAuthority/frontier, and exact same invariant package. Symmetric identity succession preserves fairness. Any route-specific semantic or authority variation is forbidden.
