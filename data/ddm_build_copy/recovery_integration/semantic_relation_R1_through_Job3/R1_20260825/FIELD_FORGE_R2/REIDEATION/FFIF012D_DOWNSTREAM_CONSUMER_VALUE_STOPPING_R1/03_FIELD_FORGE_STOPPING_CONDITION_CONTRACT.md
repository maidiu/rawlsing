# FFIF012D — FIELD FORGE R2 STOPPING-CONDITION CONTRACT R1

Status: `ENGINEERED__REPRESENTATION_NEUTRAL__NO_ARCHITECTURE_VERDICT`

## 1. Purpose

This contract answers a narrow question:

> When has FIELD FORGE R2 learned enough about its **actor-independent downstream obligations** that terminal synthesis can be honest, without confusing “more experiments are imaginable” with “the architecture question is still materially open”?

The stop rule is explicitly **not**:

`N_CANARIES >= X`

and is not a vote across representations.

A canary count cannot prove that an unresolved relation is terminal-relevant, cannot prove that a richer object adds downstream value, and cannot distinguish an authority blocker from an empirical one.

The governing criterion is downstream starvation under lawful ablation.

`RETAINED_FIELD_FORGE_OBJECT -> NAMED_DOWNSTREAM_CAPABILITY_THAT_FAILS_IF_OBJECT_IS_REMOVED`

If no such capability exists at equal semantic authority, information, negative-state, and replay grain, the object is not justified as a FIELD FORGE primitive merely because it is useful, interpretable, visual, reusable, or sociologically suggestive.

## 2. Scope of the frontier

The stopping frontier is the set of **terminal-relevant actor-independent questions**, not the set of every interesting FIELD FORGE research question.

A frontier item is terminal-relevant only when at least one of these is true:

1. its answer changes which information/relation must cross the FIELD FORGE -> structural learned-world seam;
2. its answer changes whether a downstream PRE-V3 consumer can answer a required functional query without guessing or reaching behind an information-loss boundary;
3. its answer changes whether a proposed FIELD FORGE object survives the weakest-lawful-object ablation;
4. its answer changes preservation of minority/higher-order/discovery/transport/typed-negative/replay capability;
5. its answer changes the semantic owner boundary between FIELD FORGE and later V553+ structural producers.

Research that changes only visualization, coordinate convenience, cache form, generic sociology vocabulary, or an unrequested model interface is not terminal-relevant until tied to one of those conditions.

## 3. Allowed terminal dispositions

Every terminal-relevant frontier item must end in exactly one typed disposition before this contract can call terminal synthesis honest:

### `RESOLVED_MINIMUM_SUFFICIENT_RELATION`

A weakest lawful relation/query/object family is identified for the downstream requirement, with authority/replay ceiling explicit.

### `EMPIRICALLY_FALSIFIED_AS_REQUIRED`

A candidate object/representation was tested on a properly frozen discriminating proposition and shown not to be required for the downstream capability.

### `DEMOTED_OPTIONAL_VIEW`

The object can be removed while the named downstream battery remains answerable at equal-or-stronger authority, information, negative-state and replay grain. The object may remain useful as a cache, visualization, compression, model interface, or engineering optimization.

### `TYPED_DOWNSTREAM_ONLY`

The relation is genuinely needed, but its semantic owner is a later V553+ structural producer or other downstream authority. FIELD FORGE owes only the exact prerequisites/references required to make that later transformation possible.

### `BLOCKED_EXPLICIT_AUTHORITY`

The discriminating operation cannot lawfully be executed because a named semantic/comparison/map/role/materiality/admission authority is absent. The blocker is not converted into a method choice. Terminal synthesis may state the open slot and its no-promotion consequence.

### `BLOCKED_OBSERVABILITY_LIMIT`

The current governed world does not expose the information needed to discriminate the question. Under `NO_NEW_SOURCES`, the limit is typed rather than repaired by proxy invention.

### `DEMONSTRATED_NONDISPOSITIVE`

Different lawful realizations may remain open, but every remaining outcome leaves the downstream functional battery and semantic owner boundaries unchanged. The issue is not allowed to hold FIELD FORGE semantic synthesis hostage.

No other state counts as closure. In particular, `INTERESTING`, `PROMISING`, `MORE_CANARIES_POSSIBLE`, `BEST_SCORE`, and `COMMONLY_USED_METHOD` are not terminal dispositions.

## 4. Global readiness gates

Terminal synthesis becomes honest only when **all** gates below hold.

### SC-01 — Downstream-demand coverage

Every row in `01_DOWNSTREAM_FUNCTIONAL_QUERY_BATTERY.tsv` is either:

- supplied by a named minimum FIELD FORGE information/relation requirement;
- assigned `TYPED_DOWNSTREAM_ONLY` with an exact prerequisite handoff;
- or assigned a typed authority/observability blocker with no fabricated substitute.

No terminal demand may remain as an unnamed “later stage will somehow know.”

### SC-02 — No-starvation ablation

Every proposed retained FIELD FORGE object family must have at least one named battery query that fails when that object is removed **and** cannot be restored by a simpler lawful conditional/joint/relation/query composition at equal authority/replay grain.

If an object has no starvation witness:

`NO_STARVATION_WITNESS -> DEMOTE_OPTIONAL_VIEW_OR_REMOVE_FROM_PRIMITIVE_GRAMMAR`

This is the representation-neutral successor to the historical terminal “no-starvation proof.”

### SC-03 — Weaker-object closure

For every sophisticated object proposed as architecturally required, the court must have challenged at least:

1. direct claim-native conditional/query realization where applicable;
2. exact joint/relation realization where applicable;
3. composition of independently typed weak objects where no new primitive relation is created;
4. a lossless reusable carrier/index only where discovery/replay breadth is at issue;
5. relation-specific order/metric/topology only when the claim names that relation as constitutive.

A stronger object survives only if the weaker set loses a frozen terminal invariant or cannot lawfully expose the required query.

### SC-04 — Known-claim / unknown-claim separation

FFP033/034 close only the second canary cycle.

Before FIELD FORGE terminal synthesis, the architecture must not silently assume that a representation sufficient for a frozen known claim is sufficient for:

- unknown-claim discovery;
- recursive branch reuse;
- motif/repertoire candidate generation;
- recurrence/transport;
- future claim classes.

The discovery frontier may close by proving a weaker dynamic query-generation structure sufficient. It does **not** require a persistent motif ontology. But it may not be ignored.

### SC-05 — Minority and higher-order conservation

The selected minimum object grammar must preserve, where lawfully observable:

- complete exact same-unit higher-order predicates required by claims/discovery;
- supported minority/counterpattern states;
- XOR/equal-marginal-different-k-way possibilities;
- role/cardinality/order/multiplicity when constitutive;
- recursive branch identity and lineage;
- typed sparse/underpowered/abstention states.

Convenience pooling or coordinate compression cannot satisfy this gate by changing the question.

### SC-06 — Negative-state conservation

Observed zero, exact zero difference, valid-empty, zero-denominator abstention, out-of-scope, denial, unresolved authority, noncomparability, missing authority, and integrity failure must remain distinguishable at the relevant consumer interface.

A representation that “repairs” a typed negative into a value fails this gate.

### SC-07 — Semantic owner seam

For every retained relation, the synthesis must name its owner.

FIELD FORGE must not pre-own:

- V553 temporal meaning;
- V554 basis/equivalence/affordance decisions;
- V555 actor-independent mediation-route semantics;
- V556 governed higher-order route interaction/topology/attractor-prerequisite semantics;
- V557/V558 publication/resolution authority;
- V3 actor-indexed realization, biography, psyche, belief, orientation, relationship history, or realized attractor.

FIELD FORGE may preserve the upstream information those owners lawfully require.

### SC-08 — Replay without persistence laundering

Every retained semantic object/relation must have immutable producer identity, authority, dependency closure and replay/reconstruction law.

Physical persistence is not required if exact semantic/release identity and replay closure survive without it.

A persistent carrier may still be retained for engineering/discovery reasons, but those reasons cannot be reported as extra semantic truth.

### SC-09 — Transport without common-space compulsion

Where recurrence/transport is terminal-relevant, a lawful local-invariant + typed correspondence regime must exist or the slot must be typed `NO_TRANSPORT`/blocked.

A common coordinate space is not a prerequisite unless a separately frozen claim makes coordinates themselves constitutive.

### SC-10 — No untyped dispositive frontier

No terminal-relevant frontier item may remain simply `OPEN` when its alternative outcomes could change the minimum FIELD FORGE object grammar or semantic owner seam.

It must be resolved, falsified, demoted, downstream-typed, explicitly authority/observability-blocked, or shown nondispositive.

This gate does **not** require every interesting research question to be answered.

## 5. Empirical-execution trigger

A new empirical execution is warranted only if all of the following are true:

1. the proposition is terminal-relevant under Section 2;
2. at least two lawful candidate minimum representations/relations remain;
3. different outcomes would change a downstream battery answer, retained primitive, or owner seam;
4. exact source/input/authority/claim/support/comparison prerequisites can be frozen before target outputs;
5. existing FFP032/033/034 or current PRE-V3 interface evidence does not already decide the proposition;
6. execution uses current governed evidence only and requires no new source;
7. the experiment can be stated as a smallest discriminating proposition rather than “try another method.”

If any condition fails, do not execute merely to increase canary count.

## 6. Research stop rule for an individual object family

Research on a candidate object family stops as architecturally dispositive when one of these becomes true:

- a weaker lawful object is proven sufficient for every currently owed terminal query the candidate was meant to protect;
- the candidate adds only physical/engineering value and replay equivalence is already satisfied;
- the candidate's only extra semantics are owned downstream;
- the candidate is blocked by an explicit authority/observability limit that cannot be lawfully bypassed in FIELD FORGE;
- every possible ruling on the remaining method detail leaves the downstream battery unchanged.

The object may remain available experimentally. It no longer blocks terminal FIELD FORGE synthesis.

## 7. Terminal-synthesis readiness predicate

Define `T` as the set of terminal-relevant frontier items and `O` as the proposed retained FIELD FORGE object families.

`FIELD_FORGE_R2_TERMINAL_SYNTHESIS_READY`

iff:

1. every `t in T` has one allowed terminal disposition;
2. every `o in O` has a valid no-starvation witness;
3. every sophisticated `o` has survived the weaker-object court or is explicitly conditional on a named future claim class;
4. SC-01 through SC-10 hold;
5. unresolved blockers are named with their no-promotion consequence;
6. no conclusion depends on number of canaries, physical persistence, sociological vocabulary strength, or the historical nine-strata scaffold.

This predicate authorizes **honest synthesis**, not an architecture verdict.

A later competent synthesis may still conclude that a materially dispositive blocker prevents architecture selection. Worker D does not decide that here.

## 8. Current Worker-D readiness assessment

On evidence through FFP034:

- the second known-claim canary no longer justifies further representation proliferation for that claim;
- persistent carrier, exact-joint materialization, composed sets and direct queries differ in information/replay/interface value but not frozen AS01-AS07 truth;
- higher-order V556-style objects are not universally required: current M3 explicitly supports `ZERO_V556_OBJECTS` plus direct V555 handoff when no governed higher-order meaning is required;
- common coordinates, materialized conditional views and generic graph/geometry packages have no demonstrated universal starvation witness;
- **unknown-claim discovery/repertoire generation remains materially open** because the second canary began from a frozen known claim;
- claim-scoped recurrence/transport remains a terminal function but does not currently require common coordinates or a universal signature object;
- several strong-noun questions are interpretation/authority questions, not evidence that FIELD FORGE needs stronger empirical primitives.

Therefore:

`SECOND_CANARY_CYCLE_CLOSED != FIELD_FORGE_R2_TERMINAL_SYNTHESIS_READY`

The smallest remaining potentially dispositive empirical frontier is discovery/repertoire generation, followed conditionally by relation-specific order/metric/topology and transport minimality only where a governed downstream claim makes them constitutive.
