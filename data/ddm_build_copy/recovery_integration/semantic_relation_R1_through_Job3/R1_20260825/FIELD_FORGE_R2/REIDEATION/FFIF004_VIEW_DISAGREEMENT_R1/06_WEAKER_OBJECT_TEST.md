# FFIF004 — WEAKER-OBJECT TEST

## 1. Purpose

A stronger representation should not survive merely because it is impressive.

The court asks:

> What is the least semantically committal, least representation-specific empirical object that is sufficient to answer the frozen claim while preserving every required invariant within the declared loss/uncertainty budget?

This is a sufficiency test, not an elegance contest.

## 2. Weaker does not mean smaller

`WEAKER` means requiring fewer substantive/representational commitments, not necessarily fewer bytes or less compute.

A large exact conditional table may be weaker than a tiny latent model if the model imports a mixture ontology. A source-topology hypergraph may be weaker than a smooth embedding if the embedding introduces a metric. A direct rank relation may be weaker than an axis score.

Therefore:

`COMPRESSION != EPISTEMIC WEAKNESS`.

## 3. Claim-required invariant bundle

For claim `C`, freeze:

`R(C) = {r1, r2, ... rn}`

where each `ri` is a normalized empirical assertion slot/invariant with:

- required fidelity/tolerance;
- support/uncertainty rule;
- semantic authority refs;
- downstream query need;
- whether exact existence or generalization is required.

Only invariants in `R(C)` can justify architectural necessity.

## 4. Candidate object universe

Before outcome-based selection, declare a finite candidate universe `U` such as:

- direct observation-event subset;
- exact configuration/set object;
- direct conditional distribution/contrast;
- order/rank object;
- local incidence/topology object;
- local neighborhood/order relation;
- bounded motif/signature object;
- model-derived compression object;
- explicitly declared combinations of the above.

The universe need not contain every imaginable future method. It must be sufficient for the bounded engineering decision and recorded honestly.

## 5. Sufficiency predicate

Candidate object `W` is `CLAIM_SUFFICIENT` iff all hold:

1. `W` is lawfully constructible from the common input and authorized transforms;
2. `W` can deterministically answer every required assertion slot in `R(C)` or produce an authorized uncertainty object for it;
3. each answer meets the claim's fidelity/loss/support tolerance;
4. answering does not require consulting a stronger excluded representation at query time;
5. `W` does not import semantic equivalence, metric, class, adjacency, transport, or conditioning assumptions stronger than the claim authorizes;
6. replay from common input is exact or tolerance-governed.

## 6. Dominance rule

If `W1` and `W2` are both claim-sufficient and `W1` requires a strict subset of the substantive/representational commitments of `W2`, then:

`W1 CLAIM-DOMINATES W2`.

The stronger object may retain optional utility but cannot be declared necessary for claim `C`.

No scalar quality score is used.

## 7. Minimal sufficient set

Sometimes no single object is claim-sufficient.

Find the smallest **nonredundant set** of lawful objects whose union of preserved invariants covers `R(C)`.

A set `M` is minimal iff:

- together its members answer all required slots;
- removing any member causes at least one required slot to fail;
- no single weaker object in `U` answers all slots;
- no lawful transform of one retained member makes another redundant.

Possible outcomes:

- `SINGLE_WEAKER_OBJECT_SUFFICIENT`;
- `SINGLE_STRONGER_VIEW_REQUIRED`;
- `MULTI_VIEW_MINIMAL_SET_REQUIRED`;
- `NO_ADMITTED_OBJECT_SET_SUFFICIENT`;
- `UNRESOLVED__OBJECT_UNIVERSE_OR_TOLERANCE`.

## 8. Economy is secondary

Once several objects are equally claim-sufficient, compression, compute, storage, maintainability, and downstream query cost may select an implementation.

Those utility criteria do **not** rewrite empirical sufficiency.

A geometry that is four times smaller than an exact object has compression value. It does not thereby become truer.

An atlas that is lossless but unusable may fail an engineering consumer requirement. Its exact facts do not become false.

## 9. Examples

### Exact conditional distribution beats geometry

If claim C asks only for `P(D|C)` under a frozen risk set and direct conditional tables meet support/tolerance requirements, geometry is not necessary merely because it supplies a visually elegant gradient.

### Rank relation beats full geometry

If the downstream claim requires only a stable local ordering, a stored neighborhood/rank relation may preserve the required invariant without retaining coordinates or axis orientation.

### Topology defeats pooled geometry

If the claim requires only whether measurement components are connected, a source-faithful incidence/hypergraph object is sufficient; pooled geometry is stronger and may be invalid if it bridges disconnected components.

### Multi-view set survives

If the claim jointly requires exact minority configuration existence and stable economical neighborhood interpolation, and no direct conditional/rank/topology/signature object preserves both within tolerance, the minimal sufficient set may contain an exact configuration view plus a local geometric relation view.

That supports `MULTI_VIEW_RETENTION_REQUIRED`. It supports bounded nonreducibility only after the additional proof burden in `05` passes.

## 10. Replay receipt

Every weaker-object decision records:

- claim/invariant bundle hash;
- candidate universe version;
- object refs/specifications;
- sufficiency matrix;
- failed slots per candidate;
- commitment comparison rationale;
- transform tests;
- selected minimal sufficient object/set;
- unresolved semantic judgments;
- provenance and supersession.
