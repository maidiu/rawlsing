# FFIF002 — SOURCE-FORM HOSTILE CASES R1

## Evidence boundary

This court is semantic/source-form only. It does not claim current respondent association. Where current inspected Rawlsing authority establishes a measurement property, that property is used; where exact source-variable IDs were not established by this court, no IDs are invented.

## A. Arab Barometer income-form distinction

Inherited FFX002 design capital explicitly preserves the distinction among literal income, ordinal income-situation, and food-insufficiency forms and warns that they are not interchangeable merely because each bears on material position.

Hostile test:
- converting literal amount to ordinal situation is not a rename;
- treating both as one canonical `income` state silently substitutes a construct relation for measurement identity;
- percentile/z-score normalization can make values look commensurable without authorizing what invariant is being compared.

Required disposition:
- preserve each source-native measurement identity;
- authorize any cross-measure grouping only through a claim-scoped receipt;
- freeze the chosen comparison proposition before FFX002 forks.

## B. Afrobarometer / Arab Barometer ordinal scales

Current Rawlsing authority includes certified response-scale encoding whose intended use is ordinal coordinate rather than unqualified metric cardinality.

Hostile test:
A source stores ordered response states as `1,2,3,4`. A Euclidean method reads those numbers as distances of exactly one unit.

Failure:
Storage numerics have silently minted equal intervals. Numeric type is not authority for cardinal distance.

Required disposition:
- source/codebook order may authorize `ORDER_DECLARATION`;
- cardinal spacing requires separate measurement authority;
- absent that authority, metric geometry may not pretend the raw codes are interval values.

## C. Religion / sect / ethnicity / caste / race

These families are structurally hostile to global canonicalization because category systems are constituted by local histories, state classification, sectarian formations, colonial administration, self-identification regimes, and survey instrument design.

Hostile test:
Strings that translate similarly across contexts are mapped to a universal category because their labels resemble one another.

Failure:
Lexical resemblance has become project semantic identity. Local distinctions and category absences are erased.

Required disposition:
- preserve source-native category systems;
- permit explicit project crosswalk only where evidence warrants the correspondence;
- use claim-scoped or transport equivalence where the invariant is narrower than semantic identity;
- preserve `NONCOMPARABLE` as a lawful result.

## D. Education

Credentials, tracks, schooling levels, vocational formations, and completion categories do not share a natural universal metric.

Hostile test:
Convert every education system to estimated years because a method requires one continuous input.

Failure:
The conversion invents equivalence among institutionally different credentials and makes a locally contingent time metric stand in for credential structure.

Required disposition:
- source-native levels remain recoverable;
- local order may be separately authorized;
- cross-context credential order or years mapping requires an explicit project/claim/transport proposition;
- `credential hierarchy` authority does not imply `field-specific cultural capital` equivalence.

## E. Occupation / employment across waves

Historical design work has repeatedly encountered proxy differences across waves. Broad labor-force status, occupation, employment security, and work conditions can overlap without being measurement-identical.

Hostile test:
A broad employed/not-employed recode becomes the canonical employment variable and is later reused for labor insecurity.

Failure:
A claim-local partition becomes a project-semantic object.

Required disposition:
- preserve each source-native measurement;
- bind broad employment collapse to the exact claim that tolerates the lost distinctions;
- require fresh adjudication for insecurity, prestige, formality, stability, or occupational structure.

Required disposition:

## G. Continuous / count / duration variables

Literal income provides the clearest continuous stressor; age, duration, frequency, and count forms raise analogous issues.

### Binning
Many-to-one and lossy. Lawful only with thresholds, boundary convention, source ancestry, claim scope, and explicit loss.

### Rank transform
Preserves order within a named reference universe but discards metric distance. Reference universe is part of the semantic proposition.

### Standardization
Changes scale relative to a mean/variance or other reference. Cross-context standardization cannot establish comparability; comparability must already be authorized.

### Top-coding
If source-native, loss is inherited. If project-created, exact original source value must remain addressable and the top-code rule must be receipted.

## Twelve mandated hostile attacks

### 1. `NUMERIC_CODE_CARDINALITY`
**Attack:** numeric labels become Euclidean distances.
**Ruling:** REJECT. Type/schema can reveal numeric storage, not interval measurement.

### 2. `ORDINAL_COLLAPSE_CONVENIENCE`
**Attack:** five-point attitude scale becomes agree/disagree because the model prefers binary inputs.
**Ruling:** claim-scoped category collapse required; model preference has zero semantic authority.

### 3. `CROSS_CONTEXT_LABEL_COLLAPSE`
**Attack:** translated religion/ethnicity/class strings are treated as same.
**Ruling:** REJECT absent explicit project/claim/transport authority.

### 4. `MISSING_STATE_COLLAPSE`
**Attack:** DK/refused/routed/unobserved -> one NA.
**Ruling:** REJECT as common semantic input; downstream exclusions require typed receipt and retained state ancestry.

### 5. `SOURCE_HARMONIZATION_LAUNDERING`
**Attack:** source harmonized code is assumed equivalent for every claim.
**Ruling:** REJECT. Source harmonization carries source-defined scope and inherited loss, not universal license.

### 6. `EDUCATION_AS_YEARS`
**Attack:** credentials become common years automatically.
**Ruling:** REJECT unless the years conversion and transport invariant are explicitly authorized for the bounded claim.

### 7. `INCOME_NORMALIZATION`
**Attack:** percentile or z-score is treated as proof that contexts are commensurable.
**Ruling:** REJECT. Transformation can implement an authorized comparison frame; it cannot create one.

### 8. `RARE_CATEGORY_MERGE`
**Attack:** rare source state -> Other for geometric stability.
**Ruling:** method need does not authorize semantic collapse. If a bounded claim permits it, freeze the shared receipt before the duel; otherwise retain the state, use supplementary handling, or declare method inadmissibility.

### 9. `REPRESENTATION_SPECIFIC_RECODING_LEAK`
**Attack:** MCA recoding reused in atlas/conditional/motif views.
**Ruling:** REJECT unless the recode was independently authorized as common claim semantics. Representation receipts do not travel sideways by convenience.

### 10. `TEMPORAL_SAME_LABEL_TRAP`
**Attack:** same label across waves means stable semantics.
**Ruling:** REJECT. Same label is evidence to inspect, not authority. Wording, response options, routing, context, and instrument changes remain relevant.

### 11. `GLOBAL_CANONICAL_CATEGORY_TRAP`
**Attack:** universal religion/class/occupation/ethnicity vocabulary becomes master ontology.
**Ruling:** REJECT. Crosswalks must be finite and scoped; local source categories remain replayable.

### 12. `NO_HARMONIZATION_DOGMA`
**Attack:** all cross-context equivalence is refused because local categories differ.
**Ruling:** ALSO REJECT. Comparison is lawful where a source/project/claim/transport authority explicitly supports the invariant and preserves the information loss/provenance. Refusing every transform would make Rawlsing incapable of justified comparison.

## Most dangerous operation

`UNSCOPED_MANY_TO_ONE_PROJECT_CROSSWALK`

This is more dangerous than an obviously exotic method because it looks like ordinary cleaning. It can erase local distinctions, sever ancestry, become de facto project identity, and then feed every representation as if the ontology were given by the source.

The specific danger is not many-to-one transformation itself. It is **many-to-one transformation before claim binding, with project-wide reuse and weak/no ancestry**.
