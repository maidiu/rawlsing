## Central answer

The smallest lawful object is not a universal equivalence node, canonical category layer, or generic preprocessing record.

The minimum surviving object is a **TYPED TRANSFORMATION AUTHORITY RECEIPT (`TTAR`)** attached to exact source-native ancestors.

A TTAR must minimally bind:

- authority class;
- claim scope where the proposition is analytic/transport rather than source/project semantic fact;
- source scope;
- exact input state refs;
- transformation type;
- output state specification;
- semantic assertion;
- allowed and forbidden uses;
- information-loss profile;
- authority/evidence refs;
- exact source-native ancestry;
- replay specification;
- validity/invalidation conditions;
- supersession.

The architecture is sufficient only with separate typed relation families for physical identity, source-native semantic identity, project semantic identity, analytic equivalence, order/partition authority, representational equivalence, and transport equivalence. `PERSON_ACTOR_IDENTITY` remains outside this court.

The decisive law is:

`SAME != ALLOWED_TO_TREAT_AS_SAME`

Analytic equivalence is permission for a bounded proposition. It does not become global identity, does not acquire automatic transitive closure, and does not travel into unrelated representations or claims.

## Reversibility ruling

Literal mathematical invertibility is **not** required.

The minimum conservation contract is:

`SOURCE_NATIVE RECOVERABILITY + EXPLICIT LOSS + REPLAYABLE TRANSFORM`

The court distinguishes:

- `VALUE_INVERTIBLE`
- `ANCESTRY_REVERSIBLE`
- `SOURCE_LOSS_INHERITED`
- `UNRECOVERABLE_PROJECT_LOSS`
- `NOT_APPLICABLE_NO_TRANSFORM`

Many-to-one category collapse and continuous binning may therefore be lawful while non-invertible, provided the exact source-native observations/states remain addressable, the transform is replayable, and loss is explicit. Source top-coding/harmonization is inherited loss; Rawlsing must not claim to recover distinctions never supplied by the source. Project-created loss that severs ancestry is unlawful.
