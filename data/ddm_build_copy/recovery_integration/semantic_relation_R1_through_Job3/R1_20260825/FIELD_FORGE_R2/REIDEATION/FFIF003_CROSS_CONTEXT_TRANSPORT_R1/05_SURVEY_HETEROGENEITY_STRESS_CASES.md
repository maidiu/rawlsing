# FFIF003 — SURVEY HETEROGENEITY STRESS CASES

## 1. Evidence discipline

The nine fixed FIELD FORGE survey families are treated here as **stressors, not a harmonization table**:

- GSS;
- EVS;
- WVS;
- Asian Barometer;
- Arab Barometer;
- Afrobarometer;
- Latinobarómetro;
- South Asia;
- LiTS.

This court does not invent a family-wide category crosswalk. Source-specific claims below are limited to heterogeneity already attested in FFIF001/current FIELD FORGE design capital; the remaining families supply bounded contract obligations rather than fabricated codebook details.

No respondent associations are computed.

## 2. Source-specific stress evidence inherited from FFIF001

### Arab Barometer VIII Q629 — set topology is not repeated-item topology

FFIF001 records Q629 as a `MULTIPLE_RESPONSE_SET`: one parent respondent-facing prompt, coded selectable members, shared gated routing, `SELECT ALL THAT APPLY`, and an exclusivity rule for answer 1.

Transport consequence:

- a member code cannot be treated as an independently observed coordinate merely because another family has standalone items with similar prose labels;
- set-member adjacency is instrument topology, not social topology;
- a cross-context graph that maps Q629 members to repeated-item nodes must first prove the node-role correspondence or return `NO_TRANSPORT`.

### Afrobarometer R5 Q86A–Q86F — genuine repeated block, current respondent binding not established

FFIF001 records Q86A–Q86F as a `MATRIX_GRID` / repeated-item block with current qimpl/routing authority and a shared country exclusion. FFX001-B/C did not establish a canonically reachable current respondent binding.

Transport consequence:

- repeated-grid block membership is a lawful instrument-topology stress object;
- it cannot be used here to assert respondent-level coresponse structure;
- cross-context motif transport over Q86-style blocks must remain hypothetical/design-only until respondent execution authority exists.

This is an important negative case: the architecture must distinguish **transportable source topology** from **unavailable respondent structural recurrence**.

### Arab Barometer VIII Q872–Q884 — conditional connectivity

Historical stress material contains split/randomized/conditional sequences. Therefore instrument connectivity and risk sets can be form/module/condition specific.

Transport consequence: a universal graph edge saying two items “belong to the same battery” can be false at respondent exposure grain. Local routing topology must survive underneath any cross-context block signature.

### Asian Barometer — source-specific batteries and role drift

FFIF001 records historical Asian Barometer design capital with a dense harmony/family-state hierarchy battery not mirrored in South Asia. It also records a historical employment-slot problem: an occupation proxy in one wave versus cleaner employment-status variables later.

Transport consequence:

- a canonical slot name such as `EMPLOYMENT` does not establish measurement or position-role equivalence;
- absence of a mirrored battery is not missing data to be imputed into a common latent space;
- local motif/signature transport may operate only over the actually corresponding substructure.

### Arab Barometer income semantics — numeric temptation

FFIF001 records materially different income candidates, including literal income and ordinal income-situation measures.

Transport consequence: the existence of a generic `ECONOMIC_POSITION` role cannot authorize one pooled numeric coordinate. Order/rank transport may sometimes survive where local semantics support it; cardinal transport does not follow.

## 3. Nine-family stress matrix by heterogeneity class

The following rows are architectural obligations to be checked against source-specific authority before any future execution. They are not claims that every family instantiates every row.

| heterogeneity class | transport danger | lawful response |
|---|---|---|
| sect / religion detail exists only in some contexts | canonical `RELIGION` slot invents equivalence | exact semantic transport only where supported; otherwise typed local role or no transport |
| caste / ethnicity / race category systems differ structurally | universal demographic vocabulary erases polity-specific topology | preserve source-native categories; allow only claim-scoped partial role maps with explicit forbidden inference |
| education represented with different credentials/years/levels | pooled cardinal scale manufactures interval equivalence | local order or rank transport only if ordering and denominators are authorized |
| household vs respondent economic variables | same prose label hides empirical-unit-role change | position-role mismatch is a hard blocker to exact transport |
| subjective class present in only some sources | global latent class imputes an unmeasured construct elsewhere | no transport for the absent construct; compare other invariants only |
| disposition batteries differ in item count/composition | common factor/mean gives larger blocks extra ontology | freeze local battery; test signature/motif components and block-composition nulls |
| repeated grid vs standalone items/set members | column shape is mistaken for measurement identity | preserve source-native measurement topology and member roles |
| country/module/split routing differs | source presence is mistaken for exposure | retain local eligibility/exposure/risk-set law; route mismatch can force no transport |
| institutional-trust batteries differ | shared label `TRUST` hides target/institution differences | componentwise semantic correspondence; no universal trust factor by default |
| moral/political attitude batteries differ | theoretical domain label substitutes for item authority | motif/conditional-shape transport only after exact local item-role adjudication |

## 4. Family-specific stress obligations without invented facts

### GSS and EVS
Future transport claims must demonstrate exact question/block ancestry, local response-state semantics, and local target estimands rather than infer equivalence from broad domains such as trust, morality, education, or class.

### WVS and EVS
Shared or related questionnaire traditions, where they exist, would raise an especially dangerous shortcut: **shared measurement ancestry is evidence about ancestry, not homology and not automatic portability**. Exact semantic transport can be stronger here than between unrelated families, but empirical estimand comparability still requires separate authority.

### Latinobarómetro, South Asia, and LiTS
The architecture must not fill absent/different local role systems merely to complete a global demographic or attitude schema. If only an abstract order, rank, or motif is supportable, the transport object must expose that narrower ceiling.

### Asian, Arab, and Afrobarometer
The source-specific examples above show why column naming, battery membership, and canonical slots are insufficient. They also show that heterogeneity occurs **within** a family across questions, waves, forms, modules, and routing — not only between survey brands.

## 5. Hard stress conclusions

1. `SAME COLUMN SHAPE != SAME MEASUREMENT TOPOLOGY`.
2. `SAME DOMAIN LABEL != SAME POSITION/DISPOSITION ROLE`.
3. `SHARED ANCESTRY != PORTABILITY != HOMOLOGY`.
4. `SOURCE PRESENCE != ELIGIBILITY != EXPOSURE != RESPONSE` remains binding.
5. Absence of a local construct is not a license for common-space imputation.
6. A transport contract must be allowed to shrink to a partial correspondence or terminate at `NO_TRANSPORT`.

The nine-family corpus therefore argues for a **mixed, local-first transport regime**, not for one universal harmonization vocabulary and not for unconstrained local storytelling.
