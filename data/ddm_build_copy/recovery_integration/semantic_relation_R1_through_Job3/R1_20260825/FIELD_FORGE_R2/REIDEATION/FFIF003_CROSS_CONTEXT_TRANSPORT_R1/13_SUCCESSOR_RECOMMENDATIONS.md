# FFIF003 — SUCCESSOR RECOMMENDATIONS

## 1. Do not build a universal crosswalk next

The court's ruling is architectural, not an invitation to harmonize all nine families. The next work should attack the degrees of freedom inside the transport bridge before any respondent-level cross-context execution.

## 2. P0 — Mapping authority / discretion court

Mission:

Define how a candidate correspondence becomes admissible when literal semantic identity is absent.

Must resolve:

- permissible authority sources;
- outcome-blind registration;
- partial and many-to-one maps;
- asymmetric maps/inversion;
- theoretical-role input without circularity;
- candidate mapping-space enumeration;
- source-native replay;
- supersession/versioning.

Required terminal failure state: `NO_AUTHORIZED_MAP`.

This is the single most important successor. Without it, all later transport machinery can formalize arbitrary analogy.

## 3. P0 — Signature identifiability / map-multiplicity court

Mission:

Determine when a finite invariant signature is discriminative enough to mean anything cross-contextually.

Must test:

- proportion/structure of admissible maps that satisfy the signature;
- component ablation;
- generic motif prevalence;
- signature complexity versus mapping flexibility;
- holdout-context performance;
- representation perturbation.

A signature should fail when it is “deep” only because it is generic.

## 4. P0 — Estimand and risk-set compatibility court

Mission:

Define exact compatibility classes for cross-context structural claims without collapsing local target populations.

Must separate:

- measurement universe;
- eligibility;
- exposure;
- response;
- sample frame/design;
- weighting target;
- conditional support;
- estimand.

This court must not infer exposure from missingness and must inherit FFX001 observability limits.

## 5. P1 — Transport null calibration

Design executable nulls only after a lawful respondent carrier/exposure surface exists. Calibrate semantic-map permutations, type-constrained alternative maps, unrelated-block controls, block-composition perturbations, and representation perturbations so they are neither absurdly weak nor semantically impossible.

No respondent execution should be performed merely to make FFIF003 look empirically complete.

## 6. P1 — Multi-representation transport disagreement

Extend FFIF001's nonreducible-disagreement problem specifically to transport:

- exact configuration says recurrence;
- geometry says no recurrence;
- topology says partial recurrence;
- direct conditionals show reversal.

The output must be a typed disagreement object, not a winner chosen by method prestige, compression, or majority vote.

## 7. P1 — No-transport certificate

Make `NO_TRANSPORT` operational and supersedable. Distinguish:

- semantic-authority failure;
- map non-identifiability;
- local support failure;
- risk-set/estimand incompatibility;
- representation instability;
- null failure;
- absent local object.

This protects Rawlsing from filling every gap with analogy.

## 8. P1 — Instrument topology versus social recurrence

Use the FFIF001 source-form cases — especially multi-response set versus repeated grid and conditional/split connectivity — to define when recurring questionnaire architecture may and may not enter a social-structural signature.

A shared survey tradition can produce recurring instrument motifs that must not be reported as social homology.

## 9. Separate P0 — Temporal transport court

The local-first architecture may be reusable across waves:

- independently freeze each wave/local object;
- retain source-native identity;
- state a claim-scoped correspondence;
- preserve explicit invariant;
- test alternative maps and perturbations.

But time introduces questions FFIF003 does not solve:

- instrument revision and semantic drift;
- changing routing/exposure;
- cohort replacement;
- repeated cross-section versus panel identity;
- historical transformation of category meaning;
- longitudinal estimands;
- temporal dependence.

Therefore do **not** reuse a cross-context transport success as longitudinal equivalence. Temporal comparability requires a separate court.

## 10. Homology remains downstream

No successor transport court should use `HOMOLOGY` as a transport status. The lawful stack is:

`LOCAL OBJECTS -> TYPED CORRESPONDENCE -> INVARIANT TRANSPORT -> FALSIFICATION -> BOUNDED RECURRENCE CLAIM`

Only after that may a theory-facing court ask whether a broader historical/field interpretation is justified.

## 11. Execution gate

Before any empirical cross-context respondent execution, require all of:

1. lawful current respondent carrier and identity binding;
2. exact exposure/risk-set authority with executable predicate provenance;
3. local measurement and role authority;
4. frozen local estimands/weight purposes;
5. mapping-authority contract;
6. signature/null preregistration;
7. local-first freeze receipts;
8. explicit claim ceiling.

If any gate is absent, the correct next action is further authority/design work, not weakened execution.

## 12. Terminal recommendation

Proceed toward **transport-governance closure before transport execution**. Preserve a mixed regime where exact semantic, order, rank, topology, conditional-shape, motif, signature, and no-transport outcomes coexist. Never collapse them into one global “comparability” bit.
