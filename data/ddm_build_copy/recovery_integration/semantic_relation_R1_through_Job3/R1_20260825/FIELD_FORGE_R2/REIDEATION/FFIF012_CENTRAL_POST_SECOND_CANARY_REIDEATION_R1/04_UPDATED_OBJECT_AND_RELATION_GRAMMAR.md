# FFIF012 — UPDATED OBJECT AND RELATION GRAMMAR R1

Status: `EXPLORATORY_DESIGN_HYPOTHESIS__NOT_CURRENT_PROJECT_AUTHORITY`

## 1. Governing principle

FIELD FORGE no longer treats a representation family as a candidate ontology merely because it is information-rich, persistent, mathematically elegant, or useful downstream.

The current weakest grammar is organized by semantic commitment and function.

## 2. Layer 0 — producer-owned governed empirical world

Not owned by FIELD FORGE:

- empirical unit and context;
- measurement/source-native state identity;
- source structure and routing/applicability;
- actual respondent exposure where admitted;
- sample/design/weight-purpose authority;
- source-universe/comparability authority;
- exact observations and producer provenance.

FIELD FORGE must consume these by immutable producer reference.

## 3. Layer 1 — exact information availability / recoverability

Candidate abstraction:

`EXACT_SAME_UNIT_INFORMATION_CAPABILITY`.

It means only that the exact empirical states/memberships required by a declared relation can be recovered/replayed at the relevant lawful empirical-unit/risk-set grain.

It is not automatically one persisted respondent table.

Lawful physical realizations may include, depending on query:

- direct base facts;
- respondent-state rows;
- exact profile dictionary + respondent membership;
- exact profile-count dictionary where respondent identity is not required;
- other lossless reversible encodings.

`INFORMATION_EQUIVALENT_ENCODING != DISTINCT_SEMANTIC_OBJECT`.

## 4. Layer 2 — typed empirical relations

A new semantic object appears when Rawlsing commits to a relation not supplied merely by possessing the atomic information.

Candidate relation families include:

- exact event/subset/existence/count relation;
- exact same-unit conjunction/joint-state relation;
- exact conditional redistribution/dependence relation;
- source-authorized order relation;
- source/unit-authorized cardinal magnitude/distance relation;
- explicit incidence/adjacency/connectivity/topology relation;
- explicit opposition/implication relation;
- recurrence/transport correspondence relation;
- separately admitted motif/signature equivalence relation.

Every relation carries its own authority dependencies, scope, estimand/risk set, negative states, replay law and inferential ceiling.

## 5. Layer 3 — query and discovery operators

Query/discovery operators expose or enumerate typed relations.

Examples:

- claim-native direct conditional query;
- exact conjunction generator;
- outcome-blind full profile/subset support enumeration;
- branch/minority/counterpattern enumerator;
- order/neighborhood query;
- topology/reachability query;
- transport comparator.

Ephemerality does not erase relation commitment.

A query operator need not become a persistent world object.

## 6. Layer 4 — reusable indexes / materializations

Persistent objects may be justified for:

- replay;
- latency;
- unknown-query reuse;
- complete bounded candidate enumeration;
- respondent linkage for follow-up;
- recursive reuse;
- immutable evidence banking.

Persistence does not add semantic truth by itself.

Current bounded results:

- a 1,856-row exact profile-count dictionary reproduces 62,609 bounded unconditioned conjunction-support rows exactly;
- respondent membership is not required for those support queries;
- respondent membership may become necessary when a discovered pattern must be joined to external respondent-level information.

Therefore persistence/materialization identity is engineering/replay identity unless it changes one of:

- semantic relation commitment;
- exact recoverability/loss;
- admissible query interface;
- scope/empirical-unit grain;
- authority dependency.

## 7. Layer 5 — optional lossy/model interfaces

Default optional unless a claim explicitly makes them constitutive:

- coordinates/embeddings;
- low-dimensional compression;
- latent classes/profiles;
- model scores;
- visualization layouts;
- caches that preserve a stronger exact parent relation.

They require explicit loss/representation contracts and may not overwrite exact negative/minority/higher-order facts.

## 8. Layer 6 — structural semantic admission

Neutral empirical relations are not automatically structural nouns.

A structural admission packet may consume exact typed empirical relations and precursor profiles but requires a competent separate admission authority.

Strong nouns include, among others:

- field / formation;
- field-specific capital;
- conversion;
- hegemony/subhegemony;
- homology;
- pressure footprint;
- pressure pathway/mechanism.

The default lawful output remains the weaker neutral precursor when the stronger noun has no independent admission warrant.

## 9. Relation-strength escalation law

For a candidate claim, challenge in increasing commitment:

```text
EXACT NATIVE IDENTITY / EVENT
  -> EXACT JOINT / CONDITIONAL
  -> SOURCE-AUTHORIZED ORDER
  -> CARDINAL MAGNITUDE / METRIC
  -> TOPOLOGY / PATH RELATION
  -> MODEL / COORDINATE REPRESENTATION
```

Skip levels that are irrelevant to the claim.

A stronger level survives only if a named constitutive invariant is lost by every weaker lawful challenger.

This is not a universal hierarchy of social reality. It is a commitment-lowering court.

## 10. Discovery law

Known-claim sufficiency and unknown-claim discovery remain distinct functions.

Current bounded discovery floor:

`EPHEMERAL_DYNAMIC_EXACT_ENUMERATOR`.

Current weakest demonstrated persistent support-discovery object on the tested finite surface:

`FULL_EXACT_PROFILE_COUNT_DICTIONARY`.

Open core question:

`DISCOVERY_TO_FOLLOWUP_LINKAGE` — whether respondent membership must be retained or exactly recoverable when a discovered profile/conjunction is later conditioned/joined on a respondent-level variable outside the original discovery surface.

No generic motif ontology is required merely to enumerate candidates.

## 11. Transport law

Current minimum architecture for recurrence:

```text
INDEPENDENT_LOCAL_OBJECT A
+ INDEPENDENT_LOCAL_OBJECT B
+ OUTCOME-BLIND AUTHORIZED MAP / TRANSPORT CONTRACT
+ FROZEN PRESERVATION PREDICATE
-> RECURRENCE / REVERSAL / PARTIAL_RECURRENCE / NO_TRANSPORT / ABSTAIN
```

No common coordinates or universal materialized signature object are required by default.

## 12. Negative-state law

The grammar must preserve distinct states such as:

- observed zero;
- exact zero difference;
- valid empty;
- zero-denominator abstention;
- unsupported/inferentially unresolved;
- out-of-scope;
- denied/prohibited;
- noncomparable / no transport;
- missing semantic authority;
- observability limit;
- integrity/replay failure.

No representation may convert one of these into a numeric value merely to make downstream computation easier.
