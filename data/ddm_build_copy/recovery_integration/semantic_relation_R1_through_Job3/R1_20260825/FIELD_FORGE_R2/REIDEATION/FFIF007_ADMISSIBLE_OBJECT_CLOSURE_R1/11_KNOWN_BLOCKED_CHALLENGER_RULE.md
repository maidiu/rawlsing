# FFIF007 — KNOWN-BLOCKED-CHALLENGER RULE

## 1. Central anti-starvation law

`RAWLSING MAY NOT PROVE MULTI-OBJECT NECESSITY BY WITHHOLDING OR FAILING TO COMPLETE A DEPENDENCY THAT A KNOWN CLAIM-RELEVANT CHALLENGER LAWFULLY REQUIRES.`

## 2. Three categories

### A. `KNOWN_ADMISSIBLE_BUT_UNEXECUTED`

The AOS is currently authority-valid and fairly evaluable on the frozen substrate, but implementation or execution is absent.

Result: closure blocks unless the candidate is duplicate or strictly dominated ex ante. Code absence is not empirical exclusion.

### B. `KNOWN_POTENTIAL_CHALLENGER_WITH_MISSING_OWED_DEPENDENCY`

The candidate is claim-relevant and could be fairly evaluated on the same frozen substrate if a current recognized authority/substrate/execution obligation were resolved. Examples include an absent current binding or authority that project governance already requires independently of the desired closure result.

Result:

`CLOSURE_ABSTAIN__KNOWN_BLOCKED_CHALLENGER`.

The court records the blocker, owner, obligation ref, counterfactual AOS, and why its admission could change single-object sufficiency.

### C. `KNOWN_CONCEPTUAL_BUT_NOT_CURRENTLY_ADMISSIBLE`

The idea would require new evidence, a different empirical substrate, a new unowed semantic proposition, a different CIM, or authority that current Rawlsing neither possesses nor independently owes.

Result: exclude from U with explicit limitation. It does not block finite closure and has not been empirically defeated.

## 3. Owed-dependency test

A missing dependency is `OWED` for this rule when all apply:

1. the dependency is already required or recognized by current project authority, accepted design, or the frozen claim's own prerequisites;
2. resolving it would not change the empirical proposition, CITC, or source evidence merely to help the challenger;
3. the challenger has a specifiable claim interface and could plausibly satisfy a constitutive slot or full bundle;
4. the gap is not an unknown future scientific advance;
5. exclusion would create an asymmetric burden relative to favored objects.

If owed status is unresolved, closure abstains rather than defaulting to exclusion.

## 4. Missing semantic authority

Not every missing TTAR/PRA blocks closure. If the candidate's very meaning requires a new substantive proposition not present in the CIM and not independently authorized/owed, it is not currently admissible. But if the same role/transform authority is a prerequisite of the claim or is already owed to all arms, selective noncompletion blocks closure.

## 5. Missing respondent or exposure substrate

For respondent-bearing claims, absence of lawful respondent/exposure authority blocks the whole empirical comparison, not merely one challenger. For a candidate requiring an additional carrier derivable from the same already-governed respondent events, ordinary implementation absence cannot be called empirical unexecutability.

## 6. Fair evaluability

A candidate is fairly evaluable when it can receive:

- the same common semantic input and claim contract;
- its own lawful method freedom;
- comparable support/uncertainty treatment;
- appropriate view-specific hostile tests;
- no requirement to reproduce an invariant outside its admitted interface.

Failure to build a fair evaluator is a closure blocker, not candidate failure.

## 7. Lifecycle

When an owed blocker resolves:

- create new U and COCR versions;
- include or lawfully dispose the candidate;
- rerun affected sufficiency/minimal-set comparisons on uninspected evidence where required;
- preserve the old abstention receipt.

The old court never becomes a positive result by administrative edit.
