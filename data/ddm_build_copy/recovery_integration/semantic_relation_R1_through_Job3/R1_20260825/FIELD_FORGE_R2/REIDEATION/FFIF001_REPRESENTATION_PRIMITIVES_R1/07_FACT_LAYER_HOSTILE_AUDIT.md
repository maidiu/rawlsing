# FFIF001 — FACT-LAYER HOSTILE AUDIT

## Holding

A `GOVERNED EMPIRICAL FACT SUBSTRATE` is supported only if “fact” is narrowed to source-faithful observation/provenance identity. A substrate containing configurations, dependence, geometry, graph adjacency, latent membership, or motifs as primitives is rejected as falsely method-independent.

## 1. What makes a fact method-independent?

Not philosophical innocence. Operationally:

A floor object is admissible here only if every tested representation can be regenerated from it (given its own authority/method manifest) and if the floor does not require choosing among those representations to exist.

This criterion selects observation events and measurement/source topology, not derived structural facts.

## 2. Conditional dependence is model/claim dependent

Even direct empirical conditionals require a selected conditioning set, exact risk set, reference/baseline, support law, and estimand. Model-based conditional independence adds further assumptions.

Therefore conditional dependence cannot live in the primitive layer.

## 3. Higher-order J is already a view

J is high-authority empirical structure, but it chooses a member set and order. The substrate should preserve the unit/exposure/response events from which lawful J can be replayed.

This prevents J authority from being confused with a declaration that J is the universal form of social relation.

## 4. Observed configurations privilege discreteness

If only observed configurations are stored, continuous/ordinal source values must first be discretized or treated as exact values. Exact floating-value configurations are usually unusable; bins import thresholds. Therefore native values must survive below configuration production.

## 5. “Retain every fact” can still be unusable

A raw event store is not a downstream interface. It is a replay floor.

Rawlsing needs typed indexes/views because repeatedly scanning every observation for every query is computationally expensive and epistemically opaque. The cure is not to move arbitrary summaries into the floor. It is to make views materializable, cacheable, content-addressed, and invalidatable from the weaker substrate.

## 6. Provenance is part of empirical identity

Q629 and Q86 prove why. An answer-member code and a repeated-item response can look like two columns with values. Without source-structure provenance they become falsely equivalent.

Likewise FFX001-B proves that positive question routing does not establish respondent exposure. Exposure authority/provenance determines what the observation means.

## 8. Current executability warning

FFX001-B/C do **not** establish that current Rawlsing can materialize this respondent-grain substrate now. The current strongest proved layer is pre-respondent qimpl/routing/predicate authority plus historical respondent executability evidence.

Therefore this document is architecture, not blocker closure.

## 9. The remaining ontology in the floor

The substrate still imposes:
- empirical unit identity;
- measurement identity;
- value identity;
- context identity;
- source-structure typing;
- event relation schema.

These are unavoidable engineering/semantic commitments. They must be finite-authority objects and reversible to source evidence. The substrate is **weaker**, not neutral.

## 10. Precompute-before-automate boundary

Finite authority should freeze:
- source/qimpl identity;
- source-native structure type/member semantics;
- routing predicate semantics;
- exposure-state vocabulary and producer law;
- source-native value semantics;
- analytic recodes/partitions when a view requests them;
- cross-context equivalence/transport permissions;
- claim-to-view admissibility registry.

Deterministic machinery may derive:
- event indexes;
- exact J tables from lawful member/risk-set manifests;
- configuration views;
- conditional distributions;
- graph incidence;
- geometry under frozen method manifests;
- latent/motif models under frozen specs;
- cross-view comparison receipts.

Runtime may not choose semantic equivalence or representation family because it optimizes fit.

## 11. BUT HOW audit

### `GOVERNED_OBSERVATION_EVENT_SUBSTRATE`
- **what:** replay floor of governed empirical measurement events plus source topology/provenance.
- **producer:** source/respondent/exposure binding compiler once current carrier exists.
- **exact inputs:** current qimpl/source authority; governed respondent carrier; predicate inputs; routing/exposure authority; response carrier; source semantics; design refs.
- **authority:** identity/source/routing/response semantics; no social-structural authority.
- **computation:** deterministic joins/predicate execution/state preservation.
- **semantic judgment:** only finite source/identity/value/exposure classifications.
- **preserves:** maximal source-native empirical fidelity and replayability.
- **destroys:** no intended observation information; provides no structural compression.
- **hostile defeat:** cannot regenerate exact source state; conflates Q629/Q86; infers exposure from missingness; contains hidden analytic role/equivalence.
- **consumer:** all representation producers and audit/replay courts.
- **why over weaker:** qimpl/routing alone cannot answer respondent-backed structural queries; raw physical rows without governance cannot be lawfully consumed.

## 12. Ruling

The floor should be as boring as possible. The moment it becomes interesting sociologically, it is probably already a representation view.
