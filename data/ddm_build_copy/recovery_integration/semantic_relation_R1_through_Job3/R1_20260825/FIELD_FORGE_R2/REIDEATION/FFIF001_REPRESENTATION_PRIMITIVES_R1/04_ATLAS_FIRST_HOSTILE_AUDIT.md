# FFIF001 — ATLAS-FIRST HOSTILE AUDIT

## Holding

`POSITIONAL_CONFIGURATION_ATLAS` is rejected as a privileged representation but retained as a high-value claim-scoped view.

## 1. Does atlas merely rename an enormous contingency table?

At its raw limit: yes.

FFX002 improves this by distinguishing a lossless respondent fact floor from a compact atlas of closed conjunctions, minimal generators, supported conditionals, and motifs. That solves storage redundancy but not representational primacy. The compact object still needs a candidate-generation order, support law, and member/state semantics.

## 2. What is one configuration?

A configuration is only exact relative to:
- an exact empirical-unit/risk set;
- a frozen member set;
- exact state identities;
- source-native exposure/response semantics;
- any analytic role permissions used to select members.

Therefore `configuration_id` is not primitive social identity. It is a deterministic query result under a contract.

## 3. Order-k arbitrariness

Order is simultaneously meaningful and dangerous.

A two-way conjunction may miss a real three-way articulation. But extending all combinations indefinitely produces a sparse powerset. FFX002's support/closure rules are reasonable for compactness, yet a support threshold does not establish that order-k is sociologically real or unreal.

Required separation:
- **observed exact conjunction** may exist at any order supported by the unit records;
- **admitted compact configuration/motif** is a representation decision;
- **generalizable structural object** requires additional evidence.

## 4. Similarity is not free

Without a metric, two configurations are merely identical or nonidentical at the selected state set.

Possible similarity devices—Hamming overlap, Jaccard, weighted overlap, semantic distance, shared lower-order parents, conditional-distribution similarity—are all new representations.

If atlas compression begins clustering “similar” configurations, it has imported geometry/modeling and must expose that as a separate view.

## 5. Continuous resources

A discrete atlas cannot make continuous income, age, ordered status, or other continuous/ordinal values into configuration states without a partition/equality rule.

Forbidden default:
`continuous value -> arbitrary quantile bin -> social configuration category`.

Weaker lawful pattern:
- preserve source-native value in observation substrate;
- permit exact-value or ordered/range query views where computationally possible;
- require explicit analytic partition authority before a binned configuration treats categories as meaningful states.

## 6. Sparse conjunction versus meaningful configuration

Observed rarity is not noise. But a rare exact conjunction is not automatically a stable structural pattern.

Atlas must carry two layers:
1. exact observed branch: never deleted because sparse;
2. compact/generalization status: support/stability/null/holdout governed.

This preserves reality without pretending every singleton cell is a reusable social type.

## 7. Overlapping formations

A master atlas tends to imply that the full coordinate tuple is the unit's identity. But actors can participate in overlapping formations that are salient under different claims.

Rawlsing should allow multiple claim-scoped projections of the same underlying observation set. No one projection becomes the occupant's essence.

## 8. Source topology trap — Q629

Q629 has eight coded members but one respondent-facing `SELECT ALL THAT APPLY` parent prompt with a shared gate and answer-1 exclusivity.

An atlas that expands the eight child codes as eight independent binary measurements changes the measurement ontology. A lawful representation must preserve parent-question semantics and distinguish answer membership from repeated-item exposure.

## 9. Source topology trap — Q86

Q86A–Q86F is a genuine repeated-item matrix, but current respondent exposure is not materialized. The atlas cannot infer same-respondent joint facts merely from complete source membership plus positive routing predicates.

`MATRIX_GRID + QUESTION_ELIGIBILITY != RESPONDENT_J`.

## 10. BUT HOW audit

### `EXACT_CONFIGURATION_SET_VIEW`
- **what:** deterministic conjunction/query view over lawfully coobserved source/analytic states.
- **producer:** configuration view compiler.
- **inputs:** governed observation events, risk set, state/member manifest, estimand/support rules.
- **authority:** source semantics + exposure + any analytic role/state partition authority.
- **computation:** exact set intersection/grouping; optional bounded closed-set compression.
- **semantic judgment:** member eligibility and any analytic recoding/partition.
- **preserves:** exact conjunction, contradiction, minority branches, support, higher-order J where lawful.
- **destroys:** none if exact facts retained, but compact view loses unselected relationships; no intrinsic gradient/similarity.
- **hostile defeat:** combinatorial explosion with no query gain; hidden metric in pruning; continuous binning without authority.
- **consumer:** claim-scoped plausibility/conditional query engines; representation comparison.
- **why over weaker:** needed only when the query specifically asks about joint configurations rather than individual observations.

## 11. Ruling

Atlas-first is the strongest candidate for **loss-preserving discrete joint-state queries**, not for representing society as such.
