# FFIF001 — GEOMETRY HOSTILE AUDIT

## Holding

`GEOMETRY_PRIMARY` is rejected. `CLAIM_SCOPED_LOCAL_GEOMETRIC_VIEW` survives.

## 1. Inherited attacks preserved

FFX002 and R1/R2 already correctly attack:
- questionnaire-block counterfeit;
- active/supplementary choice;
- rare modality leverage;
- category coding;
- weighting and estimand;
- disconnected coadministration;
- instrument ancestry;
- semantic axis-label storytelling.

This court adds a prior attack: **every geometry begins from an equivalence and admissibility surface that is itself not geometric.** If that surface is wrong, stable geometry can be stably wrong.

## 2. Geometry's primitive is not “social relation”

A practical MCA/GDA view takes as primitive:
- an admitted respondent/risk-set surface;
- active variables/modalities;
- coding/metric rules;
- optional blocks and weights.

The resulting distances are method outputs. They are not preserved source facts.

## 3. The identity-before-distance problem

Before distance is computed, Rawlsing must already decide:
- which qimpls are distinct measurements;
- which response values are distinct/equivalent;
- which units belong in a common risk set;
- whether a variable is active, supplementary, conditioning, or excluded;
- whether categories may be collapsed;
- whether disconnected components may share a metric.

This is the deeper hidden-ontology surface. Geometry does not solve it.

## 4. Q629 hostile case

If each answer member of Q629 becomes an active binary item, MCA would geometrize source encoding choices for a single select-all parent prompt. Because answer 1 is mutually exclusive with other answers, source response grammar itself creates strong opposition. That opposition may be perfectly real as **response grammar** while being invalid as an inferred social axis.

Source-structure type must therefore constrain geometric admissibility.

## 5. Q86 hostile case

Q86 is a legitimate repeated-item source block, so item-level geometry is more plausible after lawful respondent exposure exists. But the same block can dominate inertia simply because it contains six parallel items. Block-balanced sensitivity can diagnose this; it cannot declare the correct sociological weight.

Current FFX001-B/C means no respondent geometry may actually be fitted by this court.

## 6. Disconnected/routed hostile case

Arab Barometer VIII Q872–Q884 historical stress material contains splits, randomization, and prior-answer gates. A common respondent matrix can therefore have structural holes produced by instrument assignment.

Forbidden repairs:
- encode nonexposure as an active missing category;
- impute across randomized/routed components merely to create a common space;
- bridge components because item texts appear semantically related.

Required output where needed:
`NO_COMMON_METRIC_ACROSS_COMPONENTS`.

## 7. Geometry may reveal what exact tables do not

Geometry earns a role when it demonstrates stable, held-out value in one or more of:
- local neighborhoods;
- gradients;
- rank/opposition structure;
- economical low-dimensional compression;
- robust interpolation for downstream query approximation.

This value is real even though geometry is not primary.

## 8. New attacks

### 8.1 topology-to-metric laundering
A connected coadministration graph does not imply one meaningful metric. Connectivity is necessary evidence for some analyses, not sufficient geometry authority.

### 8.2 source-cardinality leverage
A variable with many source categories can contribute more geometric articulation simply because of coding granularity. Category count must be treated as a nuisance diagnostic.

### 8.3 analytic survivorship
A method may appear stable because unstable/rare modalities were made supplementary. Stability purchased by excluding inconvenient reality must be reported as information loss.

### 8.4 cross-context Procrustes seduction
The ability to align two spaces numerically does not establish semantic portability. Alignment is itself a model. Cross-context claims need independent transport authority.

## 9. BUT HOW audit

### `CLAIM_SCOPED_LOCAL_GEOMETRIC_VIEW`
- **what:** a local metric/embedding representation over an admitted empirical surface.
- **producer:** geometry producer under preregistered method family.
- **inputs:** observation substrate-derived lawful risk set; role manifest; category/ordinal handling; estimand/weight refs; ancestry/block manifests.
- **authority:** semantic authority decides admissible inputs/roles; method does not.
- **computation:** MCA/GDA/MFA or separately justified local method.
- **semantic judgment:** active/supplementary/conditioning status, any category merge, block manifest, estimand.
- **preserves:** approximate neighborhood/gradient relations and compressive structure if stable.
- **destroys:** exact high-order conjunction and rare branch detail unless sidecar retained.
- **hostile defeat:** block clone rotation, rare leverage, encoding/weight sensitivity, disconnectedness, null indistinguishability.
- **consumer:** neighborhood/gradient/approximation queries; cross-view diagnostics.
- **why over weaker:** only when distances/neighborhoods/compression answer a declared query better than exact set/conditional views.

## 10. Ruling

Geometry is an instrument for seeing relations under explicit assumptions, not the empirical world's native coordinate system.
