# FFX002-XC — OPTIONAL CROSS-CONTEXT EXTENSION

Status: `FUTURE_OPTION__NOT_REQUIRED_OR_EXECUTED_BY_FIRST_CANARY`

## 1. Purpose

Only after one or more local FFX002 R2 canaries have independently frozen valid local outputs may a later court ask whether a named invariant recurs across contexts.

The extension follows FFIF003: transport is a typed claim-scoped object, not a common world-space.

## 2. Preconditions

For each context:
- local common semantic manifest independently frozen;
- local respondent/risk-set/estimand authority valid;
- local views produced without cross-context fitting;
- local invariant/loss results frozen;
- representation dependence recorded;
- exact local output hashes retained.

Only then register a transport claim.

## 3. Permitted transport targets

Depending on independent authority:
- exact semantic relation;
- order/rank relation;
- topology/connectivity/opposition;
- bounded conditional redistribution shape/direction;
- typed motif;
- finite signature containing independently established invariant components.

`CLAIM_SCOPED_SIGNATURE_TRANSPORT` is the strongest general form contemplated here.

## 4. Transport object

A future transport receipt must bind:
- source local output refs/hashes;
- target local output refs/hashes;
- claim_scope_ref;
- invariant components;
- exact/partial correspondence authority;
- admissible map family;
- risk-set/estimand compatibility statement;
- allowed transforms;
- forbidden interpretations;
- alternative-map/null design;
- discriminativeness test;
- preservation predicate;
- failure/NO_TRANSPORT state.

## 5. Prohibitions

No:
- pooled global MCA/factor/latent/graph world-space used to create the local objects and then cited as recurrence evidence;
- global harmonized categories by convenience;
- homology claim;
- common field/capital claim;
- causal mechanism claim;
- post-hoc visual analogy.

## 6. First-class negative result

`NO_TRANSPORT` is valid and must not be repaired by widening mappings after seeing results.

## 7. Relationship to FFX002 R2

FFX002-XC consumes already-frozen local R2 outputs. It does not modify the first-canary common-input manifest and is not an execution prerequisite.
