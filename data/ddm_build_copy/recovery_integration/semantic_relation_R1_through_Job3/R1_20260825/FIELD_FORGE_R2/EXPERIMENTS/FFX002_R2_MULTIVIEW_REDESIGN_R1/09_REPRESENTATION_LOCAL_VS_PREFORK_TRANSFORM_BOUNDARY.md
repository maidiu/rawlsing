# FFX002 R2 — REPRESENTATION-LOCAL METHOD VS PRE-FORK SEMANTIC TRANSFORM BOUNDARY

Status: `BINDING_EXPERIMENT_DESIGN_RULE__NO_TTAR_AUTHORITY_MINTED`

## Core test

Ask of operation O:

> Could O change whether two source observations count as the same/different empirical state, their order, category membership, comparability, semantic eligibility, risk-set membership, estimand, or analytic role?

If YES, O belongs before the representation fork under the competent authority object. If it changes semantic/equivalence state, it requires the appropriate TTAR or stronger source/project authority.

If NO, ask:

> Does O merely choose how a view summarizes, estimates, indexes, embeds, regularizes, displays, or compresses the already-frozen state universe?

If YES, O may be representation-local, subject to preregistration and a loss manifest.

## Rare-category law

A geometry-specific rare-category merge is not method freedom.

Lawful choices:
1. preserve the state and let geometry bear instability;
2. use a purely method-local passivation that leaves frozen semantics/eligibility intact;
3. create a separately authorized pre-fork TTAR collapse variant applied to every arm;
4. declare geometry inadmissible.

## Active/supplementary law

The original FFX002 active/supplementary attack survives only after splitting two cases:

- `METHOD_PASSIVATION`: numerical participation changes while the frozen semantic state and authorized analytic role remain intact. This is a representation-local nuisance test.
- `ROLE_RECLASSIFICATION`: the variable/state changes active position/disposition/supplementary/conditioning/excluded status. This is a PRA/common-input variant and must occur before the fork for every arm.

## Anti-laundering receipt

Every arm method manifest must list every preprocessing function. The execution worker classifies each function as:
- `IDENTITY_PRESERVING_METHOD`
- `AUTHORIZED_PREFORK_TRANSFORM_ALREADY_IN_MANIFEST`
- `FORBIDDEN_UNDECLARED_SEMANTIC_TRANSFORM`

Unknown classification fails closed.
