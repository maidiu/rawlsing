# ROUTING → RESPONDENT EXECUTION BRIDGE

## What Contract@2 supplies

C06 `CURRENT_ROUTING_LEDGER_CONTRACT@2` is a lossless current re-expression of routing/applicability authority. At its governed grain it supplies exact current implementation identity and exact source routing/provenance fields including question implementation, source family, wave/release, raw variable, disposition semantics, verification detail, evidence source/ranges, and source-artifact/source-bucket backreferences.

For positive rows, those backreferences reach source-family carriers/sidecars that remain authoritative for exact executable predicate specifications.

This is real executable capital. It closes these arrows:

`CURRENT qimpl → current source implementation → exact routing disposition → exact predicate specification (where positive)`

## What Contract@2 does not supply

It does not itself supply:

- a current respondent entity/key;
- an exact current respondent-carrier artifact/hash;
- the carrier column/measurement identity corresponding to the routed source variable;
- respondent-row country/form/split identity;
- actual row values for predicate inputs;
- actual respondent measurement exposure/opportunity;
- response value/state;
- respondent weight rows.

Its source-carrier backreferences are therefore sufficient to locate the **predicate authority**, but not sufficient to manufacture a join to a separately governed respondent carrier whose current existence has not been proved.

## Bridge ruling

Required bridge:

`qimpl → source variable → respondent measurement → respondent key → respondent scope → predicate inputs → predicate execution → exposure → response`

Current proof:

`qimpl → source variable → predicate specification`

Current missing bridge:

`source variable ↛ current respondent measurement/key/input carrier`

Result:

`NO_CURRENT_RESPONDENT_EXECUTION_BRIDGE_PROVED`

No omitted Contract@2 field was synthesized. No historical database schema was borrowed to fill the gap.
