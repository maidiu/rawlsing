# FFX002 — FAILURE MODES AND NEGATIVE DESIGN CAPITAL

Status: `DESIGN_ONLY__PRESERVE_ON_EXECUTION`

This file records ways the duel can lie even when the code runs.

## 1. Geometry-side failures

### GNF001 — axis reification

Failure: numerical dimensions are narrated as sociological dimensions because their extremes look interpretable.

Defeat: semantic-label scramble; score numeric preservation/downstream value only; axis labels prohibited from primary comparison.

Preserved lesson: `AXIS != SOCIOLOGICAL_DIMENSION`.

### GNF002 — questionnaire-count ontology

Failure: a large source block defines the space because it has more variables/modalities.

Defeat: block counterfeit clone; source-block removal; authorized block-balanced sensitivity build.

Preserved lesson: `NUMBER_OF_QUESTIONS != SOCIAL_IMPORTANCE`.

### GNF003 — block semantic laundering

Failure: questionnaire module is renamed an economic/cultural/religious block and then equal-weighted as though the ontology were given.

Defeat: only accepted `ANALYTIC_ROLE_BLOCK` manifests may drive MFA/block balance.

Preserved lesson: `SOURCE_INSTRUMENT_BLOCK != ANALYTIC_ROLE_BLOCK != EMPIRICAL_COADMINISTRATION_BLOCK`.

### GNF004 — rare-modality leverage or erasure

Failure A: tiny category anchors a dimension. Failure B: category is deleted/collapsed because it is inconvenient.

Defeat: active/passive sensitivity where lawful; exact rare fact always preserved; no frequency-only semantic collapse.

Preserved lesson: `RARE != NOISE`, and `PASSIVE_IN_GEOMETRY != DELETED_FROM_REALITY`.

### GNF005 — missingness/exposure geometry

Failure: routed/nonexposed respondents enter as one generic missing modality and generate an axis.

Defeat: exact exposure compiler + poison fixture.

Preserved lesson: `NONRESPONSE != NONEXPOSURE`; unresolved exposure cannot construct geometry.

### GNF006 — active/supplementary winner shopping

Failure: variable role is changed after plots are inspected until a preferred geometry appears.

Defeat: accepted role authority + preregistered alternate builds only when both roles are semantically lawful.

Preserved lesson: model fit cannot mint semantic role authority.

### GNF007 — arbitrary ordinal distance

Failure: continuous/ordinal variables are quantile-binned or numerically scaled because the software needs it, then the induced topology is treated as social structure.

Defeat: only source-native or independently authorized lawful encodings; explicit sensitivity.

### GNF008 — disconnected-space counterfeit

Failure: semantically similar but never coexposed measurements are joined/imputed into one disposition space.

Defeat: exact exposure/coadministration components; `NO_COMMON_METRIC_ACROSS_COMPONENTS`.

### GNF009 — weight convenience ontology

Failure: whichever weight produces cleaner axes becomes the default social geometry.

Defeat: estimand frozen first; unweighted vs authorized weighted is an explicit difference, not a tuning choice.

Preserved lesson: `WEIGHT_AVAILABLE != WEIGHT_AUTHORIZED_FOR_THIS_ESTIMAND` and calibrated margins do not prove the full population relational structure.

### GNF010 — position/disposition circularity

Failure: same source measurement or derived ancestry actively constructs both spaces, then their correspondence is praised.

Defeat: recursive ancestry audit + injected ancestry trap + alternate primary builds.

### GNF011 — joint optimization masquerading as discovery

Failure: position and disposition embeddings are optimized to correspond, then high correspondence is treated as independent evidence.

Defeat: freeze spaces separately; primary cross-space relation is post-hoc respondent linkage only.

### GNF012 — measurement-regime socialization

Failure: mode, form, language, randomized arm, interviewer context, or administrative implementation creates structure narrated as population structure.

Defeat: regime negative controls; randomized design diagnostics where exact.

### GNF013 — low-dimensional inevitability

Failure: geometry is kept because every decomposition yields axes even when no stable low-dimensional d exists.

Defeat: held-out/stability-based d selection; permit `NO_STABLE_LOW_DIMENSIONAL_VIEW`.

### GNF014 — pretty-null problem

Failure: null data still yields visually compelling axes because dimensional methods always produce ordered coordinates.

Defeat: semantic-label scramble + association/J nulls + numerical separation requirements.

## 2. Atlas-side failures

Failure: “loss preserving” becomes enumeration of every possible conjunction, unusable downstream.

Defeat: exact raw floor + compact closed-conjunction/minimal-generator layer; FFP012 complexity ablation.

### ANF002 — pruning as hidden ontology

Failure: arbitrary support/order cutoffs determine which social configurations “exist.”

Defeat: raw observed facts survive every pruning choice; thresholds govern stable generalization/compact emission only; sensitivity court.

### ANF003 — minority erasure through support law

Failure: low-support branches vanish because they cannot support stable estimates.

### ANF004 — pooling laundering

### ANF005 — hidden metric through configuration similarity

### ANF006 — motif storytelling

Defeat: neutral `EMPIRICAL_MOTIF` IDs; late interpretation outside FFX002.

### ANF007 — motif instability

### ANF008 — cross-tab fundamentalism

### ANF009 — exactness without usefulness

### ANF010 — source representation duplication

## 4. Negative design capital to bank regardless of outcome

Execution should preserve, with exact evidence, any discovered case where:

- raw and block-balanced geometries disagree;
- weighted/unweighted relational views differ;
- a rare category causes geometric leverage;
- atlas motifs fail stability despite exact support;
- atlas compression erases minority structure;
- geometry adds no held-out value despite visual coherence;
- geometry adds real stable value unavailable economically from atlas;
- both representations reproduce a measurement-regime artifact;
- the null remains as “interesting” as the observed representation;
- downstream combined representation is materially better than either alone.

A negative result is not wasted work. It constrains which ontology Rawlsing is allowed to build.
