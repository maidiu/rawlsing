## Persistence law recovered

C07 makes four questions independent for each object: (1) must the semantic product/capability exist or remain addressable; (2) must bytes for this representation persist; (3) is warm retention operationally valuable; (4) what is primary epistemic authority?

Its persistence classes are: `PERSIST_AUTHORITATIVE_SOURCE`, `PERSIST_AUTHORITATIVE_SEMANTIC_OR_LEARNED_PRODUCT`, `PERSIST_PROVENANCE_OR_REPLAY_RECEIPT`, `PERSIST_REGENERABLE_CACHE_OPTIONAL`, `TRANSIENT_COMPILER_STATE`, and `DERIVE_ON_DEMAND`.

This is the core answer to the D15 challenge. Chetiri does not equate `REBUILDABLE` with `DISPOSABLE`. A discovered/validated/released empirical relation can be deterministically rebuildable from source yet still need durable release identity because later products cite that historical learned object. Conversely a physical index can be persistently warm for performance while remaining epistemically replaceable.

## Direct-reference dependency law

Structural products may directly reference authoritative earlier V553-V557 objects rather than republish them when identity and availability are sufficient. Runtime indexes are semantics-preserving views; losing them can increase latency without changing meaning. This preserves D15's direct-DAG impulse while reducing pressure to make every intermediate representation canonical.

## Selective invalidation

C07/C08 bind invalidation to exact dependency fingerprints: source-wave changes invalidate descendants of that exact source/release; semantic binding changes invalidate descendants of the binding; discovery-rule changes invalidate dependent search receipts/candidates and governed descendants; validation-rule changes do not mutate source facts; model changes invalidate model release and derived fields; cache-key changes invalidate cache only. C08 further states minimum lawful recompilation = changed determinant scope + transitive dependency closure (`b433435bfc9ca0c7a7ba9ec349faec069479656c:.../returns/C08/C08_RESULT.json`).

## Negative ceiling

C07 did not close general empirical validation law, empirical comparability law, positioned-subject possibility-model law, or source-universe composition law. C07R1 preserved these four fail-closed gaps. The product model therefore proves what must remain representable/addressable under the accepted terminal vision; it does not prove every product can already be lawfully generated in production.
