# I04 Target Enumeration Receipt

## Contract

Target reachability is sealed before branch-conditioned co-signature outcomes are inspected.

`TARGET_REACHABILITY_PRECEDES_OUTCOMES = TRUE`

`RANKING_CONTROLS_REACHABILITY = FALSE`

## Source of the catalog

For the exact branch source release/universe/risk context, I04 enumerates exact `QuestionVariableBinding` records in the sealed C11 release.

For each candidate question it requires:
1. exact question identity and instrument question version;
2. positive response-semantic authority;
3. positive response-topology authority;
4. one exact supported carrier topology;
5. source-native governed response states/domain replay material;
6. exact per-respondent routing/risk resolution under positive routing authority.

The target domain is derived from source/instrument response carriers before any branch-conditioned co-signature query is executed.

## Exclusions

Exact empirical coordinate refs are recorded as:

`POSITIONAL_COORDINATE__NOT_COSIGNATURE_TARGET`.

Question-like target refs whose kind attempts to encode coordinate, position, demographic, geography, structural, actor, persona, personality, belief, causal or diagnostic identity are excluded from the substantive attitude graph.

An exclusion is authority/role closure, not empirical evidence of non-cotravel.

## Canonicalization

Eligible target descriptors are deduplicated by exact target ref and sorted by exact-ref key.

For target set `T`:
- current marginal frontier = all `T_i`;
- current pair frontier = all unordered distinct `(T_i,T_j)` where `i<j`;
- expected pair count = `|T|*(|T|-1)/2`.

No top-k or winner path exists.

## Query composition

Each generated query binds:
- exact branch predicate;
- exact target descriptor(s);
- exact target catalog;
- exact branch context;
- source release and universe;
- risk set;
- response semantic/topology authorities;
- query authority;
- exact RAW or governed-weighted measure basis;
- deterministic replay ref.

Current high-level composition executes all J1 and J2 targets through existing I03.

## J=3 interface

Authority 37 allows J=3 but this I04 launch tree does not include the parallel I03 J=3 integration.

Thus:
- current executor ceiling = 2;
- J=3 request with current capability -> fail closed;
- tuple/query composition functions accept a caller-supplied integrated executor ceiling of 3 after HQ incorporates I03;
- no J=3 identity may be manufactured from J2 results.

## Completeness closure

A `BranchCosignatureTopologyClosureReceipt@1.0.0` is emitted only after:
- every eligible target has exactly one marginal query/fact binding;
- every expected J2 pair has exactly one joint query/fact binding;
- denominator/member-envelope checks pass;
- exact branch/parent/ancestry/replay/source/risk/authority/measure refs are sealed.

The closure is ref-only; all empirical cells/support remain in I03 fact refs.
