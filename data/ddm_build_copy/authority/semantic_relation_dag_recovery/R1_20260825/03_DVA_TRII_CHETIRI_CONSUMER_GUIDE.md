# Dva / Trii / Chetiri consumer guide

## Purpose

This release exists so later Rawlsing work does **not** have to rediscover semantic relation structure, failure law, coverage law, or source-first relation distinctions already established in the R1→Job3 campaign.

It is intended as a reusable project-level substrate, not as one campaign's private scratch.

## Vozhd Dva

Use this release for:
- recovery/provenance adjudication;
- distinguishing surviving authority from composted intermediate campaigns;
- tracing why a relation or non-relation exists;
- locating raw immutable recovery material by SHA when deeper archaeology is required.

Dva should treat `provenance/R16F_TO_CURRENT_EDGE_SUCCESSION.csv` as the canonical old→current edge identity bridge and must not revive superseded IDs as parallel current truth.

## Vozhd Trii

Use this release for:
- semantic typed-edge authority that complements the full question/node structural authority;
- exact relation roles, member identities, actor/target/action/routing conditions;
- T06 strict norm↔conduct versus T15 norm→praxis ontology;
- wave×rule capability/observability and open-world coverage law;
- fixed semantic fixtures when testing empirical substrate/compiler behavior.

Trii must keep semantic relation truth independent from empirical co-travel, respondent joins, source-carrier layout, pressure, or personality inference.

## Vozhd Chetiri

This release is directly useful to discovery/DAG compiler work.

For exact-bounded/open-world discovery:
- use `canonical_graph/R16F_WAVE_RULE_COVERAGE.csv`;
- use `canonical_graph/JOB3_R3_REJECTED_TYPED_RELATION_CANDIDATES.csv`;
- use `canonical_graph/JOB3_R3_BLOCKED_CANDIDATES.csv`;
- use `canaries/` and `05_HOSTILE_DISCOVERY_FIXTURES.csv`;
- apply `04_DAG_INVARIANTS_AND_DISCOVERY_LAW.md`.

For dependency/invalidation DAG work:
- use `canonical_graph/JOB3_R3_O12_SUCCESSOR_OBLIGATIONS.csv`;
- use `canonical_graph/JOB3_R3_BLOCKER_OBLIGATIONS.csv`;
- use `provenance/R16F_TO_CURRENT_EDGE_SUCCESSION.csv`;
- preserve distinction between authority succession, semantic rejection, unresolved BLOCK, and empirical independence.

For source-backed execution:
- use exact implementation IDs and source-first provenance embedded in T06/T15 authority;
- if richer questionnaire structure is needed, follow the external source-native authority pointer in `provenance/EXTERNAL_RECOVERY_PAYLOADS.json` and verify SHA before use.

## Non-negotiable anti-wheel-reinvention rule

Before inventing a new semantic-relation heuristic, ontology, negative law, candidate denominator, canary, or source-role mapping, search this release and its external recovery index first.

A later campaign may supersede these authorities only with explicit governed evidence. Mere novelty, newer timestamp, or a different implementation strategy is not supersession.
