# R16G O11 / S16 capability doctrine

S16 is a static per-wave/per-rule observability and bounded-search control surface. It consumes frozen R16F S14 typed-relation authority; it does not create or revoke relation truth.

## Capability states
- `OBSERVABLE`: at least one frozen positive relation has a current respondent-composable O06/O07 witness.
- `PARTIALLY_OBSERVABLE`: no current observable positive is required, but current R16F unresolved relation terrain contains at least one member configuration that is respondent-composable or only measurement-partial, so bounded O12 search is lawful.
- `SEMANTIC_ONLY_NONCOMPOSABLE`: semantic relation/terrain exists but common current respondent composability is not proven.
- `ROUTING_BLOCKED`: relation authority or unresolved terrain exists, but current O06 routing blocks all presently relevant member structures.
- `NOT_OBSERVED`: no frozen positive and no current R16F unresolved relation opportunity. This is explicitly **not** an absence claim.

## Laws
1. Universe is exactly 35 source-waves × T03–T11 = 315 cells.
2. R16F positive/negative relation truth is immutable input. O11 may classify observability, never semantic truth.
3. `ALLOW_BOUNDED_O12_SEARCH` requires `OBSERVABLE` or `PARTIALLY_OBSERVABLE`; routing-blocked, semantic-only, and not-observed cells do not authorize generation under current capability.
4. R16F blocked/unknown is never converted to negative.
5. Frozen typed-relation negatives never erase V550/V550J empirical co-travel.
6. O07 confirms individual measurement availability only; cross-member value portability remains candidate-specific downstream.
7. S16 does not perform respondent joins, Job-3 adjudication, V550J joint construction, pressure inference, or persona generation.
8. Old O11 proxy statuses are ancestry/diagnostic only. Stable rule labels and S13 linkage metadata may be retained, but every R16G capability/posture is rebuilt from R16F + current O06/O07.
