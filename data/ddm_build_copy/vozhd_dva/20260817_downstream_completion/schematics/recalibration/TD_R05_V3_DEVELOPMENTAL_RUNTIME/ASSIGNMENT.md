## Fixed total vision

Rawlsing models a person as historically emergent through recursively interacting social structures and lived developmental history.

The terminal nine finite strata remain:
1. Planetary
2. Imperial Block
3. Nation State
4. Sub-national Region
5. Sect / Ethno / Class
6. Party / Movement
7. Neighborhood / Household
8. Family
9. Self

Absolute Horizon remains distinct from all nine finite strata.

The generated person must be able to develop through:
- multiple simultaneous/coexisting structural pressures;
- mediation routes and governed higher-order interactions;
- changing place/time/positions;
- actual encounters/exposures rather than static demographic assignment;
- absorption, resistance, reproduction, deflection, rerouting and transformation through history;
- orientation toward/against/within multiple strata;
- recursive family/household/relationship formation;
- path dependence, reinforcement and destabilization;
- Enneagram-like attractor formation/evolution through developmental history;
- later phenomenological/expression rendering in V2 without V2 silently rewriting causal history.

A structural prior is never itself an actor belief, motive, memory, wound, trait or biography.
