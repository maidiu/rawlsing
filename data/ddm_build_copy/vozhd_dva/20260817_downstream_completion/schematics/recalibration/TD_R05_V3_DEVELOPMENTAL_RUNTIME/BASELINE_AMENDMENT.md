## 0. Governing correction

The recovered V3/V2 snapshot is important because it is the latest extant V3/V2 implementation/design presently available. It should be preserved and reused wherever that can be done **without loss to the total Rawlsing vision or to the maximal function of the accepted V550+ structural pipeline**.

The project therefore carries a real **desire for continuity**. Existing V3/V2 machinery is worth saving when it already expresses the intended causal/phenomenological design or can be adapted cleanly to the new structural world. Avoid gratuitous demolition and gratuitous reinvention.

That desire is subordinate to one absolute priority:

> **V550+-grounded Rawlsing vision-integrity.**

The governing order is:

`TOTAL RAWLSING VISION`
`→ MAXIMAL LAWFUL V550+ STRUCTURAL-WORLD IMPLEMENTATION`
`→ V3/V2 DESIGNED OR REDESIGNED AS NECESSARY TO REALIZE THAT WORLD WITHOUT LOSS`
`→ RECOVERED V3/V2 MECHANISMS REUSED WHERE THEY FIT THAT RESULT`.

The accepted V553–V558 architecture was derived from terminal demand and remains sovereign. No V3/V2 mechanism, schema, state vector, yearly loop, LLM pass, attractor model, conversation design, or compatibility concern may narrow, simplify, reinterpret, or reduce the function of V550+ even slightly.

If maximizing the finished Rawlsing machine requires substantial or total redesign of V3 and/or V2, then V3/V2 changes however much is necessary.

A serendipitous bridge between extant V3/V2 and accepted V550+ is highly desirable where it exists. Take it eagerly when it is lossless. It is an implementation advantage, never the primary reasoning axis and never a reason to accommodate upstream architecture to legacy downstream shape.

## 2. No upstream accommodation law

TD-R05 and all later workers MUST NOT reason backward from extant V3/V2 limitations to reduce or reshape accepted V550+ semantics.

Forbidden examples include:

- dropping a V553 temporal distinction because extant V3 has no field for it;
- flattening V554/V555 mediation because extant V3 expects simpler channels;
- reducing V556 n-ary interaction/topology because extant V3 only supports pairwise or scalar flow;
- collapsing nine strata or Absolute Horizon into extant V3's older field model;
- converting missing/noncomparable/negative authority into defaults because extant V3 expects populated numeric state;
- replacing mixed-producer graph identity with extant V3 slot names;
- choosing yearly integration or LLM proposal semantics merely because they are already implemented if stronger terminal architecture requires something else.

The adaptation direction is one-way:

`accepted structural world → V3/V2 adaptation`.

Never:

`extant V3/V2 limitations → structural-world reduction`.

## 3. What continuity preference means in practice

Every substantive recovered mechanism must receive an explicit disposition:

- `REUSE_UNCHANGED_IF_FULLY_COMPATIBLE`;
- `ADAPT_TO_TERMINAL_ARCHITECTURE`;
- `REPLACE_WITH_STRONGER_MECHANISM`;
- `DEFER_MISSING_AUTHORITY`;
- `REMOVE_AS_OBSOLETE_OR_REDUNDANT`.

This serves two purposes simultaneously:

1. **continuity protection** — do not discard functioning accumulated design simply because a rewrite is aesthetically cleaner;
2. **vision protection** — do not retain a legacy mechanism merely because it already exists when it constrains the terminal machine.

A recovered mechanism should survive when:

1. it already implements a terminally required function well;
2. it can consume the full new V550+ output without information loss;
3. it preserves causal/epistemic jurisdiction;
4. adapting or retaining it is cleaner and safer than rebuilding equivalent machinery.

A recovered mechanism must change or disappear when:

1. it limits information or causal possibilities supplied by V550+;
2. it encodes stale V5 assumptions;
3. it duplicates authority now owned elsewhere;
4. it relies on ungoverned shortcuts/defaults;
5. stronger architecture is required by terminal personhood;
6. preserving it would force any earlier stage or the total vision to bend around an implementation accident.

Thus continuity is **positively desired**, but never at the price of even a small loss in vision-integrity.
