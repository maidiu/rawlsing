## 4. Exact route-born predicate ownership test

A predicate may be registered under ADP-003 only if **all** of the following are true:

1. its semantic meaning is undefined before the exact canonical V555 route exists;
2. it is a property or constraint of **one exact route considered in isolation**;
3. its meaning depends on exact ADP-002 route-local bindings, such as the selected mediation locus/channel or receiving structural-position constraint;
4. it does not restate, rename, copy, or merely re-evaluate an inherited V554 F2 applicability condition;
5. it requires no actor encounter, exposure, traversal, realization, response, memory, relationship, biography or history;
6. it creates no relation among multiple V555 routes/pressures and no V556 interaction/prerequisite topology;
7. an exact accepted owning rule supplies its semantic scope, argument schema, result semantics, ID, version and hash.

Failure of any ownership test means:

`DO_NOT_REGISTER_AS_ADP003_PREDICATE`.

Foreign meanings remain with their existing owners:

- V554 F2 → `PRESERVE_EXACT_REFERENCE_ONLY`;
- actor realization → V3;

## 8. Argument states

Every declared argument resolves to one of these typed states before semantic evaluation:

- `ARGUMENTS_VALID` — all required exact arguments resolve with correct IDs/hashes and lawful use state;
- `ARGUMENT_UNKNOWN` — a producer-authorized value/state is unknown, unresolved or noncomparable; it is never coerced to false/zero;
- `ARGUMENT_NOT_APPLICABLE` — the registered predicate explicitly declares the argument/domain inapplicable for this route;
- `ARGUMENT_MISSING` — a required declared ref/value cannot resolve;
- `ARGUMENT_FORBIDDEN` — the source is outside ADP-003 jurisdiction;
- `ARGUMENT_INTEGRITY_FAILURE` — ID/hash/schema/version/reference verification fails.

An implementation may not collapse `UNKNOWN`, `MISSING`, `NOT_APPLICABLE`, `FORBIDDEN` and integrity failure into a single false result.

## 9. Evaluation result states

The canonical result domain is:

- `PREDICATE_TRUE` — a registered predicate evaluates positively from complete lawful arguments;
- `PREDICATE_FALSE` — a registered predicate evaluates negatively from complete lawful arguments;
- `PREDICATE_UNKNOWN` — lawful semantics exist but authorized input remains unknown/noncomparable/unresolved;
- `PREDICATE_NOT_APPLICABLE` — the predicate's own accepted domain rule makes it inapplicable to the exact route;
- `VALID_EMPTY_NO_ROUTE_BORN_PREDICATES` — no registered route-born predicates exist/apply; this is the v1 registry's ordinary complete result;
- `MISSING_PREDICATE_AUTHORITY` — requested predicate ID/version or owning semantic authority is absent;
- `DEFERRED_MISSING_ARGUMENT` — a registered predicate exists but a required argument is unavailable and truth cannot be computed;
- `DENIED_FOREIGN_JURISDICTION` — attempted evaluation relies on duplicated V554 meaning, actor state/history, V556 relation/topology, V2/session material or another forbidden source;
- `INTEGRITY_FAILURE` — predicate/route/rule/argument/receipt identity or hash fails verification.

Fail-closed precedence is:

```text
INTEGRITY_FAILURE
→ DENIED_FOREIGN_JURISDICTION
→ MISSING_PREDICATE_AUTHORITY
→ DEFERRED_MISSING_ARGUMENT
→ governed UNKNOWN / NOT_APPLICABLE
→ TRUE / FALSE
```

`MISSING_PREDICATE_AUTHORITY` is not `PREDICATE_FALSE`.

## 13. Hostile fixtures

1. **Empty registry:** zero predicate entries → `VALID_EMPTY_NO_ROUTE_BORN_PREDICATES`; no filler predicate.
2. **Copied V554 F2:** copy applicability predicate under new V555 ID → reject registration / `DENIED_FOREIGN_JURISDICTION`; preserve V554 ref.
3. **Runtime-position rename:** rename inherited runtime-position requirement as route receiver predicate → reject semantic duplicate.
4. **Unknown predicate:** request unknown predicate ID/version → `MISSING_PREDICATE_AUTHORITY`, never false/fallback.
5. **Fuzzy route recovery:** exact route ID missing but similar route exists → no rematch; exact identity failure.
6. **Route hash tamper:** route ID exists but content or ADP-002 rule hash mismatches → `INTEGRITY_FAILURE`.
7. **Actor traversal input:** predicate asks whether actor encountered/traversed route → `DENIED_FOREIGN_JURISDICTION`.
8. **Cross-route relation:** route A blocks/reinforces/reroutes route B → V556-owned; deny ADP-003 evaluation/registration.
9. **Attractor topology leakage:** predicate creates V556 prerequisite topology/satisfaction → deny.
10. **Unary effect invention:** route/channel existence alone implies `TRANSMIT/BUFFER/AMPLIFY/DEFLECT/BLOCK` → `MISSING_PREDICATE_AUTHORITY`; ADP-002 effect registry remains valid-empty.
11. **Numeric heuristic:** readiness/confidence/strength `0.8` controls result → reject absent exact semantic/formula authority.
12. **Missing required argument:** → `DEFERRED_MISSING_ARGUMENT`; no false/zero/default.
13. **Unknown/noncomparable argument:** → `PREDICATE_UNKNOWN` where a future registered predicate permits evaluation; never false coercion.
14. **Inherited F2 only:** route has exact V554 F2 refs and zero route-born predicates → route remains lawful under ADP-002 subject to upstream conditions; ADP-003 is valid-empty.
15. **Evaluator mutation:** evaluator tries to create actor/V556/route state → forbidden; evaluator is pure receipt-only.
16. **Order attack:** identical evaluations arrive in different collection order → same result/receipt identity.
17. **Legacy-label registration:** stale slot/channel label used as predicate authority → reject; implementation history is not semantic authority.
18. **Consumer demands nonempty:** implementation wants a predicate because a downstream schema expects one → preserve valid-empty; consumer must support zero predicates.

All hostile cases are closed by the authority contract without adding a predicate.
