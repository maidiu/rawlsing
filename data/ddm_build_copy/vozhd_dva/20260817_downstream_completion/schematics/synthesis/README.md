# Vozhd Schematic Synthesis

This directory is Vozhd-Dva-only adjudication space for reconvening breakout results.

For each seam, synthesis must record:
- competing proposed transformation equations;
- points of agreement;
- object-grain collisions;
- forward-ceiling versus backward-floor reconciliation;
- accepted preservation/uncertainty/authority law;
- rejected alternatives and why;
- resulting implementation obligations;
- adjacent seam changes caused by the ruling;
- acceptance tests that will prove the ruling in production.

## Chain rule

Adjudicate in upstream-to-downstream order unless two adjacent seams must be resolved together. Once a seam ruling is accepted, its output contract becomes the input assumption for the next seam.

Implementation workers receive only accepted synthesis plus the local canonical code/context they need. They are not asked to repeat the ontology debate while coding.
