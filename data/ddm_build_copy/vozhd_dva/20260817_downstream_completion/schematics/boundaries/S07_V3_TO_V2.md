# S07 — V3 → V2

**Question:** Given generated V3 actor state and event history, what read-only projection should V2 receive for phenomenology, memory presentation, self-narration, voice, and conversation without becoming causal authority?

## Fixed outside context
- V3 owns causal state/history.
- V2 owns phenomenological and conversational expression.
- Rendered prose cannot silently become source evidence or direct causal state mutation.
- User/environment interaction may return only as a typed event proposal for V3 mediation.

## Breakout perspectives
1. **Forward:** identify which generated V3 state/history is lawfully renderable and under what access/visibility constraints.
2. **Backward:** derive what V2 needs to express a coherent person without forcing V2 to reconstruct causal state.

## Primary adjudication targets
- read-only render-context grain and versioning;
- memory/access/salience/reliability constraints;
- public/private/intimate or equivalent register availability;
- uncertainty/ambiguity preservation;
- generated-state provenance versus rendered expression;
- typed interaction/event-proposal return path;
- explicit `causal_write_permission = false` semantics.
