# Schematic Transformation Layer

This directory is the Vozhd Dva workspace for reasoning about Rawlsing as a transformation chain before production implementation is authorized.

## Purpose

The unit of analysis here is not an isolated stage. It is a governed transformation across a seam:

`upstream authority → lawful stage intake → stage-specific operation → enriched stage output → downstream requirement`

Each session asks what the upstream pipeline has actually established, what the current stage is authorized to add, what meanings must survive unchanged, and what the next stage will require in order to operate without reconstructing lost semantics or inventing unsupported facts.

## Law

1. Downstream stages inherit lawful upstream information; they do not recreate governed identity that upstream already supplied.
2. A stage earns the right to add only the class of meaning assigned to that stage.
3. Upstream identity, lineage, epistemic state, uncertainty, negative authority, and distinctions needed later remain attached unless an explicit governed transformation says otherwise.
4. Unknown remains unknown until a stage with lawful authority can resolve it.
5. Forward reasoning and backward reasoning are both required:
   - forward: what can lawfully be produced from current inputs?
   - backward: what must the next stage receive to perform its job?
6. The seam contract is correct only where those two directions meet.
7. Schematic work is finite. It must terminate in implementable transformation obligations, explicit unresolved questions, and hostile examples; it may not become an open-ended ontology project.
8. Schematic workers are read-only against production semantics unless a separate assignment explicitly authorizes implementation.

## Promotion rule

A breakout result is advisory until Vozhd Dva reconciles it with adjacent seams and records an accepted ruling in `synthesis/`. Implementation packets may cite accepted synthesis rulings; they may not treat a worker-local schematic proposal as system law.
