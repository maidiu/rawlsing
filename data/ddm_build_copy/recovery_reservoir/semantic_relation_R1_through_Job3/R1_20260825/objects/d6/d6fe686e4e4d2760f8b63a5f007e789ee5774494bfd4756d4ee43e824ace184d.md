# Zero hidden dependency rule

A handoff may call itself **cognitively zero-loss** if a new chat can reconstruct purpose, state, method, corrections, exact next work and stopping rules from the enclosed bytes.

A handoff may call itself **physically self-contained** only if every artifact required for the claimed execution scope is enclosed or deterministically regenerable from enclosed bytes.

If a source/codebook/catalog/database/repo lookup remains external, it must appear in `EXTERNAL_SOURCE_DEPENDENCY_LEDGER.csv`. External-but-known is acceptable; external-but-hidden is not.

Therefore this handoff currently has:
- `COGNITIVE_ZERO_LOSS = PASS` for Parts A+B+C.
- `IMMEDIATE_TRUSTECOLOGY_CONTINUATION = PASS_WITH_SOURCE_ESCALATION_PATH`.
- `FULL_35_WAVE_RAW_SOURCE_OFFLINE_SELF_CONTAINMENT = PENDING/FAIL` until the explicit remaining source/catalog bytes are added.
