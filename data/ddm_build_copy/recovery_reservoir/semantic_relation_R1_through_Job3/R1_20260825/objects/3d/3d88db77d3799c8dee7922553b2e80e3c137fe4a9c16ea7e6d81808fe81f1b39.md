# C3b14 doctrine — larger-batch descriptive closure

This checkpoint changes cadence without loosening authority. The full 1,079-decision residual is first partitioned into a finite semantic-family census. Only the `HIGH_CONF_DESCRIPTIVE_CLOSURE` bucket is closed here.

`RR_NORM` is defined by R10 as a **norm / obligation / approval shore**. C3b14 therefore closes only functions whose governed proposition is descriptive of respondent state, experience, satisfaction, capability, performance, self-location, factual/temporal appraisal, or institutional role/power. It does **not** infer from broad R10G semantic-act labels alone.

Affect/favorability/liking is deliberately *not* closed in this checkpoint because the R10 definition includes an approval shore and those cases deserve separate boundary review. Likewise proposition endorsement, importance/essentiality, regime/policy preference, fairness/appropriateness, and social-acceptance/distance remain open.

Exact decision identity is `(source_family, wave, semantic_unit_id)`. Semantic-unit ID alone is forbidden after the R16C-H cross-wave bleed discovery.

Negative RR_NORM closure removes only impossible T06 norm-shore opportunities. It does not emit a T06 relation and does not authorize any relation-absence claim beyond the exact role decision.
