R7J **supersedes R7I as the controlling survey-DDM plan**. R7I remains immutable provenance. R7J does not authorize full production.

The survey-DDM spine is not a battery finder and not a correlation miner. It is a governed system for transforming heterogeneous survey questions into **structurally interpretable evidence about socially situated respondents**, while preserving source meaning, routing, measurement limits, non-observability, uncertainty, and the distinction between structure and personality.

## The most important R7J corrections

### 1. The DDM target is now an explicit authority surface

The recovered P1 material names sixteen structural-information requirements: generality/selectivity, conditional exception, principle/application, goal/means, commitment/cost, norm/conduct, general/subtype, institutional differentiation, reciprocity, explicit tradeoff, meaningful internal tension, routed contingency, boundary location, configuration breadth, target-condition interaction, and complementary-role convergence. These are **requirements**, not pre-approved relations. They tell candidate generation what distinctions are worth searching for and tell later layers what overclaims are forbidden.

### 2. “Full relation graph” now has a falsifiable denominator

The graph is complete only relative to a versioned relation-template/candidate-generation release. Candidate channels include source-native structures, governed semantic collisions/role pairs, authoritative hierarchies/matrices, and bounded recall aids. All candidates generated by those rules receive terminal ACCEPT / REJECT / BLOCKED dispositions. Negative/anti-join authority is preserved so rejected lookalikes are not rediscovered. **Arbitrary subsets of questions are never the denominator.**

R14/R15 and R6 remain important but bounded. Candidate generation must scan the broader P2/source-structure terrain, not treat the 435 R6 denominator as the maximum possible source structure.

### 3. Relation concept and implementation are separate

A portable concept such as `GOAL_MEANS` is not the same object as “these exact WVS W7 items instantiate that relation.” Each source-wave implementation preserves exact question implementations, item roles, routing, universe, completion law and measurement dependencies. Cross-source semantic analogy never joins respondents across surveys.

### 4. Respondent composability is a hard gate

Questions can exist in the same wave yet never be jointly observed because of split ballots, routed modules, country variants or universe restrictions. An implementation may therefore be semantically valid but `NOT_RESPONDENT_COMPOSABLE`. No V550J/configuration object may silently infer a join.

### 5. Association is optional enrichment

R7I wrongly made population association too central to base positioned evidence. The corrected rule is:

> A respondent's answers to a governed, composable relation implementation constitute a respondent configuration whether that pattern is common, rare, or statistically null in the population.

Population association can add typicality, cotravel or discovery context under E04/E07. It cannot create a relation, validate its semantic meaning, or suppress a directly observed configuration merely because it is rare.

### 6. The 10,477 “other” implementations cannot disappear

The 3,331 relational units and 2,525 structural-choice units remain useful workload cohorts, not a complete downstream-use census. R7J adds S00: an exact 18,276-row terminal use-disposition authority. Position, context, behavior/exposure, administration and other roles remain separate, and only the subset that can lawfully become relation endpoints receives additional semantic adjudication. This avoids both blanket exclusion and a fake new multi-thousand-row workload.

### 7. Capability is mapped before relation production

The static atlas is not a V553 afterthought. Once semantics, measurement, respondent structure, P5 placement and relation templates are accepted, S16 records for every one of the 35 waves what can be observed, partially observed, blocked or not observed. Only then is broad relation generation scoped. Temporal comparability remains a later T02 question.

### 8. P5 cannot become a second ontology

S08 owns semantic identity. P5 owns structural placement and applicability: strata relevance, multi-strata attachment, conditional structural role and horizon. If P5 work discovers a semantic error, it opens a semantic successor; it cannot mutate driver/facet identity in place.

### 9. Organization now includes primary artifacts and live state

The conceptual surface map is not enough. A01 tracks primary artifacts and supersession; A02 requires a read-only live repo/DB execution-state lock before mutation; A03 makes shadow install/differential/rollback mandatory. R7J still does **not** claim that every backup/duplicate in the user's entire Library has been classified.

## Workload honesty

Known semantic adjudication cohorts remain:

- 3,331 conservative relational semantic units (190 governed-anchor; 954 reviewed/nonfallback; 2,098 fallback-derived; 89 residual);
- 2,525 structural-choice/topology units.

R7J does **not** add an invented third giant number. S00 first measures which behavior/exposure/practice items among the remaining implementation lanes are lawful relation endpoints; S2B adjudicates only that discovered set.

## Operational sequencing

The execution program deliberately permits safe parallelism: live-state/foundation attestation, bounded R6/J shadow work, and semantic use/adjudication can proceed concurrently. Full 35-wave production remains blocked until S00/S08/S09, P4, respondent semantics, P5, requirements/templates, static capability, relation graph, J convergence and base respondent configuration evidence have passed their gates.

V552 is rerun **unchanged first** after full upstream production. Channel/contradiction inference is then separately accepted. Temporal comparability precedes V553. Downstream inter-strata mediation and V554+ remain registered but closed.
