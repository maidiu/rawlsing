# C3b17 RR_NORM endgame doctrine

`RR_NORM` is the **norm / obligation / approval shore** for T06. The approval shore is bounded: it includes approval, preference, permission, rejection, or normative criterion concerning an **actor, action, rule, role, policy, or social/political arrangement**. It does **not** automatically include mere liking/favorability, personal importance, perceived fairness, sympathy, confidence, performance evaluation, causal belief, expectation, self-reported commitment/cost, or generic outcome valence.

A broad semantic-act role, lexical cue, or proposition-endorsement label is never sufficient by itself. Exact source semantics control.

Positive RR_NORM does **not** emit a T06 relation; it transfers every exact R11 opportunity into actor-target-action link review. Negative RR_NORM retires only the impossible norm-shore path and creates no broader relation-absence claim.

Exact decision identity remains `(source_family, wave, semantic_unit_id)`; semantic-ID-only keying is forbidden. Member-complete source proof permits one decision to map to multiple exact current implementations.
