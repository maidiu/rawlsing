# Source Recovery / Library Search Law

The Rawlsing Library is not a flat set of standalone source files. Recent handoffs and reports are themselves resource indexes.

Before saying “the source is missing”:

1. Search the newest orientation/dependency ledger and ZeroLoss documents.
2. Search recent handoffs for exact Library file IDs, archive-internal locators, hashes and source-dependency maps.
3. Search later R13/R14 source-native reconciliation surfaces.
4. Search governed family deep catalogs and their source locators.
5. Resolve the actual questionnaire/codebook/native data bytes where required.
6. Use older QSM/historical mappings only to recall candidates, never to decide meaning.
7. Fail closed if proposition-defining source content remains unresolved.

A historical “external dependency” list describes the physical contents of that handoff at that time. It is not automatically the current Library availability boundary. Conversely, a deep catalog or source locator is not the same thing as having native bytes. State which kind of evidence you actually have.
