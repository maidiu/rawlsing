# Rawlsing/DDM — five-job mental model

1. **Know exactly what every survey question is.** Source text, wave, implementation identity, response options, routing/applicability, continuity and proposition identity.
2. **Know what structural information every useful question can measure.** Driver/facet/role/target/condition/action/topology/context/behavior boundaries.
3. **Know which questions can lawfully be interpreted together.** Typed relations such as principle/application, goal/means, commitment/cost, norm/conduct, target selectivity and condition sensitivity.
4. **Apply those governed relations to actual respondents.** Direct same-respondent configurations first; population association is optional enrichment, never semantic authority.
5. **Aggregate governed configuration evidence into structural pressure through time and eventually Rawlsing runtime.** V551/V552/V553 and later systems remain downstream consumers, not upstream authority.
