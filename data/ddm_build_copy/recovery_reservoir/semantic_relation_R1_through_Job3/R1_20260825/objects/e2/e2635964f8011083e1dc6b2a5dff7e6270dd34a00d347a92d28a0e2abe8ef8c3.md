# R10E P2 S2/S2B Worker Protocol

## Jurisdiction
Adjudicate only the exact implementation IDs in the supplied immutable P2 workbench. The work combines two pre-graph obligations while preserving their distinct authority:
- **S2**: structural-choice / non-scalar / response-topology authority.
- **S2B**: behavior/exposure endpoint authority.

This is **not Job 3 relation adjudication**. Do not create cross-question relations, J-families, respondent joins, P5 placement, P4 portability authority, or runtime permissions.

## Governing laws
1. Source/native meaning outranks historical mappings, QSM labels, lexical similarity, embeddings, and empirical association.
2. Fail closed when required source authority is absent or conflicting.
3. Preserve rankings, multi-select structures, nominal choices, explicit tradeoffs, and other non-scalar meanings. Never force a signed or interval scalar representation because downstream code prefers one.
4. Behavior remains behavior; exposure remains exposure. Do not convert either into a norm, attitude, motive, personality trait, or latent construct.
5. S2B terminal disposition is exactly one of `ACCEPT_ENDPOINT`, `REJECT_ENDPOINT`, `BLOCKED`. An accepted endpoint must state actor (when applicable), target/object, and action/exposure semantics explicitly enough for later governed relation-template matching.
6. S2 topology disposition is exactly one of `PRESERVE_SOURCE_TOPOLOGY`, `REVISE_TOPOLOGY`, `BLOCKED`. `REVISE_TOPOLOGY` requires source evidence that the current label is materially wrong/incomplete. Record source-native topology descriptively; do not invent numeric portability.
7. A `blocked_response_authority_gap` is **not permission to guess** and is not itself an automatic endpoint rejection. Retrieve the exact questionnaire/codebook/governed deep-catalog response evidence. You may use recovered source evidence to adjudicate S2/S2B semantics, but you may not install or silently repair P4/response-authority state. Record the evidence locator. If the response meaning needed for the decision still cannot be governed, return `BLOCKED`.
8. Do not mutate R9D, R6, P3/P3C, R7J, R10C, R10D, R10E, or R10E P1 in place. Return successor decisions only inside the P2 worker namespace.
9. Do not silently alter exact question meaning, source-wave identity, response options, universe status, or routing status.
10. Non-applicability, missingness, refusal, don't-know, routed-out, and neutral states remain distinct when the source distinguishes them.
11. Routing/composability and semantic relation truth remain separate. This worker may preserve routing evidence or flag a routing blocker but cannot create/erase Job-3 relation truth.
12. A worker may identify a likely upstream defect, but must record it as `BLOCKED` / `worker_blocker_reason`; it may not repair another authority namespace.

## Evidence procedure
For each row:
1. Read the embedded R10D exact question text, response options, topology, semantic lane/role/subrole, routing/universe status, and authority status.
2. Where insufficient—especially `S2_SOURCE_TOPOLOGY_REVIEW` or `blocked_response_authority_gap`—retrieve the source-native questionnaire/codebook or current governed deep-catalog evidence for that exact family/wave/variable.
3. Compare source response structure with the current R10D topology.
4. For S2, disposition topology without scalar coercion.
5. For S2B, decide whether the behavior/exposure item is a lawful future relation endpoint; if accepted, make actor/target/action or exposure semantics explicit.
6. Cite evidence artifact/locator in `worker_evidence_refs`.
7. State the narrow evidence ceiling and rationale. No person-level moral, causal, latent-trait, or cross-question inference.

## Required return
Return the completed workbench CSV with every assigned row exactly once, no extra IDs, all applicable decision fields terminal, plus `<WORKER>_COMPLETION_REPORT.md`, `<WORKER>_BLOCKER_LEDGER.csv` (header-only if none), and validation JSON proving exact ID coverage with zero duplicates/extras/missing. Central integration must validate cross-worker consistency before any successor authority freeze.
