# Worker Economics and Central Narrowing State

## Decision

Do **not** launch semantic workers before the central narrowing denominator is finished.

The expensive-looking theoretical pair spaces are not the actual review workload. Code should use source/wave, current meaning, exact structures, targets, actor/action, routing, and known authority to create finite recall queues. Only the unresolved semantic tail is worker-eligible.

- O10 input-contract schema
- 18,276-row spine
- authority joins and lane provenance
- candidate/recall queue generation
- cross-rule dedupe and packet/hyperedge compression
- O11 compiler
- O12 compiler
- independent completeness validator
- final reconciliation and completion claim

## Worker threshold doctrine

Do not pre-commit to a worker count. After T03–T11 narrowing and cross-rule dedupe:

- small, tightly interdependent queue → Vozhd adjudicates centrally;
- medium/large independent queue → immutable sharding by candidate IDs with one shared contract;
- ontology/schema design, validation, and final reconciliation remain central regardless.
