# T06-GATE — Correctness, recall, and non-arbitrary pruning before full C4 dispatch/promotion

## Current concern
T06 is narrow relative to the attitude-cloud engine, but it is still a real and useful relation family. Across 35 waves, a result surface with essentially no novel positives cannot be accepted merely because the rule is strict. **We do not impose an arbitrary positive-rate quota, but near-zero yield is a mandatory recall/completeness alarm.**

Current observations:

- old R15 T06: 79,148 atoms; 0 ACCEPT, 1 PARTIAL, 77,987 REJECT, 1,160 BLOCK — quarantined because R15 had a dispatch/admissibility defect;
- current governed C4 pilot: 222 exact opportunities, 222 negative, 0 positive;
- sealed R6 contains **2 known positive T06 relations**, both EVS 1999:
  - `v281` help elderly: moral duty ↔ `v278` prepared to help elderly;
  - `v286` help immigrants: moral duty ↔ `v279` prepared to help immigrants.
- the C4 worker packs include these R6 positives as calibration precedent, but the already-governed canaries are not part of the open C4 assignment denominator. Therefore their mere presence in the pack does **not** prove that the current discovery/denominator construction would rediscover them independently.

## Gate 1 — doctrine replay of sealed positives
Using the **current** C3→C4 doctrine and current governed fields, independently replay both sealed EVS 1999 positives. Require **2/2 positive** under explicit actor, target, action-domain and scope reasoning. No legacy verdict may be used as the decision shortcut; legacy authority is the expected answer for recall testing.

If either fails, C4 doctrine/normalization is overconstrained or semantically mismatched and must be redesigned before full dispatch.

## Gate 2 — denominator recall, not just verdict recall
Verify that an independent reconstruction from the 18,276 implementation spine + exact source structure + current semantic authority would place both canaries into the discoverable T06 opportunity universe before inherited R6 authority removes them from the open queue.

This detects a candidate-generation failure that a verdict-only test would miss.

## Gate 3 — 35-wave source-native T06 opportunity audit
For every active wave, independently inspect/reconstruct whether the source contains plausible T06 structures of at least these forms:

- stated moral/social/political norm ↔ stated intention/expected conduct;
- norm/obligation/permission/prohibition ↔ realized respondent conduct where the source measures both;
- policy/conduct norm with respondent/general-person scope ↔ member/respondent conduct where actor-scope conversion is explicitly warranted;
- source-native paired/battery structures that directly couple what ought to be done with whether/willingness/how the action occurs.

Report per wave:

- eligible norm-role units;
- eligible conduct/intention endpoints;
- source-native candidate links recovered independently;
- current C3/C4 denominator links;
- exact overlap / missed candidates;
- reason for every zero-opportunity or zero-positive wave;
- authority gaps vs true negatives.

The audit must search source structure/ancestry and cannot use lexical similarity, shared topic, driver/facet or co-presence as relation authority. Those may be recall aids only.

## Gate 4 — actor/target/action granularity attack
Hostile-QA whether current match rules are too literal. In particular, distinguish:

- true actor mismatch;
- general-person norm → respondent-as-member compatibility;
- respondent intention → respondent realized behavior;
- target aliases / general↔subtarget relationships already governed elsewhere;
- action-domain equivalence vs merely related political topic.

Known-positive R6 canaries define minimum precedent: a moral-duty item and a respondent willingness item can form lawful T06 even though the questionnaire wording is not a literal duplicated actor/action sentence.

## Gate 5 — mixed pilot before six-worker scale
Before full C4 dispatch (or before promotion if workers have already run), use a deliberately mixed pilot containing:

- both sealed positives;
- obvious hard negatives;
- actor-scope edge cases;
- target-hierarchy edge cases;
- intention vs realized-conduct cases;
- source-native likely positives newly found by Gate 3.

Require correct positive recall, negative precision, and `BLOCKED` treatment for genuine authority insufficiency.

## Dispatch posture
**HOLD full C4 dispatch/promotion until this gate passes.** Existing C4 packs remain immutable diagnostic/possibly reusable artifacts. If the gate shows that the denominator and doctrine are sound, they may be released (or minimally successor-wrapped) without rebuilding unnecessarily. If it shows missing opportunity classes or overstrict matching, regenerate C4 before asking six workers to grind through 30,268 rows.

## App-level interpretation
T06 is **not** the engine that discovers conditioned attitude clouds; V550/V550J do that empirically. But T06 must still correctly identify the norm↔conduct relations it claims to govern. A sparse *true* T06 network is acceptable; an arbitrarily sparse network caused by broken recall, missing endpoints, bad actor normalization, or overstrict matching is not.
