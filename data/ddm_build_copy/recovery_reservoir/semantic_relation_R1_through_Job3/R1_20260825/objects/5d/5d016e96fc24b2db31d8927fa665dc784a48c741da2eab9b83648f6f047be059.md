# C4 worker return contract

Return two primary files.

## 1. `NORM_CONTRACT_RETURN.csv`
One row for every assigned norm contract. Immutable identity/text fields must remain byte-value identical to the supplied template.

Fill:
- `norm_contract_disposition`: `EXPLICIT_ACTOR_TARGET_ACTION`, `NO_EXPECTED_CONDUCT_CONTRACT`, or `AMBIGUOUS_NEEDS_VOZHD`
- `norm_actor`, `norm_target`, `norm_action`: concise source-grounded contracts; use `NONE_GOVERNED` when the source does not govern that dimension.
- `norm_modality_or_operator`
- `contract_basis`
- `contract_confidence`: `HIGH`, `MEDIUM`, `LOW`

Do not collapse a generic respondent evaluation into an actor/action norm.

## 2. `C4_WORKER_RETURN.csv.gz`
Exactly one row for every assigned opportunity.

Allowed match values: `MATCH`, `MISMATCH`, `UNKNOWN`.

Allowed dispositions:
- `POSITIVE_T06_RELATION`
- `NEGATIVE_T06_RELATION`
- `BLOCKED_NEEDS_VOZHD`

Rules:
- positive => all three match fields `MATCH`;
- negative => at least one `MISMATCH`;
- blocked => no `MISMATCH` and at least one `UNKNOWN`;
- Stage-1 `AMBIGUOUS_NEEDS_VOZHD` => all its opportunity rows BLOCKED;
- Stage-1 `NO_EXPECTED_CONDUCT_CONTRACT` => all its opportunity rows NEGATIVE and `action_domain_match=MISMATCH`;
- all positive and blocked rows require `manual_review_flag=true`;
- a row with `manual_review_flag=false` must cite a nonblank `propagation_rule_id`.

`prohibited_inference_ack` must be exactly:
`NO_LEXICAL_TOPIC_DRIVER_FACET_OR_COPRESENCE_AUTHORITY`

## Propagation ledger
Every used `propagation_rule_id` must appear exactly once in `PROPAGATION_RULE_LEDGER.csv` with exact source family, wave, semantic unit, selector, governed basis, affected count, exclusions, hostile boundary test, and result type.

Missing authority => BLOCK, never REJECT/negative.
