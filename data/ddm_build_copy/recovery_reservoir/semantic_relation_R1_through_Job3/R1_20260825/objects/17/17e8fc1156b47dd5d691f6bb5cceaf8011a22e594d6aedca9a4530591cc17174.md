# 1. Project architecture

Rawlsing generates historically pressured personae as flows through nested and adjacent structural-relational strata. The DDM is the empirical pressure engine that produces confidence-marked, provenance-bearing distributions, determinicity indices, branch structures, and attitude co-travel surfaces.

The strata model is:

```text
planetary
→ imperial_block
→ nation_state
→ sub_national_region
→ sect_ethno_class
→ party_movement
→ neighborhood_household
→ family
→ self
(+ absolute_horizon as internal/non-surface moral-meaning pressure)
```

The lawful path is:

```text
raw response
→ response-option provenance/normalization
→ question structural mapping
→ answer distribution
→ position-conditioned determinicity
→ outlier branches
→ secondary splitters
→ recursive branches
→ co-signatures / attitude clouds
→ structural evidence atoms
→ parent/coparent priors
→ temporal pressure fields
→ persona recursion
```

The forbidden shortcut is:

```text
raw survey variable → persona prose
```

# 2. Non-negotiable separations

Codex must preserve these separations everywhere:

```text
question_structural_mapping ≠ response_option_map
response_option_map ≠ determinicity_index
determinicity_index ≠ evidence_atom
evidence_atom ≠ persona
demographic probability ≠ personhood
```

Consequences:

1. A mapped variable does not imply that its numeric answers are understood.
2. A response option label does not imply an attitude without structural mapping.
3. A demographic split does not imply essence.
4. Outliers are not noise. Outliers are central.
5. Missingness and refusal are not ordinary substantive answers.
6. Attitude clouds must never include demographic variables.
7. Within-country analysis must never rank `country_code` as a predictor.
8. Pooled/regional analysis may use `country_code` only as contextual-country signal.
9. Runtime/persona generation must consume V551/V552/V553 curated surfaces, not raw survey tables.

## 8.8 Parser rules
