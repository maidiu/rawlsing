## 4. Safe efficiency / batching law

You may use code to census, group, propagate, and fill rows, but code may **never manufacture semantic authority** from keywords, lexical similarity, embeddings, shared driver/facet/domain, proximity, or source co-membership.

Safe propagation is allowed only after proving an exact governed equivalence class. Examples:
- one source-wave-semantic RR_NORM decision may propagate to all T06 X-endpoint opportunities carrying that exact `(source_family,wave,semantic_unit_id)` norm candidate;
- an actor-class mismatch may propagate over a set of endpoints only when every endpoint in the set has the same governed actor contract relevant to the norm;
- a source-native matrix/object relation may propagate only when exact source structure proves every member/cell identity.

For every propagated rule, keep a machine-readable rule ledger with: rule ID, exact selector, governed basis, affected atom count, exclusions/exceptions, and hostile boundary checks. Save as `RETURN/PROPAGATION_RULE_LEDGER.csv`.

Never let a bulk rule cross source-wave boundaries or semantic-unit identity boundaries unless the source-governed structure itself explicitly authorizes that equivalence.
