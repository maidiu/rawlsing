# Rawlsing Native Questionnaire Structure Authority R1

This package flattens the native questionnaire/codebook PDF layer once so T06 source-first workers can work from CSV/JSON rather than repeatedly opening PDFs.

## Authority law
- Native official questionnaire/codebook text governs shared stems, batteries, question order, interviewer/programmer instructions, routing/skip/filter/split conditions, country/applicability conditions, inherited wording, and respondent/actor scope.
- The 18,276-row Rawlsing implementation spine supplies exact downstream IDs only. Its existing semantic/routing classifications are diagnostics here, not source authority.
- `SOURCE_NATIVE_STRUCTURE_OBJECTS_R1.csv` preserves exact source excerpts. Its object-type labels are navigational heuristics, never relation truth.
- Existing governed R11 source objects and memberships are preserved intact in separate tables.
- `SOURCE_CONTEXT_UNRESOLVED_R1.csv` is an escalation ledger, not an absence claim. Workers search the flattened page-text ledger first; original PDFs are last-mile evidence only.

## Files
1. `ACTIVE_35_WAVE_NATIVE_SOURCE_REGISTRY_R1.csv`
2. `SOURCE_DOCUMENT_REGISTRY_R1.csv`
3. `NATIVE_SOURCE_PAGE_TEXT_R1.jsonl.gz` — page-by-page exact extracted text for all native PDFs.
4. `SOURCE_NATIVE_STRUCTURE_OBJECTS_R1.csv` — source-text sections/stems/batteries/routing/universe objects.
5. `IMPLEMENTATION_SOURCE_CONTEXT_R1.csv` — 18,276 implementation IDs joined to their native document set, explicit source locators where already proven, and R11 memberships.
6. `EXISTING_GOVERNED_R11_SOURCE_OBJECTS_R1.csv` + membership table.
7. `SOURCE_CONTEXT_UNRESOLVED_R1.csv` — last-mile page binding queue.
8. `VALIDATION_R1.csv`, `SUMMARY_R1.json`.
