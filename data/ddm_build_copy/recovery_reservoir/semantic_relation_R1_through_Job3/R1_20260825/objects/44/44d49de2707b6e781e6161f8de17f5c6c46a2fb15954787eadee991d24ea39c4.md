## Important limitation
The preliminary deterministic pass does **not** claim that every implementation is already bound to an exact PDF page. Rows lacking an explicit current page locator or governed R11 membership remain in `SOURCE_CONTEXT_UNRESOLVED_R1.csv`. That is an indexing gap, not a source-absence claim. Workers should search the flattened page-text/FTS resource first and open a PDF only if a substantively relevant row remains unresolved.

## Authority hierarchy
1. Native questionnaire/codebook text = structural authority.
2. Existing governed R11 source-object membership = preserved governed ancestry.
3. Rawlsing implementation spine = exact downstream IDs / identity.
4. Heuristic structure-object labels = navigation only; exact source excerpts remain authoritative.

## Downstream use
