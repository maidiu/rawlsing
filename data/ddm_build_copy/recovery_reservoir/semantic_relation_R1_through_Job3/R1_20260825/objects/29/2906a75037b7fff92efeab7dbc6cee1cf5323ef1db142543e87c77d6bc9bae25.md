# T07 Doctrine Extract — R3

T07 uses existing P3/P2 governance rather than inventing a new taxonomy.

1. `NESTED_TARGET_RELATION` is a typed non-connective relation fact.
2. Broader-than/narrower-than is directional.
3. A path never creates a new direct pair authority.
4. Nested targets ordinarily remain separate families connected by a target-hierarchy hyperedge.
5. Target hierarchy is broader/narrower target families; it carries no causal authority.
6. P2 `TARGET_RELATION_COORDINATE_ONLY` rows whose status says nested OR functional are not automatically directional T07 truth.
7. Exact source co-membership and lexical generality are evidence/recall only.
