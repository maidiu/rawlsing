# Rule contracts

- **T03 PRINCIPLE↔APPLICATION** — general principle + specific application tied to the same narrow principle. Shared topic is insufficient.
- **T04 GOAL↔MEANS** — explicit end + mechanism tied to that same end. Plausible usefulness is insufficient.
- **T05 COMMITMENT↔COST** — commitment + explicit personal/fiscal/risk/autonomy burden tied to that commitment.
- **T06 NORM↔CONDUCT** — governed norm plus either (A) stated/intended/expected conduct or (B) O04-authorized realized behavior/exposure, with actor, target, action-domain and modality/scope handled explicitly. Both branches are mandatory.
- **T07 GENERAL TARGET↔SUBTARGET** — explicit broader/narrower target authority; lexical generality is insufficient.
- **T08 INSTITUTION CLASS DIFFERENTIATION** — exact institution targets with governed controlled class mapping; class does not replace target.
- **T09 RECIPROCAL ROLE REVERSAL** — same narrow proposition/action with actor/recipient direction explicitly reversed.
- **T10 TARGET×CONDITION MATRIX** — explicit matrix cell membership with governed target and condition dimensions; a one-dimensional battery is not a matrix.
- **T11 COMPLEMENTARY ROLE CONVERGENCE** — differentiated bounded roles converging on one narrow proposition; no latent-scale/additivity inference.

Across all rules, source-native structure, exact question text, routing/universe compatibility, sealed R6 authority, and current governed mappings outrank recall. Driver/facet/domain/lexical similarity are recall only.
