# Rawlsing O10→O11→O12 Input-Contract Coverage Audit — R1

## Verdict

**FAIL — O12 R2 is not proven production-complete as the Job-3 candidate denominator.**

The user's memory was correct: **semantic coverage was completed.** R9D closed the relational Job-2 semantic meaning denominator at **3,324 / 3,324 with 0 unresolved**. R10G then gave those units terminal S08 coordinates. The failure is downstream: O10 T03–T11 requires *relation-role/link structures* that are not represented as a comparable governed input layer. O11 therefore uses proxies for many templates, and the old O12 generator either excludes those proxy scopes, blocks them, or searches only bounded R14/R5 source-object terrain.

This is primarily a **contract-integration / bridge failure**, not evidence that the surveys lack these relation types and not a reason to redo R9D semantic meaning.

Those are all real accomplishments. They are not the same thing as a full O10 relation-role bridge.

## The direct schema mismatch

O10 requires explicit structures such as:

- principle role ↔ application role;
- goal role ↔ means role + common end;
- commitment role ↔ cost role + semantic tie;
- norm role ↔ conduct endpoint + actor/target/action identity;
- general target ↔ subtarget hierarchy;
- institution target ↔ governed institution class;
- reciprocal role identities + direction;
- target×condition matrix object + cell provenance;
- complementary role set + common narrow proposition.

The current R10G registries do **not** expose those structures as governed fields:

- `R10G_ROLE_REGISTRY.csv` contains 10 broad semantic roles, not O10 relation roles.
- `R10G_TARGET_REGISTRY.csv` columns are `target_id, use_count, driver_ids, facet_ids, example_semantics, authority_status` — there is no parent/subtarget or institution-class field.
- `R10G_CONDITION_REGISTRY.csv` columns are `condition_id, use_count, driver_ids, facet_ids, example_semantics, authority_status` — there is no matrix-object/cell-provenance field.
- O04 actor/target/action fields exist on behavior endpoints, but **0 / 2,113 accepted endpoints share a `sem__audit_unit_id` with the relational semantic terrain**. There are **594 normative semantic units**, but no governed norm→endpoint linker.

- T04: same driver/facet plus goal/means-ish keywords;
- T05: same driver/facet plus cost/sacrifice-ish keywords;

Those are legitimate *terrain locators*. They are not proof that the underlying relation opportunities were exhaustively represented.

## What O12 actually did

The inherited O12 generator treated T03–T08 as a **generic partial-terrain** pass. It did not construct full relation-role authority. In particular:

- T03/T04/T05 proxy scopes were ledgered and excluded for lacking the exact role/link that the input schema does not contain;
- T06 used wave-level norm/endpoint co-presence and excluded it for lacking actor/target/action linkage;
- T07 used lexical general-target signals and excluded them for lacking hierarchy;
- T08 used trust/institution proxy terrain;
- T09 emitted nothing because O11 blocked every cell;
- T10 explicitly emitted no novel direct matrices because no matrix authority surface had been installed;
- T11 searched only complete R14 source-native objects plus R6 recurrence.

R2 subsequently repaired T12 and T13, but it **inherited** the T03–T11 candidate rows and tried to establish rare-rule closure via the bounded R5→R6 source-object chain. That closure is not sufficient for a production denominator.

## Hard proof that R14/R5 closure cannot establish all-rule completeness

The accepted R6 authority includes relation construction classes that are **cross-object**:

- T06 NORM_EXPECTED_CONDUCT: **2 / 2** accepted relations are `CROSS_OBJECT_GOVERNED_ALIGNMENT`.
- T09 RECIPROCAL_ROLE_REVERSAL: **1 / 1** is cross-object.
- T10 TARGET_CONDITION_MATRIX: **11 / 14** are cross-object.

A closure proof based on source-native R14/R5 objects therefore cannot even represent the construction class used by the known positives for those rules.

The older control architecture already warned that the full candidate generator must scan the **broader P2/source-structure terrain**, not treat the 435-object R6/R5 denominator as the maximum possible structure universe.

## Key causal findings

### T01/T02

These are the only relation classes whose O10 prerequisites closely match the fields R10G actually installed: predicate/proposition, target and explicit condition. Their much higher discoverability is therefore expected from the schema itself. That does **not** prove their exact counts are perfect, but it explains why they can be generated directly while other templates cannot.

### T03/T04/T05

Semantic meaning is present, but the **relational role pairing** is not. A question can be governed as a `NORMATIVE_OR_POLICY_STANCE` or `EVALUATIVE_JUDGMENT` without the system saying whether it is the *goal*, *means*, *general principle*, *specific application*, *commitment*, or *cost-bearing application* in a relation with another question.

### T06

This is the cleanest interface failure. The norm side and conduct side were deliberately governed in separate semantic jurisdictions. O10 expects a bridge; no such bridge was installed. O11's same-wave co-presence proxy cannot substitute for it.

### T07/T08

Target identity exists; **target taxonomy/class identity does not**. That leaves O11 using lexical general-target signals and trust/institution heuristics where O10 requires authoritative hierarchy or institution class mapping.

### T09

The absence is **manufactured by the capability gate**: O11 explicitly has no safe reciprocal-role proxy and therefore blocks all 35 wave cells. R5 nevertheless contains 110 reciprocal-role discovery locators and R6 contains one accepted cross-object reciprocal relation. Zero new T09 is therefore not evidence of corpus absence.

### T10

Target and condition coordinates exist, but **matrix identity does not**. O11 finds 65 matrix-like terrains, while O12 refuses all novel direct matrices. Known R6 authority shows matrix relations are often cross-object, so source-object closure is structurally insufficient.

### T11

This is partially representable with broad canonical roles + R14 source structure, which is why R6 already has many T11s. But the current generator is not exhaustive for authority-supported complementary roles across structures.

### T12/T13

The targeted R2 repairs remain useful. This audit does not revoke their local logic; it revokes the claim that repairing them made the **whole** T01–T13 denominator complete.

## Correct repair boundary

**Do not reopen R9D semantic meaning. Do not redo R10G wholesale.**

Build one append-only **S14 relation-role bridge authority** over the already-completed semantic/source substrate. It should expose, where evidence permits:

1. principle/application role links;
2. goal/means/common-end links;
3. commitment/cost links;
4. norm↔conduct actor/target/action links between R10G semantic units and O04 endpoints;
5. target hierarchy and institution-class mappings;
6. reciprocal role identities/direction;
7. matrix identity/dimensions/cells/provenance;
8. complementary-role alignment and narrow proposition.

Inputs should be: R9D terminal meaning, R10G coordinates, R10F O03 topology, R10F O04 endpoints, the broader P2 source-structure terrain, R14, R6 positive/negative authority, and legacy QSM/structural-review material as **recall/evidence only**.

Then rebuild O11 from the bridge, and only then rebuild O12.

This is a **reconciliation/bridge job**, not a new 18,276-question semantic read.
