# 11 — ACCEPTANCE & SEMANTIC RECONSTRUCTION GATE

## 1. Definition of done

The clean machine is not done when all modules exist, CI is green, or a demo produces plausible output.

It is done when the whole system is semantically closed, replayable within its lawful claims, and every terminal capability can be traced through exact authority and data lineage without illicit inference.

## 2. Required final proofs

### A. Substrate proof

Prove the production-equivalent incoming source can be represented under the frozen physical substrate contract without loss of any required C11/terminal meaning.

Preserve all remaining populated-data unknowns honestly if production-equivalent access is unavailable.

### B. DAG proof

For every canonical object:

- exactly one semantic owner;
- every runtime/authoring/audit consumer registered;
- no required consumer starved;
- no forbidden edge reachable;
- no object retained solely as transport;
- conditional semantic transforms invoked only when their semantics are required.

### C. Source-universe proof

Prove:

- distinct universes remain distinct by default;
- respondent linkage never inferred from labels;
- pooling/composition requires explicit authority;
- actor comparability is independent authority;
- conflicting/noncomparable source states survive.

### D. Negative-authority proof

Prove typed distinctions survive end to end where relevant, including:

- denied;
- not applicable;
- valid empty;
- observed zero;
- zero support;
- low support;
- missing authority;
- unknown;
- noncomparable;
- integrity failure;
- stale/inapplicable V3 intake.

No generic null/false/zero may silently replace them.

### E. Reference/replay proof

For each terminal structural resolution or V3 transition that relies on upstream material, prove exact immutable references to the required producer and authority chain.

Historical replay may not use mutable latest/current authority.

Broken required content/hash/reference fails closed.

### F. Actor/world noncollapse proof

Prove mechanically:

- empirical fact does not become structural fact without admission;
- discovery receipt does not become structural truth;
- PSEPF does not enter V553-V558 structural repository lane;
- comparator receipt is not a developmental prior;
- PSEPF mass/modal/rank does not become belief/response/identity/memory/knowledge/psyche directly;
- ResolvedStructuralContext does not become persona/voice directly;
- V2/app cannot dereference opaque upstream evidence as expression authority;
- same lawful prior context may yield divergent actor lives under V3 history/randomness while each exact history remains replayable.

### G. Standalone repository proof

Where the final architecture requires standalone V558 repository/resolution, remove raw producer directories and prove exact lawful resolution using packaged producer material or immutable hash-bound locators.

Repository presence never implies runtime permission.

### H. Terminal capability proof

Prove at least the accepted terminal services:

1. autonomous forward social discovery;
2. reverse positioned-subject empirical possibility inference;
3. structural/stratal field production and resolution;
4. lawful integration into V3 developmental world;
5. V2/application expression only from actor-accessible truth.
