## Activation prohibition

No placeholder or anticipated architecture values may be used in an activation receipt.

Every SHA/version/hash must refer to accepted repository authority or an explicitly governed immutable external source identity.

The G2 populated-data receipt may not be replaced by schema inference or a synthetic fixture. If populated access is unavailable, activation remains blocked unless a higher authority explicitly narrows the implementation claim and records the permanent external constraint.

If final architecture has not closed, the receipt cannot lawfully exist.
