# 08 — BUILD WAVES & GOLDEN FIXTURE DOCTRINE

## 1. Objective

Compress elapsed implementation time without weakening semantic control.

The unit of scheduling is the **independent work front**, not the worker count and not historical stage number.

## 2. Wave construction

A work front may open when:

- its governing architecture is frozen;
- required substrate contract is frozen;
- required input/output interfaces are frozen;
- unresolved sibling output is not needed to define its lawful behavior;
- required hostile fixtures exist or can be prepared without deciding missing architecture.

Multiple fronts open simultaneously whenever these conditions hold.

## 3. Legitimate serial barriers

Serial execution is required only for actual information dependencies, such as:

- physical substrate contract before services that depend on its grain;
- shared interface contract before independent producer/consumer implementation;
- semantic producer object before downstream behavior whose lawful meaning cannot be specified without it;
- whole-machine integration acceptance before dependent waves launch from the new canonical SHA;
- architecture closure before production implementation.

Historical `V550 -> V551 -> ...` numbering is never itself a serial barrier.

## 5. Golden hostile fixture

G5 owns exactly one canonical miniature empirical world for shared development/testing, versioned and content-addressed.

It must contain enough complexity to invalidate simplistic assumptions.

Required dimensions include:

- at least two source universes with overlapping labels but distinct identities;
- at least one authorized and one unauthorized cross-source relationship;
- repeated respondent events;
- multi-select response;
- ranked or ordered component if supported by source family;
- question with routing/ineligible cases;
- DK/refusal/not-asked/unknown distinctions;
- weighted and unweighted measures;
- observed zero and zero-support as distinct states;
- low-support case;
- conflicting/noncomparable source evidence;
- temporal comparable and noncomparable cases;
- source revision/historical authority version;
- minority/multimodal/J-way empirical configuration;
- StructuralEmpiricalAdmission positive and denied cases;
- direct V554 and V553-required structural cases;
- exact V555 route case;
- V556 multi-route interaction case;
- V557 denied publication case;
- V558 standalone lookup case;
- actor objective-fact comparator success and failure;
- PSEPF source-disagreement case;
- V3 stale/intake denied case;
- intentionally broken content reference/hash.

## 6. Fixture immutability

Workers may not privately modify the canonical fixture.

A missing fixture capability is a G5 fixture-change request. Fixture changes are versioned and impacted workers are refreshed through G6.

Local supplemental fixtures are allowed for local mechanics but cannot substitute for required canonical hostile fixtures.

## 7. Calibration shots

Before mass integration, prove two end-to-end slices.

### Structural calibration

Use one admitted structural fact through every actually required accepted boundary to `ResolvedStructuralContext`, then prove V3 receives only the lawful structural context interface.

### Reverse possibility calibration

Use one actor objective-fact snapshot through comparator -> exact query -> source-indexed PSEPF -> thin V3 intake. Prove no field geometry becomes actor state merely by crossing the boundary.

## 8. Parallel sub-Vozhd pattern

Where a semantic organ contains several independent implementation problems, one domain Vozhd may create sub-Vozhds. Example:

```text
STRUCTURAL VOZHD
    +-- TEMPORAL/AFFORDANCE SEAM VOZHD
    +-- ROUTE/TOPOLOGY VOZHD
    `-- PUBLICATION/REPOSITORY VOZHD
```

A sub-Vozhd owns synchronization of its rabochii and emits one harmonized return upward.

The parent domain Vozhd remains responsible for cross-subcommand consistency.

## 9. No big-bang merge

Parallel work is integrated in tested tranches as soon as its dependency front is complete and reconciled. The campaign does not wait until every worker finishes and attempt one giant reconciliation.
