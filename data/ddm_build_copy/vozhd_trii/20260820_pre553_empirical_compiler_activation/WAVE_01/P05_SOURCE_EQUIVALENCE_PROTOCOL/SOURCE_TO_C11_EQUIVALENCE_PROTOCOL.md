# SOURCE→C11 EQUIVALENCE PROTOCOL

## 1. Purpose and jurisdiction

This protocol governs populated, per-source certification that a concrete source/release/universe has been preserved in C11 with sufficient source-native semantic fidelity for the retained D12/D13 replay frontier.

It is non-dispositive inspection law. It does not select a storage engine, change D13/D15 semantics, create runtime, authorize source pooling, or authorize source retirement.

## 2. Certification unit

The indivisible certification unit is:

`source_raw + source_release/instrument + raw_wave + canonical_wave + country/geography + sample/universe identity + source_snapshot_set`

A certification receipt MUST bind an exact `EmpiricalUniverse` identity and exact immutable source snapshot identity. Canonical aliases are additive; they may not replace source-native identity.

A certification for one release is not inherited by another release, wave, country, source alias, harmonized universe, or rebuilt C11 content identity.

## 3. Finite terminal states

Every attempted source/release certification returns exactly one state.

### `CERTIFIED`

Issue only when all mandatory evidence is available and every applicable proof obligation passes.

Minimum closure:

- D13B P01–P20: all applicable `PASS`;
- D13 M01–M18: every required information class physically present or immutably/exactly dereferenceable;
- D12/D13 T01–T18: every frontier-required replay fixture passes;
- source-native semantics retained alongside canonical semantics where both carry information;
- zero unauthorized defaults, coercions, fuzzy mappings, inferred topology, inferred routing, inferred weights, or source pooling;
- deterministic replay proven from identical governed inputs;
- final logical semantic integrity hash matches only after the dimensional proof succeeds.

### `FAILED`

Return when required evidence exists and proves a contradiction. Examples:

- source and C11 respondent sets differ;
- event multiplicity or topology is lost;
- routing or risk-set members differ;
- typed absence is collapsed;
- raw or weighted support differs under the same governed query;
- weight basis/value/status differs;
- source/raw-wave/country identity is collapsed;
- coordinate value/unit/taxonomy/effective-time semantics differ;
- predicate/AST/target identity differs;
- branch or k-way incidence differs;
- authority identity differs;
- illegal default/coercion occurs;
- replay is nondeterministic;
- logical semantic content differs after complete dimensional comparison.

`FAILED` is evidence of non-equivalence for the tested exact source/release/C11 identity. It does not authorize repair during the certification run.

### `BLOCKED`

Return when a mandatory proof cannot be lawfully evaluated. Examples:

- source snapshot unavailable;
- questionnaire/codebook/native labels unavailable where semantically required;
- topology authority unavailable;
- routing/applicability authority unavailable;
- weight design/basis unavailable;
- respondent/source identity unresolved;
- populated C11 relation unavailable;
- authority snapshot unavailable;
- proof object cannot be made immutable/exact;
- an execution prerequisite is not yet accepted.

A blocked state is not a failed equivalence and not a provisional certification.

## 4. D13B dimensional proof

Each source certification MUST execute the D13B proof dimensions against source-native proof objects and their C11 replay objects.

| ID | Dimension | Certification burden |
|---|---|---|
| P01 | respondent incidence | exact scoped respondent-set identity, not count parity |
| P02 | response-event multiplicity | exact event multiset at topology-authorized grain |
| P03 | response topology | exact scalar/set/repeated/ranked semantics |
| P04 | risk-set identity | exact predicate identity and exact member set |
| P05 | routing/applicability | exact typed state and authority |
| P06 | typed missingness | preserve missing/DK/refusal/IAP/not-asked/inapplicable distinctions |
| P07 | raw support | exact numerator/denominator including zero support |
| P08 | weighted support | exact governed mass or identical typed blocked state |
| P09 | weight basis | exact weight values/status/design/basis identity |
| P10 | scope | retain raw and canonical source/wave/country scope |
| P11 | predicate identity | exact typed coordinate/question/operator/value identity |
| P12 | condition AST/hash | exact canonical typed AST under frozen normalization law |
| P13 | target identity | exact target kind/component/topology identity |
| P14 | branch membership/provenance | exact semantics, lineage and member set |
| P15 | k-way joint topology | exact configuration and same-respondent joint incidence |
| P16 | authority identity | exact authority ID/version/content hash/ref |
| P17 | logical content hash | integrity seal after all semantic dimensions pass |
| P18 | deterministic replay | repeated identical inputs produce identical semantic result/status |
| P19 | duplicate semantics | conflicting scalar duplicate blocks; legitimate multiplicity survives |
| P20 | order independence | physical permutation inert except explicit rank/sequence semantics |

No mandatory dimension may be converted to `NOT_APPLICABLE` merely because C11 lacks the information. `NOT_APPLICABLE` is lawful only when the exact retained capability frontier and source authority make the dimension genuinely inapplicable.

## 5. C11 information closure

The runner MUST demonstrate preservation of the D13 minimum information family, including at least:

- empirical universe/source/study/release/instrument identity;
- scoped respondent identity;
- respondent-bound response-event incidence;
- native and canonical question/component identity;
- raw/source-native and canonical response values;
- event group/event/index identity;
- scalar/set/repeat/rank/order topology;
- routing/applicability/risk-set membership or exact replay rule;
- typed absence/non-substantive states;
- respondent-bound empirical coordinates;
- native/canonical coordinate identity, raw/canonical value, units/taxonomy and effective/reference time;
- normalization/crosswalk authority;
- weight facts plus exact design/estimand/basis authority;
- source-native semantic authority;
- cross-universe relation/overlap/linkage authority where present;
- branch/discovery/structural-admission/replay authority and provenance required by the retained frontier.

This is an information requirement, not a requirement for one physical table shape.

## 6. Mandatory hostile replay frontier

Certification must exercise the retained hostile classes, not only current happy-path queries. The populated runner MUST include fixtures or source-native proofs sufficient to test:

- unary distribution;
- single coordinate conditional;
- multi-coordinate conjunction;
- response×coordinate conjunction;
- response-response pair joint;
- bounded k-way joint including parity/XOR geometry when source topology supports it;
- minority/rare configuration;
- branch membership and branch cotravel;
- routing and typed absence;
- multiplicity/topology;
- temporal/raw-wave distinctions;
- source-universe disagreement without pooling;
- overlap/double-counting provenance where applicable;
- actor-comparator source predicate replay where applicable;
- reverse possibility-field empirical query support where applicable;
- structural-admission empirical fact provenance where applicable;
- autonomous-discovery replay over the retained frontier.

If a source cannot lawfully exercise an applicable class because the needed source semantics are unavailable, the source is `BLOCKED`, not silently exempted.

## 7. Source-native comparison law

Comparison is performed from source-native evidence outward. The runner first materializes source-native diagnostics before claiming any normalization equivalence.

The source side MUST preserve, as applicable:

- original codes and labels;
- questionnaire/instrument/question/component identity;
- source-specific topology declarations;
- routing/skip/applicability rules;
- response-state semantics;
- source weights/design variables and basis;
- source-native coordinates and units/taxonomy;
- exact release/wave/geography/sample identity.

Allowed normalization requires a named immutable authority and must be semantics-preserving for the tested dimension. Allowed examples include physical row reordering, explicit set-order normalization, canonical alias stored alongside raw identity, or exact versioned crosswalks.

Forbidden normalization includes fuzzy label matching, nearest-category/geography substitution, raw-identity deletion, missing weight→`1.0`, missing topology→scalar, absent row→not-asked, DK/refusal/IAP collapse, generic duplicate removal, unproved source pooling, or empirical-coordinate→generated-position promotion.

## 8. Risk-set and routing law

Denominator count equality is not proof. Certification binds the exact risk-set predicate and exact scoped member set.

Observed response availability may not substitute for routing eligibility. `NOT_ASKED`, `INAPPLICABLE`, `MISSING`, `DK`, `REFUSAL`, and substantive response states remain distinct.

Where routing can be deterministically reconstructed rather than stored, the receipt must bind the exact routing rule authority and prove exact member-set reconstruction.

## 9. Weight law

Raw measure and weighted measure are separate proof lanes.

For every weighted fixture, bind:

- exact weight basis/design/estimand authority;
- exact respondent weight value/status;
- exact query scope and risk set;
- canonical decimal representation used for proof;
- exact source and C11 weighted result.

Missing/invalid weight never defaults to `1.0`. Unavailable basis produces `BLOCKED`; a differing available basis/value/result produces `FAILED`.

## 10. Coordinate law

C11 coordinate certification MUST prove source-native and canonical coordinate identity without treating a current fixed coordinate inventory as the future frontier.

For each retained coordinate bind:

- native field ID;
- canonical field ID if mapped;
- raw value;
- canonical value if mapped;
- unit/taxonomy;
- effective/reference time;
- typed unknown/missing state;
- exact normalization/crosswalk authority.

Survey/empirical coordinates remain empirical coordinates. Certification cannot convert them into generated structural position or actor fact.

## 11. Lineage and replay law

The certification receipt MUST bind exact:

- Git HEAD;
- proof protocol version/hash;
- source artifact/release/universe identities and hashes;
- ingest authority/version/hash;
- query authority/version/hash;
- source semantic/topology/routing/weight/crosswalk authorities;
- code/config/fixture hashes;
- C11 universe/content/partition identities;
- dimensional evidence hashes;
- deterministic replay run identities;
- logical semantic projection/hash;
- final replay root.

No wall clock, mutable `latest`, filesystem enumeration order, unrecorded lookup, fuzzy matching, or unrecorded randomness may enter semantic identity.

## 12. Certification decision algorithm

For one exact source/release lane:

1. Verify exact clean runner checkout and protocol identity.
2. Inventory and hash the exact source/release artifacts and C11 target relation/partitions.
3. Freeze all governing source-native and C11 authorities.
4. Produce source-native diagnostics without normalization claims.
5. Validate C11 ingest identity and zero unauthorized default/coercion counts.
6. Execute P01–P20, recording source object, replay object, comparison key, allowed normalization, evidence hash, and state.
7. Execute M01–M18 information-closure checks.
8. Execute T01–T18/frontier hostile replay checks applicable to the source.
9. Repeat deterministic proof/replay under identical governed inputs.
10. Compute logical semantic integrity projection only after dimensional proof.
11. Verify clean working tree after execution.
12. Apply precedence:
   - any mandatory observed mismatch → `FAILED`;
   - else any mandatory unresolved proof → `BLOCKED`;
   - else every mandatory proof passed → `CERTIFIED`.
13. Freeze receipt and retain source snapshots regardless of result.

Observed semantic contradiction outranks a separate blocked dimension for the tested certification lane: the lane is `FAILED` because equivalence has been disproved. The receipt must still enumerate all blocked dimensions; no missing proof is hidden.

## 13. Non-certifying diagnostics

Counts, distributions, parity summaries and hashes are useful early warning diagnostics. They are never sufficient on their own.

Examples:

`same respondent count != same respondent set`

`same denominator count != same risk-set members`

`same branch N != same branch members`

`same unary marginals != same joint incidence`

`same weighted total != same weight basis`

`same displayed answers != same predicate/empirical fact`

`same schema != same populated semantics`

## 14. Retention and governance

The original source/native snapshot set remains physically retained and addressable after certification. Positive certification proves a governed equivalence relation for the exact tested identity; it does not revoke the source's evidentiary role and does not authorize deletion.

Source retirement, compaction that destroys native distinctions, or replacement of source evidence by C11 requires a separate later governance authority.
