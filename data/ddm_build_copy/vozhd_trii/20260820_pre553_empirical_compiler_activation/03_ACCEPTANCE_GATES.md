# PRE553 acceptance gates

## G-P01 — Object/authority contract
Pass only if canonical empirical objects preserve typed absence, exact content identity, authority version/hash, source-universe identity, replay provenance, and all D13 M01-M18 information classes without collapsing empirical coordinates into structural/generated positions.

## G-P02 — C11 carrier
Pass only if synthetic fixtures prove exact respondent-event/coordinate/routing/weight reconstruction across scalar, multiselect, repeated, ordered/ranked, missing/DK/refusal/IAP/not-asked/inapplicable states; no duplicate collapse; no default weight/topology substitution.

## G-P03 — Exact empirical query
Pass only if the query engine can exactly represent and replay unary distributions, arbitrary lawful coordinate conjunctions, response×position conjunctions, response-response joints, branch/cohort predicates, k-way targets, explicit risk sets, raw/weighted measures, zero-support states, and source-indexed scopes. XOR/parity and Simpson/reversal fixtures are mandatory.

## G-P04 — Source plurality
Pass only if distinct universes remain distinct by default. Pooling, linkage, backfill, overlap/double-counting treatment and semantic equivalence each require separate exact authority. Same label/canonical alias is insufficient.

## G-P05 — Discovery
EXACT_BOUNDED mode must be complete for its declared finite frontier and must not require unary signal. ADAPTIVE_EXPLORATORY must disclose evaluated/pruned/unevaluated frontier and may never convert unevaluated into negative evidence. Emitted results must dereference exact empirical facts; diagnostic scores remain derived.

## G-P06 — Structural admission
Pass only if `EmpiricalFact -> StructuralEmpiricalAdmission` requires an explicit named structural-admission rule/authority. No generic association→structure rule, no coordinate→nine-stratum binding, no survey→belief/persona. Existing V551/V552/J semantics may migrate only through explicit compatibility admission rules with parity proof.

## G-P07 — V553 ingress
Pass only if admission projections populate the frozen M1 consumer fields exactly and temporal/comparability ownership remains with V553. Pre553 may provide exact source/wave/time evidence; it may not steal V553 temporal jurisdiction.

## G-P08 — Populated-source equivalence
Per source/release, status must be one of `CERTIFIED`, `FAILED`, or `BLOCKED`. Schema parity, count parity, aggregate parity or selected-query parity alone cannot certify source→C11 equivalence. Source snapshots remain retained until positive certification plus later governance.

## G-P09 — First reservoir
A nontrivial populated run must produce a deterministic V558 StructuralPriorRepository from exact source evidence through C11/query/discovery/admission/V553+, with exact replay roots for every retained prior. Required audit: object counts by producer/source/wave/stratum/typed state, positive+negative authority closure, no orphan references, no unauthorized source composition, deterministic rebuild identity.

## G-P10 — Whole-machine reclosure
All pre553 synthetic hostile tests plus unchanged downstream 260-test suite must pass from one exact clean checkout. No legacy runtime dependency may be introduced. No SPDM positive implementation, cutover, deployment or source retirement is implied by success.

## Immediate return-required conditions
- any runtime write during Wave 01;
- any attempt to modify accepted downstream interfaces before HQ synthesis;
- any fuzzy/latest/default/nearest fallback;
- any empirical-coordinate→generated-position promotion;
- any source pooling inferred from harmonization or provenance;
- any diagnostic metric treated as canonical empirical or structural truth;
- any absence represented by missing row where typed absence is semantically required;
- any claim of populated-data completeness without exact populated execution evidence.
