## 5. BOUNDEDNESS / BACKPRESSURE LAW

### 5.1 Worker count

Court worker count is exactly:

`12`

The coordinator is additional and is not counted as a compiler worker.

### 5.2 Queue bound

Input work queues must be bounded.

Default total queued decoder batches:

`<= 12`

One queued batch per compiler worker is preferred.

No unbounded multiprocessing queue is permitted.

No corpus-growing in-memory task list is permitted.

Results are returned as small descriptors/path references; run payload bytes remain worker-private on disk until merge.

### 5.3 Aggregate RSS governors

Monitor the coordinator plus all descendant compiler worker processes at least every second during active compilation.

Thresholds:

- `< 2.5 GiB`: normal operation;
- `>= 2.5 GiB`: stop increasing queue occupancy and throttle the decoder/producer until aggregate RSS falls below the soft band;
- `>= 3.0 GiB`: stop dispatching new work and drain outstanding bounded work;
- `>= 3.5 GiB`: HARD ABORT.

Hard abort behavior:

1. stop decoder traversal;
2. terminate/join all workers;
3. do not seal/promote any partial root;
4. remove worker-private scratch;
5. write a small exact failure receipt;
6. return `R5_PARALLEL12_BLOCKED__AGGREGATE_RSS_HARD_GATE`.

The frozen historical 4 GiB R5 memory ceiling remains an absolute outer boundary; this court intentionally aborts earlier.

### 5.4 Scratch / free-space governors

Track scratch bytes and filesystem free space during execution.

- scratch soft warning: `6 GiB`;
- scratch hard abort: `8 GiB`;
- filesystem free-space hard floor: `5 GiB`.

Crossing scratch hard or free-space hard floor aborts workers, prevents sealing and cleans private scratch.

No partial carrier may be interpreted as success.

### 5.5 Worker/process failure

Any worker crash, unexpected exit, unreadable run, duplicate task completion, missing task completion, broken queue protocol, or coordinator exception is fail-closed.

No automatic serial fallback inside the same claimed parallel court.

Serial remains separately available as the accepted reference, but a parallel court failure must be returned as a failure rather than silently masked.
