## 2. FAIR-COMPETITION LAW

The purpose of parallel campaigns is not to protect an implementation choice. It is to obtain a dispositive empirical comparison between serious contenders.

Therefore:

`TRII_MUST_NOT_STARVE_ROUTE_A`

`CHETIRI_MUST_NOT_STRAW_MAN_ROUTE_A`

`TRII_MUST_NOT_PREJUDGE_B_OR_C`

`CHETIRI_MUST_NOT_INHERIT_A_BY_HISTORICAL_ACCIDENT`

All routes must satisfy the same applicable semantic, capability, provenance, replay, completeness and downstream-output obligations before performance/lightness comparison is dispositive.

Trii's job is to make Route A **immaculate as a contender**, not merely technically existent.

Evaluation remains governed by:

1. flawless effectiveness / correctness;
2. speed on actual Rawlsing workloads;
3. lightness;
4. portability and operational burden where relevant to the same lawful capability.

A route may not become faster/lighter by deleting truth, autonomous-discovery reachability, provenance, replay, negative-state completeness, source authority, learned-world capability, or the common V553+ handoff.

   - For Trii: persistent canonical empirical substrate first, then C11/I03/I05/I04/pre-V3 compilation.

   - If shared, do not reinterpret shared work as architectural convergence.

4. **Has another live HQ authority or active worker already been assigned this exact burden?**
   - If yes, do not duplicate it; consume or await the canonical return as jurisdiction requires.

5. **How does this work advance the command's terminal experiment and same V553+ handoff?**
   - If that cannot be stated concretely, the task requires re-grounding before launch.

A command action taken without this checksum is procedurally drift-prone and must not be treated as authoritative merely because it is locally plausible.
