## 2. Required distinctions recovered

### 2.1 CATEGORY EMPIRICAL OBJECT != PARENT DISTRIBUTION

V551 correction work explicitly retained the category-level `empirical_object_id` and added a stable `empirical_distribution_id` for the parent question distribution. The accepted GSS correction reported 118 category atoms but 59 distributions (55 complete, 4 partial). V552's primary grouping key became the parent distribution; category IDs remained component lineage.

A representative category ID is therefore not a lawful substitute for the parent distribution ID.

### 2.2 QUESTION DENOMINATOR != JOINT DENOMINATOR

`n_respondents` is a question-distribution denominator. V550J/V551J joint measures such as family respondent count, joint N/effective N, pattern count and pattern probability describe a joint pattern/population. They are not interchangeable, and component question denominators need not be equal across different questions in one packet because missingness/filtering can differ.

Never:

- sum category/question denominators to synthesize a population N;
- replace a component question denominator with joint N;
- replace joint N/effective N/probability with a component denominator.

### 2.3 SEMANTIC POLARITY != RETAINED SOURCE POLARITY

The historical scale-authority work learned that raw/source numeric direction and intensity are evidence requiring a governed scale/topology interpretation. A source coordinate of `0` can be the negative endpoint of an ordinal axis; it is not automatically semantic zero.

The later Aug-15 hostile issue register then found a deeper implementation defect: canonical signed projection was being recomputed in V550, V551, and V552. Its required repair was to make V551 the sole canonical signed-projection/adjudication boundary, leave V550 source-native/raw, and make V552 consume canonical V551 signed fields instead of re-inferring scale meaning.

Thus both layers must survive:

- retained source response/scale/polarity evidence;
- governed canonical semantic signed projection.

The second is not permission to erase the first.

### 2.4 FAMILY TARGET != DIRECT STRUCTURAL TARGET

V551J v2.2 repaired a false-conflict rule. A family-level target such as `abortion_permission` and a direct V551 structural target such as `infer_abortion_condition` can be parallel governed target layers. Lexical inequality does not make them structurally inconsistent. Both must remain visible unless a later governed mapping proves an exact equivalence or conflict.

### 2.5 PACKET != SCALAR ROW

A V551J packet is an ordered same-respondent morphology with component children. A V552 pressure observation is a separate empirical/structural object. A V552J pressure row may be linked to many packet components without becoming many pressure observations, and a packet may contain heterogeneous component authority that cannot be represented by one scalar field.

This distinction becomes decisive in Section 35.

### 4.1 Hostile-test matrix

| Component match state | Projected values | Scalar lawful? | Required carrier behavior |
|---|---|---:|---|
| complete | all same, all non-empty | YES | scalar may be derived; component vector remains lineage |
| complete | two or more distinct non-empty values | NO | blank scalar; retain vector |

This law defeats a common false inference: **unanimity among the rows you happened to match is not packet unanimity**. Coverage completeness is a separate necessary condition.

It also means a packet-uniform runtime/cache scalar is never the persistent authority when the underlying components differ. At most it is a regenerable projection of a component-level authoritative object.

## 5. Roles, strata, horizon, constraints and negative states

The component-vector lesson generalizes beyond strata.

### Roles

### Strata
Section 35 directly demonstrates the failure of packet-uniform strata. The tested certified packets were heterogeneous enough that **zero** packet strata scalars were lawful despite complete component matching.

### Horizon
V552 had already learned that horizon absence is not horizon constraint. V552J cannot repair that by packet scalarization. Explicit component/horizon evidence must retain its basis; absent or heterogeneous horizon values stay absent/heterogeneous.

### Constraints / prohibitions / absences
V551J's strongest contract required every contributing atom's provenance, known absences, forbidden inference and authority hashes to remain recoverable. V552J's runtime-handoff line likewise forbade person-level/runtime claims. These are not decorative audits. They are negative authority: what the system is **not allowed to infer**.

A carrier that keeps positive values while dropping the prohibition that limits their use is semantically lossy.
