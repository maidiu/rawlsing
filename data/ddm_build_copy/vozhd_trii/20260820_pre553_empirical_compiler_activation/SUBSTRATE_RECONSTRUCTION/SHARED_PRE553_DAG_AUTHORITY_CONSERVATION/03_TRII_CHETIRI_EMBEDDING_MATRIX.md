## Required integration rule

A recovered concept is not considered conserved because it appears in this matrix.

It is conserved only after one of the following is true:

1. the exact obligation is incorporated into an existing Trii contract/gate and its implementation/hostile tests;
2. the exact obligation is incorporated into an existing Chetiri contract/gate and its implementation/hostile tests;
3. a shared route-neutral prerequisite contract binds both contenders to the same semantic/capability law;
4. HQ records positive proof that the obligation is obsolete, erroneous, or losslessly superseded.

## Anti-Pyat rule

No worker may create a separate runtime, compiler, persistence architecture, candidate D, or downstream product owned by `SHARED_PRE553_DAG_AUTHORITY_CONSERVATION`.

Any implementation task generated here must be dispatched into:

- Trii Route A;
- Chetiri Route B/C;
- an already-authorized shared prerequisite gate such as source certification / G1A / common C11-I03-I05-I04 truth law.

If a proposed task cannot be routed into one of those, HQ must first determine whether the current Trii/Chetiri obligation model is underspecified and amend that model. The answer is never to let this directory become a fourth command by inertia.
