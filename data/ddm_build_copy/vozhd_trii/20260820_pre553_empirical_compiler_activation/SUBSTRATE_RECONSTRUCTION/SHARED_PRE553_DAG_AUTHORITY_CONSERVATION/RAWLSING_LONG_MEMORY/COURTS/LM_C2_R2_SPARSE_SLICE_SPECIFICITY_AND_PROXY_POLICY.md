# RAWLSING LONG MEMORY — LM-C2 R2 SPARSE-SLICE / SPECIFICITY / PROXY POLICY

Status: `TERMINAL_SERVICE_REQUIREMENT_RESOLVED__EXACT_EMPIRICAL_AUTHORITY_REMAINS_FAIL_CLOSED__TYPED_PROXY_INFERENCE_ALLOWED_ONLY_IN_SEPARATE POSSIBILITY_LANE`

Jurisdiction: historical sparse-cell broadening versus current learned-world / positioned-subject possibility requirements. This court does not validate old hand-set similarity weights and does not permit proxy evidence to become source/empirical/structural authority.

## 0. Historical problem

R01 recovered two distinct early approaches:

1. speculative weighted demographic similarity, with hand-set dimension weights explicitly requiring validation;
2. an actually implemented deterministic microdata-first broadening/walkback path with minimum-N logic and explicit fallback/proxy behavior.

The first is not authority.
The second embodied a durable capability: do not jump invisibly from a sparse exact slice to a broad population mean.

The function is therefore:

`VISIBLE_LOSS_OF_SPECIFICITY + DETERMINISTIC_PROXY_PROVENANCE`.

## 1. Modern correction

Current Rawlsing correctly strengthens the epistemic boundary:

`NO_EXACT_CELL != PERMISSION_TO_PRETEND_A_BROADER_CELL_IS_EXACT`.

`PROXY_EVIDENCE != OBSERVED_EXACT_EMPIRICAL_FACT`.

`NEAREST_AVAILABLE != SEMANTICALLY_COMPARABLE`.

`LOW_SUPPORT != ZERO`.

`SEARCH_FAILURE != NEGATIVE_TRUTH`.

This modern discipline does not require abandoning all broadening. It requires putting broadening in the correct epistemic lane.

## 2. Dispositive distinction

Rawlsing needs two separate behaviors.

### A. Exact empirical-authority query

If a consumer asks for the empirical fact under an exact predicate/risk set/scope, and the evidence is unavailable, underpowered, unresolved or noncomparable, the result must fail closed or return the typed state.

No broader cell may silently satisfy that query.

### B. Positioned-subject possibility / inference query

If the consumer's lawful operation is to estimate a possibility field for a positioned subject under uncertainty, a governed broadening operation is a terminally useful capability.

That operation may return broader or proxy evidence only when:

- the broader universe is itself lawful and observed;
- the dropped/relaxed predicates are explicit;
- the semantic/routing/measurement relationship permits the inference operation;
- the result carries a lower-specificity/proxy epistemic class;
- the fallback path and determinant set are replayable;
- uncertainty/support are surfaced;
- downstream consumers are forbidden from reclassifying it as exact empirical authority.

Freeze:

`EXACT_EMPIRICAL_QUERY -> NO_IMPLICIT_BROADENING`.

`POSITIONED_SUBJECT_POSSIBILITY_QUERY -> GOVERNED_BROADENING_MAY_BE_LAWFUL`.

## 3. Terminal requirement

Long Memory rules:

`GOVERNED_SPECIFICITY_WALKBACK = REQUIRED_TERMINAL_LEARNED_WORLD_SERVICE_CAPABILITY`.

But the terminal requirement is NOT:

- preserve the old similarity coefficients;
- always return an estimate;
- force a country mean;
- use geography/demographics as identity;
- fill a structural or actor-state gap.

The requirement is to preserve the ability to search a governed hierarchy of less-specific empirical universes and report exactly what was lost in the walkback.

## 4. Suggested epistemic states

A final implementation should distinguish at least:

- `EXACT_OBSERVED`;
- `EXACT_OBSERVED_LOW_SUPPORT`;
- `EXACT_UNAVAILABLE`;
- `NONCOMPARABLE`;
- `AUTHORIZED_PROXY_INFERENCE`;
- `AUTHORIZED_BROADER_UNIVERSE_INFERENCE`;
- `PROXY_CANDIDATE_REJECTED`;
- `NO_LAWFUL_PROXY`;
- `SEARCH_TRUNCATED_OR_BUDGET_EXHAUSTED`.

A proxy result must retain:

- requested predicate/risk-set identity;
- actual evidence predicate/risk-set identity;
- dimensions/predicates relaxed;
- broadening step sequence;
- support/weight/design basis;
- measurement/comparability authority refs;
- source/wave/country/time identity;
- algorithm/policy version;
- replay determinant hash;
- reason the proxy was authorized;
- explicit semantic ceiling.

## 5. Broadening must be partial-order policy, not arbitrary distance

The old hand-set weighted similarity idea is too easy to turn into a hidden human ontology.

Preferred modern law:

1. define which predicate relaxations are semantically lawful for the requested operation;
2. define a deterministic partial order / precedence among allowed relaxations where domain authority supports one;
3. search exact first;
4. widen one governed step at a time;
5. stop at the first evidence universe satisfying the operation's support/quality threshold, unless policy explicitly compares multiple lawful candidates;
6. preserve the whole fallback trace;
7. if no lawful path exists, return `NO_LAWFUL_PROXY`.

A learned or empirical ranking of relaxations could later be admitted, but only under its own validation/replay authority. It must not become hidden semantic truth.

## 6. Example

Requested positioned-subject possibility predicate:

`country + age-band + class-position + education + urban/rural + time`.

Suppose the exact cell is too sparse.

A lawful policy might test explicitly authorized ancestors such as:

`country + age-band + class-position + education + time`

then, if permitted:

`country + class-position + education + time`

while preserving that urban/rural and then age specificity were lost.

The returned object remains a proxy possibility field. It is not the empirical distribution for the original exact predicate.

The exact relaxation order cannot be universalized from this example.

## 7. Multi-universe and contradiction law

Broadening must not flatten genuine disagreement.

If multiple lawful broader universes disagree materially, the system may need to preserve a set/range or typed disagreement rather than choose one merely because it is numerically nearest.

Likewise a broad modal pattern may not erase a supported minority configuration present in a narrower lawful universe.

Freeze:

`BROADER_EVIDENCE != RIGHT_TO_ERASE_NARROWER_SUPPORTED_MODES`.

## 8. Relationship to actor generation

A proxy possibility field is population/learned-world evidence.

It may constrain or inform a later generated-person possibility process only through the lawful V558/V3 interface and separate causal realization authority.

It does not imply:

- actor identity;
- actor belief;
- actor awareness;
- actor orientation-to-strata;
- actor exposure/history;
- actor response.

This preserves the current anti-puppet law while retaining useful empirical inference.

## 9. Architectural consequence

This capability belongs to the learned-world/query layer, not to historical V550 stage identity and not to V3 person-state ownership.

The physical architecture may implement it through:

- on-demand queries over canonical empirical substrate;
- governed materialized indexes;
- caches;
- a hybrid.

But caches remain non-authoritative, and the same immutable input/policy version must reproduce the same fallback path/result.
