# RAWLSING LONG MEMORY — LM-C2 R3 AUTONOMOUS / ADAPTIVE DISCOVERY SEMANTIC BOUNDARY

Status: `FUNCTIONAL_BASELINE_CLOSED__EXACT_COMPLETE_AND_ADAPTIVE_PARTIAL_MODES_SEPARATED__SEARCH_POLICY_NEVER_BECOMES_EMPIRICAL_TRUTH`

Jurisdiction: terminal learned-world discovery capability. This court does not select a persistence architecture, modify I05, or authorize an unbounded learned heuristic.

## 0. Core result

Rawlsing needs two compatible discovery modes with different epistemic ceilings.

### Mode A — exact-bounded exhaustive discovery

Purpose:
- authoritative completeness within one exact declared lawful frontier;
- exact negative claims when and only when every candidate in that frontier has terminal coverage;
- canonical benchmark/replay mode.

### Mode B — adaptive exploratory discovery

Purpose:
- find promising, surprising or deeper lawful structures under finite time/compute budgets;
- alter search order/branch expansion based on already observed or validated results;
- support interactive research and practical large-frontier exploration.

Mode B may discover candidates.
It may not manufacture empirical truth, validation, structural admission or complete-negative claims.

Freeze:

`ADAPTIVE_SEARCH_PRIORITY != EMPIRICAL_AUTHORITY`.

`SEARCHED_AND_NOT_FOUND != NO_RELATION`.

`BUDGET_EXHAUSTED != COMPLETE_NEGATIVE`.

`CANDIDATE_DISCOVERED != CANDIDATE_VALIDATED`.

`VALIDATED_EMPIRICAL_RELATION != STRUCTURAL_ADMISSION`.

## 1. Exact-bounded mode preserves the strongest current law

The current C05 production profile defines an exact finite autonomous frontier using:

- exact source/universe/release authority;
- every lawful exact finite predicate atom;
- every exact governed risk set;
- every authorized RAW and weighted/design estimand;
- all I03-supported topology;
- maximal lawful finite conditioner arity K;
- maximal lawful finite target arity J;
- recursive depth bounded by unused-atom closure;
- complete deterministic expansion of accepted candidate families/forms;
- no top-k or score pruning;
- no unary pre-screening;
- no prevalence/support/effect-size reachability pruning;
- no RNG;
- canonical candidate hash order;
- terminal typed state for every candidate.

This is the correct authoritative basis for:

`COMPLETE_AUTHORIZED_SEARCH__NO_RELATION`.

No adaptive mechanism may weaken this exact completeness claim.

## 2. Why adaptive search is still a terminal capability

A finite lawful frontier may be combinatorially enormous even though its semantics are exact.

The terminal learned world requires Rawlsing to be capable of discovering important structure not manually named in advance and to remain useful under practical budgets.

Examples include:

- surprising minority configurations;
- XOR-like relations with no unary signal;
- Simpson/conditional reversals;
- recursive subgroup forks;
- branch-conditioned cotravel;
- higher-order joints;
- cross-field contradictions;
- structures suggested by newly validated prior findings.

An adaptive scheduler may therefore use previous search results to choose which still-lawful candidates or branch expansions to evaluate first.

The adaptation changes execution order and finite budget allocation.
It does not change the semantic truth condition of any candidate.

## 3. Adaptive mode authority ceiling

An adaptive exploration policy may consume non-authoritative signals such as:

- candidate support diagnostics;
- effect-size diagnostics;
- novelty/diversity scores;
- uncertainty or low-support warnings;
- already-validated relation ancestry;
- branch depth;
- compute-cost estimates;
- user/research-service query focus;
- underexplored predicate/topology regions.

Those signals may rank or schedule lawful candidates.

They may not:

- create a candidate whose predicate/query is not lawful under source/I03 authority;
- turn a diagnostic score into relation truth;
- remove an unsearched candidate from the exact authoritative frontier;
- classify an unsearched region as negative;
- silently alter source/risk/measure/topology semantics;
- pool universes or measurements without separate authority;
- use actor/person outcomes to retroactively manufacture population empirical authority.

## 4. Required adaptive-search receipt

Every adaptive run must be replayable as a search process even if it is not exhaustive.

Minimum receipt:

- exact discovery policy ID/version/hash;
- exact source/universe/release authority refs;
- exact lawful candidate frontier identity/hash where a frozen frontier exists;
- initial queue/order state;
- budget type and value;
- deterministic tie/order law or explicit governed RNG receipt if a future search policy lawfully uses randomness;
- every evaluated candidate ID in order;
- every scheduling/branch-expansion decision and its input diagnostics;
- generated descendant candidate ancestry;
- validation result refs separately from search diagnostics;
- stopped/remaining frontier identity;
- terminal completeness/search state;
- wall-clock/runtime metrics as diagnostics only.

The receipt must permit another run under the same policy and determinants to reconstruct the same search trajectory, subject only to explicitly governed nondeterminism.

## 6. Recursive discovery and newly learned predicates

The current exact profile already permits recursive branch-cohort predicates generated from frozen prior discovery ancestry under exact rule families.

Long Memory generalizes the functional law:

A newly validated empirical relation or branch may become a lawful input to a later discovery generation only if:

1. its identity and validation are frozen;
2. a candidate-family/grammar authority explicitly permits that ancestry class;
3. the new candidate receives a new exact semantic identity;
4. source/risk/measure/topology scope remains explicit;
5. circular self-justification is forbidden;
6. invalidation propagates if the ancestor relation later loses authority/currentness.

Thus the learned world may genuinely learn and then search from what it learned without turning yesterday's heuristic into today's ontology.

## 7. Exact and adaptive modes may share one engine

This is not a requirement for two separate subsystems.

A single I05/discovery engine may support:

- `EXHAUSTIVE_CANONICAL_ORDER` policy;
- one or more `ADAPTIVE_EXPLORATORY` scheduling policies.

The difference is policy/receipt/completeness semantics, not a new sovereign data owner.

All candidates still execute through the same governed I03 truth primitives and validation authority.

## 8. Caches and learned scheduling models

A cache, learned ranking model or historical search statistic may improve scheduling.

It remains non-authoritative.

Delete the cache and the set of lawful candidates does not change.
Change the ranking model and individual empirical query truth does not change.

If a ranking model affects which candidates are searched before budget exhaustion, its exact model/version becomes a search-replay determinant but still not empirical-semantic authority.

Freeze:

`SEARCH_REPLAY_DETERMINANT != EMPIRICAL_TRUTH_DETERMINANT`.

## 9. Relationship to specificity walkback

Adaptive discovery and positioned-subject proxy broadening are different operations.

Adaptive discovery chooses what lawful empirical questions to evaluate.
Specificity walkback chooses whether a less-specific empirical universe may serve as a typed proxy for one requested possibility inference.

Neither grants the other authority.
