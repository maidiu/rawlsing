`SOURCE_PURPOSE + EXACT_OPERATION/ESTIMAND + REQUIRED_DESIGN_SCOPE`.

Therefore:

`WEIGHT_DESIGN_ESTIMAND -> MEASUREMENT_PORTABILITY = INVALID_IMPLICATION`.
