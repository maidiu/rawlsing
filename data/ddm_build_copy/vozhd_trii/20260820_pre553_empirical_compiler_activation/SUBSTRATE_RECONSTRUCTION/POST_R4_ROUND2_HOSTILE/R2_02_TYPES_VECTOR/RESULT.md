## DESTRUCTION_PATHS_FOUND

1. **Reader-frame bypass is destructive.** The frozen decoder normalizes each value through `_jsonable` before classifying it. Current behavior includes NaN -> `None`, infinity -> text, finite float unchanged, NumPy-like scalar -> `.item()` recursion, collections -> recursive normalization and unsupported object -> `str(value)`. Missing classification and `raw_value_label` selection occur after this normalization. Direct pandas/pyreadstat-frame -> Arrow therefore observes a different domain unless it reproduces the exact public decoder projection.

2. **Round-1 float wording was too strong.** At the current P0 input boundary NaN payload/sign are already erased to `None/SYSTEM_MISSING`; infinity is text and then classified under declaration law; finite float remains a float and signed zero survives. P0 must preserve decoder-observed identity, not reconstruct discarded upstream bits.

3. **Physical float bits are not C11 semantic identity.** `canonicalize()` rejects every binary float. Exact physical float storage therefore needs a separately governed exact semantic projection before C11 hashing. Hashing Arrow float bytes as semantic identity is forbidden.

4. **Nominal source width cannot silently narrow decoder output.** If the reader/decoder exposes a Python float or arbitrary Python int, storage metadata remains metadata. Narrowing to a nominal width is allowed only when an exact inverse is proven. Observed min/max never certifies width.

5. **Integer lanes require total representability.** Signed/unsigned domains remain distinct. Overflow, wrap, float bridge and observed-range narrowing are destructive. Widen or use exact escape before publication.

6. **Exact text is broader than an unconditional Arrow UTF-8 assumption.** Preserve exact decoder text including empty string, embedded NUL, controls and normalization distinctions. Arrow UTF-8 is a fast lane only when strict round-trip is exact; otherwise exact text/codepoint/binary escape or validated fallback. No normalization, trimming, casefolding or replacement-character repair.

7. **Date/time may not be inferred from display format.** The decoder has no generic privileged date/time branch in `_jsonable`; unsupported objects become text. Numeric date-looking values remain numeric plus metadata absent exact decoder/type authority.

8. **Missingness remains two-dimensional.** Raw payload, `PhysicalMissingState`, and matched source declaration must remain separately reconstructible. DTA extended missing and SAV user-missing values/ranges cannot collapse to Arrow null. Declaration order matters because the frozen classifier returns the first match.

9. **Typed dictionary keys cannot redefine frozen label selection.** The decoder constructs label keys via `str(_jsonable(key))` and selects with `str(raw)`. Typed-key storage is allowed only if its inverse reproduces the same `raw_value_label` result.

10. **Round-1 locator base was underspecified.** Current decoder row and variable ordinals begin at 1. A current zero-based dense logical ordinal is `L=(r-1)*V+(v-1)`, inverse `r=L//V+1`, `v=L%V+1`. The bases must be sealed; no universal zero-base assumption.

11. **`zip(variables,row)` is a silent truncation hazard.** Successful decoder iteration does not prove row width equals `V`. Dense geometry requires exact row-width equality, exact ordered variable sequence, emitted-row equality, emitted-cell equality, no filtering/reordering and checked arithmetic. Failure disables implicit geometry or blocks publication; silent truncation is never accepted.

12. **SAV storage geometry is not logical variable geometry.** Accepted Arab Barometer evidence has string continuation slots. Latinobarometro 2024 has nominal case size 174 while parsed logical variable width/traversal is 332. P0 coordinates must use the frozen decoder logical `PhysicalVariable` axis, never raw SAV slot/header counts.

13. **DTA/SAV reader behavior is extraction identity.** The six SHA-bound latin1 overrides remain `COMPATIBILITY_EXECUTION_ONLY__NOT_SOURCE_TEXT_ENCODING_AUTHORITY`. Accepted LiTS IV evidence shows reader-option interaction. A generic direct Arrow reader may not substitute its own encoding/date/missing options.

14. **Downstream vectorization does not close current compatibility-path memory.** With a compatibility encoding override the frozen decoder retains a full reader frame. P0 may vectorize downstream transformation of emitted cells, but may not call that end-to-end bounded until the decoder path is separately fixed/equivalence-proven.

15. **Batch-local checks cannot replace C11 admission.** C11 also enforces authority registry closure, declared universe/authority/count parity, section/TypedAbsence law, respondent/universe joins, question binding, occurrence uniqueness, mapping/topology authorities, source-relation disposition, replay closure, M01-M18, validated-release seal and repository collision/atomicity law. A correct-looking Arrow batch is not a validated C11 release.
