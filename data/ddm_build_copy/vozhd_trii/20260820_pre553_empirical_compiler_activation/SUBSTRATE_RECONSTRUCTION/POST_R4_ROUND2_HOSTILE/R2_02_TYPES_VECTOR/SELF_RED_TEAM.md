First, `decoder-normalized batch` could become camouflage for a second decoder. It is lawful only as an exact differential projection of the frozen public decoder; hidden pandas/reader dtype behavior has no authority.

Second, `TAGGED_EXACT_ESCAPE` could become a garbage chute. An escape is lawful only with a versioned total inverse to the exact decoder-observed type/payload. `repr`, generic stringification, ungoverned pickle or nonreconstructible extension metadata do not qualify.

Third, “exact float bits” can overclaim source truth. The current decoder already erases NaN payload identity and converts infinity to text. If source authority later requires those upstream distinctions, the decoder/extraction boundary must be reopened under separate authority; P0 cannot reconstruct them downstream.

Fourth, the vector validator can metastasize into a second semantic system. If bounded exact release-global validation and canonical hashing require duplicating the entire C11/I03/I05 stack rather than a compact fixed projection/validation kernel, the simpler streaming/reference carrier should win on minimality.
