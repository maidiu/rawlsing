# SELF RED TEAM — R2-03 NONCIRCULAR ACCEPTANCE COURT

Status: `HOSTILE_TO_CORRECTED_ORACLE`

The corrected court can still become circular or overconfident. These attacks are acceptance blockers.

## RT01 — Passive reader is candidate code in disguise

**Attack:** candidate authors the "independent" parser or the parser imports the candidate's virtual-event decoder.

**Failure:** carrier and reader share the same omission.

**Rule:** parser must be separately reviewed against frozen physical schema and have no candidate semantic/materialization/query dependency.

## RT02 — Physical spec itself omits information

**Attack:** the format specification says nothing about a field already dropped by candidate design.

**Failure:** passive reader faithfully reads a destructive format.

**Rule:** expected primitive inventory originates from source/authority, not the candidate format. Missing representability fails C4.

## RT03 — Declarative contract copied from buggy production code

**Attack:** the mini-evaluator's "independent" table is generated automatically from production code.

**Failure:** shared bug is copied verbatim.

**Rule:** freeze/review declarative acceptance contract from authority; mutation controls must target every included field family.

## RT04 — Mutation corpus is too friendly

**Attack:** controls mutate only obvious values, not identity, completeness, negative states or zero-incidence metadata.

**Rule:** mandatory control classes are conjunctive and versioned. Candidate acceptance cannot begin if one is absent.

## RT05 — Mutation overfitting

**Attack:** evaluator contains special-case code recognizing the known mutants.

**Rule:** combine hand-seeded canaries with generated field-level mutations and real-source hostile witnesses. Minref logic must be general primitive equality/set law.

## RT06 — Aggregate digest instead of exact comparison

**Attack:** compare only one whole-stream hash.

**Failure:** implementation/serialization collision or wrong field omission is hard to diagnose; accidental non-injective summaries can hide loss.

**Rule:** exact keyed stream equality is dispositive. Digests are receipts/acceleration, with mismatch witnesses and independent cryptographic preimages.

## RT07 — Candidate manifest still defines observed enumeration

**Attack:** passive reader iterates only members listed by candidate and assumes that is completeness.

**Rule:** candidate manifest may locate observed members, but expected kind/count/key domain comes externally. Missing expected primitive fails.

## RT08 — Source truth normalizer shares candidate decoder

**Attack:** expected physical truth is generated by candidate ingestion code.

**Rule:** source expected lane uses frozen source-native decoder/accepted source witness, not candidate compiler.

## RT09 — R4 sneaks back as fixture oracle

**Attack:** hostile fixture expected values are copied from R4 output.

**Rule:** R4 can be compared as an additional subject, never the source of primitive expected truth.

## RT10 — Frozen semantic implementation wins disagreements by seniority

**Attack:** minref disagrees with production; court simply assumes production is right.

**Rule:** authoritative fixture disagreement is `ORACLE_AUTHORITY_CONFLICT`. Candidate cannot pass until adjudicated.

## RT11 — Blind frontier is disclosed by build artifacts

**Attack:** candidate build can change after nonce or embeds oracle/test version.

**Rule:** exact built root and config are committed before nonce. Any post-commit change restarts the court.

## RT12 — Candidate recognizes blind query at runtime

**Attack:** public query seam returns special-cased answers.

**Rule:** independent result is derived from passive primitives. Candidate public seam cannot certify itself.

## RT13 — Nine-family hostile set becomes a sample theorem

**Attack:** one witness per family is treated as complete corpus proof.

**Rule:** family hostile set is sensitivity-only; exact claim scope requires full source inventory closure.

## RT14 — Negative states compared by labels only

**Attack:** several distinct states serialize to similar strings or same no-data object.

**Rule:** typed state identity and reason/authority refs are separately compared.

## RT15 — Integrity passes the smaller universe

**Attack:** candidate deletes a member/record, recomputes all roots.

**Rule:** self-consistent destructive rehash is mandatory control; external semantic inventory defeats it.

## RT16 — Cache is physically reachable despite "disabled" flag

**Attack:** candidate silently reads cache after canonical miss.

**Rule:** primary court makes cache namespace inaccessible. Separate hostile fallback test observes attempted use.

## RT17 — Correct fallback hides wrong root

**Attack:** corrupt candidate returns correct result from old root.

**Rule:** correct answer from unauthorized source is failure. Root under test is isolated.

## RT18 — Benign layout change falsely fails

**Attack:** minref accidentally treats shard order/file name/block ordinal as semantic.

**Rule:** benign relayout/reorder controls must pass before candidate judgment.

## RT19 — Semantic order falsely canonicalized as set

**Attack:** to tolerate physical reordering, evaluator sorts away rank/occurrence/order.

**Rule:** only carrier order is ignored. Governed order/rank/multiplicity fields remain inside primitive identity/payload.

## RT20 — Float/string/type equality uses host language

**Attack:** evaluator uses Python equality for `-0.0`, NaN, bool/int, empty/null, or normalized strings.

**Rule:** typed canonical payload representation is explicit. Physical/source frontiers follow frozen exact type law.

## RT21 — Independent evaluator becomes a second production engine

**Attack:** it gains planner optimizations, caches, source-family branches and persistent repository state.

**Rule:** reject complexity. Keep passive parsing, exact comparison, finite set arithmetic and minimal precedence only.

## RT22 — Source semantic authority is invented by minref

**Attack:** evaluator interprets labels/country codes/weights because a pattern seems obvious.

**Rule:** unresolved semantics remain blocked. Minref consumes authority; it does not create it.

## RT23 — Oracle controls prove sensitivity only on synthetic fixtures

**Attack:** generated cases pass but real-source oddities are missed.

**Rule:** retain all nine source-family hostile witnesses and full claimed source closure.

## RT24 — Current-query behavior rescues reconstruction loss

**Attack:** candidate passes I03/I05 yet source metadata/replay primitive differs.

**Rule:** C2-C4 precede behavior and cannot be waived.

## RT25 — Cryptographic algorithm theater

**Attack:** stronger hashes are mistaken for semantic completeness.

**Rule:** byte identity and semantic inventory are separate. Rehash mutant must still fail semantically.

## RT26 — Authorization omitted

**Attack:** equivalent inactive/stale root is served because it is valid.

**Rule:** trusted active-root authorization is a separate C8 condition.

## RT27 — Candidate-specific waiver

**Attack:** a physical design "cannot expose" a primitive, so the test is narrowed.

**Rule:** inability to expose/reconstruct a frozen obligation is candidate failure or blocked scope, not an oracle adjustment.

## RT28 — Performance bargaining

**Attack:** independent full comparison is expensive, so sampled checks are substituted.

**Rule:** sampling may diagnose resources but cannot make complete equivalence dispositive for a complete claim.

## Final self-falsification

Reject `NONCIRCULAR_ACCEPTANCE_COURT@2` if expected truth ultimately depends on candidate/R4/shared semantic implementation, if mandatory mutants are not killed, if benign invariances fail, or if the evaluator accumulates new semantic authority.

A court that cannot prove its own sensitivity is not allowed to certify the carrier.
