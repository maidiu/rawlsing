# R2-04 SELF RED TEAM — ATTACK THE OPEN-WORLD COURT ITSELF

Status: `HOSTILE_TO_OWN_ROUND2_CONCLUSION`

Final candidate disposition under attack: `ROUND2_PASS_WITH_REQUIRED_CORRECTIONS__P0_REPAIRABLE`

## 1. Open-world can be rhetorically inflated into new semantics

**Attack:** “No finite query vocabulary” is read as permission for arbitrary future predicate operators or leaf meanings.

That would violate the mission. Frozen `EmpiricalPredicate` currently accepts recursive `AND`, `OR`, `NOT`, and exact authorized leaf kinds. I05 exact-bounded discovery has frozen candidate families/forms and authority-bounded K/J limits.

**Defense:** this return uses “open-world” only at the carrier layer: no ingest-time bitmap/index/query catalog may bound the set of future lawful AST instances, target combinations, or exact-bounded authority-declared frontiers. It does not widen semantic grammar.

**Reject this return if:** `P0_OPEN_WORLD_INCIDENCE_ALGEBRA@1` is used to add a new predicate meaning without separate semantic authority.

## 2. “Infinite query vocabulary” can be confused with infinite work per I05 run

**Attack:** the court appears to demand evaluation of an infinite frontier.

Frozen I05 does not. Each authorized exact-bounded run compiles one finite/finitely-constructible frontier, fixes it before data evaluation, and evaluates every candidate. What is forbidden is a carrier-wide finite vocabulary that says future authorized frontiers must be subsets of what was preindexed at ingest.

**Defense:** post-freeze blind tests are finite, exact, replayable and authority-scoped.

## 3. Full scan fallback can become a performance loophole

**Attack:** any catastrophically slow Class-C implementation can claim correctness because it can technically scan everything.

Correctness and practical sufficiency are separate gates. A full scan is enough to prove capability preservation; it does not prove the candidate should be adopted.

**Defense:** question-block/hybrid/vector mechanisms remain conditional. Benchmark whole I03/I05 workload and reject complexity that does not cure a measured blocking/practical failure.

**Reject this return if:** it is cited to waive resource/practical-query gates merely because O(N) fallback exists.

## 4. Negative closure can over-demand full-release verification unnecessarily

**Attack:** R2-04 turns every negative query into a mandatory full release scan even where exact canonical partition metadata proves a smaller exhaustive region.

That would overconstrain lawful optimization.

**Defense:** the rule is full canonical refutation-domain closure, not always whole-release scan. A root-bound canonical completeness structure may prove that a smaller region is exhaustive. Disposable cache metadata may not.

## 5. Canonical completeness indexes can become gratuitous complexity

**Attack:** the correction is read as requiring a new canonical index for every query dimension.

It does not. R01's complete verified scan remains a lawful baseline. Completeness structures are optional and must earn their complexity through a named resource/latency need.

**Defense:** minimality law explicitly prefers scan when sufficient.

## 6. Respondent-set algebra can accidentally hide event multiplicity

**Attack:** if every primitive predicate becomes a Boolean respondent selector, distinct repeated/ranked events might disappear.

For predicate membership, Boolean respondent truth is appropriate where frozen leaf semantics are existential over matching events. For target construction, however, event multiplicity/order/rank must be gathered exactly.

**Defense:** the correction separates `evaluate_leaf_selector` from `gather_target_events`. It never says a selector is the canonical event representation.

**Reject this return if:** selector construction is used to deduplicate or replace event topology.

## 7. NOT base set may be described too loosely

**Attack:** “governed risk set” could be mistaken for one globally materialized risk bitmap.

Frozen I03 resolves exact routing/risk-set facts per target and respondent and has special multi-target common-risk semantics. Unresolved facts are errors, not nonmembers.

**Defense:** NOT is applied only after the exact query's respondent/routing domain is closed under frozen semantics. No generic global complement is authorized.

## 8. Branch membership can be large

**Attack:** requiring exact branch membership to be canonical implies a giant in-memory member list.

The semantic requirement is exact membership/replay authority, not an in-memory representation. R01 bounded streaming/merge mechanics remain available. A branch membership relation can be streamed/indexed physically; a cache can accelerate it.

**Defense:** no corpus-sized Python set is required by this return.

## 9. Source-indexed multi-universe could be needlessly slowed by isolation

**Attack:** source-indexed results can share physical kernels across releases, so forbidding all cross-release alignment would throw away safe vectorization.

The court forbids **semantic respondent linkage/pooling**, not shared implementation kernels. Batches from multiple universes can be processed together so long as selector keys remain exact-universe scoped and results remain source-indexed.

**Defense:** physical co-processing is permitted; semantic co-membership is authority-gated.

## 10. Authorized composite may not require respondent-level linkage

**Attack:** the correction seems to imply composite queries need cross-universe respondent matching.

They do not necessarily. Frozen composite authority can permit pooling/nonduplication/estimand composition without one-to-one respondent linkage.

**Defense:** the correction says no cross-universe alignment *unless exact relation authority requires/permits it*. It does not invent linkage as a prerequisite.

## 11. Weight failure handling can be misstated

**Attack:** “resolve weight for every denominator member” could be read as requiring a positive weight where frozen semantics instead produce a specific typed negative condition.

**Defense:** exact resolution includes detecting missing, invalid or unauthorized weight state and preserving the frozen I03 failure outcome. It does not repair or coerce the weight.

## 12. Diagnostic ablation may remove a separately authorized reporting output

**Attack:** disabling cloud/MI diagnostics would trivially change diagnostic reports, making the metamorphic test impossible.

The invariant is narrower: diagnostic perturbation must not change exact frontier reachability, EmpiricalFact identity, or I04 admission unless separate frozen authority explicitly promotes a diagnostic role—which current I01/I05 forbids for the named diagnostic kinds.

**Defense:** diagnostic report bytes are not the comparison target.

## 13. I04 could expose a hidden physical dependency through fact provenance

**Attack:** a candidate may preserve apparent counts but alter `EmpiricalFact` provenance/replay refs; I04 then changes even though “query result” looks same.

**Defense:** R2-04 requires full fact/ref/provenance parity, not counts. Any changed fact ref is an upstream semantic failure before I04.

## 14. Post-freeze blind frontier can be gamed

**Attack:** a candidate implements a genuinely general index and the court treats “pre-indexed” as suspicious merely because the blind workload is fast.

That would be wrong. General acceleration is lawful if every unseen lawful predicate is supported and the no-cache path is also exact.

**Defense:** the blind frontier tests reachability and parity, not whether the candidate happened to accelerate it.

## 15. P0 might already imply every correction

**Attack:** Authority 54 already states cache nonauthority, governed NOT, no-reingest unseen I05, and negative-state preservation. Calling these “required corrections” may be redundant.

This is the strongest objection to the Round-2 disposition.

**Response:** the court does not claim P0's intent is wrong. It claims implementation admissibility remains under-specified in two decisive ways:

1. “fallback scan” does not explicitly prohibit an optional accelerator from delimiting the canonical scan/refutation domain;
2. P0 does not yet name a minimal carrier-neutral operation contract that every physical organization must pass with accelerators deleted.

If HQ judges Authority 54's existing prose already legally entails those points with no ambiguity, it may absorb this return as clarification rather than textual correction. The semantic disposition remains that P0 survives.

## 16. No raw probe means no new source witness

**Attack:** the court could have missed a source-specific topology/query shape.

The mission did not require source certification. Round-1 R03/R04/R06 already assembled cross-family hostile evidence sufficient to defeat naive matrix/bitmap assumptions, and frozen I03/I05 semantics supply the abstract capability court.

**Defense:** if HQ names a source-physical query ambiguity not established in the checked-in evidence, this return becomes `BLOCKED` for that exact surface and Authority 54's named-evidence raw-probe law applies.

## 17. Final self-disposition

`SURVIVES_SELF_ATTACK__CORRECTIONS_ARE_EXECUTION-LAW_CLARIFICATIONS_NOT_SEMANTIC_EXPANSION`

The most important restraint is that R2-04 must not become a second query engine specification. The frozen I03/I05/I04 contracts remain the semantics. `P0_OPEN_WORLD_INCIDENCE_ALGEBRA@1` merely states what a physical carrier must be able to supply, cache-free, so those semantics stay possible.
