## 4. DESTRUCTION_PATHS_FOUND

The court found no unavoidable information-destruction theorem against the repaired P0. It did find multiple destructive interpretations permitted by the provisional prose. Each must be closed before implementation.

### D01 — observed variation masquerading as grain authority

P0 5.3 describes event incidence as carrying material that “actually varies by event.” That wording is unsafe. A field that happens to be constant in a release has not thereby acquired a release/question/respondent functional dependency. R02 and R06 explicitly reject observed constancy, first-row choice, majority frequency, vector equality, and sampled equality as authority.

**Required repair:** replace the criterion with `EVENT_GRAIN_UNLESS_EXACT_FD_CERTIFICATE`. Grain movement occurs only after determinant, scope, authority, exception law, exact reconstruction, and fail-closed violation behavior are sealed. Otherwise store directly.

### D02 — source-cell locator overreach into semantic-event identity

The R02 arithmetic locator `L = r * V + v` is safe only for a sealed rectangular **source-cell traversal**. It is not a universal C11 `RespondentEvent` occurrence locator. Repeated, ranked, ordered, componentized, multiselect, and alias-MR topology can require multiple exact semantic occurrences associated with one respondent/question/cell surface.

**Required repair:** C06 arithmetic derivation is scoped to physical source-cell coordinates only. C11 event-group ID, deterministic occurrence/event ID, component/subitem, multiplicity, order and rank remain explicit or are separately proved by their own immutable event-topology determinant. Physical row/column/Parquet position is never semantic identity.

### D03 — event-driven metadata discovery loses zero-incidence truth

A compiler that constructs question metadata only from observed event values loses lawful metadata with no matching incidence. Afrobarometer R9 Q78F proves that a missing declaration can exist with zero observed user-missing cells. WVS all-typed-missing columns, MR declarations, type/format metadata, label dictionaries and source encoding/reader provenance likewise cannot be inferred from substantive event incidence.

**Required repair:** P0 must have an independent metadata-first source lane from frozen decoder metadata. Release/question metadata is canonical even when event incidence is zero. Source variable order, storage-slot/continuation law, declarations, labels/dictionaries, type/format/display metadata, MR declarations, encoding/text controls, reader configuration/version and exact compatibility-execution override identity require explicit owners.

### D04 — equality-based variable/topology collapse

WVS raw-identical variables with distinct dictionaries and Asian/EVS overlapping or alias MR sets prove that equality of raw vectors/member sets is not an identity or FD certificate.

**Required repair:** native variable identity/ordinal and topology object/set identity are stored or independently reconstructed from exact source authority. Vector hashes and equal membership may accelerate comparison but cannot deduplicate canonical information.

### D05 — incomplete respondent-grain compaction

Using `(source snapshot, source row ordinal)` as the respondent dimension key is correct, but it is insufficient if the compaction drops the rest of `RespondentIdentity` or treats a native ID as the key. Native respondent-key evidence may be absent, duplicated, colliding or typed missing; it remains source evidence rather than universal identity.

**Required repair:** respondent dimension stores the complete frozen `RespondentIdentity` projection, including source-native respondent-key ref or typed absence and identity-map authority ref or typed absence. Source-native ID variables remain source physical/event evidence. The universal replay coordinate remains source snapshot + row ordinal.

### D06 — default/exception completeness failure

A sparse exception layer is destructive if the default is selected from frequency/first observation or if absence from the exception store is trusted without proving the exception domain complete.

**Required repair:** every default is an encoding of a prior exact determinant; exceptions are canonical/root-bound and exhaustive for the determinant scope; publication validates exception completeness against the direct logical reference/oracle. Violation revokes the optimization for that scope and falls back to direct storage or blocks publication.

### D07 — routing collapsed through response/null incidence

Physical missing, semantic response state, routing eligibility, applicability and risk-set membership are independent. Late materialization can silently turn unresolved/not-asked/inapplicable into empty/zero if routing evidence is filtered away first.

**Required repair:** routing/risk material is a separate canonical relation with all frozen fields and authority/replay refs. No null/missing pattern is a routing default. Negative and aggregate query closure includes the routing evidence capable of changing the denominator.

### D08 — weight vector mistaken for weight/design authority

Exact numeric weights do not determine weight basis, weight source, design authority, estimand authority, normalization/recalibration law, effective scope or admissibility. EVS/WVS/LiTS evidence defeats one-default-weight or shape-based selection.

**Required repair:** the entire `WeightMeasureFact` projection is canonical at its governed respondent/basis/scope grain. No role is inferred from names, values, missing patterns or distribution.

### D09 — provenance/source relation reduced to value equality

Cross-source equality does not authorize linkage, pooling, deduplication, equivalence or nonduplication. Authority/dependency/source-relation/replay refs are not derivable from event values.

**Required repair:** `AuthoritySnapshot`, `SourceUniverseRelation`, object authority/dependency refs, predicate/comparator/discovery/admission replay bindings and `ReplayManifest` fields have explicit canonical owners. Any omission requires its own exact certificate; otherwise direct storage.

### D10 — hot/cold becomes authority partition

A hot/cold split is destructive if opening the hot tier can assert completeness, negative truth, replay closure or exact object identity while cold canonical dependencies are absent.

**Required repair:** hot and cold are storage temperature only. They remain under one canonical root. The logical view must integrity-close every cold dependency relevant to reconstruction/query/replay; missing cold material is incomplete/corrupt, not a degraded valid release.

### D11 — negative completeness mislabeled as cache

Exact absence, zero support and complete I05 coverage may require a canonical completeness structure. If the only proof of exhaustive search lives in a deletable index/cache, cache deletion destroys negative truth even if positive rows remain intact.

**Required repair:** any structure necessary to prove exhaustive absence/coverage is canonical, root-bound information and appears in the information ledger. Only over-approximate or correctness-bypassable accelerators are caches.

### D12 — dense/hybrid geometry omits nonrectangular event evidence

A dense respondent×question block can preserve scalar cells while losing event multiplicity/topology or all-typed-missing incidence if null/elision rules are implicit.

**Required repair:** dense geometry activates only under a sealed complete traversal certificate. Every nonrectangular or topology-bearing surface has a total explicit-event escape path. Every governed physical cell/state remains reconstructable; “no substantive value” is never a deletion criterion.
