## 1. WHOLE_MACHINE_CONTAINMENT

This return defines an **acceptance oracle**, not a storage representation. It writes no runtime code, modifies no `rawlsing_next/**`, changes no frozen authority, and grants no carrier semantic authority.

The reference world is, in descending force:

1. exact source bytes and source-native physical truth under the frozen source constitution/decoder law;
2. frozen I01/I02 C11 semantic identity and M01-M18 closure;
3. frozen I03 exact-query law;
4. frozen I05 exact-bounded discovery law;
5. frozen I04 structural-admission law;
6. closed whole-machine noncollapse, provenance, fail-closed, and replay law.

R4 is admissible only as historical evidence that one implementation passed prior gates. Its partitions, long-row mechanics, reopen behavior, Python object shapes, caches, or execution accidents are not oracle truth.

The oracle preserves the machine boundary:

`SOURCE EVIDENCE != STRUCTURAL PRIOR != GENERATED FACT != ACTOR KNOWLEDGE != MEMORY != EXPRESSION`.

A future carrier passes only if downstream semantics are carrier-ignorant and every applicable source/C11/query/discovery/admission observation survives exactly.

## 2. PROBLEM_OWNED

R03 owns the question:

> How can HQ decide whether an arbitrary future physical replacement is semantically equivalent without comparing it to R4's physical representation or weakening requirements around whatever the candidate finds difficult?

The answer must catch both **loss** and **false invention**. Aggregate count equality is insufficient. A carrier can preserve totals while destroying respondent identity, physical missingness, label dictionaries, rank, routing denominators, weight authority, source relation provenance, lawful negative outcomes, discovery reachability, or admission blockers.

The oracle therefore tests three independent evidence lanes:

- **source-native lane** — source identity, shape, physical states and exact metadata against checked-in source evidence and certified raw-source scans;
- **semantic-law lane** — canonical C11/I03/I05/I04 observations under frozen contracts;
- **candidate lane** — the candidate's carrier-neutral logical export and public seam behavior.

Acceptance requires convergence of all three where authority exists. Where semantic authority is absent, the correct oracle outcome is a typed block/unknown/noncomparability/integrity state, never a guessed positive.

## 3. PROPOSED_MECHANISM

The proposed mechanism is `SEMANTIC_EQUIVALENCE_ORACLE@1`, specified in `PROPOSED_CONTRACT.md`.

It has seven gates:

1. **O0 Authority Freeze** — pin source manifest, source decoder/source-native law, C11/I03/I05/I04 blob identities, whole-machine authority, candidate commit, candidate tuning-workload disclosure, and an oracle run nonce.
2. **O1 Source-Native Equivalence** — independently verify source identity/shape and physical preservation against source-native evidence. Candidate-derived manifests cannot certify themselves.
3. **O2 C11 Canonical Equivalence** — compare full canonical public/internal C11 semantic projections, recompute every content hash/ExactRef independently, and require M01-M18 closure.
4. **O3 I03 Behavioral Equivalence** — run positive and negative exact-query cases and independently recompute respondent-set/support truth from canonical C11 incidence.
5. **O4 I05 Frontier Equivalence** — exercise the frozen candidate families and historical generalized operations, then compile a **post-candidate-freeze blind frontier** not present in the disclosed tuning workload.
6. **O5 I04 Admission Equivalence** — compare exact positive and nonpositive admission decisions, precedence, authority/evidence closure, and positive-projection permission.
7. **O6 Replay/Integrity/Cache Equivalence** — fresh-process deterministic replay, corruption/partial-publication fail-closed tests, stale-cache rejection and full cache deletion/rebuild parity.

Each gate is binary for candidate acceptance: `PASS`, `BLOCKED_BY_MISSING_AUTHORITY`, or `FAIL`. `BLOCKED_BY_MISSING_AUTHORITY` is not a pass and may not be converted into inferred truth.

The oracle includes both:
- **invariance metamorphs**: changes that must not alter semantics, such as legal partition/chunk/cache changes; and
- **sensitivity metamorphs**: changes that must alter a canonical projection/outcome, such as swapping ranked order, dropping a zero-incidence missing declaration, or changing a routing denominator.

## 4. WHAT_CHANGES_PHYSICALLY

Nothing is prescribed.

The candidate may use long form, normalized tables, columnar arrays, matrices, bitmaps, native typed lanes, late materialization, streaming, compression, sparse exceptions, or another lawful layout. R03 neither prefers nor rejects any of those forms in advance.

The only physical requirement imposed by this oracle is observational: after lawful reconstruction, the candidate must expose exactly the source-native and logical information required by the frozen machine, and its nonauthoritative accelerators must be deletable/rebuildable without changing truth.

Carrier-specific physical identifiers such as R4 partition paths or row-group names are explicitly **not** equality targets.

## 9. I03_I05_I04_EFFECT

### I03

The oracle compares full `EmpiricalFact` projections, not only counts. It requires exact target/condition/risk/source/measure identity, respondent-set membership, raw supports, authorized weighted supports, typed fact state, uncertainty/provenance and replay refs.

Positive and negative truth are equally binding. Missing authority/risk/measure/source conditions must produce the frozen lawful negative state. Hash/identity corruption remains an integrity failure and cannot be laundered into `UNAVAILABLE`, `VALID_EMPTY`, or another normal negative.

### I05

The oracle covers the frozen exact-bounded families, including:

- unary/social forks;
- response × coordinate and bounded coordinate conjunctions;
- pair response cotravel;
- bounded k-way response configurations;
- conditional/reversal/Simpson grids;
- minority/nonmodal departure;
- recursive subgroup forks;
- branch-conditioned distributions and cotravel;
- joint/co-signature patterns needed for cloud-like structure.

`CLOUD_SCORE` and related association scores remain diagnostic-only. A diagnostic may report/rank only where separately lawful; it may not prune the exact frontier or become `EmpiricalFact`.

The required **untuned workload** is late-bound: after the candidate commit and its tuning-workload disclosure are frozen, the oracle records a nonce, deterministically compiles exact predicate/query combinations not present in the disclosed tuning hashes, and seals the compiled frontier hash into the replay receipt. The workload must include pair, k-way, conditional/reversal, recursive, branch-conditioned and co-signature/cloud-like cases. Every compiled candidate is evaluated.

### I04

The oracle compares exact admission decision state, public typed state, reason code, authority/evidence/negative refs, target/source/time/estimand/measure closure, and whether positive projection is permitted.

The frozen precedence beginning with integrity/missing/conflicting/denial blockers and ending in `ADMITTED` is tested by blocker injection. Only `ADMITTED` may project positive structural evidence.

## 10. INTEGRITY_REPLAY_EFFECT

A semantic-equivalent carrier must be replay-equivalent under clean-process execution.

Required replay perturbations include:

- fresh process;
- varied `PYTHONHASHSEED`;
- irrelevant filesystem enumeration order;
- legal batch/partition/row-group changes;
- lawful worker/concurrency-count changes;
- cache present versus absent;
- cache built twice from the same authoritative release.

Canonical semantic projections, ExactRefs, I03 facts, I05 receipts/frontier closure, I04 receipts and replay hashes must be identical.

Required fail-closed corruption cases include:

- authoritative member byte flip;
- missing/truncated member;
- pre-seal/partial publication visibility;
- semantic projection mutation with stale stored ExactRef;
- authority snapshot/hash mismatch;
- stale cache from another release.

No corrupted/partial release may return semantic truth. Cache corruption may be healed only by rejecting/deleting the cache and rebuilding from still-valid authoritative state.

## 11. RESOURCE_EXPECTATION

This oracle is intentionally more expensive than a normal query path. It is a release-acceptance instrument, not the production carrier.

Expected resource shape:

- source-native full scans are required for source certification surfaces that cannot be proven from sealed manifests;
- C11 canonical projection/hash comparison is linear in logical objects/records;
- I03 reference evaluation is linear in scoped respondent incidence per query;
- I05 exact work is proportional to the declared finite frontier and its query evaluations;
- corruption/cache/fresh-process suites multiply acceptance-run cost but remain bounded by a fixed manifest.

Performance may be sampled after correctness, but no resource threshold waives a failed semantic gate.

## 12. COMPLEXITY_COST

The main cost is **independent truth machinery**:

- a carrier-neutral logical export adapter;
- a source-native physical witness normalizer;
- a small independent canonical projection/ExactRef verifier;
- a simple independent respondent-set/query evaluator;
- a deterministic blind-frontier compiler;
- fault-injection and fresh-process harnessing.

This duplication is deliberate. If the oracle merely imports the candidate's materialization/index logic, a shared loss bug can make candidate and test agree falsely.

The oracle should stay small by avoiding a second production query engine: only the frozen acceptance grammar and exact set/support semantics need independent reimplementation.

## 15. FALSIFICATION_CONDITIONS

A candidate is falsified by **one** reproducible mismatch on an applicable authoritative surface.

Examples:

- one source byte/shape/ordinal mismatch;
- one lost missing declaration;
- one ordinary blank normalized to null;
- one ExactRef/content-hash mismatch;
- one missing/extra C11 object or internal record;
- one M01-M18 coverage hole;
- one topology/order/rank/multiplicity mismatch;
- one routing/risk denominator mismatch;
- one unauthorized weight/design inference;
- one I03 positive or lawful negative mismatch;
- one I05 candidate omitted, unreachable, differently evaluated or pruned by diagnostic;
- one I04 decision/precedence/projection mismatch;
- one fresh-process semantic drift;
- one corruption case that fails open;
- one stale/deleted cache that changes truth.

`BLOCKED_BY_MISSING_AUTHORITY` falsifies a claim of complete equivalence for that surface until authority closes. It does not falsify the carrier's unrelated surfaces.
