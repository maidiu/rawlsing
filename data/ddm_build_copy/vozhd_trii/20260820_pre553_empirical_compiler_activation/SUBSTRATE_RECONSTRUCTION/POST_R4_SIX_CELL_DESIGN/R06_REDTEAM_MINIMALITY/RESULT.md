1. **Class A presumption.** First prove or disprove the simplest bounded streaming-long path in the complete resource/query/replay court.

## Adversarial findings

### 1. Equality is not a functional dependency

Accepted SR09-PRE evidence defeats several tempting deduplications:

- WVS Wave 4 `V220` and `Q223_LOCAL` can have identical raw vectors while their dictionaries differ.
- WVS Wave 7 `Q223`, `Q223_ABREV`, and `Q223_LOCAL` can have identical raw vectors while retaining distinct variable/label views.
- Asian Barometer Wave 5 and EVS 2008 contain overlapping or alias native multiple-response set declarations; membership equality/overlap does not erase set identity.
- Afrobarometer Round 9 has a declared user-missing code with zero observed user-missing incidence; declaration cannot be inferred from observed cells.
- GSS 2024 participates in a family pattern where every variable declares the shared `[-100,-10]` user-missing range; declaration is metadata, not a fact recoverable from values alone.

Therefore compaction by apparent vector equality, observed incidence, or shared membership is unlawful unless the omitted field is formally reconstructed from a frozen determinant and the reconstruction is independently tested.

### 2. Missingness/absence cannot be compressed through a single null notion

Accepted cross-corpus counterexamples include:

- Arab Barometer Wave 2 `q2062`: true system-missing and ordinary code `0` labeled `missing` coexist in one variable.
- LiTS III `q112_1` and LiTS IV `q1032`: system missing coexists with ordinary `-99` refusal values.
- South Asia Wave 1: code `8` / `No opinion` is ordinary in one variable and format user-missing in another.
- Arab Barometer Wave 8 `BLOCK_ID`: ordinary empty string on 2,408 Iraq rows with zero system missing.

Any typed lane, bitmap, null elision, or source-level missing policy that merges these dimensions destroys replayable physical truth.

### 3. Nonrectangular topology defeats question-only physical assumptions

The accepted corpus contains native MR sets, overlapping aliases, mirrored respondent modules, repeated/ordered/ranked structures, mass skip surfaces, and source-local topology drift. A physical layout keyed only by canonical question risks erasing:

- source variable identity;
- set identity distinct from membership;
- component/subitem identity;
- order/rank/slot;
- respondent/module namespace;
- routing carrier incidence.

The exact query layer requires these distinctions for arbitrary conjunctions, risk sets, replay, and unforeseen I05 discovery.

### 4. Identity cannot float with layout

Accepted evidence includes a source with no evident native respondent ID, a source with 2,400 repeated `ID=0` values, and WVS Wave 4 native-ID values that can themselves be typed missing/colliding. The source constitution correctly makes `(source_snapshot_id, source_row_ordinal)` replay identity authoritative unless stronger identity is proved. Any locator or virtual-event scheme tied to mutable partition/order is therefore a high-risk coupling.

### 5. Source-format irregularity is hostile to over-specialized compilers

Accepted evidence includes SPSS logical-variable continuation slots, a SAV header/dictionary width inconsistency, BIG-5 source encoding, frozen latin1 execution-only overrides, literal C1 controls under declared UTF-8, reader encoding-report conflicts, a reader-option interaction failure, date/display/storage heterogeneity, SAV user-missing declarations/ranges, and DTA system/extended missing states. Source-specialized physical compilers multiply proof obligations unless they terminate in one audited neutral C11 contract.

### 6. Class C can make I03/I05 fast locally while making the machine less exact globally

Question partitions, bitmaps, matrices, and late materialization can lower scans yet endanger:

- arbitrary k-way respondent conjunctions across partitions;
- unanticipated I05 predicates not covered by prebuilt bitmap vocabulary;
- exact risk-set/routing/weight joins;
- reconstruction of rare physical states and topology;
- stable event identity under repartitioning;
- single-copy truth if accelerators become persistent shadow stores.

The optimization court must therefore measure build + reopen + I03 + I05 + replay/reconstruction + integrity, not a favored kernel.

### 7. Integrity mechanisms themselves can overengineer the carrier

A whole-artifact cryptographic identity plus immutable root/release receipt is sufficient unless the threat model or repair/reopen unit requires independently verifiable chunks. A Merkle tree, Parquet checksums, per-member hashes, and cache digests can become redundant integrity layers with distinct version/invalidation rules. Redundancy here increases failure-state ambiguity unless each layer has a named job.

### 8. Current C11 code already encodes useful fail-closed boundaries that replacements must not bypass

Read-only inspection found:

- `C11LogicalRelease` rejects construction without the private validation seal;
- `C11Repository` accepts only validated sealed releases and has exact-key/no-fallback resolution;
- internal/public C11 records validate exact refs, typed absence, authority refs, and content identity;
- I03 consumes exact identity-bearing C11 objects and explicitly rejects fuzzy/default resolution.

R06 does **not** report a present constructor bypass bug. It reports a replacement hazard: a compressed/virtual materializer must not create a second path that fabricates partial public objects or events outside these validated boundaries.
