# R04 SELF RED TEAM — ATTACK THE COLUMNAR/VECTOR ENDGAME

Status: `HOSTILE_TO_OWN_PROPOSAL`

Candidate under attack: `CCIV` — Canonical Columnar Incidence + Virtual C11.

The burden is not “can a matrix store surveys?” It is whether a Class-C physical architecture can remain semantically invisible while preserving the entire source/C11/I03/I05/I04/whole-machine contract and materially outperforming a simpler passing representation.

## Attack 1 — The rectangularity seduction

**Attack:** WVS7 and LiTS I look like respondent x variable tables, so the design deletes explicit event identity and treats row/column position as truth.

**Break:** source reconnaissance establishes multiple-response metadata, overlapping/alias MR sets, repeated/ranked/componentized topology, and no universal native respondent-ID law. Current query semantics can return multiple events per respondent/target and require exact ordering/rank/multiplicity keys. A rectangular cell cannot represent this without extra event structure.

**Required defense:** dense-axis representation is conditional per block. Any unproved or nonrectangular question uses explicit event coordinates/topology. Physical position is never semantic identity.

**Reject if:** the dense profile becomes the universal default and exceptions become an afterthought.

## Attack 2 — “Missing bitmap” semantic collapse

**Attack:** compress observed/missing/DK/refusal/not-asked/inapplicable into one small state map because all are “absence-like.”

**Break:** SR03 proves physical system missing and SPSS user-missing are source-physical distinctions, while the source constitution says semantic state is separately governed. LiTS ordinary labeled sentinel codes can be physically ordinary values. Routing states are separately governed again.

**Required defense:** at minimum distinct raw-value lane, physical-state lane, semantic response-state lane, and routing/applicability relation. No cross-lane inference except exact authority.

**Reject if:** any query can derive routing, semantic absence, or authority from a physical-state code alone.

## Attack 3 — Bitmap vocabulary becomes an ontology

**Attack:** precompute bitmaps for every common value/state and let the query planner reject or skip predicates not represented by a bitmap.

**Break:** I03 grammar permits exact predicates over governed values/states; I05 constructs exact future combinations after ingest. High-cardinality/open-text values make exhaustive bitmap vocabularies impractical. A finite index catalog would turn storage design into empirical possibility authority.

**Required defense:** every predicate has a canonical scan fallback. Bitmaps are removable caches keyed by exact release + predicate semantics + authority dependencies.

**Reject if:** an uncached lawful predicate requires re-ingest, returns unsupported, or is silently pruned.

## Attack 4 — NOT computed against the wrong universe

**Attack:** implement `NOT P` as bitwise complement over all physical rows in a column block.

**Break:** I03 evaluates respondents within exact source/risk-set/routing semantics. Physical row presence is not eligibility. An unresolved routing state must not be coerced into nonmembership.

**Required defense:** complement is taken only against the exact governed respondent/risk-set selector after routing authority resolution.

**Reject if:** physical block cardinality can determine a semantic denominator.

## Attack 5 — Late materialization erases negative truth

**Attack:** apply value predicates first, drop rows without target values, then resolve routing or typed state only for survivors.

**Break:** the frozen query executor distinguishes unavailable routing, explicitly inapplicable, unresolved, valid-empty, zero support/overlap, and target-unavailable states. Early dropping can convert “cannot lawfully decide” into empty/zero.

**Required defense:** authority/risk-set/negative-state resolution precedes any pruning capable of erasing the evidence needed to distinguish these outcomes.

**Reject if:** late materialization changes any negative/failure state even when positive counts match.

## Attack 6 — Question-oriented storage makes joints expensive enough to starve I05

**Attack:** pair/k-way queries must open hundreds of files or repeatedly transpose data; a streaming long scan is actually faster.

**Break:** R04 is not allowed to win on compression alone. I05 includes pair cotravel, bounded k-way configurations, conditional reversals, recursive subgroup forks, and branch-conditioned operations.

**Required defense:** block multiple question lanes per physical member; measure joint-heavy and storage-untuned I05 workloads against streaming-long. Use exact respondent alignment and late target fetch, not precomputed joints.

**Reject if:** required joint/discovery workloads materially regress without a compensating blocking-resource win.

## Attack 7 — Vector compiler bypasses semantic constructors

**Attack:** Arrow kernels populate columns that “look equivalent” but omit frozen object validation because constructing `RespondentEvent` is expensive.

**Break:** the current object/integrity code enforces exact ref hashes, typed-state vocabularies, nonempty authority closure, canonical set ordering/deduplication, deterministic semantic identity, response_state == typed_state, internal/public ontology separation, and cross-record C11 closure. R4 reconstruction deliberately reused the constructor.

**Required defense:** enumerate and independently implement all observable invariants in vector form; differentially compare full semantic projections/content hashes against the frozen semantic oracle on hostile fixtures and generated rare exceptions. Missing invariant means fallback or rejection.

**Reject if:** vector acceptance is based only on counts, values, or successful Parquet readback.

## Attack 8 — Source specialization becomes source semantics

**Attack:** the code says “WVS => dense scalar,” “LiTS => dense numeric,” “EVS => MR exceptions,” and downstream query code branches accordingly.

**Break:** the campaign explicitly forbids I03/I05 source-family branches for storage convenience. Family identity does not prove topology, missingness, or semantic meaning.

**Required defense:** profile selection is based only on exact release-local physical capability descriptors whose semantic consequence is zero. The logical interface does not expose source family as a meaning switch.

**Reject if:** adding a new source requires a new I03/I05 semantic branch rather than a compiler/profile certification.

## Attack 9 — Axis compaction claims functional dependencies R04 does not own

**Attack:** question-level topology, event IDs, canonical question refs, authority sets, or respondent properties are stored once because they appeared constant in WVS/LiTS samples.

**Break:** R02 owns functional-dependency proof. “Usually constant” is forbidden. Rare exceptions are exactly where semantic destruction hides.

**Required defense:** R04’s baseline stores material directly. Axis/default omission activates only when R02/equivalent authority names determinant, scope, exception law, and failure behavior.

**Reject if:** byte reduction relies on an unproved event-field omission.

## Attack 10 — Physical-state bit packing loses declarations

**Attack:** encode only `FORMAT_USER_MISSING_VALUE` and discard which declared code/range produced it.

**Break:** source-native law requires missing declarations, including declarations with zero observed incidence. Two codes/ranges can share a physical class while remaining different source facts.

**Required defense:** state code is only the class lane; exact variable declaration metadata remains canonical, and cell-to-declaration matching is reconstructable where required.

**Reject if:** decoding cannot recover the exact declaration associated with a cell or preserve unobserved declarations.

## Attack 11 — String/typed value lane corrupts exactness

**Attack:** dictionary encoding, null handling, Unicode normalization, float conversion, or Arrow casting changes raw identity.

**Break:** raw versus canonical separation is frozen; ordinary blank strings remain ordinary source values; semantic hashing forbids casual binary-float identity. R02 owns exact type-preservation proofs.

**Required defense:** CCIV consumes only R02-approved typed encodings; it may not invent type coercion. Any value that cannot be losslessly represented uses an exact typed fallback lane/exception.

**Reject if:** round-trip source/C11 equivalence depends on lossy Arrow casting or normalization.

## Attack 12 — All-missing column elision

**Attack:** a column contains only typed missing states, so the compiler records only “all missing” metadata or drops it.

**Break:** cross-corpus reconnaissance explicitly says all-row typed-missing columns remain source information. Question existence, declaration metadata, typed state, routing, and future source comparisons survive even without substantive values.

**Required defense:** retain the question and exact per-row state incidence or use only an independently proved immutable derivation law that reconstructs it exactly.

**Reject if:** “no substantive values” becomes a deletion criterion.

## Attack 13 — MR alias deduplication

**Attack:** two MR sets share the same variables, so storage interns them to one topology object.

**Break:** R10 explicitly forbids deduplication of overlapping/alias MR-set identity by shared membership.

**Required defense:** topology identity and relation membership are content-addressed/governed objects, not inferred from equal variable sets.

**Reject if:** equality of physical members implies semantic/topological identity.

## Attack 14 — Cache staleness returns plausible wrong answers

**Attack:** source release or authority dependency changes but a persisted predicate bitmap remains readable.

**Break:** a stale cache can produce a fully plausible respondent set and therefore poison I03/I05 invisibly.

**Required defense:** caches are keyed by canonical release identity and exact semantic/authority dependency hashes; reopen verifies cache key; mismatch discards cache. Cache corruption never degrades to “best effort.”

**Reject if:** a cache can be used without proving exact dependency closure.

## Attack 15 — Release identity depends on caches

**Attack:** cache rebuild changes member hashes and therefore the authoritative release hash.

**Break:** then a performance artifact has become semantic provenance.

**Required defense:** authoritative release seal enumerates canonical members separately; caches have a separate optional cache manifest and are excluded from canonical release identity.

**Reject if:** deleting a cache changes an ExactRef, replay root, I03/I05/I04 result, or canonical release identity.

## Attack 16 — Corruption fallback is permissive

**Attack:** one incidence block hash fails; planner skips the block, falls back to stale bitmap, or returns partial results.

**Break:** partial plausible results are more dangerous than hard failure.

**Required defense:** authoritative member corruption invalidates the release for affected semantic operation and fails closed. Only corrupt nonauthoritative cache members may be discarded and regenerated.

**Reject if:** authoritative corruption can produce a result state other than integrity failure/unavailability required by frozen law.

## Attack 17 — Matrix position leaks into semantic identity

**Attack:** event object IDs are calculated from physical block/column/row coordinates.

**Break:** block widths, Parquet row groups, compaction and file reorganization are physical choices. Semantic identity must survive physical re-layout.

**Required defense:** virtual event reconstruction uses exact semantic fields/refs and frozen hashing only. Physical locators can locate bytes but cannot enter semantic projection unless independently governed source-event identity already does.

**Reject if:** repacking a semantically identical release changes logical object IDs/hashes.

## Attack 18 — I05 benchmark is tuned to the storage

**Attack:** benchmark only low-cardinality pair predicates that have bitmaps and conclude CCIV dominates.

**Break:** I05’s purpose includes unforeseen combinations. Storage-tuned benchmarking hides the most important failure mode.

**Required defense:** freeze at least one discovery frontier after the physical design is fixed; include uncached, high-cardinality/string, k-way, reversal, recursive/branch, and multi-universe cases.

**Reject if:** every benchmark predicate was known to the index designer before storage/index design.

## Attack 19 — Operational complexity eats the gain

**Attack:** CCIV saves 30% bytes but doubles compiler/query code, certification matrices, corruption modes, and maintenance burden.

**Break:** whole-machine law prefers the minimum sufficient mechanism. Class C has a higher proof burden than simpler lower-risk designs.

**Required defense:** measure end-to-end compile, reopen, audit, I03, I05, replay, disk, RSS, and operational artifacts; compare to R01 streaming-long.

**Reject if:** benefit is modest/nonblocking or mostly disk compression.

## Attack 20 — The simplest design is already good enough

**Attack:** R01 produces a bounded streaming-long carrier that passes exact parity, stays under hard/preferred budgets, and is operationally simple.

**Break:** there is no remaining reason to accept CCIV’s extra semantic attack surface.

**Required defense:** none. CCIV should lose.

**Required disposition:** `REJECT_CCIV__SIMPLER_PASSING_CARRIER_IS_SUFFICIENT`.

## Final hostile verdict

CCIV is technically plausible only as a challenger. Its strongest feature is not matrix compression but the combination of: direct batch/vector compilation, question projection pruning, exact ephemeral respondent-set algebra, and late materialization while retaining an explicit event/topology escape hatch and an open-world scan fallback.

Its strongest weakness is architectural complexity. If the lower-risk streaming-long design is sufficient, CCIV should be rejected even if it is smaller.
