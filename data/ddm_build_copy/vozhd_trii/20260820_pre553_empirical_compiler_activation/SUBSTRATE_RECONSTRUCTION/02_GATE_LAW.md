# SUBSTRATE RECONSTRUCTION GATE LAW

## G-SR00 — Command freeze
PASS iff frozen parent, write terrain, evidence rank, task states, terminal dispositions, and pause boundary are explicit.

## G-SR01 — Source byte universe
PASS iff every serious empirical source/release has one exact file identity, format, byte count and SHA-256; duplicates/aliases are adjudicated; expected source count reconciles.

Current census: 35 real files = 31 SAV + 4 DTA. macOS AppleDouble files excluded as packaging metadata.

## G-SR02 — Legacy writer genealogy
PASS iff every script/SQL writer touching empirical source, respondent, response, weight, demo, mapping, cube, aggregate, or derived empirical surface is inventoried and every relevant DB surface has a writer/provenance disposition.

Static discovery alone does not establish execution history. Current populated state must be probed read-only where execution history materially affects trust.

## G-SR03 — Source-native physical metadata
PASS iff all 35 sources have machine-generated physical manifests covering row count, variable identity/order, storage/value types, raw labels, missing machinery, respondent-ID candidates, weights/design candidates, topology-relevant metadata, and format-specific metadata without semantic normalization.

SAV must preserve SPSS user-missing declarations/ranges and system missing distinctly. DTA must preserve Stata system/extended missing distinctly and ordinary labeled sentinel codes without reclassifying them.

## G-SR04 — Physical carrier selection
Candidates are evaluated on exact Rawlsing workload. Required order: correctness -> speed -> lightness.

Minimum candidates:
- Parquet canonical + DuckDB analytical engine;
- PostgreSQL canonical C11 implementation/control.

SQLite disposition at campaign start: `NO_PRIMARY_ROLE__REOPEN_ONLY_FOR_A_CONCRETE_SMALL_MUTABLE_METADATA_NEED`.

PASS iff candidate produces identical exact answers for required I03/I05 hostile workloads and has recorded latency, throughput, peak RAM, disk size, cold-start/replay cost, operational dependencies, deterministic rebuild identity, and failure behavior.

No carrier wins on speed if it loses information or replay semantics.

## G-SR05 — Format-neutral source constitution
PASS iff a single source-native incidence contract lawfully represents both WVS7 SAV and LiTS I DTA without equating physical missingness with semantic response state.

Must retain at minimum source snapshot, row identity, variable/event identity, raw storage value, physical missing state, source value label, source missing declaration, source variable metadata, source-format metadata, and authority linkages required by M01-M18.

## G-SR06 — Decoder/C11 implementation
PASS iff implementation contains thin SAV/DTA physical decoders plus one format-neutral C11 writer/repository interface, with no source-specific semantic inference inside the physical decoder.

## G-SR07 — WVS7 hostile certification
PASS iff exact raw source -> C11 proves preservation of WVS typed absence, rank topology, source identity, weights/design evidence, local codes, respondent incidence and exact joints. All legacy-positive retained values must parity-check where legacy provenance is trustworthy. Legacy missing-row collapse must not be reproduced.

## G-SR08 — LiTS I hostile certification
PASS iff exact raw source -> C11 proves ordinary labeled semantic sentinel codes remain observed source codes, Stata physical missing remains distinct, respondent identity is preserved, weights remain distinct, and exact joints replay.

## G-SR09 — Remaining-source batch certification
Every source/release ends in `CERTIFIED`, `FAILED`, or `BLOCKED`. No family-level certification by analogy.

## G-SR10 — Legacy surface disposition
Every relevant legacy DB surface ends in one terminal disposition. Derived empirical surfaces used by the rebuilt machine must be regenerated from certified C11 or explicitly retained only as compatibility/historical evidence.

## G-SR11 — Populated PRE553 re-entry
PASS iff I03 exact query, I05 discovery and I04 admission run from certified C11, with no legacy Postgres carrier required as empirical truth.

## G-SR12 — Reservoir reclosure / rebuild resume
PASS iff deterministic populated reservoir and whole-machine hostile suites close, all campaign threads terminalize, and an exact resume head is emitted.
