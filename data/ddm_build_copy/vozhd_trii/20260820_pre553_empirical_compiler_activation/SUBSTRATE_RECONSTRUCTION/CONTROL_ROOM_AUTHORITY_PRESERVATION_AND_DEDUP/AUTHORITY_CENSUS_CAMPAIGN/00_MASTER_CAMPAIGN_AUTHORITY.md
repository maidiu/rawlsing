## 1. Mission

Construct an exhaustive, content-addressed, provenance-aware map of the authority that Rawlsing already possesses before authorizing creation of any replacement or new semantic/structural authority.

The campaign must answer, with evidence:

1. What authority-bearing objects exist?
2. Where does every physical copy of each object live?
3. What exact epistemic work does each object perform?
4. Which objects were manually/adjudicatively created, mechanically derived, documentary, review-only, or unresolved?
5. Which historical objects remain live?
6. Which later objects losslessly absorb or supersede earlier authority, and under what accepted rule?
7. Which apparent gaps are merely unlocated, unadjudicated, or unproved supersession?
8. What authority is genuinely absent after exhaustive search and therefore still needs to be made?

The governing order is:

`DISCOVER -> LOCATE -> HASH -> INSPECT -> ADJUDICATE -> PROVE LINEAGE -> PROVE GAP -> ONLY THEN AUTHOR NEW AUTHORITY`
