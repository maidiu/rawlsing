# HQ Recovery Task Protocol

For REC-01 and REC-02, the executable task file and any named `*_INPUT_ACCESS_PATCH.md` are jointly binding.

Where an input-access patch conflicts with an earlier current-tree read assumption, the patch controls.

Pinned sibling worker returns are immutable evidence inputs and must be read by exact commit/path (`git show`) without merge, rebase, cherry-pick, or working-tree mutation.

A worker must never infer that a sibling return is unavailable merely because its path is absent from the current recovery branch.
