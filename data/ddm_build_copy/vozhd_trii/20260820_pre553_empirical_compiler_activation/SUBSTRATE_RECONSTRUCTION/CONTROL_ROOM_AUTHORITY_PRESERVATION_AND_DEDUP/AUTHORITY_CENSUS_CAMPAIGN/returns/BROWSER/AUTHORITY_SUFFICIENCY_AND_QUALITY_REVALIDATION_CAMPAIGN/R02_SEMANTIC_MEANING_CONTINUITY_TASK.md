# R02 — Semantic Meaning, Concept & Continuity Quality Court

Status: `ISSUED__NONDISPOSITIVE__HIGH_REASONING`

## Mission

Hostile-revalidate the quality of Rawlsing's governed semantic meaning, concept grouping, continuity/equivalence and canonical semantic-coordinate judgments, especially where they originate in legacy agent/manual stages not independently revalidated to the current standard.

The question is not whether semantic authority exists. The question is whether its **meaning claims survive source-backed challenge**.

## Primary scope

- P2 semantic-unit / concept / continuity / pair authority;
- R9D terminal Job-2 semantic meaning;
- R10G canonical semantic coordinates and bounded successors;
- P3/P3C family/variant/genealogy authority where it bears on meaning or continuity;
- implementation-to-semantic-unit membership;
- source target/actor/condition/modality/horizon judgments embedded in semantic authority.

## Core audit questions

For each audited assertion ask:

1. Does the semantic unit preserve the proposition actually asked by the source?
2. Are actor, target, object, condition and modality preserved?
3. Does a continuity/equivalence edge collapse meaningful source differences?
4. Conversely, are materially equivalent implementations incorrectly separated?
5. Are hypothetical/intention/realized behavior/status/perception/normative judgments distinguished correctly?
6. Is a source label being treated as sufficient where questionnaire context changes the proposition?
7. Does the canonical coordinate exceed the evidence ceiling?
8. Did later source-backed authority actually correct an earlier semantic problem, or merely relabel it?

## Risk priorities

Elevate:

- legacy-agent-produced semantic groups with weak provenance;
- cross-wave/cross-family equivalence;
- high-fanout semantic units feeding many Job-3 candidates;
- multi-target and multi-condition batteries;
- translation-sensitive items;
- semantic-only anti-joins;
- source-helper aliases;
- items whose response topology suggests a different proposition class than the semantic label;
- any lineage where R07 finds elevated source contradiction.

## Sampling

Follow the common deterministic risk protocol.

Additionally include:

- a representative cross-family baseline from all nine families;
- all known `T4_CRITICAL` semantic conflicts within practical bound;
- a bounded sample of apparently easy/low-risk units to detect systematic overconfidence;
- at least 50 equivalence/continuity assertions if denominator permits;
- at least 50 target/condition/modality-heavy items.

## Source evidence

Prefer exact questionnaire/codebook/source-native context and response options. Variable labels alone are insufficient where fuller source context exists.

## Defect significance

Classify defects as:

- `LOCAL_LABEL_OR_METADATA_IMPRECISION`
- `MATERIAL_SEMANTIC_CATEGORY_ERROR`
- `UNSUPPORTED_EQUIVALENCE`
- `MISSED_EQUIVALENCE`
- `TARGET_ACTOR_CONDITION_LOSS`
- `MODALITY_HORIZON_LOSS`
- `SOURCE_CONTEXT_CONTRADICTION`
- `ONTOLOGY_JURISDICTION_ERROR`

Only material defects count toward systematic-quality triggers.

## Forbidden

- no wholesale semantic rewrite;
- no preference-based taxonomy changes unsupported by source evidence;
- no replacing P2 implementation identity;
- no relation/driver/routing authority creation outside this court's meaning-quality evidence;
- no promotion of the worker's preferred interpretation to canonical authority.

## Terminal proposal

For each material semantic lineage, propose one of:

- `LEGACY_AUTHORITY__HOSTILE_SAMPLE_PASS`
- `QUALITY_ACCEPTABLE_WITH_BOUNDED_LOCAL_DEFECTS`
- `SYSTEMATIC_DEFECT_DETECTED__TARGETED_EXPANSION_REQUIRED`
- `SOURCE_LIMITED__AMBIGUITY_IS_REAL`
- `HQ_CONFLICT_ADJUDICATION_REQUIRED`.
