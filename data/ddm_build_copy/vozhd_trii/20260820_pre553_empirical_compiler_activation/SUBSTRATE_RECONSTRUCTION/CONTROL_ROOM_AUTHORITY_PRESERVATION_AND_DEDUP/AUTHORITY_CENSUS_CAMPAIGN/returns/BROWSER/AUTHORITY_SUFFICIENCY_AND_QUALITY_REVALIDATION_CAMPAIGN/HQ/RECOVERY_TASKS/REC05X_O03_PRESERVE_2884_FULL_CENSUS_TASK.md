## 6. Mechanical topology rules

These rules prevent recurring category errors. They do not replace exact source evidence.

### Ordered scale

If source labels explicitly encode ordered intensity/frequency/agreement/likelihood/evaluation/importance/rank/quantity bands, then a current nominal classification that discards order is defective.

Examples of textual order signals include:

- never / rarely / sometimes / often / always;
- strongly disagree ... strongly agree;
- very unlikely ... very likely;
- very bad ... very good;
- none / some / most / all;
- first / second / third / ... rank;
- bounded numeric quantity or duration where the object is genuinely quantitative.

Do not assume interval distance merely because order exists.

### Nominal single choice

Named alternatives without a source-defined order remain nominal. Numeric category codes do not create order.

### Binary state/indicator

A yes/no, reason/not-a-reason, selected/not-selected or other state indicator is not automatically a substantive two-pole tradeoff.

### Ranked/priority choice

A question asking for one most-important/priority item is not a ranked-response object unless the respondent actually supplies multiple rank positions.

### Multiselect child

Preserve child selection/nonselection nested within its source battery and preserve missing/not-asked/routed states separately.

### Tradeoff

Use tradeoff only when the source names substantively opposed alternatives/poles. Do not use tradeoff for administrative quantities or simple binary indicators.

### Special states

DK/refusal/IAP/not-asked/missing/nonresponse are not substantive scale anchors and do not establish topology.
