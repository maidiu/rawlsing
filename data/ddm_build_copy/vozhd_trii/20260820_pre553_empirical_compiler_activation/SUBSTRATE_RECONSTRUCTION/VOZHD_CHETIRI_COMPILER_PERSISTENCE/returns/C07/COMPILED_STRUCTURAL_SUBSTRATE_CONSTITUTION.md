Status: `NON_DISPOSITIVE__STRUCTURAL_SUBDAG_OF_COMPLETE_LEARNED_WORLD`

## Boundary

The compiled structural substrate is one branch of the learned-world DAG, not Rawlsing's whole learned destination. It contains governed structural knowledge and semantics-preserving runtime views; it never contains generated actor life.

## Direct reuse law

If an earlier authoritative object already provides the necessary immutable identity, semantics and availability, the downstream learned release SHOULD reference it rather than republish equivalent payload. A new physical copy requires an independent operational or publication justification.

## Runtime deletion test

Deleting P4 runtime racks/indexes may make startup or lookup slower but must not alter the structural answer. Ordinary V3 runtime must be reconstructible from retained P2/P3 structural releases/receipts without respondent/event-grain empirical truth being silently required by the rack.

## Life exclusion

The structural substrate MUST NOT contain actor exposure, actor orientation, actor belief, actor memory, actor knowledge/accessibility state, realized disposition, biography, actor-specific attractor realization, or V2 expression. It may preserve structural prerequisites that V3 develops through history.

## Provenance

Every structural learned release binds its exact upstream structural authority references, empirical/source references where admission lineage requires them, release identity, support/uncertainty/admission state, dependency fingerprints and replay/explanation lineage. Provenance need not be duplicated into every runtime row if an exact immutable reference is sufficient.
