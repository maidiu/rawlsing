# PROPOSED MINIMAL HQ ADOPTION — C07 EMPIRICAL VALIDATION TRANSITION META-LAW

Status: `PROPOSED_ONLY__POSITIVELY_DERIVED_CONSOLIDATION__NO_STATISTICAL_POLICY_INVENTED`

Proposed identity:

`C07_EMPIRICAL_VALIDATION_TRANSITION_META_LAW@1.0.0`

## Purpose

Close only the semantic transition/governance seam between an exact discovered candidate and a C07 learned-world validation disposition. This adoption does not create a validator, significance threshold, confidence level, resampling count, power rule, diagnostic score, or empirical-comparability rule.

## Binding transition law proposed for HQ

1. `DiscoveryResultReceipt` is candidate-evaluation evidence, not by itself a validated learned relation.
2. Every learned-world validation attempt must positively bind one exact validation-rule authority/version before execution. If no exact rule is bound, disposition is `BLOCKED_MISSING_AUTHORITY`.
3. Existing exact source/release/universe/risk/measure/topology/replay determinants remain mandatory. Missing/conflicting authority is never empirical rejection.
4. Positive exact noncomparability, where already governed for the evaluated scope, terminalizes as `NONCOMPARABLE`; this court does not create the separate general comparability law.
5. Positive governed support insufficiency terminalizes as `UNDERPOWERED`; no implementation fallback or worker-chosen threshold is elevated to production authority.
6. Valid-empty/zero-evaluable-evidence remains distinct from rejection.
7. `VALIDATED` may be minted only when the exact named validation rule executes over authority-complete, sufficiently supported, comparable evidence and returns its positive disposition.
8. `REJECTED` may be minted only when the exact named validation rule executes over authority-complete, sufficiently supported, comparable evidence and returns its explicit negative disposition.
9. A current I05 `DISCOVERED_RESULT_SUPPORTED` is sufficient **validation evidence** for the exact I05 validator that produced it, but it does not auto-promote to `VALIDATED` until this transition law is adopted and a learned-world validation release is minted with the required lineage.
10. A current I05 `VALID_EMPTY` is not sufficient by itself to mint `REJECTED`, because current I05 also uses that state for pre-validation valid-empty evidence. A rejection transition must bind the exact validator execution path/evidence proving the negative disposition rather than infer from the state token.
11. The validation release must bind at minimum: candidate identity; discovery authority/ref; source/release/universe/risk/measure/topology determinants; exact validation rule/version; validation fact refs; support/uncertainty state; validation disposition; replay ref; dependency/invalidation determinants.
12. Validation-rule change invalidates validation/accepted-relation descendants but never rewrites source evidence.
13. Structural admission remains downstream and separate. No `VALIDATED` relation becomes structural authority except through accepted I04/structural-admission law.
14. Any product family or validation operation lacking its own exact positive validator/rule remains `BLOCKED_MISSING_AUTHORITY` after this meta-law is adopted.

## Exact effect if HQ adopts

Closed by consolidation:

- candidate-versus-validation noncollapse;
- terminal-state precedence/non-substitution;
- explicit positive pass/reject requirement;
- no implicit default statistical policy;
- validation release provenance/replay/invalidation requirements;
- exact fail-closed behavior when rule authority is absent.

Not closed:

- any missing product-family-specific validator;
- any missing support/uncertainty/statistical parameter required by a validator;
- the separate empirical-comparability authority;
- positioned-subject possibility model authority;
- source-universe composition authority;
- structural admission authority;
- architecture A/B/C.

Therefore HQ adoption would narrow the C07 marker from a blanket missing validation law to a precise set of missing validation-rule bindings while preserving fail-closed behavior.
