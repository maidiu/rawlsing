## 1. Three non-collapsible compiler input classes

The complete PRE553 compiler consumes three epistemically distinct inputs:

1. **A — authoritative source evidence**: immutable source bytes, source-native metadata, exact incidence, frozen decoder/config/replay determinants.
2. **B — governed source-semantic authority**: questionnaire/codebook/methodology meaning; response states; routing/applicability/risk sets; topology; weights/design/estimands; source universe/time/comparability; source→canonical C11 binding.
3. **C — governed Rawlsing semantic/structural authority**: semantic roles, response lanes, directionality, directional applicability, use eligibility, block/battery authority, driver/facet/domain/axis/target mappings, position conditioning, QRA/QSM/Full Question Relation authority, manual overrides, and negative/blocked/review-required states.

Neither A nor A+B derives C by default. I05 statistical discovery is empirical evidence only and cannot manufacture C.

## 2. Required compiler intake behavior

- pin every consumed authority artifact by identity/version/hash or exact immutable repository commit;
- preserve epistemic class: manual/adjudicated, deterministic derivation, frozen accepted precedent, unresolved/blocked, diagnostic/proposal-only;

- emit provenance from every accepted structural/semantic output back to exact authority inputs;
