# BLIND DISCOVERY FIXTURE SPEC

## Freeze protocol

The fixture generator/oracle is frozen **before** the discovery grammar/frontier is executed. The I05 runner receives only governed atoms/templates/authority, not a named expected relationship. Expected truth is held by an independent oracle. No real-survey empirical relationship is invented or presumed.

Every fixture must record exact respondent rows, risk sets, topology, measure basis, universe/time identity, authority refs, grammar/frontier hash, candidate count, and terminal coverage receipt.

## Required hostile fixtures

### 1. XOR / zero unary signal
Binary X and Y each have zero unary signal for Z, while `X XOR Y` predicts Z exactly. Pass only if the higher-order lawful candidate is reached without unary screening.

### 2. Simpson reversal
Pooled association has the opposite direction from each governed stratum. Preserve pooled and stratified facts separately and detect the reversal only under explicit stratum authority.

### 3. Rare minority mode
A small but sufficiently supported subgroup has a materially different response mode. Pass only if prevalence/top-k does not prune it.

### 4. Deep conditional fork
A lawful relation appears only under a predeclared multi-level branch ancestry. Parent/child ancestry refs must survive exactly; no adaptive score-driven expansion is invented.

### 5. Three-way interaction invisible unary/pairwise
Construct Y from parity of A/B/C such that all unary and pairwise margins are flat. The bounded k-way joint must expose it.

### 6. Identical marginals / different joint topology
Two universes or branches have identical marginals but different joint cell structure. Exact joint facts/refs must remain distinct.

### 7. Contradictory recurrent configuration
The same broad condition contains two recurrent, adequately supported response configurations pointing in opposite directions. Multimodality/contradiction must survive rather than collapse to one mean/modal story.

### 8. Weighted / unweighted reversal
Raw support and a separately authorized weighted estimand reverse direction. Both are exact but different facts; no implicit default weight.

### 9. Routing false signal
Naive missingness creates an apparent relationship because risk sets differ. Exact routing/applicability authority must remove the false signal or type the comparison noncomparable.

### 10. Topology false cotravel
Naive respondent-question flattening makes repeated/ranked/MR occurrences look like same-event cotravel. Exact occurrence/topology identity must prevent the false joint.

### 11. Multi-universe pooling reversal
Separate source universes/time slices support different relationships; unauthorized pooling produces a reversal. Without explicit composition/comparability authority, pooled discovery must fail closed as noncomparable rather than emit a fact.

## Additional exact-negative controls

For each fixture include at least one lawful candidate known to be:

- `EVALUATED_VALID_EMPTY`;
- `EVALUATED_UNDERPOWERED` where support rules demand it;
- `EVALUATED_NONCOMPARABLE` where authority forbids comparison;
- `EVALUATED_DENIED_BY_EXACT_AUTHORITY` or `EVALUATED_MISSING_OR_CONFLICTING_AUTHORITY`.

A complete-search negative is accepted only when every compiled candidate has a terminal state. Budget exhaustion, timeout, missing decoder dependency, missing authority, or partial source traversal is never relabeled as absence.

## Diagnostic boundary

Cloud/MI/NMI/Cramer's-V style diagnostics may be computed for reporting if separately authorized, but the fixture must prove that they cannot prune the frontier or become canonical empirical truth. The accepted I05 test already rejects diagnostic validation as a fact-producing rule.
