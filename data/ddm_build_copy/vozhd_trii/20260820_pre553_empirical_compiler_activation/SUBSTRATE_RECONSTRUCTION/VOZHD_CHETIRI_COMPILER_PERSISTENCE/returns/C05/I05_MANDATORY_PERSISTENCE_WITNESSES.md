# I05 MANDATORY PERSISTENCE WITNESSES

## Must persist for correctness / authority

1. **Exact raw source bytes and source snapshot identity.** Primary physical evidence until separately certified/retired.
2. **Source semantic authority and C11 side-material that is not exactly derivable from bytes.** Routing/applicability, semantic response states, topology/occurrence, weight/design meaning, universe/time/comparability, mapping authority, and immutable authority snapshots remain explicit where required.
3. **Canonical semantic object identities used by the discovery program.** Exact predicates, query specs, risk sets/universes, and other governed objects referenced by the frozen program must be resolvable by ExactRef.
4. **Production `DiscoveryAuthority` and exact candidate grammar.** These define the lawful search frontier and cannot be reconstructed from observed results or a physical cache.
5. **Frontier/completeness/replay receipts.** Exact frontier hash, candidate identities/coverage states, branch ancestry, replay identity, and typed negative scope must survive if the result is to be reused as a claim of complete search.
6. **Canonical empirical facts and validation products that are retained as learned-world evidence.** Support/uncertainty and validation provenance must remain exact.
7. **I04 admission receipts for any structural use.** Discovery candidates do not self-promote into structural truth.

## May be transient or optional regenerable acceleration

- decoded physical frames/batches;
- typed value/state vectors derived exactly from source + authority;
- respondent ordinal arrays;
- predicate masks/bitsets;
- conjunction/XOR/branch masks;
- joint/co-signature working sets;
- query-result memoization;
- compiled in-memory frontier if the exact grammar/catalog can reconstruct it identically;
- cloud/association diagnostic values;
- temporary sort/hash/scratch.

These are lawful as nonauthoritative acceleration only if deletion changes **cost, not reachability, facts, coverage, exact-negative scope, or replay identity**.

## Not established as mandatory

C05 found no witness showing that a permanent full respondent×event payload table is logically required by I05. The present return does not establish the opposite either, because the required source-backed production program was not executable.

## Exact-negative rule

A full-event table is not, by itself, a completeness proof. Exact absence requires the governed frontier identity plus evidence that every candidate in that frontier reached a terminal coverage state under the exact source/universe/risk/measure authority. Persist the closure receipt; do not infer completeness from storage format.
