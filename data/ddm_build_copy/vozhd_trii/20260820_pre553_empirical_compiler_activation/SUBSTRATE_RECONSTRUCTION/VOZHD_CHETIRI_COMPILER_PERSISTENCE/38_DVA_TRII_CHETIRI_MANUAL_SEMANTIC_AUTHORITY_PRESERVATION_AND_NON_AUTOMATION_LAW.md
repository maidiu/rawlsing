## 0. Purpose

This authority closes one specific future-drift risk:

> Rawlsing has accumulated a large body of source-semantic, question-semantic, directional, applicability, relational and structural authority that was created through documentary research, manual review, manual adjudication, governed human/agent judgment, and explicit fail-closed decisions. A cleaner physical source pipeline MUST NOT cause later workers to assume that this semantic authority is automatically reconstructable from `.sav` / `.dta` bytes, labels, variable names, frequencies, source codebooks, embeddings, LLM interpretation, or generic heuristics.

The portable physical/source-backed compiler does **not** erase the epistemic labor that made the existing 35-source Rawlsing semantic world lawful.

Binding rule:

`PORTABLE_SOURCE_EXECUTION != AUTOMATIC_SEMANTIC_AUTHORITY`

and:

`RAW SOURCE + DOCUMENTS != GOVERNED RAWLSING MEANING UNLESS AN ACCEPTED AUTHORITY RULE ACTUALLY DERIVES THAT MEANING`

## 2. Two different authority layers MUST remain distinct

### 2.1 SOURCE-SEMANTIC AUTHORITY

This layer answers what the survey source itself means and what may be lawfully projected into C11.

Potentially manual/documentary authority includes:

- questionnaire item identity and wording;
- codebook correction/reconciliation;
- source-native category meanings;
- ordinary-code versus semantic-absence interpretation;
- routing / skip / applicability / risk-set meaning;
- multiple-response, repeated, ranked, matrix, household-member and other topology meaning beyond dumb physical metadata;
- respondent/native-ID semantic scope;
- country/local-category meaning;
- weight role, estimand, target population, design and lawful combinations;
- source-text encoding authority when compatibility decoding is not semantic text authority;
- wave/release equivalence or non-equivalence;
- cross-source comparability/noncomparability;
- source-specific semantic authority overlays;
- manually recovered or corrected documentary authority.

A dumb decoder or statistical pattern may expose evidence relevant to these questions. It does not thereby answer them.

### 2.2 RAWLSING SEMANTIC / STRUCTURAL AUTHORITY

This layer answers how lawfully understood empirical material may participate in Rawlsing's learned world and structural pipeline.

Potentially manual/adjudicated authority includes:

- question semantic role;
- relation-evidence versus position/context/admin/missingness/forbidden classification;
- response-semantic lane;
- directional meaning / polarity;
- directional applicability;
- response topology for downstream use;
- question-block/battery authority;
- source-local versus cross-wave equivalence;
- relation-axis identity;
- structural-domain identity;
- target-entity identity;
- driver and driver-facet identity;
- position-conditioning meaning;
- eligibility for response distribution, demographic prediction, branch splitting, cotravel/co-signature, attitude-cloud diagnostics, V551 relation evidence, parent-prior coordinates, temporal-pressure use and runtime/persona evidence;
- manual exceptions and overrides;
- negative authority, blocked coordinates, review-required states and forbidden inference;
- structural admission authority.

These decisions are not automatically recoverable from C11 empirical incidence.

## 3. Manual work is SEMANTIC CAPITAL, not incidental build residue

The fact that an authority was manually or semi-manually constructed does not make it an implementation smell.

Where a decision required documentary interpretation, semantic adjudication, cross-source comparison, contextual reasoning or explicit policy/jurisdiction choice, its accepted result is part of Rawlsing's governed epistemic capital.

A later implementation may:

- normalize its storage;
- compile it into a canonical immutable authority product;
- create indexes;
- validate it automatically;
- propagate it deterministically;
- reuse it across proven-equivalent survey items;
- retire superseded intermediate files under explicit provenance-preserving retirement authority.

A later implementation may NOT treat the underlying semantic decision as reconstructable merely because the final authority can now be read by software.

`MACHINE_READABLE_AUTHORITY != MACHINE_DERIVABLE_AUTHORITY`

## 4. Forbidden automation assumptions

Absent explicit accepted derivation authority for the exact field, no worker/runtime may manufacture new governed semantic authority from:

- variable names or codes;
- labels alone;
- question text alone;
- embeddings/similarity;
- LLM interpretation;
- source-family resemblance;
- cross-wave name similarity;
- observed response distributions;
- missingness frequency;
- native-ID injectivity;
- source ordering;
- co-occurrence/correlation;
- discovered I05 association;
- existing structural mappings in neighboring questions;
- majority vote among heuristics;
- convenience defaults;
- a claim that a manual task is now 'obvious'.

Automation may propose candidates for review. Proposal is not authority.

## 5. Lawful automation boundary

The following may be automated when their exact rules are already governed:

- byte hashing and source identity;
- decoder execution;
- source-native metadata extraction;
- row/variable/cell incidence traversal;
- deterministic joins to accepted authority;
- exact replay-coordinate construction;
- validation of authority closure;
- propagation of an already-governed mapping across an explicitly governed equivalence class;
- generation of review queues;
- detection of conflicts, drift and missing authority;
- hostile tests;
- exact I03 computation;
- governed I05 search within its frozen frontier;
- compilation of accepted empirical/structural learned-world products;
- provenance/hash/receipt construction.

None of these operations grants authority to invent a semantic mapping that is absent from the accepted authority graph.

## 7. New-survey portability law

A new `.sav` / `.dta` family does NOT become persona-generation ready merely by passing physical/C11 source certification.

Admission is layered:

1. `PHYSICAL_SOURCE_ADMITTED`
2. `SOURCE_SEMANTIC_C11_ADMITTED`
3. `EMPIRICAL_I03_I05_ADMITTED`
4. `CROSS_SURVEY_SEMANTIC_EQUIVALENCE_ADMITTED` where applicable
5. `RAWLSING_SEMANTIC_STRUCTURAL_AUTHORITY_ADMITTED`
6. `PERSONA_GENERATION_ELIGIBLE`

A family may lawfully stop at any earlier layer while later authority remains missing.

The presence of a generic source-backed C11 facade changes the cost of physical admission. It does not collapse these authority gates.

## 8. Reuse law

Existing manually adjudicated authority SHOULD reduce future manual burden when exact equivalence is positively governed.

For example, a new wave may reuse an existing canonical question/response/direction/structural mapping only after the new source item is lawfully bound to the same governed semantic unit and scope.

Forbidden shortcut:

`SAME LABEL / SAME CODE / SAME FAMILY -> SAME SEMANTICS`

Lawful reuse:

`EXACT NEW SOURCE ITEM + POSITIVE EQUIVALENCE AUTHORITY -> REUSE EXISTING GOVERNED SEMANTIC AUTHORITY`

The manual work is therefore reusable, not disposable.
