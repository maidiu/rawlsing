# DR-R02 — V554 DIRECT ADMISSION MINIMALITY

## 1. Dispositive ruling

For the admission class that is already temporally complete for the target use and needs no new V553-owned temporal/comparability meaning:

`DIRECT_V554_EDGE_REQUIRED_FOR_NON_TEMPORAL_CLASS`

This is not a universal `StructuralEmpiricalAdmission -> V554` permission. It is a typed direct edge whose eligibility is governed by the V554 affordance rule registry.

## 2. Why the edge is required rather than merely optional

R01 already rejects mandatory no-op transit through V553.

If a lawful structural admission is:

- complete as an admitted structural proposition;
- complete in time/scope for the intended V554 use;
- eligible under a V554 rule;
- and requires no V553 temporal/comparability transform;

then V554 is the earliest existing stage that creates new downstream meaning: `BOUNDED_STRUCTURAL_AFFORDANCE` and its pre-route applicability conditions.

Without the direct edge, the machine has only two choices:

1. starve an otherwise lawful structural use; or
2. manufacture a no-op V553 object solely to preserve stage numbering.

Both violate the accepted rebase law.

Therefore the direct edge is required for the non-temporal affordance-eligible class.

## 3. V554 still does not consume generic empirical evidence

The lawful direct input is:

```text
StructuralEmpiricalAdmission
```

not:

```text
EmpiricalFact
DiscoveryResultReceipt
PositionedSubjectEmpiricalPossibilityField
C11 incidence
```

Admission has already established the bounded structural interpretation/use under separate authority. V554 then performs its own unique operation: whether that exact governed structural basis is eligible as a mediation input and what V554-owned applicability conditions attach.

## 4. Minimum direct admission contract

A direct admission presented to V554 must expose or immutably dereference enough information for the V554 rule to identify its semantic basis without rematching labels.

Minimum semantic basis:

- `structural_empirical_admission_id`;
- structural-admission rule ID/version/hash;
- exact target structural relation/object/use identity;
- exact source/driver and target/receiving position refs where the admission meaning has them;
- relation axis / structural channel where governed;
- structural source→target direction where governed;
- `0..n` role-qualified finite-stratum refs where governed;
- generic Horizon / explicit Absolute-Horizon refs only when positively governed;
- native geography/scope identity and grain;
- exact effective time/interval required by the target use;
- typed support/uncertainty/negative/noncomparability state relevant to admission;
- exact producer/replay locator sufficient to reach the underlying empirical fact/query/universe/measure authority.

V554 should not copy the entire `EmpiricalFact`, query AST, response contingency or C11 rows merely to have this information nearby.

## 5. V554 rule-registry extension

No new authority **class** is required merely to permit the direct edge.

The accepted V554 architecture already requires `V554_AFFORDANCE_RULE_REGISTRY` to bind eligible upstream object classes/signatures to one bounded use class.

R02 requires that registry to be extended with explicit input-basis semantics, at minimum:

- `basis_kind = DIRECT_STRUCTURAL_EMPIRICAL_ADMISSION | V553_TEMPORAL_OBJECT`;
- eligible admission/temporal object class/signature;
- required structural reference classes;
- whether V553 temporal semantics are mandatory for the rule;
- temporal-completeness requirements for direct admission;
- positive/denial precedence;
- duplicate-equivalence key;
- rule ID/version/hash.

This is an extension of the already-required authority, not a new generic structural-promotion authority.

## 6. Coexistence with V553-temporalized evidence

V554 may lawfully have two different input basis families:

```text
A. DIRECT_STRUCTURAL_EMPIRICAL_ADMISSION
B. V553_TEMPORAL_OBJECT
```

They are not two interchangeable physical routes to be unioned blindly.

Each V554 rule declares which basis family it accepts.

Examples:

- a rule for a point/static bounded structural affordance may accept A;
- a rule whose eligibility depends on persistence/change/comparability may require B.

## 7. Precedence and deduplication

For one structural proposition/use/rule version, exactly one eligible semantic basis is allowed unless the rule explicitly says that two distinct propositions are independent participants.

The minimum duplicate identity is conceptually:

```text
(structural proposition identity,
 structural use class,
 originating StructuralEmpiricalAdmission lineage,
 V554 rule id/version)
```

Rules:

1. `basis_kind = V553_TEMPORAL_OBJECT`: V553 object is the semantic basis; originating admission is provenance only.
2. `basis_kind = DIRECT_STRUCTURAL_EMPIRICAL_ADMISSION`: admission is the semantic basis; any V553 restatement that adds no required meaning is ineligible as a duplicate.
3. If V553 creates a genuinely new temporal proposition, it is not a duplicate; it receives its own proposition identity and may support a different rule/use.
4. Artifact presence, latest timestamp, score, row order and filename do not establish precedence.

## 8. Hostile cases

### H1 — direct admission lacks exact effective time required by V554 rule

Direct edge fails closed. If V553 can lawfully create the missing temporal semantic, route through V553; otherwise `MISSING_AUTHORITY` / no positive affordance.

### H2 — admission has source year but V554 rule requires persistence

Source-year metadata is insufficient. V553 required.

### H3 — V553 output exists only because a compatibility pipeline created one, but it adds no temporal meaning required by the V554 rule

Compatibility existence is not semantic precedence. Direct admission remains the lawful minimal basis.

### H4 — same admission can feed two V554 rules, one static and one temporal

The static rule may use direct admission. The temporal rule may require V553. These are distinct use identities, not duplicate entry.

### H5 — discovery result has a high score and identifies the admission's underlying cohort

The score does not make it a V554 basis. V554 consumes the separately governed admission.

## 9. Later-stage bypass rejection

Direct admission does not justify skipping V554 to V555 or V556.

- V555 creates route semantics over one V554 affordance.
- V556 creates interaction/topology semantics over V555 routes.

Without the preceding producer object, neither stage has the input grain required by its accepted jurisdiction.

## 10. Close-read obligations

The V554 stage close-read must freeze:

- exact machine-readable direct admission signature;
- exact `basis_kind` vocabulary;
- positive/negative precedence;
- duplicate-equivalence key;
- which structural references are directly indexed versus transitively dereferenced;
- compatibility treatment for old V553/V552/V552J paths.

It may harden this contract, but a return to universal no-op V553 transit would require concrete semantic evidence, not convenience.
