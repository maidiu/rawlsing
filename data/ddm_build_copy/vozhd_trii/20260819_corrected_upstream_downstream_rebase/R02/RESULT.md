## 1. Dispositive result

DR-R02 closes with:

`DIRECT_DAG_OWNERSHIP_MINIMALITY_CLOSED__R03_READY`

R02 resolves the broad direct-DAG ownership/minimality frontier while preserving R01 and frozen D15 upstream law.

The principal theorem is:

> **Every object routes to the earliest lawful consumer that creates the first unique semantic transformation. Temporal structural admissions go through V553 only when V553 must create new temporal/comparability meaning; temporally complete non-temporal admissions that are V554-rule-eligible enter V554 directly. Later structural stages remain because they create distinct affordance, route, interaction/topology, publication-governance and repository/resolution meaning. Provenance is normally preserved by immutable transitive reference closure rather than repeated semantic copying.**

## 2. V553 temporalization boundary closed at broad-sweep level

R02 establishes a finite semantic rule.

### V553 required

V553 is required when downstream structural use needs a semantic that is not already lawfully complete in `StructuralEmpiricalAdmission`, including:

- new cross-wave/cross-time comparability decision;
- temporal harmonization across governed representations;
- new temporal relation/delta;
- temporal limit/noncomparability;
- derived effective period/historical interval;
- derived relation timing/sequence;
- a governed persistence/drift/change/reversal/rupture semantic.

The rule is not triggered merely because an object has a timestamp or came from a historical survey.

### V553 not required

V553 is not required when:

- the admission is already a complete structural proposition;
- exact time/interval/scope needed by the target use is already governed;
- no new temporal relation/comparison/harmonization/limit/interval/timing semantic is needed;
- an existing downstream owner can perform the next unique structural transformation directly.

This boundary is specified in `V553_TEMPORALIZATION_BOUNDARY.md` and `STRUCTURAL_ADMISSION_ROUTING_MATRIX.csv`.

## 3. Direct non-temporal admission -> V554 resolved

R02 returns:

`DIRECT_V554_EDGE_REQUIRED_FOR_NON_TEMPORAL_CLASS`

for admissions that are:

- structurally admitted already;
- temporally complete for the V554 use;
- explicitly eligible under a V554 affordance rule;
- not dependent on any new V553 temporal/comparability semantic.

This edge is required rather than merely optional because otherwise the machine would either starve a lawful non-temporal structural use or manufacture a no-op V553 object solely to preserve stage numbering.

V554 is the earliest existing structural owner that creates new meaning for this class: bounded mediation-input eligibility and V554-owned applicability conditions.

The direct input remains `StructuralEmpiricalAdmission`, not raw `EmpiricalFact`, discovery score, PSEPF or C11 incidence.

## 4. V554 authority impact

The already-required `V554_AFFORDANCE_RULE_REGISTRY` must be extended to distinguish input basis class and precedence, including at minimum:

This extension does not widen generic empirical-to-structural authority. `StructuralEmpiricalAdmission` remains the only generic upstream promotion seam.

## 5. Direct V555/V556 admission bypass rejected

```text

```

because V555's unique route grain requires exactly one V554 `BOUNDED_STRUCTURAL_AFFORDANCE` plus a route rule, mediator/channel role and receiver constraint.

Principal rulings:

- admission -> V556 = `FORBIDDEN_SEMANTIC_EDGE`.

## 7. Precedence / deduplication law

One structural proposition may not enter the same V554 use twice because both direct admission and a V553 derivative happen to exist.

A V554 rule declares one basis family for the use:

```text
DIRECT_STRUCTURAL_EMPIRICAL_ADMISSION
or
V553_TEMPORAL_OBJECT
```

For a fixed structural proposition/use/rule version:

- if V553 semantics are required, the V553 object is the semantic basis and admission remains provenance;
- if no V553 semantics are required, direct admission is the semantic basis and any no-op temporal restatement is ineligible;
- both may coexist only when they are genuinely distinct structural propositions or use classes.

Artifact presence, latest timestamp, score and row order do not create precedence.

## 9. Reference-closure minimality

R02 rejects flat copied provenance as the default downstream representation.

The target is a content-addressed immutable transitive reference graph.

For example:

```text
V556 F1/F2
-> V555 route
-> V554 affordance
-> [V553 temporal object when required]
-> StructuralEmpiricalAdmission
-> EmpiricalFact
-> EmpiricalQuerySpec / EmpiricalUniverse / measure / authority / replay
```

is sufficient exact closure if every locator is immutable and the standalone V558 repository can resolve it with raw producer stage directories absent.

Therefore V556 does not need a copied `EmpiricalQuerySpec` ID, weight basis or admission payload on every row merely for convenience.

Direct operational indexes may repeat locators for performance, but those copies are nonsemantic and may never outrank the producer reference.

The wrapper therefore survives the minimality test as a narrow V3 boundary object.

R02 does not design the metabolism algorithm.
