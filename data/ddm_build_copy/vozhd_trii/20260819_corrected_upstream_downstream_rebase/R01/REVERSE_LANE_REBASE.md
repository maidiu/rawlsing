# DR-R01 — REVERSE POSSIBILITY LANE REBASE

**Court:** Vozhd Trii DR-R01  
**Status:** broad dependency/contract rebase only

## 1. Frozen upstream path

The corrected upstream reverse service is binding:

```text
objective generated actor fact(s)
-> ActorComparabilityService
-> ActorComparatorReceipt(s)
-> exact empirical conditioner predicate
-> source applicability
-> EmpiricalQueryEngine
-> exact source-indexed EmpiricalFact(s)
-> PositionedSubjectEmpiricalPossibilityField
-> V3EmpiricalPossibilityInput
-> V3 developmental metabolism
```

The field remains:

```text
POPULATION EMPIRICAL POSSIBILITY GEOMETRY
!= ACTOR STATE
!= GENERATED STRUCTURAL POSITION
!= BELIEF / RESPONSE / MEMORY / KNOWLEDGE / PERSONA
```

## 2. V553-V558 hostile jurisdiction test

DR-R01 attempted to locate a unique semantic transformation any structural stage could lawfully perform on the reverse field.

### V553

V553 owns temporal structural observations/relations/limits over already-governed structural evidence. PSEPF is not a structural proposition and requires no V553 temporal structural transformation.

**Result:** no jurisdiction.

### V554

V554 owns bounded structural mediation-input eligibility/applicability. PSEPF is not structural affordance and does not state that an actor occupies a structural position.

**Result:** no jurisdiction.

### V555

V555 owns actor-independent structural mediation route candidates derived from V554 F1 affordances. PSEPF is not a route, mediator, channel or receiver constraint.

**Result:** no jurisdiction.

### V556

V556 owns governed interaction/topology over V555 structural routes. PSEPF is neither a route nor structural interaction/topology.

**Result:** no jurisdiction.

### V557

V557 publishes runtime-authorized structural objects. It has no domain-semantic ownership and its repository path is explicitly structural.

**Result:** no jurisdiction and no transport need.

### V558

V558 resolves structural priors only. Adding PSEPF to `StructuralPriorRepository` would create a generic all-prior container and erase the type boundary D12/D15 established.

**Result:** no jurisdiction.

Therefore the direct V3 lane is not merely an optimization. It is the only presently lawful downstream ownership result.

## 3. Exact producer/consumer boundary

### Producer side

`PossibilityFieldService` owns the canonical source-indexed `PositionedSubjectEmpiricalPossibilityField`.

It depends on:

- exact actor objective fact refs/effective time;
- exact comparator receipts;
- exact source-applicability authority;
- exact EmpiricalUniverse identities;
- exact query/risk-set/topology/measure identity;
- support/uncertainty state;
- C11 content/replay identity.

### Consumer side

V3 must gain a narrow intake capability represented by `V3EmpiricalPossibilityInput` or a terminally equivalent typed boundary.

The wrapper is semantically justified because it binds a **V3 decision context** to one or more immutable PSEPF refs, effective time, negative states and the metabolism rule version. It must not duplicate the field payload as a second authority.

Broad ruling:

```text
PSEPF producer authority remains upstream.
V3 intake owns admission to developmental use.
V3 owns developmental consequences.
```

## 4. Objective actor fact seam

The reverse lane creates one new outbound dependency from V3-generated truth to the corrected upstream comparator service.

V3 must expose exact objective generated demographic/biographical fact references and effective time to `ActorComparabilityService`.

This is **not** a V3->survey inference rule. V3 owns the fact; comparator authority owns whether that fact is empirically comparable.

The following are forbidden comparator substitutions:

- generated nine-stratum structural position;
- actor belief;
- actor memory;
- current simulated response;
- population prevalence used to fill a missing actor fact;
- fuzzy/nearest semantic/geographic matching.

The comparator receipt returns to the field producer as proof/provenance. It is not a standalone actor prior.

## 5. Lifecycle and effective-time semantics

The pre-correction V3 architecture has no field lifecycle because the field did not exist. DR-R01 therefore identifies a required downstream authority question rather than inventing the rule.

At minimum the V3 intake/metabolism contract must bind:

- objective actor fact snapshot/hash used by comparator;
- actor effective/query time;
- PSEPF field ID/hash;
- source component identities;
- target tuple/query identity;
- comparator/source/uncertainty authority versions;
- metabolism rule version;
- typed field state;
- replay identity.

A field may be reused only while its governed identity remains applicable. A later field is a new immutable input, not mutation of the old one.

Potential refresh causes to be adjudicated by the V3 close-read include:

- objective comparable actor fact changes;
- effective/query time crosses a comparator/source applicability boundary;
- target query/arity changes;
- admitted source universe changes;
- upstream C11/authority version changes where runtime policy requests refresh.

Actor belief, memory, response or attractor changes are **not** automatic refresh causes merely because they changed. Those are developed states, not comparator facts.

## 6. Negative authority

V3 must receive typed negative/weak states without synthesizing a replacement field.

At minimum:

- `NO_FIELD`;
- `ACTOR_PROPERTY_MISSING`;
- `NO_COMPARATOR`;
- `AMBIGUOUS_COMPARATOR`;
- `TEMPORAL_NONCOMPARABLE`;
- `SOURCE_NOT_APPLICABLE`;
- `TARGET_UNAVAILABLE`;
- `ZERO_SUPPORT`;
- `LOW_SUPPORT`;
- `UNCERTAINTY_UNQUANTIFIED`;
- source disagreement/noncomparability.

Binding semantics:

- zero support = no empirical conditional basis;
- low support = supported but weak/uncertain;
- no comparator = no reverse empirical inference;
- disagreement remains source-indexed information;
- no nearest-cohort/default/global distribution fallback is implied.

## 7. V3 metabolism boundary

The missing authority is real:

`V3_EMPIRICAL_POSSIBILITY_METABOLISM_AUTHORITY`.

It must specify how field geometry may influence the selection/proposal of otherwise lawful developmental possibilities while preserving V3 causal ownership.

The authority may not authorize:

```text
belief_probability = field.mass
response_probability = field.mass
actor.identity = modal_configuration
actor.memory = survey_configuration
actor.knowledge = field component
actor.structural_position = comparator predicate
```

The field can constrain possibility; generated life must still pass through actual V3 opportunity, encounter, exposure, relationship, mediation, action, consequences, memory/knowledge rules, path dependence and explicit lawful randomness.

The same field and same structural context must remain compatible with divergent lives under different generated histories.

## 8. Relationship to ResolvedStructuralContext

V3 now has two upstream families:

```text
ResolvedStructuralContext
+
V3EmpiricalPossibilityInput
```

They are not merged.

`ResolvedStructuralContext` answers structural-world questions already governed through V553-V558.

`V3EmpiricalPossibilityInput` supplies source-indexed population possibility geometry for the lawfully comparable generated subject.

A V3 rule may jointly condition on both only under explicit metabolism/developmental authority. Neither object may rewrite the other.

## 9. Replay

Reverse-field replay remains upstream and binds field/comparator/query/C11/source/uncertainty authority.

V3 causal replay additionally binds:

- exact V3EmpiricalPossibilityInput refs;
- metabolism authority version;
- structural context bundle/query refs where used;
- actual V3 event/state history;
- named RNG stream/candidate-set identity where randomness participates.

A field replay proving the same population geometry does not prove the same actor life. That is required, not a defect.

## 10. V2 / application impact

V2 remains expression-only over V3 actor-safe generated truth. Application remains presentation/session + typed external-event proposal transport.

No new positive V2/app input is needed.

However the new nonstructural empirical possibility object creates one boundary-hardening requirement worth carrying forward:

> PSEPF, comparator receipts, source disagreement and V3EmpiricalPossibilityInput are not persona, belief, voice or expression authority and may not be dereferenced directly by V2/application.

Opaque provenance refs may pass only if the V3 render/accessibility boundary explicitly marks them audit-safe; they confer no expression semantics.
