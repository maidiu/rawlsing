# DR-R01 — STRUCTURAL LANE REBASE

**Court:** Vozhd Trii DR-R01  
**Base:** `afffe8573a54bcc3b6aad801496abca65665b095`  
**Status:** broad dependency rebase only; no final V553+ redesign

## 1. Governing correction

The corrected upstream structural seam is frozen as:

```text
C11
-> EmpiricalQuerySpec / EmpiricalFact
-> StructuralEmpiricalAdmission
-> lawful structural consumer(s)
```

The old stage-number instinct:

```text
anything structurally relevant
-> V553
-> V554
-> V555
-> V556
-> V557
-> V558
```

is not itself authority.

D15's own canonical object model already states that `StructuralEmpiricalAdmission` may be consumed by `V553 structural temporalization/harmonization` **and by direct-DAG structural consumers where authorized**. The post-D15 parent then explicitly demotes D15's V553+ matrix from final architecture to a rebase seed.

Therefore DR-R01 does not accept `StructuralEmpiricalAdmission -> V553` as a universal transit law.

## 2. What V553 uniquely owns

The accepted V553 contract remains independently coherent.

V553 owns:

- temporal structural identity;
- exact temporal observation identity;
- lawful cross-wave temporal relation/delta semantics;
- temporal limit / negative authority;
- temporal comparability/harmonization under exact authority;
- preservation of producer-owned structural references.

V553 does **not** own:

- generic empirical query evaluation;
- empirical-to-structural admission;
- bounded structural affordance;
- mediation routes;
- cross-route structural interaction;
- runtime publication;
- stage-blind runtime resolution;
- reverse positioned-subject possibility.

Accordingly, V553 remains required whenever an admitted structural proposition needs the temporal transformation V553 actually owns. It must not become a generic admission bus merely to preserve numbering.

## 3. Corrected V553 intake

For temporally governed structural use, the corrected intake must be equivalent to:

```text
StructuralEmpiricalAdmission
  + exact EmpiricalFact / EmpiricalQuerySpec reference
  + EmpiricalUniverse/source identity
  + support/measure/uncertainty basis
  + structural target/relation/direction/use authority
  + exact replay/authority snapshot identity
-> V553 temporal semantics
```

Respondent-event C11 incidence does not cross the boundary. V553 receives an already-governed structural proposition plus exact replay provenance.

Old V552/V552J fact/admission packets become compatibility inputs only for the semantics intentionally retained by explicit admission parity. They are no longer the complete target producer frontier.

## 4. V553 bypass theorem

DR-R01 establishes a broad-sweep theorem:

> If a `StructuralEmpiricalAdmission` does not require a V553-owned temporal/comparability transformation, routing it through V553 merely because V553 is numerically next is an `OBSOLETE_TRANSIT_DEPENDENCY` candidate.

This does **not** select the final direct consumer. It establishes that the final consumer must be the earliest downstream stage that owns a necessary semantic transformation and has explicit authority to accept that admission class.

The strongest present candidate is V554 because:

1. V554 already has a canonical input authority/reference resolver;
2. V554 creates the next unique semantic object, `BOUNDED_STRUCTURAL_AFFORDANCE`;
3. V554 architecture already prefers direct-DAG reuse over copying producer-owned meanings;
4. V554's missing `V554_AFFORDANCE_RULE_REGISTRY` is exactly the authority that can declare eligible corrected upstream object classes;
5. V555 constitutionally requires exactly one V554 F1 affordance as its route basis;
6. V556 constitutionally requires V555 route identities as its base graph.

Thus a generic new `StructuralEmpiricalAdmission -> V555` or `-> V556` shortcut is not supported by current independent stage law.

R02 / the V554 close-read must determine the exact direct-admission classes, if any, that V554 may accept and the precedence between direct admissions and V553-temporalized inputs.

## 5. V554 rebase

V554's unique jurisdiction remains:

```text
exact governed structural basis
-> BOUNDED_STRUCTURAL_AFFORDANCE
+ STRUCTURAL_MEDIATION_APPLICABILITY_CONDITION
```

The corrected upstream requires the V554 rule registry to distinguish at least:

- V553-temporalized structural basis required;
- direct non-temporal `StructuralEmpiricalAdmission` basis permitted;
- direct admission prohibited because temporal support is required;
- raw `EmpiricalFact` prohibited;
- reverse possibility field prohibited.

No admission, temporal object, source label or diagnostic score creates F1 eligibility without the V554 rule.

Exact canonical admission/query/replay refs should be preserved in F1/F2/B1 when they are part of the source basis. Those refs remain producer-owned provenance, not V554 semantics.

## 6. V555 rebase

No corrected-upstream object displaces V555's accepted semantic grain:

```text
exactly one V554 F1 affordance
x one governed V555 route rule
x one mediation locus/channel role
x one receiver constraint
-> one STRUCTURAL_MEDIATION_ROUTE_CANDIDATE
```

Therefore:

- no raw empirical fact enters V555;
- no discovery result enters V555 by scoring alone;
- no `StructuralEmpiricalAdmission` bypasses V554 to become a route;
- no possibility field becomes a route or route condition.

The only likely rebase is reference-contract hardening so a route can reach corrected admission/query/replay provenance through direct refs when relevant.

V555 remains `STILL_VALID_INDEPENDENTLY` at broad-sweep level.

## 7. V556 rebase

V556's accepted no-duplicate-base-edge law remains independently correct.

Its base graph is still the set of V555 routes admitted for structural use. Its unique semantics remain:

- governed `2..n` cross-route/cross-pressure interaction relation;
- governed structural attractor-prerequisite topology.

No empirical association, discovery score, `EmpiricalFact`, `StructuralEmpiricalAdmission` or reverse possibility field may directly instantiate a V556 F1/F2 object.

Corrected empirical provenance may remain reachable behind the participant V555/V554/V553/admission chain. V556 should not copy or re-own it.

## 8. V557 rebase

The corrected upstream strengthens rather than weakens V557's existing mixed-producer law.

V557 still owns:

- runtime publication authorization;
- permission narrowing;
- referential closure;
- immutable collection publication;
- publication/use provenance.

It owns no new structural domain meaning.

The corrected graph may add `StructuralEmpiricalAdmission`, `EmpiricalFact`, `EmpiricalQuerySpec`, `EmpiricalUniverse` and `ReplayReceipt` IDs to the transitive closure required to interpret published structural objects. That is an object/reference registration change, not a reason to republish them as V557-owned semantic copies.

`PositionedSubjectEmpiricalPossibilityField` is not a V557 structural runtime object.

## 9. V558 rebase

V558 remains an immutable stage-agnostic **structural** repository and deterministic structural resolver.

Its repository may need to preserve corrected admission/query/replay reference closure for structural objects. It must not absorb:

- PSEPF;
- ActorComparatorReceipt as a runtime prior;
- DiscoveryAuthority/DiscoveryResultReceipt as generic runtime context;
- raw C11 incidence.

The existing mixed-producer resolver contract is already the correct antidote to stage-number repackaging: V3 can resolve a structural context containing exact producer-owned IDs without each stage re-owning the object.

## 10. Producer-owned direct reuse

The following direct-reference posture survives the rebase:

```text
V553 temporal object
  -> V554 semantic use where rule-authorized
  -> exact upstream refs remain reachable

V554 F1/F2
  -> V555 route semantics
  -> exact upstream refs remain reachable

V555 routes
  -> V556 graph semantics
  -> route IDs remain V555-owned

mixed V553/V554/V555/V556 graph
```

This is not redundant duplication. Each stage adds a unique semantic transformation. The redundancy to eliminate is *transit copying* of earlier meaning, not the downstream objects themselves.
