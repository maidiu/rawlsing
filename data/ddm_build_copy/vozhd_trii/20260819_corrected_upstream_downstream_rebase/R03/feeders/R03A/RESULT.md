## 3. Attack results

### A01 — apparently static admission with hidden temporal semantics

Constructed case: an admission carries one exact 1985 structural proposition. A V554 rule is described superficially as consuming a static basis, but the actual governed use asks whether the condition persisted to 1995, whether two waves are comparable, or whether an interval must be derived.

A safe architecture must classify **the target use**, not just the admission's visible time fields. R02 does so in its finite temporal predicate and routing matrix: persistence/comparison/derived interval forces V553 when the relevant temporal authority exists; unresolved authority fails closed.

The attack does not falsify H01. It does expose a required qualification: the V554 rule signature must declare its temporal demand, and source-relation/comparability prerequisites must already be positively governed. `looks static` is never a routing class.

**Status:** `SURVIVES_WITH_QUALIFICATION`.

### A02 — timestamp/history metadata with no new temporal meaning

Constructed case: a structurally admitted point proposition has exact `effective_time = 1985`; the V554 rule asks only whether that same governed basis is eligible for a bounded affordance at 1985. A compatibility path can manufacture a V553-shaped observation that adds no new temporal relation, interval, limit, comparison, or harmonization.

No V553-owned semantic transformation exists. Sending the object through V553 would be transit/repackaging and would create duplicate-path pressure when the direct basis is also available.

R02 explicitly rejects this no-op temporalization.

**Status:** `SURVIVES`.

### A03 — direct-V554 starvation test

Constructed case: a complete point/static admission or already-governed interval is structurally admitted, exact for the target use, and explicitly accepted by a V554 affordance rule. Remove V553 from the path.

Nothing V553 owns is lost because no new temporal operation is requested. V554 still creates the first new downstream meaning, while the admission/fact/query/universe/authority chain remains reachable through immutable provenance references. Refusing the direct edge would either starve the lawful V554 use or require a no-op V553 object.

**Status:** `SURVIVES`.

### A04 — direct + temporal duplicate-path attack

Constructed case 1: the same admission can be presented directly and through a V553 compatibility/no-op temporal object for the same V554 proposition/use/rule. R02's immutable `basis_kind` rule selects one basis family and prohibits union-by-presence; that law is sufficient at the conceptual level.

Constructed case 2 is harder: admission `A` and reissued/alias admission `A2` encode the same governed structural proposition while carrying different receipt IDs or lineages; one path is direct and the other reaches V554 through V553. R02's proposed conceptual key includes both semantic proposition identity and originating admission lineage, but the exact canonical proposition-equivalence rule and serialization are explicitly deferred to the V554 close-read.

Therefore R03A cannot certify deterministic deduplication for alias/reissued-lineage cases from the binding repository authority. The safe rule is:

- lineage is provenance unless a governing rule explicitly makes evidence/source lineage part of the structural proposition identity;
- canonical semantic equivalence for the exact V554 use must dominate mere receipt/lineage identity;
- if equivalence is `UNKNOWN`, neither path may be silently unioned or chosen by artifact order/latest timestamp.

**Status:** `BLOCKED_MISSING_AUTHORITY`.

### A05 — temporal negative authority / noncomparability

Constructed case: two source universes contain observations in the same calendar year with similar labels, but the source-universe relation or cross-source temporal comparability is unknown. A V554 use asks for a cross-source/time structural comparison.

Same-year timing and string similarity are not comparability authority. D15 requires explicit source/universe applicability and positive universe relation authority where linkage/harmonization/composition is needed. Therefore:

- direct V554 must not treat `same year` as temporal completeness for this cross-source use;
- V553 may not manufacture source equivalence;
- if V553 has a positively governed temporal comparison over already-lawful comparable inputs, it may produce the comparison/limit;
- otherwise the result is typed `NONCOMPARABLE`, `MISSING_AUTHORITY`, or an equivalent fail-closed negative state; independent admissions may remain plural where authority permits.

R02 already blocks direct use when comparability is unresolved, but its phrase `source/time comparability -> V553` needs this authority qualification so V553 is not mistaken for a source-universe equivalence court.

**Status:** `SURVIVES_WITH_QUALIFICATION`.

## 5. Non-dispositive finite routing predicate proposed for close-read

This predicate is a feeder recommendation, not a final architecture ruling.

Let:

- `A` = one valid `StructuralEmpiricalAdmission`;
- `U` = exact downstream structural proposition/use and immutable V554 rule version;
- `DIRECT_ELIGIBLE(A,U)` = V554 rule explicitly accepts direct admission basis;
- `TIME_COMPLETE(A,U)` = exact time/interval/scope required by `U` is positively governed in `A`, including any required source/universe relation;
- `NEEDS_V553(A,U)` = `U` requires any new V553-owned temporal/comparability semantic not already lawfully contained in `A`;
- `V553_AUTH(A,U)` = positive authority exists for that exact temporal/comparability operation;
- `TEMPORAL_BLOCK(A,U)` = applicable typed temporal/source noncomparability, ambiguity, or missing-authority state;
- `EQ(X,Y,U)` = canonical semantic equivalence for the V554 proposition/use/rule, with result `SAME | DISTINCT | UNKNOWN`.

Recommended predicate:

```text
if A is not positively structurally admitted for U:
    NO_POSITIVE_ROUTE

else if TEMPORAL_BLOCK(A,U):
    if V553 owns a governed negative/limit result for the exact operation:
        V553_NEGATIVE_OR_LIMIT_ONLY
    else:
        NO_POSITIVE_ROUTE

else if NEEDS_V553(A,U):
    if V553_AUTH(A,U):
        ROUTE A -> V553 -> V554
    else:
        NO_POSITIVE_ROUTE__MISSING_AUTHORITY

else if TIME_COMPLETE(A,U) and DIRECT_ELIGIBLE(A,U):
    ROUTE A -> V554

else:
    NO_POSITIVE_ROUTE__TEMPORAL_COMPLETENESS_OR_V554_ELIGIBILITY_UNPROVED
```

Negative routing law:

```text
HAS_TIMESTAMP
OR HISTORICAL_SOURCE
OR V553_ARTIFACT_PRESENT
!= NEEDS_V553
```

Source relation law:

```text
SAME_YEAR
OR SAME_LABEL
OR SAME_CANONICAL_VALUE
!= CROSS_SOURCE_COMPARABILITY_AUTHORITY
```

Duplicate law:

```text
for each exact V554 proposition/use/rule:
    immutable rule selects one basis_kind
    if EQ(candidate_1, candidate_2, U) == SAME:
        admit at most one semantic basis
    if EQ(...) == DISTINCT:
        coexist only as separately identified propositions/use participants allowed by rule
    if EQ(...) == UNKNOWN:
        FAIL_CLOSED; do not union, latest-win, score-win, or artifact-order select
```

A receipt/admission lineage may participate in semantic identity only when the governing structural rule says that source/evidence lineage is itself part of the proposition. Otherwise lineage remains provenance and must not defeat semantic deduplication.
