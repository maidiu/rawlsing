## 3. Classification method

`RETENTION_CAPABILITY_MATRIX.csv` is a wide matrix with one row per candidate and one classification column for each of the 31 commanded information dimensions. This is equivalent to 310 candidate×dimension adjudications.

The classification vocabulary is used literally:

- `PROVEN_CAPABLE_IN_PRINCIPLE` — no information-theoretic obstruction exists if the stated retained fields/identities are exact.
- `PROVEN_INSUFFICIENT` — at least two distinct deeper empirical states can map to the same surviving candidate, so exact inversion is impossible.
- `CAPABLE_ONLY_WITH_EXTRA_METADATA` — the physical observations may be sufficient only if exact topology/authority/provenance/branch/design metadata survives alongside them.
- `CAPABLE_ONLY_FOR_FIXED_QUERY_SET` — exact reconstruction is bounded to the questions/predicates/configurations already materialized in that candidate.
- `LOSSY_DERIVED_SUMMARY` — a non-invertible functional or composite view of a richer relation.
- `POPULATED_EQUIVALENCE_UNKNOWN` — current populated equivalence is not proved under D05.
- `STATIC_EQUIVALENCE_UNKNOWN` — exact external/static snapshot identity or completeness is not independently proved.
- `NOT_APPLICABLE` — populated/static equivalence is not a meaningful property of the theoretical candidate.

The equivalence status is carried separately from the per-dimension capability classification. This prevents the false move:

```text
schema has respondent_id
therefore
current populated cache is lossless
```

## 4. Candidate capability holdings

### C1 — Original/raw source snapshots

Raw source snapshots are a deep information carrier **in principle** for source-native respondent/event incidence when the exact original structure survives. This includes the possibility of preserving native routing, set-valued responses, repeated/ranked structures and source-native coordinates that a later projection did not choose.

That does not make a raw snapshot self-describing or self-governing. Canonical-wave identity, normalized-response semantics, weight authority, branch law, semantic authority, logical-content hashing and deterministic replay require extra metadata/crosswalk/provenance.

D13A does **not** claim the current external raw/source corpus has been statically or populatedly proven complete.

### C2 — Current Postgres respondent/response substrate

The core respondent + long-response relation is structurally capable in principle of arbitrary response-response conjunctions because the same respondent binder can connect multiple question rows.

It is not by itself a complete empirical algebra. Exact topology, routing/applicability, typed absence, survey-weight design authority, empirical-position coordinates, branch semantics and replay provenance require adjacent metadata/relations. A future empirical coordinate absent from the retained core respondent/response pair cannot be reconstructed merely from response rows.

All current populated-equivalence claims remain unknown under D05.

### C3 — Current normalized/facet-ready database surfaces

A respondent-linked facet-ready projection is structurally capable in principle of response×position and response-response reconstruction **for fields actually retained without multiplicity loss**. Its utility comes from preserving the respondent binder while attaching normalized scope/question/position/weight fields.

But normalization is a projection boundary. A source-native coordinate omitted from that projection cannot be recreated from the projection alone. Generic multiselect/repeated/ranked/routing semantics also require explicit topology/event metadata rather than inference from duplicate rows or cardinality.

D05 has not proved that the actual populated facet views preserve raw multiplicity/values or are source-equivalent.

### C4 — Current V550/V550J shared respondent substrate

The current shared-substrate contract is a real respondent-grain co-execution surface. It retains stable respondent/question/scope identity, normalized response and typed special-state fields, and it supports the **selected base + authorized V550J `JOINT_ONLY` union**.

That selection boundary is decisive. The current shared substrate is therefore capable of exact joint reconstruction only inside the questions/configurations it actually selected and retained; it is not an open-ended guarantee for arbitrary future coordinates/questions.

The required contract also lacks a generic `response_event_id`, set-member/order representation sufficient to prove lossless replay of arbitrary repeated, multiselect or ranked topologies. Position fields may be carried as extra columns, but they are not part of the required logical-column contract inspected here; exact position/branch/design replay therefore requires additional proof/metadata.

D05 leaves actual materialized cache equivalence unknown.

### C5 — Theoretical normalized respondent-incidence projection

A theoretical projection that **by definition** retains the D08 primitive information — exact respondent/event binder, native+canonical identities, typed response topology, routing/applicability/absence, respondent positions, governed measures and all source facts needed for future-authorized predicates — is information-theoretically capable of reconstructing the commanded empirical geometry.

This is a theorem about representation capacity, not an implementation recommendation.

Weight-design authority, branch-law provenance, semantic-authority versions, deterministic hashes and exact replay receipts remain metadata obligations even for a complete incidence projection.

### C6 — Selectively materialized E1 conditional facts

E1 facts are exact for the predicates, risk sets, targets and scopes actually materialized.

They are not a general replacement for respondent incidence. Selective E1 cannot recover an unseen XOR, unseen k-way response configuration, future conditioner, respondent membership, repeated-event structure or arbitrary same-person cotravel unless the exact needed conditional was already materialized.

Therefore E1 is a fixed-query carrier, not an invertible general incidence store.

### C7 — Selectively materialized E2 joint facts

An exact E2 contingency can preserve real higher-order joint geometry for its configured component set and can distinguish same-marginal/different-joint worlds inside that set.

Its boundary is the dimensions retained in the contingency. If a future query asks for a new conditioner/question outside those dimensions, the aggregate contingency cannot be reconditioned without respondent membership/deeper incidence.

D11 supplies a current concrete instance of this boundary: governed V550J aggregate joint-pattern semantics can pass downstream after exact respondent membership stops upstream.

### C8 — Current E3 cloud artifacts

Current E3 is a `LOSSY_DERIVED_SUMMARY`.

The current V550 cloud row preserves one selected modal joint cell plus conditional/baseline and association quantities built over non-identical risk sets. It does not preserve full pairwise contingency, respondent membership, branch membership or arbitrary k-way incidence.

Therefore distinct deeper empirical substrates can generate the same persisted E3 representation.

### C9 — Current E4 association summaries

Current E4 association summaries are non-invertible derived functionals.

An NMI/Cramér's-V/MI/lift-like score does not identify the contingency table that generated it, much less respondent membership, routing, topology or higher-order joint incidence. Same score does not imply same empirical geometry.

E4 can retain diagnostic identity/provenance metadata, but cannot act as an information-equivalent substitute for the underlying relation.

### C10 — Hybrids of source + cache + materialized facts

D13A deliberately does not define a particular hybrid and therefore cannot certify a generic hybrid as lossless.

The exact law is:

```text
hybrid information
=
union of information actually retained by components
subject to exact identity/provenance joins
```

A hybrid cannot resurrect a coordinate, routing state, event topology or respondent relationship that every retained component discarded. Conversely, a deep component may permit regeneration of a shallower cache/fact if its transformation and authorities are exact.

This is a capability law only. It does not select a hybrid architecture.

## 5. Hostile information-loss theorems

`CANDIDATE_FAILURE_CASES.csv` is a wide matrix with one row per candidate and one cell for each of 12 commanded hostile tests; each cell is `classification|outcome`. This represents 120 candidate×test rulings.

### P1 — Aggregate non-invertibility

Unary marginals, selective conditionals and scalar association summaries cannot reconstruct arbitrary unseen joint incidence.

Witnesses: XOR/parity; same marginals/different joint incidence; rare three-way configuration.

### P2 — Fixed-contingency boundary

A selected E2 contingency answers exact queries over its retained dimensions. It cannot be reconditioned on an absent dimension.

Witness: two populations identical on stored `(X,Y)` but different on `(X,Y,Z)`; a later query asks for `P(Y | X, Z)`.

### P3 — Event/topology boundary

A scalar respondent/question row key is not enough to distinguish one multiselect `{A,B}`, two repeated scalar events `A` then `B`, a duplicate ingestion, and a ranked pair `A > B`. Without typed event/set/order structure these worlds can collapse.

### P4 — Branch identity boundary

`branch_id` is not branch membership. Branch-conditioned replay requires exact respondent membership or an exact deterministic branch predicate plus all incidence needed to rerun it, with branch-law/provenance identity.

### P5 — Hybrid union limit

If every component of a hybrid discarded some distinguishing information, combining those components cannot recreate it. Adding E3/E4 summaries to E1 marginals does not restore respondent incidence.

### P6 — Populated-equivalence separation

Static representational capacity does not prove current populated source equivalence. This applies to current Postgres, facet-ready, shared-substrate and current E1/E2/E3/E4 materializations.

## 6. Hostile query consequences

The failure matrix directly tests XOR, Simpson reversal, rare three-way conjunction, routed conditional, repeated response, multiselect, future unmaterialized coordinate, branch-conditioned distribution, response-response cotravel, same-marginal/different-joint incidence, minority configuration and exact replay.

The non-ranking result is that candidates fail for different information reasons:

- source/respondent incidence carriers depend on topology/authority/provenance completeness;
- fixed E1/E2 facts fail outside their materialized dimensions;
- E3/E4 fail because their transforms are non-invertible;
- hybrids inherit both information retained by components and every dimension lost by all of them.

D13A does not convert those differences into a preferred substrate.
