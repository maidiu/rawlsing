!= `ENCOUNTER`

!= `ROUTE REALIZATION`

### ADP-010

- AVAILABLE = addressable basis, no history.
- OPPORTUNITY = actor-specific possibility, no occurrence.

Knowledge requires objective support **and** an actor-facing acquisition/recognition basis **and** an owning rule that emits the exact knowledge effect.

Belief requires an exact canonical claim, an exact generated/admitted V3 parent/transition and an owning rule that emits the belief content/polarity.

Neither objective truth nor exposure nor memory existence is sufficient.

### CAN-008

Response requires an exact generated/admitted causal parent and exact response rule. Raw structural pressure, prevalence, demographics, unrealized V555 routes and unrealized V556 interactions are forbidden direct response parents.

This is the machine's anti-puppet membrane.
