# D12C — D09 Population-Meaning-Field Admission Requirements

**Status:** D12 feeder evidence only.  
**Source D09 law:** `POPULATION_MEANING_FIELD` is a lawful population-level semantic distinction; it is not generated actor position, belief or psyche.

This document answers one question only:

> What minimum authority must exist before a D09 population-meaning-field distinction may lawfully affect each later stage?

The required authority is additive. A later-stage rule cannot silently repair an earlier missing transformation.

---

## General admission law

A population-meaning-field fact must preserve its own empirical identity before any structural use:

- source / source-family;
- wave / canonical wave;
- country/native scope;
- target question/component;
- response topology;
- exact condition predicate;
- exact risk set / denominator;
- raw/governed weight basis;
- typed missing/special states;
- branch/cohort provenance when applicable;
- joint-configuration identity when applicable;
- semantic/directionality authority;
- admissibility/use permission;
- provenance and replay identity.

Equal numeric values under different predicates or risk sets are not equal facts.

No empirical fact receives, merely from being empirically real:

- a structural-position binding key;
- an actor membership probability;
- an actor propensity;
- an actor belief;
- a mediation route;
- a lived encounter;
- a memory;
- a response.

## A. E1 conditional empirical fact -> V552 structural interpretation

**Classification:** `MISSING_AUTHORITY`

Current D08/D09 law makes E1 a lawful empirical fact type. Current D11 law does not establish a canonical E1 structural consumer: exact response×position conditional meaning is not proven preserved by the canonical V551/V552 spine, and the V552 `conditional_determinicity` input is not a semantic build input.

### Minimum authority required

A future lawful edge would need a versioned producer/interpreter rule that binds:

1. exact E1 empirical fact ID;
2. exact predicate and conjunction semantics;
3. risk set / denominator;
4. weighting basis;
5. source/wave/country/native scope;
6. response topology and semantic identity;
7. current directionality/structural semantic authority;
8. exact V552 structural target/type/use;
9. negative/unknown/missing/noncomparability behavior;
10. provenance/replay identity.

It must explicitly state whether the conditional fact is evidence for a structural pressure, relation, constraint, heterogeneity fact or some other already-governed structural semantic family.

It must **not** create actor position, actor probability or belief.

The current bounded path is:

`governed V550J pattern`
→ `V551J component/packet certification`
→ `V552J exact-scope association with a V552 structural fact`.

### Current minimum authority

The path requires:

- governed V550J joint configuration ID;
- exact component question/response identity;

- exact source/wave/country scope;

- joint semantic/measurement/structural signatures;

- arbitrary respondent conjunctions;

- association-index measurements as core packet semantics;
- arbitrary cloud geometry;
- actor worldview or belief.

A branch label or tree summary is not enough.

### Current minimum authority

The candidate must match one ADP-001 signature and preserve:

- focal V552 structural fact ref;
- exact V552J association/admission/use permission ref;
- semantic/directionality/position/use authority refs;
- final source/family/country/native scope;

No descriptive rematch, score threshold, interpolation, inferred actor membership or structural guess may fill a missing exact ref.

### Result ceiling

`ELIGIBLE` means:

> this structural basis is eligible as structural mediation input.

It does not mean:

> an actor has this position, will encounter this mediation, or will respond in a particular way.

## F. Mediation candidate -> actual actor encounter/exposure

**Classification:** `ACTOR_DEVELOPMENT_REQUIRED`

The direct edge is forbidden.

ADP-010 owns actor-specific:

`AVAILABLE -> OPPORTUNITY -> ENCOUNTER -> EXPOSURE`.

A V555 route or V554/V556 structural ref may be an availability/constraint input. It is never by itself an encounter/exposure witness.

### Minimum current authority for OEE

- active generated actor/developmental phase;
- exact AVAILABLE basis and use permission;
- actor-specific opportunity basis;
- exact opportunity parent;
- exact independent contact witness for ENCOUNTER;
- exact presentation/impingement witness for EXPOSURE;
- lawful time/phase/bindings;
- provenance/replay;
- ADP-020 only if an exact stochastic rule explicitly requires it.

### Additional gap for actual route traversal

If the claim is:

> the actor actually traversed this V555 mediation route,

then ADP-010 is not enough.

ADP-011 must bind:

- route ID/hash;
- actor;
- causal/OEE parent;
- route-condition results;
- effective causal time;
- realization result;
- provenance/replay.

At the exact D12C base, ADP-011 is only a W3 launched authority cell. It is **not accepted current authority**.

Therefore no fallback route traversal is lawful.

## G. Exposure -> actor knowledge/belief

**Classification:** `ACTOR_DEVELOPMENT_REQUIRED`

The direct edge is forbidden.

ADP-010 explicitly defines exposure without awareness, absorption, memory, belief or response.

### Knowledge minimum

ADP-017 requires all of:

- exact canonical claim;
- objective support in the same scope;
- exact generated/admitted actor-facing acquisition or recognition basis;
- an owning V3 rule explicitly emitting `KNOWLEDGE` for that claim;
- sufficient actor role under that rule;
- verified causal parent/pre-state;
- complete authority/provenance.

Objective truth is necessary but not sufficient.

### Belief minimum

ADP-017 requires:

- exact canonical claim;
- exact generated/admitted causal parent or actor-state transition;
- owning V3 rule explicitly emitting exact belief content/polarity;
- actor/time/rule/pre-state/provenance integrity;
- no prohibited source promotion.

Belief may be objectively supported, contradicted or unresolved. Objective status does not automatically edit belief.

### Memory is separate

If exposure is to form memory, ADP-016 separately requires a typed memory effect over exact source-bound generated causal material. Memory existence or accessibility still does not automatically create knowledge/belief.
