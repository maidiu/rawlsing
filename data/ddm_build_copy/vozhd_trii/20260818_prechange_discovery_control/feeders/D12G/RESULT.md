## 4. Current code/authority findings that control this feeder

### 4.1 Source/wave/country canonicalization is not composition authority

`ddm_survey_identity.py` explicitly keeps source family and wave identity explicit, normalizes aliases, refuses silent country guessing, and states that family adapters may normalize naming but may not create authority.

Therefore:

```text
canonical_family_key(A) == canonical_family_key(B)
```

proves a family-name equivalence, not:
- same study release;
- same sample frame;
- same respondents;
- same target population;
- same questionnaire version;
- same weight design;
- lawful pooling.

Likewise:

```text
canonical_wave_key(source, rawA) == canonical_wave_key(source, rawB)
```

may prove that two labels refer to one canonical wave alias. It does not prove two arbitrary files are nonduplicative pieces of one sample.

### 4.2 Family overlays are source-scoped and fail closed

`ddm_v550_family_overlay.py` is family-dispatched and wave-alias aware. It validates source/wave columns when present and explicitly refuses a fallback that would let non-GSS sources inherit GSS authority.

This demonstrates a current design principle:

`shared semantic vocabulary != shared source authority`.

### 4.3 Response scales are contract identities

The current response-scale registry records:
- a `response_semantics_contract_hash`;
- response family;
- coordinate geometry/endpoints where applicable;
- scale direction;
- projection rule;
- exact source authority path/hash;
- authority row-set hash/status.

Consequently:

```text
same displayed label
!= same response event
!= same response topology
!= same numerical coordinate meaning
```

unless an exact contract equivalence or transformation authority says otherwise.

### 4.4 Current V553 temporal harmonization is deliberately narrow

`build_v553_wave_harmonization_report(...)` rejects:
- more than one survey family in one report;
- more than one country in one report.

It further requires:
- at least two waves;
- shared semantic signal structure;
- shared directionality structure;
- shared position structure;
- wave-specific certified authority.

Its output includes cross-wave comparability and noncomparability surfaces and preserves wave-specific differences.

This is positive evidence for:

`COMPARE_SEPARATELY` under exact within-family/country comparability.

It is not authority for cross-survey respondent joins, cross-country pooling, cross-family pooled structural estimates, or reverse-field source weighting.

### 4.5 V553 producer scope is exact

The current V553 canonical trust boundary checks producer run, source, wave, and country. Mismatches fail closed.

This reinforces that downstream harmonization depends on exact upstream scope rather than merely matching semantic labels.

### 4.6 D08 makes source/risk-set/measure identity part of the fact

## 5. Respondent universe definition

D12G defines an **empirical respondent universe** as:

> An authority-bound empirical observation/sample-space identity over a governed source/study release, instrument, geography, time, target population/sample frame/design, respondent namespace, questionnaire/routing/response semantics, measure/weight regime, and immutable provenance.

The identity dimensions are enumerated in `RESPONDENT_UNIVERSE_IDENTITY_MATRIX.csv`.

At minimum they include source family, source study/release, instrument/questionnaire release, country, sampling geography/locality, raw wave, canonical wave, field dates, sample frame, target population, sampling design, respondent identity namespace, question instrument/version, question semantic authority, response topology, response scale/encoding contract, routing/applicability/risk set, weighting regime/estimand basis, provenance/import lineage, harmonization authority, and respondent overlap/constituent relation.

Not every difference has the same consequence.

Two questions inside the same respondent universe can have different response topologies. That does not split the sample itself, but it prevents the response facts from being pooled as equivalent.

Conversely, two waves can use the same instrument semantics but remain distinct temporal respondent universes.

## 6. SAME_UNIVERSE standard

`SAME_UNIVERSE` is a positive classification, not a default.

It requires exact authority that the compared datasets are observations from the same intended sample universe, nonduplicative partitions/continuations/alternate representations with known lineage, and governed under materially compatible scope/design/instrument/weight identities for the intended operation.

The cleanest lawful row-concatenation case is two nonoverlapping shards of the same study/release/wave/country/sample frame, with one design and one instrument, where an immutable partition manifest proves nonoverlap and shared weight semantics.

Then `SAME_UNIVERSE` and `POOLING_AUTHORIZED` may both hold.

If the two representations contain the same underlying rows, `SAME_UNIVERSE` can hold while `POOLING_FORBIDDEN` also holds because counting both would duplicate evidence.

## 7. False respondent-join court

### 7.1 Exact authorization

`EXACT_RESPONDENT_JOIN_AUTHORIZED` requires positive authority for respondent namespace identity or cross-namespace linkage, stable person key, linkage grain, time/event identity, relevant geography/sample relation, question applicability/routing, repeated/multiselect/duplicate semantics, and immutable linkage provenance.

No generic current authority located in D12G proves cross-survey person linkage.

### 7.2 String-equal respondent IDs

String equality is insufficient.

If two independent source namespaces both contain `123`, joining those records creates fabricated same-person cotravel.

Known distinct namespaces: `RESPONDENT_JOIN_FORBIDDEN`.

Unknown relation: `RESPONDENT_JOIN_UNPROVEN`.

### 7.3 Different waves and panel linkage

Different waves are distinct temporal observation universes by default.

If exact panel authority proves person continuity, `EXACT_RESPONDENT_JOIN_AUTHORIZED` may be lawful for the authorized longitudinal query.

That does not imply `SAME_UNIVERSE` for the time-indexed observations and does not authorize one undifferentiated pooled cross-section.

### 7.4 Cross-survey response-response cotravel

Without exact respondent linkage: `RESPONDENT_JOIN_FORBIDDEN`.

Comparing `P_A(Q1,Q2)` with `P_B(Q1,Q2)` can be lawful if both joint facts exist and are harmonized.

Constructing `P(Q1_A,Q2_B)` by pairing unrelated respondents is not.

## 8. Naive pooling court

### 8.1 Pooling authorized

`POOLING_AUTHORIZED` only when a positive composition authority establishes one intended sample/estimand, nonduplicate components, compatible target population/sample frame, compatible field-time scope for the intended estimand, exact instrument/question relation, compatible routing/risk set, response topology equivalence, compatible design/weight basis, and exact provenance/overlap treatment.

### 8.2 Harmonized but distinct

Two universes can be semantically harmonized and remain distinct.

Then the default is `POOLING_REQUIRES_HARMONIZATION_AUTHORITY` plus `COMPARE_SEPARATELY`.

“Harmonized” means some dimensions are declared comparable. It does not mean counts or respondents become additive.

### 8.3 Pooling forbidden

`POOLING_FORBIDDEN` applies when target populations are incompatible and no target estimand reconciles them; response topology/scale is incompatible without transform authority; question semantic equivalence is unresolved; joining requires fabricated respondent identity; one representation duplicates the other; weights/designs would be summed without a governed common estimand; or overlap/constituent structure makes naive addition double-count.

## 9. Weight / double-counting court

D12G inherits:
- D08: raw and weighted facts are different measure bases;
- D13B: missing/invalid weights cannot become unit weights for replay proof;
- D13C: current shared substrate can default missing `weight_value` to `1.0`, so that surface does not prove source-equivalent weighting semantics;
- D05: actual populated weight coverage is unknown.

Therefore different source weights cannot be converted into a single cross-source weight by intuition.

No “larger N gets more weight,” “more local gets more weight,” “more recent gets more weight,” or equal-source weighting rule is authorized here.

Any future combination must state its target estimand, sampling/design assumptions, source dependence, weight transformation, and uncertainty behavior.

### Double-counting risks

D12G identifies these semantic risk classes:

1. same source study imported twice;
2. original rows plus a harmonized derivative of the same rows;
3. regional product plus an included country sample;
4. pooled product/wave plus constituent observations;
5. linked panel observations counted as independent where the query assumes independent persons.

Required provenance includes original study/release, immutable source artifact hash, import/extraction instance, sample frame/target population, field dates/wave, respondent namespace, member-set/overlap identity where lawfully available, parent/derived relation, constituent/subsample/pooled relation, harmonization transform/version, weight basis/recalibration, questionnaire version, and one-count-only/dedup rule.

Under the no-DB law, D12G does not assert that any named production source actually overlaps another.

## 10. Service A — autonomous forward social discovery

### Within-universe discovery

Forward discovery may search unary conditionals, empirical conjunctions, response-response cotravel, higher-order response configurations, minority configurations, social forks, and reversals when their workload/query authority and required E0/E1/E2 information are present.

### Cross-universe discovery

Cross-universe autonomous discovery is a different operation.

It may search for recurrence of a fork across sources, reversal of a conditional relation, geographic or temporal divergence, configurations found only in one source, minority configurations absent elsewhere, noncomparability itself, and source disagreement.

The result remains a comparison over source-indexed facts.

It may not synthesize a respondent vector across surveys.

Case G is decisive:

```text
Survey A: income + religion + Q1
Survey B: education + Q1 + Q2
```

Lawful discovery can inspect income/religion/Q1 relationships inside A, education/Q1/Q2 relationships inside B, and Q1 cross-source comparison if Q1 equivalence is governed.

It cannot claim observed empirical `income × religion × education × Q1 × Q2` because no respondent universe observed that joint.

## 11. Service B — reverse positioned-subject empirical possibility field

Parent corrective 15 requires this target service.

D12G does not decide which generated actor properties bind to empirical conditioners. That remains a separate authority seam.

It does decide that every candidate empirical universe needs its own **universe applicability** before contribution.

For each source, authority must establish as applicable target geography/population, time, questionnaire/construct, response topology/scale, empirical condition availability, routing/risk set, support/uncertainty, sampling/weight basis, and provenance/overlap.

### Beirut test

Suppose the generated actor is in Beirut.

Candidate evidence:
1. Beirut/local;
2. Lebanon-national;
3. Arab-regional;
4. global.

No automatic hierarchy follows.

Locality closeness is not sufficient. Country identity is not sufficient. Sample size is not sufficient. Recency is not sufficient.

Each source is independently admitted or rejected for the query.

When several sources are admitted: `SOURCE_INDEXED_FIELD_REQUIRED`.

When they disagree: `DISAGREEMENT_IS_INFORMATION`.

If regional/global evidence is introduced to compensate for sparse/absent local evidence: `BACKFILL_REQUIRES_EXPLICIT_AUTHORITY`.

Backfill must remain typed as broader-universe evidence. It cannot masquerade as direct Beirut evidence.

D12G assigns no actual source weights.

## 12. Service C — structural/stratal field production

Structural evidence can have a different lawful source set from reverse possibility inference.

A broad regional survey might be lawfully useful to one structural producer and not lawfully applicable as reverse positioned-subject evidence.

A local survey might be applicable to reverse inference while lacking authority to create a particular structural fact.

Therefore:

```text
STRUCTURAL_SOURCE_ADMISSIBILITY
!=
REVERSE_FIELD_SOURCE_APPLICABILITY
!=
FORWARD_DISCOVERY_WORKLOAD_AUTHORITY
```

The current machine supplies no generic source hierarchy that applies to all three.

Final R1 is source-implementation-specific semantic/structural authority, not multi-universe pooling authority.

Current V553 temporal harmonization is a bounded same-family/same-country structural temporal comparison surface, not a general cross-survey structural aggregation rule.

## 13. Disagreement semantics

D12G recognizes these lawful disagreement states:

- multiple source-specific empirical facts;
- source-indexed reverse possibility components;
- uncertainty/ambiguity;
- temporal change, when temporal comparability is governed;
- geographic heterogeneity, when geographic comparability is governed;
- instrument non-equivalence;
- target-population/design non-equivalence;
- unresolved contradiction.

The detailed law is in `SOURCE_DISAGREEMENT_SEMANTICS.md`.

A supported configuration in source A cannot be erased because source B lacks it.

Nor does a source disagreement authorize actor ambivalence, actor belief probability, cultural essence, generated structural position, or a latent ideology label.

- **I — equal ID strings, different namespaces:** `RESPONDENT_JOIN_FORBIDDEN`.
- **J — different weighting regimes:** `POOLING_REQUIRES_HARMONIZATION_AUTHORITY`; no invented weight combination.
- **K — different target populations:** `DISTINCT_UNIVERSES`; `POOLING_FORBIDDEN`.
- **L — minority supported in A, absent in B:** `SOURCE_INDEXED_FIELD_REQUIRED`; `DISAGREEMENT_IS_INFORMATION`.
- **M — closer but smaller vs farther but larger:** no automatic ranking; `BACKFILL_REQUIRES_EXPLICIT_AUTHORITY`.
- **N — sparse local vs broad regional:** regional substitution is not automatic; `BACKFILL_REQUIRES_EXPLICIT_AUTHORITY`.

## 16. Requirements on any future multi-universe combination

D12G does not design a hierarchical model, but any lawful combination would have to preserve:

1. explicit target estimand/population;
2. source/universe index;
3. instrument/question equivalence;
4. topology/scale transformation status;
5. time/geographic applicability;
6. sampling design and weight basis;
7. source overlap/dependence/constituent relation;
8. source-specific support/uncertainty;
9. disagreement residual/heterogeneity;
10. exact provenance to each source fact;
11. typed exclusions/noncomparability;
12. service-specific permission.

A pooled scalar that deletes those identities is not a semantic substitute for the source-specific facts.
