# D15 — MIGRATION AND EQUIVALENCE PLAN

## 1. Migration principle

The target is introduced **side-by-side**, not by deleting the current V550/V550J/V551/V552 surfaces first.

Every retirement requires positive evidence that the replacement preserves the intended capability/meaning. Source retirement has an additional independent source-native equivalence gate.

No production deletion is authorized by D15.

## 2. Gate G00 — authority/object freeze

Before implementation:

- install/review target object schemas;
- install authority contracts from `AUTHORITY_ADDITION_AND_REPAIR_LEDGER.csv`;
- freeze typed absence/noncollapse rules;
- freeze C11 semantic projection and content-address identity;
- freeze D15 acceptance fixture versions.

**Pass:** every implementation cell can name its producer, consumer, authority, prohibited inference and replay identity.

## 3. Gate G01 — concrete C11 implementation exists

Build source-universe-scoped append-only normalized incidence and immutable authority manifests for a bounded source fixture first.

Must represent M01–M18, especially response-event multiplicity/topology, routing, future-authorizable coordinates and weights without current shared-substrate scalar assumptions.

**Pass:** static schema/object validation + synthetic T01–T18/P01–P20 fixture capability.

## 4. Gate G02 — source -> C11 equivalence

For each source/instrument release migrated:

1. identify immutable source snapshot(s);
2. bind questionnaire/instrument/topology/routing/weight semantics;
3. compare source-native event incidence to C11;
4. run D13B P01–P20;
5. run all applicable D12 T01–T18 hostile fixtures/replays;
6. verify canonical semantic hash covers every proof-relevant field;
7. verify no first-row/scalar/default-fill loss;
8. verify source-universe/derivation/overlap provenance.

Possible results:

- `SOURCE_TO_C11_EQUIVALENCE_CERTIFIED`
- `SOURCE_TO_C11_EQUIVALENCE_FAILED`
- `SOURCE_TO_C11_EQUIVALENCE_BLOCKED`

Only the first permits later consideration of source retirement. It does not itself delete anything.

## 5. Gate G03 — exact EmpiricalQueryEngine

Run T01–T16 against C11 without relying on current derived artifacts.

Mandatory:

- unary distribution;
- single/multi-coordinate conditionals;
- response×position conjunction;
- pair joint;
- k-way parity;
- minority;
- routing/typed absence;
- multiplicity/topology;
- temporal/source distinction;
- comparator-ready predicates;
- exact reverse query building blocks.

**Pass:** exact results/typed failures are deterministic under exact semantic identity.

## 6. Gate G04 — current-path semantic parity where intentionally retained

For current semantics that D15 preserves, shadow-run target facts against current outputs after normalizing known current defects/limitations according to accepted law.

Examples:

- answer/country distributions;
- prepared-frame unary crosstabs where topology is lawful;
- bounded governed V550J joint patterns/membership;
- current intentionally retained structural evidence inputs.

A mismatch is triaged as:

- target defect;
- current known defect;
- semantic authority difference;
- source/C11 ingest difference;
- measurement blocker.

Do not force parity with a current behavior already adjudicated defective or lossy.

## 7. Gate G05 — structural admission parity and V553 revalidation

Implement compatibility admission rules reproducing intentionally retained V551/V552 and V551J/V552J semantics.

Shadow:

```text
current V551/V552 path
vs
EmpiricalQueryEngine -> StructuralEmpiricalAdmission -> V553 target intake
```

Verify:

- same lawful structural interpretation;
- same or stricter negative authority;
- exact empirical query/source provenance survives;
- temporal/comparability V553 outputs remain equivalent where intended;
- broader empirical facts remain blocked without positive admission.

**Pass:** V553 receives corrected input without acquiring generic survey-interpretation jurisdiction.

## 8. Gate G06 — V554–V558 downstream regression/revalidation

Run existing accepted V554–V558 architecture fixtures plus new provenance/input-version fixtures.

Verify:

- V554 affordance semantics unchanged;
- V555 remains structural mediation possibility;
- V556 remains structural pressure-flow topology;
- V557 remains lossless publisher;

- no PositionedSubjectEmpiricalPossibilityField enters the structural repository.

**Pass:** `V553_PLUS_REVALIDATION_MATRIX.csv` rows with no semantic change remain true under implementation.

## 9. Gate G07 — autonomous discovery coverage/replay

Implement DiscoveryAuthority plus `EXACT_BOUNDED` first.

Mandatory fixtures:

- unexpected lawful fork;
- all-pair winner excluding strongest unary;
- XOR/zero unary signal;
- Simpson/conditional reversal;
- rare third category;
- recursive secondary/tertiary branch;
- branch-conditioned cotravel;

- order/permutation replay.

Then implement `ADAPTIVE_EXPLORATORY` with explicit non-exhaustive receipt.

**Pass:** coverage claim equals actual evaluation/pruning law and deterministic replay reproduces result/typed-empty state.

## 10. Gate G08 — actor comparator authority

For each first supported comparator family:

- positive exact comparator;
- range/band comparator;
- temporal mismatch;
- source-specific semantic mismatch;
- no comparator;
- ambiguous comparator;
- actor property missing.

**Pass:** exact predicate/receipt or typed failure; no fuzzy/geographic-nearest/structural-position fallback.

## 11. Gate G09 — reverse possibility field

Run unary and J-way fields over one and multiple source universes.

Mandatory:

- conjunction conditioning;
- pair joint;
- k-way parity;
- low support;
- zero support;
- target unavailable;
- routed target;
- source disagreement;
- noncomparable source;
- sparse J-way support.

**Pass:** exact source-indexed field; no independent marginal product; no direct actor state.

## 12. Gate G10 — V3 metabolism boundary

Add `V3EmpiricalPossibilityInput` and explicit metabolism authority.

Mandatory:

- field cannot directly set belief/response/identity/memory/knowledge;
- generated structural position is not comparator bridge;
- same field + same structural context can yield divergent lives under different histories;
- replay includes field refs plus actual V3 causal history and lawful randomness;
- no reverse field leaks to V2 except through developed actor state/accessibility authority.

**Pass:** AT16/AT17 and V3 revalidation rows.

## 13. Gate G11 — cache/materialization shadow

Introduce caches only after exact uncached behavior is proven.

For E1/E2, branch membership, comparator receipts, reverse fields, temporal/source components and diagnostics:

- warm result equals cold result;
- key mutation causes miss;
- authority/C11 version change invalidates;
- eviction leaves terminal workload intact;
- stale result never becomes authoritative.

**Pass:** AT23.

## 14. Gate G12 — retirement eligibility

Artifacts may become retirement-eligible only after their replacement capability is positively proven.

### Derived current facts

Answer/country distributions, matrices and bounded joints may cease mandatory materialization after exact query + consumer/admission parity.

### Superseded search/tree/cloud shapes

Secondary summary, recursive tree, branch co-signature and cloud authoritative uses may retire after AT01–AT20 demonstrate replacement capabilities; diagnostic views can remain optionally.

### Shared substrate

Current V550/V550J shared substrate may retire only after every source/workload depending on it has migrated to a concrete C11 implementation passing G01–G04 and no current consumer remains dependent on the old surface.

### V551/V552 packaging

Packet/table shapes may retire only after structural admission/V553 compatibility parity and downstream V554–V558 regression pass.

### Source snapshots

Source retirement is **separate**: only a positive per-source G02 equivalence receipt plus later explicit governance can authorize it. D15 does not authorize deletion.

## 15. Negative-authority verification

Every gate includes tests for:

- missing authority;
- denied use;
- unknown/unresolved;
- no comparator/ambiguity;
- source nonapplicability;
- not-asked/IAP/DK/refusal;
- zero support vs observed zero;
- low support;
- uncertainty unquantified;
- noncomparability;
- coverage not claimed;
- replay hash mismatch.

Typed failure parity is part of equivalence.

## 16. Multi-universe / double-counting validation

Before any positive linkage/pooling/backfill implementation:

- prove universe identities;
- prove linkage namespace/person relation;
- prove estimand/sample/design compatibility;
- prove weights/nonduplication;
- record original/derivative and pooled/constituent relation;
- verify one-count rule.

Default remains source-indexed separate facts.

## 17. Shadow execution strategy

Recommended migration order is read-only/shadow first:

1. build C11 beside current pipeline;
2. produce target facts beside current outputs;
3. compare exact semantic identities;
4. feed target structural admissions into shadow V553+ path;
5. run discovery/reverse/V3 experimental fixtures outside current production semantics;
6. switch consumers only after gates pass;
7. retire old materialization later.

## 18. Blocked empirical/runtime dimensions

Actual populated source equivalence, performance, bytes, selectivity and savings remain measured implementation facts. A gate requiring those measurements stays blocked until the data/implementation exists, but this does not reopen architecture.

## 19. Migration theorem

No semantic capability disappears at the moment its old artifact is retired. The replacement capability must already be alive, exact and positively validated.

`BUILD -> PROVE -> SHADOW -> SWITCH -> RETIRE_ELIGIBLE`, never `DELETE -> RECONSTRUCT_LATER`.
