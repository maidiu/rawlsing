## 5. D12G — cross-survey / multi-universe composition

**Parent disposition:**

`ACCEPTED__DISTINCT_UNIVERSES_BY_DEFAULT__SOURCE_INDEXED_COMPOSITION__EXACT_AUTHORITY_REQUIRED_FOR_JOIN_POOLING_BACKFILL`

Accepted universe identity law:

A respondent universe is an authority-bound empirical observation/sample-space identity over source/study release, instrument, geography, time, target population/sample frame/design, respondent namespace, question/routing/topology semantics, measure/weight regime and immutable provenance.

By default:

- different waves are distinct universes;
- different countries are distinct universes;
- different instruments are distinct universes;
- harmonized does not mean same universe;
- canonical alias does not create sample equivalence;
- same label does not create topology equivalence;
- string-equal respondent IDs do not create person linkage.

Respondent-level cross-universe joins require positive person-linkage/namespace authority and retained linkage provenance. Exact person linkage may join observations across distinct universes without converting them into one undifferentiated cross-sectional sample.

Pooling requires positive estimand/sample/design/topology/weight/nonduplication authority. Original + harmonized derivative, pooled product + constituents, and regional + included country sample create explicit double-counting risk.

For reverse possibility fields:

- each source/universe requires independent service-specific applicability authority;
- locality or country identity alone does not assign a priority weight;
- broader-source backfill requires explicit authority;
- admitted source components remain source-indexed;
- disagreement is information, not noise to be silently averaged away.

For forward discovery:

- respondent-bound discovery occurs within a lawful universe unless exact linkage exists;
- cross-universe analysis is comparison of source-indexed facts, not invented same-respondent cotravel.

For structural-field production:

- source admissibility is separately governed and need not use the same hierarchy as reverse inference or forward discovery.

No statistical composition model or numeric source weighting is selected.
