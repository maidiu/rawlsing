# 04 — Discovery Courts Register

**Status:** `PRECHANGE_DISCOVERY_CAMPAIGN`  
**Rule:** courts investigate; they do not implement production changes.

The work is intentionally decomposed so one attractive theory cannot silently answer several different questions. Each court returns evidence, contradictions, a finite verdict, and explicit unresolved authority. Parent Vozhd Trii synthesizes only after the relevant courts close.

## Priority model

- **P0:** foundational; later courts depend on it or redesign would otherwise be unsafe.
- **P1:** required before architecture synthesis.
- **P2:** useful before implementation sizing, but may follow semantic closure.
