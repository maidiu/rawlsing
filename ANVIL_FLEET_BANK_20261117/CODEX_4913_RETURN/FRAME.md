1. **Real capital exists, but its acceptance boundary is narrower than its names.** Exact-key C11, M01–M18 closure, typed absence, I03/I05 and atomic closure are real code. The prepared saved I03 session is a `TEST_ONLY` candidate at this cut. Batch/NORMAL/resume remain typed owner handoffs. No accepted native 1/10/100 cost parity or 100k/6 GiB run exists.

3. **The analytical primitives are present, the scientific first effect is not.** Joint composition, recursive handoff, diagnostics and effective N exist; independent equivalence to historical DDM and a real joined F1–F4 first effect are unproved.
4. **The historical 118-record transfer is genuinely missing.** No accepted `ANVIL_SPINE_R5/R6` file exists in the package, reference ZIPs, old run or exact Git cuts. Only explicitly synthetic examples were found. The frame records the exact hold; it does not manufacture rows or relabel a synthetic spine.
5. **Downstream nonpreclusion is a real constraint now.** Even though N9/N10W/FF02/SOROK are not current science, the C11 and query interfaces must preserve source/time/universe/authority/member distinctions so those later consumers are not forced into a rewrite.
