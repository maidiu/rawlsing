# Authority boundary and method

## What this tranche governs

- Stable all-nine implementation and source-local lineage identities.
- Group-level policies for 146 recurring exact normalized propositions.
- Pair-level rulings for 751 high-precision exact/inherited-content candidates.
- Explicit relation type, authority status, confidence, evidence provenance and portability ceiling for each pair ruling.
- A complete registry of 200 inherited cross-source semantic neighborhoods and their full 136,329-pair discovery surface.
- A bounded 18,831-row priority queue: at most 25 candidate pairs per semantic-neighborhood/source-pair cell.
- Exact memberships for all 2,499 source structures, recovered from governing exposed files or governing nested source packages.
- Nineteen exact-label structure-analogy candidates, retained as provisional review prompts.
- A semantic/driver/position/strata/horizon bridge preserving available coordinates and missingness.

## What it does not govern

- J-family membership, joint propositions, collision hyperedges or executable family registries.
- Respondent-level joins, patterns, scores or inference.
- Database writes or modifications to V550/V551/V552/V552J/V553.
- Equivalence inferred from an inherited semantic ID, translated gloss, shared target label, source-structure label or response topology alone.
- Raw-value portability for demographic, administrative, asset or derived-index coordinates.

## Exact proposition method

Exact recurrence is adjudicated by proposition type rather than accepted wholesale:

- Full propositions can support cross-source proposition identity; response and implementation differences set the ceiling.
- Demographic and administrative labels can support coordinate-level comparability only when both records are typed as coordinates and neither is a scalar, multiselect shell or differently referented construct.
- Material-asset labels can support target/context comparability only; ownership universe and coding remain source-versioned.
- Bare targets such as “parliament,” “the police,” or “abortion” remain unresolved until the relation axis and source parent are recovered.
- Generic prompt shells, “don’t know,” generic IDs and weights become negative authority rather than false equivalence.
- Inherited exact-content IDs without exact proposition evidence remain unresolved discovery candidates.

## Semantic neighborhood method

Inherited `semantic_content_id` values define discovery neighborhoods only. Every neighborhood records complete source/lineage membership and full Cartesian candidate count. The materialized queue is bounded for review efficiency; it does not erase the full surface. Exact item text, source-local semantic role, response topology and token overlap determine review priority, not authority.

## Structure method

Memberships are taken from governing source membership files. For GSS, WVS, EVS and Arab Barometer, those files were recovered from the governing nested source-package ZIPs; no row-range reconstruction is used. All 2,499 structure membership counts reconcile exactly. Structure analogies remain provisional until every member, target, relation axis, response frame and routing condition is adjudicated.
