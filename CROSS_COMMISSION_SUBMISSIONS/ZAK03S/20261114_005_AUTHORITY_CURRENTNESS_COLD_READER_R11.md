## Finding 2 — Three different kinds of selection/currentness

**(a) Historical QSM:** a selected old source file, row payload hash, authority rule/version, source/wave/country and question_id/var_code with F03 directional, neutral, blocked and certified-QUC branches. The ZAK02 primary record remains [here](https://github.com/maidiu/rawlsing/blob/bc71b590484bf18a4e5bb5201a65292a201816d3/UNIFIED_LOG_R1/ZAK02_AGENTB_RECON_20261114/00_RETURN.md). Its source retention does not prove active selection.
**(b) Z06 semantic current selection:** resolve_current_exact(authority_id, selection_receipt_ref) demands the exact latest governing release. Its resolve_historical_exact and the immutable AuthorityRegistry.resolve_exact intentionally keep older exact snapshots retrievable. These are two DIFFERENT uses of authoritative history; an archival ALLOW is not by itself current ALLOW. [current selector](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_authority_maintenance.py#L1190-L1213), [exact registry](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_empirical_authority.py#L212-L267).
**(c) U43 workload issuance:** CurrentDecisionResolver.resolve_current(decision_ref) must return an IssuedWorkloadRecord with source/science permissions, source edition, host/purpose, U/E_pre roots, jobs, currentness and scope. The Z06 interface instead returns AuthoritySnapshot by authority_id and selection receipt. These are not interchangeable interfaces or output contracts. [U43 contract](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L71-L130).

The protected [I03 use-fit function](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_empirical_query.py#L296-L440) checks explicit grammar/query operation/scope, and positive TARGET_USE_PERMISSION when its optional complete triple is declared. It does not itself take a Z06 current-selection receipt or selected historical QSM row. That can be entirely legitimate for a RAW inquiry; it cannot prove historical directional/structural permission.

## Finding 3 — Currentness revocation is graph-qualified

Z06 [SemanticDeterminantGraph](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_authority_maintenance.py#L527-L610) materializes authority→object and object→child dependencies. [Recompilation](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_authority_maintenance.py#L1626-L1698) requires each graph-affected object be replaced with a different exact ref or independently grounded as noncurrent. Its [lifecycle reader](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_authority_maintenance.py#L1705-L1818) refuses NOT_GOVERNED cases rather than treating unknown/cache-only objects as current. This is substantial, reusable operational engineering.

However, AuthorityMaintenanceExecutor defaults to an empty determinant graph unless supplied otherwise. Invalidation covers the registered graph, not unnamed external facts/readers by magic. Thus a perfectly formed Z06 release is not evidence of **whole QSM→I03→Batch→issued consumer graph completeness**. This is a source-scope qualification, NOT an observed live invalidation bug.

## Finding 4 — Current U43 admission versus completed checkpoint re-reading

Fresh [admit](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L219-L264) checks CURRENT_GRANTED, competent source/science refs, permitted original/test scope, host, purpose, exact source SHA, U/E_pre roots, expected jobs, envelope and original wave identity where required. [execute_issued_workload](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L280-L371) calls admit before source open and rechecks currentness before and after source and per QUERY/DISCOVERY unit. This is real operational functionality.

Cold [restore_joined_checkpoint](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L686-L765) demands an external checkpoint pin and verifies entry/manifest hashes. [resume_joined_workloads](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L767-L839) compares decision/source SHA/envelope identities. **PARTIAL/new** entries invoke execute_issued_workload and thus admission. A **COMPLETED** entry instead passes directly through _completed_entry_view and continues without admit. This avoids re-executing previously completed work and preserves historical output custody. It does not itself establish a NEW currently admitted scientific use of that archived output.

## Finding 5 — Output/input shape and first reader

Old selected QSM rule input: historical file bytes and row/version/question/variable tuple, source/wave/country, rule/use/eligibility. Old output: a governed relation-evidence/coverage/blocked disposition affecting downstream structural eligibility. Modern Z06 input: evidence receipts, source_release_ref, authority candidate scope/version and adjudication. Modern output: sealed AuthoritySnapshot plus current selection and dependent invalidation receipts. Modern U43 input: a different IssuedWorkloadRecord, canonical NativeWorkload envelope (projection, catalog, query/discovery refs, U/E_pre roots) and exact source. Modern output: Batch QUERY/DISCOVERY receipts and result refs. A restored completed result is an archived output view, not a new execution. The [closed envelope schema](https://github.com/maidiu/rawlsing/blob/6a5c12f04323d74001f9632063ec907f4fc4468e/rawlsing_next/pre553_issued_workload.py#L189-L217) has no separately required QSM row/version key; indirect encoded lineage may exist through catalog/queries but is not proved. The missing semantic join remains selected historical QSM row -> competent current source/scientific semantic issuer -> U43 exact decision -> independent consumer effect.
